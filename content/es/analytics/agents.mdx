# Analíticas de Agents

Visualiza métricas de rendimiento detalladas para todos tus agents. Compara volúmenes de consultas, conversaciones y uso de credits en todo tu portafolio de agents.

## Acceder a Analíticas de Agents

1. Navega a **Analytics** en la barra lateral
2. Haz clic en **View All** junto a "Top Agents", o
3. Ve directamente a **Analytics > Agents**

## Navegación

La ruta de navegación muestra tu ubicación: **Dashboard / Agents**. Haz clic en "Dashboard" para regresar a la página principal de analytics.

## Controles de Rango de Fechas

| Control | Descripción |
|---------|-------------|
| **Last 7 days** | Ver métricas de la última semana |
| **Last 14 days** | Ver métricas de las últimas dos semanas |
| **Last 30 days** | Ver métricas del último mes |
| **Last 90 days** | Ver métricas del último trimestre |
| **Refresh** | Recargar datos con los valores más recientes |

## Tabla de Agents

Todos tus agents listados con métricas de rendimiento:

| Columna | Descripción | Ordenable |
|---------|-------------|-----------|
| Agent | Nombre del agent | No |
| Status | active, inactive, testing o archived | No |
| Queries | Total de preguntas respondidas | Sí |
| Conversations | Sesiones de chat | Sí |
| Credits | Recursos consumidos | Sí |
| Channels | En qué canales se usa el agent | No |
| (Flecha) | Enlace a vista detallada | No |

### Ordenamiento

Haz clic en cualquier encabezado de columna ordenable para ordenar por esa métrica:
- **Primer clic**: Orden descendente (mayor primero)
- **Segundo clic**: Orden ascendente (menor primero)
- La columna de orden activa se resalta

### Paginación

Para listas grandes de agents:
- Muestra "Showing X - Y of Z"
- Usa los botones **Previous/Next** para navegar entre páginas

## Badges de Estado del Agent

| Badge | Color | Significado |
|-------|-------|-------------|
| active | Verde | El agent está desplegado y recibiendo consultas |
| inactive | Gris | El agent está pausado |
| testing | Amarillo | El agent se está probando antes del despliegue |
| archived | Amarillo | El agent está archivado |

## Badges de Canales

La columna Channels muestra en qué plataformas se usa cada agent:
- Se muestran hasta 3 badges de canal (ej., "web", "telegram", "discord")
- Si hay más de 3, muestra "+X" para indicar canales adicionales

## Ver Detalles del Agent

Haz clic en la flecha de cualquier fila de agent para ver:
- Métricas detalladas para ese agent específico
- Gráficos de series de tiempo
- Desglose por canales
- Datos más granulares

## Consejos

- Ordena por **Credits** para encontrar tus agents que consumen más recursos
- Ordena por **Queries** para identificar tus agents más populares
- Usa **90 days** para análisis de tendencias a largo plazo
- Revisa los agents inactive para ver si deberían reactivarse
- Haz clic en agents individuales para obtener insights más profundos

## Preguntas Frecuentes

**P: ¿Cómo encuentro mi agent más utilizado?**

Haz clic en el encabezado de la columna "Queries" para ordenar por cantidad de consultas. La primera fila es tu agent más activo.

**P: ¿Qué significan los badges de canales?**

Muestran desde qué plataformas (Web, Telegram, Discord, Slack, etc.) cada agent recibe consultas.

**P: ¿Por qué un agent muestra cero consultas?**

El agent puede ser nuevo, estar inactive, o no estar desplegado en ningún canal aún.
