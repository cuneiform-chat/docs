# Analytics

Monitorea el rendimiento de tus agents y comprende cómo los usuarios interactúan con tus chatbots.

## Descripción General

Analytics te ayuda a:
- Rastrear el volumen de conversaciones y patrones de consultas
- Monitorear el rendimiento de los agents y el uso de credits
- Comprender la distribución por canales
- Identificar áreas de mejora

## Dashboard

Accede a analytics desde la sección **Analytics** en tu barra lateral.

### Métricas Principales

| Métrica | Descripción |
|---------|-------------|
| Total Queries | Ejecuciones del agent (respuestas de IA) |
| Conversations | Número de sesiones de chat |
| Unique Users | Usuarios individuales que interactuaron |
| Credits Used | Credits de la plataforma consumidos |

### Uso de Credits

El dashboard muestra el consumo de credits del ciclo de facturación actual:
- Credits utilizados vs. asignados
- Barra de progreso con porcentaje
- Credits restantes para el período

### Gráficos

El dashboard incluye gráficos visuales:
- **Query Volume** — Gráfico de líneas mostrando consultas a lo largo del tiempo
- **Channel Distribution** — Gráfico circular desglosando consultas por canal
- **Agent Distribution** — Gráfico circular desglosando consultas por agent

### Top Agents

Una lista clasificada de tus agents más activos mostrando:
- Nombre del agent y posición
- Total de consultas procesadas
- Número de conversaciones
- Credits consumidos
- Estado actual (active, inactive, testing, archived)

Haz clic en cualquier agent para ver analíticas detalladas, o haz clic en **View All** para ver todos los agents.

### Top Channels

Una lista clasificada de tus canales de comunicación más activos mostrando:
- Nombre del canal y posición
- Total de consultas procesadas
- Número de conversaciones
- Credits consumidos

Haz clic en cualquier canal para ver analíticas detalladas, o haz clic en **View All** para ver todos los canales.

## Períodos de Tiempo

Visualiza analytics para diferentes rangos de tiempo:
- Ciclo de facturación actual
- Últimos 7 días
- Últimos 14 días
- Últimos 30 días
- Últimos 90 días

## Granularidad

Ajusta cómo se agrupan los datos:
- Por hora
- Diario
- Semanal
- Mensual

## Filtros

Filtra analytics por:
- **Agent** — Ver métricas para agents específicos
- **Channel** — Comparar rendimiento entre plataformas
- **Rango de fechas** — Analizar períodos de tiempo específicos

## Usando Analytics

### Identificar Patrones

Observa qué canales y agents manejan más consultas para:
- Optimizar la asignación de recursos
- Enfocar mejoras donde sea necesario
- Comprender las preferencias de los usuarios

### Monitorear Rendimiento

Rastrea tendencias para asegurar que:
- El uso de credits se mantenga dentro de los límites
- La participación de los usuarios sea saludable
- No haya patrones inusuales

### Optimizar Agents

Usa los insights para:
- Ajustar las personas de los agents
- Agregar documentación faltante
- Mejorar la precisión de las respuestas
