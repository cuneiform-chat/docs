# Opciones de Configuración

import { Callout } from 'nextra/components'

Guía detallada de todas las opciones de configuración del agent.

## Estructura de la página

La página de edición del agent tiene tres pestañas:

| Pestaña | Propósito |
|---------|-----------|
| **Configuration** | Configuración principal (estado, nombre, persona, LLM, mensajes) |
| **Knowledge Access** | Controlar qué documentos puede usar el agent |
| **Integrations** | Conectar a canales externos (Telegram, Discord, etc.) |

## Pestaña Configuration

### Status

Controla la disponibilidad de tu agent:

| Status | Playground | Integrations | Notas |
|--------|------------|--------------|-------|
| **Testing** | ✅ Habilitado | ❌ Deshabilitado | Predeterminado para nuevos agents. Prueba antes de lanzar. |
| **Active** | ✅ Habilitado | ✅ Habilitado | Listo para uso en producción. |
| **Inactive** | ❌ Deshabilitado | ❌ Deshabilitado | Temporalmente deshabilitado. |
| **Archived** | ❌ Deshabilitado | ❌ Deshabilitado | Oculto de la lista principal. |

<Callout type="warning">
  Si tu agent tiene integraciones conectadas y cambias de Active a otro estado, verás un diálogo de confirmación advirtiendo que el agent dejará de responder en los canales conectados.
</Callout>

### Configuración básica

- **Name** — Identifica al agent en tu dashboard
- **Description** — Notas internas sobre el propósito del agent

### LLM Configuration

Controla el modelo de IA que impulsa tu agent.

**Default Mode (Advanced toggle desactivado):**
- Usa los valores predeterminados del tier de tu organización
- Muestra un cuadro informativo explicando que se usan los valores del tier
- Recomendado para la mayoría de los casos

**Advanced Mode (Advanced toggle activado):**

| Configuración | Descripción |
|---------------|-------------|
| **Model** | Selecciona entre los modelos de IA disponibles según tu plan |
| **Temperature** | Controla la creatividad de las respuestas (0.0-1.0) |

#### Guía de Temperature

| Valor | Comportamiento |
|-------|----------------|
| 0.0 - 0.3 | Respuestas enfocadas y deterministas |
| 0.4 - 0.7 | Balance entre creatividad y consistencia |
| 0.8 - 1.0 | Respuestas más creativas y variadas |

**Recomendación:** Comienza con 0.3-0.5 para Q&A basado en documentos.

#### Show Document References

Este toggle (siempre visible independientemente del modo Advanced) controla si el agent incluye citas de fuentes en las respuestas:

- **Off** (predeterminado) — Las respuestas no mencionan documentos fuente
- **On** — Las respuestas incluyen referencias a documentos fuente

<Callout type="important">
  Activa las referencias a documentos para casos de uso que requieren transparencia, como legal, compliance o contenido interno donde los usuarios necesitan verificar fuentes.
</Callout>

### Soporte de idiomas

Tu agent detecta automáticamente el idioma de cada mensaje del usuario y responde en el mismo idioma — sin necesidad de configuración manual. Se soportan 176 idiomas de forma nativa, incluyendo árabe, francés, alemán, español, turco, chino, japonés y más.

### Agent Persona

Las instrucciones que controlan el comportamiento del agent. Consulta [Agent Personas](/agents/agent-personas) para mejores prácticas.

**Acciones disponibles:**
- **Generate** — Abre el [Agent Persona Builder](/agents/persona-builder)
- **Edit** — Abre un panel deslizante para escribir o modificar la persona directamente

Haz clic en el área de texto de la persona para abrir el panel de edición.

**Platform Rules Box:**
Haz clic para ver las reglas de confiabilidad de la plataforma que se aplican automáticamente a todos los agents:
- No fabrication — no inventará hechos
- Acknowledges gaps — dice "no lo sé" cuando corresponde
- Resists speculation — no adivinará información faltante
- No professional impersonation — no actuará como abogados, médicos, etc.
- Corrects false premises — señala suposiciones incorrectas
- Blocks harmful content — rechaza solicitudes inapropiadas

<Callout type="info">
  Las platform rules aseguran que todos los agents se comporten de manera confiable y segura. No se pueden desactivar ni modificar.
</Callout>

## Pestaña Knowledge Access

Controla qué documentos puede acceder tu agent al responder consultas.

### Modos de acceso

| Modo | Comportamiento | Cuándo usarlo |
|------|----------------|---------------|
| **Exclude Mode** | El agent accede a TODOS los documentos EXCEPTO los seleccionados | Ocultar documentos sensibles permitiendo acceso a todo lo demás |
| **Include Mode** | El agent accede SOLO a los elementos seleccionados | Restringir el agent a un conjunto específico de documentos |

### Opciones de selección

Ajusta el acceso usando múltiples tipos de selección:

- **Folders** — Selecciona carpetas completas y todos los documentos dentro de ellas
- **Tags** — Filtra documentos por sus tags asignados
- **Individual Documents** — Incluye o excluye documentos específicos dentro de las carpetas seleccionadas

### Vista previa de acceso

El panel de vista previa muestra el acceso efectivo a documentos basado en tus selecciones actuales. Úsalo para verificar tu configuración antes de guardar.

<Callout type="info">
  Comienza con **Exclude Mode** si deseas acceso amplio con restricciones específicas. Usa **Include Mode** cuando necesites control estricto sobre exactamente qué documentos puede referenciar el agent.
</Callout>

## Human Handoff

Habilita la transferencia de chat en vivo para que tu agent de IA pueda transferir conversaciones a un humano real cuando los usuarios lo soliciten.

**Cómo habilitarlo:**

1. En la pestaña **Configuration**, desplázate hasta la sección **Human Handoff**
2. Activa **Enable Human Handoff**
3. Configura los mensajes:
   - **Handoff Message** — Se muestra al usuario cuando comienza la transferencia
   - **Resolve Message** — Se muestra cuando el agente humano finaliza la conversación
   - **Max Wait Time** — Expiración automática si ningún agente acepta (predeterminado: 30 minutos)
4. Haz clic en **Save Changes**

Cuando un usuario pide hablar con un humano, la IA crea una solicitud de handoff visible en la página **Inbox**. Un miembro del equipo acepta, chatea con el usuario en su canal y resuelve cuando termina.

<Callout type="info">
  Human Handoff está disponible en todos los planes. Habilítalo por agent en la pestaña Configuration.
</Callout>

## Probar tu Agent

Antes de guardar cambios, puedes probar tu agent:

1. Haz clic en el botón **Test Agent** en la parte inferior del formulario
2. El panel del Playground se abre deslizándose
3. Ten una conversación de prueba con tu agent
4. Cierra el Playground cuando termines

<Callout type="info">
  El botón Test Agent se desactiva cuando el estado del agent es Archived o Inactive. Cambia el estado a Active o Testing para habilitar las pruebas.
</Callout>

## Guardar cambios

| Botón | Acción |
|-------|--------|
| **Save Changes** | Guardar todas las modificaciones |
| **Test Agent** | Abrir el Playground para probar |

Para descartar cambios, navega fuera usando el botón de retroceso o la navegación lateral.

**Qué se guarda:**
- Solo los campos modificados se actualizan
- Verás "No changes to save" si nada fue modificado
- Mensajes de éxito o error aparecen después de guardar

**Manejo de guardado parcial:**
Si algunos cambios se guardan pero otros fallan, se te notificará qué secciones fallaron y la página se actualizará para mostrar el estado actual.

<Callout type="info">
  Los cambios en la configuración del agent surten efecto inmediatamente después de guardar. Prueba en el Playground después de hacer cambios.
</Callout>
