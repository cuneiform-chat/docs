# Agents

Los agents son los chatbots de IA que interactúan con tus usuarios. Cada agent tiene su propia configuración, acceso al conocimiento y personalidad.

## ¿Qué es un Agent?

Un agent es un chatbot configurado que:

- Responde preguntas usando tu contenido
- Sigue las instrucciones definidas en su agent persona
- Mantiene el contexto de la conversación dentro de las sesiones
- Puede desplegarse en múltiples canales

## Conceptos de Agent

### Agent Persona

El agent persona es el conjunto de instrucciones que define cómo se comporta tu agent. Controla:

- **Personality** — Amigable, profesional, casual, etc.
- **Scope** — Qué temas debe y no debe abordar el agent
- **Response style** — Longitud, formato y tono de las respuestas
- **Guardrails** — Límites y restricciones
- **Language** — Detección automática por mensaje (176 idiomas soportados)

### Knowledge Access

Cada agent accede a tu contenido para encontrar información relevante. Puedes configurar:

- Qué documentos puede buscar el agent
- Cuántas fuentes recuperar
- Si mostrar citas de fuentes

### Channels

Los agents pueden desplegarse en múltiples canales simultáneamente:

- Plataformas de mensajería (Telegram, Discord, Slack, WhatsApp, Google Chat)
- Facebook Messenger a través de la integración con Meta
- Human Handoff — transfiere conversaciones a un miembro humano del equipo de forma fluida
