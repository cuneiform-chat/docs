# Agents

Los agents son los chatbots de AI que interactúan con tus usuarios. Cada agent tiene su propia configuración, acceso al conocimiento y personalidad.

## ¿Qué es un Agent?

Un agent es un chatbot configurado que:

- Responde preguntas usando tu contenido
- Sigue las instrucciones definidas en su agent persona
- Mantiene el contexto de la conversación dentro de cada sesión
- Puede desplegarse en múltiples canales

## Conceptos del Agent

### Agent Persona

El agent persona es el conjunto de instrucciones que define cómo se comporta tu agent. Controla:

- **Personalidad** — Amigable, profesional, casual, etc.
- **Alcance** — Qué temas debe y no debe abordar el agent
- **Estilo de respuesta** — Longitud, formato y tono de las respuestas
- **Límites** — Fronteras y restricciones
- **Idioma** — Detección automática por mensaje (176 idiomas soportados)

### Acceso al Conocimiento

Cada agent accede a tu contenido para encontrar información relevante. Puedes configurar:

- Qué documentos puede consultar el agent
- Cuántas fuentes recuperar
- Si se muestran citas de las fuentes

### Canales

Los agents pueden desplegarse en múltiples canales simultáneamente:

- Plataformas de mensajería (Telegram, Discord, Slack, WhatsApp, Google Chat)
- Facebook Messenger mediante la integración con Meta
- Human Handoff — transfiere conversaciones sin fricción a un miembro humano del equipo
