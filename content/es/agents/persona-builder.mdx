# Agent Persona Builder

import { Callout } from 'nextra/components'

Genera agent personas profesionales en segundos seleccionando características.

<Callout type="info">
  El Agent Persona Builder te ayuda a crear agent personas eficaces sin escribir prompts desde cero.
</Callout>

## Cómo Empezar

1. Navega a **Agents** y crea o edita un agent
2. Haz clic en **Generate** junto al campo Agent Persona
3. Se abre el panel del Agent Persona Builder con tres pestañas

## Pestañas del Builder

### Custom Build

Crea un persona único seleccionando características en 5 categorías:

| Categoría | Qué Controla |
|-----------|--------------|
| **Role & Identity** | La función principal del agent (soporte al cliente, ventas, soporte técnico, RR. HH., etc.) |
| **Communication Style** | Formalidad, tono, verbosidad y nivel técnico |
| **Response Behavior** | Formato (conversacional vs. con viñetas), proactividad, manejo de preguntas |
| **Operational Boundaries** | Cuán estrictamente se mantiene el agent en el tema, tendencia a escalar |
| **Knowledge Integration** | Estilo de citación, cómo maneja el agent la incertidumbre |

**Navegación entre Categorías:**
- Haz clic en cualquier encabezado de categoría para expandirla o contraerla
- Cada categoría contiene varios campos con opciones desplegables
- Las opciones seleccionadas aparecen resaltadas

**Botón Reset:**
Haz clic en **Reset** dentro de la sección Custom Build para restaurar todos los valores predeterminados.

#### Opciones de Role & Identity

Elige la función principal de tu agent:
- Customer Support
- Sales
- Technical Support
- HR / Internal
- Education
- Healthcare Information
- Legal Information
- Finance / Accounting
- General Assistant

#### Communication Style

Ajusta con precisión cómo se comunica tu agent:

| Ajuste | Opciones |
|--------|----------|
| **Formality** | Casual, Friendly Professional, Formal Professional, Corporate Formal |
| **Tone** | Empathetic & Supportive, Confident & Authoritative, Calm & Reassuring, Enthusiastic & Engaging, Neutral & Objective |
| **Verbosity** | Concise, Balanced, Comprehensive |
| **Technical Level** | Layperson, Mixed, Technical |

#### Opciones de Tone

Presets de tono disponibles:
- Empathetic & Supportive
- Confident & Authoritative
- Calm & Reassuring
- Enthusiastic & Engaging
- Neutral & Objective

#### Niveles de Detalle

- **Concise** — Respuestas breves y directas
- **Balanced** — Detalle moderado con explicaciones claras
- **Comprehensive** — Respuestas exhaustivas y detalladas

#### Response Behavior

Controla cómo se estructuran las respuestas:
- **Format** — Conversational, Step-by-Step Guides o Technical Documentation
- **Proactivity** — Si el agent sugiere temas relacionados
- **Question Handling** — Cómo el agent pide clarificación

#### Operational Boundaries

Define los límites de tu agent:
- **Scope Strictness** — Cuán estrictamente se mantiene el agent dentro de los temas documentados
- **Escalation** — Cuándo sugerir contactar con soporte humano
- **Out-of-scope Handling** — Cómo responder a preguntas fuera de tema

#### Knowledge Integration

Configura cómo el agent usa tus documentos:
- **Citation Style** — Si referenciar documentos específicos
- **Uncertainty Handling** — Cómo responder cuando no está seguro

### Use Preset

Carga personas preconfiguradas para casos de uso comunes:

- **System Templates** — Presets proporcionados por la plataforma, optimizados para roles específicos
- **My Templates** — Presets guardados por los administradores de tu organización

**Cómo Usar un Preset:**
1. Haz clic en la pestaña **Use Preset**
2. Explora los presets disponibles
3. Haz clic en un preset para seleccionarlo
4. El preset se carga en la pestaña Custom Build
5. Ajusta cualquier característica si es necesario
6. Haz clic en **Generate Persona**

### Platform Rules

Consulta las medidas de seguridad de solo lectura que se aplican automáticamente a todos los agents:

- **Sin invenciones** — No inventará hechos, números ni fechas que no estén en tu contenido
- **Reconoce vacíos** — Dice "I don't have that information" en lugar de adivinar
- **Rechaza la especulación** — No estimará valores faltantes ni siquiera cuando se le pida
- **Sin suplantación profesional** — No actuará como abogado, médico, contador ni asesor financiero
- **Corrige premisas falsas** — Señala suposiciones incorrectas antes de responder
- **Bloquea contenido dañino** — Rechaza contenido autolesivo, explícito o fraudulento

<Callout type="info">
  Las reglas de la plataforma garantizan que todos los agents se comporten de forma fiable y segura, independientemente de la configuración del persona. No pueden desactivarse.
</Callout>

## Generar un Persona

**Antes de Generar:**
El panel muestra tus opciones de configuración a ancho completo.

**Botón Generate:**
Cuando estés en la pestaña Custom Build:
1. Haz clic en **Generate Persona** al final
2. Se muestra un estado de carga durante la generación
3. Tarda unos segundos

**Después de Generar:**
La disposición del panel cambia a una vista dividida:
- **Lado izquierdo:** Tus opciones de configuración
- **Lado derecho:** Vista previa del prompt generado

**Características del Panel de Vista Previa:**
- Texto completo del prompt de sistema generado
- Editable — puedes modificar el texto directamente
- Conteo de caracteres mostrado al final

## Después de Generar

Una vez que tengas un persona generado, tienes varias opciones:

### Regenerar

Haz clic en **Regenerate** para crear una nueva versión con los mismos ajustes. Cada generación produce resultados ligeramente distintos.

### Editar el Prompt

Haz clic en el panel de vista previa para editar el texto generado directamente. Haz los ajustes que necesites para tu caso de uso específico.

### Guardar como Preset

Haz clic en **Save as Preset** para guardar tu configuración y reutilizarla:
1. Se abre un diálogo pidiendo el nombre del preset
2. Introduce un nombre descriptivo
3. El preset se guarda en tu organización dentro de **My Templates**

<Callout type="important">
  Los presets guardados están disponibles para todos los administradores de tu organización. Úsalos para mantener personalidades de agent consistentes en varios agents.
</Callout>

### Aplicar al Agent

Haz clic en **Apply to Agent** para usar este persona:
1. El prompt se inserta en el campo del prompt de sistema de tu agent
2. El builder se cierra
3. Continúa configurando el resto de ajustes del agent

## Mejores Prácticas

- **Empieza con un preset** — Usa los system templates como punto de partida y luego personaliza
- **Haz coincidir el rol con el propósito** — Elige un rol que se alinee con la función real de tu agent
- **Equilibra la verbosidad** — Concise funciona mejor para preguntas y respuestas rápidas; el detalle, para temas complejos
- **Prueba después de generar** — Prueba siempre tu agent en el Playground después de aplicar un nuevo persona
- **Itera** — Regenera con ajustes distintos si los resultados no son del todo correctos
- **Mantenlo enfocado** — Los prompts excesivamente complejos pueden confundir al agent
