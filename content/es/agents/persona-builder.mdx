# Agent Persona Builder

import { Callout } from 'nextra/components'

Genera agent personas profesionales en segundos usando selección de características.

<Callout type="info">
  El Agent Persona Builder te ayuda a crear agent personas efectivas sin escribir prompts desde cero.
</Callout>

## Primeros pasos

1. Navega a **Agents** y crea o edita un agent
2. Haz clic en **Generate** junto al campo de Agent Persona
3. El panel del Agent Persona Builder se abre deslizándose con tres pestañas

## Pestañas del Builder

### Custom Build

Crea una persona única seleccionando características en 5 categorías:

| Categoría | Qué controla |
|-----------|--------------|
| **Role & Identity** | Función principal del agent (customer support, ventas, soporte técnico, RRHH, etc.) |
| **Communication Style** | Formalidad, tono, verbosidad y nivel técnico |
| **Response Behavior** | Formato (conversacional vs viñetas), proactividad, manejo de preguntas |
| **Operational Boundaries** | Qué tan estrictamente el agent se mantiene en el tema, tendencia a escalar |
| **Knowledge Integration** | Estilo de citas, cómo el agent maneja la incertidumbre |

**Navegación por categorías:**
- Haz clic en cualquier encabezado de categoría para expandirlo o colapsarlo
- Cada categoría contiene múltiples campos con opciones desplegables
- Las opciones seleccionadas se resaltan

**Botón Reset:**
Haz clic en **Reset** en la sección Custom Build para restaurar todos los valores predeterminados.

#### Opciones de Role & Identity

Elige la función principal de tu agent:
- Customer Support Representative
- Sales Consultant
- Technical Support Specialist
- HR/People Operations
- General Assistant
- Custom role

#### Communication Style

Ajusta cómo se comunica tu agent:

| Configuración | Opciones |
|---------------|----------|
| **Formality** | Formal, Professional, Casual |
| **Tone** | Warm & Friendly, Neutral, Direct |
| **Verbosity** | Concise, Balanced, Detailed |
| **Technical Level** | Non-technical, Mixed, Technical |

#### Opciones de Tone

Presets de tono disponibles:
- Empathetic & Supportive
- Confident & Authoritative
- Calm & Reassuring
- Enthusiastic & Engaging
- Neutral & Objective

#### Niveles de detalle

- **Concise** — Respuestas breves y directas
- **Balanced** — Detalle moderado con explicaciones claras
- **Comprehensive** — Respuestas exhaustivas y detalladas

#### Response Behavior

Controla cómo se estructuran las respuestas:
- **Format** — Párrafos conversacionales o viñetas estructuradas
- **Proactivity** — Si el agent sugiere temas relacionados
- **Question Handling** — Cómo el agent pide aclaraciones

#### Operational Boundaries

Establece salvaguardas para tu agent:
- **Scope Strictness** — Qué tan estrictamente el agent se mantiene dentro de los temas documentados
- **Escalation** — Cuándo sugerir contactar soporte humano
- **Out-of-scope Handling** — Cómo responder a preguntas fuera del tema

#### Knowledge Integration

Configura cómo el agent usa tus documentos:
- **Citation Style** — Si referenciar documentos específicos
- **Uncertainty Handling** — Cómo responder cuando no está seguro

### Use Preset

Carga personas preconfiguradas para casos de uso comunes:

- **System Templates** — Presets proporcionados por la plataforma, optimizados para roles específicos
- **My Templates** — Presets guardados por los administradores de tu organización

**Usar un Preset:**
1. Haz clic en la pestaña **Use Preset**
2. Navega por los presets disponibles
3. Haz clic en un preset para seleccionarlo
4. El preset se carga en la pestaña Custom Build
5. Ajusta cualquier característica si es necesario
6. Haz clic en **Generate Persona**

### Platform Rules

Visualiza las salvaguardas de solo lectura aplicadas automáticamente a todos los agents:

- **No fabrication** — No inventará hechos, números o fechas que no estén en tu contenido
- **Acknowledges gaps** — Dice "no tengo esa información" en lugar de adivinar
- **Resists speculation** — No estimará valores faltantes incluso cuando se le pida
- **No professional impersonation** — No actuará como abogados, médicos, contadores o asesores financieros
- **Corrects false premises** — Señala suposiciones incorrectas antes de responder
- **Blocks harmful content** — Rechaza contenido de autolesión, explícito o fraudulento

<Callout type="info">
  Las platform rules aseguran que todos los agents se comporten de manera confiable y segura, independientemente de la configuración de la persona. No se pueden desactivar.
</Callout>

## Generar una Persona

**Antes de generar:**
El panel muestra tus opciones de configuración a ancho completo.

**Botón Generate:**
En la pestaña Custom Build:
1. Haz clic en **Generate Persona** en la parte inferior
2. Se muestra un estado de carga mientras genera
3. Toma unos segundos

**Después de generar:**
El diseño del panel cambia a una vista dividida:
- **Lado izquierdo:** Tus opciones de configuración
- **Lado derecho:** Vista previa del prompt generado

**Características del panel de vista previa:**
- Texto completo del system prompt generado
- Editable — puedes modificar el texto directamente
- Contador de caracteres mostrado en la parte inferior

## Después de generar

Una vez que tienes una persona generada, tienes varias opciones:

### Regenerar

Haz clic en **Regenerate** para crear una nueva versión con la misma configuración. Cada generación produce resultados ligeramente diferentes.

### Editar el Prompt

Haz clic en el panel de vista previa para editar el texto generado directamente. Realiza los ajustes necesarios para tu caso de uso específico.

### Guardar como Preset

Haz clic en **Save as Preset** para guardar tu configuración para reutilización:
1. Se abre un diálogo pidiendo el nombre del preset
2. Ingresa un nombre descriptivo
3. El preset se guarda en tu organización bajo **My Templates**

<Callout type="important">
  Los presets guardados están disponibles para todos los administradores de tu organización. Úsalos para mantener personalidades de agent consistentes en múltiples agents.
</Callout>

### Aplicar al Agent

Haz clic en **Apply to Agent** para usar esta persona:
1. El prompt se inserta en el campo de system prompt de tu agent
2. El builder se cierra
3. Continúa configurando otras opciones del agent

## Mejores prácticas

- **Comienza con un preset** — Usa system templates como punto de partida, luego personaliza
- **Alinea el rol con el propósito** — Elige un rol que se alinee con la función real de tu agent
- **Equilibra la verbosidad** — Conciso funciona mejor para Q&A rápido, detallado para temas complejos
- **Prueba después de generar** — Siempre prueba tu agent en el Playground después de aplicar una nueva persona
- **Itera** — Regenera con diferentes configuraciones si los resultados no son los esperados
- **Mantenlo enfocado** — Los prompts excesivamente complejos pueden confundir al agent
