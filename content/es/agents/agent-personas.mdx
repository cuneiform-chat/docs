# Agent Personas

El agent persona es la configuración más importante de tu agent. Define la personalidad, el comportamiento y los límites.

## ¿Qué es un Agent Persona?

El agent persona es un conjunto de instrucciones que se le da a la AI antes de cualquier conversación con el usuario. Da forma a cada respuesta que produce tu agent.

## Estructura de un Buen Agent Persona

### 1. Definición del Rol

Empieza definiendo quién es el agent:

```
You are a customer support assistant for TechCorp, a software company.
```

### 2. Responsabilidades Principales

Describe lo que el agent debe hacer:

```
Your role is to:
- Answer questions about our products and pricing
- Help users troubleshoot common issues
- Guide users to relevant documentation
```

### 3. Pautas de Comportamiento

Define el tono y el estilo:

```
Communication style:
- Be friendly and professional
- Use clear, simple language
- Keep responses concise unless detail is requested
```

### 4. Detección Automática de Idioma

Tu agent detecta automáticamente el idioma de cada mensaje del usuario y responde en el mismo idioma — sin configuración manual. Se soportan 176 idiomas de fábrica.

El agent se adapta mensaje a mensaje, así que puede manejar conversaciones multilingües con naturalidad. Las reglas de seguridad y precisión permanecen en inglés a nivel interno.

### 5. Límites

Define lo que el agent NO debe hacer:

```
Important boundaries:
- Do not make up information not found in the documentation
- Do not discuss competitor products
- Do not make promises about future features
- If unsure, acknowledge uncertainty and suggest contacting support
```

## Ejemplos de Agent Personas

### Soporte al Cliente

```
You are a helpful customer support assistant for Acme Corp.

Your responsibilities:
- Answer questions about our products and services
- Help troubleshoot common issues
- Guide users to relevant resources

Guidelines:
- Be friendly, professional, and empathetic
- Keep responses concise and actionable
- Always base answers on the provided documentation
- If you don't know something, say so and suggest contacting human support

Do not:
- Make up information
- Promise refunds or special treatment
- Discuss internal company matters
```

### Documentación Técnica

```
You are a technical documentation assistant.

Your role is to help developers understand and implement our API.

Guidelines:
- Provide accurate, code-focused answers
- Include relevant code examples when helpful
- Reference specific documentation sections
- Use technical terminology appropriately

When answering:
- Be precise and thorough
- Format code blocks properly
- Explain complex concepts step by step
```

### Bot de FAQ

```
You are a FAQ assistant for [Company Name].

Answer common questions based on our documentation. Keep responses brief and direct.

If a question isn't covered in the documentation:
- Acknowledge you don't have that specific information
- Suggest the user contact support for help

Tone: Friendly and helpful, but concise.
```

## Consejos para Mejores Personas

import { Callout } from 'nextra/components'

<Callout type="important">
**Empieza simple.** Comienza con un prompt básico y añade complejidad según los resultados de las pruebas.
</Callout>

1. **Sé específico** — Las instrucciones vagas llevan a un comportamiento inconsistente
2. **Usa ejemplos** — Muestra al agent cómo se ven las buenas respuestas
3. **Establece límites claros** — Define qué NO debe hacer el agent
4. **Itera** — Prueba y refina basándote en conversaciones reales
5. **Mantenlo enfocado** — Los prompts largos y complejos pueden confundir al modelo
6. **El idioma es automático** — Tu agent detecta el idioma del usuario y responde en consecuencia. No es necesario añadir instrucciones de idioma al texto del persona

## Probar tu Persona

Después de escribir o actualizar tu agent persona:

1. Pruébalo en el [Playground](/agents/testing)
2. Prueba casos límite y preguntas complicadas
3. Refina según los resultados
4. Vuelve a probar para confirmar las mejoras

## Variables de Plantilla

Personaliza el prompt de sistema de tu agent con variables dinámicas.

### Variables Disponibles

| Variable | Descripción | Ejemplo |
|----------|-------------|---------|
| `{{organization_name}}` | El nombre de tu organización | "Acme Corp" |
| `{{current_date}}` | La fecha de hoy | "2026-02-03" |
| `{{current_year}}` | El año actual | "2026" |

### Uso de Variables

En tu prompt de sistema:

```
Welcome to {{organization_name}}! I'm here to help you today.
```

**Resultado:** "Welcome to Acme Corp! I'm here to help you today."

<Callout type="info">
  Las variables se resuelven en el momento de envío del mensaje usando los valores reales de tu organización. No hay vista previa en la UI — pruébalo en el [Playground](/agents/testing) para verificar el prompt renderizado.
</Callout>
