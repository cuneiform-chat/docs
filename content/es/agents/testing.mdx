# Probar en Playground

import { Callout } from 'nextra/components'

El Playground es tu entorno para probar y refinar agents antes del despliegue.

## Acceder al Playground

1. Ve a **Agents** en la barra lateral
2. Haz clic en **Test** en la tarjeta de tu agent (o en **Test Agent** al editar un agent)
3. El Playground se abre como un panel lateral — inicia una conversación

<Callout type="info">
  El botón Test está desactivado cuando el estado del agent es **Archived** o **Inactive**. Cambia el estado a **Active** o **Testing** para activar las pruebas.
</Callout>

## Qué Probar

### Funcionalidad Básica

- ¿Puede el agent responder preguntas a partir de tus documentos?
- ¿Las respuestas son precisas y relevantes?
- ¿El tono coincide con tus expectativas?

### Casos Límite

Prueba escenarios que podrían poner en aprietos a tu agent:

- Preguntas que no cubren tus documentos
- Preguntas ambiguas o poco claras
- Preguntas con varias partes
- Preguntas de seguimiento que requieren contexto

### Flujo de Conversación

Prueba conversaciones de varios turnos:

- ¿Recuerda el agent el contexto de mensajes anteriores?
- ¿Maneja con elegancia los cambios de tema?
- ¿Pide aclaraciones cuando es necesario?

## Evaluar las Respuestas

Para cada respuesta, considera:

| Aspecto | Preguntas a Hacerse |
|--------|-----------------|
| **Accuracy** | ¿Es correcta la información? |
| **Relevance** | ¿Responde realmente a la pregunta? |
| **Completeness** | ¿Falta algo importante? |
| **Tone** | ¿Coincide con la voz de tu marca? |
| **Length** | ¿Es adecuadamente concisa o detallada? |

## Mejora Iterativa

### Identificar Problemas

Problemas habituales y soluciones:

| Problema | Solución |
|-------|----------|
| Información incorrecta | Revisa el contenido del documento, mejora la recuperación |
| Demasiado verboso | Añade "be concise" al agent persona |
| Demasiado formal/casual | Ajusta el tono en el agent persona |
| No conoce la respuesta | Añade documentos relevantes |
| Inventa hechos | Refuerza los límites en el prompt |

### Hacer Cambios

1. Identifica el problema durante las pruebas en el Playground
2. Ajusta los ajustes pertinentes (prompt, documentos, configuración)
3. Vuelve a probar con las mismas preguntas
4. Verifica que la corrección no rompe otros comportamientos

## Lista de Escenarios de Prueba

Crea un conjunto estándar de preguntas de prueba:

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  Guarda tus escenarios de prueba y vuelve a ejecutarlos tras hacer cambios para detectar regresiones.
</Callout>

## Listo para el Despliegue

Tu agent está listo cuando:

- ✓ Responde preguntas comunes con precisión
- ✓ Gestiona los casos límite con elegancia
- ✓ Mantiene un tono adecuado
- ✓ Respeta los límites definidos
- ✓ Las conversaciones de varios turnos funcionan bien

A continuación, despliega tu agent en los [canales](/integrations) donde los usuarios interactuarán con él.
