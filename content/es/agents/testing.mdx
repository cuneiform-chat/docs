# Probar en Playground

import { Callout } from 'nextra/components'

El Playground es tu entorno para probar y refinar agents antes del despliegue.

## Acceder al Playground

1. Navega a **Agents** en la barra lateral
2. Haz clic en **Test** en la tarjeta de tu agent (o **Test Agent** al editar un agent)
3. El Playground se abre deslizándose como un panel lateral — inicia una conversación

<Callout type="info">
  El botón Test se desactiva cuando el estado del agent es **Archived** o **Inactive**. Cambia el estado a **Active** o **Testing** para habilitar las pruebas.
</Callout>

## Qué probar

### Funcionalidad básica

- ¿Puede el agent responder preguntas de tus documentos?
- ¿Son las respuestas precisas y relevantes?
- ¿El tono coincide con tus expectativas?

### Casos extremos

Prueba escenarios que podrían complicar a tu agent:

- Preguntas no cubiertas por tus documentos
- Preguntas ambiguas o poco claras
- Preguntas de múltiples partes
- Preguntas de seguimiento que requieren contexto

### Flujo de conversación

Prueba conversaciones de múltiples turnos:

- ¿Recuerda el agent el contexto de mensajes anteriores?
- ¿Puede manejar cambios de tema con naturalidad?
- ¿Pide aclaraciones cuando es necesario?

## Evaluar respuestas

Para cada respuesta, considera:

| Aspecto | Preguntas a hacer |
|---------|-------------------|
| **Accuracy** | ¿Es correcta la información? |
| **Relevance** | ¿Responde la pregunta real? |
| **Completeness** | ¿Falta algo importante? |
| **Tone** | ¿Coincide con la voz de tu marca? |
| **Length** | ¿Es apropiadamente concisa o detallada? |

## Mejora iterativa

### Identificar problemas

Problemas comunes y soluciones:

| Problema | Solución |
|----------|----------|
| Información incorrecta | Revisa el contenido de los documentos, mejora la recuperación |
| Demasiado verboso | Añade "be concise" al agent persona |
| Demasiado formal/casual | Ajusta el tono en el agent persona |
| No sabe la respuesta | Añade documentos relevantes |
| Inventa hechos | Fortalece los límites en el prompt |

### Hacer cambios

1. Identifica el problema en las pruebas del Playground
2. Ajusta las configuraciones relevantes (prompt, documentos, configuración)
3. Prueba de nuevo con las mismas preguntas
4. Verifica que la corrección no rompa otros comportamientos

## Checklist de escenarios de prueba

Crea un conjunto de preguntas de prueba estándar:

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  Guarda tus escenarios de prueba y vuelve a ejecutarlos después de hacer cambios para detectar regresiones.
</Callout>

## Listo para desplegar

Tu agent está listo cuando:

- ✅ Responde preguntas comunes con precisión
- ✅ Maneja casos extremos con naturalidad
- ✅ Mantiene un tono apropiado
- ✅ Respeta los límites definidos
- ✅ Las conversaciones de múltiples turnos funcionan bien

A continuación, despliega tu agent en los [canales](/integrations) donde los usuarios interactuarán con él.
