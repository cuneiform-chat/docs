# Crear Agents

import { Callout } from 'nextra/components'

Aprende a crear nuevos agents en Cuneiform Chat.

## Cómo Empezar

1. Navega a **Agents** en la barra lateral
2. Haz clic en el botón **Create Agent** en la esquina superior derecha
3. Completa las secciones del formulario que aparecen abajo

## Información Básica

Esta sección captura los detalles esenciales sobre tu agent.

| Campo | Obligatorio | Descripción |
|-------|-------------|-------------|
| **Name** | Sí | Un nombre para tu agent (p. ej., "Agent de Soporte al Cliente"). Máximo 100 caracteres. |
| **Description** | No | Una descripción breve de lo que hace este agent. Máximo 500 caracteres. |

**Consejos:**
- Elige un nombre descriptivo que indique el propósito del agent
- La descripción te ayuda a ti y a tu equipo a entender el rol del agent

## Agent Persona

El agent persona define cómo se comporta y responde tu agent mediante un prompt de sistema.

**Elementos Clave:**

- **Caja de Reglas de la Plataforma** — Muestra las reglas de seguridad integradas que se aplican automáticamente (haz clic para ver los detalles)
- **Botón Generate** — Abre el [Agent Persona Builder](/agents/persona-builder) para ayudarte a crear tu persona
- **Botón Edit** — Abre un panel para escribir o editar manualmente el persona

### Reglas de la Plataforma

Estas medidas de seguridad se aplican automáticamente a todos los agents:

- **Sin invenciones** — No inventará hechos que no estén en tu contenido
- **Reconoce vacíos** — Dice "No lo sé" cuando corresponde
- **Rechaza la especulación** — No adivinará información faltante
- **Sin suplantación profesional** — No actuará como abogado, médico, etc.
- **Corrige premisas falsas** — Señala suposiciones incorrectas
- **Bloquea contenido dañino** — Rechaza solicitudes inapropiadas

<Callout type="info">
  Las reglas de la plataforma garantizan que todos los agents se comporten de forma fiable y segura. No pueden desactivarse. Consulta [Agent Persona Builder](/agents/persona-builder#platform-rules) para más detalles.
</Callout>

### Ejemplo Rápido de Persona

```
You are a helpful assistant for [Your Company].
Answer questions based on the provided documentation.
Be concise and friendly.
```

Consulta [Agent Personas](/agents/agent-personas) para una guía detallada sobre cómo escribir personas eficaces.

## Soporte de Idiomas

Tu agent detecta automáticamente el idioma de cada mensaje del usuario y responde en el mismo idioma — sin necesidad de configuración. Se soportan 176 idiomas de fábrica. Consulta [Agent Personas — Detección Automática de Idioma](/agents/agent-personas#4-automatic-language-detection) para más detalles.

## Configuración del LLM

Esta sección controla los ajustes del modelo de AI.

**Modo Predeterminado:**

Por defecto, los ajustes del LLM usan los valores predeterminados del tier de tu organización. Verás una caja de información que dice "Using tier defaults". Esto se recomienda para la mayoría de los casos de uso.

**Modo Avanzado:**

Activa **Advanced** para personalizar:

| Ajuste | Descripción |
|--------|-------------|
| **Model** | Elige entre los modelos de AI disponibles según tu plan |
| **Temperature** | Controla la creatividad de las respuestas (más bajo = más consistente, más alto = más creativo) |

**Show Document References:**

Este toggle (siempre visible) controla si el agent incluye citas de fuentes en sus respuestas:
- **Off** (predeterminado) — Las respuestas no mencionan documentos fuente
- **On** — Las respuestas incluyen referencias a los documentos fuente (útil para casos legales o de cumplimiento)

## Control de Acceso al Conocimiento

Controla qué documentos puede consultar tu agent al responder preguntas.

| Modo | Comportamiento | Cuándo Usarlo |
|------|----------------|---------------|
| **Exclude Mode** | El agent accede a TODOS los documentos EXCEPTO los seleccionados | Ocultar documentos sensibles al agent |
| **Include Mode** | El agent accede SOLO a los elementos seleccionados | Restringir el agent a un conjunto específico de conocimiento |

**Al usar Include Mode:**
- Selecciona las carpetas específicas a las que el agent puede acceder
- Selecciona las etiquetas específicas a las que el agent puede acceder
- Selecciona los documentos individuales a los que el agent puede acceder

El agent solo usará información de las fuentes seleccionadas al responder.

<Callout type="important">
  Empieza con Exclude Mode (acceso completo al conocimiento) a menos que necesites ocultar documentos específicos. Siempre puedes restringir el acceso más adelante.
</Callout>

## Acciones del Formulario

Al final del formulario:

| Botón | Acción |
|-------|--------|
| **Cancel** | Descartar cambios y volver atrás |
| **Reset** | Limpiar todos los campos y empezar de nuevo (muestra un diálogo de confirmación) |
| **Create Agent** | Guardar el agent y abrir su página de edición |

<Callout type="info">
  Tu borrador se guarda automáticamente mientras trabajas. Si te vas y vuelves, tu progreso se restaurará.
</Callout>

## Después de Crear

Cuando hagas clic en **Create Agent**:

1. El agent se crea con estado **Testing**
2. Te lleva a la página de edición del agent
3. Prueba el agent usando el Playground
4. Conecta integraciones cuando esté listo para entrar en producción
5. Cambia el estado a **Active** cuando esté listo

<Callout type="info">
  Los nuevos agents empiezan con estado **Testing**. Puedes probar en el Playground, pero las integraciones de canales están deshabilitadas hasta que actives el agent.
</Callout>

## Gestión de Agents

Desde la página de Agents puedes:

- **Edit** — Haz clic en cualquier agent para modificar sus ajustes
- **Test** — Haz clic en **Test** en la tarjeta del agent para abrir el Playground
- **Cambiar Estado** — Establecer en Testing, Active, Inactive o Archived

Consulta [Opciones de Configuración](/agents/configuring) para ver los detalles de todos los ajustes del agent.
