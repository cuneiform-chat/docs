# Integraciones

Despliega tus agents en múltiples canales y llega a los usuarios donde estén.

## Canales Disponibles

| Canal | Descripción | Mejor Para |
|---------|-------------|----------|
| [Telegram](/integrations/telegram) | Bot de Telegram | Usuarios móviles, comunidades |
| [Discord](/integrations/discord) | Bot de Discord con slash commands | Gaming, comunidades de desarrolladores |
| [Slack](/integrations/slack) | App de Slack | Espacios de trabajo en equipo |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | Comunicación con clientes |
| [Google Chat](/integrations/google-chat) | App de Google Workspace | Equipos empresariales |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | Audiencia de consumidores |
| [Website Widget](/integrations/website-widget) | Widget de chat embebible | Atención al cliente, cualquier sitio web |

## Cómo Funcionan las Integraciones

1. **Configurar** — Configura la integración para el canal elegido
2. **Conectar** — Vincula tu agent al canal
3. **Desplegar** — Tu agent queda disponible para los usuarios
4. **Monitorear** — Realiza seguimiento de conversaciones y uso

## Despliegue Multicanal

Un mismo agent puede desplegarse en varios canales simultáneamente:

- Mismo contenido en todos los canales
- Respuestas consistentes en todas partes
- Historial de conversaciones centralizado
- Analítica unificada

## Funciones Específicas por Canal

Cada canal tiene capacidades únicas:

- **Telegram** — Mensajes enriquecidos, teclados inline
- **Discord** — Slash commands, integración con servidores
- **Slack** — Apps de workspace, respuestas en canales
- **WhatsApp** — Mensajería empresarial, contenido multimedia
- **Google Chat** — Integración con Google Workspace, soporte para Spaces, preguntas y respuestas sobre documentos + base de conocimiento del Space
- **Meta (Facebook)** — Integración con Messenger, mensajería de Page
- **Website Widget** — Chat embebible, apariencia personalizable, lista de dominios permitidos

## Requisitos

Antes de configurar las integraciones:

1. ✅ Crea al menos un agent
2. ✅ Sube documentos a tu contenido
3. ✅ Prueba tu agent en el Playground

Cada canal puede tener requisitos adicionales (tokens de bot, credenciales de app, etc.) detallados en sus respectivas guías.
