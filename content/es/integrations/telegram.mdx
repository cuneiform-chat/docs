# Integración con Telegram

Conecta tu agent a Telegram y permite que los usuarios chateen directamente en la app de Telegram.

## Descripción General

La integración con Telegram proporciona:
- Mensajería directa con tu bot
- Soporte de group chats
- Formato de mensajes enriquecidos
- Teclados inline para interacciones

## Requisitos Previos

- Una cuenta de Telegram
- Acceso a BotFather (herramienta de creación de bots de Telegram)

## Pasos de Configuración

### 1. Crear un Bot de Telegram

1. Abre Telegram y busca **@BotFather**
2. Inicia un chat y envía `/newbot`
3. Sigue las instrucciones:
   - Ingresa un nombre para tu bot (ej., "My Support Bot")
   - Ingresa un username (debe terminar en "bot", ej., "mysupportbot")
4. BotFather te dará un **Bot Token** — guárdalo de forma segura

### 2. Conectar a Cuneiform Chat

1. Ve a **Agents** → Selecciona tu agent
2. Navega a la pestaña **Integrations**
3. Haz clic en **Telegram**
4. Pega tu Bot Token
5. Haz clic en **Connect**

### 3. Configurar tu Bot

Ajustes opcionales del bot mediante BotFather:

- `/setdescription` — Qué hace el bot
- `/setabouttext` — Información en el perfil del bot
- `/setuserpic` — Imagen de perfil de tu bot

### 4. Probar tu Bot

1. Busca tu bot en Telegram por su username
2. Inicia una conversación con `/start`
3. Envía un mensaje y verifica que recibes una respuesta

## Cómo Funciona

```
El usuario envía un mensaje → Telegram → Cuneiform Chat → El agent procesa → La respuesta se envía de vuelta
```

Los mensajes se procesan en tiempo real. El agent busca en tu contenido y genera respuestas basadas en tu configuración.

## Características

### Mensajes Directos

Los usuarios pueden chatear con tu bot de forma privada para conversaciones de soporte.

### Group Chats

Agrega tu bot a group chats:

1. Agrega el bot a un grupo
2. Hazlo admin (para acceso a mensajes)
3. Los usuarios pueden mencionar al bot o usar comandos

import { Callout } from 'nextra/components'

<Callout type="info">
  En grupos, el bot solo responde cuando es mencionado o cuando se usan comandos, para evitar spam.
</Callout>

### Formato Enriquecido

Las respuestas de tu agent soportan:
- Texto en **negritas** y *cursiva*
- Enlaces
- Bloques de código
- Listas

## Help Center Mini App

Cada bot de Telegram que conectas viene con un **Help Center** integrado — un Mini App que se abre dentro de Telegram cuando los usuarios finales pulsan el botón de menú junto al compositor de mensajes.

### Qué Ven los Usuarios Finales

Una lista ordenable de entradas de FAQ que has creado desde el admin panel. Dos modos por entrada:

- **Curated** — pulsa para leer la respuesta inline. Markdown renderizado, sin tráfico de chat, sin coste de LLM.
- **Ask the bot** — pulsa para enviar al chat una pregunta predefinida a tu agent.

### Configuración Automática, Sin Setup

Cuando conectas un bot de Telegram, el chat-menu button queda configurado automáticamente para abrir el Help Center. Disponible en cualquier plan, incluido el trial gratuito. Esta vía no requiere configuración en BotFather.

### Crear Entradas

1. Ve a **Integrations** → tu tarjeta de bot de Telegram
2. Abre el menú de tres puntos → **Help Center**
3. Agrega hasta ~50 entradas; arrastra para reordenar; elige el modo (curated o ask-the-bot)

Los cambios se propagan al Mini App en ~5 minutos (caché del servidor).

### Opcional: Enlace de Lanzamiento Directo

Si también quieres un enlace `t.me/<your_bot>/<your_app>` para marketing o códigos QR, abre **Mini App settings** en la misma tarjeta y sigue el playbook de BotFather (5 pasos). El chat-menu button sigue funcionando sin esto — el playbook solo agrega la forma de enlace orientada a marketing.

### Soporte de Idiomas

La interfaz del Mini App sigue el idioma de Telegram de cada usuario final — actualmente inglés, español, portugués y francés, con inglés como fallback. El *contenido* del Help Center que escribes es monolingüe por entrada hoy; las variantes de contenido por idioma están en el roadmap.

## Comandos del Bot

Puedes configurar comandos personalizados mediante BotFather:

| Comando | Descripción |
|---------|-------------|
| `/start` | Iniciar conversación |
| `/help` | Mostrar mensaje de ayuda |
| `/ask [pregunta]` | Hacer una pregunta específica |

## Solución de Problemas

### El Bot No Responde

1. Verifica que el bot token sea correcto
2. Comprueba que la integración está conectada en Cuneiform Chat
3. Asegúrate de que tu agent esté configurado correctamente
4. Prueba el agent en el Playground primero

### Problemas con el Token

Si necesitas un nuevo token:
1. Ve a BotFather
2. Envía `/mybots` → Selecciona tu bot → **API Token** → **Revoke**
3. Actualiza el nuevo token en Cuneiform Chat

### Problemas en Group Chats

- Asegúrate de que el bot tenga permisos de admin
- Verifica la configuración del modo de privacidad en BotFather (`/setprivacy`)

## Seguridad

- Los bot tokens se encriptan y almacenan de forma segura
- Las conversaciones se procesan a través de conexiones seguras

## Desconexión

Para eliminar la integración con Telegram:

1. Ve a **Agents** → Selecciona el agent → **Integrations**
2. Haz clic en **Telegram** → **Disconnect**

Esto detiene las respuestas del bot pero no elimina el bot de Telegram en sí. Elimínalo mediante BotFather si es necesario.
