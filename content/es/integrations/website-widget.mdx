# Website Chat Widget

Integra un widget de chat con IA directamente en tu sitio web. Los visitantes obtienen respuestas instantáneas de tu agent de IA sin salir de tu sitio.

## Descripción General

El Website Widget proporciona:
- Burbuja de chat flotante en tu sitio web
- Respuestas de IA con streaming en tiempo real
- Apariencia personalizable (colores, posición, mensajes)
- Menos de 11KB comprimido — impacto de rendimiento casi nulo
- Allowlisting de dominios para seguridad

## Requisitos Previos

- Un agent de IA activo en tu panel de admin
- Acceso al HTML de tu sitio web (para pegar una etiqueta script)

## Pasos de Configuración

### 1. Crear un Widget

1. Ve a **Integrations** desde la barra lateral
2. Desplázate a la sección **Website Widget**
3. Haz clic en **Create Widget**
4. Ingresa un nombre y selecciona el agent de IA
5. Haz clic en **Create**

### 2. Personalizar la Apariencia

Haz clic en la tarjeta del widget para abrir el panel de edición:

- **Primary Color** — Color de la burbuja de chat y el encabezado
- **Text Color** — Texto en la burbuja y el encabezado
- **Position** — Inferior derecha o inferior izquierda
- **Welcome Message** — Primer mensaje que ven los visitantes
- **Suggested Questions** — Hasta 4 preguntas iniciales clicables
- **Avatar URL** — Imagen personalizada en el encabezado del chat
- **Border Radius** — Redondez de las esquinas

Una vista previa en vivo se actualiza a medida que realizas cambios.

### 3. Configurar Dominios Permitidos (Recomendado)

Restringe qué sitios web pueden integrar tu widget:

- Déjalo vacío para permitir todos los dominios (predeterminado)
- Agrega dominios específicos: `example.com`, `*.example.com`
- Usa entradas con puerto para desarrollo: `localhost:3000`

### 4. Integrar en tu Sitio Web

Haz clic en el ícono de embed en la tarjeta del widget y copia el código:

```html
<script src="https://core-api.cuneiform.chat/api/widget/widget.js"
  data-widget-id="your-widget-id" async></script>
```

Pégalo antes de la etiqueta de cierre `</body>` en tu sitio web.

## Cómo Funciona

```
El visitante abre tu sitio web
  → La burbuja de chat aparece en la esquina
  → El visitante hace clic → Se abre el panel de chat
  → Se muestran el mensaje de bienvenida + preguntas sugeridas
  → El visitante escribe una pregunta
  → El agent de IA busca en tu contenido
  → La respuesta se transmite en tiempo real
```

Los mensajes se procesan en tiempo real. El agent busca en tu contenido y genera respuestas usando el mismo pipeline de IA que todos los demás canales.

## Características

### Respuestas con Streaming

Las respuestas se transmiten en tiempo real usando Server-Sent Events (SSE). Los visitantes ven la respuesta aparecer progresivamente, similar a ChatGPT.

### Persistencia de Sesión

Los visitantes que regresan en el mismo navegador retoman su conversación anterior dentro de una ventana de 24 horas. Las sesiones se almacenan en el localStorage del navegador.

### Preguntas Sugeridas

Configura hasta 4 preguntas clicables que aparecen cuando se abre el chat. Ideal para guiar a los visitantes hacia temas comunes.

import { Callout } from 'nextra/components'

<Callout type="info">
  El widget se ejecuta dentro de un Shadow DOM, por lo que no interferirá con los estilos ni el JavaScript de tu sitio web.
</Callout>

### Renderizado de Markdown

Las respuestas del agent soportan formato markdown incluyendo negritas, cursiva, listas, bloques de código y enlaces.

## Gestión de Widgets

En la página de Integrations, cada tarjeta de widget muestra:

- Nombre del widget y estado
- Agent asignado
- Acciones de editar, código embed y eliminar

| Acción | Cómo |
|--------|------|
| Editar configuración | Haz clic en la tarjeta del widget |
| Obtener código embed | Haz clic en el ícono de embed |
| Eliminar | Menú de tres puntos → Delete |

## Seguridad

- **Aislamiento Shadow DOM** — El widget está aislado de tu página
- **Tokens de sesión HMAC** — Tokens firmados con expiración de 24 horas
- **Allowlisting de dominios** — Restringe qué sitios pueden integrar tu widget
- **Rate limiting** — 30 mensajes/minuto por sesión
- **Sin acceso a datos** — El widget no puede leer ni modificar el contenido de tu página

## Solución de Problemas

### El widget no aparece

1. Verifica que la etiqueta script esté antes de `</body>`, no en `<head>`
2. Comprueba que `data-widget-id` coincida con tu panel de admin
3. Si el allowlisting de dominios está configurado, verifica que tu dominio esté listado
4. Revisa la consola del navegador para errores

### El widget no responde

1. Asegúrate de que el agent asignado esté en estado **Active**
2. Verifica que el agent tenga documentos en su contenido
3. Revisa la pestaña Network del navegador para solicitudes API fallidas

### Problemas de apariencia

El widget usa aislamiento Shadow DOM. El CSS de tu página no afectará al widget. Usa la vista previa en vivo del panel de edición para personalizar la apariencia.

## Preguntas Frecuentes

### ¿Puedo integrar el widget en múltiples páginas?

Sí. Usa el mismo código embed en cada página. El widget comparte el estado de sesión entre páginas del mismo dominio.

### ¿Funciona en dispositivos móviles?

Sí. El widget es completamente responsivo y está optimizado para navegadores móviles.

### ¿Puedo eliminar el badge "Powered by"?

El badge es obligatorio en los planes Trial y Starter. Actualiza a Professional o superior para eliminarlo.

### ¿Funciona con React/Next.js/Vue?

Sí. El widget se carga como un script independiente y funciona con cualquier framework, incluyendo aplicaciones de página única.

### ¿Cuál es el límite de longitud de mensajes?

4,000 caracteres por mensaje.
