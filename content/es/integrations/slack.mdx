# Integración con Slack

Agrega tu agent a los workspaces de Slack para acceso de todo el equipo.

## Descripción General

La integración con Slack ofrece:
- Soporte de slash commands (`/ask`)
- Conversaciones por mensaje directo
- Menciones en canales
- Disponibilidad en todo el workspace

## Requisitos Previos

- Permisos de admin del workspace de Slack o de instalación de apps
- Cuenta de Cuneiform Chat con un agent activo

## Pasos de Configuración

### 1. Iniciar la Configuración de la Integración

1. Ve a **Agents** → Selecciona tu agent
2. Navega a la pestaña **Integrations**
3. Haz clic en **Slack**
4. Haz clic en **Add to Slack**

### 2. Autorizar la App

1. Selecciona el workspace donde instalar
2. Revisa los permisos
3. Haz clic en **Allow**

### 3. Verificar la Instalación

1. Abre Slack
2. Prueba el slash command: `/ask Hello`
3. Verifica que recibas una respuesta

## Usar el Bot

### Slash Commands

Usa el comando `/ask` en cualquier canal:

```
/ask ¿Cuál es nuestra política de reembolso?
```

La respuesta aparece en el canal (o como mensaje efímero, según la configuración).

### Mensajes Directos

Envía un mensaje al bot directamente para conversaciones privadas:

1. Encuentra la app en la barra lateral de Slack
2. Abre un mensaje directo
3. Conversa con naturalidad

### Menciones en Canales

Menciona al bot en los canales para hacer preguntas:

```
@YourBot ¿Cuáles son las opciones de envío?
```

## Funcionalidades

### Acceso en Todo el Workspace

Una vez instalado, el bot está disponible para todos los miembros del workspace.

### Respuestas en Threads

Las respuestas pueden publicarse en threads para mantener los canales organizados.

### Formato Enriquecido

Las respuestas admiten el formato de Slack:
- Texto en negrita y cursiva
- Enlaces
- Bloques de código
- Listas

## Opciones de Configuración

### Configuración de Respuestas

| Configuración | Descripción |
|---------|-------------|
| Tipo de respuesta | In-channel o ephemeral |
| Comportamiento de thread | Responder en thread o en el canal principal |

### Restricciones por Canal

Opcionalmente restringe el bot a canales específicos para un uso enfocado.

## Soporte Multi-Workspace

Puedes instalar el mismo agent en varios workspaces de Slack:

1. Cada workspace requiere autorización por separado
2. Todos los workspaces comparten el mismo agent y contenido
3. Las conversaciones se rastrean por separado en cada workspace

## Solución de Problemas

### Comando No Encontrado

Si `/ask` no funciona:
1. Verifica que la app esté instalada en tu workspace
2. Comprueba que la app tenga los permisos adecuados
3. Intenta reinstalar la integración

### Sin Respuesta

Si el bot no responde:
1. Verifica que tu agent esté configurado y funcionando (pruébalo en el Playground)
2. Comprueba que la integración con Slack esté conectada
3. Asegúrate de que el bot tenga acceso al canal

### Problemas de Permisos

Permisos requeridos:
- `commands` — Para slash commands
- `chat:write` — Para enviar mensajes
- `app_mentions:read` — Para @ menciones

## Seguridad

- Los OAuth tokens están cifrados
- Sin acceso a los mensajes salvo por comandos/menciones explícitos
- Los datos del workspace permanecen privados

## Desconectar

Para eliminar la integración con Slack:

1. **Desde Cuneiform Chat:**
   - Agents → Selecciona el agent → Integrations → Slack → Disconnect

2. **Desde Slack:**
   - Ve a la configuración del workspace
   - Apps → Encuentra la app → Remove

Ambos pasos garantizan la eliminación completa.
