# Integración con Slack

Agrega tu agent a workspaces de Slack para acceso de todo el equipo.

## Descripción General

La integración con Slack proporciona:
- Soporte de slash commands (`/ask`)
- Conversaciones por mensaje directo
- Menciones en canales
- Disponibilidad en todo el workspace

## Requisitos Previos

- Permisos de admin o de instalación de apps en el workspace de Slack
- Cuenta de Cuneiform Chat con un agent activo

## Pasos de Configuración

### 1. Iniciar la Configuración de la Integración

1. Ve a **Agents** → Selecciona tu agent
2. Navega a la pestaña **Integrations**
3. Haz clic en **Slack**
4. Haz clic en **Add to Slack**

### 2. Autorizar la App

1. Selecciona el workspace donde instalar
2. Revisa los permisos
3. Haz clic en **Allow**

### 3. Verificar la Instalación

1. Abre Slack
2. Prueba el slash command: `/ask Hello`
3. Verifica que recibes una respuesta

## Uso del Bot

### Slash Commands

Usa el comando `/ask` en cualquier canal:

```
/ask What is our refund policy?
```

La respuesta aparece en el canal (o como mensaje efímero, según la configuración).

### Mensajes Directos

Envía un mensaje directo al bot para conversaciones privadas:

1. Busca la app en la barra lateral de Slack
2. Abre un mensaje directo
3. Chatea de forma natural

### Menciones en Canales

Menciona al bot en canales para hacer preguntas:

```
@YourBot What are the shipping options?
```

## Características

### Acceso en Todo el Workspace

Una vez instalado, el bot está disponible para todos los miembros del workspace.

### Respuestas en Hilos

Las respuestas pueden publicarse en hilos para mantener los canales organizados.

### Formato Enriquecido

Las respuestas soportan el formato de Slack:
- Texto en negritas y cursiva
- Enlaces
- Bloques de código
- Listas

## Opciones de Configuración

### Ajustes de Respuesta

| Ajuste | Descripción |
|--------|-------------|
| Tipo de respuesta | En el canal o efímera |
| Comportamiento de hilos | Responder en hilo o en el canal principal |

### Restricciones de Canal

Opcionalmente restringe el bot a canales específicos para uso enfocado.

## Soporte Multi-Workspace

Puedes instalar el mismo agent en múltiples workspaces de Slack:

1. Cada workspace requiere autorización por separado
2. Todos los workspaces comparten el mismo agent y contenido
3. Las conversaciones se rastrean por separado en cada workspace

## Solución de Problemas

### Comando No Encontrado

Si `/ask` no funciona:
1. Verifica que la app esté instalada en tu workspace
2. Comprueba que la app tenga los permisos adecuados
3. Intenta reinstalar la integración

### Sin Respuesta

Si el bot no responde:
1. Verifica que tu agent esté configurado y funcionando (prueba en el Playground)
2. Comprueba que la integración de Slack esté conectada
3. Asegúrate de que el bot tenga acceso al canal

### Problemas de Permisos

Permisos requeridos:
- `commands` — Para slash commands
- `chat:write` — Para enviar mensajes
- `app_mentions:read` — Para menciones con @

## Seguridad

- Los tokens OAuth se encriptan
- Sin acceso a mensajes excepto comandos/menciones explícitas
- Los datos del workspace permanecen privados

## Desconexión

Para eliminar la integración con Slack:

1. **Desde Cuneiform Chat:**
   - Agents → Selecciona el agent → Integrations → Slack → Disconnect

2. **Desde Slack:**
   - Ve a la configuración del workspace
   - Apps → Busca la app → Remove

Ambos pasos aseguran una eliminación completa.
