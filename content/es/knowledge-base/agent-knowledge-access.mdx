# Acceso al Conocimiento del Agent

Controle a qué documentos puede acceder cada agent al responder preguntas. Restrinja agents a carpetas o tags específicos, o excluya cierto contenido de su alcance.

## Cómo Llegar

1. Navegue a **Agents** en el menú lateral
2. Haga clic en un agent para editarlo, o cree un nuevo agent
3. Desplácese hasta la sección **Knowledge Access Control**

## Modos de Acceso

El modo de acceso determina cómo sus selecciones afectan el acceso del agent a los documentos.

| Modo | Icono | Descripción | Cuándo Usar |
|------|-------|-------------|-------------|
| **Exclude Mode** | X roja | El agent accede a TODOS los documentos EXCEPTO los seleccionados | Cuando quiere ocultar documentos sensibles pero permitir todo lo demás |
| **Include Mode** | Check verde | El agent accede SOLO a los documentos seleccionados | Cuando quiere restringir el agent a contenido específico |

### Elegir el Modo Correcto

**Exclude Mode** (predeterminado):
- Comienza con acceso completo a todos los documentos
- Seleccione carpetas/tags para bloquear del agent
- Ideal para: Ocultar documentos de RRHH, datos financieros o borradores

**Include Mode**:
- Comienza sin acceso
- Seleccione carpetas/tags para otorgar acceso
- Ideal para: Crear agents especializados para temas específicos

## Seleccionar Contenido

### Por Carpetas

1. Haga clic en la pestaña **Folders**
2. Use el cuadro de búsqueda para encontrar carpetas
3. Marque carpetas para incluir/excluir
4. Expanda carpetas (haga clic en la flecha) para seleccionar documentos individuales
5. Una marca de verificación muestra los elementos seleccionados; la selección parcial muestra un guion

### Por Tags

1. Haga clic en la pestaña **Tags**
2. Use el cuadro de búsqueda para encontrar tags
3. Marque tags para incluir/excluir
4. Cada tag muestra cuántos documentos lo usan

## Panel de Vista Previa

El panel de vista previa a la derecha muestra:
- Total de documentos accesibles según la selección actual
- Se actualiza en tiempo real a medida que realiza cambios

## Guardar Cambios

Al editar un agent existente:
1. Realice sus selecciones
2. Haga clic en **Save Changes** (botón verde)
3. O haga clic en **Reset Changes** para deshacer cambios no guardados

Al crear un nuevo agent:
- La configuración de acceso al conocimiento se guarda automáticamente al enviar el formulario del agent

## Consejos

- Use **Exclude Mode** cuando desee acceso amplio con algunas excepciones
- Use **Include Mode** para agents enfocados en temas específicos
- Combine carpetas Y tags para un control preciso
- Verifique el panel de vista previa para confirmar su selección antes de guardar
- Para Include Mode, debe seleccionar al menos una carpeta o tag

## Preguntas Frecuentes

**P: ¿Qué pasa si selecciono carpetas y tags?**
R: El agent puede acceder a documentos que coincidan con CUALQUIERA de sus selecciones. Las carpetas y los tags se combinan de forma inclusiva.

**P: ¿Puedo dar a un agent acceso a todo?**
R: Sí. Use Exclude Mode y no seleccione nada para excluir. El agent tendrá acceso completo.

**P: ¿Qué pasa si un documento está en una carpeta seleccionada pero tiene un tag excluido?**
R: En Exclude Mode, cualquier coincidencia con contenido excluido bloquea el acceso. En Include Mode, cualquier coincidencia con contenido incluido otorga acceso.

**P: ¿Esto afecta las conversaciones existentes?**
R: Sí. Los cambios surten efecto inmediatamente para los nuevos mensajes. El agent usará las reglas de acceso actualizadas.
