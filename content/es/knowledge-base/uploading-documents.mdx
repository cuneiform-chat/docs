# Subir Documentos

Suba documentos a su content para que sus AI agents puedan usarlos para responder preguntas. Los documentos se procesan automáticamente y se hacen buscables.

## Cómo Llegar

1. Inicie sesión en el Admin Panel
2. Navegue a **Contenido** en el menú lateral
3. El área de upload se muestra en la parte superior de la página

## Métodos de Upload

### Upload de Archivos Locales

1. **Arrastre y suelte** archivos directamente en el área de upload, O
2. **Haga clic** en el área de upload para abrir el explorador de archivos
3. Seleccione uno o más archivos
4. Los archivos comienzan a subirse automáticamente con seguimiento de progreso

### Importar desde Cloud Storage

Importe archivos directamente desde sus proveedores de cloud storage:

| Proveedor | Icono | Cómo Usar |
|-----------|-------|-----------|
| Google Drive | Icono de Google Drive | Haga clic para abrir el selector de Google Drive, seleccione archivos |
| Dropbox | Icono de Dropbox | Haga clic para abrir el selector de Dropbox, seleccione archivos |
| OneDrive | Icono de OneDrive | Haga clic para abrir el selector de OneDrive, seleccione archivos |
| Box | Icono de Box | Haga clic para abrir el selector de Box, seleccione archivos |

Después de seleccionar archivos de cualquier proveedor, se importan automáticamente a su content.

## Opciones de Upload

### Agregar Tags

Opcionalmente asigne tags a los documentos durante el upload:

1. Haga clic en **+ Add Tags** antes de subir
2. Seleccione tags del menú desplegable
3. Los tags seleccionados se aplicarán a todos los documentos subidos

## Tipos de Archivo Compatibles

Los tipos de archivo que puede subir dependen de su plan. Los formatos comunes incluyen:

- **Documentos:** PDF, DOCX, DOC, TXT, MD, RTF
- **Presentaciones:** PPTX, PPT
- **Web/Datos:** HTML, HTM, JSON, XML

Los límites de tamaño de archivo también varían según el plan (se muestran en el área de upload).

Consulte [Formatos Compatibles](/knowledge-base/supported-formats) para la lista completa.

## Durante el Upload

### Seguimiento de Progreso

- Cada archivo muestra el progreso de upload con una barra de porcentaje
- Se muestra la velocidad de upload y el tiempo estimado restante
- Los archivos se procesan uno a la vez

### Opciones de Cancelación

- **Cancelar archivo individual:** Haga clic en la X junto a un archivo
- **Cancelar todos:** Haga clic en "Cancel All Pending" para detener todo el lote
- Aparece una advertencia si intenta salir de la página durante el upload

## Estado de Procesamiento

Rastree el estado de los documentos en Content:

| Status | Significado |
|--------|-------------|
| Uploading | El documento se está subiendo al sistema |
| Ready | El documento está procesado y disponible para sus agents |
| Processing | El documento se está analizando |
| Queued | En espera de ser procesado |
| Retrying | El procesamiento se está reintentando |
| Failed | El procesamiento encontró un error (se puede reintentar) |

## Después del Upload

### Upload Exitoso

- Los archivos subidos exitosamente aparecen en su navegador de documentos
- Los documentos se procesan automáticamente para búsqueda
- Puede organizarlos en carpetas o agregar tags

### Detección de Duplicados

- El sistema detecta contenido duplicado automáticamente
- Si ya existe un archivo con contenido idéntico, verá una advertencia
- La ubicación del archivo existente se muestra en el mensaje de error

### Manejo de Errores

- Si un archivo falla al subirse, un mensaje de error explica por qué
- Los problemas comunes incluyen archivo demasiado grande o formato no compatible
- Puede reintentar archivos individuales o subirlos de nuevo

## Consejos

- Suba múltiples archivos a la vez para ahorrar tiempo
- Aplique tags durante el upload para mantener los documentos organizados
- Verifique los tipos de archivo compatibles mostrados en el área de upload

## Preguntas Frecuentes

**P: ¿Cuántos archivos puedo subir a la vez?**
R: Puede seleccionar múltiples archivos para upload por lotes. Se procesan uno a la vez con seguimiento de progreso.

**P: ¿Por qué fue rechazado mi archivo?**
R: Verifique si el tipo de archivo es compatible y si el tamaño está dentro de los límites (se muestra en el área de upload). Algunos archivos pueden ser bloqueados por razones de seguridad.

**P: ¿Cuánto tarda el procesamiento?**
R: El tiempo de upload depende del tamaño del archivo y su conexión. Después del upload, los documentos se procesan en segundo plano y se vuelven buscables automáticamente.

**P: ¿Puedo subir a una carpeta específica?**
R: Sí, puede subir directamente a carpetas usando el menú de carpetas u organizar los documentos después del upload.
