# Carpetas y Etiquetas

Organice sus documentos de Content usando carpetas y tags. Las carpetas proporcionan organización jerárquica, mientras que los tags permiten categorización transversal entre carpetas.

## Cómo Llegar

Navegue a **Contenido** en el menú lateral. Las carpetas aparecen en el navegador de documentos y los controles de tags están en la barra de herramientas.

## Trabajar con Carpetas

### Crear una Carpeta

1. Haga clic en el botón **New Folder** (icono de carpeta con +) en la barra de herramientas
2. Ingrese un nombre de carpeta (obligatorio)
3. Opcionalmente agregue una descripción
4. Elija un color usando el selector de colores
5. Haga clic en **Create**

### Editar una Carpeta

1. Haga clic en el menú de tres puntos (...) en la fila de una carpeta
2. Seleccione **Rename**
3. Actualice el nombre, descripción o color
4. Haga clic en **Save Changes**

### Eliminar una Carpeta

1. Haga clic en el menú de tres puntos (...) en la fila de una carpeta
2. Seleccione **Delete**
3. Confirme la eliminación

### Subir a una Carpeta

- Arrastre archivos directamente sobre la fila de una carpeta
- Pase el cursor sobre una carpeta para revelar los iconos de upload (cloud storage + archivos locales)
- Haga clic para expandir una carpeta y ver sus documentos

## Trabajar con Tags

### Gestionar Tags (Crear, Editar, Eliminar)

1. Haga clic en el desplegable **Tag Filter** en la barra de herramientas
2. Haga clic en **Manage Tags** en la parte inferior
3. En el modal:
   - Haga clic en **Create Tag** para agregar un nuevo tag
   - Use los tags sugeridos para creación rápida
   - Edite tags existentes (nombre, color)
   - Elimine tags sin usar

### Agregar Tags a un Documento

1. Pase el cursor sobre la fila de un documento
2. Haga clic en el botón **Tag** (icono de tag)
3. En el diálogo Manage Tags:
   - Vea los tags actuales en la parte superior
   - Busque tags disponibles
   - Marque tags para agregar
   - Haga clic en el botón **Add X tags**

### Eliminar Tags de un Documento

1. Abra el diálogo Manage Tags para un documento
2. En la sección "Current Tags", haga clic en la X de los tags que desea eliminar
3. Haga clic en el botón **Remove X tags**

### Filtrar Documentos por Tags

1. Haga clic en el desplegable **Tag Filter** en la barra de herramientas
2. Seleccione uno o más tags
3. Solo se muestran documentos con esos tags
4. Los tags seleccionados aparecen en una barra de filtro debajo de la barra de herramientas
5. Haga clic en la X de un chip de tag para eliminar ese filtro, o **Clear all**

## Carpetas vs Tags

| Característica | Carpetas | Tags |
|----------------|----------|------|
| Estructura | Jerárquica (una carpeta por documento) | Plana (múltiples tags por documento) |
| Mejor para | Categorías amplias, proyectos, departamentos | Temas, estados, asuntos transversales |
| Filtrado | Haga clic en la carpeta para ver su contenido | Use el filtro de tags para buscar entre carpetas |
| Límite por documento | Una carpeta por documento | Tags ilimitados por documento |

## Consejos

- Use carpetas para categorías principales (ej. "Product Docs", "HR Policies")
- Use tags para temas transversales (ej. "Q1-2024", "Compliance", "Draft")
- Use colores en carpetas y tags para organización visual
- Los tags muestran el conteo de uso para ver cuántos documentos usan cada tag
- Combine filtrado por carpeta y tag para encontrar documentos con precisión

## Preguntas Frecuentes

**P: ¿Puede un documento estar en múltiples carpetas?**
R: No, cada documento pertenece a una carpeta (o "Unfiled"). Use tags para categorización transversal.

**P: ¿Qué pasa con los documentos cuando elimino una carpeta?**
R: Las carpetas con documentos no se pueden eliminar. Mueva o elimine los documentos primero.

**P: ¿Cómo veo todos los documentos con un tag específico?**
R: Use el desplegable Tag Filter en la barra de herramientas y seleccione el tag.
