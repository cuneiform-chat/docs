# Content

Content es donde gestiona todos los documentos que sus AI agents utilizan para responder preguntas. Suba documentos, organícelos en carpetas, agregue tags y controle qué agents pueden acceder a qué contenido.

## Cómo Funciona

1. **Agregar Content** — Suba documentos, importe desde cloud storage o rastree sitios web
2. **Process** — Los documentos se procesan e indexan automáticamente
3. **Search** — Los agents buscan contenido relevante al responder preguntas
4. **Respond** — Las respuestas se generan basándose en su contenido real

## Cómo Llegar

Navegue a **Knowledge** en el menú lateral. Este es su centro principal para la gestión de documentos.

## Lo Que Verá

### Área de Upload

En la parte superior de la página:
- **Iconos de Cloud Storage** — Haga clic en Google Drive, Dropbox, OneDrive o Box para importar archivos directamente
- **Drop Zone** — Arrastre y suelte archivos o haga clic para explorar archivos locales
- **Pestaña Website** — Cambie a la pestaña Website para rastrear e importar contenido de sitios web públicos

### Navegador de Documentos

Debajo del área de upload, una tabla muestra todos sus documentos:

| Columna | Descripción |
|---------|-------------|
| Name | Nombre del archivo con icono de tipo e indicador de origen |
| Tags | Etiquetas asignadas al documento |
| Status | Estado de procesamiento (ver Document Status abajo) |
| Size | Tamaño del archivo en MB |
| Type | Extensión del archivo (PDF, DOCX, etc.) |
| Uploaded | Fecha y hora de subida |
| Actions | Menú de operaciones del documento |

### Barra de Herramientas

- **Search** — Buscar documentos por nombre
- **Tag Filter** — Mostrar solo documentos con tags específicos
- **Refresh** — Actualizar la lista de documentos
- **New Folder** — Crear una carpeta para organización
- **Fullscreen** — Expandir el navegador para más espacio

## Document Status

| Status | Significado |
|--------|-------------|
| Uploading | El documento se está subiendo al sistema |
| Ready | El documento está procesado y disponible para sus agents |
| Processing | El documento se está analizando |
| Queued | En espera de ser procesado |
| Retrying | El procesamiento se está reintentando |
| Failed | El procesamiento encontró un error (se puede reintentar) |

## Trabajar con Documentos

### Ver un Documento

Haga clic en cualquier fila de documento para abrir el visor, que muestra el contenido y los metadatos.

### Acciones de Documento

Pase el cursor sobre un documento para ver los botones de acción rápida:
- **Tag** — Agregar o eliminar tags
- **Premium Processing** — Mejorar la calidad de procesamiento (si es elegible)
- **Retry** — Reprocesar documentos fallidos
- **Chat** — Tener una conversación sobre este documento específico

Desde el menú Actions (...):
- **Move to Folder** — Reubicar el documento
- **Reprocess** — Reintentar el procesamiento de documentos fallidos
- **Delete** — Eliminar el documento permanentemente

## Mejores Prácticas

- **Mantenga el contenido actualizado** — Actualice los documentos regularmente para mantener la precisión
- **Organice con carpetas** — Agrupe documentos relacionados para una gestión más fácil
- **Use tags para temas transversales** — Los tags ayudan a encontrar documentos entre carpetas
- **La calidad importa** — Documentos bien estructurados producen mejores respuestas de IA
- **Elimine duplicados** — Evite subir el mismo contenido varias veces
