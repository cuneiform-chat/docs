# Formatos Compatibles

Cuneiform Chat admite una amplia variedad de formatos de documentos.

## Tipos de Documentos

### Documentos de Texto

| Formato | Extensiones | Notas |
|---------|-------------|-------|
| PDF | `.pdf` | Basados en texto y escaneados (con OCR) |
| Microsoft Word | `.docx`, `.doc` | Soporte completo de formato |
| Texto plano | `.txt` | Archivos de texto simples |
| Markdown | `.md` | Se preserva el formato Markdown |
| Rich Text | `.rtf` | Soporte básico de formato |

### Presentaciones

| Formato | Extensiones | Notas |
|---------|-------------|-------|
| PowerPoint | `.pptx`, `.ppt` | Se extrae el contenido de las diapositivas |

### Contenido Web

| Formato | Extensiones | Notas |
|---------|-------------|-------|
| HTML | `.html`, `.htm` | Contenido de páginas web |

### Formatos de Datos

| Formato | Extensiones | Notas |
|---------|-------------|-------|
| JSON | `.json` | Archivos de datos estructurados |
| XML | `.xml` | Documentos XML |

## Notas Específicas por Formato

### PDFs

Los PDFs funcionan mejor cuando son:
- **Basados en texto** — Creados a partir de documentos digitales
- **Buscables** — El texto se puede seleccionar/copiar

Los PDFs escaneados son compatibles pero pueden tener menor calidad de extracción debido a las limitaciones del OCR.

### Documentos de Word

Se recomienda `.docx` (formato moderno) sobre `.doc` (formato legacy) para mejores resultados.

Elementos compatibles:
- Texto y párrafos
- Encabezados y estilos
- Tablas
- Listas

### Markdown

El formato Markdown se preserva durante el procesamiento:
- Los encabezados se convierten en marcadores de sección
- Las listas mantienen su estructura
- Los bloques de código se reconocen

## Formatos No Compatibles

Los siguientes formatos no son compatibles actualmente:
- Imágenes (`.jpg`, `.png`, `.gif`)
- Archivos de audio (`.mp3`, `.wav`)
- Archivos de video (`.mp4`, `.mov`)
- Archivos comprimidos (`.zip`, `.rar`)
- Archivos ejecutables (`.exe`, `.app`)

## Límites de Tamaño de Archivo

Los tamaños máximos de archivo dependen de su plan. Los documentos muy grandes pueden tardar más en procesarse.

Para un mejor rendimiento:
- Divida documentos muy grandes en archivos más pequeños
- Elimine imágenes innecesarias de los PDFs si no son necesarias
- Use formatos basados en texto cuando sea posible
