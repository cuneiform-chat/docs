# Uso y Créditos

Entiende cómo funcionan los créditos y monitorea tu consumo.

## Sistema de Créditos

Cuneiform Chat utiliza créditos (llamados Platform Credits) para medir el uso:
- **Consultas de IA** — Cuando tus agents responden preguntas
- **Procesamiento de documentos** — Cuando se suben e indexan documentos
- **Embeddings** — Generación de vectores para búsqueda

## Cómo se Usan los Créditos

### Consultas de IA

Cada vez que tu agent responde una pregunta:
- Los créditos se consumen según el modelo de IA utilizado
- Las respuestas más largas pueden usar ligeramente más créditos
- Las consultas fallidas no consumen créditos

### Procesamiento de Documentos

Cuando subes documentos:
- Los créditos se usan para extraer y procesar contenido
- Los documentos más grandes usan más créditos
- El reprocesamiento usa créditos adicionales

## Ver el Uso

Accede a tu uso desde **Billing & Plans** en la barra lateral:

- **Uso del período actual** — Créditos usados en este ciclo de billing
- **Créditos restantes** — Créditos disponibles
- **Porcentaje de uso** — Barra de progreso visual mostrando el consumo

## Monitoreo de Uso

### Visualización de Uso

La página de billing muestra:
- Créditos usados vs. asignados
- Porcentaje de uso con barra de progreso visual
- Indicador de estado (normal, advertencia, excedido, bloqueado)

### Advertencias de Uso

La plataforma muestra advertencias automáticamente a medida que te acercas a tus límites:

| Umbral | Qué Sucede |
|--------|------------|
| ~80% usado | Aparece un banner de advertencia en la página de Billing |
| 100% usado | Banner de "Limit Reached" con solicitud de upgrade |
| Bloqueado | Servicio pausado hasta el próximo período o upgrade |

Estas advertencias aparecen automáticamente — no se necesita configuración.

## Optimizar el Uso de Créditos

### Agents Eficientes

- Escribe agent personas claras para respuestas precisas desde el primer intento

### Gestión Inteligente de Documentos

- Sube solo los documentos necesarios
- Elimina contenido desactualizado
- Evita documentos duplicados

### Patrones de Uso

- Monitorea qué agents usan más créditos
- Identifica períodos de alto volumen
- Optimiza basándote en patrones

## Qué Sucede en los Límites

### Acercándose a los Límites

A medida que te acercas a tu límite de créditos, aparecen banners de advertencia en la página de Billing sugiriendo que actualices tu plan o habilites Extra Usage.

### Excediendo los Límites

Cuando excedes tu cuota mensual:
- Un banner de advertencia indica "Limit Reached"
- Habilita **Extra Usage** para continuar sin esperar
- O actualiza tu plan para más créditos mensuales

### Estado Bloqueado

Si el saldo de Extra Usage también se agota:
- El servicio se pausa hasta el próximo período de billing
- O agrega fondos a tu saldo de Extra Usage

## Extra Usage

Extra Usage te permite seguir usando el servicio cuando tu cuota mensual se agota.

### Habilitar Extra Usage

1. Ve a **Billing & Plans**
2. Encuentra la sección **Extra Usage**
3. Activa el toggle para habilitar
4. Completa la recarga inicial (mínimo $10)

### Gestionar Extra Usage

Una vez habilitado, puedes:

- **Ver saldo** — Consulta tus fondos disponibles de Extra Usage
- **Agregar fondos** — Recarga tu saldo ($10-$500 por transacción)
- **Establecer límite de gasto** — Limita el gasto mensual de Extra Usage ($10-$500)

### Cómo Funciona Extra Usage

- Los cargos se deducen de tu saldo de Extra Usage
- El uso se detiene cuando alcanzas tu límite de gasto
- El saldo se mantiene entre períodos de billing
- No se puede deshabilitar una vez activado (usa el límite de gasto para controlar)

<Callout type="info">
  Extra Usage solo está disponible para planes de pago (Starter, Plus y Enterprise).
</Callout>

## Período de Billing

- Los créditos se reinician al inicio de cada período de billing
- Tu fecha de billing se muestra en la configuración de la cuenta
- Los créditos no utilizados podrían no acumularse (consulta tu plan)
