# Billing y Plans

Gestiona tu suscripción y comprende tu billing.

## Descripción General

Cuneiform Chat ofrece planes flexibles para adaptarse a tus necesidades:
- **Trial** — Un plan gratuito que se renueva cada mes y nunca vence
- **Starter** — Para equipos que están comenzando
- **Plus** — Para negocios en crecimiento
- **Enterprise** — Para despliegues a gran escala

## Billing Dashboard

Accede al billing desde el menú **Billing & Plans** en la barra lateral:

- Plan actual y estado
- Uso en este período
- Historial de transacciones
- Configuración de Extra Usage

## Acciones Rápidas

| Acción | Ubicación |
|--------|-----------|
| Ver plan actual | Tab **Overview** |
| Mejorar plan | Botón **Change Plan** |
| Ver transacciones | Tab **Payments** |
| Agregar fondos de Extra Usage | Sección **Extra Usage** |

## Ciclo de Billing

- Los planes se facturan mensualmente
- El uso se reinicia al inicio de cada período de billing
- Los upgrades se aplican de inmediato
- Los downgrades se aplican al final del período de billing (los cambios de plan quedan bloqueados hasta entonces)

## Métodos de Pago

Métodos de pago aceptados:
- Tarjetas de crédito (Visa, Mastercard, Amex)
- Tarjetas de débito
