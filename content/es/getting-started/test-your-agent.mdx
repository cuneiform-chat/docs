# Prueba tu Agent

Antes de desplegar tu agent, usa el Playground para probar sus respuestas y ajustar su comportamiento.

## Acceder al Playground

1. Navega a **Agents** en la barra lateral
2. Haz clic en **Test** en la tarjeta de tu agent
3. El Playground se abre como un panel lateral — ¡empieza a chatear!

Usa el botón de alternar la barra lateral para ocultar la lista de conversaciones y tener más espacio. Presiona **Shift+Enter** para agregar nuevas líneas sin enviar.

## Probar tu agent

### Haz preguntas de ejemplo

Prueba preguntas que tus usuarios podrían hacer:

- Preguntas respondidas directamente por tus documentos
- Preguntas de seguimiento que requieren contexto
- Casos límite y consultas ambiguas
- Preguntas fuera de tu contenido (para probar los límites)

### Evalúa las respuestas

Para cada respuesta, considera:

- **Precisión** — ¿Es correcta la información?
- **Relevancia** — ¿Responde a la pregunta real?
- **Tono** — ¿Coincide con el estilo esperado?
- **Fuentes** — ¿Son útiles las referencias a documentos?

## Refinar tu agent

Basándote en las pruebas, puede que quieras ajustar:

### Agent Persona

Si las respuestas no son del todo correctas, refina el agent persona:

- Agrega instrucciones específicas para escenarios comunes
- Aclara el tono y la personalidad
- Establece límites sobre lo que el agent debe y no debe hacer

### Contenido

Si el agent no encuentra información:

- Verifica que los documentos relevantes estén subidos
- Confirma que los documentos se procesaron correctamente
- Considera agregar contenido más detallado

## Historial de conversaciones

El Playground mantiene el historial de conversaciones dentro de una sesión. Úsalo para probar:

- Conversaciones de múltiples turnos
- Retención de contexto
- Preguntas de seguimiento

Mientras el agent responde, verás indicadores de herramientas mostrando lo que está haciendo (buscando documentos, procesando tu consulta, etc.). Haz clic en **Stop** si necesitas cancelar una respuesta.

## Activar tu agent

Los agents nuevos comienzan en estado **Testing** — puedes probar en el Playground, pero las integraciones de canales están desactivadas.

Para habilitar integraciones:

1. Abre la página de edición de tu agent
2. Cambia el dropdown de **Status** de "Testing" a "Active"
3. Haz clic en **Save**

Una vez activo, puedes desplegar en varios canales:

- [Telegram](/es/integrations/telegram) — Conecta con Telegram
- [Discord](/es/integrations/discord) — Agrega a tu servidor de Discord
- [Slack](/es/integrations/slack) — Integra con espacios de trabajo de Slack
- [WhatsApp](/es/integrations/whatsapp) — Conecta con WhatsApp Business
- [Messenger](/es/integrations/facebook) — Conecta con Facebook Messenger
- [Google Chat](/es/integrations/google-chat) — Integra con Google Workspace
