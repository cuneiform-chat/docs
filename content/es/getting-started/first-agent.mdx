# Crea tu Primer Agent

Los agents son los chatbots que interactúan con tus usuarios. Cada agent puede configurarse con conocimiento, comportamiento y personalidad específicos.

## Crear un agent

1. Navega a **Agents** en la barra lateral
2. Haz clic en **Create Agent**
3. Completa la información básica:
   - **Name** — Un nombre descriptivo para tu agent (ej. "Bot de Soporte al Cliente")
   - **Description** — Qué hace este agent (para tu referencia)

## Configuración del agent

### Agent Persona

El agent persona define la personalidad y el comportamiento de tu agent. Esta es la instrucción que guía cómo responde tu agent.

Puedes escribir tu propio persona o hacer clic en **Generate** para usar el Persona Builder impulsado por AI que crea uno basado en tus requisitos.

**Ejemplo:**
```
You are a helpful customer support assistant for Acme Corp.
You answer questions about our products and services based on the provided documentation.
Be friendly, professional, and concise.
If you don't know the answer, say so rather than making something up.
```

### Reglas de la plataforma

Todos los agents incluyen automáticamente medidas de seguridad integradas:

- No fabrican hechos, números ni fechas
- Dicen "No lo sé" cuando la información no está disponible
- No adivinan información faltante
- Corrigen suposiciones incorrectas en las preguntas
- No se hacen pasar por profesionales (abogados, médicos, etc.)
- Rechazan contenido dañino o inapropiado

Estas reglas están siempre activas y no pueden desactivarse.

### Knowledge Access Control

Controla a qué documentos puede acceder tu agent:

- **Exclude Mode** (predeterminado) — El agent accede a todos los documentos excepto los que selecciones para ocultar
- **Include Mode** — El agent solo accede a las carpetas, etiquetas o documentos específicos que selecciones

Usa Include Mode cuando quieras restringir un agent a un conjunto de conocimiento específico.

### Configuración de LLM

Para la mayoría de los usuarios, la configuración predeterminada del modelo de AI funciona bien. Los usuarios avanzados pueden personalizar:

- **Model** — Elige entre los modelos de AI disponibles
- **Temperature** — Más bajo = más consistente, más alto = más creativo
- **Show Document References** — Activa para incluir citas de fuentes en las respuestas

## Guarda tu agent

Haz clic en **Create Agent** para guardar. Tu agent comienza en estado **Testing**, lo que significa que puedes probarlo en el Playground pero las integraciones de canales están desactivadas hasta que lo actives.
