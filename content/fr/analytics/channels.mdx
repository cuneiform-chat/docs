# Analytique des canaux

Consultez les métriques de performance ventilées par canal. Comparez les volumes de requêtes, les conversations, les utilisateurs uniques et l'utilisation des crédits sur toutes les plateformes où vos agents reçoivent des requêtes.

## Accéder à l'analytique des canaux

1. Naviguez vers **Analytics** dans la barre latérale
2. Cliquez sur **View All** à côté de "Channel Distribution", ou
3. Allez directement dans **Analytics > Channels**

## Navigation

Le fil d'Ariane montre votre emplacement : **Dashboard / Channels**. Cliquez sur "Dashboard" pour revenir à la page analytique principale.

## Contrôles de plage de dates

| Contrôle | Description |
|----------|-------------|
| **Last 7 days** | Voir les métriques de la dernière semaine |
| **Last 14 days** | Voir les métriques des deux dernières semaines |
| **Last 30 days** | Voir les métriques du dernier mois |
| **Last 90 days** | Voir les métriques du dernier trimestre |
| **Refresh** | Recharger les données avec les dernières valeurs |

## Cartes récapitulatives

Quatre cartes montrant les métriques agrégées de tous les canaux :

| Carte | Description |
|-------|-------------|
| Total Channels | Nombre de canaux actifs |
| Total Queries | Somme des requêtes de tous les canaux |
| Total Conversations | Somme des conversations de tous les canaux |
| Total Credits | Somme des crédits utilisés de tous les canaux |

## Tableau des canaux

Tous vos canaux actifs listés avec les métriques de performance :

| Colonne | Description |
|---------|-------------|
| Channel | Nom du canal avec badge codé par couleur |
| Queries | Total des questions répondues sur ce canal |
| Conversations | Sessions de chat sur ce canal |
| Unique Users | Utilisateurs distincts ayant interagi via ce canal |
| Credits | Ressources consommées par ce canal |
| % of Total | Barre de progression visuelle montrant la part de ce canal dans le total des requêtes |
| (Flèche) | Lien vers la vue détaillée du canal |

## Types de canaux

Vos agents peuvent recevoir des requêtes de diverses plateformes :

| Canal | Description |
|-------|-------------|
| Playground | Requêtes depuis l'interface de test des agents |
| Telegram | Intégration bot Telegram |
| Discord | Intégration bot Discord |
| Slack | Intégration application Slack |
| Meta | Intégration Meta/Messenger |
| WhatsApp | Intégration WhatsApp Business |
| Google Chat | Intégration Google Chat (Workspace) |

## Voir les détails d'un canal

Cliquez sur la flèche de n'importe quelle ligne de canal pour voir :
- Métriques détaillées pour ce canal spécifique
- Graphiques de séries temporelles avec options de granularité (par heure, jour, semaine, mois)
- Répartition par agent au sein de ce canal

## Conseils

- Comparez le **% of Total** pour comprendre quels canaux génèrent le plus de trafic
- Utilisez cette vue pour identifier les canaux sous-performants qui nécessitent de l'attention
- Vérifiez les **Unique Users** pour comprendre la portée de l'audience par plateforme
- Consultez les **Credits** pour voir la consommation de ressources par canal

## Questions fréquentes

**Q : Pourquoi tous les canaux ne sont-ils pas listés ?**

Seuls les canaux ayant au moins une requête pendant la plage de dates sélectionnée apparaissent dans le tableau.

**Q : Comment le pourcentage est-il calculé ?**

Le pourcentage montre la part de chaque canal dans le total des requêtes de tous les canaux pour la période sélectionnée.

**Q : Puis-je comparer les canaux dans le temps ?**

Cliquez sur un canal spécifique pour voir ses données de séries temporelles et ses tendances.
