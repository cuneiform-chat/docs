# Analytique

Surveillez les performances de vos agents et comprenez comment les utilisateurs interagissent avec vos chatbots.

## Aperçu

L'analytique vous aide à :
- Suivre le volume des conversations et les tendances des requêtes
- Surveiller les performances des agents et l'utilisation des crédits
- Comprendre la distribution des canaux
- Identifier les axes d'amélioration

## Tableau de bord

Accédez à l'analytique depuis la section **Analytics** dans votre barre latérale.

### Métriques clés

| Métrique | Description |
|----------|-------------|
| Total Queries | Exécutions d'agents (réponses IA) |
| Conversations | Nombre de sessions de chat |
| Unique Users | Utilisateurs individuels ayant discuté |
| Credits Used | Crédits de la plateforme consommés |

### Utilisation des crédits

Le tableau de bord affiche la consommation de crédits du cycle de facturation en cours :
- Crédits utilisés vs. alloués
- Barre de progression en pourcentage
- Crédits restants pour la période

### Graphiques

Le tableau de bord inclut des graphiques visuels :
- **Query Volume** — Graphique linéaire montrant les requêtes dans le temps
- **Channel Distribution** — Graphique circulaire détaillant les requêtes par canal
- **Agent Distribution** — Graphique circulaire détaillant les requêtes par agent

### Top Agents

Une liste classée de vos agents les plus actifs montrant :
- Nom de l'agent et rang
- Total des requêtes traitées
- Nombre de conversations
- Crédits consommés
- Statut actuel (active, inactive, testing, archived)

Cliquez sur n'importe quel agent pour voir l'analytique détaillée, ou cliquez sur **View All** pour voir tous les agents.

### Top Channels

Une liste classée de vos canaux de communication les plus actifs montrant :
- Nom du canal et rang
- Total des requêtes traitées
- Nombre de conversations
- Crédits consommés

Cliquez sur n'importe quel canal pour voir l'analytique détaillée, ou cliquez sur **View All** pour voir tous les canaux.

## Périodes

Consultez l'analytique pour différentes plages de temps :
- Cycle de facturation en cours
- 7 derniers jours
- 14 derniers jours
- 30 derniers jours
- 90 derniers jours

## Granularité

Ajustez le regroupement des données :
- Par heure
- Par jour
- Par semaine
- Par mois

## Filtrage

Filtrez l'analytique par :
- **Agent** — Voir les métriques pour des agents spécifiques
- **Canal** — Comparer les performances entre les plateformes
- **Plage de dates** — Analyser des périodes spécifiques

## Utiliser l'analytique

### Identifier les tendances

Voyez quels canaux et agents traitent le plus de requêtes pour :
- Optimiser l'allocation des ressources
- Concentrer les améliorations où c'est nécessaire
- Comprendre les préférences des utilisateurs

### Surveiller les performances

Suivez les tendances pour vous assurer que :
- L'utilisation des crédits reste dans les limites
- L'engagement des utilisateurs est sain
- Aucun schéma inhabituel n'apparaît

### Optimiser les agents

Utilisez les informations pour :
- Ajuster les personas des agents
- Ajouter la documentation manquante
- Améliorer la précision des réponses
