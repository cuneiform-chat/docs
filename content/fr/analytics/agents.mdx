# Analytique des Agents

Consultez les métriques de performance détaillées de tous vos agents. Comparez les volumes de requêtes, les conversations et l'utilisation des crédits de l'ensemble de votre portefeuille d'agents.

## Accéder à l'analytique des Agents

1. Naviguez vers **Analytics** dans la barre latérale
2. Cliquez sur **View All** à côté de "Top Agents", ou
3. Allez directement dans **Analytics > Agents**

## Navigation

Le fil d'Ariane montre votre emplacement : **Dashboard / Agents**. Cliquez sur "Dashboard" pour revenir à la page analytique principale.

## Contrôles de plage de dates

| Contrôle | Description |
|----------|-------------|
| **Last 7 days** | Voir les métriques de la dernière semaine |
| **Last 14 days** | Voir les métriques des deux dernières semaines |
| **Last 30 days** | Voir les métriques du dernier mois |
| **Last 90 days** | Voir les métriques du dernier trimestre |
| **Refresh** | Recharger les données avec les dernières valeurs |

## Tableau des Agents

Tous vos agents listés avec les métriques de performance :

| Colonne | Description | Triable |
|---------|-------------|---------|
| Agent | Nom de l'agent | Non |
| Status | active, inactive, testing ou archived | Non |
| Queries | Total des questions répondues | Oui |
| Conversations | Sessions de chat | Oui |
| Credits | Ressources consommées | Oui |
| Channels | Sur quels canaux l'agent est utilisé | Non |
| (Flèche) | Lien vers la vue détaillée | Non |

### Tri

Cliquez sur n'importe quel en-tête de colonne triable pour trier par cette métrique :
- **Premier clic** : Tri décroissant (le plus élevé en premier)
- **Deuxième clic** : Tri croissant (le plus bas en premier)
- La colonne de tri active est mise en surbrillance

### Pagination

Pour les grandes listes d'agents :
- Affiche "Showing X - Y of Z"
- Utilisez les boutons **Previous/Next** pour naviguer entre les pages

## Badges de statut des Agents

| Badge | Couleur | Signification |
|-------|---------|---------------|
| active | Vert | L'agent est déployé et reçoit des requêtes |
| inactive | Gris | L'agent est en pause |
| testing | Jaune | L'agent est en cours de test avant le déploiement |
| archived | Jaune | L'agent est archivé |

## Badges de canaux

La colonne Channels montre sur quelles plateformes chaque agent est utilisé :
- Jusqu'à 3 badges de canal affichés (ex. : "web", "telegram", "discord")
- Si plus de 3, affiche "+X" pour indiquer les canaux supplémentaires

## Voir les détails d'un Agent

Cliquez sur la flèche de n'importe quelle ligne d'agent pour voir :
- Métriques détaillées pour cet agent spécifique
- Graphiques de séries temporelles
- Répartition par canal
- Données plus granulaires

## Conseils

- Triez par **Credits** pour trouver vos agents les plus gourmands en ressources
- Triez par **Queries** pour identifier vos agents les plus populaires
- Utilisez **90 days** pour l'analyse des tendances à long terme
- Vérifiez les agents inactifs pour voir s'ils devraient être réactivés
- Cliquez sur les agents individuels pour des analyses plus approfondies

## Questions fréquentes

**Q : Comment trouver mon agent le plus utilisé ?**

Cliquez sur l'en-tête de colonne "Queries" pour trier par nombre de requêtes. La première ligne est votre agent le plus actif.

**Q : Que signifient les badges de canaux ?**

Ils montrent quelles plateformes (Web, Telegram, Discord, Slack, etc.) chaque agent reçoit des requêtes.

**Q : Pourquoi un agent affiche-t-il zéro requête ?**

L'agent est peut-être nouveau, inactif ou pas encore déployé sur un canal.
