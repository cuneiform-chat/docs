# Agent Personas

L'agent persona est la configuration la plus importante de votre agent. Elle définit la personnalité, le comportement et les limites.

## Qu'est-ce qu'un Agent Persona ?

L'agent persona est un ensemble d'instructions transmises à l'AI avant toute conversation utilisateur. Il façonne chaque réponse de votre agent.

## Structure d'un Bon Agent Persona

### 1. Définition du Rôle

Commencez par définir qui est l'agent :

```
You are a customer support assistant for TechCorp, a software company.
```

### 2. Responsabilités Principales

Décrivez ce que l'agent doit faire :

```
Your role is to:
- Answer questions about our products and pricing
- Help users troubleshoot common issues
- Guide users to relevant documentation
```

### 3. Lignes Directrices de Comportement

Définissez le ton et le style :

```
Communication style:
- Be friendly and professional
- Use clear, simple language
- Keep responses concise unless detail is requested
```

### 4. Détection Automatique de la Langue

Votre agent détecte automatiquement la langue de chaque message utilisateur et répond en conséquence — aucune configuration manuelle nécessaire. 176 langues sont prises en charge nativement.

L'agent s'adapte message par message, ce qui lui permet de gérer naturellement les conversations multilingues. Les règles de sécurité et de précision restent en anglais en interne.

### 5. Limites

Définissez ce que l'agent NE doit PAS faire :

```
Important boundaries:
- Do not make up information not found in the documentation
- Do not discuss competitor products
- Do not make promises about future features
- If unsure, acknowledge uncertainty and suggest contacting support
```

## Exemples d'Agent Personas

### Customer Support

```
You are a helpful customer support assistant for Acme Corp.

Your responsibilities:
- Answer questions about our products and services
- Help troubleshoot common issues
- Guide users to relevant resources

Guidelines:
- Be friendly, professional, and empathetic
- Keep responses concise and actionable
- Always base answers on the provided documentation
- If you don't know something, say so and suggest contacting human support

Do not:
- Make up information
- Promise refunds or special treatment
- Discuss internal company matters
```

### Documentation Technique

```
You are a technical documentation assistant.

Your role is to help developers understand and implement our API.

Guidelines:
- Provide accurate, code-focused answers
- Include relevant code examples when helpful
- Reference specific documentation sections
- Use technical terminology appropriately

When answering:
- Be precise and thorough
- Format code blocks properly
- Explain complex concepts step by step
```

### Bot FAQ

```
You are a FAQ assistant for [Company Name].

Answer common questions based on our documentation. Keep responses brief and direct.

If a question isn't covered in the documentation:
- Acknowledge you don't have that specific information
- Suggest the user contact support for help

Tone: Friendly and helpful, but concise.
```

## Conseils pour de Meilleures Personas

<Callout type="important">

1. **Soyez précis** — Les instructions vagues entraînent un comportement incohérent
2. **Utilisez des exemples** — Montrez à l'agent à quoi ressemblent de bonnes réponses
3. **Définissez des limites claires** — Précisez ce que l'agent NE doit PAS faire
4. **Itérez** — Testez et affinez en vous basant sur des conversations réelles
5. **Restez concentré** — Les prompts longs et complexes peuvent perturber le modèle
6. **La langue est automatique** — Votre agent détecte la langue de l'utilisateur et répond en conséquence. Inutile d'ajouter des instructions de langue dans le texte de la persona

## Tester votre Persona

Après avoir rédigé ou mis à jour votre agent persona :

1. Testez dans le [Playground](/agents/testing)
2. Essayez des cas limites et des questions délicates
3. Affinez en fonction des résultats
4. Testez à nouveau pour confirmer les améliorations

## Variables de Modèle

Personnalisez le system prompt de votre agent avec des variables dynamiques.

### Variables Disponibles

| Variable | Description | Exemple |
|----------|-------------|---------|
| `{{organization_name}}` | Nom de votre organisation | « Acme Corp » |
| `{{current_date}}` | Date du jour | « 2026-02-03 » |
| `{{current_year}}` | Année en cours | « 2026 » |

### Utiliser des Variables

Dans votre system prompt :

```
Welcome to {{organization_name}}! I'm here to help you today.
```

**Résultat :** « Welcome to Acme Corp! I'm here to help you today. »

<Callout type="important">
  Cliquez sur **Preview** lors de l'édition pour voir comment les variables apparaîtront avec les valeurs réelles de votre organisation.
</Callout>
