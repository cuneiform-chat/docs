# Créer des Agents

import { Callout } from 'nextra/components'

Apprenez à créer de nouveaux agents dans Cuneiform Chat.

## Premiers Pas

1. Accédez à **Agents** dans la barre latérale
2. Cliquez sur le bouton **Create Agent** en haut à droite
3. Remplissez les sections du formulaire ci-dessous

## Informations de Base

Cette section recueille les informations essentielles concernant votre agent.

| Champ | Obligatoire | Description |
|-------|----------|-------------|
| **Name** | Oui | Un nom pour votre agent (par exemple, « Customer Support Agent »). Maximum 100 caractères. |
| **Description** | Non | Une brève description de ce que fait cet agent. Maximum 500 caractères. |

**Conseils :**
- Choisissez un nom descriptif qui indique l'objectif de l'agent
- La description vous aide, vous et votre équipe, à comprendre le rôle de l'agent

## Agent Persona

L'agent persona définit le comportement et les réponses de votre agent à travers un system prompt.

**Éléments clés :**

- **Encadré Platform Rules** — Affiche les règles de sécurité intégrées appliquées automatiquement (cliquez pour voir les détails)
- **Bouton Generate** — Ouvre l'[Agent Persona Builder](/agents/persona-builder) pour vous aider à créer votre persona
- **Bouton Edit** — Ouvre un panneau pour rédiger ou modifier la persona manuellement

### Platform Rules

Ces guardrails de sécurité s'appliquent automatiquement à tous les agents :

- **No fabrication** — N'invente pas de faits absents de votre contenu
- **Acknowledges gaps** — Dit « je ne sais pas » lorsque c'est approprié
- **Resists speculation** — Ne devine pas les informations manquantes
- **No professional impersonation** — Ne se fait pas passer pour un avocat, un médecin, etc.
- **Corrects false premises** — Signale les hypothèses incorrectes
- **Blocks harmful content** — Refuse les demandes inappropriées

<Callout type="info">
  Les Platform Rules garantissent que tous les agents se comportent de manière fiable et sûre. Elles ne peuvent pas être désactivées. Voir [Agent Persona Builder](/agents/persona-builder#platform-rules) pour plus de détails.
</Callout>

### Exemple Rapide de Persona

```
You are a helpful assistant for [Your Company].
Answer questions based on the provided documentation.
Be concise and friendly.
```

Voir [Agent Personas](/agents/agent-personas) pour des conseils détaillés sur la rédaction de personas efficaces.

## Prise en Charge des Langues

Votre agent détecte automatiquement la langue de chaque message utilisateur et répond dans la même langue — aucune configuration nécessaire. 176 langues sont prises en charge nativement. Voir [Agent Personas — Détection de la langue](/agents/agent-personas#4-automatic-language-detection) pour plus de détails.

## Configuration du LLM

Cette section contrôle les paramètres du modèle AI.

**Mode par défaut :**

Par défaut, les paramètres LLM utilisent les valeurs par défaut du tier de votre organisation. Vous verrez un encadré indiquant « Using tier defaults ». C'est recommandé pour la plupart des cas d'usage.

**Mode Avancé :**

Activez **Advanced** pour personnaliser :

| Paramètre | Description |
|---------|-------------|
| **Model** | Choisissez parmi les modèles AI disponibles selon votre plan |
| **Temperature** | Contrôle la créativité des réponses (plus bas = plus cohérent, plus haut = plus créatif) |

**Show Document References :**

Ce toggle (toujours visible) contrôle si l'agent inclut des citations de sources dans ses réponses :
- **Off** (par défaut) — Les réponses ne mentionnent pas les documents sources
- **On** — Les réponses incluent les références aux documents sources (utile pour les usages juridiques ou de conformité)

## Contrôle d'Accès aux Connaissances

Contrôlez les documents auxquels votre agent peut accéder pour répondre aux questions.

| Mode | Comportement | Quand l'utiliser |
|------|----------|-------------|
| **Exclude Mode** | L'agent accède à TOUS les documents SAUF ceux sélectionnés | Masquer des documents sensibles à l'agent |
| **Include Mode** | L'agent accède UNIQUEMENT aux éléments sélectionnés | Restreindre l'agent à un ensemble spécifique de connaissances |

**En utilisant Include Mode :**
- Sélectionnez les dossiers spécifiques accessibles à l'agent
- Sélectionnez les tags spécifiques accessibles à l'agent
- Sélectionnez les documents individuels accessibles à l'agent

L'agent n'utilisera que les informations des sources sélectionnées pour répondre.

<Callout type="important">
  Commencez avec Exclude Mode (accès complet aux connaissances), sauf si vous devez masquer des documents spécifiques. Vous pouvez toujours restreindre l'accès plus tard.
</Callout>

## Actions du Formulaire

En bas du formulaire :

| Bouton | Action |
|--------|--------|
| **Cancel** | Abandonner les modifications et revenir |
| **Reset** | Vider tous les champs et recommencer (affiche une boîte de dialogue de confirmation) |
| **Create Agent** | Enregistrer l'agent et ouvrir sa page d'édition |

<Callout type="info">
  Votre brouillon est enregistré automatiquement pendant que vous travaillez. Si vous quittez puis revenez, votre progression sera restaurée.
</Callout>

## Après la Création

Lorsque vous cliquez sur **Create Agent** :

1. L'agent est créé avec le statut **Testing**
2. Vous êtes dirigé vers la page d'édition de l'agent
3. Testez l'agent à l'aide du Playground
4. Connectez les intégrations lorsque vous êtes prêt à passer en production
5. Changez le statut en **Active** quand c'est prêt

<Callout type="info">
  Les nouveaux agents démarrent avec le statut **Testing**. Vous pouvez les tester dans le Playground, mais les intégrations de canaux sont désactivées tant que l'agent n'est pas activé.
</Callout>

## Gérer les Agents

Depuis la page Agents, vous pouvez :

- **Edit** — Cliquez sur n'importe quel agent pour modifier ses paramètres
- **Test** — Cliquez sur **Test** sur la carte d'un agent pour ouvrir le Playground
- **Change Status** — Définir sur Testing, Active, Inactive ou Archived

Voir [Options de configuration](/agents/configuring) pour le détail de tous les paramètres de l'agent.
