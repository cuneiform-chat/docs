# Tester dans le Playground

import { Callout } from 'nextra/components'

Le Playground est votre environnement pour tester et affiner les agents avant le déploiement.

## Accéder au Playground

1. Naviguez vers **Agents** dans la barre latérale
2. Cliquez sur **Test** sur la carte de votre agent (ou **Test Agent** lors de l'édition d'un agent)
3. Le Playground s'ouvre dans un panneau latéral — commencez une conversation

<Callout type="info">
  Le bouton Test est désactivé quand le statut de l'agent est **Archived** ou **Inactive**. Changez le statut en **Active** ou **Testing** pour activer les tests.
</Callout>

## Quoi tester

### Fonctionnalités de base

- L'agent peut-il répondre aux questions à partir de vos documents ?
- Les réponses sont-elles précises et pertinentes ?
- Le ton correspond-il à vos attentes ?

### Cas limites

Testez des scénarios qui pourraient mettre votre agent en difficulté :

- Questions non couvertes par vos documents
- Questions ambiguës ou peu claires
- Questions en plusieurs parties
- Questions de suivi nécessitant du contexte

### Flux de conversation

Testez les conversations à plusieurs tours :

- L'agent se souvient-il du contexte des messages précédents ?
- Peut-il gérer les changements de sujet avec aisance ?
- Demande-t-il des clarifications quand c'est nécessaire ?

## Évaluer les réponses

Pour chaque réponse, considérez :

| Aspect | Questions à se poser |
|--------|---------------------|
| **Précision** | L'information est-elle correcte ? |
| **Pertinence** | Répond-elle à la question posée ? |
| **Complétude** | Manque-t-il quelque chose d'important ? |
| **Ton** | Correspond-il à la voix de votre marque ? |
| **Longueur** | Est-elle suffisamment concise ou détaillée ? |

## Amélioration itérative

### Identifier les problèmes

Problèmes courants et solutions :

| Problème | Solution |
|----------|----------|
| Information incorrecte | Vérifier le contenu des documents, améliorer la récupération |
| Trop verbeux | Ajouter "be concise" à l'Agent Persona |
| Trop formel/décontracté | Ajuster le ton dans l'Agent Persona |
| Ne connaît pas la réponse | Ajouter des documents pertinents |
| Invente des faits | Renforcer les limites dans le prompt |

### Effectuer des modifications

1. Identifiez le problème lors des tests dans le Playground
2. Ajustez les paramètres pertinents (prompt, documents, configuration)
3. Retestez avec les mêmes questions
4. Vérifiez que la correction ne casse pas d'autres comportements

## Checklist de scénarios de test

Créez un ensemble de questions de test standard :

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  Sauvegardez vos scénarios de test et rejouez-les après chaque modification pour détecter les régressions.
</Callout>

## Prêt pour le déploiement

Votre agent est prêt quand :

- ✅ Répond aux questions courantes avec précision
- ✅ Gère les cas limites avec aisance
- ✅ Maintient un ton approprié
- ✅ Respecte les limites définies
- ✅ Les conversations à plusieurs tours fonctionnent bien

Ensuite, déployez votre agent sur les [canaux](/integrations) où les utilisateurs interagiront avec lui.
