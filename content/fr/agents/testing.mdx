# Tester dans le Playground

import { Callout } from 'nextra/components'

Le Playground est votre environnement pour tester et affiner les agents avant le déploiement.

## Accéder au Playground

1. Accédez à **Agents** dans la barre latérale
2. Cliquez sur **Test** sur la carte de votre agent (ou sur **Test Agent** lors de l'édition d'un agent)
3. Le Playground s'ouvre en panneau latéral — démarrez une conversation

<Callout type="info">
  Le bouton Test est désactivé lorsque le statut de l'agent est **Archived** ou **Inactive**. Changez le statut en **Active** ou **Testing** pour activer les tests.
</Callout>

## Que Tester

### Fonctionnalités de Base

- L'agent peut-il répondre aux questions à partir de vos documents ?
- Les réponses sont-elles exactes et pertinentes ?
- Le ton correspond-il à vos attentes ?

### Cas Limites

Testez les scénarios susceptibles de mettre votre agent en difficulté :

- Questions non couvertes par vos documents
- Questions ambiguës ou peu claires
- Questions à plusieurs parties
- Questions de suivi nécessitant du contexte

### Flux de Conversation

Testez des conversations multi-tours :

- L'agent se souvient-il du contexte des messages précédents ?
- Gère-t-il les changements de sujet avec aisance ?
- Demande-t-il des clarifications quand c'est nécessaire ?

## Évaluer les Réponses

Pour chaque réponse, considérez :

| Aspect | Questions à Se Poser |
|--------|-----------------|
| **Accuracy** | L'information est-elle correcte ? |
| **Relevance** | Répond-elle réellement à la question posée ? |
| **Completeness** | Manque-t-il quelque chose d'important ? |
| **Tone** | Correspond-il à la voix de votre marque ? |
| **Length** | Est-elle suffisamment concise ou détaillée ? |

## Amélioration Itérative

### Identifier les Problèmes

Problèmes courants et solutions :

| Problème | Solution |
|-------|----------|
| Information incorrecte | Vérifiez le contenu du document, améliorez la récupération |
| Trop verbeux | Ajoutez « be concise » à l'agent persona |
| Trop formel/décontracté | Ajustez le ton dans l'agent persona |
| Ne connaît pas la réponse | Ajoutez des documents pertinents |
| Invente des faits | Renforcez les limites dans le prompt |

### Apporter des Modifications

1. Identifiez le problème lors des tests dans le Playground
2. Ajustez les paramètres concernés (prompt, documents, configuration)
3. Testez à nouveau avec les mêmes questions
4. Vérifiez que la correction ne casse pas d'autres comportements

## Liste de Scénarios de Test

Créez un ensemble standard de questions de test :

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  Enregistrez vos scénarios de test et exécutez-les à nouveau après chaque modification pour détecter les régressions.
</Callout>

## Prêt pour le Déploiement

Votre agent est prêt lorsqu'il :

- ✓ Répond avec précision aux questions courantes
- ✓ Gère les cas limites avec aisance
- ✓ Maintient un ton approprié
- ✓ Respecte les limites définies
- ✓ Les conversations multi-tours fonctionnent bien

Ensuite, déployez votre agent sur les [canaux](/integrations) où les utilisateurs interagiront avec lui.
