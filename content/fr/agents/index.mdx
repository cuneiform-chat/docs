# Agents

Les agents sont les chatbots AI qui interagissent avec vos utilisateurs. Chaque agent dispose de sa propre configuration, de son accès aux connaissances et de sa personnalité.

## Qu'est-ce qu'un Agent ?

Un agent est un chatbot configuré qui :

- Répond aux questions à partir de votre contenu
- Suit les instructions définies dans son agent persona
- Conserve le contexte de la conversation au sein des sessions
- Peut être déployé sur plusieurs canaux

## Concepts d'Agent

### Agent Persona

L'agent persona est l'ensemble des instructions qui définit le comportement de votre agent. Il contrôle :

- **Personality** — Amical, professionnel, décontracté, etc.
- **Scope** — Les sujets que l'agent doit ou ne doit pas aborder
- **Response style** — Longueur, format et ton des réponses
- **Guardrails** — Limites et restrictions
- **Language** — Détection automatique par message (176 langues prises en charge)

### Accès aux Connaissances

Chaque agent accède à votre contenu pour trouver les informations pertinentes. Vous pouvez configurer :

- Les documents que l'agent peut consulter
- Le nombre de sources à récupérer
- L'affichage ou non des citations de sources

### Canaux

Les agents peuvent être déployés simultanément sur plusieurs canaux :

- Plateformes de messagerie (Telegram, Discord, Slack, WhatsApp, Google Chat)
- Facebook Messenger via l'intégration Meta
- Human Handoff — transférez de manière fluide les conversations à un membre humain de l'équipe
