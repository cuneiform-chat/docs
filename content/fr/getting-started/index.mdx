# Premiers pas

Démarrez avec Cuneiform Chat en quelques minutes. Ce guide vous accompagne dans la création de votre premier chatbot IA entraîné sur vos documents.

## Ce que vous apprendrez

- Comment créer et configurer votre compte
- Comment téléverser des documents dans votre contenu
- Comment créer et configurer votre premier agent
- Comment tester votre agent dans le Playground

## Prérequis

- Une adresse e-mail valide
- Des documents sur lesquels vous souhaitez entraîner votre chatbot (PDF, documents Word, fichiers texte, etc.)
