# Créer un compte

Démarrez avec Cuneiform Chat en créant votre compte.

## Inscription

1. Rendez-vous sur [cuneiform.chat](https://cuneiform.chat)
2. Cliquez sur **Get Started** ou **Sign Up**
3. Choisissez votre méthode de connexion :
   - **Google** — Cliquez sur "Sign in with Google" pour un accès en un clic
   - **Microsoft** — Cliquez sur "Sign in with Microsoft" pour utiliser votre compte Microsoft 365
   - **Email** — Entrez votre adresse e-mail et cliquez sur "Continue with Email"
4. Si vous utilisez l'e-mail, vérifiez votre boîte de réception et cliquez sur le lien magique pour vous connecter

## Options de connexion

Vous pouvez vous connecter avec :
- **Google** — Connexion en un clic avec votre compte Google
- **Microsoft** — Connexion avec votre compte Microsoft 365 ou professionnel
- **Lien magique par e-mail** — Connexion sans mot de passe via un lien envoyé à votre adresse e-mail

## Créer votre organisation

Après votre première connexion, vous devrez créer une organisation. C'est votre espace de travail pour gérer les agents, documents et intégrations.

1. Sur le tableau de bord, cliquez sur **Create Organization**
2. Entrez le **Organization Name** (nom de l'entreprise ou du projet)
3. Ajoutez éventuellement une **Description** de votre organisation
4. Sélectionnez votre **Industry** et **Team Size**
5. Cliquez sur **Create Organization**

Les organisations vous permettent de :

- Gérer plusieurs agents sous un seul compte
- Inviter des membres d'équipe et contrôler les accès
- Suivre l'utilisation et la facturation de tous vos chatbots

Vous pouvez modifier les détails de l'organisation à tout moment depuis **Account Management** dans le menu de votre profil.

## Période d'essai

Les nouveaux comptes bénéficient d'un essai gratuit qui comprend :
- Accès complet à toutes les fonctionnalités
- Des crédits pour tester le traitement de documents et les requêtes IA
- Aucune carte bancaire requise
