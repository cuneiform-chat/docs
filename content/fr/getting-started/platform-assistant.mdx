# Assistant de la plateforme

Découvrez Saba, votre assistant IA pour naviguer dans Cuneiform Chat.

## Qu'est-ce que Saba ?

Saba est un assistant IA intégré qui vous aide à tirer le meilleur parti de Cuneiform Chat. Nommé d'après Nisaba — la déesse sumérienne de l'écriture et des arts des scribes — Saba représente notre voyage des tablettes d'argile aux chatbots.

Saba peut vous aider à :

- Découvrir les fonctionnalités de la plateforme et comment les utiliser
- Accéder aux informations sur vos agents, documents et intégrations
- Comprendre vos détails de facturation et d'abonnement
- Résoudre les problèmes courants

## Accéder à Saba

### Bouton flottant

Cherchez l'icône Saba dans le **coin inférieur droit** de votre écran. Cliquez dessus pour ouvrir l'assistant.

### Raccourcis clavier

| Action | Mac | Windows/Linux |
|--------|-----|---------------|
| Ouvrir/Fermer Saba | `Cmd + K` | `Ctrl + K` |
| Nouvelle conversation | `Cmd + N` | `Ctrl + N` |
| Fermer | `Escape` | `Escape` |

### Depuis Telegram

Vous pouvez aussi discuter avec Saba depuis Telegram — mêmes permissions, même accès aux données, depuis votre téléphone. Deux surfaces, toutes deux incluses dans tous les forfaits payants :

- **Bot DM** — votre administrateur connecte un bot Telegram dédié (« Saba sur Telegram ») dans le panneau. Vous liez votre compte une fois avec un code de 10 minutes, puis vous envoyez un DM au bot comme à un collègue. Les notes vocales sont transcrites et transmises à Saba.
- **Saba Mini App** — chaque réponse du bot est accompagnée d'un bouton « Open in Mini App » qui vous emmène vers une expérience de chat plus riche dans Telegram (`saba-mini.cuneiform.chat`) avec historique des conversations, détail des appels d'outils, saisie vocale dans le navigateur, export Markdown et un sélecteur de langue intégré.

Les réponses de Saba sur Telegram incluent les mêmes boutons d'action que le panneau — un tap et vous êtes envoyé directement à la bonne page du panneau.

La configuration est côté administrateur. Consultez [Intégration Telegram → Saba sur Telegram](/integrations/telegram) pour le flux de connexion.

## Ce que Saba peut faire

### Fonctionnalités de la plateforme

Posez des questions comme :

- "Comment créer un agent ?"
- "Quels formats de fichiers sont pris en charge ?"
- "Comment connecter Slack ?"

### Vos données

Saba peut accéder aux données de votre organisation pour répondre à des questions spécifiques :

- "Combien d'agents ai-je ?"
- "Quels documents sont dans mon contenu ?"
- "Quelles intégrations sont actives ?"

### Informations de facturation

Obtenez des réponses rapides sur votre compte :

- "Quel est mon plan actuel ?"
- "Combien de crédits ai-je utilisés ?"
- "Quand se termine ma période de facturation ?"

## Fonctionnalités

### Mode de requête

Basculez entre les modes de réponse avec le bouton à côté du champ de saisie :

- **Fast** (icône éclair) — Réponses rapides pour les questions simples
- **Reasoning** (icône cerveau) — Analyse plus approfondie pour les questions complexes

Votre préférence est sauvegardée entre les sessions.

### Détection automatique de la langue

Saba détecte automatiquement la langue de votre message et répond dans la même langue — aucune configuration nécessaire. 176 langues sont prises en charge, vous pouvez donc simplement écrire dans votre langue préférée et Saba répondra en conséquence.

### Saisie vocale

Cliquez sur l'**icône microphone** à côté du bouton d'envoi pour poser votre question à la voix plutôt qu'au clavier.

### Commandes slash

Tapez `/` dans le champ de saisie pour voir les commandes rapides :

| Commande | Ce qu'elle fait |
|----------|----------------|
| `/health` | Aperçu de la santé de votre organisation |
| `/agents` | Liste tous vos agents avec leur statut |
| `/analytics` | Métriques de performance de vos agents |
| `/usage` | Affiche vos statistiques d'utilisation mensuelle |
| `/billing` | Détails de votre plan et crédits |
| `/integrations` | Vos intégrations de canaux actives |
| `/conversations` | Affiche l'activité récente des conversations |
| `/help` | Liste les commandes disponibles |

### Historique des conversations

Vos conversations avec Saba sont sauvegardées automatiquement. Accédez aux conversations passées depuis la barre latérale pour reprendre là où vous en étiez.

### Questions suggérées

Saba suggère des questions pertinentes en fonction de votre page actuelle. Elles apparaissent comme options de démarrage rapide lorsque vous ouvrez l'assistant.

### Suggestions de suivi

Après chaque réponse, Saba propose des questions connexes que vous pourriez vouloir poser ensuite.

### Exporter les conversations

Sauvegardez les conversations avec le bouton d'export :

- **Download as Markdown** — Sauvegarder en fichier .md avec le formatage
- **Download as Text** — Sauvegarder en fichier .txt brut
- **Copy to Clipboard** — Copier la conversation complète

### Feedback

Aidez à améliorer Saba avec les options de feedback sur chaque réponse :

- **Thumbs up/down** — Feedback rapide sur la qualité de la réponse
- **Submit Feedback** — Fournir des commentaires détaillés pour améliorer l'assistant
