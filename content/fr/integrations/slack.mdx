# Intégration Slack

Ajoutez votre agent à des workspaces Slack pour un accès à l'échelle de l'équipe.

## Aperçu

L'intégration Slack offre :
- Prise en charge des slash commands (`/ask`)
- Conversations par message direct
- Mentions dans les canaux
- Disponibilité dans tout le workspace

## Prérequis

- Permissions d'admin du workspace Slack ou d'installation d'apps
- Compte Cuneiform Chat avec un agent actif

## Étapes de Configuration

### 1. Lancer la Configuration de l'Intégration

1. Rendez-vous dans **Agents** → Sélectionnez votre agent
2. Allez dans l'onglet **Integrations**
3. Cliquez sur **Slack**
4. Cliquez sur **Add to Slack**

### 2. Autoriser l'App

1. Sélectionnez le workspace où installer
2. Examinez les permissions
3. Cliquez sur **Allow**

### 3. Vérifier l'Installation

1. Ouvrez Slack
2. Essayez le slash command : `/ask Hello`
3. Vérifiez que vous recevez une réponse

## Utiliser le Bot

### Slash Commands

Utilisez la commande `/ask` dans n'importe quel canal :

```
/ask Quelle est notre politique de remboursement ?
```

La réponse apparaît dans le canal (ou en message éphémère, selon les paramètres).

### Messages Directs

Envoyez un message au bot directement pour des conversations privées :

1. Trouvez l'app dans la barre latérale Slack
2. Ouvrez un message direct
3. Discutez naturellement

### Mentions dans les Canaux

Mentionnez le bot dans les canaux pour poser des questions :

```
@YourBot Quelles sont les options de livraison ?
```

## Fonctionnalités

### Accès dans Tout le Workspace

Une fois installé, le bot est disponible pour tous les membres du workspace.

### Réponses dans les Threads

Les réponses peuvent être publiées dans les threads pour garder les canaux organisés.

### Mise en Forme Enrichie

Les réponses prennent en charge la mise en forme Slack :
- Texte en gras et en italique
- Liens
- Blocs de code
- Listes

import { Callout } from 'nextra/components'

<Callout type="info">
  Le bot ne répond que lorsqu'il est explicitement invoqué (slash command ou mention) afin d'éviter le bruit.
</Callout>

## Options de Configuration

### Paramètres de Réponse

| Paramètre | Description |
|---------|-------------|
| Type de réponse | In-channel ou ephemeral |
| Comportement de thread | Répondre dans le thread ou dans le canal principal |

### Restrictions par Canal

Vous pouvez éventuellement restreindre le bot à des canaux spécifiques pour un usage ciblé.

## Prise en Charge Multi-Workspace

Vous pouvez installer le même agent dans plusieurs workspaces Slack :

1. Chaque workspace nécessite une autorisation distincte
2. Tous les workspaces partagent le même agent et le même contenu
3. Les conversations sont suivies séparément par workspace

## Dépannage

### Commande Introuvable

Si `/ask` ne fonctionne pas :
1. Vérifiez que l'app est installée dans votre workspace
2. Vérifiez que l'app dispose des permissions appropriées
3. Essayez de réinstaller l'intégration

### Pas de Réponse

Si le bot ne répond pas :
1. Vérifiez que votre agent est configuré et fonctionne (testez-le dans le Playground)
2. Vérifiez que l'intégration Slack est connectée
3. Assurez-vous que le bot a accès au canal

### Problèmes de Permissions

Permissions requises :
- `commands` — Pour les slash commands
- `chat:write` — Pour envoyer des messages
- `app_mentions:read` — Pour les @ mentions

## Sécurité

- Les OAuth tokens sont chiffrés
- Aucun accès aux messages en dehors des commandes/mentions explicites
- Les données du workspace restent privées

## Déconnecter

Pour supprimer l'intégration Slack :

1. **Depuis Cuneiform Chat :**
   - Agents → Sélectionnez l'agent → Integrations → Slack → Disconnect

2. **Depuis Slack :**
   - Rendez-vous dans les paramètres du workspace
   - Apps → Trouvez l'app → Remove

Les deux étapes garantissent une suppression complète.
