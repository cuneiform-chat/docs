# Intégration Telegram

Connectez votre agent à Telegram et permettez aux utilisateurs de discuter avec lui directement dans l'app Telegram.

## Aperçu

L'intégration Telegram offre :
- Réponses en streaming en direct (Bot API 9.5 `sendMessageDraft` avec fallback d'édition de message)
- Messages vocaux transcrits automatiquement avec Whisper
- Mise en forme MarkdownV2 qui s'affiche proprement à chaque fois
- Campagnes avec deep links comportant un welcome et des réponses suggérées personnalisées
- Réactions par emoji en un clic avec classification de sentiment
- Slash commands intégrés (`/start`, `/help`, `/reset`, `/new`)
- Messages directs et chats de groupe (sessions par utilisateur dans les groupes)
- [Pièces jointes](/integrations/document-attachments) — envoyez un fichier et posez des questions à son sujet (désactivé par défaut, plans payants)
- Une [Boutique intégrée](/integrations/telegram-mini-app) — catalogue produits multipage, chat IA par produit et prise de commande légère, le tout dans Telegram (gratuit sur tous les plans)
- Co-pilot Telegram Premium optionnel pour les utilisateurs Premium (intégration distincte)
- Saba sur Telegram pour les opérateurs (intégration distincte)

## Prérequis

- Un compte Telegram
- Accès à BotFather (l'outil de création de bots de Telegram)

## Étapes de Configuration

### 1. Créer un Bot Telegram

1. Ouvrez Telegram et recherchez **@BotFather**
2. Démarrez une discussion et envoyez `/newbot`
3. Suivez les invites :
   - Saisissez un nom pour votre bot (par exemple, « My Support Bot »)
   - Saisissez un nom d'utilisateur (doit se terminer par « bot », par exemple « mysupportbot »)
4. BotFather vous fournira un **Bot Token** — conservez-le en lieu sûr

### 2. Connecter à Cuneiform Chat

1. Rendez-vous dans **Agents** → Sélectionnez votre agent
2. Allez dans l'onglet **Integrations**
3. Cliquez sur **Telegram**
4. Collez votre Bot Token
5. Cliquez sur **Connect**

### 3. Configurer votre Bot

Paramètres facultatifs du bot via BotFather :

- `/setdescription` — Ce que fait le bot
- `/setabouttext` — Informations dans le profil du bot
- `/setuserpic` — Photo de profil de votre bot

### 4. Tester votre Bot

1. Trouvez votre bot dans Telegram en recherchant son nom d'utilisateur
2. Démarrez une conversation avec `/start`
3. Envoyez un message et vérifiez que vous recevez une réponse

## Comment Cela Fonctionne

```
L'utilisateur envoie un message → Telegram → Cuneiform Chat → L'agent traite → Réponse renvoyée
```

Les messages sont traités en temps réel. L'agent recherche dans votre contenu et génère des réponses selon votre configuration.

## Fonctionnalités

### Réponses en streaming en direct

La réponse du bot apparaît en quelques millisecondes et grandit sur place pendant que votre agent réfléchit — en utilisant le `sendMessageDraft` natif de Telegram (Bot API 9.5) là où il est pris en charge, avec un fallback d'édition de message throttlée ailleurs. Fini les 5 à 15 secondes de silence entre la question et la réponse.

### Messages vocaux

Les notes vocales envoyées au bot sont transcrites via Whisper et traitées comme si elles avaient été tapées. La langue est détectée automatiquement à partir de la conversation, de sorte que les courts clips dans n'importe quelle langue restent précis. Plafond de 2 minutes par note. Disponible sur tous les plans, y compris le trial gratuit.

### Pièces jointes

Quelqu'un peut envoyer un fichier au bot et poser des questions à son sujet. **Envoyez une image en tant que *fichier*, pas en tant que photo** — une photo envoyée normalement n'est pas lue, car Telegram la transmet sous forme d'aperçus redimensionnés, sans nom de fichier. Un document par message.

Sur Telegram, c'est **désactivé par défaut** : un administrateur active **Autoriser les pièces jointes** sur la carte d'intégration, et les images ou les scans nécessitent en plus l'**Analyse premium des documents complexes**. Voir [Pièces Jointes de Documents](/integrations/document-attachments) pour les types pris en charge, les limites et la configuration.

### Mise en forme MarkdownV2

Le gras, l'italique, les blocs de code, les listes et les liens s'affichent exactement comme votre agent l'a prévu — pas de markdown cassé ni d'astérisques égarés. L'échappement est centralisé dans la plateforme pour que chaque réponse reste propre. MarkdownV2 est la valeur par défaut ; le mode HTML est disponible par intégration si besoin.

### Deep links et campagnes de parrainage

Générez des liens `t.me/your-bot?start=your-code` depuis la carte d'intégration. Chaque code peut comporter un message de bienvenue personnalisé et jusqu'à trois réponses suggérées. Le click-through, les utilisateurs uniques et la conversion de conversation sont suivis par code — utiles pour les campagnes publicitaires, les codes QR et l'attribution multicanal.

### Réactions par emoji en un clic

Les utilisateurs réagissent aux messages du bot avec 👍, ❤, 😡 ou n'importe quel emoji. Le bot répond avec le ton approprié via de courtes réponses d'accusé de réaction. Un classifier intégré associe n'importe quel emoji à un signal positif, négatif ou neutre que vous pouvez analyser plus tard. Actuellement actif en DMs.

### Slash commands

L'intégration enregistre une liste de commandes par défaut auprès de Telegram lors de la connexion, de sorte que les utilisateurs voient `/start`, `/help`, `/reset` et toutes les commandes personnalisées que vous créez dans le menu d'autocomplétion natif de Telegram. `/start`, `/help`, `/reset` et `/new` sont gérés inline sans coût AI. Glissez pour réorganiser ; jusqu'à 32 entrées.

### Messages directs

Les utilisateurs discutent avec votre bot en tête-à-tête pour des conversations de support privées. Chaque utilisateur a sa propre session.

### Chats de groupe

Ajoutez votre bot à des chats de groupe :

1. Ajoutez le bot à un groupe
2. Donnez-lui le rôle d'admin (pour un accès complet aux messages — voir Group Privacy ci-dessous)
3. Les utilisateurs mentionnent le bot (`@your_bot`) ou répondent à ses messages

import { Callout } from 'nextra/components'

<Callout type="info">
  Par défaut, les bots Telegram ont le mode **Group Privacy** activé — le bot ne voit que les messages qui le mentionnent directement ou qui répondent à ses propres messages. Désactivez-le dans BotFather (My bots → votre bot → Bot Settings → Group Privacy → Off) si vous voulez que le bot voie tous les messages.

Chaque utilisateur dans un groupe a son propre thread de conversation — le bot ne mélange pas les sessions entre les membres. Les groupes forum-topic sont pris en charge ; les threads restent cantonnés à leur sujet.

## Boutique Telegram

Chaque bot Telegram que vous connectez est livré avec une **Boutique** intégrée — un site web in-bot soigné et multipage qui s'ouvre dans Telegram lorsque les utilisateurs finaux touchent le bouton de menu à côté du compositeur de message. Fiches produits, galeries, vidéos, pages thématisées, chat IA par produit et prise de commande légère qui passe le relais à un humain dans votre inbox — le tout sans installer d'app ni passer par un site web séparé.

Câblage automatique à la connexion : le bouton du menu de chat ouvre la boutique, libellé **« Shop »** si vous publiez un produit ou **« Open »** sinon. Disponible sur tous les plans, y compris le trial gratuit.

Le guide complet de la fonctionnalité — composeur, blocs, thèmes, chat par produit, CTAs de commande, limites par tier — vit sur une page dédiée :

→ **[Boutique Telegram](/integrations/telegram-mini-app)** pour la configuration complète, la référence des blocs et le parcours client.

Un petit panneau de support **Help Center** est épinglé à la fin du menu de pages de la boutique pour des raccourcis FAQ + ask-the-bot ponctuels. La plupart des boutiques ne s'appuient pas beaucoup dessus — les produits et les CTAs de commande répondent aux questions du parcours d'achat directement sur la boutique. Rédigez les entrées depuis le menu à trois points de la carte du bot → **Help Center** (jusqu'à ~50 entrées, glisser pour réorganiser, cache serveur ~5 minutes).

## Co-pilot Telegram Premium

Les utilisateurs Telegram de niveau Premium peuvent demander à votre bot de répondre aux DMs **sur leur compte personnel** via le mode Business de Telegram. Le bot répond via le `business_connection_id` de l'utilisateur Premium, de sorte que les contacts voient ce qui ressemble à des réponses de l'utilisateur Premium lui-même — utile pour les founders, les créateurs et les petites équipes qui reçoivent des DMs sur leurs comptes personnels toute la journée.

La configuration est une intégration distincte dans le panneau d'administration (« Telegram Premium co-pilot »). Invariants clés :

- **1 bot = 1 customer agent.** Un bot Telegram ne peut pointer que vers un seul webhook à la fois — vous ne pouvez pas partager un bot avec l'intégration Telegram régulière ni avec Saba sur Telegram. Créez un nouveau bot BotFather pour le mode Business.
- **La bascule Business Mode de BotFather est obligatoire.** Sans elle, les utilisateurs Premium voient *« this bot doesn't support Telegram Business yet »* en l'ajoutant. Activez-la sous Bot Settings → Business Mode.
- **N utilisateurs Premium par intégration.** Chacun se lie une fois via `/start <code>` dans un DM régulier avec le bot.
- **DMs uniquement.** Les connexions Business ne couvrent pas les chats de groupe.
- **Le takeover manuel est automatique.** Lorsque l'utilisateur Premium tape lui-même une réponse, le bot se met en pause sur ce chat pendant une fenêtre glissante pour ne pas couper la parole à une conversation en direct.
- **Kill switch au niveau de la connexion.** Activez « Disable auto-reply » sur la carte d'intégration pour mettre le bot en pause sur tous les utilisateurs Premium liés sans déconnecter.

Voir **Connect Premium bot** sous la section Telegram Premium co-pilot de la page Integrations du panneau d'administration pour le playbook complet de configuration.

## Saba sur Telegram

Les opérateurs peuvent également discuter avec **Saba** (l'assistant de la plateforme) depuis un bot Telegram dédié. Mêmes permissions et accès aux données que le panneau d'administration — utile lorsque vous êtes loin de votre laptop et que vous devez consulter les statistiques d'agents, le billing ou l'activité récente.

Deux surfaces sur le même canal :

- **DM bot** — réponses textuelles dans un DM Telegram régulier, avec des boutons d'action inline qui font un deep-link vers la bonne page du panneau d'administration (`?from=saba_telegram` pour l'attribution).
- **Saba Mini App** — une surface de chat plus riche dans Telegram à `saba-mini.cuneiform.chat` avec historique de conversation, détail des tool-call, saisie vocale par navigateur et export markdown. Chaque réponse en DM embarque un bouton inline « Open in Mini App » pour basculer de surface au milieu d'une conversation.

La configuration est côté admin : connectez un nouveau bot BotFather sous « Saba on Telegram » dans Integrations. Chaque membre de l'organisation lie ensuite son compte personnel avec un code de 10 minutes.

Voir [Platform Assistant → From Telegram](/getting-started/platform-assistant#from-telegram) pour l'expérience côté utilisateur.

Vous pouvez configurer des commandes personnalisées via BotFather :

|---------|-------------|
| `/start` | Démarre la conversation |
| `/help` | Affiche le message d'aide |

## Dépannage

### Le Bot ne Répond Pas

1. Vérifiez que le bot token est correct
2. Vérifiez que l'intégration est connectée dans Cuneiform Chat
3. Assurez-vous que votre agent est correctement configuré
4. Testez d'abord l'agent dans le Playground

### Problèmes de Token

Si vous avez besoin d'un nouveau token :
1. Rendez-vous chez BotFather
2. Envoyez `/mybots` → Sélectionnez votre bot → **API Token** → **Revoke**
3. Mettez à jour le nouveau token dans Cuneiform Chat

### Problèmes en Chats de Groupe

- Assurez-vous que le bot dispose des permissions d'admin
- Vérifiez les paramètres du mode de confidentialité via BotFather (`/setprivacy`)

## Sécurité

- Les bot tokens sont chiffrés et stockés de manière sécurisée
- Les conversations sont traitées via des connexions sécurisées

## Déconnecter

Pour supprimer l'intégration Telegram :

1. Rendez-vous dans **Agents** → Sélectionnez l'agent → **Integrations**
2. Cliquez sur **Telegram** → **Disconnect**

Cela arrête les réponses du bot mais ne supprime pas le bot Telegram lui-même. Supprimez-le via BotFather si nécessaire.
