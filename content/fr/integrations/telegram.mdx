# Telegram

Connectez votre agent à Telegram et laissez les utilisateurs discuter avec lui directement dans l'application Telegram.

## Aperçu

L'intégration Telegram fournit :
- Messagerie directe avec votre bot
- Support des discussions de groupe
- Formatage enrichi des messages
- Claviers inline pour les interactions

## Prérequis

- Un compte Telegram
- Accès à BotFather (l'outil de création de bots de Telegram)

## Étapes de configuration

### 1. Créer un bot Telegram

1. Ouvrez Telegram et recherchez **@BotFather**
2. Démarrez une conversation et envoyez `/newbot`
3. Suivez les instructions :
   - Entrez un nom pour votre bot (ex. : "Mon Bot Support")
   - Entrez un nom d'utilisateur (doit se terminer par "bot", ex. : "monsupportbot")
4. BotFather vous donnera un **Bot Token** — conservez-le en lieu sûr

### 2. Connecter à Cuneiform Chat

1. Allez dans **Agents** → Sélectionnez votre agent
2. Naviguez vers l'onglet **Integrations**
3. Cliquez sur **Telegram**
4. Collez votre Bot Token
5. Cliquez sur **Connect**

### 3. Configurer votre bot

Paramètres optionnels du bot via BotFather :

- `/setdescription` — Ce que fait le bot
- `/setabouttext` — Informations dans le profil du bot
- `/setuserpic` — Photo de profil pour votre bot

### 4. Tester votre bot

1. Trouvez votre bot dans Telegram en recherchant son nom d'utilisateur
2. Démarrez une conversation avec `/start`
3. Envoyez un message et vérifiez que vous recevez une réponse

## Comment ça fonctionne

```
L'utilisateur envoie un message → Telegram → Cuneiform Chat → L'agent traite → Réponse renvoyée
```

Les messages sont traités en temps réel. L'agent recherche dans votre contenu et génère des réponses selon votre configuration.

## Fonctionnalités

### Messages directs

Les utilisateurs peuvent discuter avec votre bot en privé pour des conversations de support.

### Discussions de groupe

Ajoutez votre bot aux discussions de groupe :

1. Ajoutez le bot à un groupe
2. Faites-le administrateur (pour l'accès aux messages)
3. Les utilisateurs peuvent mentionner le bot ou utiliser des commandes

Les réponses de votre agent supportent :
- Texte **gras** et *italique*
- Liens
- Blocs de code
- Listes

## Help Center Mini App

Chaque bot Telegram que vous connectez est livré avec un **Help Center** intégré — un Mini App qui s'ouvre dans Telegram lorsque les utilisateurs finaux appuient sur le bouton de menu à côté du compositeur de messages.

### Ce que voient les utilisateurs finaux

Une liste triable d'entrées FAQ que vous avez créées depuis le admin panel. Deux modes par entrée :

- **Curated** — appuyez pour lire la réponse inline. Markdown rendu, sans trafic de chat, sans coût de LLM.
- **Ask the bot** — appuyez pour envoyer dans le chat une question prédéfinie à votre agent.

### Configuration automatique, sans setup

Lorsque vous connectez un bot Telegram, le chat-menu button est automatiquement configuré pour ouvrir le Help Center. Disponible sur tous les plans, y compris le trial gratuit. Ce chemin ne nécessite pas de configuration dans BotFather.

### Créer des entrées

1. Allez dans **Integrations** → votre carte de bot Telegram
2. Ouvrez le menu à trois points → **Help Center**
3. Ajoutez jusqu'à ~50 entrées ; glissez pour réordonner ; choisissez le mode (curated ou ask-the-bot)

Les changements se propagent au Mini App en ~5 minutes (cache serveur).

### Optionnel : lien de lancement direct

Si vous voulez aussi un lien `t.me/<your_bot>/<your_app>` pour le marketing ou des QR codes, ouvrez **Mini App settings** sur la même carte et suivez le playbook BotFather (5 étapes). Le chat-menu button continue de fonctionner sans cela — le playbook ne fait qu'ajouter la forme de lien orientée marketing.

### Support des langues

L'interface du Mini App suit la langue Telegram de chaque utilisateur final — actuellement anglais, espagnol, portugais et français, avec l'anglais en fallback. Le *contenu* du Help Center que vous rédigez est monolingue par entrée aujourd'hui ; les variantes de contenu par langue sont sur la feuille de route.

## Commandes du bot

Vous pouvez configurer des commandes personnalisées via BotFather :

| Commande | Description |
|----------|-------------|
| `/start` | Démarrer la conversation |
| `/help` | Afficher le message d'aide |
| `/ask [question]` | Poser une question spécifique |

## Dépannage

### Le bot ne répond pas

1. Vérifiez que le bot token est correct
2. Vérifiez que l'intégration est connectée dans Cuneiform Chat
3. Assurez-vous que votre agent est correctement configuré
4. Testez d'abord l'agent dans le Playground

### Problèmes de token

Si vous avez besoin d'un nouveau token :
1. Allez sur BotFather
2. Envoyez `/mybots` → Sélectionnez votre bot → **API Token** → **Revoke**
3. Mettez à jour le nouveau token dans Cuneiform Chat

### Problèmes de discussion de groupe

- Assurez-vous que le bot a les permissions d'administrateur
- Vérifiez les paramètres du mode de confidentialité via BotFather (`/setprivacy`)

## Sécurité

- Les tokens de bot sont chiffrés et stockés en toute sécurité
- Les conversations sont traitées via des connexions sécurisées

## Déconnexion

Pour supprimer l'intégration Telegram :

1. Allez dans **Agents** → Sélectionnez l'agent → **Integrations**
2. Cliquez sur **Telegram** → **Disconnect**

Cela empêche le bot de répondre mais ne supprime pas le bot Telegram lui-même. Supprimez via BotFather si nécessaire.
