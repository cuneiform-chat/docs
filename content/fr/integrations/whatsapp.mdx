# Intégration WhatsApp

Connectez votre agent à WhatsApp Business pour la communication client.

## Aperçu

L'intégration WhatsApp offre :
- Capacités de messagerie professionnelle
- Prise en charge de médias enrichis
- Réponses automatisées
- Portée mondiale
- Conformité avec la fenêtre de messagerie de 24 heures

## Prérequis

- Un AI agent actif (créé dans la section Agents)
- Un WhatsApp Business Account (WABA)
- Un numéro de téléphone vérifié dans WhatsApp Business
- Accès au Meta Developer Portal

## Étapes de Configuration

### 1. Connecter avec Embedded Signup (Recommandé)

La façon la plus simple de connecter WhatsApp est via le flux embedded signup de Meta :

1. Rendez-vous dans **Agents** → Sélectionnez votre agent
2. Allez dans l'onglet **Integrations**
3. Cliquez sur **WhatsApp**
4. Cliquez sur **Connect with Facebook** pour ouvrir la popup de signup Meta
5. Connectez-vous avec votre compte Facebook/Meta
6. Sélectionnez ou créez un WhatsApp Business Account
7. Choisissez le numéro de téléphone à connecter
8. La popup se ferme et votre connexion est établie

import { Callout } from 'nextra/components'

<Callout type="important">
  Le flux embedded signup gère la majeure partie de la configuration automatiquement. C'est la méthode recommandée pour la plupart des utilisateurs.
</Callout>

### 2. Vérification du Téléphone (Si Nécessaire)

Après avoir terminé le signup Meta, vous devrez peut-être vérifier votre numéro de téléphone :

1. Choisissez comment recevoir votre code de vérification : **SMS** ou **Voice Call**
2. Cliquez sur **Send Code**
3. Saisissez le code à 6 chiffres reçu
4. Cliquez sur **Verify**

Si vous n'avez pas reçu le code, cliquez sur « Didn't receive the code? Send again » pour réessayer.

### 3. Vérification en Deux Étapes (Si Activée)

Si votre compte WhatsApp Business a la vérification en deux étapes activée :

1. Saisissez votre PIN à 6 chiffres lorsqu'il est demandé
2. Cliquez sur **Complete Registration**

<Callout type="info">
  Ce PIN a été configuré dans WhatsApp Business Manager → Security Center. Il est différent du code de vérification SMS.
</Callout>

### 4. Configurer le Webhook (Si Nécessaire)

Après la configuration, vous devrez peut-être configurer votre webhook dans Meta Business Suite :

1. Copiez la webhook URL fournie après la connexion
2. Dans Meta Developer Portal, rendez-vous dans **WhatsApp** → **Configuration**
3. Ajoutez la webhook URL
4. Abonnez-vous au champ webhook `messages`

## Utiliser le Bot

### Messages Clients

Lorsque les clients envoient un message à votre numéro WhatsApp :

1. Le message arrive via WhatsApp
2. Cuneiform Chat traite la requête
3. L'agent génère une réponse à partir du contenu
4. La réponse est renvoyée au client

### Flux de Conversation

```
Client → WhatsApp → Cuneiform Chat → Agent → Réponse → Client
```

## Fonctionnalités

### Fenêtre de Messagerie de 24 Heures

Règles de la WhatsApp Business API :
- Vous pouvez répondre aux messages initiés par le client pendant 24 heures
- Après 24 heures, la fenêtre se ferme jusqu'à ce que le client réécrive
- Chaque nouveau message du client rouvre la fenêtre

<Callout type="info">
  Votre agent répond automatiquement dans la fenêtre de 24 heures. Les messages template pour la relance ne sont pas pris en charge actuellement.
</Callout>

### Médias Enrichis

Les réponses peuvent inclure :
- Messages texte
- Liens
- Texte mis en forme

### Multi-Langue

Votre agent détecte automatiquement la langue du client et répond dans la même — 176 langues prises en charge, sans configuration nécessaire.

## Dépannage

### Échec de la Connexion

1. Assurez-vous d'avoir un WhatsApp Business Account valide
2. Vérifiez que votre numéro de téléphone est vérifié
3. Réessayez le flux embedded signup

### La Vérification du Téléphone ne Fonctionne Pas

1. Assurez-vous d'avoir accès au numéro de téléphone pour SMS/Voix
2. Patientez quelques minutes avant de demander un nouveau code
3. Vérifiez que le numéro de téléphone n'est pas déjà connecté ailleurs

### Erreur de Vérification en Deux Étapes

1. Saisissez le PIN configuré dans WhatsApp Business Manager → Security Center
2. Il est différent du code de vérification SMS
3. Contactez votre admin WhatsApp Business si vous ne connaissez pas le PIN

### Les Messages n'Arrivent Pas

1. Vérifiez que le webhook est correctement configuré dans Meta Business Suite
2. Vérifiez que l'abonnement webhook inclut `messages`
3. Confirmez que le statut de l'intégration est « Active »

### Échecs de Réponse

1. Vérifiez que votre agent fonctionne dans le Playground
2. Vérifiez que la fenêtre de 24 heures est active (le client a écrit récemment)
3. Vérifiez le statut de l'intégration dans le panneau d'administration

## Sécurité

- Les access tokens sont chiffrés et stockés de manière sécurisée
- Les messages sont traités via des connexions sécurisées

## Conformité

WhatsApp Business a des politiques d'utilisation :
- Ne répondez qu'aux conversations initiées par le client
- Fournissez des options de désinscription
- Respectez les politiques Commerce et Business de Meta

## Déconnecter

Pour supprimer l'intégration WhatsApp :

1. Rendez-vous dans **Agents** → Sélectionnez l'agent → **Integrations**
2. Cliquez sur le menu à trois points sur votre intégration WhatsApp
3. Sélectionnez **Disconnect**

Cela arrête les réponses de l'agent. Pour supprimer entièrement :
- Supprimez le webhook dans Meta Developer Portal
- Retirez éventuellement le produit WhatsApp de votre app Meta

## Questions Fréquentes

**Q : Comment connecter WhatsApp ?**
R : Utilisez l'embedded signup en cliquant sur « WhatsApp » dans l'onglet Integrations, puis sur « Connect with Facebook ». Cela vous guide automatiquement à travers le processus de signup Meta.

**Q : Pourquoi me demande-t-on un code de vérification ?**
R : WhatsApp exige une vérification du téléphone pour les nouvelles connexions. Choisissez SMS ou Voice Call pour recevoir un code à 6 chiffres, puis saisissez-le pour terminer la configuration.

**Q : Qu'est-ce que le PIN de vérification en deux étapes ?**
R : Si vous avez activé la vérification en deux étapes dans WhatsApp Business Manager, vous devrez saisir ce PIN à 6 chiffres lors de la configuration. Il est différent du code de vérification SMS.

**Q : Puis-je connecter plusieurs numéros WhatsApp ?**
R : Oui, vous pouvez connecter plusieurs numéros WhatsApp Business. Chaque numéro peut être connecté à un AI agent différent (ou au même).
