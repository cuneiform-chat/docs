# Intégrations

Déployez vos agents sur plusieurs canaux et atteignez les utilisateurs là où ils se trouvent.

## Canaux Disponibles

| Canal | Description | Idéal Pour |
|---------|-------------|----------|
| [Telegram](/integrations/telegram) | Bot Telegram | Utilisateurs mobiles, communautés |
| [Discord](/integrations/discord) | Bot Discord avec slash commands | Gaming, communautés de développeurs |
| [Slack](/integrations/slack) | App Slack | Espaces de travail d'équipe |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | Communication client |
| [Google Chat](/integrations/google-chat) | App Google Workspace | Équipes en entreprise |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | Audience grand public |
| [Website Widget](/integrations/website-widget) | Widget de chat intégrable | Support client, tout site web |

## Comment Fonctionnent les Intégrations

1. **Configurer** — Paramétrez l'intégration pour le canal choisi
2. **Connecter** — Reliez votre agent au canal
3. **Déployer** — Votre agent devient disponible pour les utilisateurs
4. **Surveiller** — Suivez les conversations et l'utilisation

## Déploiement Multicanal

Un même agent peut être déployé simultanément sur plusieurs canaux :

- Même contenu sur tous les canaux
- Réponses cohérentes partout
- Historique de conversation centralisé
- Analytique unifiée

## Fonctionnalités Spécifiques par Canal

Chaque canal possède des capacités uniques :

- **Telegram** — Messages enrichis, claviers inline
- **Discord** — Slash commands, intégration aux serveurs
- **Slack** — Apps de workspace, réponses dans les canaux
- **WhatsApp** — Messagerie professionnelle, médias enrichis
- **Google Chat** — Intégration à Google Workspace, prise en charge des Spaces, questions-réponses sur documents + base de connaissances du Space
- **Meta (Facebook)** — Intégration Messenger, messagerie de Page
- **Website Widget** — Chat intégrable, apparence personnalisable, liste blanche de domaines

## Prérequis

Avant de configurer les intégrations :

1. ✅ Créez au moins un agent
2. ✅ Téléversez des documents dans votre contenu
3. ✅ Testez votre agent dans le Playground

Chaque canal peut avoir des prérequis supplémentaires (bot tokens, identifiants d'app, etc.) détaillés dans leurs guides respectifs.
