# Intégrations

Déployez vos agents sur plusieurs canaux et atteignez les utilisateurs où qu'ils soient.

## Canaux disponibles

| Canal | Description | Idéal pour |
|-------|-------------|------------|
| [Telegram](/integrations/telegram) | Bot Telegram | Utilisateurs mobiles, communautés |
| [Discord](/integrations/discord) | Bot Discord avec commandes slash | Gaming, communautés de développeurs |
| [Slack](/integrations/slack) | Application Slack | Espaces de travail d'équipe |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | Communication client |
| [Google Chat](/integrations/google-chat) | Application Google Workspace | Équipes entreprise |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | Audience grand public |
| [Widget de site web](/integrations/website-widget) | Widget de chat intégrable | Support client, tout site web |

## Comment fonctionnent les intégrations

1. **Configurer** — Paramétrez l'intégration pour le canal choisi
2. **Connecter** — Liez votre agent au canal
3. **Déployer** — Votre agent devient disponible pour les utilisateurs
4. **Surveiller** — Suivez les conversations et l'utilisation

## Déploiement multicanal

Un seul agent peut être déployé sur plusieurs canaux simultanément :

- Même contenu sur tous les canaux
- Réponses cohérentes partout
- Historique des conversations centralisé
- Analytique unifiée

## Fonctionnalités spécifiques aux canaux

Chaque canal a des capacités uniques :

- **Telegram** — Messages enrichis, claviers inline
- **Discord** — Commandes slash, intégration serveur
- **Slack** — Applications d'espace de travail, réponses dans les canaux
- **WhatsApp** — Messagerie professionnelle, médias enrichis
- **Google Chat** — Intégration Google Workspace, support des Spaces
- **Meta (Facebook)** — Intégration Messenger, messagerie via la Page
- **Widget de site web** — Chat intégrable, apparence personnalisable, liste de domaines autorisés

Avant de configurer les intégrations :

2. ✅ Téléverser des documents dans votre contenu
3. ✅ Tester votre agent dans le Playground
