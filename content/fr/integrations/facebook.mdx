# Intégration Meta (Facebook)

Connectez votre agent à Facebook Messenger via votre Page Facebook.

## Aperçu

L'intégration Meta offre :
- Conversations Facebook Messenger via votre Page
- Une [Boutique Messenger](/integrations/messenger-mini-app) intégrée, lançable depuis le Persistent Menu de la Page
- Traitement en arrière-plan avec indicateurs de saisie
- Découpage automatique des messages pour les longues réponses
- Conformité avec la fenêtre de messagerie de 24 heures
- Mémoire de conversation au sein des sessions

## Prérequis

- Une Page Facebook que vous administrez
- Rôle Admin ou Editor sur la Page
- Compte Cuneiform Chat avec un agent actif

## Étapes de Configuration

### 1. Lancer la Configuration de l'Intégration

1. Rendez-vous dans **Agents** → Sélectionnez votre agent
2. Allez dans l'onglet **Integrations**
3. Cliquez sur **Meta (Facebook)**
4. Cliquez sur **Connect Page**

### 2. Autoriser avec Facebook

1. Sélectionnez quel **Agent** doit répondre
2. Cliquez sur **Connect with Facebook**
3. Connectez-vous à Facebook (si nécessaire)
4. Sélectionnez la Page que vous souhaitez connecter
5. Accordez les permissions Messenger
6. Vous serez redirigé avec un message de succès

### 3. Vérifier la Connexion

Une fois connectée, votre Page apparaîtra dans la liste des intégrations en affichant :
- Nom et statut de la Page
- Page ID
- Horodatage de la dernière activité

## Comment Cela Fonctionne

Lorsque les utilisateurs envoient un message à votre Page Facebook via Messenger :

1. Le message arrive via Facebook Messenger
2. Le bot affiche un indicateur de saisie pendant le traitement
3. Votre agent traite la question
4. La réponse est renvoyée via Messenger

<Callout type="info">
  Les messages sont traités en arrière-plan. Le bot affiche un indicateur de saisie pendant que votre agent génère une réponse.
</Callout>

## Fonctionnalités

### Réponses Automatiques

Votre agent répond automatiquement aux conversations Messenger entrantes en s'appuyant sur votre contenu. Tous les messages texte déclenchent une réponse — aucune commande ni préfixe nécessaire.

### Indicateurs de Saisie

Pendant que votre agent traite un message, les utilisateurs voient un indicateur de saisie (« ... ») dans Messenger, ce qui donne une impression naturelle de conversation.

### Découpage des Messages

Les réponses de plus de 2 000 caractères sont automatiquement découpées en plusieurs messages, en préservant les sauts de paragraphe et les frontières de phrases pour la lisibilité.

### Mémoire de Conversation

Le bot mémorise le contexte au sein d'une session, de sorte que les utilisateurs peuvent poser des questions de suivi sans avoir à se répéter.

### File d'Attente des Messages

Si un utilisateur envoie d'autres messages alors que le bot est encore en train de traiter, ils sont mis en file d'attente et inclus dans la réponse suivante.

### Fenêtre de Messagerie de 24 Heures

La politique de Facebook autorise des réponses dans les 24 heures suivant le dernier message de l'utilisateur. Votre agent répond en temps réel, bien dans cette fenêtre. Après 24 heures d'inactivité, l'utilisateur doit envoyer un nouveau message pour relancer la conversation.

<Callout type="warning">
  Les utilisateurs doivent écrire en premier à votre Page — vous ne pouvez pas envoyer de messages non sollicités. Si plus de 24 heures se sont écoulées depuis leur dernier message, le bot ne pourra pas répondre tant que l'utilisateur n'aura pas réécrit.
</Callout>

## Gérer les Pages

### Voir les Pages Connectées

Chaque Page connectée affiche :
- Nom de la Page et statut de la connexion
- Agent associé
- Informations d'activité

### Actions Disponibles

| Action | Description |
|--------|-------------|
| **Test Connection** | Vérifie que l'intégration fonctionne |
| **Disconnect** | Supprime la connexion à la Page |

Accédez-y via le menu à trois points sur chaque Page connectée.

## Dépannage

### La Page n'Apparaît Pas

1. Vérifiez que vous avez le rôle Admin ou Editor sur la Page
2. Vérifiez que vous avez accordé toutes les permissions demandées
3. Essayez de déconnecter puis reconnecter

### Les Messages ne Reçoivent Pas de Réponse

1. Utilisez « Test Connection » pour vérifier l'intégration
2. Vérifiez que votre agent est configuré et fonctionne (testez-le dans le Playground)
3. Assurez-vous que les permissions Messenger sont accordées
4. Vérifiez que l'utilisateur a écrit dans les 24 dernières heures (politique de fenêtre de messagerie)

### Erreurs d'Autorisation

1. Effacez la session de connexion Facebook et réessayez
2. Vérifiez que votre compte Facebook a accès à la Page
3. Vérifiez que la Page n'est pas restreinte par Facebook

## Sécurité

- Les **OAuth tokens** sont chiffrés et stockés de manière sécurisée
- Les **signatures de webhook** sont vérifiées avec HMAC-SHA256 sur chaque requête entrante
- Aucun accès au contenu de la Page au-delà des conversations Messenger
- Conforme aux politiques de la Plateforme Facebook

## Déconnecter

Pour supprimer l'intégration Meta :

1. Rendez-vous dans **Agents** → Sélectionnez l'agent → **Integrations**
2. Cliquez sur le menu à trois points sur votre Page
3. Sélectionnez **Disconnect**

Pour révoquer entièrement l'accès :
1. Rendez-vous dans Paramètres Facebook → Intégrations Business
2. Supprimez l'app Cuneiform Chat

## Notes Importantes

- **Un agent par Page** : chaque Page Facebook ne peut être connectée qu'à un seul AI agent à la fois
- **Messenger uniquement** : cette intégration fonctionne via Facebook Messenger, pas via les commentaires ou publications de la Page
- **Limite de message** : les messages individuels sont limités à 2 000 caractères ; les réponses plus longues sont automatiquement découpées
- **Pour changer d'agent** : déconnectez d'abord l'intégration existante, puis reconnectez avec un autre agent
