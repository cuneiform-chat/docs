# Dossiers et étiquettes

Organisez vos documents Content à l'aide de dossiers et d'étiquettes. Les dossiers fournissent une organisation hiérarchique, tandis que les étiquettes permettent une catégorisation transversale à travers les dossiers.

## Y accéder

Naviguez vers **Content** dans la barre latérale. Les dossiers apparaissent dans le navigateur de documents, et les contrôles d'étiquettes sont dans la barre d'outils.

## Travailler avec les dossiers

### Créer un dossier

1. Cliquez sur le bouton **New Folder** (icône dossier avec +) dans la barre d'outils
2. Entrez un nom de dossier (requis)
3. Ajoutez éventuellement une description
4. Choisissez une couleur avec le sélecteur de couleurs
5. Cliquez sur **Create**

### Modifier un dossier

1. Cliquez sur le menu à trois points (...) sur une ligne de dossier
2. Sélectionnez **Rename**
3. Mettez à jour le nom, la description ou la couleur
4. Cliquez sur **Save Changes**

### Supprimer un dossier

1. Cliquez sur le menu à trois points (...) sur une ligne de dossier
2. Sélectionnez **Delete**
3. Confirmez la suppression

### Téléverser dans un dossier

- Glissez des fichiers directement sur une ligne de dossier
- Survolez un dossier pour révéler les icônes de téléversement (stockage cloud + fichiers locaux)
- Cliquez pour développer un dossier et voir ses documents

## Travailler avec les étiquettes

### Gérer les étiquettes (Créer, Modifier, Supprimer)

1. Cliquez sur le menu déroulant **Tag Filter** dans la barre d'outils
2. Cliquez sur **Manage Tags** en bas
3. Dans la modale :
   - Cliquez sur **Create Tag** pour ajouter une nouvelle étiquette
   - Utilisez les étiquettes suggérées pour une création rapide
   - Modifiez les étiquettes existantes (nom, couleur)
   - Supprimez les étiquettes inutilisées

### Ajouter des étiquettes à un document

1. Survolez une ligne de document
2. Cliquez sur le bouton **Tag** (icône étiquette)
3. Dans la boîte de dialogue Manage Tags :
   - Voir les étiquettes actuelles en haut
   - Rechercher les étiquettes disponibles
   - Cochez les étiquettes à ajouter
   - Cliquez sur le bouton **Add X tags**

### Supprimer des étiquettes d'un document

1. Ouvrez la boîte de dialogue Manage Tags pour un document
2. Dans la section "Current Tags", cliquez sur le X des étiquettes à supprimer
3. Cliquez sur le bouton **Remove X tags**

### Filtrer les documents par étiquettes

1. Cliquez sur le menu déroulant **Tag Filter** dans la barre d'outils
2. Sélectionnez une ou plusieurs étiquettes
3. Seuls les documents avec ces étiquettes sont affichés
4. Les étiquettes sélectionnées apparaissent dans une barre de filtre sous la barre d'outils
5. Cliquez sur X sur une pastille d'étiquette pour retirer ce filtre, ou **Clear all**

## Dossiers vs Étiquettes

| Fonctionnalité | Dossiers | Étiquettes |
|----------------|----------|------------|
| Structure | Hiérarchique (un dossier par document) | Plate (plusieurs étiquettes par document) |
| Idéal pour | Grandes catégories, projets, départements | Thèmes, sujets, statuts, préoccupations transversales |
| Filtrage | Cliquez sur le dossier pour voir le contenu | Utilisez le filtre d'étiquettes pour chercher à travers les dossiers |
| Limite par document | Un dossier par document | Étiquettes illimitées par document |

## Conseils

- Utilisez les dossiers pour les catégories principales (ex. : "Docs Produit", "Politiques RH")
- Utilisez les étiquettes pour les thèmes transversaux (ex. : "Q1-2024", "Conformité", "Brouillon")
- Utilisez des codes couleur pour les dossiers et étiquettes pour une organisation visuelle
- Les étiquettes affichent le nombre d'utilisation pour voir combien de documents utilisent chaque étiquette
- Combinez le filtrage par dossier et par étiquette pour une découverte précise des documents

## Questions fréquentes

**Q : Un document peut-il être dans plusieurs dossiers ?**
R : Non, chaque document appartient à un seul dossier (ou "Unfiled"). Utilisez les étiquettes pour la catégorisation transversale.

**Q : Que se passe-t-il pour les documents quand je supprime un dossier ?**
R : Les dossiers contenant des documents ne peuvent pas être supprimés. Déplacez ou supprimez d'abord les documents.

**Q : Comment voir tous les documents avec une étiquette spécifique ?**
R : Utilisez le menu déroulant Tag Filter dans la barre d'outils et sélectionnez l'étiquette.
