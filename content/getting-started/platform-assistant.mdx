# Platform Assistant

Meet Saba, your AI helper for navigating Cuneiform Chat.

## What is Saba?

Saba is an in-app AI assistant that helps you get the most out of Cuneiform Chat. Named after Nisaba — the Sumerian goddess of writing and scribal arts — Saba represents our journey from clay tablets to chatbots.

Saba can help you:

- Learn about platform features and how to use them
- Access information about your agents, documents, and integrations
- Understand your billing and subscription details
- Troubleshoot common issues

## Accessing Saba

### Floating Button

Look for the Saba icon in the **bottom-right corner** of your screen. Click it to open the assistant.

### Keyboard Shortcuts

| Action | Mac | Windows/Linux |
|--------|-----|---------------|
| Open/Close Saba | `Cmd + K` | `Ctrl + K` |
| New Conversation | `Cmd + N` | `Ctrl + N` |
| Close | `Escape` | `Escape` |

## What Saba Can Help With

### Platform Features

Ask questions like:

- "How do I create an agent?"
- "What file formats are supported?"
- "How do I connect Slack?"

### Your Data

Saba can access your organization's data to answer specific questions:

- "How many agents do I have?"
- "What documents are in my content?"
- "Which integrations are active?"

### Billing Information

Get quick answers about your account:

- "What plan am I on?"
- "How many credits have I used?"
- "When does my billing period end?"

## Features

### Query Mode

Toggle between response modes using the button next to the input field:

- **Fast** (Zap icon) — Quick responses for simple questions
- **Reasoning** (Brain icon) — More thorough analysis for complex questions

Your preference is saved across sessions.

### Voice Input

Click the **microphone icon** next to the send button to speak your question instead of typing.

### Slash Commands

Type `/` in the input field to see quick commands:

| Command | What it does |
|---------|--------------|
| `/agents` | List all your agents with status |
| `/usage` | Show your usage statistics |
| `/docs` | Show documents in your content |
| `/help` | List available commands |
| `/new` | Get step-by-step guidance to create an agent |
| `/conversations` | Show recent conversation activity |

### Conversation History

Your conversations with Saba are saved automatically. Access past conversations from the sidebar to continue where you left off.

### Suggested Questions

Saba suggests relevant questions based on your current page. These appear as quick-start options when you open the assistant.

### Follow-up Suggestions

After each response, Saba offers related questions you might want to ask next.

### Export Conversations

Save conversations using the export button:

- **Download as Markdown** — Save as .md file with formatting
- **Download as Text** — Save as plain .txt file
- **Copy to Clipboard** — Copy the full conversation

### Feedback

Help improve Saba with feedback options on each response:

- **Thumbs up/down** — Quick feedback on response quality
- **Submit Feedback** — Provide detailed comments to help improve the assistant
