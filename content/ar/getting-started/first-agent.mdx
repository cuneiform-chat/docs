# إنشاء أول Agent

الـ Agents هي روبوتات الدردشة التي تتفاعل مع مستخدميك. يمكن ضبط كل Agent بمعرفة وسلوك وشخصية محدّدة.

## إنشاء Agent

1. انتقل إلى **Agents** في الشريط الجانبي
2. انقر على **Create Agent**
3. املأ المعلومات الأساسية:
   - **Name** — اسم وصفي للـ Agent (مثل "Customer Support Bot")
   - **Description** — ما الذي يفعله هذا الـ Agent (لمرجعك الخاص)

## ضبط الـ Agent

### شخصية الـ Agent

تحدّد شخصية الـ Agent طابعه وسلوكه. وهي التعليمات التي توجّه طريقة ردّ الـ Agent.

يمكنك كتابة شخصيتك الخاصة أو النقر على **Generate** لاستخدام Persona Builder المدعوم بالذكاء الاصطناعي الذي ينشئ شخصية بناءً على متطلباتك.

**مثال:**
```
You are a helpful customer support assistant for Acme Corp.
You answer questions about our products and services based on the provided documentation.
Be friendly, professional, and concise.
If you don't know the answer, say so rather than making something up.
```

### قواعد المنصة

تتضمّن جميع الـ Agents تلقائيًا ضوابط أمان مدمجة:

- لن تختلق وقائع أو أرقامًا أو تواريخ
- تقول "لا أعرف" عندما تكون المعلومات غير متوفرة
- لن تخمّن المعلومات الناقصة
- تصحّح الافتراضات الخاطئة في الأسئلة
- لن تنتحل صفة المتخصصين (المحامين، الأطباء، إلخ)
- ترفض المحتوى الضار أو غير اللائق

هذه القواعد فعّالة دائمًا ولا يمكن تعطيلها.

### التحكم في الوصول إلى المعرفة

تحكَّم في المستندات التي يمكن لـ Agent الوصول إليها:

- **Exclude Mode** (الوضع الافتراضي) — يصل الـ Agent إلى جميع المستندات باستثناء تلك التي تختار إخفاءها
- **Include Mode** — يصل الـ Agent فقط إلى المجلدات أو الوسوم أو المستندات المحدّدة التي تختارها

استخدم Include Mode عندما تريد قصر الـ Agent على مجموعة معرفة محدّدة.

### ضبط الـ LLM

بالنسبة لمعظم المستخدمين، تعمل إعدادات نموذج الذكاء الاصطناعي الافتراضية بشكل جيّد. ويمكن للمستخدمين المتقدمين تخصيص:

- **Model** — اختر من بين نماذج الذكاء الاصطناعي المتاحة
- **Temperature** — كلما انخفضت = أكثر اتساقًا، وكلما ارتفعت = أكثر إبداعًا
- **Show Document References** — فعِّلها لتضمين استشهادات المصادر في الإجابات

## حفظ الـ Agent

انقر على **Create Agent** للحفظ. يبدأ الـ Agent في حالة **Testing**، أي أنه يمكنك اختباره في الـ Playground لكن عمليات دمج القنوات تظل معطّلة حتى تقوم بتفعيله.
