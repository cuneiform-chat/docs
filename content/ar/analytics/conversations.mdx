# تحليلات المحادثات

تتبّع مقاييس المحادثات واعرض النصوص الكاملة التفصيلية عبر الـ Agents والقنوات لديك.

## نظرة عامة

توفّر تحليلات المحادثات:

- إجمالي حجم المحادثات
- المحادثات لكل Agent
- المحادثات لكل قناة
- النصوص الكاملة للرسائل
- رؤى مدعومة بالـ AI حول المحادثات

## الوصول إلى المحادثات

### من الـ Dashboard

1. انتقل إلى **Analytics** في الشريط الجانبي
2. انقر **Conversations** في القائمة الفرعية للتحليلات

(ملاحظة: يفتح زر **View All** على بطاقتي Top Agents وTop Channels التفصيل حسب الـ Agent أو القناة — وليس قائمة المحادثات.)

### قائمة المحادثات

اعرض جميع المحادثات مع:

| العمود | الوصف |
|--------|-------------|
| Title | عنوان المحادثة أو معرّف الجلسة |
| Agent | الـ Agent الذي عالج المحادثة |
| Channel | المنصّة (Telegram وDiscord وSlack، إلخ) |
| Messages | إجمالي عدد الرسائل |
| Last Active | آخر تحديث للمحادثة |
| Status | active أو handoff أو archived أو deleted |

## تصفية المحادثات

صفِّ قائمة المحادثات حسب:

- **Agent** — اختر Agent محددًا أو كل الـ Agents
- **Channel** — صفِّ حسب المنصّة (WhatsApp وTelegram وMeta وSlack وDiscord وGoogle Chat وWidget وPlayground)
- **Date range** — آخر 7 أو 14 أو 30 أو 90 يومًا

## تفاصيل المحادثة

انقر على أي محادثة لعرض تفاصيلها الكاملة:

### تبويب Overview

- **Total Messages** — عدد الرسائل في المحادثة
- **Credits Spent** — الـ credits المستخدمة من المنصّة
- **Agent** — الـ Agent الذي عالج المحادثة
- **Channel** — المنصّة التي جرت فيها
- **Created** — وقت بدء المحادثة
- **Last Active** — أحدث نشاط

### رسم نشاط الرسائل

تصوّر أنماط الرسائل عبر الزمن:
- بدّل بين مستوى التفصيل الساعي واليومي
- أظهِر/أخفِ رسائل المستخدم ورسائل المساعد
- اطّلع على أنماط نشاط المحادثة

### تبويب Messages

اعرض النص الكامل للمحادثة:

- **Full message history** — اطّلع على كل رسالة في المحادثة
- **Role indicators** — رسائل User وAssistant وSystem وTool مرمّزة بالألوان
- **Timestamps** — وقت إرسال كل رسالة
- **Token usage** — رموز الإدخال/الإخراج لكل رسالة (عند توفّرها)

#### تصفية الرسائل

صفِّ الرسائل حسب الفترة الزمنية:
- آخر 24 ساعة
- آخر 7 أيام
- آخر 30 يومًا
- كل الرسائل

#### التصدير

انقر **Export** لتنزيل المحادثة كملف JSON يحتوي على:
- البيانات الوصفية للمحادثة
- جميع الرسائل مع الطوابع الزمنية
- معلومات الـ tokens

## الرؤى المدعومة بالـ AI

ولِّد ملخّصات ذكية للمحادثات:

1. انتقل إلى تبويب **Messages** في المحادثة
2. انقر **Generate Insights**
3. اعرض الرؤى المحلَّلة بالـ AI، ومنها:
   - **Key Points** — أبرز المواضيع التي نُوقِشت
   - **User Intents** — ما كان المستخدم يحاول إنجازه
   - **Key Info Shared** — المعلومات المهمّة المتبادَلة
   - **Suggested Actions** — توصيات مبنية على المحادثة

## اعتبارات الخصوصية

تُعالَج بيانات المحادثات وفقًا لـ:

- متطلّبات سياسة الخصوصية
- موافقة المستخدم حيثما ينطبق ذلك

## نصائح

- استخدم عوامل التصفية للعثور على محادثات من Agents أو قنوات محددة
- صدِّر المحادثات المهمّة لحفظ السجلّات أو التحليل
- ولِّد رؤى الـ AI لفهم المحادثات الطويلة بسرعة
- تفقّد رسم نشاط الرسائل لتحديد أوقات الذروة في الاستخدام
- راجع نصوص المحادثات لتحسين شخصية الـ Agent لديك
- راقب الـ credits المستهلكة لتتبّع أنماط الاستخدام

## أسئلة شائعة

**س: كيف أعثر على المحادثات من قناة محددة؟**

استخدم عامل تصفية Channel أعلى قائمة المحادثات لاختيار منصّة محددة مثل Telegram أو Discord أو Slack.

**س: هل يمكنني تصدير عدّة محادثات دفعةً واحدة؟**

حاليًا، يعمل التصدير لمحادثة واحدة في كل مرّة. صدِّر كل محادثة على حدة من تبويب Messages.

**س: ماذا يفعل "Generate Insights"؟**

يستخدم الـ AI لتحليل المحادثة وتقديم ملخّص يتضمّن النقاط الرئيسية ونوايا المستخدم والمعلومات المهمّة المتبادَلة والإجراءات المقترحة.

**س: هل تكلّف رؤى الـ AI أي credits؟**

نعم، يستهلك توليد الرؤى credits من حسابك. لكن النتائج تُخزَّن مؤقتًا، فعرض الرؤى نفسها مرّة أخرى مجاني.

**س: إلى متى تُخزَّن المحادثات؟**

تُخزَّن المحادثات بأمان وتبقى متاحة للتحليلات. تواصل مع الدعم إن كانت لديك أسئلة حول تخزين البيانات.
