# تحليلات الـ Agent

اعرض مقاييس الأداء التفصيلية لجميع الـ Agents لديك. قارن أحجام الاستعلامات والمحادثات واستهلاك الـ credits عبر محفظة الـ Agents بأكملها.

## الوصول إلى تحليلات الـ Agent

1. انتقل إلى **Analytics** في الشريط الجانبي
2. انقر **View All** بجوار "Top Agents"، أو
3. انتقل مباشرةً إلى **Analytics > By Agent**

## التنقّل

يعرض مسار التنقّل موضعك الحالي: **Dashboard / Agents**. انقر "Dashboard" للعودة إلى صفحة التحليلات الرئيسية.

## عناصر التحكم في النطاق الزمني

| عنصر التحكم | الوصف |
|---------|-------------|
| **Last 7 days** | عرض المقاييس للأسبوع الماضي |
| **Last 14 days** | عرض المقاييس لأسبوعين |
| **Last 30 days** | عرض المقاييس للشهر الماضي |
| **Last 90 days** | عرض المقاييس للربع الماضي |
| **Refresh** | إعادة تحميل البيانات بأحدث القيم |

## جدول الـ Agents

تُدرَج جميع الـ Agents لديك مع مقاييس الأداء:

| العمود | الوصف | قابل للفرز |
|--------|-------------|----------|
| Agent | اسم الـ Agent | لا |
| Status | active أو inactive أو testing أو archived | لا |
| Queries | إجمالي الأسئلة المُجاب عنها | نعم |
| Conversations | جلسات الدردشة | نعم |
| Credits | الموارد المستهلكة | نعم |
| Channels | القنوات التي يُستخدَم فيها الـ Agent | لا |
| (السهم) | رابط إلى العرض التفصيلي | لا |

### الفرز

انقر على ترويسة أي عمود قابل للفرز للترتيب حسب ذلك المقياس:
- **النقرة الأولى**: فرز تنازلي (الأعلى أولًا)
- **النقرة الثانية**: فرز تصاعدي (الأدنى أولًا)
- يُميَّز عمود الفرز النشط

### تقسيم الصفحات

لقوائم الـ Agents الكبيرة:
- يُعرَض "Showing X - Y of Z"
- استخدم زرّي **Previous/Next** للتنقّل بين الصفحات

## شارات حالة الـ Agent

| الشارة | اللون | المعنى |
|-------|-------|---------|
| active | أخضر | الـ Agent منشور ويستقبل الاستعلامات |
| inactive | رمادي | الـ Agent متوقّف مؤقتًا |
| testing | أصفر | يجري اختبار الـ Agent قبل النشر |
| archived | أصفر | الـ Agent مؤرشَف |

## شارات القنوات

يوضّح عمود Channels المنصّات التي يُستخدَم عليها كل Agent:
- تُعرَض حتى 3 شارات قنوات (مثل "web" و"telegram" و"discord")
- إذا زاد العدد عن 3، يُعرَض "X+" للإشارة إلى قنوات إضافية

## عرض تفاصيل الـ Agent

انقر على السهم في أي صفّ Agent لرؤية:
- مقاييس تفصيلية لذلك الـ Agent تحديدًا
- رسوم بيانية زمنية
- تفصيل حسب القناة
- بيانات أكثر تفصيلًا

## نصائح

- افرز حسب **Credits** للعثور على الـ Agents الأكثر استهلاكًا للموارد
- افرز حسب **Queries** لتحديد الـ Agents الأكثر شيوعًا
- استخدم **90 days** لتحليل الاتجاهات على المدى الطويل
- تفقّد الـ Agents غير النشطة لمعرفة ما إذا كان ينبغي إعادة تفعيلها
- انقر للدخول إلى الـ Agents الفردية للحصول على رؤى أعمق

## أسئلة شائعة

**س: كيف أعثر على الـ Agent الأكثر استخدامًا لديّ؟**

انقر على ترويسة عمود "Queries" للفرز حسب عدد الاستعلامات. الصفّ العلوي هو الـ Agent الأكثر نشاطًا لديك.

**س: ماذا تعني شارات القنوات؟**

تُظهِر المنصّات (Web وTelegram وDiscord وSlack، إلخ) التي يستقبل منها كل Agent الاستعلامات.

**س: لماذا يُظهِر أحد الـ Agents صفر استعلامات؟**

قد يكون الـ Agent جديدًا أو غير نشط أو لم يُنشَر بعد على أي قناة.
