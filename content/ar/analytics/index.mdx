# التحليلات

راقب أداء الـ Agents لديك وافهم كيف يتفاعل المستخدمون مع روبوتات الدردشة الخاصة بك.

## نظرة عامة

تساعدك التحليلات على:
- تتبّع حجم المحادثات وأنماط الاستعلامات
- مراقبة أداء الـ Agent واستهلاك الـ credits
- فهم توزيع القنوات
- تحديد مجالات التحسين

## Dashboard

ادخل إلى التحليلات من قسم **Analytics** في الشريط الجانبي.

### المقاييس الرئيسية

| المقياس | الوصف |
|--------|-------------|
| Total Queries | عمليات تنفيذ الـ Agent (ردود الـ AI) |
| Conversations | عدد جلسات الدردشة |
| Unique Users | المستخدمون الأفراد الذين أجروا محادثة |
| Credits Used | الـ credits المستهلكة من المنصة |

### استهلاك الـ Credits

يعرض الـ Dashboard استهلاك الـ credits لدورة الفوترة الحالية:
- الـ credits المستخدمة مقابل المخصصة
- شريط تقدّم بالنسبة المئوية
- الـ credits المتبقية للفترة

### الرسوم البيانية

يتضمّن الـ Dashboard رسومًا بيانية مرئية:
- **Query Volume** — رسم خطي يوضّح الاستعلامات عبر الزمن
- **Channel Distribution** — رسم دائري يقسّم الاستعلامات حسب القناة
- **Agent Distribution** — رسم دائري يقسّم الاستعلامات حسب الـ Agent

### أبرز الـ Agents

قائمة مرتّبة بأكثر الـ Agents نشاطًا لديك تعرض:
- اسم الـ Agent وترتيبه
- إجمالي الاستعلامات المُعالَجة
- عدد المحادثات
- الـ credits المستهلكة
- الحالة الراهنة (active، inactive، testing، archived)

انقر على أي Agent لعرض التحليلات التفصيلية، أو انقر **View All** لرؤية جميع الـ Agents.

### أبرز القنوات

قائمة مرتّبة بأكثر قنوات التواصل نشاطًا لديك تعرض:
- اسم القناة وترتيبها
- إجمالي الاستعلامات المُعالَجة
- عدد المحادثات
- الـ credits المستهلكة

انقر على أي قناة لعرض التحليلات التفصيلية، أو انقر **View All** لرؤية جميع القنوات.

## الفترات الزمنية

اعرض التحليلات لنطاقات زمنية مختلفة:
- دورة الفوترة الحالية
- آخر 7 أيام
- آخر 14 يومًا
- آخر 30 يومًا
- آخر 90 يومًا

## مستوى التفصيل

اضبط كيفية تجميع البيانات:
- كل ساعة
- يوميًا
- أسبوعيًا
- شهريًا

## التصفية

يدعم الـ Dashboard الرئيسي تحديد **Date range** وعناصر التحكم في **Granularity**. للتصفية حسب الـ Agent أو القناة، افتح [صفحة المحادثات](/analytics/conversations) التي تتيح قوائم منسدلة للـ Agent والقناة إلى جانب نطاقها الزمني.

## استخدام التحليلات

### تحديد الأنماط

اطّلع على القنوات والـ Agents التي تعالج أكبر عدد من الاستعلامات من أجل:
- تحسين توزيع الموارد
- تركيز التحسينات حيث تلزم
- فهم تفضيلات المستخدمين

### مراقبة الأداء

تتبّع الاتجاهات لضمان:
- بقاء استهلاك الـ credits ضمن الحدود
- صحّة تفاعل المستخدمين
- عدم وجود أنماط غير معتادة

### تحسين الـ Agents

استخدم الرؤى من أجل:
- تعديل شخصيات الـ Agent
- إضافة الوثائق الناقصة
- تحسين دقة الردود
