# تحليلات القنوات

اعرض مقاييس الأداء مفصّلة حسب القناة. قارن أحجام الاستعلامات والمحادثات والمستخدمين الفريدين واستهلاك الـ credits عبر جميع المنصّات التي تستقبل عليها الـ Agents الاستعلامات.

## الوصول إلى تحليلات القنوات

1. انتقل إلى **Analytics** في الشريط الجانبي
2. انقر **View All** بجوار "Channel Distribution"، أو
3. انتقل مباشرةً إلى **Analytics > By Channel**

## التنقّل

يعرض مسار التنقّل موضعك الحالي: **Dashboard / Channels**. انقر "Dashboard" للعودة إلى صفحة التحليلات الرئيسية.

## عناصر التحكم في النطاق الزمني

| عنصر التحكم | الوصف |
|---------|-------------|
| **Last 7 days** | عرض المقاييس للأسبوع الماضي |
| **Last 14 days** | عرض المقاييس لأسبوعين |
| **Last 30 days** | عرض المقاييس للشهر الماضي |
| **Last 90 days** | عرض المقاييس للربع الماضي |
| **Refresh** | إعادة تحميل البيانات بأحدث القيم |

## بطاقات الملخّص

أربع بطاقات تعرض مقاييس مجمّعة عبر جميع القنوات:

| البطاقة | الوصف |
|------|-------------|
| Total Channels | عدد القنوات النشطة |
| Total Queries | مجموع الاستعلامات عبر جميع القنوات |
| Total Conversations | مجموع المحادثات عبر جميع القنوات |
| Total Credits | مجموع الـ credits المستخدمة عبر جميع القنوات |

## جدول القنوات

تُدرَج جميع قنواتك النشطة مع مقاييس الأداء:

| العمود | الوصف |
|--------|-------------|
| Channel | اسم القناة مع شارة ملوّنة |
| Queries | إجمالي الأسئلة المُجاب عنها على هذه القناة |
| Conversations | جلسات الدردشة على هذه القناة |
| Unique Users | المستخدمون المتمايزون الذين تفاعلوا عبر هذه القناة |
| Credits | الموارد المستهلكة من هذه القناة |
| % of Total | شريط تقدّم مرئي يوضّح حصّة هذه القناة من إجمالي الاستعلامات |
| (السهم) | رابط إلى العرض التفصيلي للقناة |

## أنواع القنوات

يمكن للـ Agents لديك استقبال الاستعلامات من منصّات متنوّعة:

| القناة | الوصف |
|---------|-------------|
| Web | الاستعلامات من سطح دردشة الويب القابل للتضمين |
| Widget | الاستعلامات من أداة دردشة الموقع الإلكتروني |
| Telegram | تكامل بوت Telegram |
| Discord | تكامل بوت Discord |
| Slack | تكامل تطبيق Slack |
| Meta | تكامل Meta/Messenger |
| WhatsApp | تكامل WhatsApp Business |
| Google Chat | تكامل Google Chat (Workspace) |
| OpenAI Apps | المحادثات من OpenAI Apps SDK |
| Playground | الاستعلامات من واجهة اختبار الـ Agent |
| API | استدعاءات الـ API المباشرة إلى الـ Agent |

## عرض تفاصيل القناة

انقر على السهم في أي صفّ قناة لرؤية:
- مقاييس تفصيلية لتلك القناة تحديدًا
- رسوم بيانية زمنية مع خيارات لمستوى التفصيل (Hourly وDaily وWeekly وMonthly)
- تفصيل الـ Agents ضمن تلك القناة

## نصائح

- قارن **% of Total** لفهم القنوات التي تدفع أكبر قدر من حركة الاستخدام
- استخدم هذا العرض لتحديد القنوات الضعيفة الأداء التي تحتاج إلى اهتمام
- تفقّد **Unique Users** لفهم مدى وصول الجمهور لكل منصّة
- راجع **Credits** لمعرفة استهلاك الموارد حسب القناة

## أسئلة شائعة

**س: لماذا لا أرى جميع القنوات مدرجة؟**

تظهر في الجدول فقط القنوات التي سجّلت استعلامًا واحدًا على الأقل خلال النطاق الزمني المحدد.

**س: كيف تُحتسَب النسبة المئوية؟**

تُظهِر النسبة المئوية حصّة كل قناة من إجمالي الاستعلامات عبر جميع القنوات للفترة المحددة.

**س: هل يمكنني مقارنة القنوات عبر الزمن؟**

انقر للدخول إلى قناة محددة لرؤية بياناتها الزمنية واتجاهاتها.
