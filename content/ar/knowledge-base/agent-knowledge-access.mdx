# وصول الـ Agent إلى المعرفة

تحكّم في المستندات التي يمكن لكل Agent الوصول إليها عند الإجابة عن الأسئلة. قيّد الـ Agents بمجلدات أو وسوم محدّدة، أو استبعِد محتوى معيّنًا من نطاق وصولها.

## كيفية الوصول

1. انتقل إلى **Agents** في الشريط الجانبي
2. انقر على Agent لتعديله، أو أنشئ Agent جديدًا
3. مرّر إلى قسم **Knowledge Access Control**

## أوضاع الوصول

يحدّد وضع الوصول كيفية تأثير اختياراتك على وصول الـ Agent إلى المستندات.

| الوضع | الأيقونة | الوصف | متى يُستخدَم |
|------|------|-------------|----------|
| **Exclude Mode** | X حمراء | يصل الـ Agent إلى كل المستندات باستثناء المختارة | تريد إخفاء مستندات حسّاسة مع السماح بكل ما عداها |
| **Include Mode** | علامة صحّ خضراء | يصل الـ Agent إلى المستندات المختارة فقط | تريد تقييد الـ Agent بمحتوى محدّد |

### اختيار الوضع المناسب

**Exclude Mode** (الافتراضي):
- يبدأ بوصول كامل إلى جميع المستندات
- اختر المجلدات/الوسوم لحجبها عن الـ Agent
- مناسب لـ: إخفاء مستندات الموارد البشرية أو البيانات المالية أو المسوّدات

**Include Mode**:
- يبدأ بدون أيّ وصول
- اختر المجلدات/الوسوم لمنح الوصول إليها
- مناسب لـ: إنشاء Agents متخصّصة لمواضيع محدّدة

## اختيار المحتوى

### حسب المجلدات

1. انقر على تبويب **Folders**
2. استخدم مربّع البحث للعثور على المجلدات
3. حدّد المجلدات لتضمينها/استبعادها
4. وسّع المجلدات (انقر على السهم) لاختيار مستندات فردية
5. تُظهِر علامة الصحّ العناصر المختارة؛ ويُظهِر التحديد الجزئي شَرطة

### حسب الوسوم

1. انقر على تبويب **Tags**
2. استخدم مربّع البحث للعثور على الوسوم
3. حدّد الوسوم لتضمينها/استبعادها
4. يُظهِر كل وسم عدد المستندات التي تستخدمه

## لوحة المعاينة

تُظهِر لوحة المعاينة على اليمين:
- إجمالي المستندات التي يمكن الوصول إليها بناءً على التحديد الحالي
- تتحدّث في الوقت الفعلي مع إجرائك التغييرات

## حفظ التغييرات

عند تعديل Agent موجود:
1. أجرِ اختياراتك
2. انقر على **Save Changes** (الزرّ الأخضر)
3. أو انقر على **Reset Changes** للتراجع عن التغييرات غير المحفوظة

عند إنشاء Agent جديد:
- تُحفَظ إعدادات الوصول إلى المعرفة تلقائيًا عند إرسال نموذج الـ Agent

## نصائح

- استخدم **Exclude Mode** عندما تريد وصولًا واسعًا مع بعض الاستثناءات
- استخدم **Include Mode** للـ Agents المركّزة الخاصة بموضوع محدّد
- ادمج المجلدات والوسوم معًا للتحكّم الدقيق
- تحقّق من لوحة المعاينة للتأكّد من تحديدك قبل الحفظ
- في Include Mode، يجب اختيار مجلد أو وسم واحد على الأقلّ

## أسئلة شائعة

**س: ماذا يحدث إذا اخترت المجلدات والوسوم معًا؟**
ج: يمكن للـ Agent الوصول إلى المستندات التي تطابق أيًّا من اختياراتك. تتكامل المجلدات والوسوم بشكل شامل.

**س: هل يمكنني منح Agent وصولًا إلى كل شيء؟**
ج: نعم. استخدم Exclude Mode ولا تختر شيئًا لاستبعاده. سيحظى الـ Agent بوصول كامل.

**س: ماذا لو كان مستند في مجلد مختار لكن يحمل وسمًا مُستبعَدًا؟**
ج: في Exclude Mode، أيّ تطابق مع محتوى مُستبعَد يحجب الوصول. وفي Include Mode، أيّ تطابق مع محتوى مُضمَّن يمنح الوصول.

**س: هل يؤثّر هذا في المحادثات الحالية؟**
ج: نعم. تسري التغييرات فورًا على الرسائل الجديدة. سيستخدم الـ Agent قواعد الوصول المحدّثة.
