# Folders and Tags

Organize your Content documents using folders and tags. Folders provide hierarchical organization, while tags allow cross-cutting categorization across folders.

## Getting There

Navigate to **Content** in the sidebar. Folders appear in the document browser, and tag controls are in the toolbar.

## Working with Folders

### Create a Folder

1. Click the **New Folder** button (folder icon with +) in the toolbar
2. Enter a folder name (required)
3. Optionally add a description
4. Choose a color using the color picker
5. Click **Create**

### Edit a Folder

1. Click the three-dot menu (...) on a folder row
2. Select **Rename**
3. Update the name, description, or color
4. Click **Save Changes**

### Delete a Folder

1. Click the three-dot menu (...) on a folder row
2. Select **Delete**
3. Confirm deletion

### Upload to a Folder

- Drag files directly onto a folder row
- Hover over a folder to reveal upload icons (cloud storage + local files)
- Click to expand a folder and see its documents

## Working with Tags

### Manage Tags (Create, Edit, Delete)

1. Click the **Tag Filter** dropdown in the toolbar
2. Click **Manage Tags** at the bottom
3. In the modal:
   - Click **Create Tag** to add a new tag
   - Use suggested tags for quick creation
   - Edit existing tags (name, color)
   - Delete unused tags

### Add Tags to a Document

1. Hover over a document row
2. Click the **Tag** button (tag icon)
3. In the Manage Tags dialog:
   - See current tags at the top
   - Search available tags
   - Check tags to add
   - Click **Add X tags** button

### Remove Tags from a Document

1. Open the Manage Tags dialog for a document
2. In the "Current Tags" section, click the X on tags to select for removal
3. Click **Remove X tags** button

### Filter Documents by Tags

1. Click the **Tag Filter** dropdown in the toolbar
2. Select one or more tags
3. Only documents with those tags are shown
4. Selected tags appear in a filter bar below the toolbar
5. Click X on a tag chip to remove that filter, or **Clear all**

## Folders vs Tags

| Feature | Folders | Tags |
|---------|---------|------|
| Structure | Hierarchical (one folder per document) | Flat (multiple tags per document) |
| Best for | Broad categories, projects, departments | Topics, themes, status, cross-cutting concerns |
| Filtering | Click folder to see contents | Use tag filter to find across folders |
| Document limit | One folder per document | Unlimited tags per document |

## Tips

- Use folders for major categories (e.g., "Product Docs", "HR Policies")
- Use tags for cross-cutting themes (e.g., "Q1-2024", "Compliance", "Draft")
- Color-code folders and tags for visual organization
- Tags show usage count so you can see how many documents use each tag
- Combine folder and tag filtering for precise document discovery

## Common Questions

**Q: Can a document be in multiple folders?**
A: No, each document belongs to one folder (or "Unfiled"). Use tags for cross-cutting categorization.

**Q: What happens to documents when I delete a folder?**
A: Folders with documents cannot be deleted. Move or delete documents first.

**Q: How do I see all documents with a specific tag?**
A: Use the Tag Filter dropdown in the toolbar and select the tag.
