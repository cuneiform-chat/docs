# OneDrive Integration

Import documents from OneDrive to train your AI agents.

## Overview

Connect your Microsoft account to Cuneiform Chat and import documents directly into your content. Your AI agent can then answer questions based on the content of these documents.

## Getting Started

### Step 1: Navigate to Content

1. Log in to [Cuneiform Chat](https://admin.cuneiform.chat)
2. Go to **Content** in the sidebar
3. Look for the cloud storage icons at the top of the page

### Step 2: Connect OneDrive

1. Click the **OneDrive icon** in the cloud storage icons row
2. Sign in with your Microsoft account (if prompted)
3. Grant Cuneiform Chat permission to access your files

### Step 3: Select Files

1. Use the OneDrive file picker to browse your files
2. Navigate through folders to find documents
3. Select one or more files to import
4. Click to confirm your selection

### Step 4: Processing

Once imported:
- Documents are automatically processed
- Text is extracted and indexed
- Your agent can answer questions about the content

## Supported File Types

| Format | Extension | Notes |
|--------|-----------|-------|
| PDF | .pdf | Text and scanned (OCR) |
| Word | .docx, .doc | Microsoft Word documents |
| PowerPoint | .pptx, .ppt | Presentation slides |
| Text | .txt | Plain text files |
| Markdown | .md | Markdown formatting |
| Rich Text | .rtf | Rich Text Format |
| Web/Data | .html, .htm, .json, .xml | Web pages and structured data |

The same set is available across every cloud-storage provider. See [Supported Formats](/knowledge-base/supported-formats) for details and per-tier file-size limits.

## Permissions

Cuneiform Chat requests minimal permissions:

- **Read-only access** to files you select
- **No write access** to your OneDrive account
- **No access** to files you don't explicitly choose

## Best Practices

- **Select relevant files** — Only import documents your agent needs
- **Organize first** — Structure your OneDrive folders before importing
- **Check formats** — Ensure files are in supported formats
- **Monitor progress** — Verify documents process successfully

## Troubleshooting

### Can't Connect to OneDrive

- Verify you're signed into the correct Microsoft account
- Check that third-party apps are allowed in your Microsoft settings
- Try clearing browser cookies and reconnecting

### Files Not Importing

- Confirm files are in supported formats
- Check you have permission to access the files
- Try importing fewer files at once

### Import Taking Too Long

- Large files take longer to process
- Check the document status in Content
- Complex PDFs with images require more processing time

## Data Privacy

- Original files are not permanently stored
- Only extracted text embeddings are retained
- Your Microsoft credentials are encrypted
- We never access files you haven't selected
