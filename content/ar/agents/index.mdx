# Agents

الـ Agents هي روبوتات الدردشة الذكية التي تتفاعل مع مستخدميك. لكل Agent إعداداته الخاصة، ووصوله إلى المعرفة، وشخصيته.

## ما هو الـ Agent؟

الـ Agent هو روبوت دردشة مضبوط:

- يجيب عن الأسئلة باستخدام محتواك
- يتّبع التعليمات المحدّدة في شخصيته
- يحافظ على سياق المحادثة ضمن الجلسات
- يمكن نشره على قنوات متعدّدة

## مفاهيم الـ Agent

### شخصية الـ Agent

شخصية الـ Agent هي مجموعة التعليمات التي تحدّد كيف يتصرّف. وهي تتحكّم في:

- **الطابع** — ودود، احترافي، عفوي، إلخ.
- **النطاق** — المواضيع التي ينبغي للـ Agent تناولها وتلك التي يجب تجنّبها
- **أسلوب الردّ** — طول الإجابات وتنسيقها ونبرتها
- **الضوابط** — الحدود والقيود
- **اللغة** — كشف تلقائي لكل رسالة (دعم 176 لغة)

### الوصول إلى المعرفة

يصل كل Agent إلى محتواك للعثور على المعلومات ذات الصلة. يمكنك ضبط:

- المستندات التي يمكن للـ Agent البحث فيها
- عدد المصادر التي يجري استرجاعها
- ما إذا كان سيعرض استشهادات المصادر

### القنوات

يمكن نشر الـ Agents على قنوات متعدّدة في آنٍ واحد:

- منصّات المراسلة (Telegram وDiscord وSlack وWhatsApp وGoogle Chat)
- Facebook Messenger عبر تكامل Meta
- Human Handoff — انقل المحادثات بسلاسة إلى عضو بشري في الفريق
