# الاختبار في Playground

import { Callout } from 'nextra/components'

الـ Playground هو بيئتك لاختبار الـ Agents وصقلها قبل النشر.

## الوصول إلى الـ Playground

1. انتقل إلى **Agents** في الشريط الجانبي
2. انقر على **Test** في بطاقة الـ Agent (أو **Test Agent** أثناء تعديل Agent)
3. ينزلق الـ Playground ليُفتَح كلوحة جانبية — ابدأ محادثة

<Callout type="info">
  يكون زر Test معطّلًا عندما تكون حالة الـ Agent هي **Archived** أو **Inactive**. غيّر الحالة إلى **Active** أو **Testing** لتمكين الاختبار.
</Callout>

## ماذا تختبر

### الوظائف الأساسية

- هل يستطيع الـ Agent الإجابة عن الأسئلة من مستنداتك؟
- هل الردود دقيقة وذات صلة؟
- هل تطابق النبرة توقّعاتك؟

### الحالات الحديّة

اختبر السيناريوهات التي قد تُربِك الـ Agent:

- أسئلة لا تغطّيها مستنداتك
- أسئلة غامضة أو غير واضحة
- أسئلة متعدّدة الأجزاء
- أسئلة متابعة تتطلّب سياقًا

### تدفّق المحادثة

اختبر المحادثات متعدّدة الأدوار:

- هل يتذكّر الـ Agent السياق من الرسائل السابقة؟
- هل يستطيع التعامل مع تغيّرات الموضوع بسلاسة؟
- هل يطلب التوضيح عند الحاجة؟

## تقييم الردود

لكل ردّ، ضع في اعتبارك:

| الجانب | أسئلة لطرحها |
|--------|-----------------|
| **الدقّة** | هل المعلومة صحيحة؟ |
| **الصلة** | هل تجيب عن السؤال الفعلي؟ |
| **الاكتمال** | هل ينقص شيء مهمّ؟ |
| **النبرة** | هل تطابق صوت علامتك التجارية؟ |
| **الطول** | هل هو موجز أو مفصّل بالقدر المناسب؟ |

## التحسين التكراري

### تحديد المشكلات

المشكلات الشائعة وحلولها:

| المشكلة | الحل |
|-------|----------|
| معلومات خاطئة | تحقّق من محتوى المستند، وحسّن الاسترجاع |
| إسهاب مفرط | أضِف "be concise" إلى شخصية الـ Agent |
| رسمي/عفوي بإفراط | اضبط النبرة في شخصية الـ Agent |
| لا يعرف الإجابة | أضِف مستندات ذات صلة |
| يختلق وقائع | عزّز الحدود في الموجّه |

### إجراء التغييرات

1. حدّد المشكلة أثناء الاختبار في الـ Playground
2. اضبط الإعدادات ذات الصلة (الموجّه، المستندات، الإعداد)
3. اختبر مجدّدًا بالأسئلة نفسها
4. تحقّق من أن الإصلاح لا يكسر سلوكيات أخرى

## قائمة سيناريوهات الاختبار

أنشئ مجموعة من أسئلة الاختبار القياسية:

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  احفظ سيناريوهات الاختبار وأعد تشغيلها بعد إجراء التغييرات لرصد أي تراجعات.
</Callout>

## جاهز للنشر

يكون الـ Agent جاهزًا عندما:

- ✅ يجيب عن الأسئلة الشائعة بدقّة
- ✅ يتعامل مع الحالات الحديّة بسلاسة
- ✅ يحافظ على نبرة مناسبة
- ✅ يحترم الحدود المحدّدة
- ✅ تعمل المحادثات متعدّدة الأدوار جيّدًا

بعد ذلك، انشر الـ Agent على [القنوات](/integrations) حيث سيتفاعل معه المستخدمون.
