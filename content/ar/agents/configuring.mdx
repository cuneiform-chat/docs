# خيارات الإعداد

import { Callout } from 'nextra/components'

دليل مفصّل لجميع خيارات إعداد الـ Agent.

## بنية الصفحة

تحتوي صفحة تعديل الـ Agent على ثلاث علامات تبويب:

| علامة التبويب | الغرض |
|-----|---------|
| **Configuration** | الإعدادات الأساسية (الحالة، الاسم، الشخصية، الـ LLM، الرسائل) |
| **Knowledge Access** | التحكم في المستندات التي يمكن للـ Agent استخدامها |
| **Integrations** | الربط بالقنوات الخارجية (Telegram وDiscord، إلخ) |

## علامة تبويب Configuration

### الحالة

تحكَّم في توفّر الـ Agent:

| الحالة | Playground | Integrations | ملاحظات |
|--------|------------|--------------|-------|
| **Testing** | ✅ مفعّل | ❌ معطّل | الوضع الافتراضي للـ Agents الجديدة. اختبره قبل الإطلاق. |
| **Active** | ✅ مفعّل | ✅ مفعّل | جاهز للاستخدام في الإنتاج. |
| **Inactive** | ❌ معطّل | ❌ معطّل | معطّل مؤقتًا. |
| **Archived** | ❌ معطّل | ❌ معطّل | مخفيّ من القائمة الرئيسية. |

<Callout type="warning">
  إذا كانت للـ Agent عمليات دمج مرتبطة وغيّرت حالته من Active إلى حالة أخرى، فسترى مربّع تأكيد يحذّر من أن الـ Agent سيتوقّف عن الردّ على القنوات المرتبطة.
</Callout>

### الإعدادات الأساسية

- **Name** — يحدّد الـ Agent في لوحة التحكم
- **Description** — ملاحظات داخلية عن غرض الـ Agent

### ضبط الـ LLM

تحكَّم في نموذج الذكاء الاصطناعي الذي يشغّل الـ Agent.

**الوضع الافتراضي (مفتاح Advanced مُطفأ):**
- يستخدم القيم الافتراضية لباقة مؤسستك
- يعرض مربّع معلومات يوضّح أن القيم الافتراضية للباقة قيد الاستخدام
- مُوصى به لمعظم حالات الاستخدام

**الوضع المتقدّم (مفتاح Advanced مُفعَّل):**

| الإعداد | الوصف |
|---------|-------------|
| **Model** | اختر من بين نماذج الذكاء الاصطناعي المتاحة حسب باقتك |
| **Temperature** | يتحكّم في إبداع الردّ (0.0–2.0) |

#### دليل Temperature

| القيمة | السلوك |
|-------|----------|
| 0.0 - 0.3 | ردود مركّزة وحتمية |
| 0.4 - 0.7 | توازن بين الإبداع والاتساق |
| 0.8 - 2.0 | ردود أكثر إبداعًا وتنوّعًا |

**التوصية:** ابدأ بـ 0.3–0.5 للأسئلة والأجوبة الواقعية المستندة إلى المستندات.

#### Show Document References

يتحكّم هذا المفتاح (الظاهر دائمًا بصرف النظر عن الوضع المتقدّم) في ما إذا كان الـ Agent يضمّن استشهادات المصادر في الردود:

- **Off** (الوضع الافتراضي) — لا تذكر الردود المستندات المصدرية
- **On** — تتضمّن الردود إشارات إلى المستندات المصدرية

<Callout type="important">
  فعّل استشهادات المستندات لحالات الاستخدام التي تتطلّب الشفافية، مثل المجالات القانونية أو الامتثال أو المحتوى الداخلي حيث يحتاج المستخدمون إلى التحقّق من المصادر.
</Callout>

### دعم اللغات

يكشف الـ Agent تلقائيًا لغة كل رسالة من المستخدم ويردّ بها — دون أي إعداد يدوي. ويُدعَم 176 لغة جاهزة، بما في ذلك العربية والفرنسية والألمانية والإسبانية والتركية والصينية واليابانية وغيرها.

### شخصية الـ Agent

التعليمات التي تتحكّم في سلوك الـ Agent. راجع [شخصيات الـ Agent](/agents/agent-personas) لأفضل الممارسات.

**الإجراءات المتاحة:**
- **Generate** — يفتح [منشئ شخصيات الـ Agent](/agents/persona-builder)
- **Edit** — يفتح لوحة منزلقة لكتابة الشخصية أو تعديلها مباشرة

انقر على منطقة نصّ الشخصية لفتح لوحة التعديل.

**Platform Rules Box:**
انقر لعرض قواعد الموثوقية للمنصة المطبّقة تلقائيًا على جميع الـ Agents:
- لا اختلاق — لن تخترع وقائع
- الإقرار بالنقص — تقول "لا أعرف" عند الاقتضاء
- مقاومة التخمين — لن تخمّن المعلومات الناقصة
- لا انتحال للمهن — لن تتصرّف كمحامين أو أطباء، إلخ.
- تصحيح المقدّمات الخاطئة — تنبّه إلى الافتراضات غير الصحيحة
- حجب المحتوى الضار — ترفض الطلبات غير اللائقة

<Callout type="info">
  تضمن قواعد المنصة أن تتصرّف جميع الـ Agents بموثوقية وأمان. ولا يمكن تعطيلها أو تعديلها.
</Callout>

## علامة تبويب Knowledge Access

تحكَّم في المستندات التي يمكن للـ Agent الوصول إليها عند الردّ على الاستفسارات.

### أوضاع الوصول

| الوضع | السلوك | متى تستخدمه |
|------|----------|-------------|
| **Exclude Mode** | يصل الـ Agent إلى جميع المستندات باستثناء المحدّدة | إخفاء المستندات الحسّاسة مع السماح بالوصول إلى كل ما عداها |
| **Include Mode** | يصل الـ Agent فقط إلى العناصر المحدّدة | قصر الـ Agent على مجموعة محدّدة من المستندات |

### خيارات التحديد

اضبط الوصول بدقّة باستخدام أنواع تحديد متعدّدة:

- **Folders** — اختر مجلدات كاملة وجميع المستندات بداخلها
- **Tags** — رشّح المستندات حسب الوسوم المسندة إليها
- **Individual Documents** — ضمّن أو استبعد مستندات محدّدة ضمن المجلدات المختارة

### معاينة الوصول

تعرض لوحة المعاينة الوصول الفعلي إلى المستندات بناءً على تحديداتك الحالية. استخدمها للتحقّق من إعدادك قبل الحفظ.

<Callout type="info">
  ابدأ بـ **Exclude Mode** إذا كنت تريد وصولًا واسعًا مع قيود محدّدة. استخدم **Include Mode** عندما تحتاج إلى تحكّم دقيق في المستندات التي يمكن للـ Agent الإشارة إليها بالضبط.
</Callout>

## علامة تبويب Integrations

اربط الـ Agent بقنوات التواصل.

تعرض علامة التبويب هذه خيارات الدمج المتاحة للـ Agent. يمكنك ربط قنوات مثل:
- Telegram
- Discord
- Slack
- WhatsApp
- Meta (Facebook Messenger)
- وغيرها (حسب باقتك)

راجع [توثيق Integrations](/integrations) للحصول على أدلّة إعداد مفصّلة لكل قناة.

## Human Handoff

فعّل التحويل إلى الدردشة المباشرة كي يتمكّن الـ Agent من نقل المحادثات إلى إنسان حقيقي عندما يطلب المستخدمون ذلك.

**كيفية التفعيل:**

1. في علامة تبويب **Configuration**، مرّر إلى قسم **Human Handoff**
2. فعّل **Enable Human Handoff**
3. اضبط الرسائل:
   - **Handoff Message** — تُعرَض للمستخدم عند بدء التحويل
   - **Accept Message** — تُرسَل تلقائيًا عندما يقبل عضو بشري المحادثة
   - **Resolve Message** — تُعرَض عندما ينهي العضو البشري المحادثة
   - **Max Wait Time** — انتهاء تلقائي إذا لم يقبل أي عضو (5 أو 15 أو 30 أو 60 أو 120 دقيقة؛ الافتراضي: 30 دقيقة)
4. انقر على **Save Changes**

عندما يطلب مستخدم التحدّث إلى إنسان، يُنشئ الذكاء الاصطناعي طلب تحويل يظهر في صفحة **Inbox**. يقبله عضو في الفريق، ويتحادث مع المستخدم على قناته، ثم يحلّ الطلب عند الانتهاء.

<Callout type="info">
  يتوفّر Human Handoff في جميع الباقات. فعّله لكل Agent على حدة في علامة تبويب Configuration.
</Callout>

## اختبار الـ Agent

قبل حفظ التغييرات، يمكنك اختبار الـ Agent:

1. انقر على زر **Test Agent** في أسفل النموذج
2. تنزلق لوحة الـ Playground لتُفتَح
3. أجرِ محادثة اختبارية مع الـ Agent
4. أغلق الـ Playground عند الانتهاء

<Callout type="info">
  يكون زر Test Agent معطّلًا عندما تكون حالة الـ Agent هي Archived أو Inactive. غيّر الحالة إلى Active أو Testing لتمكين الاختبار.
</Callout>

## حفظ التغييرات

| الزر | الإجراء |
|--------|--------|
| **Save Changes** | حفظ جميع التعديلات |
| **Test Agent** | فتح الـ Playground للاختبار |

لتجاهُل التغييرات، انتقل بعيدًا باستخدام زر الرجوع أو التنقّل في الشريط الجانبي.

**ما الذي يُحفَظ:**
- لا تُحدَّث إلا الحقول المتغيّرة
- سترى "No changes to save" إذا لم يتغيّر شيء
- تظهر رسائل النجاح أو الخطأ بعد الحفظ

**معالجة الحفظ الجزئي:**
إذا حُفظت بعض التغييرات وفشلت أخرى، فستُخطَر بالأقسام التي فشلت وستُحدَّث الصفحة لتعرض الحالة الراهنة.

<Callout type="info">
  تسري تغييرات إعدادات الـ Agent فور الحفظ. اختبر في الـ Playground بعد إجراء التغييرات.
</Callout>
