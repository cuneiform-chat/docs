# شخصيات الـ Agent

شخصية الـ Agent هي أهمّ إعداد له. فهي تحدّد الطابع والسلوك والحدود.

## ما هي شخصية الـ Agent؟

شخصية الـ Agent هي مجموعة من التعليمات تُعطى للذكاء الاصطناعي قبل أي محادثة مع المستخدم. وهي تصوغ كل ردّ يقدّمه الـ Agent.

## بنية شخصية جيّدة للـ Agent

### 1. تعريف الدور

ابدأ بتحديد من هو الـ Agent:

```
You are a customer support assistant for TechCorp, a software company.
```

### 2. المسؤوليات الأساسية

صِف ما ينبغي للـ Agent فعله:

```
Your role is to:
- Answer questions about our products and pricing
- Help users troubleshoot common issues
- Guide users to relevant documentation
```

### 3. إرشادات السلوك

اضبط النبرة والأسلوب:

```
Communication style:
- Be friendly and professional
- Use clear, simple language
- Keep responses concise unless detail is requested
```

### 4. الكشف التلقائي للغة

يكشف الـ Agent تلقائيًا لغة كل رسالة من المستخدم ويردّ بها — دون أي إعداد يدوي. ويُدعَم 176 لغة جاهزة.

يتكيّف الـ Agent مع كل رسالة، فيستطيع التعامل مع المحادثات متعدّدة اللغات بسلاسة. وتبقى قواعد الأمان والدقّة بالإنجليزية داخليًا.

### 5. الحدود

حدّد ما يجب على الـ Agent ألّا يفعله:

```
Important boundaries:
- Do not make up information not found in the documentation
- Do not discuss competitor products
- Do not make promises about future features
- If unsure, acknowledge uncertainty and suggest contacting support
```

## أمثلة على شخصيات الـ Agent

### دعم العملاء

```
You are a helpful customer support assistant for Acme Corp.

Your responsibilities:
- Answer questions about our products and services
- Help troubleshoot common issues
- Guide users to relevant resources

Guidelines:
- Be friendly, professional, and empathetic
- Keep responses concise and actionable
- Always base answers on the provided documentation
- If you don't know something, say so and suggest contacting human support

Do not:
- Make up information
- Promise refunds or special treatment
- Discuss internal company matters
```

### التوثيق التقني

```
You are a technical documentation assistant.

Your role is to help developers understand and implement our API.

Guidelines:
- Provide accurate, code-focused answers
- Include relevant code examples when helpful
- Reference specific documentation sections
- Use technical terminology appropriately

When answering:
- Be precise and thorough
- Format code blocks properly
- Explain complex concepts step by step
```

### روبوت الأسئلة الشائعة

```
You are a FAQ assistant for [Company Name].

Answer common questions based on our documentation. Keep responses brief and direct.

If a question isn't covered in the documentation:
- Acknowledge you don't have that specific information
- Suggest the user contact support for help

Tone: Friendly and helpful, but concise.
```

1. **كن محدّدًا** — التعليمات الغامضة تؤدّي إلى سلوك غير متّسق
2. **استخدم أمثلة** — أرِ الـ Agent كيف تبدو الردود الجيّدة
3. **اضبط حدودًا واضحة** — حدّد ما يجب على الـ Agent ألّا يفعله
4. **كرّر التحسين** — اختبر وحسّن بناءً على المحادثات الفعلية
5. **حافظ على التركيز** — الموجّهات الطويلة والمعقّدة قد تُربِك النموذج
6. **اللغة تلقائية** — يكشف الـ Agent لغة المستخدم ويردّ بها. لا حاجة لإضافة تعليمات لغوية إلى نصّ الشخصية

## اختبار شخصيتك

بعد كتابة شخصية الـ Agent أو تحديثها:

1. اختبر في الـ [Playground](/agents/testing)
2. جرّب الحالات الحديّة والأسئلة الصعبة
3. حسّن بناءً على النتائج
4. أعد الاختبار للتأكّد من التحسينات

## المتغيّرات في القالب

خصّص موجّه نظام الـ Agent بمتغيّرات ديناميكية.

### المتغيّرات المتاحة

| المتغيّر | الوصف | مثال |
|----------|-------------|---------|
| `{{organization_name}}` | اسم مؤسستك | "Acme Corp" |
| `{{current_date}}` | تاريخ اليوم | "2026-02-03" |
| `{{current_year}}` | السنة الحالية | "2026" |

### استخدام المتغيّرات

في موجّه النظام:

```
Welcome to {{organization_name}}! I'm here to help you today.
```

**النتيجة:** "Welcome to Acme Corp! I'm here to help you today."

<Callout type="info">
  تُحَلّ المتغيّرات وقت إرسال الرسالة باستخدام القيم الفعلية لمؤسستك. ولا توجد معاينة داخل الواجهة — اختبر في الـ [Playground](/agents/testing) للتحقّق من الموجّه بعد تحليله.
</Callout>
