# إنشاء الـ Agents

import { Callout } from 'nextra/components'

تعرّف على كيفية إنشاء Agents جديدة في Cuneiform Chat.

## البدء

1. انتقل إلى **Agents** في الشريط الجانبي
2. انقر على زر **Create Agent** في أعلى اليمين
3. املأ أقسام النموذج أدناه

## المعلومات الأساسية

يلتقط هذا القسم التفاصيل الجوهرية عن الـ Agent.

| الحقل | مطلوب | الوصف |
|-------|----------|-------------|
| **Name** | نعم | اسم للـ Agent (مثل "Customer Support Agent"). بحدّ أقصى 100 حرف. |
| **Description** | لا | وصف موجز لما يفعله هذا الـ Agent. بحدّ أقصى 500 حرف. |

**نصائح:**
- اختر اسمًا وصفيًا يدلّ على غرض الـ Agent
- يساعدك الوصف وفريقك على فهم دور الـ Agent

## شخصية الـ Agent

تحدّد شخصية الـ Agent كيف يتصرّف ويردّ من خلال موجّه نظام (system prompt).

**العناصر الأساسية:**

- **Platform Rules Box** — تعرض قواعد الأمان المدمجة المطبّقة تلقائيًا (انقر لعرض التفاصيل)
- **Generate Button** — يفتح [منشئ شخصيات الـ Agent](/agents/persona-builder) لمساعدتك على إنشاء شخصيتك
- **Edit Button** — يفتح لوحة لكتابة الشخصية أو تعديلها يدويًا

### قواعد المنصة

تُطبَّق ضوابط الأمان هذه تلقائيًا على جميع الـ Agents:

- **لا اختلاق** — لن تخترع وقائع غير موجودة في محتواك
- **الإقرار بالنقص** — تقول "لا أعرف" عند الاقتضاء
- **مقاومة التخمين** — لن تخمّن المعلومات الناقصة
- **لا انتحال للمهن** — لن تتصرّف كمحامين أو أطباء، إلخ.
- **تصحيح المقدّمات الخاطئة** — تنبّه إلى الافتراضات غير الصحيحة
- **حجب المحتوى الضار** — ترفض الطلبات غير اللائقة

<Callout type="info">
  تضمن قواعد المنصة أن تتصرّف جميع الـ Agents بموثوقية وأمان. ولا يمكن تعطيلها. راجع [منشئ شخصيات الـ Agent](/agents/persona-builder#platform-rules) للتفاصيل.
</Callout>

### مثال سريع على الشخصية

```
You are a helpful assistant for [Your Company].
Answer questions based on the provided documentation.
Be concise and friendly.
```

راجع [شخصيات الـ Agent](/agents/agent-personas) للحصول على إرشادات مفصّلة حول كتابة شخصيات فعّالة.

## دعم اللغات

يكشف الـ Agent تلقائيًا لغة كل رسالة من المستخدم ويردّ باللغة نفسها — دون أي إعداد. ويُدعَم 176 لغة جاهزة. راجع [شخصيات الـ Agent — كشف اللغة](/agents/agent-personas#4-automatic-language-detection) للتفاصيل.

## ضبط الـ LLM

يتحكّم هذا القسم في إعدادات نموذج الذكاء الاصطناعي.

**الوضع الافتراضي:**

افتراضيًا، تستخدم إعدادات الـ LLM القيم الافتراضية لباقة مؤسستك. سترى مربّع معلومات يعرض "Using tier defaults". وهذا مُوصى به لمعظم حالات الاستخدام.

**الوضع المتقدّم:**

فعّل **Advanced** للتخصيص:

| الإعداد | الوصف |
|---------|-------------|
| **Model** | اختر من بين نماذج الذكاء الاصطناعي المتاحة حسب باقتك |
| **Temperature** | يتحكّم في إبداع الردّ (أقل = أكثر اتساقًا، أعلى = أكثر إبداعًا) |

**Show Document References:**

يتحكّم هذا المفتاح (الظاهر دائمًا) في ما إذا كان الـ Agent يضمّن استشهادات المصادر في الردود:
- **Off** (الوضع الافتراضي) — لا تذكر الردود المستندات المصدرية
- **On** — تتضمّن الردود إشارات إلى المستندات المصدرية (مفيد للأغراض القانونية/الامتثال)

## التحكم في الوصول إلى المعرفة

تحكَّم في المستندات التي يمكن للـ Agent الوصول إليها عند الإجابة عن الأسئلة.

| الوضع | السلوك | متى تستخدمه |
|------|----------|-------------|
| **Exclude Mode** | يصل الـ Agent إلى جميع المستندات باستثناء المحدّدة | إخفاء المستندات الحسّاسة عن الـ Agent |
| **Include Mode** | يصل الـ Agent فقط إلى العناصر المحدّدة | قصر الـ Agent على مجموعة معرفة محدّدة |

**عند استخدام Include Mode:**
- اختر مجلدات محدّدة يمكن للـ Agent الوصول إليها
- اختر وسومًا محدّدة يمكن للـ Agent الوصول إليها
- اختر مستندات فردية يمكن للـ Agent الوصول إليها

سيستخدم الـ Agent المعلومات من المصادر المحدّدة فقط عند الردّ.

<Callout type="important">
  ابدأ بـ Exclude Mode (وصول كامل إلى المعرفة) ما لم تكن بحاجة إلى إخفاء مستندات محدّدة. يمكنك دائمًا تقييد الوصول لاحقًا.
</Callout>

## إجراءات النموذج

في أسفل النموذج:

| الزر | الإجراء |
|--------|--------|
| **Cancel** | تجاهُل التغييرات والعودة |
| **Reset** | مسح جميع الحقول والبدء من جديد (يعرض مربّع تأكيد) |
| **Create Agent** | حفظ الـ Agent وفتح صفحة تعديله |

<Callout type="info">
  تُحفظ مسوّدتك تلقائيًا أثناء العمل. إذا غادرت ثم عُدت، فستُستعاد تقدّمك.
</Callout>

## بعد الإنشاء

عند النقر على **Create Agent**:

1. يُنشَأ الـ Agent بحالة **Testing**
2. تنتقل إلى صفحة تعديل الـ Agent
3. اختبر الـ Agent باستخدام الـ Playground
4. اربط عمليات الدمج عندما تكون جاهزًا للإطلاق
5. غيّر الحالة إلى **Active** عند الجاهزية

<Callout type="info">
  تبدأ الـ Agents الجديدة بحالة **Testing**. يمكنك الاختبار في الـ Playground، لكن عمليات دمج القنوات معطّلة حتى تفعّل الـ Agent.
</Callout>

## إدارة الـ Agents

من صفحة Agents، يمكنك:

- **Edit** — انقر على أي Agent لتعديل إعداداته
- **Test** — انقر على **Test** في بطاقة Agent لفتح الـ Playground
- **Change Status** — اضبطها على Testing أو Active أو Inactive أو Archived

راجع [خيارات الإعداد](/agents/configuring) للاطّلاع على تفاصيل جميع إعدادات الـ Agent.
