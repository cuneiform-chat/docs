# منشئ شخصيات الـ Agent

import { Callout } from 'nextra/components'

أنشئ شخصيات احترافية للـ Agent في ثوانٍ عبر تحديد الخصائص.

<Callout type="info">
  يساعدك منشئ شخصيات الـ Agent على إنشاء شخصيات فعّالة دون كتابة الموجّهات من الصفر.
</Callout>

## البدء

1. انتقل إلى **Agents** وأنشئ Agent أو عدّله
2. انقر على **Generate** بجوار حقل شخصية الـ Agent
3. تنزلق لوحة منشئ شخصيات الـ Agent لتُفتَح بثلاث علامات تبويب

## علامات تبويب المنشئ

### Custom Build

أنشئ شخصية فريدة عبر تحديد خصائص عبر 5 فئات:

| الفئة | ما الذي تتحكّم فيه |
|----------|------------------|
| **Role & Identity** | الوظيفة الأساسية للـ Agent (دعم العملاء، المبيعات، الدعم التقني، الموارد البشرية، إلخ) |
| **Communication Style** | الرسمية والنبرة والإسهاب والمستوى التقني |
| **Response Behavior** | التنسيق (حواري مقابل نقاط)، والمبادرة، والتعامل مع الأسئلة |
| **Operational Boundaries** | مدى التزام الـ Agent بالموضوع، وميله إلى التصعيد |
| **Knowledge Integration** | أسلوب الاستشهاد، وكيفية تعامل الـ Agent مع عدم اليقين |

**التنقّل بين الفئات:**
- انقر على عنوان أي فئة لتوسيعها أو طيّها
- تحتوي كل فئة على حقول متعدّدة بخيارات منسدلة
- تُبرَز الخيارات المحدّدة

**زر Reset:**
انقر على **Reset** في قسم Custom Build لاستعادة جميع القيم الافتراضية.

#### خيارات Role & Identity

اختر الوظيفة الأساسية للـ Agent:
- Customer Support
- Sales
- Technical Support
- HR / Internal
- Education
- Healthcare Information
- Legal Information
- Finance / Accounting
- General Assistant

#### Communication Style

اضبط بدقّة كيفية تواصل الـ Agent:

| الإعداد | الخيارات |
|---------|---------|
| **Formality** | Casual, Friendly Professional, Formal Professional, Corporate Formal |
| **Tone** | Empathetic & Supportive, Confident & Authoritative, Calm & Reassuring, Enthusiastic & Engaging, Neutral & Objective |
| **Verbosity** | Concise, Balanced, Comprehensive |
| **Technical Level** | Layperson, Mixed, Technical |

#### خيارات Tone

إعدادات النبرة المتاحة مسبقًا:
- Empathetic & Supportive
- Confident & Authoritative
- Calm & Reassuring
- Enthusiastic & Engaging
- Neutral & Objective

#### مستويات التفصيل

- **Concise** — ردود موجزة ومباشرة
- **Balanced** — تفصيل معتدل مع شروح واضحة
- **Comprehensive** — ردود شاملة ومفصّلة

#### Response Behavior

تحكَّم في كيفية بناء الردود:
- **Format** — Conversational أو Step-by-Step Guides أو Technical Documentation
- **Proactivity** — ما إذا كان الـ Agent يقترح مواضيع ذات صلة
- **Question Handling** — كيف يطلب الـ Agent التوضيح

#### Operational Boundaries

اضبط ضوابط الـ Agent:
- **Scope Strictness** — مدى التزام الـ Agent بالمواضيع الموثّقة
- **Escalation** — متى يقترح التواصل مع الدعم البشري
- **Out-of-scope Handling** — كيفية الردّ على الأسئلة خارج الموضوع

#### Knowledge Integration

اضبط كيفية استخدام الـ Agent لمستنداتك:
- **Citation Style** — ما إذا كان سيشير إلى مستندات محدّدة
- **Uncertainty Handling** — كيفية الردّ عند عدم اليقين

### Use Preset

حمّل شخصيات مُعدّة مسبقًا لحالات الاستخدام الشائعة:

- **System Templates** — إعدادات مسبقة توفّرها المنصة ومُحسَّنة لأدوار محدّدة
- **My Templates** — إعدادات مسبقة حفظها مسؤولو مؤسستك

**استخدام إعداد مسبق:**
1. انقر على علامة تبويب **Use Preset**
2. تصفّح الإعدادات المسبقة المتاحة
3. انقر على إعداد مسبق لتحديده
4. يُحمَّل الإعداد المسبق في علامة تبويب Custom Build
5. عدّل أي خصائص عند الحاجة
6. انقر على **Generate Persona**

### Platform Rules

اعرض الضوابط للقراءة فقط المطبّقة تلقائيًا على جميع الـ Agents:

- **لا اختلاق** — لن تخترع وقائع أو أرقامًا أو تواريخ غير موجودة في محتواك
- **الإقرار بالنقص** — تقول "ليست لديّ هذه المعلومة" بدلًا من التخمين
- **مقاومة التخمين** — لن تقدّر القيم الناقصة حتى لو طُلب منها
- **لا انتحال للمهن** — لن تتقمّص دور المحامين أو الأطباء أو المحاسبين القانونيين أو المستشارين الماليين
- **تصحيح المقدّمات الخاطئة** — تنبّه إلى الافتراضات غير الصحيحة قبل الإجابة
- **حجب المحتوى الضار** — ترفض محتوى إيذاء النفس أو المحتوى الصريح أو الاحتيالي

<Callout type="info">
  تضمن قواعد المنصة أن تتصرّف جميع الـ Agents بموثوقية وأمان، بصرف النظر عن إعداد الشخصية. ولا يمكن تعطيلها.
</Callout>

## توليد شخصية

**قبل التوليد:**
تعرض اللوحة خيارات إعدادك بعرض كامل.

**زر Generate:**
عند وجودك في علامة تبويب Custom Build:
1. انقر على **Generate Persona** في الأسفل
2. تظهر حالة تحميل أثناء التوليد
3. يستغرق الأمر بضع ثوانٍ

**بعد التوليد:**
يتغيّر تخطيط اللوحة إلى عرض مقسوم:
- **الجانب الأيسر:** خيارات إعدادك
- **الجانب الأيمن:** معاينة الموجّه المُولَّد

**ميزات لوحة المعاينة:**
- النصّ الكامل لموجّه النظام المُولَّد
- قابل للتعديل — يمكنك تعديل النصّ مباشرة
- يُعرَض عدد الأحرف في الأسفل

## بعد التوليد

بمجرّد حصولك على شخصية مُولَّدة، تتوفّر لديك عدّة خيارات:

### Regenerate

انقر على **Regenerate** لإنشاء نسخة جديدة بالإعدادات نفسها. ينتج عن كل عملية توليد نتائج مختلفة قليلًا.

### تعديل الموجّه

انقر داخل لوحة المعاينة لتعديل النصّ المُولَّد مباشرة. أجرِ أي تعديلات لازمة لحالة استخدامك المحدّدة.

### Save as Preset

انقر على **Save as Preset** لحفظ إعدادك لإعادة الاستخدام:
1. يُفتَح مربّع حوار يطلب اسم الإعداد المسبق
2. أدخِل اسمًا وصفيًا
3. يُحفَظ الإعداد المسبق في مؤسستك ضمن **My Templates**

<Callout type="important">
  تتوفّر الإعدادات المسبقة المحفوظة لجميع المسؤولين في مؤسستك. استخدمها للحفاظ على شخصيات متّسقة للـ Agents عبر عدّة Agents.
</Callout>

### Apply to Agent

انقر على **Apply to Agent** لاستخدام هذه الشخصية:
1. يُدرَج الموجّه في حقل موجّه نظام الـ Agent
2. يُغلَق المنشئ
3. تابع ضبط إعدادات الـ Agent الأخرى

## أفضل الممارسات

- **ابدأ بإعداد مسبق** — استخدم قوالب النظام كنقطة بداية، ثم خصّص
- **طابِق الدور مع الغرض** — اختر دورًا يتماشى مع الوظيفة الفعلية للـ Agent
- **وازِن الإسهاب** — الإيجاز أفضل للأسئلة السريعة، والتفصيل للمواضيع المعقّدة
- **اختبر بعد التوليد** — اختبر الـ Agent دائمًا في الـ Playground بعد تطبيق شخصية جديدة
- **كرّر التوليد** — أعد التوليد بإعدادات مختلفة إذا لم تكن النتائج مناسبة تمامًا
- **حافظ على التركيز** — الموجّهات المفرطة التعقيد قد تُربِك الـ Agent
