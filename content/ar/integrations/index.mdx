# عمليات الدمج

انشر الـ Agents الخاصة بك على قنوات متعددة وتواصل مع المستخدمين أينما كانوا.

## القنوات المتاحة

| القناة | الوصف | الأنسب لـ |
|---------|-------------|----------|
| [Telegram](/integrations/telegram) | روبوت Telegram | مستخدمو الأجهزة المحمولة، المجتمعات |
| [Discord](/integrations/discord) | روبوت Discord مع أوامر slash | الألعاب، مجتمعات المطورين |
| [Slack](/integrations/slack) | تطبيق Slack | مساحات عمل الفرق |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | التواصل مع العملاء |
| [Google Chat](/integrations/google-chat) | تطبيق Google Workspace | فرق المؤسسات |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | الجمهور الاستهلاكي |
| [Website Widget](/integrations/website-widget) | أداة دردشة قابلة للتضمين | دعم العملاء، أي موقع إلكتروني |

## كيف تعمل عمليات الدمج

1. **الإعداد** — قم بإعداد عملية الدمج للقناة التي اخترتها
2. **الربط** — اربط الـ Agent الخاص بك بالقناة
3. **النشر** — يصبح الـ Agent الخاص بك متاحًا للمستخدمين
4. **المراقبة** — تتبّع المحادثات والاستخدام

## النشر متعدد القنوات

يمكن نشر Agent واحد على قنوات متعددة في وقت واحد:

- المحتوى نفسه عبر جميع القنوات
- ردود متّسقة في كل مكان
- سجلّ محادثات مركزي
- تحليلات موحّدة

## ميزات خاصة بكل قناة

تتمتّع كل قناة بقدرات فريدة:

- **Telegram** — رسائل غنية، لوحات مفاتيح مدمجة (inline keyboards)
- **Discord** — أوامر slash، دمج مع الخوادم
- **Slack** — تطبيقات مساحة العمل، ردود في القنوات
- **WhatsApp** — مراسلة الأعمال، وسائط غنية
- **Google Chat** — دمج مع Google Workspace، دعم المساحات (spaces)، أسئلة وأجوبة حول المستندات + قاعدة معرفة المساحة
- **Meta (Facebook)** — دمج مع Messenger، مراسلة الصفحات
- **Website Widget** — دردشة قابلة للتضمين، مظهر قابل للتخصيص، قائمة نطاقات مسموح بها

## المتطلبات

قبل إعداد عمليات الدمج:

1. ✅ أنشئ Agent واحدًا على الأقل
2. ✅ ارفع المستندات إلى المحتوى الخاص بك
3. ✅ اختبر الـ Agent الخاص بك في الـ Playground

قد تتطلّب كل قناة متطلبات إضافية (رموز الروبوت، بيانات اعتماد التطبيق، إلخ) موضّحة في أدلّتها الخاصة.
