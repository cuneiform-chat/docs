# تكامل WooCommerce

اربط متجر **WooCommerce** المستضاف ذاتيًا الخاص بك حتى يتمكن الـ AI agent من الإجابة عن أسئلة المنتجات، والبحث عن طلب أحد المتسوقين، والتوصية بالعناصر المتوفرة في المخزون، وإرسال تحديثات حالة الطلب — كل ذلك انطلاقًا من بيانات الكتالوج والطلبات الحقيقية والحيّة لديك.

## نظرة عامة

يربط تكامل WooCommerce متجرك المستضاف ذاتيًا بالـ AI agents لديك عبر WooCommerce REST API. WooCommerce هو الواجهة الخلفية للتجارة لديك؛ والـ agent من Cuneiform هو طبقة المحادثة عبر كل قناة تنشره فيها. بعد الربط، يمكن للـ agent أن:

- **أسئلة الكتالوج** — يجيب انطلاقًا من منتجاتك ومتغيّراتك وأسعارك وتوفّرك الحالي الحقيقي
- **البحث عن الطلب (WISMO)** — يتيح للمتسوقين معرفة "أين طلبي؟" عبر رقم الطلب مع البريد الإلكتروني أو الهاتف المسجّل على الطلب
- **التوصيات** — يقترح منتجات متوفرة فعلًا **في المخزون**
- **تحديثات حالة الطلب** — يرسل للمتسوقين الذين يوافقون تحديثات الشحن في المحادثة نفسها
- **مخزون حيّ** — يقرأ دائمًا الأسعار والمخزون المحدّثة لحظة الإجابة
- **التحويل إلى الدفع** — يوجّه المتسوق المستعد للشراء إلى صفحة دفع WooCommerce الخاصة بك

## المتطلبات الأساسية

- **متجر WooCommerce مستضاف ذاتيًا** تديره
- **رابط متجرك** (على سبيل المثال، `https://your-store.com`)
- **agent واحد** على الأقل ليصبح agent التجارة لديك (يمكنك إنشاء واحد أثناء عملية الربط)

لست بحاجة إلى تثبيت أي إضافة (plugin) أو كتابة أي شيفرة. عملية الربط القياسية هي موافقة لمرة واحدة؛ ولا تحتاج إلى consumer key/secret للقراءة فقط إلا إذا كان متجرك خلف جدار حماية.

## خطوات الإعداد

### 1. افتح Commerce

في لوحة الإدارة، انتقل إلى **Commerce** واختر **WooCommerce**. Commerce هو الموطن الوحيد للتكامل — بطاقة الربط، و**Product Library** الخاصة بك، و**Settings**، و**Analytics** كلها هنا.

### 2. اربط متجرك

أدخل رابط متجرك وانقر **Connect**. ستوافق على تفويض لمرة واحدة لـ WooCommerce REST API على متجرك، ثم تعود إلى **Commerce**. إذا كان متجرك خلف جدار حماية يحجب إعادة التوجيه، فوسّع **Enter API keys manually** والصق consumer key وsecret **للقراءة فقط** (يتم إنشاؤهما في WooCommerce → Settings → Advanced → REST API).

### 3. اختر agent التجارة

التجارة **اختيارية لكل agent** و**معطّلة افتراضيًا**. عند الربط، اختر الـ agent **الوحيد** الذي سيصبح agent التجارة لديك — agent نشطًا موجودًا أو agent جديدًا. هذا الـ agent وحده يحصل على أدوات WooCommerce؛ ولا تتأثر بقية الـ agents. يمكنك تغيير ذلك لاحقًا من **Commerce → Settings**.

### 4. اترك الكتالوج يتزامن

يبدأ الربط استيرادًا لمرة واحدة لمنتجاتك ومتغيّراتها وأسعارها وصورها ومخزونها. بعد ذلك، تتزامن التغييرات تلقائيًا، وتلتقط عملية مطابقة يومية أي شيء فائت.

### 5. جرّبه

افتح agent التجارة واطرح سؤالًا عن الكتالوج ("ما المقاسات المتوفرة لهذا؟"، "هل الأزرق متوفر في المخزون؟") أو ابحث عن طلب ("أين طلبي رقم 1001؟"). يجيب الـ agent انطلاقًا من بيانات WooCommerce الحيّة لديك.

## كيف يعمل

```
يطرح المتسوق سؤالًا
  → يقرأ agent التجارة كتالوجك وطلباتك الحيّة في WooCommerce (قراءة فقط)
  → يجيب عن المنتجات والمخزون وحالة الطلب
  → يحوّل إلى صفحة دفع WooCommerce الخاصة بك للشراء
```

يقرأ الـ agent منتجاتك وأسعارك ومخزونك وطلباتك مباشرةً عبر WooCommerce REST API ويحافظ على تحديث الأسعار والمخزون — دون نسخ كتالوجك ولصقه في قاعدة معرفة.

## الميزات

### قراءة فقط بحكم التصميم

لا يقوم التكامل إلا **بالقراءة** من WooCommerce (المنتجات، المخزون، الطلبات). لا يغيّر أبدًا كتالوجك أو مخزونك، ولا يستقبل المدفوعات أبدًا، ولا ينشئ الطلبات أبدًا. يتم الدفع دائمًا على متجر WooCommerce الخاص بك.

### متجر واحد، agent تجارة واحد

تربط **متجر WooCommerce واحدًا لكل مؤسسة** وتمنح التجارة لـ **agent واحد بالضبط** عند الربط. تبقى بقية الـ agents غير تجارية ما لم تفعّلها من **Commerce → Settings**.

### بحث عن الطلب مُتحقَّق منه

لا يرى المتسوقون تفاصيل الطلب إلا بعد تقديم رقم الطلب الدقيق **و** البريد الإلكتروني أو الهاتف المسجّل على الطلب. تُرجِع جهة اتصال خاطئة وطلب غير موجود الرد نفسه "تعذّر العثور عليه" دون تفاصيل — وهو تحصين ضد التعداد يحمي عملاءك.

### كتالوج ومخزون حيّان

يقرأ الـ agent الأسعار والمخزون المحدّثة لحظة الإجابة، لذا تقتصر التوصيات على العناصر المتوفرة فعلًا في المخزون. تصلح عملية المطابقة اليومية أي شيء يفوت التزامن.

### تحديثات حالة الطلب بالاشتراك

بعد أن يتحقق المتسوق من طلبه في المحادثة، يمكنه الاشتراك لتلقّي تحديثات الشحن على قناة مدعومة. لا تُرسَل التحديثات إلا عندما تفعّلها في **Commerce → Settings → Notifications** ويشترك المتسوق.

## الأمان

- **وصول للقراءة فقط** — لا يمكن للتكامل إنشاء أي شيء في متجرك أو تعديله أو حذفه، ولا تغيير المخزون، ولا استقبال المدفوعات
- **عزل حسب المؤسسة** — كتالوجك وطلباتك ملك لمؤسستك وحدها ولا تظهر أبدًا لمستأجرين آخرين
- **بحث عن الطلب مُتحقَّق منه** — تتطلب تفاصيل الطلب رقم الطلب الدقيق مع البريد الإلكتروني أو الهاتف المطابق (ضد التعداد)
- **إشعارات بالاشتراك** — تتطلب تحديثات الشحن اشتراكًا صريحًا لكل متسوق في المحادثة
- **دفع آمن** — تكتمل المشتريات على صفحة دفع WooCommerce الخاصة بك؛ ولا تمر أي بيانات بطاقة أو دفع عبر الـ agent

## استكشاف الأخطاء وإصلاحها

### الربط يتوقف أو يفشل

يتطلب الربط أن يصل الخادم إلى رابط متجرك، و— في العملية القياسية — أن تُكمل التفويض لمرة واحدة على متجرك. إذا توقف، فذلك عادةً مشكلة شبكة أو جدار حماية في الوصول إلى المتجر، وليست في بيانات اعتمادك. إذا كان متجرك خلف جدار حماية، فاتصل باستخدام consumer key/secret **للقراءة فقط** بدلًا من ذلك (**Enter API keys manually**).

### الـ agent لا يجيب عن أسئلة المنتجات

التجارة **معطّلة افتراضيًا** وتُمنح لـ agent واحد عند الربط. إذا كان agent معيّن لا يجيب عن أسئلة الكتالوج، فافتح **Commerce → Settings** وفعّل مفتاح التجارة الخاص به.

### الكتالوج يبدو فارغًا بعد الربط مباشرة

يملأ الاستيراد الأول كامل كتالوجك وقد يستغرق بضع دقائق للمتجر الكبير. بعد اكتماله، تصبح منتجاتك قابلة للبحث؛ وبعد ذلك تتزامن التغييرات تلقائيًا.

### سعر أو مستوى مخزون يبدو قديمًا

يقرأ الـ agent الأسعار والمخزون المحدّثة في كل مرة، لذا لا ينبغي أن تصبح قديمة. في الحالة النادرة لفوات تزامن، تصلح المطابقة اليومية الكتالوج تلقائيًا.

### البحث عن الطلب لا يجد الطلب

أداة البحث عن الطلب صارمة عمدًا: لا تُرجِع التفاصيل إلا عندما يقدّم المتسوق رقم الطلب الدقيق **و** بريدًا إلكترونيًا أو هاتفًا يطابق الطلب.

### لا تُرسَل تحديثات حالة الطلب

تتطلب التحديثات شرطين: فعّلها في **Commerce → Settings → Notifications**، واجعل المتسوق يشترك في المحادثة على قناة مدعومة.

## الأسئلة الشائعة

### هل أحتاج إلى خطة مدفوعة لربط WooCommerce؟

لا. يعمل تكامل WooCommerce على جميع الخطط، بما في ذلك الفترة التجريبية المجانية. يمكنك ربط متجر واستخدام أسئلة الكتالوج والبحث عن الطلب والتوصيات وتحديثات حالة الطلب على أي خطة.

### هل عليّ تثبيت إضافة (plugin)؟

لا إضافة. العملية القياسية موافقة لمرة واحدة — أدخل رابط متجرك ووافق على تفويض WooCommerce REST API للقراءة فقط. لا تلصق consumer key/secret **للقراءة فقط** إلا إذا حجب جدار حماية متجرك إعادة التوجيه التلقائية.

### هل يمكن لجميع agents لدي استخدام WooCommerce، أم واحد فقط؟

التجارة اختيارية لكل agent ومعطّلة افتراضيًا. عند الربط تمنح التجارة لـ **agent واحد**؛ هذا الـ agent وحده يحصل على أدوات WooCommerce. يمكنك تفعيل التجارة لمزيد من الـ agents لاحقًا من **Commerce → Settings**.

### ماذا يفعل التكامل ببيانات متجري؟

يقرأ كتالوجك ومخزونك وطلباتك للإجابة عن الأسئلة وإرسال التحديثات المشترَك بها. إنه للقراءة فقط — لا يغيّر متجرك أبدًا، ولا يغيّر المخزون، ولا يستقبل المدفوعات. يتم الدفع دائمًا على متجر WooCommerce الخاص بك.

### هل يغيّر الـ agent متجري أو ينشئ طلبات؟

لا. التكامل للقراءة فقط بصرامة. لا يعدّل المنتجات أبدًا، ولا يعدّل المخزون، ولا ينشئ الطلبات أو يدفع ثمنها نيابةً عن المتسوق — تحدث هذه الإجراءات دائمًا على متجر WooCommerce الخاص بك.
