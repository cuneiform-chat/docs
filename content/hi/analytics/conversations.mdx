# Conversation Analytics

अपने agents और channels में conversation metrics track करें और detailed transcripts देखें।

## अवलोकन

Conversation analytics प्रदान करता है:

- Total conversation volume
- Agent के अनुसार conversations
- Channel के अनुसार conversations
- Full message transcripts
- AI-powered conversation insights

## Conversations Access करना

### Dashboard से

1. Sidebar में **Analytics** पर जाएं
2. Top Agents या Top Channels cards पर **View All** पर क्लिक करें
3. या analytics menu से सीधे Conversations पर navigate करें

### Conversation List

सभी conversations देखें:

| Column | विवरण |
|--------|-------|
| Title | Conversation title या session ID |
| Agent | किस agent ने conversation handle किया |
| Channel | Platform (Telegram, Discord, Slack, आदि) |
| Messages | Total message count |
| Last Active | Conversation आखिरी बार कब update हुई |
| Status | Active, archived, या deleted |

## Conversations Filter करना

Conversation list filter करें:

- **Agent** — Specific agent या सभी agents चुनें
- **Channel** — Platform के अनुसार filter करें (WhatsApp, Telegram, Meta, Slack, Discord, Google Chat, Playground)
- **Date range** — Last 7, 14, 30, या 90 days

## Conversation Details

किसी भी conversation पर click करके पूरी details देखें:

### Overview Tab

- **Total Messages** — Conversation में message count
- **Credits Spent** — Platform credits used
- **Agent** — किस agent ने conversation handle किया
- **Channel** — Platform जहाँ यह हुई
- **Created** — Conversation कब शुरू हुई
- **Last Active** — सबसे हालिया activity

### Message Activity Chart

समय के साथ message patterns visualize करें:
- Hourly और daily granularity के बीच toggle करें
- User messages और assistant messages show/hide करें
- Conversation activity patterns देखें

### Messages Tab

Complete conversation transcript देखें:

- **Full message history** — Conversation का हर message देखें
- **Role indicators** — User, Assistant, System, और Tool messages color-coded हैं
- **Timestamps** — हर message कब भेजा गया
- **Token usage** — प्रति message input/output tokens (जब available हो)

#### Message Filtering

Time period के अनुसार messages filter करें:
- Last 24 hours
- Last 7 days
- Last 30 days
- All messages

#### Export

Conversation को JSON file के रूप में download करने के लिए **Export** पर click करें जिसमें शामिल है:
- Conversation metadata
- Timestamps के साथ सभी messages
- Token information

## AI-Powered Insights

Conversations के intelligent summaries generate करें:

1. किसी conversation के **Messages** tab पर navigate करें
2. **Generate Insights** पर click करें
3. AI-analyzed insights देखें जिनमें शामिल हैं:
   - **Key Points** — चर्चा किए गए main topics
   - **User Intents** — User क्या accomplish करना चाहता था
   - **Key Info Shared** — साझा की गई महत्वपूर्ण जानकारी
   - **Suggested Actions** — Conversation के आधार पर recommendations

## Privacy Considerations

Conversation data को इनके अनुसार handle किया जाता है:

- Privacy policy requirements
- जहाँ applicable हो वहाँ user consent

## Tips

- Specific agents या channels से conversations ढूंढने के लिए filters use करें
- Record-keeping या analysis के लिए important conversations export करें
- Long conversations को जल्दी समझने के लिए AI insights generate करें
- Peak usage times identify करने के लिए Message Activity chart check करें
- अपने agent की persona बेहतर करने के लिए conversation transcripts review करें
- Usage patterns track करने के लिए credits spent monitor करें

## सामान्य प्रश्न

**Q: किसी specific channel से conversations कैसे ढूंढें?**

Conversation list के top पर Channel filter use करके Telegram, Discord, या Slack जैसा specific platform चुनें।

**Q: क्या मैं एक साथ कई conversations export कर सकता हूँ?**

Currently, export एक बार में एक conversation के लिए काम करता है। Messages tab से हर conversation को individually export करें।

**Q: "Generate Insights" क्या करता है?**

यह conversation analyze करने के लिए AI use करता है और एक summary provide करता है जिसमें key points, user intents, साझा की गई महत्वपूर्ण जानकारी, और suggested actions शामिल हैं।

**Q: क्या AI insights में credits लगते हैं?**

हाँ, insights generate करने से आपके account से credits consume होते हैं। हालाँकि, results cached होते हैं इसलिए वही insights दोबारा देखना free है।

**Q: Conversations कितने समय तक stored रहती हैं?**

Conversations securely stored हैं और analytics के लिए available हैं। Data storage के बारे में प्रश्न होने पर support से contact करें।
