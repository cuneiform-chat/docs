# Analytics

अपने agents की performance monitor करें और समझें कि users आपके chatbots के साथ कैसे interact करते हैं।

## अवलोकन

Analytics आपकी मदद करता है:
- Conversation volume और query patterns track करें
- Agent performance और credit usage monitor करें
- Channel distribution समझें
- सुधार के क्षेत्र पहचानें

## Dashboard

अपने sidebar में **Analytics** section से analytics access करें।

### मुख्य Metrics

| Metric | विवरण |
|--------|-------|
| Total Queries | Agent executions (AI responses) |
| Conversations | Chat sessions की संख्या |
| Unique Users | जिन individual users ने chat किया |
| Credits Used | Platform credits उपयोग किए गए |

### Credit Usage

Dashboard आपके current billing cycle का credit उपयोग दिखाता है:
- Credits used बनाम allocated
- Percentage progress bar
- Period के लिए remaining credits

### Charts

Dashboard में visual charts शामिल हैं:
- **Query Volume** — समय के साथ queries दिखाने वाला line chart
- **Channel Distribution** — Channel के अनुसार queries break down करने वाला pie chart
- **Agent Distribution** — Agent के अनुसार queries break down करने वाला pie chart

### Top Agents

आपके सबसे active agents की ranked list जिसमें दिखाई देता है:
- Agent का नाम और rank
- Total queries handled
- Conversations की संख्या
- Credits consumed
- Current status (active, inactive, testing, archived)

Detailed analytics देखने के लिए किसी agent पर क्लिक करें, या सभी agents देखने के लिए **View All** पर क्लिक करें।

### Top Channels

आपके सबसे active communication channels की ranked list जिसमें दिखाई देता है:
- Channel का नाम और rank
- Total queries handled
- Conversations की संख्या
- Credits consumed

Detailed analytics देखने के लिए किसी channel पर क्लिक करें, या सभी channels देखने के लिए **View All** पर क्लिक करें।

## समय अवधि

विभिन्न time ranges के लिए analytics देखें:
- Current Billing Cycle
- Last 7 days
- Last 14 days
- Last 30 days
- Last 90 days

## Granularity

Data को group करने का तरीका adjust करें:
- Hourly
- Daily
- Weekly
- Monthly

## Filtering

Analytics filter करें:
- **Agent** — Specific agents के लिए metrics देखें
- **Channel** — Platforms पर performance compare करें
- **Date range** — Specific time periods analyze करें

## Analytics का उपयोग

### Patterns पहचानें

देखें कि कौन से channels और agents सबसे अधिक queries handle करते हैं:
- Resource allocation optimize करें
- जहाँ ज़रूरत हो वहाँ improvements focus करें
- User preferences समझें

### Performance Monitor करें

Trends track करके सुनिश्चित करें:
- Credit usage limits के अंदर रहे
- User engagement healthy हो
- कोई असामान्य pattern न हो

### Agents Optimize करें

Insights का उपयोग करें:
- Agent personas adjust करें
- Missing documentation जोड़ें
- Response accuracy बेहतर करें
