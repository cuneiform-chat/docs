# उपयोग मेट्रिक्स

अपने resource consumption और credit utilization track करें।

## Credit Usage Overview

Analytics dashboard आपका current billing cycle usage दिखाता है:

- **Credits Used** — इस period में consume किए गए platform credits
- **Credits Remaining** — Period end तक available credits
- **Usage Percentage** — Consumption का visual progress bar

## मुख्य Metrics

### Query Volume

| Metric | विवरण |
|--------|-------|
| Total Queries | Period में AI agent executions |
| Conversations | Total chat sessions |
| Unique Users | Interact करने वाले individual users |

### Distribution Breakdown

Usage कैसे distributed है देखें:

- **By Agent** — कौन से agents सबसे अधिक queries handle करते हैं
- **By Channel** — Telegram, Discord, Slack, WhatsApp, आदि पर usage

## Usage Trends

### Query Volume Chart

Main analytics dashboard एक query volume chart display करता है जिसमें दिखाई देता है:
- समय के साथ queries
- Configurable granularity (hourly, daily, weekly, monthly)
- Date range selection

### Distribution Charts

Pie charts जो दिखाते हैं:
- Channel distribution — प्रति platform queries का percentage
- Agent distribution — प्रति agent queries का percentage

## Usage Warnings

**Billing** page automatic warning banners display करता है जब:

- **Approaching limit** — आपने अपना अधिकांश monthly quota use कर लिया है
- **Limit reached** — Monthly quota depleted हो गया है
- **Blocked** — Extra usage balance भी depleted हो गया है

ये warnings **Billing & Plans** में appear होते हैं ताकि service affect होने से पहले आप action ले सकें।

## Optimization Tips

### Query Usage कम करें

- Better first-response accuracy के लिए agent personas improve करें
- Follow-up questions कम करने के लिए FAQ content जोड़ें
- Faster retrieval के लिए content optimize करें

### High-Usage Areas Monitor करें

- Check करें कि कौन से agents सबसे अधिक credits consume करते हैं
- सबसे अधिक volume वाले channels identify करें
- ऐसी conversations review करें जो अधिक tokens use करती हैं
