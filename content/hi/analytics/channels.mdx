# Channel Analytics

Channel के अनुसार performance metrics देखें। सभी platforms पर query volumes, conversations, unique users, और credit usage compare करें जहाँ आपके agents queries receive करते हैं।

## Channel Analytics Access करना

1. Sidebar में **Analytics** पर navigate करें
2. "Channel Distribution" के बगल में **View All** पर क्लिक करें, या
3. सीधे **Analytics > Channels** पर जाएं

## Navigation

Breadcrumb आपकी location दिखाता है: **Dashboard / Channels**। Main analytics page पर वापस जाने के लिए "Dashboard" पर क्लिक करें।

## Date Range Controls

| Control | विवरण |
|---------|-------|
| **Last 7 days** | पिछले हफ्ते के metrics देखें |
| **Last 14 days** | दो हफ्तों के metrics देखें |
| **Last 30 days** | पिछले महीने के metrics देखें |
| **Last 90 days** | पिछले quarter के metrics देखें |
| **Refresh** | Latest values के साथ data reload करें |

## Summary Cards

सभी channels में aggregated metrics दिखाने वाले चार cards:

| Card | विवरण |
|------|-------|
| Total Channels | Active channels की संख्या |
| Total Queries | सभी channels में queries का योग |
| Total Conversations | सभी channels में conversations का योग |
| Total Credits | सभी channels में use किए गए credits का योग |

## Channels Table

सभी active channels performance metrics के साथ listed हैं:

| Column | विवरण |
|--------|-------|
| Channel | Color-coded badge के साथ channel का नाम |
| Queries | इस channel पर total सवालों के जवाब |
| Conversations | इस channel पर chat sessions |
| Unique Users | इस channel के माध्यम से interact करने वाले distinct users |
| Credits | इस channel द्वारा उपयोग किए गए resources |
| % of Total | Total queries में इस channel की share दिखाने वाला visual progress bar |
| (Arrow) | Detailed channel view का link |

## Channel Types

आपके agents विभिन्न platforms से queries receive कर सकते हैं:

| Channel | विवरण |
|---------|-------|
| Playground | Agent testing interface से queries |
| Telegram | Telegram bot integration |
| Discord | Discord bot integration |
| Slack | Slack app integration |
| Meta | Meta/Messenger integration |
| WhatsApp | WhatsApp Business integration |
| Google Chat | Google Chat (Workspace) integration |

## Channel Details देखना

किसी भी channel row पर arrow पर click करके देखें:
- उस specific channel के detailed metrics
- Granularity options के साथ time-series charts (Hourly, Daily, Weekly, Monthly)
- उस channel के अंदर agent breakdown

## Tips

- सबसे अधिक traffic drive करने वाले channels समझने के लिए **% of Total** compare करें
- ध्यान देने की ज़रूरत वाले underperforming channels identify करने के लिए इस view का use करें
- प्रति platform audience reach समझने के लिए **Unique Users** check करें
- Channel के अनुसार resource consumption देखने के लिए **Credits** review करें

## सामान्य प्रश्न

**Q: सभी channels listed क्यों नहीं दिखते?**

Table में केवल वे channels appear होते हैं जिन पर selected date range के दौरान कम से कम एक query आई हो।

**Q: Percentage कैसे calculate होती है?**

Percentage selected period में सभी channels में total queries का हर channel का share दिखाती है।

**Q: क्या मैं channels को समय के साथ compare कर सकता हूँ?**

Time-series data और trends देखने के लिए किसी specific channel पर click करें।
