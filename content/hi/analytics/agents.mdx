# Agent Analytics

अपने सभी agents के लिए detailed performance metrics देखें। अपने पूरे agent portfolio में query volumes, conversations, और credit usage compare करें।

## Agent Analytics Access करना

1. Sidebar में **Analytics** पर navigate करें
2. "Top Agents" के बगल में **View All** पर क्लिक करें, या
3. सीधे **Analytics > Agents** पर जाएं

## Navigation

Breadcrumb आपकी location दिखाता है: **Dashboard / Agents**। Main analytics page पर वापस जाने के लिए "Dashboard" पर क्लिक करें।

## Date Range Controls

| Control | विवरण |
|---------|-------|
| **Last 7 days** | पिछले हफ्ते के metrics देखें |
| **Last 14 days** | दो हफ्तों के metrics देखें |
| **Last 30 days** | पिछले महीने के metrics देखें |
| **Last 90 days** | पिछले quarter के metrics देखें |
| **Refresh** | Latest values के साथ data reload करें |

## Agents Table

सभी agents performance metrics के साथ listed हैं:

| Column | विवरण | Sortable |
|--------|-------|----------|
| Agent | Agent का नाम | नहीं |
| Status | active, inactive, testing, या archived | नहीं |
| Queries | कुल सवालों के जवाब | हाँ |
| Conversations | Chat sessions | हाँ |
| Credits | उपयोग किए गए resources | हाँ |
| Channels | Agent किन channels पर use होता है | नहीं |
| (Arrow) | Detailed view का link | नहीं |

### Sorting

किसी भी sortable column header पर क्लिक करके उस metric के अनुसार sort करें:
- **पहली click**: Descending sort (सबसे अधिक पहले)
- **दूसरी click**: Ascending sort (सबसे कम पहले)
- Active sort column highlighted होता है

### Pagination

बड़े agent lists के लिए:
- "Showing X - Y of Z" दिखाता है
- Pages navigate करने के लिए **Previous/Next** buttons use करें

## Agent Status Badges

| Badge | Color | अर्थ |
|-------|-------|------|
| active | Green | Agent deploy है और queries receive कर रहा है |
| inactive | Gray | Agent paused है |
| testing | Yellow | Agent deployment से पहले test हो रहा है |
| archived | Yellow | Agent archived है |

## Channel Badges

Channels column दिखाता है कि हर agent किन platforms पर use होता है:
- अधिकतम 3 channel badges दिखाई देते हैं (जैसे "web", "telegram", "discord")
- 3 से अधिक होने पर "+X" दिखाता है अतिरिक्त channels indicate करने के लिए

## Agent Details देखना

किसी भी agent row पर arrow पर click करके देखें:
- उस specific agent के detailed metrics
- Time-series charts
- Channel breakdown
- अधिक granular data

## Tips

- अपने सबसे resource-intensive agents ढूंढने के लिए **Credits** के अनुसार sort करें
- अपने सबसे popular agents identify करने के लिए **Queries** के अनुसार sort करें
- Long-term trend analysis के लिए **90 days** use करें
- Inactive agents check करें कि क्या उन्हें reactivate करना चाहिए
- Deeper insights के लिए individual agents पर click करें

## सामान्य प्रश्न

**Q: अपना सबसे ज्यादा use होने वाला agent कैसे ढूंढें?**

Query count के अनुसार sort करने के लिए "Queries" column header पर click करें। Top row आपका सबसे active agent है।

**Q: Channel badges का क्या मतलब है?**

वे दिखाते हैं कि किन platforms (Web, Telegram, Discord, Slack, आदि) से हर agent queries receive करता है।

**Q: किसी agent पर zero queries क्यों दिख रहे हैं?**

Agent नया हो सकता है, inactive हो सकता है, या अभी तक किसी channel पर deploy नहीं किया गया हो।
