# Integrations

अपने agents को कई channels पर deploy करें और users तक उनकी पसंदीदा जगह पहुंचें।

## उपलब्ध Channels

| Channel | विवरण | के लिए बेहतर |
|---------|-------------|----------|
| [Telegram](/integrations/telegram) | Telegram bot | Mobile users, communities |
| [Discord](/integrations/discord) | Slash commands के साथ Discord bot | Gaming, developer communities |
| [Slack](/integrations/slack) | Slack app | Team workspaces |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | Customer communication |
| [Google Chat](/integrations/google-chat) | Google Workspace app | Enterprise teams |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | Consumer audience |
| [Website Widget](/integrations/website-widget) | Embeddable chat widget | Customer support, any website |

## Integrations कैसे काम करती हैं

1. **Configure** — अपने चुने हुए channel के लिए integration सेट करें
2. **Connect** — अपने agent को channel से जोड़ें
3. **Deploy** — आपका agent users के लिए उपलब्ध हो जाता है
4. **Monitor** — Conversations और usage ट्रैक करें

## Multi-Channel Deployment

एक ही agent को एक साथ कई channels पर deploy किया जा सकता है:

- सभी channels पर same content
- हर जगह consistent responses
- Centralized conversation history
- Unified analytics

## Channel-Specific Features

प्रत्येक channel की unique capabilities हैं:

- **Telegram** — Rich messages, inline keyboards
- **Discord** — Slash commands, server integration
- **Slack** — Workspace apps, channel responses
- **WhatsApp** — Business messaging, rich media
- **Google Chat** — Google Workspace integration, spaces support, document Q&A + Space Knowledge Base
- **Meta (Facebook)** — Messenger integration, page messaging
- **Website Widget** — Embeddable chat, customizable appearance, domain allowlisting
