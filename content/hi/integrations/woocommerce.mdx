# WooCommerce इंटीग्रेशन

अपना सेल्फ़-होस्टेड **WooCommerce** स्टोर कनेक्ट करें ताकि आपका AI agent उत्पादों के सवालों के जवाब दे सके, किसी ग्राहक का ऑर्डर ढूँढ सके, स्टॉक में मौजूद आइटम की सिफ़ारिश कर सके और ऑर्डर-स्टेटस अपडेट भेज सके — यह सब आपके असली, लाइव कैटलॉग और ऑर्डर डेटा से।

## अवलोकन

WooCommerce इंटीग्रेशन आपके सेल्फ़-होस्टेड स्टोर को WooCommerce REST API के ज़रिए आपके AI agents से जोड़ता है। WooCommerce आपका कॉमर्स बैकएंड है; और आपका Cuneiform agent हर उस चैनल पर बातचीत की परत है जहाँ आप उसे डिप्लॉय करते हैं। कनेक्ट होने के बाद agent यह कर सकता है:

- **कैटलॉग प्रश्नोत्तर** — आपके असली उत्पादों, वेरिएंट, कीमतों और मौजूदा उपलब्धता से जवाब देता है
- **ऑर्डर खोज (WISMO)** — ग्राहक अपने ऑर्डर नंबर और ऑर्डर पर दर्ज ईमेल या फ़ोन के साथ "मेरा ऑर्डर कहाँ है?" जान सकते हैं
- **सिफ़ारिशें** — ऐसे उत्पाद सुझाता है जो वाकई **स्टॉक में** हैं
- **ऑर्डर-स्टेटस अपडेट** — जो ग्राहक ऑप्ट-इन करते हैं उन्हें उसी चैट में शिपिंग अपडेट भेजता है
- **लाइव इन्वेंटरी** — जवाब देते समय हमेशा ताज़ा कीमतें और स्टॉक पढ़ता है
- **चेकआउट हैंडऑफ़** — खरीदने के लिए तैयार ग्राहक को आपके अपने WooCommerce चेकआउट पर भेजता है

## पूर्वापेक्षाएँ

- एक **सेल्फ़-होस्टेड WooCommerce स्टोर** जिसे आप प्रबंधित करते हैं
- आपका **स्टोर URL** (उदाहरण के लिए, `https://your-store.com`)
- आपका कॉमर्स agent बनने के लिए कम-से-कम **एक agent** (आप कनेक्ट के दौरान नया बना सकते हैं)

आपको कोई प्लगइन इंस्टॉल करने या कोड लिखने की **ज़रूरत नहीं** है। मानक कनेक्ट प्रक्रिया एक बार की मंज़ूरी है; रीड-ओनली consumer key/secret केवल तभी चाहिए जब आपका स्टोर फ़ायरवॉल के पीछे हो।

## सेटअप चरण

### 1. Commerce खोलें

एडमिन पैनल में, **Commerce** पर जाएँ और **WooCommerce** चुनें। Commerce इंटीग्रेशन का एकमात्र घर है — कनेक्ट कार्ड, आपकी **Product Library**, **Settings** और **Analytics** सब यहीं हैं।

### 2. अपना स्टोर कनेक्ट करें

अपना स्टोर URL डालें और **Connect** पर क्लिक करें। आप अपने स्टोर पर WooCommerce REST API की एक बार की अनुमति देंगे, फिर **Commerce** पर लौटेंगे। यदि आपका स्टोर रीडायरेक्ट को ब्लॉक करने वाले फ़ायरवॉल के पीछे है, तो **Enter API keys manually** को विस्तृत करें और एक **रीड-ओनली** consumer key और secret पेस्ट करें (WooCommerce → Settings → Advanced → REST API में बनाए गए)।

### 3. अपना कॉमर्स agent चुनें

कॉमर्स **प्रति agent ऑप्ट-इन** और **डिफ़ॉल्ट रूप से बंद** है। कनेक्ट के समय, वह **एकमात्र** agent चुनें जो आपका कॉमर्स agent बनेगा — कोई मौजूदा सक्रिय agent या नया। केवल उसी agent को WooCommerce टूल मिलते हैं; आपके बाकी agents अप्रभावित रहते हैं। आप इसे बाद में **Commerce → Settings** में बदल सकते हैं।

### 4. अपने कैटलॉग को सिंक होने दें

कनेक्ट करने से आपके उत्पादों, वेरिएंट, कीमतों, छवियों और स्टॉक का एक बार का इम्पोर्ट शुरू होता है। उसके बाद, बदलाव अपने-आप सिंक होते हैं, और एक दैनिक रिकंसाइल छूटी हुई किसी भी चीज़ को पकड़ लेता है।

### 5. आज़माएँ

अपना कॉमर्स agent खोलें और कोई कैटलॉग प्रश्न पूछें ("यह किन साइज़ में आता है?", "नीला स्टॉक में है?") या कोई ऑर्डर खोजें ("मेरा ऑर्डर #1001 कहाँ है?")। agent आपके लाइव WooCommerce डेटा से जवाब देता है।

## यह कैसे काम करता है

```
ग्राहक एक सवाल पूछता है
  → कॉमर्स agent आपके लाइव WooCommerce कैटलॉग और ऑर्डर पढ़ता है (रीड-ओनली)
  → उत्पादों, स्टॉक और ऑर्डर स्टेटस के बारे में जवाब देता है
  → खरीदने के लिए आपके अपने WooCommerce चेकआउट पर भेजता है
```

agent आपके उत्पादों, कीमतों, इन्वेंटरी और ऑर्डर को सीधे WooCommerce REST API के ज़रिए पढ़ता है और कीमतें व स्टॉक ताज़ा रखता है — आपके कैटलॉग को किसी नॉलेज बेस में कॉपी-पेस्ट किए बिना।

## विशेषताएँ

### डिज़ाइन से ही रीड-ओनली

इंटीग्रेशन केवल WooCommerce से **पढ़ता** है (उत्पाद, इन्वेंटरी, ऑर्डर)। यह कभी आपका कैटलॉग या इन्वेंटरी नहीं बदलता, कभी भुगतान नहीं लेता, और कभी ऑर्डर नहीं बनाता। चेकआउट हमेशा आपके अपने WooCommerce स्टोर पर होता है।

### एक स्टोर, एक कॉमर्स agent

आप **प्रति संगठन एक WooCommerce स्टोर** कनेक्ट करते हैं और कनेक्ट के समय **ठीक एक agent** को कॉमर्स देते हैं। जब तक आप **Commerce → Settings** में उन्हें चालू नहीं करते, बाकी agents नॉन-कॉमर्स रहते हैं।

### सत्यापित ऑर्डर खोज

ग्राहक ऑर्डर का विवरण केवल सही ऑर्डर नंबर **और** ऑर्डर पर दर्ज ईमेल या फ़ोन देने के बाद ही देखते हैं। ग़लत संपर्क और न मौजूद ऑर्डर दोनों बिना विवरण के वही "नहीं मिला" जवाब देते हैं — यह एंटी-एन्युमरेशन सुरक्षा है जो आपके ग्राहकों की रक्षा करती है।

### लाइव कैटलॉग और इन्वेंटरी

agent जवाब देते समय कीमतें और स्टॉक ताज़ा पढ़ता है, इसलिए सिफ़ारिशें केवल उन आइटम तक सीमित रहती हैं जो वाकई स्टॉक में हैं। कोई सिंक छूट जाने पर दैनिक रिकंसाइल उसे ठीक कर देता है।

### ऑप्ट-इन ऑर्डर-स्टेटस अपडेट

ग्राहक द्वारा चैट में अपना ऑर्डर सत्यापित करने के बाद, वह किसी समर्थित चैनल पर शिपिंग अपडेट पाने के लिए ऑप्ट-इन कर सकता है। अपडेट केवल तभी भेजे जाते हैं जब आपने उन्हें **Commerce → Settings → Notifications** में चालू किया हो और ग्राहक ने ऑप्ट-इन किया हो।

## सुरक्षा

- **रीड-ओनली एक्सेस** — इंटीग्रेशन आपके स्टोर में कुछ भी बना, संपादित या हटा नहीं सकता, इन्वेंटरी नहीं बदल सकता, या भुगतान नहीं ले सकता
- **संगठन के अनुसार पृथक्करण** — आपका कैटलॉग और ऑर्डर केवल आपके संगठन के हैं और दूसरे टेनेंट को कभी दिखाई नहीं देते
- **सत्यापित ऑर्डर खोज** — ऑर्डर विवरण के लिए सही ऑर्डर नंबर के साथ मिलान करने वाला ईमेल या फ़ोन ज़रूरी है (एंटी-एन्युमरेशन)
- **ऑप्ट-इन सूचनाएँ** — शिपिंग अपडेट के लिए चैट में प्रत्येक ग्राहक की स्पष्ट ऑप्ट-इन ज़रूरी है
- **सुरक्षित चेकआउट** — खरीदारी आपके अपने WooCommerce चेकआउट पर पूरी होती है; कोई कार्ड या भुगतान डेटा agent से होकर नहीं गुज़रता

## समस्या निवारण

### कनेक्शन अटक जाता है या विफल हो जाता है

कनेक्ट करने के लिए सर्वर को आपके स्टोर URL तक पहुँचना होता है और — मानक प्रक्रिया के लिए — आपको स्टोर पर एक बार की अनुमति पूरी करनी होती है। अगर यह अटकता है, तो आमतौर पर यह स्टोर तक पहुँचने की नेटवर्क या फ़ायरवॉल समस्या है, आपके क्रेडेंशियल की नहीं। यदि आपका स्टोर फ़ायरवॉल के पीछे है, तो इसके बजाय **रीड-ओनली** consumer key/secret से कनेक्ट करें (**Enter API keys manually**)।

### agent उत्पादों के सवालों का जवाब नहीं देता

कॉमर्स **डिफ़ॉल्ट रूप से बंद** है और कनेक्ट के समय एक agent को दिया जाता है। यदि कोई खास agent कैटलॉग सवालों का जवाब नहीं दे रहा, तो **Commerce → Settings** खोलें और उसका कॉमर्स टॉगल चालू करें।

### कनेक्ट करने के तुरंत बाद कैटलॉग खाली दिखता है

पहला इम्पोर्ट आपका पूरा कैटलॉग भरता है और बड़े स्टोर के लिए कुछ मिनट ले सकता है। पूरा होने पर, आपके उत्पाद खोजे जा सकते हैं; उसके बाद बदलाव अपने-आप सिंक होते हैं।

### कोई कीमत या स्टॉक स्तर पुराना दिखता है

agent हर बार कीमतें और स्टॉक ताज़ा पढ़ता है, इसलिए वे पुराने नहीं होने चाहिए। किसी सिंक के छूटने की दुर्लभ स्थिति में, दैनिक रिकंसाइल कैटलॉग को अपने-आप ठीक कर देता है।

### ऑर्डर खोज कोई ऑर्डर नहीं ढूँढ पाती

ऑर्डर-खोज टूल जान-बूझकर सख़्त है: यह विवरण केवल तभी लौटाता है जब ग्राहक सही ऑर्डर नंबर **और** ऑर्डर से मिलान करने वाला ईमेल या फ़ोन देता है।

### कोई ऑर्डर-स्टेटस अपडेट नहीं भेजा जाता

अपडेट के लिए दोनों शर्तें ज़रूरी हैं: उन्हें **Commerce → Settings → Notifications** में चालू करें, और ग्राहक को किसी समर्थित चैनल पर चैट में ऑप्ट-इन कराएँ।

## अक्सर पूछे जाने वाले प्रश्न

### WooCommerce कनेक्ट करने के लिए क्या मुझे पेड प्लान चाहिए?

नहीं। WooCommerce इंटीग्रेशन हर प्लान पर, फ़्री ट्रायल सहित काम करता है। आप किसी भी प्लान पर स्टोर कनेक्ट करके कैटलॉग प्रश्नोत्तर, ऑर्डर खोज, सिफ़ारिशें और ऑर्डर-स्टेटस अपडेट इस्तेमाल कर सकते हैं।

### क्या मुझे कोई प्लगइन इंस्टॉल करना होगा?

कोई प्लगइन नहीं। मानक प्रक्रिया एक बार की मंज़ूरी है — अपना स्टोर URL डालें और एक रीड-ओनली WooCommerce REST API अनुमति दें। आप **रीड-ओनली** consumer key/secret केवल तभी पेस्ट करते हैं जब आपके स्टोर का फ़ायरवॉल स्वचालित रीडायरेक्ट ब्लॉक करता है।

### क्या मेरे सभी agents WooCommerce इस्तेमाल कर सकते हैं, या केवल एक?

कॉमर्स प्रति agent ऑप्ट-इन और डिफ़ॉल्ट रूप से बंद है। कनेक्ट पर आप **एक** agent को कॉमर्स देते हैं; केवल उसी agent को WooCommerce टूल मिलते हैं। आप बाद में **Commerce → Settings** में और agents के लिए कॉमर्स चालू कर सकते हैं।

### इंटीग्रेशन मेरे स्टोर डेटा के साथ क्या करता है?

यह सवालों के जवाब देने और ऑप्ट-इन किए गए अपडेट भेजने के लिए आपका कैटलॉग, इन्वेंटरी और ऑर्डर पढ़ता है। यह रीड-ओनली है — कभी आपका स्टोर नहीं बदलता, कभी इन्वेंटरी नहीं बदलता, और कभी भुगतान नहीं लेता। चेकआउट हमेशा आपके अपने WooCommerce स्टोर पर होता है।

### क्या agent कभी मेरा स्टोर बदलता है या ऑर्डर बनाता है?

नहीं। इंटीग्रेशन सख़्ती से रीड-ओनली है। यह कभी उत्पाद संपादित नहीं करता, कभी इन्वेंटरी समायोजित नहीं करता, और ग्राहक की ओर से कभी ऑर्डर नहीं बनाता या भुगतान नहीं करता — ये क्रियाएँ हमेशा आपके अपने WooCommerce स्टोर पर होती हैं।
