# Telegram Integration

अपने agent को Telegram से connect करें और users को सीधे Telegram app में chat करने दें।

## अवलोकन

Telegram integration प्रदान करती है:
- Bot के साथ direct messaging
- Group chat support
- Rich message formatting
- Interactions के लिए inline keyboards

## पूर्व-आवश्यकताएं

- एक Telegram account
- BotFather access (Telegram का bot बनाने का tool)

## Setup Steps

### 1. Telegram Bot बनाएं

1. Telegram खोलें और **@BotFather** खोजें
2. Chat शुरू करें और `/newbot` भेजें
3. Prompts follow करें:
   - अपने bot के लिए नाम दर्ज करें (जैसे, "My Support Bot")
   - Username दर्ज करें (अंत में "bot" होना चाहिए, जैसे, "mysupportbot")
4. BotFather आपको एक **Bot Token** देगा — इसे सुरक्षित रख लें

### 2. Cuneiform Chat से Connect करें

1. **Agents** में जाएं → अपना agent चुनें
2. **Integrations** tab पर जाएं
3. **Telegram** पर क्लिक करें
4. अपना Bot Token paste करें
5. **Connect** पर क्लिक करें

### 3. अपना Bot Configure करें

BotFather के माध्यम से optional bot settings:

- `/setdescription` — Bot क्या करता है
- `/setabouttext` — Bot profile में जानकारी
- `/setuserpic` — अपने bot के लिए profile picture

### 4. अपना Bot Test करें

1. Telegram में अपने bot का username खोजें
2. `/start` के साथ conversation शुरू करें
3. Message भेजें और verify करें कि response मिलता है

## यह कैसे काम करता है

```
User sends message → Telegram → Cuneiform Chat → Agent processes → Response sent back
```

Messages real-time में process होते हैं। Agent आपके content में खोज करता है और आपकी configuration के आधार पर responses generate करता है।

## Features

### Direct Messages

Users आपके bot के साथ एकांत में private support conversations के लिए chat कर सकते हैं।

### Group Chats

अपने bot को group chats में जोड़ें:

1. Bot को group में जोड़ें
2. इसे admin बनाएं (message access के लिए)
3. Users bot को mention कर सकते हैं या commands का उपयोग कर सकते हैं

### Rich Formatting

आपके agent के responses support करते हैं:
- **Bold** और *italic* text
- Links
- Code blocks
- Lists

## Bot Commands

आप BotFather के माध्यम से custom commands configure कर सकते हैं:

| Command | विवरण |
|---------|-------------|
| `/start` | Conversation शुरू करें |
| `/help` | Help message दिखाएं |
| `/ask [question]` | कोई specific सवाल पूछें |

## Troubleshooting

### Bot Respond नहीं कर रहा

1. Verify करें कि bot token सही है
2. Check करें कि Cuneiform Chat में integration connected है
3. सुनिश्चित करें कि आपका agent सही तरह configure है
4. पहले Playground में agent test करें

### Token Issues

अगर आपको नया token चाहिए:
1. BotFather पर जाएं
2. `/mybots` भेजें → अपना bot चुनें → **API Token** → **Revoke**
3. Cuneiform Chat में नया token update करें

### Group Chat Issues

- Ensure करें कि bot के पास admin permissions हैं
- BotFather के माध्यम से privacy mode settings check करें (`/setprivacy`)

## Security

- Bot tokens encrypted और सुरक्षित रूप से stored हैं
- Conversations secure connections के माध्यम से process होते हैं

## Disconnect करना

Telegram integration हटाने के लिए:

1. **Agents** में जाएं → Agent चुनें → **Integrations**
2. **Telegram** पर क्लिक करें → **Disconnect**

यह bot को respond करने से रोकता है लेकिन Telegram bot को delete नहीं करता। जरूरत पड़ने पर BotFather के माध्यम से delete करें।
