# WhatsApp Integration

Customer communication के लिए अपने agent को WhatsApp Business से connect करें।

## अवलोकन

WhatsApp integration प्रदान करती है:
- Business messaging capabilities
- Rich media support
- Automated responses
- Global reach
- 24-hour messaging window compliance

## पूर्व-आवश्यकताएं

- एक active AI agent (Agents section में बनाया गया)
- एक WhatsApp Business Account (WABA)
- WhatsApp Business में एक verified phone number
- Meta Developer Portal का access

## Setup Steps

### 1. Embedded Signup से Connect करें (Recommended)

WhatsApp connect करने का सबसे आसान तरीका embedded Meta signup flow है:

1. **Agents** में जाएं → अपना agent चुनें
2. **Integrations** tab पर जाएं
3. **WhatsApp** पर क्लिक करें
4. Meta signup popup खोलने के लिए **Connect with Facebook** पर क्लिक करें
5. अपने Facebook/Meta account से log in करें
6. WhatsApp Business Account चुनें या बनाएं
7. Connect करने के लिए phone number चुनें
8. Popup बंद होता है और आपका connection establish हो जाता है

<Callout type="important">
  Embedded signup flow ज़्यादातर configuration automatically handle करता है। यह अधिकांश users के लिए recommended method है।
</Callout>

### 2. Phone Verification (अगर जरूरी हो)

Meta signup पूरा करने के बाद, आपको अपना phone number verify करना पड़ सकता है:

1. अपना verification code प्राप्त करने का तरीका चुनें: **SMS** या **Voice Call**
2. **Send Code** पर क्लिक करें
3. मिला 6-digit code दर्ज करें
4. **Verify** पर क्लिक करें

अगर code नहीं मिला, retry के लिए "Didn't receive the code? Send again" पर क्लिक करें।

### 3. Two-Step Verification (अगर Enable हो)

अगर आपके WhatsApp Business account में Two-Step Verification enabled है:

1. Prompt होने पर अपना 6-digit PIN दर्ज करें
2. **Complete Registration** पर क्लिक करें

<Callout type="info">
  यह PIN WhatsApp Business Manager → Security Center में set किया गया था। यह SMS verification code से अलग है।
</Callout>

### 4. Webhook Configure करें (अगर जरूरी हो)

Setup के बाद, आपको Meta Business Suite में अपना webhook configure करना पड़ सकता है:

1. Connection के बाद provide किया गया webhook URL copy करें
2. Meta Developer Portal में, **WhatsApp** → **Configuration** पर जाएं
3. Webhook URL add करें
4. `messages` webhook field को subscribe करें

## Bot का उपयोग करना

### Customer Messages

जब customers आपके WhatsApp number पर message करते हैं:

1. Message WhatsApp के माध्यम से आता है
2. Cuneiform Chat request process करता है
3. Agent content से response generate करता है
4. Response customer को वापस भेजा जाता है

### Conversation Flow

```
Customer → WhatsApp → Cuneiform Chat → Agent → Response → Customer
```

## Features

### 24-Hour Messaging Window

WhatsApp Business API rules:
- आप customer-initiated messages का 24 घंटे तक respond कर सकते हैं
- 24 घंटे के बाद, window बंद हो जाती है जब तक customer दोबारा message न करे
- हर नया customer message window दोबारा खोलता है

<Callout type="info">
  आपका agent automatically 24-hour window के भीतर respond करता है। Re-engagement के लिए template messages currently supported नहीं हैं।
</Callout>

### Rich Media

Responses में शामिल हो सकते हैं:
- Text messages
- Links
- Formatted text

### Multi-Language

आपका agent automatically customer की language detect करता है और उसी में respond करता है — 176 languages supported, कोई configuration जरूरी नहीं।

## Connected Numbers Manage करना

प्रत्येक connected WhatsApp number दिखाता है:
- **Business name** या display phone number
- **Status badge** - Active, Inactive, या Error
- **Phone number**
- **Last activity** timestamp

|--------|-------------|
| **Test Connection** | Verify करता है कि integration काम कर रहा है |

Integration card पर three-dot menu के माध्यम से इन्हें access करें।

## Troubleshooting

### Connection Failed

1. Ensure करें कि आपके पास valid WhatsApp Business Account है
2. Check करें कि आपका phone number verified है
3. Embedded signup flow दोबारा try करें

### Phone Verification काम नहीं कर रहा

1. Ensure करें कि SMS/Voice के लिए phone number का access है
2. नया code request करने से पहले कुछ मिनट wait करें
3. Check करें कि phone number कहीं और connected तो नहीं है

### Two-Step Verification Error

1. WhatsApp Business Manager → Security Center में set किया PIN दर्ज करें
2. यह SMS verification code से अलग है
3. अगर PIN नहीं पता, तो अपने WhatsApp Business admin से contact करें

### Messages नहीं आ रहे

1. Verify करें कि Meta Business Suite में webhook सही तरह configured है
2. Check करें कि webhook subscription में `messages` शामिल है
3. Confirm करें कि integration status "Active" है

### Response Failures

1. Check करें कि Playground में agent काम करता है
2. Verify करें कि 24-hour window active है (customer ने recently message किया हो)
3. Admin panel में integration status check करें

## Security

- Access tokens encrypted और सुरक्षित रूप से stored हैं
- Messages secure connections पर process होते हैं

## Compliance

WhatsApp Business की usage policies हैं:
- केवल customer-initiated conversations का respond करें
- Opt-out options provide करें
- Meta की Commerce और Business policies follow करें

## Disconnect करना

WhatsApp integration हटाने के लिए:

1. **Agents** में जाएं → Agent चुनें → **Integrations**
2. अपने WhatsApp integration पर three-dot menu पर क्लिक करें
3. **Disconnect** चुनें

यह agent को respond करने से रोकता है। पूरी तरह हटाने के लिए:
- Meta Developer Portal में webhook delete करें
- Optionally अपने Meta app से WhatsApp product हटाएं

## सामान्य सवाल

**Q: WhatsApp कैसे connect करूं?**
A: Integrations tab में "WhatsApp" पर क्लिक करके, फिर "Connect with Facebook" पर क्लिक करके embedded signup का उपयोग करें। यह automatically Meta signup process के माध्यम से guide करता है।

**Q: Verification code क्यों मांगा जाता है?**
A: WhatsApp नए connections के लिए phone verification require करता है। SMS या Voice Call चुनें 6-digit code प्राप्त करने के लिए, फिर setup complete करने के लिए दर्ज करें।

**Q: Two-Step Verification PIN क्या है?**
A: अगर आपने WhatsApp Business Manager में Two-Step Verification enable किया है, तो setup के दौरान वह 6-digit PIN दर्ज करना होगा। यह SMS verification code से अलग है।

**Q: क्या मैं कई WhatsApp numbers connect कर सकता हूं?**
A: हाँ, आप कई WhatsApp Business numbers connect कर सकते हैं। प्रत्येक number को एक अलग (या same) AI agent से connect किया जा सकता है।
