# Configuration विकल्प

import { Callout } from 'nextra/components'

सभी agent configuration options का detailed guide।

## Page Structure

Agent edit page में तीन tabs हैं:

| Tab | Purpose |
|-----|---------|
| **Configuration** | Core settings (status, name, persona, LLM, messages) |
| **Knowledge Access** | Agent कौन से documents उपयोग कर सकता है यह control करें |
| **Integrations** | External channels से connect करें (Telegram, Discord, आदि) |

## Configuration Tab

### Status

अपने agent की availability control करें:

| Status | Playground | Integrations | Notes |
|--------|------------|--------------|-------|
| **Testing** | ✅ Enabled | ❌ Disabled | नए agents के लिए default। Live जाने से पहले test करें। |
| **Active** | ✅ Enabled | ✅ Enabled | Production use के लिए तैयार। |
| **Inactive** | ❌ Disabled | ❌ Disabled | अस्थायी रूप से disabled। |
| **Archived** | ❌ Disabled | ❌ Disabled | Main list से hidden। |

<Callout type="warning">
  यदि आपके agent में connected integrations हैं और आप Active से किसी अन्य status में बदलते हैं, तो आपको एक confirmation dialog दिखेगा जो बताएगा कि agent connected channels पर respond करना बंद कर देगा।
</Callout>

### बुनियादी Settings

- **Name** — Dashboard में agent को identify करता है
- **Description** — Agent के उद्देश्य के बारे में internal notes

### LLM Configuration

आपके agent को power करने वाले AI model को control करें।

**Default Mode (Advanced toggle off):**
- आपके organization के tier defaults का उपयोग करता है
- एक info box दिखाता है जो बताता है कि tier defaults उपयोग में हैं
- अधिकांश use cases के लिए recommended

**Advanced Mode (Advanced toggle on):**

| Setting | Description |
|---------|-------------|
| **Model** | अपने plan के आधार पर available AI models में से select करें |
| **Temperature** | Response creativity को control करता है (0.0-1.0) |

#### Temperature Guide

| Value | Behavior |
|-------|----------|
| 0.0 - 0.3 | Focused, deterministic responses |
| 0.4 - 0.7 | Creativity और consistency का संतुलन |
| 0.8 - 1.0 | अधिक creative, varied responses |

**Recommendation:** Documents पर based factual Q&A के लिए 0.3-0.5 से शुरू करें।

#### Show Document References

यह toggle (Advanced mode की परवाह किए बिना हमेशा visible) control करता है कि agent responses में source citations शामिल करे या नहीं:

- **Off** (default) — Responses source documents का उल्लेख नहीं करतीं
- **On** — Responses में source documents के references शामिल होते हैं

<Callout type="important">
  Transparency की ज़रूरत वाले use cases के लिए document references enable करें, जैसे legal, compliance, या internal content जहाँ users को sources verify करने की ज़रूरत हो।
</Callout>

### भाषा Support

आपका agent हर user message की भाषा automatically detect करता है और उसी भाषा में respond करता है — कोई manual configuration की ज़रूरत नहीं। Arabic, French, German, Spanish, Turkish, Chinese, Japanese, और अन्य सहित 176 languages out of the box supported हैं।

### Agent Persona

वे instructions जो agent behavior को control करती हैं। Best practices के लिए [Agent Personas](/agents/agent-personas) देखें।

**Available actions:**
- **Generate** — [Agent Persona Builder](/agents/persona-builder) खोलता है
- **Edit** — Persona को directly लिखने या modify करने के लिए slide-out panel खोलता है

Persona text area पर click करें edit panel खोलने के लिए।

**Platform Rules Box:**
सभी agents पर automatically apply होने वाले platform reliability rules देखने के लिए click करें:
- No fabrication — facts नहीं बनाएगा
- Acknowledges gaps — जब उचित हो तो "I don't know" कहता है
- Resists speculation — गायब जानकारी का अनुमान नहीं लगाएगा
- No professional impersonation — lawyers, doctors, आदि का रूप नहीं धारण करेगा
- Corrects false premises — गलत assumptions indicate करता है
- Blocks harmful content — अनुचित requests refuse करता है

<Callout type="info">
  Platform rules सुनिश्चित करती हैं कि सभी agents reliably और safely behave करें। इन्हें disable या modify नहीं किया जा सकता।
</Callout>

## Knowledge Access Tab

Control करें कि आपका agent queries का जवाब देते समय कौन से documents access कर सकता है।

### Access Modes

| Mode | Behavior | कब उपयोग करें |
|------|----------|-------------|
| **Exclude Mode** | Agent चुने गए को छोड़कर सभी documents access करता है | सब कुछ allow करते हुए sensitive documents hide करें |
| **Include Mode** | Agent ONLY selected items access करता है | Agent को specific set of documents तक restrict करें |

### Selection Options

Multiple selection types का उपयोग करके access fine-tune करें:

- **Folders** — पूरे folders और उनके सभी documents select करें
- **Tags** — Documents को उनके assigned tags से filter करें
- **Individual Documents** — Selected folders के भीतर specific documents include या exclude करें

### Access Preview

Preview panel आपके current selections के आधार पर effective document access दिखाता है। Save करने से पहले अपना configuration verify करने के लिए इसका उपयोग करें।

<Callout type="info">
  यदि आप specific restrictions के साथ broad access चाहते हैं तो **Exclude Mode** से शुरू करें। **Include Mode** का उपयोग तब करें जब आपको exactly control करने की ज़रूरत हो कि agent कौन से documents reference कर सकता है।
</Callout>

हर channel के detailed setup guides के लिए [Integrations documentation](/integrations) देखें।

## Human Handoff

Live chat handoff enable करें ताकि आपका AI agent users के request करने पर conversations को एक real human को transfer कर सके।

**Enable कैसे करें:**

1. **Configuration** tab में, **Human Handoff** section तक scroll करें
2. **Enable Human Handoff** toggle करें
3. Messages configure करें:
   - **Handoff Message** — Transfer शुरू होने पर user को दिखाया जाता है
   - **Resolve Message** — Human agent conversation समाप्त करने पर दिखाया जाता है
   - **Max Wait Time** — यदि कोई agent accept नहीं करता तो auto-expire (default: 30 minutes)
4. **Save Changes** पर click करें

जब कोई user किसी human से बात करने के लिए कहता है, तो AI **Inbox** page पर visible एक handoff request बनाता है। कोई team member accept करता है, user के channel पर chat करता है, और समाप्त होने पर resolve करता है।

<Callout type="info">
  Human Handoff सभी plans पर available है। इसे Configuration tab में प्रति agent enable करें।
</Callout>

## Agent Test करना

Changes save करने से पहले, आप अपना agent test कर सकते हैं:

1. Form के नीचे **Test Agent** button पर click करें
2. Playground panel slide होकर खुलता है
3. अपने agent के साथ test conversation करें
4. समाप्त होने पर Playground बंद करें

<Callout type="info">
  Agent status Archived या Inactive होने पर Test Agent button disabled होता है। Testing enable करने के लिए status Active या Testing में बदलें।
</Callout>

## Changes Save करना

| Button | Action |
|--------|--------|
| **Save Changes** | सभी modifications save करें |
| **Test Agent** | Test करने के लिए Playground खोलें |

Changes discard करने के लिए, back button या sidebar navigation का उपयोग करके navigate away करें।

**क्या save होता है:**
- केवल changed fields update होती हैं
- यदि कुछ भी modify नहीं हुआ तो "No changes to save" दिखेगा
- Save के बाद success या error messages appear होते हैं

**Partial Save Handling:**
यदि कुछ changes save होती हैं लेकिन अन्य fail होती हैं, तो आपको बताया जाएगा कि कौन से sections fail हुए और page current state दिखाने के लिए refresh होगा।

<Callout type="info">
  Agent settings में changes save करने के बाद तुरंत effect होती हैं। Changes करने के बाद Playground में test करें।
</Callout>
