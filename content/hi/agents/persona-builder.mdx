# Agent Persona Builder

import { Callout } from 'nextra/components'

Characteristics selection का उपयोग करके seconds में professional agent personas generate करें।

<Callout type="info">
  Agent Persona Builder आपको scratch से prompts लिखे बिना effective agent personas बनाने में मदद करता है।
</Callout>

## शुरू करें

1. **Agents** पर navigate करें और एक agent create या edit करें
2. Agent Persona field के पास **Generate** click करें
3. Agent Persona Builder panel तीन tabs के साथ slide होकर खुलता है

## Builder Tabs

### Custom Build

5 categories में characteristics select करके एक unique persona बनाएं:

| Category | यह क्या control करती है |
|----------|------------------|
| **Role & Identity** | Agent का primary function (customer support, sales, tech support, HR, आदि) |
| **Communication Style** | Formality, tone, verbosity, और technical level |
| **Response Behavior** | Format (conversational vs bullet points), proactivity, question handling |
| **Operational Boundaries** | Agent topic पर कितनी strictly रहती है, escalation tendency |
| **Knowledge Integration** | Citation style, agent uncertainty में कैसे respond करता है |

**Category Navigation:**
- Expand या collapse करने के लिए किसी भी category header पर click करें
- हर category में dropdown options के साथ multiple fields हैं
- Selected options highlighted होते हैं

**Reset Button:**
सभी defaults restore करने के लिए Custom Build section में **Reset** click करें।

#### Role & Identity Options

अपने agent का primary function चुनें:
- Customer Support Representative
- Sales Consultant
- Technical Support Specialist
- HR/People Operations
- General Assistant
- Custom role

#### Communication Style

अपने agent के communicate करने के तरीके को fine-tune करें:

| Setting | Options |
|---------|---------|
| **Formality** | Formal, Professional, Casual |
| **Tone** | Warm & Friendly, Neutral, Direct |
| **Verbosity** | Concise, Balanced, Detailed |
| **Technical Level** | Non-technical, Mixed, Technical |

#### Tone Options

Available tone presets:
- Empathetic & Supportive
- Confident & Authoritative
- Calm & Reassuring
- Enthusiastic & Engaging
- Neutral & Objective

#### Detail Levels

- **Concise** — संक्षिप्त, to-the-point responses
- **Balanced** — Clear explanations के साथ moderate detail
- **Comprehensive** — Thorough, detailed responses

#### Response Behavior

Responses कैसे structured हों यह control करें:
- **Format** — Conversational paragraphs या structured bullet points
- **Proactivity** — Agent related topics suggest करे या नहीं
- **Question Handling** — Agent clarification कैसे माँगता है

#### Operational Boundaries

अपने agent के लिए guardrails set करें:
- **Scope Strictness** — Agent documented topics के भीतर कितनी strictly रहती है
- **Escalation** — Human support से contact करने का suggest कब करें
- **Out-of-scope Handling** — Off-topic सवालों का जवाब कैसे दें

#### Knowledge Integration

Agent आपके documents का उपयोग कैसे करे यह configure करें:
- **Citation Style** — Specific documents reference करें या नहीं
- **Uncertainty Handling** — Unsure होने पर कैसे respond करें

### Use Preset

Common use cases के लिए pre-configured personas load करें:

- **System Templates** — Platform द्वारा provided presets specific roles के लिए optimized
- **My Templates** — आपके organization के admins द्वारा saved presets

**Preset का उपयोग करना:**
1. **Use Preset** tab click करें
2. Available presets browse करें
3. Select करने के लिए preset पर click करें
4. Preset Custom Build tab में load होती है
5. ज़रूरत पड़ने पर कोई भी characteristics adjust करें
6. **Generate Persona** click करें

### Platform Rules

सभी agents पर automatically apply होने वाले read-only guardrails देखें:

- **No fabrication** — आपके content में नहीं होने वाले facts, numbers, या dates नहीं बनाएगा
- **Acknowledges gaps** — Guess करने के बजाय "I don't have that information" कहता है
- **Resists speculation** — माँगने पर भी missing values estimate नहीं करेगा
- **No professional impersonation** — Attorneys, doctors, CPAs, या financial advisors का role-play नहीं करेगा
- **Corrects false premises** — जवाब देने से पहले गलत assumptions indicate करता है
- **Blocks harmful content** — Self-harm, explicit, या fraudulent content refuse करता है

<Callout type="info">
  Platform rules सुनिश्चित करती हैं कि सभी agents persona configuration की परवाह किए बिना reliably और safely behave करें। इन्हें disable नहीं किया जा सकता।
</Callout>

## Persona Generate करना

**Generation से पहले:**
Panel आपके configuration options full width पर दिखाता है।

**Generate Button:**
Custom Build tab पर होने पर:
1. नीचे **Generate Persona** click करें
2. Generate होते समय एक loading state दिखाई देती है
3. कुछ seconds लगते हैं

**Generation के बाद:**
Panel layout split view में बदल जाती है:
- **बाईं ओर:** आपके configuration options
- **दाईं ओर:** Generated prompt preview

**Preview Panel Features:**
- Generated system prompt का full text
- Editable — आप text directly modify कर सकते हैं
- नीचे character count displayed

## Generate करने के बाद

एक generated persona होने पर, आपके पास कई options हैं:

### Regenerate

Same settings के साथ एक नया version बनाने के लिए **Regenerate** click करें। हर generation slightly different results produce करती है।

### Prompt Edit करें

Generated text directly edit करने के लिए preview panel में click करें। अपने specific use case के लिए ज़रूरी कोई भी adjustments करें।

### Save as Preset

Reuse के लिए अपनी configuration save करने के लिए **Save as Preset** click करें:
1. Dialog preset name माँगता है
2. एक descriptive नाम enter करें
3. Preset **My Templates** के अंतर्गत आपके organization में save हो जाती है

<Callout type="important">
  Saved presets आपके organization के सभी admins के लिए available हैं। Multiple agents में consistent agent personalities maintain करने के लिए इनका उपयोग करें।
</Callout>

### Agent पर Apply करें

इस persona का उपयोग करने के लिए **Apply to Agent** click करें:
1. Prompt आपके agent के system prompt field में insert हो जाता है
2. Builder बंद हो जाता है
3. अन्य agent settings configure करना जारी रखें

## Best Practices

- **Preset से शुरू करें** — Starting point के रूप में system templates का उपयोग करें, फिर customize करें
- **Role को purpose से match करें** — एक ऐसा role चुनें जो आपके agent के actual function से align हो
- **Verbosity balance करें** — Quick Q&A के लिए Concise बेहतर काम करता है, complex topics के लिए detailed
- **Generate करने के बाद test करें** — New persona apply करने के बाद हमेशा Playground में agent test करें
- **Iterate करें** — अगर results ठीक नहीं हैं तो different settings के साथ regenerate करें
- **Focused रखें** — अत्यधिक complex prompts agent को confuse कर सकते हैं
