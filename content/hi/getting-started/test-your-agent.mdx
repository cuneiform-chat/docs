# Agent का परीक्षण करें

Agent deploy करने से पहले, Playground का उपयोग करके उसके responses test करें और उसके behavior को fine-tune करें।

## Playground तक पहुंचें

1. Sidebar में **Agents** पर जाएं
2. अपने agent card पर **Test** पर क्लिक करें
3. Playground एक side panel के रूप में खुलता है — chatting शुरू करें!

अधिक space के लिए conversation list छिपाने के लिए sidebar toggle का उपयोग करें। बिना send किए नई lines जोड़ने के लिए **Shift+Enter** दबाएं।

## Agent को Test करें

### Sample प्रश्न पूछें

वे प्रश्न आज़माएं जो आपके users पूछ सकते हैं:

- आपके documents द्वारा सीधे उत्तर दिए जाने वाले प्रश्न
- Follow-up प्रश्न जिनके लिए context की आवश्यकता है
- Edge cases और अस्पष्ट queries
- आपके content के बाहर के प्रश्न (boundaries test करने के लिए)

### Responses का मूल्यांकन करें

हर response के लिए विचार करें:

- **Accuracy** — क्या जानकारी सही है?
- **Relevance** — क्या यह वास्तविक प्रश्न का उत्तर देता है?
- **Tone** — क्या यह आपकी अपेक्षित style से मेल खाता है?
- **Sources** — क्या document references helpful हैं?

## Agent को बेहतर बनाएं

Testing के आधार पर, आप adjust करना चाहेंगे:

### Agent Persona

यदि responses बिल्कुल सही नहीं हैं, तो agent persona को refine करें:

- सामान्य scenarios के लिए specific instructions जोड़ें
- Tone और personality स्पष्ट करें
- agent को क्या करना चाहिए और क्या नहीं, इसके लिए boundaries निर्धारित करें

### Content

यदि agent जानकारी नहीं ढूंढ पाता:

- जांचें कि relevant documents upload हैं
- Verify करें कि documents successfully process हुए
- अधिक detailed content जोड़ने पर विचार करें

## Conversation History

Playground एक session के भीतर conversation history बनाए रखता है। इसका उपयोग test करने के लिए करें:

- Multi-turn conversations
- Context retention
- Follow-up प्रश्न

जब agent respond करता है, तो आप tool indicators देखेंगे जो दिखाते हैं कि वह क्या कर रहा है (documents खोजना, आपकी query process करना, आदि)। Response रद्द करने के लिए **Stop** पर क्लिक करें।

## Agent को Activate करें

नए agents **Testing** status में शुरू होते हैं — आप Playground में test कर सकते हैं, लेकिन channel integrations disabled रहती हैं।

Integrations enable करने के लिए:

1. अपने agent का edit page खोलें
2. **Status** dropdown को "Testing" से "Active" में बदलें
3. **Save** पर क्लिक करें

Active होने के बाद, आप विभिन्न channels पर deploy कर सकते हैं:

- [Telegram](/integrations/telegram) — Telegram से connect करें
- [Discord](/integrations/discord) — अपने Discord server में जोड़ें
- [Slack](/integrations/slack) — Slack workspaces के साथ integrate करें
- [WhatsApp](/integrations/whatsapp) — WhatsApp Business से connect करें
- [Messenger](/integrations/facebook) — Facebook Messenger से connect करें
- [Google Chat](/integrations/google-chat) — Google Workspace के साथ integrate करें
