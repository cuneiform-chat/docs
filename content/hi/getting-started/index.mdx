# शुरुआत करें

Cuneiform Chat के साथ कुछ ही मिनटों में शुरुआत करें। यह guide आपको अपने documents पर trained पहला AI chatbot बनाने के हर चरण से गुज़ारती है।

## आप क्या सीखेंगे

- अपना account कैसे बनाएं और set up करें
- अपने content में documents कैसे upload करें
- अपना पहला agent कैसे बनाएं और configure करें
- Playground में अपने agent को कैसे test करें

## आवश्यकताएं

- एक valid email address
- वे documents जिनसे आपका chatbot सीखे (PDFs, Word docs, text files, आदि)
