# Platform Assistant

Saba से मिलें, Cuneiform Chat में navigate करने के लिए आपका AI सहायक।

## Saba क्या है?

Saba एक in-app AI assistant है जो आपको Cuneiform Chat का अधिकतम लाभ उठाने में मदद करता है। Nisaba — लेखन और लिपि कला की Sumerian देवी — के नाम पर रखा गया, Saba clay tablets से chatbots तक की हमारी यात्रा का प्रतिनिधित्व करता है।

Saba आपकी मदद कर सकता है:

- Platform features के बारे में जानें और उन्हें कैसे उपयोग करें
- अपने agents, documents, और integrations के बारे में जानकारी प्राप्त करें
- अपने billing और subscription की जानकारी समझें
- सामान्य समस्याओं का समाधान करें

## Saba तक पहुंचें

### Floating Button

अपनी screen के **bottom-right corner** में Saba icon देखें। Assistant खोलने के लिए उस पर क्लिक करें।

### Keyboard Shortcuts

| Action | Mac | Windows/Linux |
|--------|-----|---------------|
| Saba खोलें/बंद करें | `Cmd + K` | `Ctrl + K` |
| नई Conversation | `Cmd + N` | `Ctrl + N` |
| बंद करें | `Escape` | `Escape` |

## Saba किसमें मदद कर सकता है

### Platform Features

इस तरह के प्रश्न पूछें:

- "Agent कैसे बनाएं?"
- "कौन से file formats support होते हैं?"
- "Slack कैसे connect करें?"

### आपका Data

Saba specific प्रश्नों का उत्तर देने के लिए आपके organization का data access कर सकता है:

- "मेरे पास कितने agents हैं?"
- "मेरे content में कौन से documents हैं?"
- "कौन सी integrations active हैं?"

### Billing की जानकारी

अपने account के बारे में जल्दी उत्तर पाएं:

- "मैं किस plan पर हूं?"
- "मैंने कितने credits use किए हैं?"
- "मेरी billing period कब समाप्त होती है?"

## Features

### Query Mode

Input field के बगल में button का उपयोग करके response modes के बीच toggle करें:

- **Fast** (Zap icon) — सरल प्रश्नों के लिए quick responses
- **Reasoning** (Brain icon) — जटिल प्रश्नों के लिए अधिक thorough analysis

आपकी preference sessions में save रहती है।

### Automatic Language Detection

Saba automatically आपके message की भाषा detect करता है और उसी भाषा में respond करता है — कोई configuration की आवश्यकता नहीं। 176 languages support होती हैं, इसलिए आप अपनी पसंदीदा भाषा में type कर सकते हैं और Saba उसी के अनुसार reply करेगा।

### Voice Input

typing के बजाय अपना प्रश्न बोलने के लिए send button के बगल में **microphone icon** पर क्लिक करें।

### Slash Commands

Quick commands देखने के लिए input field में `/` type करें:

| Command | क्या करता है |
|---------|--------------|
| `/health` | आपके Organization का स्वास्थ्य अवलोकन |
| `/agents` | status के साथ सभी agents की list |
| `/analytics` | आपकी agent performance metrics |
| `/usage` | आपकी मासिक usage statistics दिखाएं |
| `/billing` | आपका plan और credit विवरण |
| `/integrations` | आपकी active channel integrations |
| `/conversations` | हाल की conversation activity दिखाएं |
| `/help` | उपलब्ध commands की list |

### Conversation History

Saba के साथ आपकी conversations automatically save होती हैं। जहां छोड़ा था वहां से जारी रखने के लिए sidebar से पुरानी conversations access करें।

### Suggested Questions

Saba आपके current page के आधार पर relevant प्रश्न suggest करता है। जब आप assistant खोलते हैं तो ये quick-start options के रूप में दिखाई देते हैं।

### Follow-up Suggestions

हर response के बाद, Saba related प्रश्न offer करता है जो आप आगे पूछना चाहते हैं।

### Conversations Export करें

Export button का उपयोग करके conversations save करें:

- **Download as Markdown** — formatting के साथ .md file के रूप में save करें
- **Download as Text** — plain .txt file के रूप में save करें
- **Copy to Clipboard** — पूरी conversation copy करें

### Feedback

हर response पर feedback options के साथ Saba को बेहतर बनाने में मदद करें:

- **Thumbs up/down** — response quality पर quick feedback
- **Submit Feedback** — assistant को बेहतर बनाने में मदद के लिए detailed comments दें

## बेहतर परिणामों के लिए Tips
