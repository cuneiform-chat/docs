# Content जोड़ें

आपके chatbot का ज्ञान आपके द्वारा दिए गए content से आता है। यह guide आपको documents upload करने और websites crawl करके अपना content बनाने का तरीका बताती है।

## Content तक पहुंचें

1. अपने Cuneiform Chat dashboard में sign in करें
2. Sidebar में **Content** पर जाएं
3. **Upload Documents** पर क्लिक करें या files drag और drop करें

## समर्थित File प्रकार

Cuneiform Chat कई document formats को support करता है:

| Format | Extensions | विवरण |
|--------|-----------|-------|
| PDF | `.pdf` | Text-based और scanned (OCR) |
| Word | `.docx`, `.doc` | Microsoft Word documents |
| Text | `.txt`, `.md`, `.rtf` | Plain text, Markdown, Rich Text |
| PowerPoint | `.pptx`, `.ppt` | Presentation slides |
| Web/Data | `.html`, `.htm`, `.json`, `.xml` | Web pages और structured data |

## Upload के तरीके

### सीधा Upload

1. **Upload Documents** पर क्लिक करें
2. अपने computer से files चुनें
3. Processing पूरी होने तक प्रतीक्षा करें

### Drag और Drop

अपने computer से files को drag करें और Content area में drop करें।

### Cloud Storage

seamless import के लिए अपना cloud storage connect करें:

- **Google Drive** — अपने Drive से सीधे import करें
- **Dropbox** — अपना Dropbox account connect करें
- **OneDrive** — Microsoft OneDrive से import करें
- **Box** — अपना Box account connect करें

setup के निर्देशों के लिए [Cloud Storage Integration](/knowledge-base/cloud-storage) देखें।

### Website Crawling

Public websites crawl करें और content को documents के रूप में import करें:

1. **Content** पर जाएं और **Website** tab पर क्लिक करें
2. एक URL डालें और **Crawl** पर क्लिक करें
3. Crawl किए गए pages review और edit करें
4. Pages चुनें और **Process Selected** पर क्लिक करें

Crawler 2 levels deep तक links follow करता है। आप कितने pages crawl कर सकते हैं यह आपके [plan](/billing/plans) पर निर्भर करता है।

पूरी guide के लिए [Website Crawling](/knowledge-base/website-crawling) देखें।

## Document Processing

Upload या crawl करने के बाद, आपका content automatically process होता है और आपके agents के लिए searchable बन जाता है।

import { Callout } from 'nextra/components'

<Callout type="info">
  Processing का समय document के आकार और जटिलता पर निर्भर करता है। अधिकांश documents कुछ ही मिनटों में complete हो जाते हैं। System automatically duplicate content detect करता है ताकि redundant uploads से बचा जा सके।
</Callout>

## सर्वोत्तम अभ्यास

- **मात्रा से बेहतर गुणवत्ता** — अच्छी तरह structured documents बेहतर responses देते हैं
- **Content को अद्यतन रखें** — भ्रम से बचने के लिए पुराने documents हटाएं
- **Folders से organize करें** — Documents को व्यवस्थित रखने के लिए folder structure का उपयोग करें
- **Selectively crawl करें** — Processing से पहले crawl किए गए pages review और edit करें ताकि navigation और boilerplate हटाया जा सके

## अगला चरण
