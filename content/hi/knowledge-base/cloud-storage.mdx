# Cloud Storage Integration

import { Callout } from 'nextra/components'

अपने cloud storage accounts से सीधे documents import करें। Google Drive, Dropbox, OneDrive, या Box से connect करके files को पहले download किए बिना अपने Content में जोड़ें।

## यहाँ कैसे जाएं

Sidebar में **Content** पर navigate करें। Page के शीर्ष पर, upload drop zone के पास, cloud storage icons दिखाई देते हैं।

## समर्थित Providers

| Provider | Icon Location | क्या Import कर सकते हैं |
|----------|---------------|------------------------|
| Google Drive | Cloud icons row | Files, Google Docs, Slides |
| Dropbox | Cloud icons row | आपके Dropbox से files |
| OneDrive | Cloud icons row | आपके OneDrive से files |
| Box | Cloud icons row | आपके Box account से files |

## Files Import कैसे करें

### Step 1: Provider Icon पर Click करें

अपने cloud storage provider का icon click करें। Hover करने पर provider का नाम दिखाने वाला tooltip दिखाई देगा।

### Step 2: Sign In करें

आपको sign in और access authorize करने के लिए prompt किया जाएगा। यह authorization आपके browser session के लिए remembered रहता है।

### Step 3: Files Select करें

एक file picker खुलता है जो आपके cloud storage contents दिखाता है:
- Files खोजने के लिए folders में navigate करें
- एक साथ कई files select करें
- केवल supported file types दिखाई जाती हैं (आपके plan के आधार पर)

### Step 4: Import करें

अपना selection confirm करने के लिए click करें। Files import के लिए queue होती हैं और processing automatically शुरू हो जाती है।

## Import Options

Import करने से पहले, आप configure कर सकते हैं:

| Option | विवरण |
|--------|-------|
| Premium Processing | बेहतर AI understanding के लिए enable करें (upload area के नीचे checkbox) |
| Target Folder | Folder row पर provider icon click करके सीधे folder में upload करें |

## Specific Folder में Import करना

आप cloud files को सीधे किसी folder में import कर सकते हैं:

1. अपने document browser में folder खोजें
2. Folder row पर hover करें
3. दिखाई देने वाले cloud storage icon पर click करें
4. अपने cloud storage से files select करें
5. Files directly उस folder में import हो जाती हैं

## Import के दौरान

- Progress indicator import status दिखाता है
- Files process होते ही आपके document list में दिखाई देती हैं
- Files import होते समय आप काम जारी रख सकते हैं
- यदि duplicates detect होते हैं, तो import complete होने के बाद आपको notify किया जाएगा

## Google Workspace Files

Google Drive native Google Workspace documents support करता है:
- **Google Docs** — Automatically text में convert होते हैं
- **Google Slides** — Automatically presentation format में convert होते हैं

<Callout type="info">
  Formatting और charts preserved नहीं होते — केवल text content extract किया जाता है।
</Callout>

## Permissions

Cuneiform Chat minimal permissions request करता है:
- केवल selected files का read access
- आपके cloud storage का कोई write access नहीं
- जो files आप explicitly select नहीं करते उन तक कोई access नहीं

<Callout type="info">
  आप किसी भी समय अपने cloud provider की settings के माध्यम से access revoke कर सकते हैं।
</Callout>

## Sync Behavior

Currently, cloud imports **one-time imports** हैं:
- Import के समय files copy की जाती हैं
- Cloud storage में changes automatically sync नहीं होते
- Content update करने के लिए, modified files दोबारा import करें

## Tips

- समय बचाने के लिए एक साथ कई files select करें
- Picker में केवल supported file types दिखाई देती हैं (आपके plan के आधार पर)
- बेहतर organization के लिए folder-level import उपयोग करें
- Import के बाद large files को process होने में अधिक समय लग सकता है

## सामान्य प्रश्न

**प्र: क्या मुझे हर बार re-authorize करना होगा?**
उ: आमतौर पर नहीं। यदि आपका session active है, तो icon click करने पर file picker directly खुलता है। Browser data clear करने या नया browser उपयोग करने के बाद कभी-कभी re-authorize करना पड़ सकता है।

**प्र: क्या मैं पूरे folders import कर सकता हूँ?**
उ: Currently, आप individual files select करते हैं। Picker में folders के अंदर navigate करके उनमें मौजूद files select करें।

**प्र: मेरी original files का क्या होता है?**
उ: आपकी cloud files unchanged रहती हैं। हम आपके Content में एक copy बनाते हैं।

**प्र: Picker में कुछ files क्यों नहीं दिख रहीं?**
उ: केवल supported file types दिखाई जाती हैं। Available formats के लिए [supported file types](/knowledge-base/supported-formats) check करें।

## Troubleshooting

### Authorization Issues

यदि connect नहीं हो पा रहे:
- Check करें कि आप सही account में sign in हैं
- Access revoke करके re-authorize करने की कोशिश करें
- अपने provider settings में third-party app access enabled है यह सुनिश्चित करें

### Import Failures

यदि files import fail हो रही हैं:
- Verify करें कि files supported formats में हैं
- Check करें कि files corrupted नहीं हैं
- सुनिश्चित करें कि आपके पास files access करने की permission है
- एक साथ कम files import करने की कोशिश करें
