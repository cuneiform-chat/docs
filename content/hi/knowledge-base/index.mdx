# Content

Content वह जगह है जहाँ आप अपने AI agents के लिए सभी documents प्रबंधित करते हैं। Documents अपलोड करें, उन्हें folders में व्यवस्थित करें, tags जोड़ें और control करें कि कौन से agents किस content तक पहुँच सकते हैं।

## यह कैसे काम करता है

1. **Content जोड़ें** — Documents अपलोड करें, cloud storage से import करें, या websites crawl करें
2. **Process** — Documents automatically process और index हो जाते हैं
3. **Search** — Agents प्रश्नों के उत्तर देते समय relevant content खोजते हैं
4. **Respond** — उत्तर आपके actual content के आधार पर generate होते हैं

## यहाँ कैसे जाएं

Sidebar menu में **Content** पर navigate करें। यह document management का आपका central hub है।

## आप क्या देखते हैं

### Upload Area

Page के शीर्ष पर:
- **Cloud Storage Icons** — Google Drive, Dropbox, OneDrive, या Box से files directly import करने के लिए click करें
- **Drop Zone** — Files drag and drop करें या local files browse करने के लिए click करें
- **Website Tab** — Public website content crawl और import करने के लिए Website tab पर switch करें

### Document Browser

Upload area के नीचे, एक table आपके सभी documents दिखाती है:

| Column | विवरण |
|--------|-------|
| Name | Document filename type icon और source indicator के साथ |
| Tags | Document को assigned labels |
| Status | Processing state (नीचे Document Status देखें) |
| Size | MB में file size |
| Type | File extension (PDF, DOCX, आदि) |
| Uploaded | Upload की date और time |
| Actions | Document operations के लिए menu |

### Toolbar

- **Search** — नाम से documents खोजें
- **Tag Filter** — केवल specific tags वाले documents दिखाएं
- **Refresh** — Document list update करें
- **New Folder** — Organization के लिए folder बनाएं
- **Fullscreen** — अधिक space के लिए browser expand करें

## Document Status

| Status | अर्थ |
|--------|------|
| Pending | Document processing के लिए queue में है |
| Uploaded | Document system में upload हो गया है |
| Validating | Document validate किया जा रहा है |
| Stored | Document store हो गया है और processing की प्रतीक्षा में है |
| Processing | Document analyze और index हो रहा है |
| Ready | Document process हो गया है और आपके agents के लिए उपलब्ध है |
| Completed | Document processing पूरी तरह complete है |
| Failed | Processing में error आई (retry किया जा सकता है) |

## Documents के साथ काम करना

### Document देखें

Document viewer खोलने के लिए किसी भी document row पर click करें, जो content और metadata दिखाता है।

### Document Actions

Quick action buttons देखने के लिए किसी document पर hover करें:
- **Tag** — Tags जोड़ें या हटाएं
- **Premium Processing** — Processing quality upgrade करें (यदि eligible हों)
- **Retry** — Failed documents को reprocess करें
- **Chat** — इस specific document के बारे में conversation करें

Actions menu (...) से:
- **Move to Folder** — Document को relocate करें
- **Reprocess** — Failed documents के लिए processing retry करें
- **Delete** — Document permanently हटाएं

## Best Practices

- **Content को current रखें** — Accuracy बनाए रखने के लिए नियमित रूप से documents update करें
- **Folders से organize करें** — आसान management के लिए related documents को group करें
- **Cross-cutting themes के लिए tags उपयोग करें** — Tags folders में documents खोजने में मदद करते हैं
- **Quality मायने रखती है** — Well-structured documents बेहतर AI responses देते हैं
- **Duplicates हटाएं** — एक ही content को कई बार upload करने से बचें
