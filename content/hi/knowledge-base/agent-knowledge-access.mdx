# Agent Knowledge Access

Control करें कि प्रत्येक agent प्रश्नों के उत्तर देते समय किन documents तक पहुँच सकता है। Agents को specific folders या tags तक restrict करें, या कुछ content को उनकी पहुँच से exclude करें।

## यहाँ कैसे जाएं

1. Sidebar में **Agents** पर navigate करें
2. Edit करने के लिए किसी agent पर click करें, या नया agent बनाएं
3. **Knowledge Access Control** section तक scroll करें

## Access Modes

Access mode determine करता है कि आपके selections agent के document access को कैसे प्रभावित करते हैं।

| Mode | Icon | विवरण | कब उपयोग करें |
|------|------|-------|--------------|
| **Exclude Mode** | Red X | Agent EXCEPT selected के सभी documents access करता है | Sensitive documents छुपाना है लेकिन बाकी सब allow करना है |
| **Include Mode** | Green Check | Agent ONLY selected documents access करता है | Agent को specific content तक restrict करना है |

### सही Mode चुनना

**Exclude Mode** (default):
- सभी documents तक full access से शुरू होता है
- Agent से block करने के लिए folders/tags select करें
- इनके लिए अच्छा: HR documents, financial data, या drafts छुपाना

**Include Mode**:
- No access से शुरू होता है
- Access grant करने के लिए folders/tags select करें
- इनके लिए अच्छा: Specific topics के लिए specialized agents बनाना

## Content Select करना

### Folders द्वारा

1. **Folders** tab पर click करें
2. Folders खोजने के लिए search box उपयोग करें
3. Include/exclude करने के लिए folders check करें
4. Individual documents select करने के लिए folders expand करें (arrow click करें)
5. Checkmark selected items दिखाता है; partial selection dash दिखाता है

### Tags द्वारा

1. **Tags** tab पर click करें
2. Tags खोजने के लिए search box उपयोग करें
3. Include/exclude करने के लिए tags check करें
4. प्रत्येक tag दिखाता है कि कितने documents उसका उपयोग करते हैं

## Preview Panel

दाईं ओर preview panel दिखाता है:
- Current selection के आधार पर total accessible documents
- Changes करते ही real-time में update होता है

## Changes Save करना

Existing agent edit करते समय:
1. अपने selections करें
2. **Save Changes** (green button) पर click करें
3. या unsaved changes undo करने के लिए **Reset Changes** पर click करें

नया agent बनाते समय:
- Agent form submit करने पर knowledge access settings automatically save हो जाती हैं

## Tips

- **Exclude Mode** तब उपयोग करें जब broad access चाहिए हो कुछ exceptions के साथ
- **Include Mode** focused, topic-specific agents के लिए उपयोग करें
- Precise control के लिए folders AND tags combine करें
- Save करने से पहले अपना selection verify करने के लिए preview panel check करें
- Include Mode के लिए, कम से कम एक folder या tag select करना जरूरी है

## सामान्य प्रश्न

**प्र: यदि मैं folders और tags दोनों select करूं तो क्या होगा?**
उ: Agent उन documents access कर सकता है जो आपके ANY selections से match करते हैं। Folders और tags inclusively combine होते हैं।

**प्र: क्या मैं agent को सब कुछ access दे सकता हूँ?**
उ: हाँ। Exclude Mode उपयोग करें और exclude करने के लिए कुछ भी select न करें। Agent को full access मिलेगा।

**प्र: क्या हो अगर document selected folder में है लेकिन उस पर excluded tag है?**
उ: Exclude Mode में, excluded content से कोई भी match access block करता है। Include Mode में, included content से कोई भी match access grant करता है।

**प्र: क्या यह existing conversations को affect करता है?**
उ: हाँ। Changes नए messages के लिए तुरंत effective हो जाते हैं। Agent updated access rules उपयोग करेगा।
