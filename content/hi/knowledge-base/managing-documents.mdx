# Documents प्रबंधित करें

अपने content documents को organize, update, और maintain करना सीखें। इसमें documents देखना, folders से organize करना, content update करना, और bulk operations करना शामिल है।

## यहाँ कैसे जाएं

1. Sidebar में **Content** पर click करें
2. List में अपने सभी documents देखें

## Documents देखना

Content section से अपने documents access करें:

- List में सभी documents देखें
- प्रत्येक document के लिए processing status देखें
- Check करें कि documents कब जोड़े या update किए गए

### Document Details

किसी भी document पर click करके देखें:

| जानकारी | विवरण |
|---------|-------|
| **File information** | नाम, size, format, upload date |
| **Processing status** | Pipeline में current state |
| **Chunk count** | बनाए गए searchable segments की संख्या |

## Documents Organize करना

### Folders उपयोग करना

Related documents organize करने के लिए folders बनाएं:

1. **New Folder** button (folder icon with plus) पर click करें
2. Folder का नाम enter करें
3. **Create** पर click करें

Suggested organization:
- Topic के अनुसार (Products, Policies, FAQs)
- Department के अनुसार (Sales, Support, HR)
- Document type के अनुसार (Guides, References, Tutorials)

### Documents Move करना

Folders के बीच documents move करें:

1. Document menu (⋮) पर click करें
2. **Move to Folder** select करें
3. Destination folder चुनें

### Tags उपयोग करना

Flexible categorization के लिए documents में tags जोड़ें:

1. Document menu (⋮) पर click करें
2. **Manage Tags** select करें
3. जरूरत के अनुसार tags जोड़ें या हटाएं

Tags folders के साथ काम करते हैं — primary organization के लिए folders और cross-cutting categories के लिए tags उपयोग करें।

## Documents Update करना

### Failed Document Reprocess करें

यदि कोई document process fail हो जाए, तो retry कर सकते हैं:

1. Document menu (⋮) पर click करें
2. **Reprocess** select करें

import { Callout } from 'nextra/components'

<Callout type="info">
  Reprocess option केवल "Failed" status वाले documents के लिए दिखाई देता है।
</Callout>

### Content Replace करना

Document का content update करने के लिए, पुराना version delete करें और नई file upload करें। Document automatically process होगा।

## Documents Delete करना

जिन documents की जरूरत न हो उन्हें हटाएं:

1. Document menu (⋮) पर click करें
2. **Delete** select करें
3. Deletion confirm करें

<Callout type="warning">
  Deleted documents permanently remove हो जाते हैं और recover नहीं किए जा सकते। Content आपके agents द्वारा searchable नहीं रहेगा।
</Callout>

## Bulk Operations

एक साथ कई documents manage करें:

1. Checkboxes उपयोग करके कई documents select करें
2. Bulk action menu उपयोग करें:
   - **Move to Folder** — Selected documents को folder में move करें
   - **Reprocess Failed** — Selection में failed documents के लिए processing retry करें

## Search और Filter

Specific documents खोजें:

| Feature | विवरण |
|---------|-------|
| **Search** | Document name से search करें |
| **Filter by folder** | उसके contents देखने के लिए document browser में folder click करें |
| **Filter by tag** | Specific tags वाले documents दिखाने के लिए tag filter उपयोग करें |

Documents upload date (सबसे नया पहले) के अनुसार sort किए जाते हैं।

## Storage Management

अपना storage usage track करें:

1. **Dashboard** पर जाएं
2. Current usage और limit दिखाने वाला "Storage Used" card देखें
3. Space free करने के लिए unnecessary documents delete करें

## Tips

- Content clean रखने के लिए नियमित रूप से outdated documents हटाएं
- Easy retrieval के लिए documents organize करने के लिए folders और tags उपयोग करें
- Failed documents check करें और जरूरत पड़ने पर reprocess करें
- Content update करने के लिए, पुराना document delete करके नया version upload करें
- एक साथ कई documents को folders में move करने के लिए bulk operations उपयोग करें
- Agents को confuse करने से बचाने के लिए duplicates delete करें

## सामान्य प्रश्न

**प्र: Document का content कैसे update करूं?**
उ: पुराना document delete करके नया version upload करें। नया document automatically process होगा।

**प्र: क्या deleted document recover हो सकता है?**
उ: नहीं, deleted documents permanently remove हो जाते हैं और recover नहीं किए जा सकते। Delete करने से पहले backup सुनिश्चित करें।

**प्र: Document successfully process हुआ या नहीं यह कैसे पता करूं?**
उ: Processing status column check करें। Complete होने पर documents **Ready** दिखाते हैं, या error होने पर **Failed**।

**प्र: Document process fail हो जाए तो क्या करूं?**
उ: Document menu (⋮) पर click करके **Reprocess** select करें। यह option केवल failed documents के लिए दिखाई देता है। यदि बार-बार fail हो, तो file format और size check करें।
