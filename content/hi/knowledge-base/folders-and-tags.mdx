# Folders और Tags

Folders और tags का उपयोग करके अपने Content documents व्यवस्थित करें। Folders hierarchical organization प्रदान करते हैं, जबकि tags folders में cross-cutting categorization की अनुमति देते हैं।

## यहाँ कैसे जाएं

Sidebar में **Content** पर navigate करें। Folders document browser में दिखाई देते हैं, और tag controls toolbar में होते हैं।

## Folders के साथ काम करना

### Folder बनाएं

1. Toolbar में **New Folder** button (folder icon with +) पर click करें
2. Folder का नाम enter करें (required)
3. Optional रूप से description जोड़ें
4. Color picker से color चुनें
5. **Create** पर click करें

### Folder Edit करें

1. Folder row पर three-dot menu (...) पर click करें
2. **Rename** select करें
3. नाम, description, या color update करें
4. **Save Changes** पर click करें

### Folder Delete करें

1. Folder row पर three-dot menu (...) पर click करें
2. **Delete** select करें
3. Deletion confirm करें

### Folder में Upload करें

- Files को सीधे folder row पर drag करें
- Upload icons reveal करने के लिए folder पर hover करें (cloud storage + local files)
- Folder को expand करने और उसके documents देखने के लिए click करें

## Tags के साथ काम करना

### Tags Manage करें (Create, Edit, Delete)

1. Toolbar में **Tag Filter** dropdown पर click करें
2. नीचे **Manage Tags** पर click करें
3. Modal में:
   - नया tag जोड़ने के लिए **Create Tag** पर click करें
   - Quick creation के लिए suggested tags उपयोग करें
   - Existing tags edit करें (नाम, color)
   - Unused tags delete करें

### Document में Tags जोड़ें

1. Document row पर hover करें
2. **Tag** button (tag icon) पर click करें
3. Manage Tags dialog में:
   - शीर्ष पर current tags देखें
   - Available tags search करें
   - Tags check करें जोड़ने के लिए
   - **Add X tags** button पर click करें

### Document से Tags हटाएं

1. Document के लिए Manage Tags dialog खोलें
2. "Current Tags" section में हटाने के लिए tags पर X click करें
3. **Remove X tags** button पर click करें

### Tags से Documents Filter करें

1. Toolbar में **Tag Filter** dropdown पर click करें
2. एक या अधिक tags select करें
3. केवल उन tags वाले documents दिखाए जाते हैं
4. Selected tags toolbar के नीचे filter bar में दिखाई देते हैं
5. वह filter हटाने के लिए tag chip पर X click करें, या **Clear all**

## Folders बनाम Tags

| Feature | Folders | Tags |
|---------|---------|------|
| Structure | Hierarchical (एक document में एक folder) | Flat (एक document में कई tags) |
| Best for | Broad categories, projects, departments | Topics, themes, status, cross-cutting concerns |
| Filtering | Contents देखने के लिए folder click करें | Folders में खोजने के लिए tag filter उपयोग करें |
| Document limit | एक document में एक folder | एक document में unlimited tags |

## Tips

- Major categories के लिए folders उपयोग करें (जैसे, "Product Docs", "HR Policies")
- Cross-cutting themes के लिए tags उपयोग करें (जैसे, "Q1-2024", "Compliance", "Draft")
- Visual organization के लिए folders और tags को color-code करें
- Tags usage count दिखाते हैं ताकि आप देख सकें कि कितने documents हर tag उपयोग करते हैं
- Precise document discovery के लिए folder और tag filtering combine करें

## सामान्य प्रश्न

**प्र: क्या एक document कई folders में हो सकता है?**
उ: नहीं, प्रत्येक document एक folder (या "Unfiled") में होता है। Cross-cutting categorization के लिए tags उपयोग करें।

**प्र: Folder delete करने पर documents का क्या होता है?**
उ: Documents वाले folders को delete नहीं किया जा सकता। पहले documents move या delete करें।

**प्र: Specific tag वाले सभी documents कैसे देखें?**
उ: Toolbar में Tag Filter dropdown उपयोग करें और tag select करें।
