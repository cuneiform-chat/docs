# Documents अपलोड करें

अपने content में documents अपलोड करें ताकि आपके AI agents उनका उपयोग प्रश्नों के उत्तर देने के लिए कर सकें। Documents automatically process होकर searchable बन जाते हैं।

## यहाँ कैसे जाएं

1. Admin Panel में log in करें
2. Sidebar menu में **Content** पर navigate करें
3. Page के शीर्ष पर upload area दिखाई देता है

## Upload के तरीके

### Local File Upload

1. Upload area पर सीधे files **drag and drop** करें, या
2. File browser खोलने के लिए upload area पर **click** करें
3. Upload करने के लिए एक या अधिक files select करें
4. Progress tracking के साथ files automatically upload होना शुरू हो जाती हैं

### Cloud Storage Import

अपने cloud storage providers से सीधे files import करें:

| Provider | Icon | कैसे उपयोग करें |
|----------|------|----------------|
| Google Drive | Google Drive icon | Google Drive picker खोलने के लिए click करें, files select करें |
| Dropbox | Dropbox icon | Dropbox chooser खोलने के लिए click करें, files select करें |
| OneDrive | OneDrive icon | OneDrive picker खोलने के लिए click करें, files select करें |
| Box | Box icon | Box picker खोलने के लिए click करें, files select करें |

किसी भी provider से files select करने के बाद, वे automatically आपके content में import हो जाती हैं।

## Upload Options

### Tags जोड़ना

Upload के दौरान optional रूप से documents को tags assign करें:

1. Upload करने से पहले **+ Add Tags** पर click करें
2. Dropdown से tags select करें
3. Selected tags सभी uploaded documents पर apply होंगे

## समर्थित File Types

आप जो file types upload कर सकते हैं वे आपके plan पर निर्भर करती हैं। सामान्य formats में शामिल हैं:

- **Documents:** PDF, DOCX, DOC, TXT, MD, RTF
- **Presentations:** PPTX, PPT
- **Web/Data:** HTML, HTM, JSON, XML

File size limits भी plan के अनुसार अलग होती हैं (upload area में दिखाई जाती हैं)।

पूरी सूची के लिए [समर्थित प्रारूप](/knowledge-base/supported-formats) देखें।

## Upload के दौरान

### Progress Tracking

- प्रत्येक file percentage bar के साथ upload progress दिखाती है
- Upload speed और अनुमानित remaining time दिखाया जाता है
- Files एक-एक करके process होती हैं

### Cancel Options

- **Individual file cancel:** किसी file के पास X पर click करें
- **सब cancel:** पूरा batch बंद करने के लिए "Cancel All Pending" पर click करें
- Upload के दौरान page छोड़ने की कोशिश करने पर warning दिखाई देती है

## Processing Status

Content में document status track करें:

| Status | अर्थ |
|--------|------|
| Uploading | Document system में upload हो रहा है |
| Ready | Document process हो गया है और आपके agents के लिए उपलब्ध है |
| Processing | Document analyze हो रहा है |
| Queued | Process होने की प्रतीक्षा में है |
| Retrying | Processing दोबारा try की जा रही है |
| Failed | Processing में error आई (retry किया जा सकता है) |

## Upload के बाद

### सफल Upload

- Successfully upload हुई files आपके document browser में दिखाई देती हैं
- Documents automatically search के लिए process होते हैं
- आप उन्हें folders में व्यवस्थित कर सकते हैं या tags जोड़ सकते हैं

### Duplicates का पता लगाना

- System automatically duplicate content का पता लगाता है
- यदि identical content वाली कोई file पहले से मौजूद है, तो आपको warning दिखेगी
- Error message में existing file की location दिखाई जाती है

### Errors से निपटना

- यदि कोई file upload fail होती है, तो error message कारण बताता है
- सामान्य समस्याओं में बहुत बड़ी file या unsupported format शामिल हैं
- आप individual files retry कर सकते हैं या उन्हें दोबारा upload कर सकते हैं

## Tips

- समय बचाने के लिए एक साथ कई files upload करें
- Documents को organized रखने के लिए upload के दौरान tags apply करें
- Upload area में दिखाए गए supported file types check करें

## सामान्य प्रश्न

**प्र: एक साथ कितनी files upload की जा सकती हैं?**
उ: आप batch upload के लिए कई files select कर सकते हैं। वे progress tracking के साथ एक-एक करके process होती हैं।

**प्र: मेरी file क्यों reject हुई?**
उ: Check करें कि file type supported है और file size limits के अंदर है (upload area में दिखाई जाती है)। कुछ files security कारणों से block हो सकती हैं।

**प्र: Processing में कितना समय लगता है?**
उ: Upload time file size और आपके connection पर निर्भर करता है। Upload के बाद, documents background में process होते हैं और automatically searchable बन जाते हैं।

**प्र: क्या मैं specific folder में upload कर सकता हूँ?**
उ: हाँ, आप folder menu का उपयोग करके सीधे folders में upload कर सकते हैं या upload के बाद documents व्यवस्थित कर सकते हैं।
