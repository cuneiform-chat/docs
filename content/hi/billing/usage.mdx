# उपयोग और Credits

Credits कैसे काम करते हैं यह समझें और अपनी consumption monitor करें।

## Credit System

Cuneiform Chat usage मापने के लिए credits (Platform Credits) उपयोग करता है:
- **AI queries** — जब आपके agents सवालों का जवाब देते हैं
- **Document processing** — जब documents upload और index किए जाते हैं
- **Embeddings** — Search के लिए vector generation

## Credits कैसे उपयोग होते हैं

### AI Queries

हर बार जब आपका agent कोई सवाल का जवाब देता है:
- Credits उपयोग किए गए AI model के आधार पर consume होते हैं
- लंबे responses थोड़े अधिक credits उपयोग कर सकते हैं
- Failed queries credits consume नहीं करती

### Document Processing

जब आप documents upload करते हैं:
- Content extract और process करने के लिए credits उपयोग होते हैं
- बड़े documents अधिक credits उपयोग करते हैं
- Re-processing अतिरिक्त credits उपयोग करती है

## Usage देखें

Sidebar में **Billing & Plans** से अपना usage access करें:

- **Current period usage** — इस billing cycle में उपयोग किए गए credits
- **Remaining credits** — उपलब्ध credits
- **Usage percentage** — Consumption दिखाता visual progress bar

## Usage Monitor करें

### Usage Display

Billing page दिखाता है:
- उपयोग किए गए vs. allocated credits
- Visual progress bar के साथ usage percentage
- Status indicator (normal, warning, exceeded, blocked)

### Usage Warnings

Platform अपने-आप warnings display करता है जैसे-जैसे आप limits के पास पहुंचते हैं:

| Threshold | क्या होता है |
|-----------|--------------|
| ~80% उपयोग | Billing page में Warning banner दिखता है |
| 100% उपयोग | Upgrade prompt के साथ "Limit Reached" banner |
| Blocked | अगले period या upgrade तक service paused |

ये warnings अपने-आप दिखती हैं — कोई configuration नहीं चाहिए।

## Limits पर क्या होता है

### Limits के पास पहुंचने पर

जैसे-जैसे आप credit limit के पास पहुंचते हैं, Billing page में warning banners दिखते हैं जो आपको upgrade करने या extra usage enable करने के लिए prompt करते हैं।

### Limits से अधिक होने पर

जब आप अपना monthly quota exceed करते हैं:
- एक warning banner "Limit Reached" indicate करता है
- बिना इंतजार किए जारी रखने के लिए **Extra Usage** enable करें
- या अधिक monthly credits के लिए अपना plan upgrade करें

### Blocked State

अगर extra usage balance भी समाप्त हो जाए:
- अगले billing period तक service pause होती है
- या अपने extra usage balance में funds जोड़ें

## Extra Usage

Extra usage आपको अपना monthly quota समाप्त होने पर service जारी रखने देता है।

### Extra Usage Enable करें

1. **Billing & Plans** पर जाएं
2. **Extra Usage** section ढूंढें
3. Enable करने के लिए toggle करें
4. Initial top-up complete करें (minimum $10)

### Extra Usage Manage करें

Enable होने के बाद, आप कर सकते हैं:

- **Balance देखें** — अपने available extra usage funds देखें
- **Funds जोड़ें** — Balance top up करें ($10-$500 प्रति transaction)
- **Spending cap set करें** — Monthly extra usage spending limit करें ($10-$500)

### Extra Usage कैसे काम करता है

- Charges आपके extra usage balance से deduct होते हैं
- Usage तब रुकती है जब आप spending cap तक पहुंचते हैं
- Balance billing periods के बीच carry over होता है
- Enable होने के बाद disable नहीं किया जा सकता (limit के लिए spending cap उपयोग करें)

<Callout type="info">
  Extra usage केवल paid plans (Starter, Plus, और Enterprise) के लिए उपलब्ध है।
</Callout>

## Billing Period

- Credits प्रत्येक billing period की शुरुआत में reset होते हैं
- आपकी billing date account settings में दिखती है
- अप्रयुक्त credits roll over नहीं हो सकते (अपना plan check करें)
