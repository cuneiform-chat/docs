# অ্যাকাউন্ট তৈরি করুন

আপনার অ্যাকাউন্ট তৈরি করে Cuneiform Chat দিয়ে শুরু করুন।

## সাইন আপ

1. [cuneiform.chat](https://cuneiform.chat)-এ যান
2. **Get Started** বা **Sign Up** ক্লিক করুন
3. আপনার সাইন-ইন পদ্ধতি বেছে নিন:
   - **Google** — এক ক্লিকে অ্যাক্সেসের জন্য "Sign in with Google" ক্লিক করুন
   - **Microsoft** — আপনার Microsoft 365 অ্যাকাউন্ট ব্যবহার করতে "Sign in with Microsoft" ক্লিক করুন
   - **Email** — আপনার ইমেইল লিখুন এবং "Continue with Email" ক্লিক করুন
4. ইমেইল ব্যবহার করলে, আপনার ইনবক্স চেক করুন এবং সাইন ইন করতে ম্যাজিক লিংকে ক্লিক করুন

## সাইন ইন অপশন

আপনি যেভাবে সাইন ইন করতে পারেন:
- **Google** — আপনার Google অ্যাকাউন্ট দিয়ে এক ক্লিকে সাইন ইন
- **Microsoft** — আপনার Microsoft 365 বা কর্মক্ষেত্রের অ্যাকাউন্ট দিয়ে সাইন ইন
- **ইমেইল ম্যাজিক লিংক** — আপনার ইমেইলে পাঠানো লিংকের মাধ্যমে পাসওয়ার্ডবিহীন সাইন-ইন

## আপনার Organization তৈরি করুন

প্রথমবার সাইন ইন করার পর, আপনাকে একটি Organization তৈরি করতে হবে। এটি আপনার এজেন্ট, ডকুমেন্ট এবং ইন্টিগ্রেশন পরিচালনার জন্য আপনার কর্মক্ষেত্র।

1. ড্যাশবোর্ডে **Create Organization** ক্লিক করুন
2. আপনার **Organization Name** লিখুন (কোম্পানি বা প্রজেক্টের নাম)
3. ঐচ্ছিকভাবে আপনার Organization-এর একটি **Description** যোগ করুন
4. আপনার **Industry** এবং **Company Size** নির্বাচন করুন
5. ঐচ্ছিকভাবে **Support Contact**-এর তথ্য যোগ করুন (ইমেইল, ফোন, ওয়েবসাইট, ঠিকানা) — ব্যবহারকারীদের মানবিক সহায়তা প্রয়োজন হলে আপনার এজেন্ট এগুলো শেয়ার করবে
6. **Create Organization** ক্লিক করুন

Organization আপনাকে সাহায্য করে:

- একটি অ্যাকাউন্টে একাধিক এজেন্ট পরিচালনা করতে
- টিম সদস্যদের আমন্ত্রণ জানাতে এবং অ্যাক্সেস নিয়ন্ত্রণ করতে
- আপনার সব চ্যাটবটের ব্যবহার ও বিলিং ট্র্যাক করতে

আপনি যেকোনো সময় আপনার প্রোফাইল মেনুর **Account Management** থেকে Organization-এর তথ্য আপডেট করতে পারেন।

## ট্রায়াল পিরিয়ড

নতুন অ্যাকাউন্টগুলো একটি ফ্রি ট্রায়াল দিয়ে শুরু হয় যাতে রয়েছে:
- সব ফিচারে সম্পূর্ণ অ্যাক্সেস
- ডকুমেন্ট প্রসেসিং ও AI কোয়েরি পরীক্ষা করার জন্য ক্রেডিট
- কোনো ক্রেডিট কার্ডের প্রয়োজন নেই
