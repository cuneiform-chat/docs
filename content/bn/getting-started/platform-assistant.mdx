# প্ল্যাটফর্ম সহকারী

Cuneiform Chat নেভিগেট করতে আপনার AI সহকারী Saba-র সাথে পরিচিত হোন।

## Saba কী?

Saba হলো একটি ইন-অ্যাপ AI সহকারী যা আপনাকে Cuneiform Chat থেকে সর্বোচ্চ সুবিধা পেতে সাহায্য করে। নিসাবা — লেখা ও লিপিকলার সুমেরীয় দেবী — এর নামে নামকরণ করা হয়েছে। Saba আমাদের মাটির ফলক থেকে চ্যাটবট পর্যন্ত যাত্রাকে প্রতিনিধিত্ব করে।

Saba আপনাকে সাহায্য করতে পারে:

- প্ল্যাটফর্মের ফিচারগুলো ও সেগুলো কীভাবে ব্যবহার করতে হয় তা জানতে
- আপনার এজেন্ট, ডকুমেন্ট ও ইন্টিগ্রেশনের তথ্য অ্যাক্সেস করতে
- আপনার বিলিং ও সাবস্ক্রিপশনের বিবরণ বুঝতে
- সাধারণ সমস্যা সমাধান করতে

## Saba অ্যাক্সেস করা

### ফ্লোটিং বাটন

আপনার স্ক্রিনের **নিচে-ডানদিকে** Saba আইকন খুঁজুন। সহকারী খুলতে এটিতে ক্লিক করুন।

### কীবোর্ড শর্টকাট

| অ্যাকশন | Mac | Windows/Linux |
|---------|-----|---------------|
| Saba খুলুন/বন্ধ করুন | `Cmd + K` | `Ctrl + K` |
| নতুন কথোপকথন | `Cmd + N` | `Ctrl + N` |
| বন্ধ করুন | `Escape` | `Escape` |

## Saba কীভাবে সাহায্য করতে পারে

### প্ল্যাটফর্ম ফিচার

এরকম প্রশ্ন করুন:

- "কীভাবে একটি এজেন্ট তৈরি করব?"
- "কোন ফাইল ফরম্যাট সমর্থিত?"
- "কীভাবে Slack সংযুক্ত করব?"

### আপনার ডেটা

Saba নির্দিষ্ট প্রশ্নের উত্তর দিতে আপনার Organization-এর ডেটা অ্যাক্সেস করতে পারে:

- "আমার কতগুলো এজেন্ট আছে?"
- "আমার বিষয়বস্তুতে কী কী ডকুমেন্ট আছে?"
- "কোন ইন্টিগ্রেশনগুলো সক্রিয়?"

### বিলিং তথ্য

আপনার অ্যাকাউন্ট সম্পর্কে দ্রুত উত্তর পান:

- "আমি কোন প্ল্যানে আছি?"
- "আমি কত ক্রেডিট ব্যবহার করেছি?"
- "আমার বিলিং পিরিয়ড কখন শেষ হবে?"

## ফিচারসমূহ

### কোয়েরি মোড

ইনপুট ফিল্ডের পাশের বাটন ব্যবহার করে উত্তরের মোড টগল করুন:

- **Fast** (Zap আইকন) — সহজ প্রশ্নের জন্য দ্রুত উত্তর
- **Reasoning** (Brain আইকন) — জটিল প্রশ্নের জন্য আরও গভীর বিশ্লেষণ

আপনার পছন্দ সেশন জুড়ে সংরক্ষিত থাকে।

### স্বয়ংক্রিয় ভাষা সনাক্তকরণ

Saba স্বয়ংক্রিয়ভাবে আপনার বার্তার ভাষা সনাক্ত করে এবং একই ভাষায় উত্তর দেয় — কোনো কনফিগারেশনের প্রয়োজন নেই। ১৭৬টি ভাষা সমর্থিত, তাই আপনি আপনার পছন্দের ভাষায় টাইপ করুন এবং Saba সেই অনুযায়ী উত্তর দেবে।

### ভয়েস ইনপুট

টাইপ করার বদলে প্রশ্ন বলতে সেন্ড বাটনের পাশের **মাইক্রোফোন আইকনে** ক্লিক করুন।

### স্ল্যাশ কমান্ড

দ্রুত কমান্ড দেখতে ইনপুট ফিল্ডে `/` টাইপ করুন:

| কমান্ড | কী করে |
|--------|--------|
| `/agents` | সব এজেন্ট তাদের স্ট্যাটাস সহ তালিকাভুক্ত করে |
| `/usage` | আপনার ব্যবহারের পরিসংখ্যান দেখায় |
| `/docs` | আপনার বিষয়বস্তুতে ডকুমেন্ট দেখায় |
| `/help` | উপলব্ধ কমান্ডের তালিকা দেখায় |
| `/new` | এজেন্ট তৈরির ধাপে ধাপে গাইডেন্স দেয় |
| `/conversations` | সাম্প্রতিক কথোপকথনের কার্যকলাপ দেখায় |

### কথোপকথনের ইতিহাস

Saba-র সাথে আপনার কথোপকথন স্বয়ংক্রিয়ভাবে সংরক্ষিত হয়। আগের কথোপকথন চালিয়ে যেতে সাইডবার থেকে অ্যাক্সেস করুন।

### প্রস্তাবিত প্রশ্ন

Saba আপনার বর্তমান পেজের ভিত্তিতে প্রাসঙ্গিক প্রশ্ন প্রস্তাব করে। আপনি সহকারী খুললে এগুলো কুইক-স্টার্ট অপশন হিসেবে দেখা যায়।

### ফলো-আপ প্রস্তাবনা

প্রতিটি উত্তরের পর, Saba সম্পর্কিত প্রশ্ন প্রস্তাব করে যা আপনি পরবর্তীতে জিজ্ঞাসা করতে চাইতে পারেন।

### কথোপকথন এক্সপোর্ট

এক্সপোর্ট বাটন ব্যবহার করে কথোপকথন সংরক্ষণ করুন:

- **Download as Markdown** — ফরম্যাটিং সহ .md ফাইল হিসেবে সংরক্ষণ করুন
- **Download as Text** — প্লেইন .txt ফাইল হিসেবে সংরক্ষণ করুন
- **Copy to Clipboard** — সম্পূর্ণ কথোপকথন কপি করুন

### ফিডব্যাক

প্রতিটি উত্তরে ফিডব্যাক অপশন দিয়ে Saba-কে উন্নত করতে সাহায্য করুন:

- **থাম্বস আপ/ডাউন** — উত্তরের মানের উপর দ্রুত ফিডব্যাক
- **Submit Feedback** — সহকারী উন্নত করতে বিস্তারিত মন্তব্য প্রদান করুন
