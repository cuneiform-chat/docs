# Playground-এ Testing

import { Callout } from 'nextra/components'

Playground হলো deployment-এর আগে agent test ও refine করার environment।

## Playground-এ প্রবেশ

1. Sidebar-এ **Agents**-এ navigate করুন
2. আপনার agent card-এ **Test**-এ click করুন (অথবা agent edit করার সময় **Test Agent**)
3. Playground একটি side panel হিসেবে slide করে খোলে — conversation শুরু করুন

<Callout type="info">
  Agent status **Archived** বা **Inactive** হলে Test button disabled থাকে। Testing enable করতে status **Active** বা **Testing**-এ পরিবর্তন করুন।
</Callout>

## কী Test করবেন

### মৌলিক কার্যকারিতা

- Agent আপনার document থেকে প্রশ্নের উত্তর দিতে পারে?
- Response সঠিক ও প্রাসঙ্গিক?
- Tone আপনার প্রত্যাশার সাথে মিলছে?

### Edge Cases

Agent-কে বিভ্রান্ত করতে পারে এমন scenario test করুন:

- আপনার document-এ নেই এমন প্রশ্ন
- অস্পষ্ট বা unclear প্রশ্ন
- একাধিক অংশের প্রশ্ন
- Context প্রয়োজন এমন follow-up প্রশ্ন

### Conversation Flow

Multi-turn conversation test করুন:

- Agent আগের message-এর context মনে রাখে?
- Topic পরিবর্তন সুন্দরভাবে handle করতে পারে?
- প্রয়োজনে clarification চায়?

## Response মূল্যায়ন

প্রতিটি response-এর জন্য বিবেচনা করুন:

| দিক | জিজ্ঞাসা করুন |
|-----|--------------|
| **Accuracy** | তথ্য সঠিক? |
| **Relevance** | প্রকৃত প্রশ্নের উত্তর দিয়েছে? |
| **Completeness** | গুরুত্বপূর্ণ কিছু বাদ পড়েছে? |
| **Tone** | আপনার brand voice-এর সাথে মিলছে? |
| **Length** | যথাযথভাবে সংক্ষিপ্ত বা বিস্তারিত? |

## ধাপে ধাপে উন্নতি

### সমস্যা চিহ্নিত করুন

সাধারণ সমস্যা ও সমাধান:

| সমস্যা | সমাধান |
|---------|--------|
| ভুল তথ্য | Document content পরীক্ষা করুন, retrieval উন্নত করুন |
| অতিরিক্ত verbose | Agent persona-তে "be concise" যোগ করুন |
| অতিরিক্ত formal/casual | Agent persona-তে tone adjust করুন |
| উত্তর জানে না | প্রাসঙ্গিক document যোগ করুন |
| তথ্য তৈরি করে | Prompt-এ boundary শক্তিশালী করুন |

### পরিবর্তন করুন

1. Playground testing-এ সমস্যা চিহ্নিত করুন
2. প্রাসঙ্গিক setting adjust করুন (prompt, document, configuration)
3. একই প্রশ্ন দিয়ে আবার test করুন
4. Fix অন্য আচরণ ভাঙেনি তা যাচাই করুন

## Test Scenario Checklist

একটি standard test question set তৈরি করুন:

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  আপনার test scenario save করুন এবং পরিবর্তনের পর regression ধরতে আবার চালান।
</Callout>

## Deployment-এর জন্য প্রস্তুত

আপনার agent প্রস্তুত যখন:

- ✅ সাধারণ প্রশ্নের সঠিক উত্তর দেয়
- ✅ Edge case সুন্দরভাবে handle করে
- ✅ যথাযথ tone বজায় রাখে
- ✅ নির্ধারিত সীমানা মেনে চলে
- ✅ Multi-turn conversation ভালো কাজ করে

এরপর, আপনার agent-কে [channel](/integrations)-এ deploy করুন যেখানে user-রা interact করবে।
