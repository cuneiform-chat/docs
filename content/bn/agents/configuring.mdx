# Configuration বিকল্পসমূহ

import { Callout } from 'nextra/components'

সব agent configuration option-এর বিস্তারিত গাইড।

## Page কাঠামো

Agent edit page-এ তিনটি tab আছে:

| Tab | উদ্দেশ্য |
|-----|---------|
| **Configuration** | মূল setting (status, name, persona, LLM, message) |
| **Knowledge Access** | Agent কোন document ব্যবহার করতে পারবে তা নিয়ন্ত্রণ |
| **Integrations** | বাহ্যিক channel-এ সংযোগ (Telegram, Discord ইত্যাদি) |

## Configuration Tab

### Status

আপনার agent-এর availability নিয়ন্ত্রণ করুন:

| Status | Playground | Integrations | নোট |
|--------|------------|--------------|------|
| **Testing** | ✅ Enabled | ❌ Disabled | নতুন agent-এর জন্য default। Live হওয়ার আগে test করুন। |
| **Active** | ✅ Enabled | ✅ Enabled | Production ব্যবহারের জন্য প্রস্তুত। |
| **Inactive** | ❌ Disabled | ❌ Disabled | সাময়িকভাবে disabled। |
| **Archived** | ❌ Disabled | ❌ Disabled | মূল তালিকা থেকে লুকানো। |

<Callout type="warning">
  যদি আপনার agent-এ connected integration থাকে এবং আপনি Active থেকে অন্য status-এ পরিবর্তন করেন, তাহলে একটি confirmation dialog দেখাবে যে agent connected channel-এ respond করা বন্ধ করবে।
</Callout>

### মৌলিক Setting

- **Name** — Dashboard-এ agent চিহ্নিত করে
- **Description** — Agent-এর উদ্দেশ্য সম্পর্কে internal নোট

### LLM Configuration

আপনার agent-কে power করা AI model নিয়ন্ত্রণ করুন।

**Default Mode (Advanced toggle off):**
- আপনার organization-এর tier default ব্যবহার করে
- Tier default ব্যবহৃত হচ্ছে এমন একটি info box দেখায়
- বেশিরভাগ ক্ষেত্রে recommended

**Advanced Mode (Advanced toggle on):**

| Setting | বিবরণ |
|---------|-------|
| **Model** | আপনার plan অনুযায়ী available AI model থেকে নির্বাচন করুন |
| **Temperature** | Response creativity নিয়ন্ত্রণ করে (0.0-1.0) |

#### Temperature গাইড

| মান | আচরণ |
|-----|-------|
| 0.0 - 0.3 | Focused, deterministic response |
| 0.4 - 0.7 | Balanced creativity ও consistency |
| 0.8 - 1.0 | আরও creative, বৈচিত্র্যময় response |

**সুপারিশ:** Document-ভিত্তিক factual Q&A-এর জন্য 0.3-0.5 দিয়ে শুরু করুন।

#### Show Document References

এই toggle (Advanced mode নির্বিশেষে সবসময় visible) নিয়ন্ত্রণ করে agent response-এ source citation অন্তর্ভুক্ত করবে কিনা:

- **Off** (default) — Response-এ source document উল্লেখ করে না
- **On** — Response-এ source document-এর reference অন্তর্ভুক্ত করে

<Callout type="important">
  স্বচ্ছতা প্রয়োজন এমন ক্ষেত্রে document reference enable করুন, যেমন legal, compliance, বা internal content যেখানে user-দের source যাচাই করা প্রয়োজন।
</Callout>

### ভাষা সমর্থন

আপনার agent স্বয়ংক্রিয়ভাবে প্রতিটি user message-এর ভাষা শনাক্ত করে এবং একই ভাষায় respond করে — কোনো manual configuration প্রয়োজন নেই। Arabic, French, German, Spanish, Turkish, Chinese, Japanese সহ ১৭৬টি ভাষা out of the box সমর্থিত।

### Agent Persona

Agent-এর আচরণ নিয়ন্ত্রণকারী নির্দেশনা। Best practice-এর জন্য [Agent Personas](/agents/agent-personas) দেখুন।

**উপলব্ধ action:**
- **Generate** — [Agent Persona Builder](/agents/persona-builder) খোলে
- **Edit** — সরাসরি persona লিখতে বা পরিবর্তন করতে একটি slide-out panel খোলে

Edit panel খুলতে persona text area-তে click করুন।

**Platform Rules Box:**
সব agent-এ স্বয়ংক্রিয়ভাবে প্রয়োগ হওয়া platform reliability rule দেখতে click করুন:
- No fabrication — তথ্য তৈরি করবে না
- Acknowledges gaps — যথাযথ সময়ে "আমি জানি না" বলে
- Resists speculation — অনুপস্থিত তথ্য অনুমান করবে না
- No professional impersonation — আইনজীবী, ডাক্তার ইত্যাদি সেজে কাজ করবে না
- Corrects false premises — ভুল ধারণা চিহ্নিত করে
- Blocks harmful content — অনুচিত request প্রত্যাখ্যান করে

<Callout type="info">
  Platform rule সব agent-কে নির্ভরযোগ্য ও নিরাপদভাবে কাজ করতে নিশ্চিত করে। এগুলো disable বা modify করা যায় না।
</Callout>

## Knowledge Access Tab

Query-এর respond করার সময় আপনার agent কোন document access করতে পারবে তা নিয়ন্ত্রণ করুন।

### Access Mode

| Mode | আচরণ | কখন ব্যবহার করবেন |
|------|-------|-------------------|
| **Exclude Mode** | Agent নির্বাচিত document ছাড়া সব document access করে | বাকি সবকিছুতে access রেখে sensitive document লুকান |
| **Include Mode** | Agent শুধুমাত্র নির্বাচিত item access করে | নির্দিষ্ট document set-এ agent সীমাবদ্ধ করুন |

### নির্বাচন বিকল্প

একাধিক selection type ব্যবহার করে access fine-tune করুন:

- **Folders** — সম্পূর্ণ folder ও তার মধ্যের সব document নির্বাচন করুন
- **Tags** — Assign করা tag অনুযায়ী document filter করুন
- **Individual Documents** — নির্বাচিত folder-এর মধ্যে নির্দিষ্ট document include বা exclude করুন

### Access Preview

Preview panel আপনার বর্তমান নির্বাচন অনুযায়ী কার্যকর document access দেখায়। Save করার আগে আপনার configuration যাচাই করতে এটি ব্যবহার করুন।

<Callout type="info">
  নির্দিষ্ট restriction সহ broad access চাইলে **Exclude Mode** দিয়ে শুরু করুন। Agent ঠিক কোন document reference করতে পারবে তার উপর tight control প্রয়োজন হলে **Include Mode** ব্যবহার করুন।
</Callout>

## Integrations Tab

আপনার agent-কে communication channel-এ সংযুক্ত করুন।

এই tab আপনার agent-এর জন্য উপলব্ধ integration option দেখায়। আপনি এই ধরনের channel সংযুক্ত করতে পারেন:
- Telegram
- Discord
- Slack
- WhatsApp
- Meta (Facebook Messenger)
- এবং আরও (আপনার plan অনুযায়ী)

প্রতিটি channel-এর বিস্তারিত setup guide-এর জন্য [Integrations documentation](/integrations) দেখুন।

## Human Handoff

Live chat handoff enable করুন যাতে user request করলে আপনার AI agent conversation একজন মানুষের কাছে transfer করতে পারে।

**কীভাবে enable করবেন:**

1. **Configuration** tab-এ **Human Handoff** section-এ scroll করুন
2. **Enable Human Handoff** toggle on করুন
3. Message-গুলো configure করুন:
   - **Handoff Message** — Transfer শুরু হলে user-কে দেখানো হয়
   - **Accept Message** — Human agent conversation accept করলে স্বয়ংক্রিয়ভাবে পাঠানো হয়
   - **Resolve Message** — Human agent conversation শেষ করলে দেখানো হয়
   - **Max Wait Time** — কেউ accept না করলে auto-expire (৫, ১৫, ৩০, ৬০, বা ১২০ মিনিট; default: ৩০ মিনিট)
4. **Save Changes**-এ click করুন

User যখন একজন মানুষের সাথে কথা বলতে চায়, AI **Inbox** page-এ দৃশ্যমান একটি handoff request তৈরি করে। একজন team member accept করে, তাদের channel-এ user-এর সাথে chat করে এবং শেষ হলে resolve করে।

<Callout type="info">
  Human Handoff সব plan-এ available। Configuration tab-এ প্রতি agent-এ enable করুন।
</Callout>

## আপনার Agent Testing

পরিবর্তন save করার আগে আপনি আপনার agent test করতে পারেন:

1. Form-এর নিচে **Test Agent** button-এ click করুন
2. Playground panel slide করে খোলে
3. আপনার agent-এর সাথে একটি test conversation করুন
4. শেষ হলে Playground বন্ধ করুন

<Callout type="info">
  Agent status Archived বা Inactive হলে Test Agent button disabled থাকে। Testing enable করতে status Active বা Testing-এ পরিবর্তন করুন।
</Callout>

## পরিবর্তন Save করা

| Button | Action |
|--------|--------|
| **Save Changes** | সব পরিবর্তন save করুন |
| **Test Agent** | Test করতে Playground খুলুন |

পরিবর্তন বাতিল করতে back button বা sidebar navigation ব্যবহার করে navigate away করুন।

**যা save হয়:**
- শুধুমাত্র পরিবর্তিত field update হয়
- কিছু পরিবর্তন না হলে "No changes to save" দেখাবে
- Save-এর পর success বা error message দেখায়

**Partial Save Handling:**
কিছু পরিবর্তন save হলে কিন্তু অন্যগুলো fail করলে, কোন section fail করেছে তা জানানো হবে এবং page বর্তমান state দেখাতে refresh হবে।

<Callout type="info">
  Agent setting-এর পরিবর্তন save করার সাথে সাথে কার্যকর হয়। পরিবর্তন করার পর Playground-এ test করুন।
</Callout>
