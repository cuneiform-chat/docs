# Agent তৈরি

import { Callout } from 'nextra/components'

Cuneiform Chat-এ নতুন agent কীভাবে তৈরি করবেন তা শিখুন।

## শুরু করুন

1. Sidebar-এ **Agents**-এ navigate করুন
2. উপরের ডানদিকে **Create Agent** button-এ click করুন
3. নিচের form section-গুলো পূরণ করুন

## মৌলিক তথ্য

এই section-এ আপনার agent সম্পর্কে প্রয়োজনীয় তথ্য থাকে।

| ক্ষেত্র | আবশ্যক | বিবরণ |
|---------|---------|-------|
| **Name** | হ্যাঁ | আপনার agent-এর একটি নাম (যেমন, "Customer Support Agent")। সর্বোচ্চ ১০০ অক্ষর। |
| **Description** | না | Agent কী করে তার সংক্ষিপ্ত বিবরণ। সর্বোচ্চ ৫০০ অক্ষর। |

**পরামর্শ:**
- Agent-এর উদ্দেশ্য বোঝায় এমন একটি বর্ণনামূলক নাম বেছে নিন
- Description আপনাকে এবং আপনার team-কে agent-এর ভূমিকা বুঝতে সাহায্য করে

## Agent Persona

Agent persona একটি system prompt-এর মাধ্যমে আপনার agent-এর আচরণ ও response নির্ধারণ করে।

**মূল উপাদানসমূহ:**

- **Platform Rules Box** — Built-in safety rule দেখায় যা স্বয়ংক্রিয়ভাবে প্রয়োগ হয় (detail দেখতে click করুন)
- **Generate Button** — আপনার persona তৈরিতে সাহায্য করতে [Agent Persona Builder](/agents/persona-builder) খোলে
- **Edit Button** — Persona manually লিখতে বা edit করতে একটি panel খোলে

### Platform Rules

এই safety guardrail-গুলো সব agent-এ স্বয়ংক্রিয়ভাবে প্রয়োগ হয়:

- **No fabrication** — আপনার content-এ নেই এমন তথ্য তৈরি করবে না
- **Acknowledges gaps** — যথাযথ সময়ে "আমি জানি না" বলে
- **Resists speculation** — অনুপস্থিত তথ্য অনুমান করবে না
- **No professional impersonation** — আইনজীবী, ডাক্তার ইত্যাদি সেজে কাজ করবে না
- **Corrects false premises** — ভুল ধারণা চিহ্নিত করে
- **Blocks harmful content** — অনুচিত request প্রত্যাখ্যান করে

<Callout type="info">
  Platform rule সব agent-কে নির্ভরযোগ্য ও নিরাপদভাবে কাজ করতে নিশ্চিত করে। এগুলো disable করা যায় না। বিস্তারিত দেখুন [Agent Persona Builder](/agents/persona-builder#platform-rules)।
</Callout>

### দ্রুত Persona উদাহরণ

কার্যকর persona লেখার বিস্তারিত নির্দেশনার জন্য [Agent Personas](/agents/agent-personas) দেখুন।

## ভাষা সমর্থন

আপনার agent স্বয়ংক্রিয়ভাবে প্রতিটি user message-এর ভাষা শনাক্ত করে এবং একই ভাষায় respond করে — কোনো configuration প্রয়োজন নেই। ১৭৬টি ভাষা out of the box সমর্থিত। বিস্তারিত দেখুন [Agent Personas — Language Detection](/agents/agent-personas#4-automatic-language-detection)।

## LLM Configuration

এই section AI model-এর setting নিয়ন্ত্রণ করে।

**Default Mode:**

By default, LLM setting আপনার organization-এর tier default ব্যবহার করে। আপনি "Using tier defaults" দেখানো একটি info box দেখবেন। বেশিরভাগ ক্ষেত্রে এটি recommended।

**Advanced Mode:**

**Advanced** toggle on করে customize করুন:

| Setting | বিবরণ |
|---------|-------|
| **Model** | আপনার plan অনুযায়ী available AI model থেকে বেছে নিন |
| **Temperature** | Response creativity নিয়ন্ত্রণ করে (কম = আরও consistent, বেশি = আরও creative) |

**Show Document References:**

এই toggle (সবসময় visible) নিয়ন্ত্রণ করে agent response-এ source citation অন্তর্ভুক্ত করবে কিনা:
- **Off** (default) — Response-এ source document উল্লেখ করে না
- **On** — Response-এ source document-এর reference অন্তর্ভুক্ত করে (legal/compliance-এর জন্য উপযোগী)

## Knowledge Access Control

প্রশ্নের উত্তর দেওয়ার সময় আপনার agent কোন document access করতে পারবে তা নিয়ন্ত্রণ করুন।

| Mode | আচরণ | কখন ব্যবহার করবেন |
|------|-------|-------------------|
| **Exclude Mode** | Agent নির্বাচিত document ছাড়া সব document access করে | Agent থেকে sensitive document লুকান |
| **Include Mode** | Agent শুধুমাত্র নির্বাচিত item access করে | নির্দিষ্ট knowledge set-এ agent সীমাবদ্ধ করুন |

**Include Mode ব্যবহার করলে:**
- Agent যে specific folder access করতে পারবে তা নির্বাচন করুন
- Agent যে specific tag access করতে পারবে তা নির্বাচন করুন
- Agent যে individual document access করতে পারবে তা নির্বাচন করুন

Agent শুধুমাত্র নির্বাচিত source-এর তথ্য ব্যবহার করে respond করবে।

<Callout type="important">
  নির্দিষ্ট document লুকাতে না চাইলে Exclude Mode (full knowledge access) দিয়ে শুরু করুন। পরে যেকোনো সময় access সীমিত করতে পারবেন।
</Callout>

## Form Actions

Form-এর নিচে:

| Button | Action |
|--------|--------|
| **Cancel** | পরিবর্তন বাতিল করুন এবং ফিরে যান |
| **Reset** | সব field মুছে নতুন করে শুরু করুন (confirmation dialog দেখায়) |
| **Create Agent** | Agent save করুন এবং এর edit page খুলুন |

<Callout type="info">
  আপনার draft কাজ করার সময় স্বয়ংক্রিয়ভাবে save হয়। আপনি চলে গিয়ে ফিরে আসলে আপনার progress পুনরুদ্ধার হবে।
</Callout>

## তৈরির পরে

আপনি **Create Agent**-এ click করলে:

1. Agent **Testing** status-এ তৈরি হয়
2. আপনাকে agent-এর edit page-এ নিয়ে যাওয়া হয়
3. Playground ব্যবহার করে agent test করুন
4. Live হতে প্রস্তুত হলে integration connect করুন
5. প্রস্তুত হলে status **Active**-এ পরিবর্তন করুন

<Callout type="info">
  নতুন agent **Testing** status-এ শুরু হয়। আপনি Playground-এ test করতে পারবেন, তবে agent activate না করা পর্যন্ত channel integration disabled থাকবে।
</Callout>

## Agent পরিচালনা

Agents page থেকে আপনি:

- **Edit** — Setting পরিবর্তন করতে যেকোনো agent-এ click করুন
- **Test** — Playground খুলতে agent card-এ **Test**-এ click করুন
- **Change Status** — Testing, Active, Inactive, বা Archived-এ সেট করুন

সব agent setting-এর বিস্তারিত জানতে [Configuration Options](/agents/configuring) দেখুন।
