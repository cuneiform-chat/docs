# Agent Persona Builder

import { Callout } from 'nextra/components'

Characteristics selection ব্যবহার করে কয়েক সেকেন্ডে professional agent persona generate করুন।

<Callout type="info">
  Agent Persona Builder আপনাকে শূন্য থেকে prompt না লিখে কার্যকর agent persona তৈরি করতে সাহায্য করে।
</Callout>

## শুরু করুন

1. **Agents**-এ navigate করুন এবং একটি agent তৈরি বা edit করুন
2. Agent Persona field-এর পাশে **Generate**-এ click করুন
3. Agent Persona Builder panel তিনটি tab সহ slide করে খোলে

## Builder Tabs

### Custom Build

৫টি category জুড়ে characteristics নির্বাচন করে একটি unique persona তৈরি করুন:

| Category | কী নিয়ন্ত্রণ করে |
|----------|------------------|
| **Role & Identity** | Agent-এর প্রাথমিক কাজ (customer support, sales, tech support, HR ইত্যাদি) |
| **Communication Style** | Formality, tone, verbosity এবং technical level |
| **Response Behavior** | Format (conversational vs bullet points), proactivity, question handling |
| **Operational Boundaries** | Agent কতটা কঠোরভাবে topic-এ থাকে, escalation tendency |
| **Knowledge Integration** | Citation style, agent অনিশ্চয়তা কীভাবে handle করে |

**Category Navigation:**
- Expand বা collapse করতে যেকোনো category header-এ click করুন
- প্রতিটি category-তে dropdown option সহ একাধিক field আছে
- নির্বাচিত option highlight হয়

**Reset Button:**
সব default restore করতে Custom Build section-এ **Reset**-এ click করুন।

#### Role & Identity Options

আপনার agent-এর প্রাথমিক কাজ বেছে নিন:
- Customer Support
- Sales
- Technical Support
- HR / Internal
- Education
- Healthcare Information
- Legal Information
- Finance / Accounting
- General Assistant

#### Communication Style

আপনার agent কীভাবে communicate করে তা fine-tune করুন:

| Setting | Options |
|---------|---------|
| **Formality** | Formal, Professional, Casual |
| **Tone** | Warm & Friendly, Neutral, Direct |
| **Verbosity** | Concise, Balanced, Detailed |
| **Technical Level** | Non-technical, Mixed, Technical |

#### Tone Options

উপলব্ধ tone preset:
- Empathetic & Supportive
- Confident & Authoritative
- Calm & Reassuring
- Enthusiastic & Engaging
- Neutral & Objective

#### Detail Levels

- **Concise** — সংক্ষিপ্ত, সরাসরি response
- **Balanced** — স্পষ্ট ব্যাখ্যা সহ মাঝারি detail
- **Comprehensive** — পুঙ্খানুপুঙ্খ, বিস্তারিত response

#### Response Behavior

Response কীভাবে structured হবে তা নিয়ন্ত্রণ করুন:
- **Format** — Conversational paragraph বা structured bullet point
- **Proactivity** — Agent সম্পর্কিত topic suggest করবে কিনা
- **Question Handling** — Agent কীভাবে clarification চায়

#### Operational Boundaries

আপনার agent-এর জন্য guardrail সেট করুন:
- **Scope Strictness** — Agent কতটা কঠোরভাবে documented topic-এর মধ্যে থাকে
- **Escalation** — কখন human support-এ যোগাযোগের পরামর্শ দেবে
- **Out-of-scope Handling** — Off-topic প্রশ্নে কীভাবে respond করবে

#### Knowledge Integration

Agent আপনার document কীভাবে ব্যবহার করে তা configure করুন:
- **Citation Style** — নির্দিষ্ট document reference করবে কিনা
- **Uncertainty Handling** — অনিশ্চিত হলে কীভাবে respond করবে

### Use Preset

সাধারণ use case-এর জন্য pre-configured persona load করুন:

- **System Templates** — নির্দিষ্ট role-এর জন্য optimized platform-provided preset
- **My Templates** — আপনার organization-এর admin-দের save করা preset

**Preset ব্যবহার:**
1. **Use Preset** tab-এ click করুন
2. উপলব্ধ preset browse করুন
3. নির্বাচন করতে একটি preset-এ click করুন
4. Preset Custom Build tab-এ load হয়
5. প্রয়োজনে যেকোনো characteristic adjust করুন
6. **Generate Persona**-এ click করুন

### Platform Rules

সব agent-এ স্বয়ংক্রিয়ভাবে প্রয়োগ হওয়া read-only guardrail দেখুন:

- **No fabrication** — আপনার content-এ নেই এমন তথ্য, সংখ্যা বা তারিখ তৈরি করবে না
- **Acknowledges gaps** — অনুমান না করে "আমার কাছে সেই তথ্য নেই" বলে
- **Resists speculation** — চাইলেও অনুপস্থিত মান অনুমান করবে না
- **No professional impersonation** — আইনজীবী, ডাক্তার, CPA বা আর্থিক উপদেষ্টা সেজে কাজ করবে না
- **Corrects false premises** — উত্তর দেওয়ার আগে ভুল ধারণা চিহ্নিত করে
- **Blocks harmful content** — Self-harm, explicit বা fraudulent content প্রত্যাখ্যান করে

<Callout type="info">
  Persona configuration নির্বিশেষে platform rule সব agent-কে নির্ভরযোগ্য ও নিরাপদভাবে কাজ করতে নিশ্চিত করে। এগুলো disable করা যায় না।
</Callout>

## Persona Generate করা

**Generate-এর আগে:**
Panel আপনার configuration option full width-এ দেখায়।

**Generate Button:**
Custom Build tab-এ থাকলে:
1. নিচে **Generate Persona**-এ click করুন
2. Generate হওয়ার সময় একটি loading state দেখায়
3. কয়েক সেকেন্ড সময় লাগে

**Generate-এর পরে:**
Panel layout split view-তে পরিবর্তন হয়:
- **বাম দিক:** আপনার configuration option
- **ডান দিক:** Generated prompt preview

**Preview Panel Features:**
- Generated system prompt-এর সম্পূর্ণ text
- Editable — আপনি সরাসরি text পরিবর্তন করতে পারেন
- নিচে character count দেখায়

## Generate-এর পরে

একটি generated persona পাওয়ার পর আপনার কাছে কয়েকটি option আছে:

### Regenerate

একই setting দিয়ে নতুন version তৈরি করতে **Regenerate**-এ click করুন। প্রতিটি generation সামান্য ভিন্ন result তৈরি করে।

### Prompt Edit করুন

Generated text সরাসরি edit করতে preview panel-এ click করুন। আপনার specific use case-এর জন্য প্রয়োজনীয় adjustment করুন।

### Save as Preset

আপনার configuration পুনরায় ব্যবহারের জন্য save করতে **Save as Preset**-এ click করুন:
1. Preset name চাওয়া dialog খোলে
2. একটি বর্ণনামূলক নাম দিন
3. Preset আপনার organization-এর **My Templates**-এ save হয়

<Callout type="important">
  Save করা preset আপনার organization-এর সব admin-এর জন্য available। একাধিক agent জুড়ে consistent agent personality বজায় রাখতে এগুলো ব্যবহার করুন।
</Callout>

### Apply to Agent

এই persona ব্যবহার করতে **Apply to Agent**-এ click করুন:
1. Prompt আপনার agent-এর system prompt field-এ insert হয়
2. Builder বন্ধ হয়
3. অন্যান্য agent setting configure করা চালিয়ে যান

## Best Practices

- **Preset দিয়ে শুরু করুন** — System template starting point হিসেবে ব্যবহার করুন, তারপর customize করুন
- **Role-কে purpose-এর সাথে match করুন** — Agent-এর প্রকৃত কাজের সাথে সামঞ্জস্যপূর্ণ role বেছে নিন
- **Verbosity balance করুন** — দ্রুত Q&A-এর জন্য Concise ভালো কাজ করে, জটিল বিষয়ের জন্য Detailed
- **Generate-এর পর test করুন** — নতুন persona apply করার পর সবসময় Playground-এ agent test করুন
- **পুনরাবৃত্তি করুন** — Result ঠিক না হলে ভিন্ন setting দিয়ে regenerate করুন
- **Focused রাখুন** — অতিরিক্ত জটিল prompt agent-কে confused করতে পারে
