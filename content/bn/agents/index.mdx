# Agents

Agent হলো AI chatbot যা আপনার user-দের সাথে interact করে। প্রতিটি agent-এর নিজস্ব configuration, knowledge access এবং personality রয়েছে।

## Agent কী?

Agent হলো একটি configured chatbot যা:

- আপনার content ব্যবহার করে প্রশ্নের উত্তর দেয়
- Agent persona-তে নির্ধারিত নির্দেশনা অনুসরণ করে
- Session-এর মধ্যে conversation context বজায় রাখে
- একাধিক channel-এ deploy করা যায়

## Agent-এর ধারণাসমূহ

### Agent Persona

Agent persona হলো নির্দেশনার সেট যা আপনার agent-এর আচরণ নির্ধারণ করে। এটি নিয়ন্ত্রণ করে:

- **Personality** — বন্ধুসুলভ, পেশাদার, সহজ ইত্যাদি
- **Scope** — Agent কোন বিষয়ে কথা বলবে এবং বলবে না
- **Response style** — উত্তরের দৈর্ঘ্য, format এবং tone
- **Guardrails** — সীমানা ও সীমাবদ্ধতা
- **Language** — স্বয়ংক্রিয় প্রতি-message ভাষা শনাক্তকরণ (১৭৬টি ভাষা সমর্থিত)

### Knowledge Access

প্রতিটি agent আপনার content থেকে প্রাসঙ্গিক তথ্য খুঁজে বের করে। আপনি configure করতে পারেন:

- Agent কোন document-গুলো search করতে পারবে
- কতগুলো source retrieve করবে
- Source citation দেখানো হবে কিনা

### Channels

Agent-গুলো একসাথে একাধিক channel-এ deploy করা যায়:

- Messaging platform (Telegram, Discord, Slack, WhatsApp, Google Chat)
- Meta integration-এর মাধ্যমে Facebook Messenger
- Human Handoff — নির্বিঘ্নে conversation একজন মানব team member-এর কাছে transfer করুন
