# Google Chat ইন্টিগ্রেশন

Google Workspace-এর মধ্যে নির্বিঘ্ন যোগাযোগের জন্য আপনার agent-কে Google Chat-এ সংযুক্ত করুন।

## সংক্ষিপ্ত বিবরণ

Google Chat integration প্রদান করে:
- আপনার bot-এর সাথে সরাসরি messaging
- @mention trigger সহ Google Workspace Spaces support
- **Document Q&A** — একটি file আপলোড করুন এবং bot-কে সে সম্পর্কে জিজ্ঞাসা করুন (paid plan); দেখুন [নথি সংযুক্তি](/integrations/document-attachments)
- **Space Knowledge Base** — Space-গুলো তাদের মধ্যে শেয়ার করা প্রতিটি document মনে রাখে এবং পুরো সংগ্রহ থেকে উত্তর দেয়
- **Cited answer** — bot যে document বা source থেকে উত্তর দিয়েছে তার নাম উল্লেখ করে
- Space-level agent routing — বিভিন্ন Space-এ বিভিন্ন agent নির্ধারণ
- Conversation memory এবং opt-in space context awareness
- তাৎক্ষণিক acknowledgment সহ async processing
- Domain-based isolation সহ enterprise-ready নিরাপত্তা

## পূর্বশর্ত

- একটি active AI agent (Agents section-এ তৈরি)
- একটি Google Workspace account (ব্যক্তিগত Gmail account সমর্থিত নয়)
- একটি **verified domain** — সংযুক্ত করার আগে **Settings > Domains**-এ আপনার domain ownership verify করুন

## সেটআপ ধাপসমূহ

### ১. আপনার Domain verify করুন (এক-বারের সেটআপ)

Google Chat সংযুক্ত করার আগে আপনার domain ownership verify করুন:

1. Sidebar থেকে **Settings**-এ যান
2. **Domains** tab-এ click করুন
3. আপনার account email থেকে domain স্বয়ংক্রিয়ভাবে শনাক্ত হয়
4. আপনার DNS provider-এ দেখানো মান সহ একটি **TXT record** যোগ করুন:
   - **Type:** TXT
   - **Name:** `_cuneiform-verify` (অথবা দেখানো পূর্ণ মান)
   - **Content:** প্রদর্শিত verification string (যেমন, `cuneiform-verify=abc123...`)
5. **Verify Now**-এ click করুন — DNS পরিবর্তন propagate হতে ৪৮ ঘণ্টা পর্যন্ত সময় লাগতে পারে
6. Status **Verified** হলে integration তৈরি করতে এগিয়ে যান

Verification card-এ সাধারণ DNS provider-দের (Cloudflare, GoDaddy, Namecheap, Route 53, DigitalOcean, Hostinger) দ্রুত link দেখানো হয়।

### ২. Google Chat Integration তৈরি করুন

1. Sidebar থেকে **Integrations**-এ যান
2. "Google Chat Bots"-এর নিচে **Connect Bot**-এ click করুন
3. DM এবং unlinked Space-এর জন্য default হবে এমন **Agent** নির্বাচন করুন
4. একটি **Bot Name** দিন (admin panel-এ আপনার reference-এর জন্য)
5. **Connect Bot**-এ click করুন
6. প্রদর্শিত **Verification Code** copy করুন (format: `VERIFY-XXXXXX`)

### ৩. Bot Verification সম্পন্ন করুন

Integration তৈরির পর আপনি একটি verification code পাবেন:

1. Google Chat খুলুন
2. **Start a chat** → **Find apps**-এ click করুন
3. Platform bot সার্চ করুন
4. Bot-এর সাথে direct message শুরু করুন
5. Verification code পাঠান (যেমন, `VERIFY-ABC123`)
6. Bot নিশ্চিত করবে: "Setup complete! Your workspace (yourdomain.com) is now connected. Send a message to start chatting!"

আপনার integration status "Pending Verification" থেকে "Active"-এ পরিবর্তন হবে।

<Callout type="warning">
  শুধুমাত্র আপনার Google Workspace domain-এর user-রা verification সম্পন্ন করতে পারবে। অন্য domain বা ব্যক্তিগত Gmail account-এর user-রা error দেখবে।
</Callout>

## Bot ব্যবহার করা

### Direct Message

User-রা conversation শুরু করতে পারে:

1. Google Chat খুলুন
2. **Start a chat** → **Find apps**-এ click করুন
3. আপনার bot name সার্চ করুন
4. স্বাভাবিকভাবে chat শুরু করুন — bot DM-এ সব message-এ respond করে

DM সবসময় **default agent** দ্বারা পরিচালিত হয়।

### Space-এ

একটি Space-এ bot যোগ করুন:

1. Space খুলুন
2. Space name → **Manage apps**-এ click করুন
3. আপনার bot যোগ করুন
4. Interact করতে `@Cuneiform Chat` দিয়ে bot-কে mention করুন — bot শুধুমাত্র Space-এ @mention-এ respond করে

<Callout type="info">
  Bot প্রথমবার Space-এ যোগ হলে উপলব্ধ bot command সহ একটি welcome message পাঠায়। DM-এ একটি সাধারণ পরিচিতি পাঠায়।
</Callout>

## Space-Level Agent Routing

প্রতিটি Space ঐচ্ছিকভাবে default-এর পরিবর্তে ভিন্ন agent ব্যবহার করতে পারে। Space-এ এই bot command ব্যবহার করুন (@mention প্রয়োজন):

| Command | বিবরণ |
|---------|-------|
| `@Cuneiform Chat /set-agent <name>` | এই Space-কে একটি নির্দিষ্ট agent-এর সাথে link করুন |
| `@Cuneiform Chat /current-agent` | এই Space কোন agent পরিচালনা করে তা দেখুন |
| `@Cuneiform Chat /reset-agent` | Space-কে default agent-এ ফিরিয়ে দিন |
| `@Cuneiform Chat /connect` | (শুধু Space manager) Thread history awareness চালু করুন |
| `@Cuneiform Chat /space-memory on\|off` | এই Space-এর জন্য Space Knowledge Base চালু/বন্ধ করুন (শুধু command দিলে status দেখায়) |

**Routing কীভাবে কাজ করে:**
- **DM** → সবসময় default agent ব্যবহার করে
- **Custom agent সহ Space** → নির্ধারিত agent ব্যবহার করে
- **Custom agent ছাড়া Space** → default agent-এ fallback করে

<Callout type="info">
  Integration card-এর "Space mappings" section-এ admin panel-এ Space-agent mapping দেখতে পারবেন।
</Callout>

## Thread History Awareness

ডিফল্টভাবে bot শুধু সেই message দেখে যা সরাসরি এটিকে @mention করেছে। Team সদস্যরা যদি আগে context message পাঠায় (অন্য thread-এ বা Space-এ আগে) এবং তারপর bot-কে @mention করে, তবে সেই context bot-এর কাছে থাকবে না — যদি না কোনো Space manager `/connect` চালায়।

### এটি কীভাবে কাজ করে

1. একজন Space manager Space-এ `@Cuneiform Chat /connect` পাঠায়
2. Bot একটি এক-বারের authorization link পাঠায় (১০ মিনিটে expire হয়)
3. Manager link-এ click করে তাদের Google Workspace account দিয়ে সাইন ইন করে
4. Bot এখন প্রতিটি @mention-এর আগের ২৪ ঘণ্টায় Space-এ পাঠানো সাম্প্রতিক message (সর্বোচ্চ ১০টি) পড়তে পারে

Connect হয়ে গেলে, প্রতিটি @mention-এ bot স্বয়ংক্রিয়ভাবে সাম্প্রতিক Space message context হিসেবে পড়ে — @mention হওয়ার আগে team কী নিয়ে আলোচনা করছিল তা বোঝে।

**উদাহরণ:** Team সদস্যরা "what are the pricing plans?" এবং "what's included in starter?" পোস্ট করে এরপর "can you help?" দিয়ে bot-কে @mention করে — bot তিনটি message-ই দেখে এবং পূর্ণ context সহ উত্তর দেয়।

### Requirements ও Privacy

- শুধুমাত্র **Space manager** (নিয়মিত সদস্য নয়) `/connect` চালাতে পারে
- Authorization প্রতি-Space — প্রতিটি Space-এর নিজস্ব `/connect` প্রয়োজন
- Space manager-এর Google OAuth token এনক্রিপ্ট করে সুরক্ষিতভাবে সংরক্ষণ করা হয়
- শুধুমাত্র সেই manager-এর account-এ দৃশ্যমান message পড়া যায়
- Space থেকে bot সরালে সংরক্ষিত token স্বয়ংক্রিয়ভাবে মুছে যায়

### Re-authorization

Bot access হারালে (যেমন, আপনার Google account-এ token revoke হলে), এটি Space-কে জানাবে:

> ⚠️ Thread history access has expired or been revoked. A space manager should run `/connect` to restore it.

Access পুনরুদ্ধার করতে আবার `/connect` চালান।

## বৈশিষ্ট্যসমূহ

### Async Response

আপনি message পাঠালে bot তাৎক্ষণিকভাবে একটি সংক্ষিপ্ত acknowledgment (যেমন, "Working on it...") দিয়ে reply করে এবং তারপর processing সম্পন্ন হলে পূর্ণ উত্তর দেয়। আপনার প্রশ্নের জটিলতার উপর নির্ভর করে এটি সাধারণত ৩-৮ সেকেন্ড সময় নেয়।

### Conversation Memory

Bot একটি session-এর মধ্যে context মনে রাখে, তাই আপনি নিজেকে পুনরাবৃত্তি না করে follow-up প্রশ্ন করতে পারেন।

**Space context awareness (opt-in):** একজন Space manager `/connect` চালানোর পর, bot প্রতিটি @mention-এর আগের ২৪ ঘণ্টায় Space-এ পাঠানো সাম্প্রতিক message (সর্বোচ্চ ১০টি) পড়ে — তাই আপনার context পুনরাবৃত্তি না করেই এটি বোঝে team আগে থেকে কী নিয়ে আলোচনা করছিল। সেটআপের ধাপের জন্য নিচে [Thread History Awareness](#thread-history-awareness) দেখুন।

### Message Queuing

Bot এখনও প্রক্রিয়া করার সময় আপনি অতিরিক্ত message পাঠালে, সেগুলো queue হয় এবং পরবর্তী response-এ অন্তর্ভুক্ত হয়। আপনি একটি message দেখবেন: "I'm still working on your previous question. I'll include this in my next response."

### `/help` Command

ব্যবহার নির্দেশনা দেখতে `/help` বা `help` টাইপ করুন, উপলব্ধ space command সহ।

### Domain-Based Access

শুধুমাত্র আপনার Google Workspace domain-এর user-রা আপনার bot-এর সাথে interact করতে পারে, enterprise-level নিরাপত্তা নিশ্চিত করে।

### Text Replies

Bot text-এ **reply** করে — এটি image, interactive button, বা card attachment পাঠায় না, এবং response আনুমানিক ৩০,০০০ অক্ষরে সীমাবদ্ধ। তবে আপনি bot-এর **কাছে** document পাঠাতে *পারেন* — নিচে [Working with Documents](#working-with-documents) দেখুন।

## Working with Documents

Paid plan-এ team সদস্যরা একটি document আপলোড করে bot-কে সে সম্পর্কে জিজ্ঞাসা করতে পারে — DM-এ বা Space-এ। একই সুবিধা WhatsApp, Slack, Discord, Telegram এবং Meta (Facebook)-এও আছে; সাধারণ আচরণ [নথি সংযুক্তি](/integrations/document-attachments) পৃষ্ঠায় আছে, আর এই অংশে কেবল Google Chat-এর নিজস্ব বিষয়গুলো আছে।

### Attach and Ask

1. একটি DM বা Space-এ (Space-এ @mention সহ) একটি file attach করুন এবং আপনার প্রশ্ন জিজ্ঞাসা করুন
2. Bot document পড়ে এবং সেখান থেকে উত্তর দেয়
3. Follow-up প্রশ্ন করতে থাকুন — document conversation-এর জন্য active থাকে, পুনরায় attach করার প্রয়োজন নেই

**সমর্থিত file type:** PDF, DOCX, PPTX, TXT, Markdown, PNG এবং JPEG।

<Callout type="info">
  ছবি (PNG, JPEG) এবং scan করা PDF পৃষ্ঠার লেখা পড়ার জন্য প্রক্রিয়া করা হয়, এবং কেবল তখনই যখন একজন admin integration-এ **premium parsing** চালু করে রেখেছেন। Spreadsheet/CSV, audio, এবং video সমর্থিত নয়। Google Drive link প্রক্রিয়া করা যায় না — file সরাসরি আপলোড করুন।
</Callout>

**File size সীমা:** Starter-এ ১০ MB, Plus-এ ৫০ MB এবং Enterprise-এ ১০০ MB পর্যন্ত।

**Google Chat-এ একবারে একটি document:** আপনি একসাথে একাধিক file attach করলে, bot প্রথমটি ব্যবহার করে এবং বাকিগুলো একটি একটি করে পাঠাতে বলে। বাকি পাঁচটি channel-এ প্রতি conversation-এ একাধিক file active থাকে।

### Cited Answers

Bot যখন একটি document বা আপনার knowledge base থেকে উত্তর দেয়, তখন এটি source-এর নাম উল্লেখ করে — যেমন, *"According to handbook.pdf, …"* — যাতে আপনার team প্রতিটি উত্তর কোথা থেকে এসেছে তা বিশ্বাস করতে পারে। Citation ডিফল্টভাবে চালু থাকে।

### Space Knowledge Base

একটি Space-এ bot সেখানে **শেয়ার করা প্রতিটি document মনে রাখতে** পারে এবং team-এর জন্য একটি জীবন্ত knowledge base তৈরি করতে পারে। একবার একটি document একটি Space-এ শেয়ার হলে, bot সেই Space-এর **যেকোনো thread-এ** সে সম্পর্কে প্রশ্নের উত্তর দেয় — শুধু যে thread-এ এটি আপলোড হয়েছিল সেখানে নয় — আপনার organization-এর প্রধান knowledge base-এর পাশাপাশি।

- **ডিফল্টভাবে চালু** Space-এ (paid plan) — কোনো সেটআপ প্রয়োজন নেই
- **Document জমা হয়** — Space-এ শেয়ার করা প্রতিটি file মনে রাখা হয়; নতুন আপলোড পুরোনোগুলোকে প্রতিস্থাপন করে না
- **Space-এর মধ্যেই থাকে** — একটি Space-এ মনে রাখা document কখনো অন্য Space-এ উত্তর দিতে ব্যবহৃত হয় না
- **আপনার document quota-এর সাথে গণনা হয়** — এককালীন attachment-এর বিপরীতে, Space-এর knowledge base-এ রাখা document আপনার organization-এর document allowance-এর সাথে গণনা হয়
- **Cleanup** — Space থেকে bot সরালে মনে রাখা document স্বয়ংক্রিয়ভাবে মুছে যায়

| `@Cuneiform Chat /space-memory on` | এই Space-এ শেয়ার করা document মনে রাখা শুরু করুন |
| `@Cuneiform Chat /space-memory off` | শেয়ার করা document ব্যবহার বন্ধ করুন (ইতিমধ্যে শেয়ার করা file রাখা হয়, মুছে যায় না) |
| `@Cuneiform Chat /space-memory` | বর্তমান status দেখুন |

## আপনার Integration পরিচালনা

প্রতিটি integration card দেখায়:
- **Bot name** - আপনি configure করা display name
- **Status badge** - Active, Pending Verification, বা Error
- **Domain name** - আপনার Google Workspace domain (verification-এর পর)
- **Default agent** - Default agent পরিবর্তন করতে dropdown (DM + unlinked Space-এর জন্য ব্যবহৃত)
- **Space mappings** - কোন Space-এ custom agent assignment আছে তা দেখানো collapsible section
- **Space commands** - উপলব্ধ bot command দেখানো collapsible section
- **শেষ কার্যকলাপ** timestamp

## সমস্যা সমাধান

### Bot Google Chat-এ দেখা যাচ্ছে না

1. আপনি Google Workspace account ব্যবহার করছেন কিনা নিশ্চিত করুন (ব্যক্তিগত Gmail নয়)
2. "Find apps"-এ bot name সার্চ করুন
3. App propagate হওয়ার জন্য কয়েক মিনিট অপেক্ষা করুন

### Google Chat Section দেখা যাচ্ছে না

1. Google Chat শুধুমাত্র Google Workspace ব্যবহারকারী organization-এর জন্য দেখা যায়
2. আপনার organization ভিন্ন email provider ব্যবহার করলে (যেমন, Microsoft 365), section লুকানো থাকে
3. System স্বয়ংক্রিয়ভাবে MX record-এর মাধ্যমে আপনার email provider শনাক্ত করে

### Domain Verification সমস্যা

1. DNS পরিবর্তন propagate হতে ৪৮ ঘণ্টা পর্যন্ত সময় লাগতে পারে — অপেক্ষা করুন এবং আবার **Verify Now** চেষ্টা করুন
2. Settings > Domains-এ দেখানো সঠিক মান সহ TXT record যোগ করেছেন কিনা পরীক্ষা করুন
3. Record সঠিক domain-এ আছে কিনা যাচাই করুন (যেমন, `_cuneiform-verify.yourdomain.com`)
4. সহজ access-এর জন্য verification card-এ DNS provider quick link ব্যবহার করুন

### Verification Code কাজ করছে না

1. আপনার Google Workspace email থেকে code পাঠাচ্ছেন কিনা নিশ্চিত করুন
2. Code ঠিক দেখানো মতো দিয়েছেন কিনা পরীক্ষা করুন (`VERIFY-` prefix সহ)
3. Integration এখনও "Pending Verification" status-এ আছে কিনা যাচাই করুন
4. Code expire হলে নতুন integration তৈরি করে দেখুন

### Bot "Working on it..." বলে কিন্তু কোনো Response আসে না

1. Bot message asynchronously প্রক্রিয়া করে — পূর্ণ response-এর জন্য ২৫ সেকেন্ড পর্যন্ত অপেক্ষা করুন
2. কোনো response না এলে আপনার message আবার পাঠিয়ে দেখুন
3. সংশ্লিষ্ট agent সঠিকভাবে configured কিনা পরীক্ষা করুন

### Message প্রক্রিয়া হচ্ছে না

1. আপনার workspace verified কিনা নিশ্চিত করুন (status "Active" হওয়া উচিত)
2. Space-এ bot-কে @mention করছেন কিনা নিশ্চিত করুন
3. সংশ্লিষ্ট agent সঠিকভাবে configured কিনা পরীক্ষা করুন

### "Organization hasn't connected" Message

এর মানে bot আপনার Google Workspace domain চিনতে পারছে না:
1. আপনার admin এখনও integration তৈরি করেনি
2. Domain verification code দিয়ে verify হয়নি
3. আপনি ব্যক্তিগত Gmail account থেকে message করছেন (সমর্থিত নয়)

### `/set-agent` বলছে Agent পাওয়া যায়নি

1. Admin panel-এ সঠিক agent name পরীক্ষা করুন (case-sensitive)
2. Agent "Active" status-এ আছে কিনা নিশ্চিত করুন
3. Space সহ agent name সমর্থিত — `/set-agent`-এর পর পূর্ণ নাম টাইপ করুন

### `/connect` বলছে "Only space managers can run /connect"

`/connect` চালানোর জন্য আপনাকে অবশ্যই একজন Space manager হতে হবে। আপনার Space-এর একজন Space manager-কে command-টি চালাতে বলুন।

### `/connect` Authorization Link Expire হয়েছে

Link ১০ মিনিটের জন্য বৈধ। একটি নতুন link পেতে আবার `@Cuneiform Chat /connect` চালান।

### Bot "Thread history access has expired" বলে

পুনরায় authorize করতে একজন Space manager-কে আবার `@Cuneiform Chat /connect` চালাতে হবে। Google OAuth token revoke হলে (যেমন, Google account setting-এ) এটি ঘটে।

### আপলোড করা Document খালি ফিরে এসেছে

1. Scan করা বা image-only PDF প্রায়ই standard parser পড়তে পারে না — একজন admin-কে Google Chat integration-এ **premium parsing** চালু করতে বলুন
2. কোনো ছবি খালি ফিরে এসেছে, বা bot তার বদলে একটি document চেয়েছে — ছবি কেবল **premium parsing** চালু থাকলেই পড়া হয়, এবং তখনও শুধু পৃষ্ঠার লেখাটুকু
3. File type সমর্থিত কিনা নিশ্চিত করুন (PDF, DOCX, PPTX, TXT, Markdown, PNG, JPEG) — spreadsheet/CSV এবং Drive link নয়
4. File আপনার plan-এর size সীমার মধ্যে আছে কিনা পরীক্ষা করুন (Starter ১০ MB, Plus ৫০ MB, Enterprise ১০০ MB)

### Document আপলোড করা যাচ্ছে না

1. Document attachment একটি paid-plan বৈশিষ্ট্য — এগুলো free trial-এ উপলব্ধ নয়
2. একজন admin Google Chat integration card-এ **নথি সংযুক্তির অনুমতি দিন** চালু আছে কিনা নিশ্চিত করতে পারেন

## নিরাপত্তা

- **Domain ownership verification** — সংযুক্ত করার আগে DNS TXT record আপনার organization domain-এর মালিকানা প্রমাণ করে
- **Google Workspace detection** — MX record check আপনার domain Google Workspace ব্যবহার করে কিনা নিশ্চিত করে
- **Domain-based isolation** — শুধুমাত্র আপনার organization-এর Google Workspace user-রা আপনার bot-এর সাথে interact করতে পারে
- **Webhook verification** — প্রতিটি incoming request আপনার platform-এর Google Cloud project-এর বিরুদ্ধে validate হয়
- **Verification code** একবার ব্যবহারযোগ্য এবং আপনার domain-এর সাথে সংযুক্ত
- Message secure, encrypted connection-এর মাধ্যমে প্রক্রিয়া হয়

## গুরুত্বপূর্ণ তথ্য

- **Google Workspace আবশ্যক**: ব্যক্তিগত Gmail account এই integration ব্যবহার করতে পারে না। আপনার org Google Workspace ব্যবহার না করলে Google Chat section দেখা যাবে না।
- **Domain verification আবশ্যক**: Google Chat সংযুক্ত করার আগে Settings > Domains-এ আপনার domain verify করুন।
- **প্রতি organization একটি integration**: প্রতিটি organization একটি Google Chat integration রাখতে পারে
- **Text reply**: Bot text-এ reply করে (কোনো image বা interactive button নয়), তবে এটি paid plan-এ আপলোড করা document গ্রহণ করতে এবং সে সম্পর্কে প্রশ্নের উত্তর দিতে পারে — [Working with Documents](#working-with-documents) দেখুন
- **Org level-এ পরিচালিত**: Google Chat Integrations page-এ configure করা হয়, per-agent নয়
- **Space routing**: বিভিন্ন team-এ বিশেষায়িত agent নির্ধারণ করতে Space-এ `/set-agent` ব্যবহার করুন
- **Default agent**: যেকোনো সময় dropdown ব্যবহার করে default agent পরিবর্তন করুন — disconnect প্রয়োজন নেই
