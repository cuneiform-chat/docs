# Saba on Telegram

একটি নিবেদিত Telegram bot সংযুক্ত করুন যাতে আপনার organization-এর সদস্যরা Telegram থেকেই **Saba**-র সাথে — Cuneiform Chat platform assistant — chat করতে পারে। admin panel-এর ভেতরের Saba-র মতোই একই উত্তর ও একই data access, শুধু আপনার ফোনে।

## সংক্ষিপ্ত বিবরণ

Saba on Telegram আপনার team-কে দেয়:

- একটি Telegram DM থেকে agent, conversation, billing, usage ও integration সম্পর্কে Saba-কে জিজ্ঞাসা করার সুযোগ
- voice note পাঠানো — Saba সেগুলো transcribe করে এবং টাইপ করা প্রশ্নের মতো উত্তর দেয়
- প্রতিটি reply-এর নিচে Saba যে follow-up suggestion দেখায় তাতে tap করা
- প্রতিটি reply-এর নিচে একটি inline button-এর মাধ্যমে thread-এর মাঝপথে **Saba Mini App**-এ (Telegram-এর ভেতরে একটি আরও সমৃদ্ধ chat surface) switch করা
- slash command ব্যবহার করা (`/agents`, `/analytics`, `/usage`, `/billing`, `/integrations`, `/conversations`, `/health`, `/help`, `/new`, `/clear`, `/reset`)

এটি একটি customer-facing channel **নয়** — এটি সম্পূর্ণভাবে org সদস্যদের জন্য। End user-রা কখনো এই bot-এর সাথে interact করে না।

## regular Telegram integration থেকে এটি কীভাবে আলাদা

| | Telegram | Saba on Telegram |
|---|----------|------------------|
| কে bot-এর সাথে chat করে? | আপনার end user-রা | আপনার org সদস্যরা (admin, operator) |
| এটি কী করে? | আপনার AI agent চালায় | Saba চালায় (platform assistant) |
| কোথায়? | DM ও group chat | শুধু ব্যক্তিগত DM |
| Per-user link প্রয়োজন? | না — যে কেউ chat করতে পারে | হ্যাঁ — প্রতিটি সদস্য একবার তাদের account link করে |

আপনি যদি আপনার agent-কে end user-দের কাছে deploy করতে চান, [Telegram Integration](/integrations/telegram) দেখুন। এই page-টি operator-facing bot সম্পর্কে।

## পূর্বশর্ত

- একটি Telegram account
- অন্তত একজন admin সদস্য সহ একটি organization
- Saba-র জন্য নিবেদিত একটি নতুন BotFather bot (regular Telegram integration-এর সাথে ইতিমধ্যে সংযুক্ত একটি bot পুনরায় ব্যবহার করা যাবে না — প্রতি bot-এ একটি webhook)

## সেটআপ ধাপসমূহ

### ১. BotFather-এ একটি নিবেদিত bot তৈরি করুন

1. Telegram খুলুন এবং **@BotFather** সার্চ করুন
2. `/newbot` পাঠান
3. একটি নাম ও username বেছে নিন — `acme-saba-bot`-এর মতো কিছু এর উদ্দেশ্য স্পষ্ট করে
4. BotFather যে **Bot Token** দিয়ে reply দেয় তা copy করুন

### ২. bot সংযুক্ত করুন

1. Cuneiform Chat-এ, sidebar-এ **Integrations** খুলুন
2. **Saba on Telegram** card খুঁজুন
3. **Connect Saba Bot**-এ click করুন
4. bot token paste করুন এবং submit করুন

platform token-টি validate করে, webhook register করে এবং card-টি সক্রিয় করে।

### ৩. আপনার account link করুন

আপনার org-এর প্রতিটি সদস্যকে একবার তাদের ব্যক্তিগত Telegram account link করতে হবে।

1. Saba on Telegram card-এ, **Link my account**-এ click করুন
2. যে ১০-মিনিটের code আসে তা copy করুন (অথবা QR code scan করুন)
3. Telegram-এ bot খুলুন
4. `/start <your-code>` পাঠান — Saba link নিশ্চিত করে

Code single-use এবং ১০ মিনিট পরে মেয়াদ শেষ হয়। আপনারটির মেয়াদ শেষ হলে, একটি নতুন তৈরি করতে আবার **Link my account**-এ click করুন।

### ৪. অন্য admin-দের নিজেদের link করতে বলুন

Teammate-দের bot-এর `t.me/<bot-username>` link পাঠান এবং তাদের বলুন:

1. তাদের নিজস্ব admin panel session-এ একই Saba on Telegram card-এ যেতে
2. তাদের নিজস্ব link code তৈরি করতে
3. `/start <code>` দিয়ে bot-কে DM করতে

প্রতিটি linked সদস্যের Telegram account তাদের org membership-এর সাথে আবদ্ধ — Saba admin panel-এর ভেতরে যেভাবে করে সেভাবেই একই role-based permission প্রয়োগ করে।

## bot ব্যবহার করা

### panel-এ Saba যা উত্তর দিতে পারে যেকোনো কিছু জিজ্ঞাসা করুন

```
How many agents do I have?
What did we spend on Telegram last week?
Show me failing integrations.
```

Saba আপনার org-এর data থেকে পড়ে এবং inline reply দেয়।

### voice note

২ মিনিট পর্যন্ত একটি voice note পাঠান। Whisper এটি transcribe করে, এবং Saba এমনভাবে উত্তর দেয় যেন আপনি প্রশ্নটি টাইপ করেছেন। আপনি হাঁটার সময়, গাড়ি চালানোর সময়, বা যখন শুধু টাইপ করতে চান না তখন উপযোগী।

### slash command

autocomplete menu দেখতে chat-এ `/` টাইপ করুন। আপনি bot সংযুক্ত করার সময় Saba command-এর একটি default set register করে:

| Command | এটি কী করে |
|---------|------------|
| `/help` | সক্ষমতা ও command তালিকা দেখায় |
| `/new`, `/clear`, `/reset` | একটি নতুন কথোপকথন শুরু করে (conversation memory পরিষ্কার করে) |
| `/agents` | আপনার agent-গুলোর সারসংক্ষেপ দেয় |
| `/analytics` | সাম্প্রতিক analytics-এর সংক্ষিপ্ত বিবরণ |
| `/usage` | বর্তমান usage ও quota |
| `/billing` | Subscription ও সাম্প্রতিক charge |
| `/integrations` | প্রতিটি সংযুক্ত channel-এর status |
| `/conversations` | সাম্প্রতিক কথোপকথন কার্যকলাপ |
| `/health` | Workspace-এর health সারসংক্ষেপ |

### follow-up suggestion

প্রতিটি Saba reply তিনটি পর্যন্ত follow-up প্রশ্নের button দিয়ে শেষ হয়। পুনরায় টাইপ না করে Saba-কে পাঠাতে একটিতে tap করুন। reply আসার পর button-গুলো ২৪ ঘণ্টা valid থাকে।

### Mini App-এ খুলুন

প্রতিটি reply-এ একটি **Open in Mini App** button-ও রয়েছে। Saba Mini App-এ switch করতে এটি tap করুন — Telegram-এর ভেতরে কথোপকথনের ইতিহাস, tool-call detail ও একটি markdown export সহ একটি আরও সমৃদ্ধ chat surface। দুটি surface-ই একই কথোপকথন share করে, তাই আপনি যেকোনো সময় এদের মধ্যে অদলবদল করতে পারেন।

## Configuration অপশন

### slash command resync করুন

Telegram-এর slash menu sync-এর বাইরে চলে গেলে (বিরল — আপনার bot সংযুক্ত হওয়ার পরে command তালিকা server-side update করা হলে ঘটতে পারে), Saba on Telegram card-এ three-dot menu খুলুন এবং **Resync slash commands** বেছে নিন। platform canonical set-টি আবার BotFather-এ push করে।

### Disconnect

integration সরাতে:

1. **Cuneiform Chat থেকে:** Integrations → Saba on Telegram card → three-dot menu → **Delete**
2. **Telegram থেকে (ঐচ্ছিক):** BotFather-এর মাধ্যমে bot delete করুন (`/mybots` → bot নির্বাচন করুন → **Delete bot**)

Disconnect করলে প্রতিটি সদস্যের link সরে যায় এবং bot-কে response দেওয়া থেকে থামায়। আপনি BotFather-এ এটি delete না করলে Telegram bot নিজে সেখানেই থাকে।

## নকশা অনুসারে read-only

Saba on Telegram প্রশ্নের উত্তর দেয় এবং তথ্য তুলে ধরে — এটি আপনার org-এর data পরিবর্তন **করে না**। আপনি জিজ্ঞাসা করতে পারেন "কী ব্যর্থ হচ্ছে?" কিন্তু Telegram-এর মাধ্যমে "এটি ঠিক করো" বলতে পারবেন না। একটি agent edit করা, billing পরিবর্তন করা, বা একটি কথোপকথন delete করার মতো write action-এর জন্য admin panel ব্যবহার করুন।
