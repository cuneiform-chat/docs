# Telegram Premium co-pilot

আপনার AI agent-কে **একজন Telegram Premium user-এর ব্যক্তিগত account-এ** DM-এর reply দিতে দিন। তাদের contact-রা যা দেখে তা Premium user-এর নিজের reply-এর মতোই — যেসব founder, creator, solopreneur ও ছোট team-এর customer-রা তাদের ব্যক্তিগত Telegram-এ সরাসরি DM করে তাদের জন্য একদম উপযুক্ত।

## সংক্ষিপ্ত বিবরণ

Telegram Premium co-pilot প্রদান করে:

- Premium user-এর `business_connection`-এর মাধ্যমে পাঠানো AI reply, যাতে response তাদের কাছ থেকেই এসেছে বলে মনে হয়
- Per-Premium-user linking — একটি bot একই org-এর একাধিক Premium user-কে সমর্থন করতে পারে
- স্বয়ংক্রিয় manual takeover — Premium user যখন নিজে একটি reply টাইপ করেন, তখন bot সেই chat-এ একটি sliding window-এর জন্য থেমে যায় যাতে একটি চলমান কথোপকথনের উপর কথা না বলে
- Disconnect না করেই প্রতিটি linked user জুড়ে bot-কে চুপ করানোর জন্য connection-level kill switch
- Voice-note transcription ও live-streaming reply, regular Telegram channel-এর মতোই

## regular Telegram থেকে এটি কীভাবে আলাদা

regular [Telegram integration](/integrations/telegram) একটি agent-কে **একটি bot-এর নিজস্ব inbox**-এর সাথে সংযুক্ত করে — আপনার end user-রা সরাসরি `t.me/<bot>`-এ bot-কে DM করে। Telegram Premium co-pilot ঠিক উল্টো: bot **একজন ব্যক্তির ব্যক্তিগত Telegram account**-এ reply দেয়, সেই ব্যক্তির স্বাভাবিক chat list-এ আসা DM-গুলো intercept করে।

| | Telegram | Telegram Premium co-pilot |
|---|----------|----------------------------|
| Contact-রা কাকে message করে? | bot-কে (`t.me/<bot>`) | Premium user-এর ব্যক্তিগত account |
| Contact-রা কী দেখে? | bot থেকে reply | যেসব reply Premium user-এর কাছ থেকে এসেছে বলে মনে হয় |
| একটি bot সমর্থন করে… | সীমাহীন end user | আপনার org-এ N জন Premium user (প্রত্যেকে একটি করে row) |
| Group chat? | হ্যাঁ | না — শুধু DM |
| Manual takeover? | প্রযোজ্য নয় | Premium user টাইপ করলে auto-pause হয় |

## পূর্বশর্ত

- প্রতিটি user-এর জন্য একটি **Telegram Premium** সহ Telegram account, যিনি চান bot তাদের হয়ে reply দিক
- একটি নতুন BotFather bot — **Business mode-এর জন্য নিবেদিত** (অন্য কোনো integration-এর সাথে পুনরায় ব্যবহার করা যাবে না)
- একটি Cuneiform Chat agent যা ইতিমধ্যে Playground-এ configure ও test করা হয়েছে

## সেটআপ ধাপসমূহ

### ১. BotFather-এ একটি নিবেদিত bot তৈরি করুন

1. Telegram খুলুন, **@BotFather** সার্চ করুন এবং `/newbot` পাঠান
2. একটি নাম ও username বেছে নিন
3. **Bot Token** copy করুন

### ২. bot-এ Business Mode সক্রিয় করুন

এই ধাপটিই bot-কে একজন Premium user-এর account-এ reply দেওয়ার যোগ্য করে তোলে। এটি ছাড়া, Premium user-রা bot যোগ করার সময় *"this bot doesn't support Telegram Business yet"* দেখে।

1. BotFather-এ `/mybots` পাঠান এবং আপনার নতুন bot নির্বাচন করুন
2. **Bot Settings** → **Business Mode** বেছে নিন
3. এটি **ON** করুন

<Callout type="warning">
  Business Mode per-bot। আপনি এটি সক্রিয় করতে ভুলে গেলে, প্রতিটি Premium-user link প্রচেষ্টা উপরের message সহ নীরবে ব্যর্থ হয়। এটি আবার toggle করুন এবং পরের চেষ্টায় link কাজ করবে।
</Callout>

### ৩. Cuneiform Chat-এ bot সংযুক্ত করুন

1. Cuneiform Chat-এ, sidebar-এ **Integrations** খুলুন
2. **Telegram Premium co-pilot** card খুঁজুন
3. **Connect Premium bot**-এ click করুন
4. কোন **Agent** DM-এর উত্তর দেবে তা বেছে নিন (আপনি পরে এটি পরিবর্তন করতে পারবেন)
5. bot token paste করুন এবং submit করুন

### ৪. Premium user-রা তাদের ব্যক্তিগত account link করেন

প্রতিটি Premium user যিনি চান bot তাদের হয়ে reply দিক, তিনি একবার এটি করেন:

1. Telegram Premium card-এ, **Link a Premium user**-এ click করুন — একটি ১০-মিনিটের code আসে (একটি QR shortcut সহ)
2. Premium user **Telegram → Settings → Business → Chatbots** খোলেন
3. আপনার bot-এর username যোগ করেন এবং এটি সক্রিয় করেন
4. bot-এর সাথে একটি regular DM খোলেন এবং `/start <code>` পাঠান
5. bot একটি confirmation দিয়ে reply দেয়

একবার link সম্পন্ন হলে, Premium user-কে DM করা প্রতিটি contact AI reply পায় — শুধু তখনই নয় যখন Premium user নিজে একটি reply টাইপ করেন (নিচের Manual takeover দেখুন)।

## বৈশিষ্ট্যসমূহ

### Premium user-এর account-এ reply

একজন contact যখন Premium user-কে DM করে, Telegram Premium user-এর `business_connection`-এর মাধ্যমে bot-কে একটি `business_message` event পাঠায়। bot agent-কে call করে, তারপর একই connection-এর মাধ্যমে reply ফেরত পাঠায় — তাই contact বিদ্যমান thread-এ message-টি দেখে, Premium user-এর নামে। Contact-এর দিকে কোনো নতুন bot কথোপকথন তৈরি হয় না।

### স্বয়ংক্রিয় manual takeover

Premium user যে মুহূর্তে যেকোনো chat-এ নিজে একটি reply টাইপ করে পাঠান, bot **সেই chat**-এ একটি sliding window-এর জন্য থেমে যায়। Premium user আবার টাইপ করলেই window reset হয়, তাই চলমান কথোপকথন যতক্ষণ চলে bot ততক্ষণ চুপ থাকে। নীরবতার সময়ের পরে, bot আবার auto-reply শুরু করে।

এর মানে Premium user-কে একটি কথোপকথনে ঢোকার সময় স্পষ্টভাবে bot বন্ধ করতে হয় না — bot এমনিতেই সরে দাঁড়ায়।

### connection-level kill switch

Premium user যদি unlink না করেই **প্রতিটি** chat জুড়ে AI reply disable করতে চান:

1. Cuneiform Chat-এ Telegram Premium card খুলুন
2. **Disable auto-reply** toggle on করুন

Integration সংযুক্ত থাকে (পুনরায় link করার প্রয়োজন নেই) কিন্তু bot কিছুতেই reply দেয় না। আবার শুরু করতে এটি back on করুন।

### Voice note ও rich formatting

Contact-দের voice note Whisper-এর মাধ্যমে transcribe করা হয় এবং টাইপ করা message-এর মতো উত্তর দেওয়া হয়। Reply MarkdownV2-তে bold, italic, code block ও link সহ render হয় — regular Telegram channel-এর মতো একই toolkit।

## Configuration অপশন

### Per-integration setting

| Setting | বিবরণ |
|---------|-------|
| Agent | এই bot-এর জন্য সব linked Premium user জুড়ে কোন agent DM-এর উত্তর দেয় |
| Auto-reply enabled | connection-level kill switch (card-এ toggle) |

### Per-link control

card-এ প্রতিটি Premium-user row দেখায়:

- linked user-এর display name
- শেষ activity-র timestamp
- সেই user-কে unlink করার একটি delete control (bot তাদের জন্য reply দেওয়া বন্ধ করে; তাদের contact-রা আবার bot থেকে কিছুই না দেখা অবস্থায় ফিরে যায়)

## সমস্যা সমাধান

### Premium user "this bot doesn't support Telegram Business yet" দেখছেন

bot-এ Business Mode সক্রিয় নেই। BotFather → `/mybots` → আপনার bot → **Bot Settings** → **Business Mode** → **ON** করুন, তারপর Premium user-কে Settings → Business → Chatbots ধাপটি পুনরায় চেষ্টা করতে বলুন।

### Link code-এর মেয়াদ শেষ হয়ে গেছে

Code ১০ মিনিট পর্যন্ত valid থাকে। একটি নতুন তৈরি করতে আবার **Link a Premium user**-এ click করুন।

### bot সবার জন্য চুপ থাকে

integration card-এ **Disable auto-reply** toggle check করুন — এটি off থাকলে, bot প্রতিটি linked user উপেক্ষা করে। এটি আবার on করুন।

### bot একটি নির্দিষ্ট contact-এর জন্য চুপ থাকে

Premium user সম্প্রতি সেই chat-এ একটি reply টাইপ করেছেন এবং manual-takeover pause এখনো সক্রিয়। sliding window পরিষ্কার হওয়ার জন্য অপেক্ষা করুন, অথবা Premium user-কে সেই chat-এ টাইপ করা বন্ধ করতে বলুন।

### bot-এর reply ভুল দেখায়

Premium user-এর contact-রা ঠিক যা agent generate করে তাই দেখে। off-brand বা off-policy কিছু পার হয়ে গেলে, agent-এর prompt ও tool-এ এটি ঠিক করুন — এটি Telegram channel যে agent ব্যবহার করে সেই একই agent, test করার জন্য একই Playground সহ।

## Disconnect করা

একটি Telegram Premium integration সরাতে:

1. **Cuneiform Chat থেকে:** Integrations → Telegram Premium co-pilot card → three-dot menu → **Delete**

এটি প্রতিটি Premium-user link সরিয়ে দেয় এবং bot-কে reply দেওয়া থেকে থামায়। আপনি BotFather-এ bot-টি delete না করলে bot নিজে সেখানেই থাকে।
