# WooCommerce ইন্টিগ্রেশন

আপনার সেল্ফ-হোস্টেড **WooCommerce** স্টোর সংযুক্ত করুন যাতে আপনার AI agent পণ্যের প্রশ্নের উত্তর দিতে, ক্রেতার অর্ডার খুঁজে দিতে, স্টকে থাকা পণ্যের সুপারিশ করতে এবং অর্ডার-স্ট্যাটাস আপডেট পাঠাতে পারে — সবকিছুই আপনার আসল, লাইভ ক্যাটালগ ও অর্ডার ডেটা থেকে।

## সংক্ষিপ্ত বিবরণ

WooCommerce ইন্টিগ্রেশন আপনার সেল্ফ-হোস্টেড স্টোরকে WooCommerce REST API-এর মাধ্যমে আপনার AI agents-এর সাথে যুক্ত করে। WooCommerce হলো আপনার কমার্স ব্যাকএন্ড; আর আপনার Cuneiform agent হলো আপনি যে সব চ্যানেলে এটি ডিপ্লয় করেন তার সবগুলোতে কথোপকথনের স্তর। সংযুক্ত হওয়ার পর agent যা করতে পারে:

- **ক্যাটালগ প্রশ্নোত্তর** — আপনার আসল পণ্য, ভ্যারিয়েন্ট, দাম ও বর্তমান স্টক থেকে উত্তর দেয়
- **অর্ডার খোঁজা (WISMO)** — ক্রেতারা তাদের অর্ডার নম্বর এবং অর্ডারে থাকা ইমেইল বা ফোন দিয়ে "আমার অর্ডার কোথায়?" জানতে পারে
- **সুপারিশ** — এমন পণ্য প্রস্তাব করে যা আসলে **স্টকে** আছে
- **অর্ডার-স্ট্যাটাস আপডেট** — যেসব ক্রেতা অপ্ট-ইন করে তাদের একই চ্যাটে শিপিং আপডেট পাঠায়
- **লাইভ ইনভেন্টরি** — উত্তর দেওয়ার মুহূর্তে সবসময় হালনাগাদ দাম ও স্টক পড়ে
- **চেকআউট হ্যান্ডঅফ** — কিনতে প্রস্তুত ক্রেতাকে আপনার নিজের WooCommerce চেকআউটে পাঠায়

## পূর্বশর্ত

- একটি **সেল্ফ-হোস্টেড WooCommerce স্টোর** যা আপনি পরিচালনা করেন
- আপনার **স্টোর URL** (যেমন, `https://your-store.com`)
- আপনার কমার্স agent হওয়ার জন্য অন্তত **একটি agent** (সংযোগের সময় আপনি নতুন একটি তৈরি করতে পারেন)

আপনাকে কোনো প্লাগইন ইনস্টল করতে বা কোড লিখতে **হবে না**। স্ট্যান্ডার্ড সংযোগ প্রক্রিয়া হলো এককালীন অনুমোদন; শুধুমাত্র আপনার স্টোর ফায়ারওয়ালের পেছনে থাকলে রিড-অনলি consumer key/secret দরকার হয়।

## সেটআপ ধাপ

### 1. Commerce খুলুন

অ্যাডমিন প্যানেলে, **Commerce**-এ যান এবং **WooCommerce** বেছে নিন। Commerce হলো ইন্টিগ্রেশনের একক ঠিকানা — সংযোগ কার্ড, আপনার **Product Library**, **Settings** ও **Analytics** সবই এখানে।

### 2. আপনার স্টোর সংযুক্ত করুন

আপনার স্টোর URL দিন এবং **Connect** ক্লিক করুন। আপনি আপনার স্টোরে WooCommerce REST API-এর এককালীন অনুমোদন দেবেন, তারপর **Commerce**-এ ফিরে আসবেন। আপনার স্টোর যদি রিডাইরেক্ট ব্লক করা ফায়ারওয়ালের পেছনে থাকে, তবে **Enter API keys manually** প্রসারিত করুন এবং একটি **রিড-অনলি** consumer key ও secret পেস্ট করুন (WooCommerce → Settings → Advanced → REST API-এ তৈরি করা)।

### 3. আপনার কমার্স agent বেছে নিন

কমার্স **প্রতি agent-এ অপ্ট-ইন** এবং **ডিফল্টভাবে বন্ধ**। সংযোগের সময়, **একটিমাত্র** agent বেছে নিন যেটি আপনার কমার্স agent হবে — একটি বিদ্যমান সক্রিয় agent বা নতুন একটি। কেবল সেই agent WooCommerce টুল পায়; আপনার অন্য agents প্রভাবিত হয় না। পরে আপনি এটি **Commerce → Settings**-এ পরিবর্তন করতে পারেন।

### 4. আপনার ক্যাটালগ সিঙ্ক হতে দিন

সংযোগ আপনার পণ্য, ভ্যারিয়েন্ট, দাম, ছবি ও স্টকের এককালীন ইমপোর্ট শুরু করে। এরপর, পরিবর্তনগুলো স্বয়ংক্রিয়ভাবে সিঙ্ক হয়, এবং একটি দৈনিক রিকনসাইল বাদ পড়া যেকোনো কিছু ধরে ফেলে।

### 5. চেষ্টা করে দেখুন

আপনার কমার্স agent খুলুন এবং একটি ক্যাটালগ প্রশ্ন করুন ("এটি কোন কোন সাইজে পাওয়া যায়?", "নীলটি কি স্টকে আছে?") বা একটি অর্ডার খুঁজুন ("আমার অর্ডার #1001 কোথায়?")। agent আপনার লাইভ WooCommerce ডেটা থেকে উত্তর দেয়।

## এটি যেভাবে কাজ করে

```
ক্রেতা একটি প্রশ্ন করে
  → কমার্স agent আপনার লাইভ WooCommerce ক্যাটালগ ও অর্ডার পড়ে (রিড-অনলি)
  → পণ্য, স্টক ও অর্ডার স্ট্যাটাস নিয়ে উত্তর দেয়
  → কিনতে আপনার নিজের WooCommerce চেকআউটে পাঠায়
```

agent আপনার পণ্য, দাম, ইনভেন্টরি ও অর্ডার সরাসরি WooCommerce REST API-এর মাধ্যমে পড়ে এবং দাম ও স্টক হালনাগাদ রাখে — আপনার ক্যাটালগ কোনো নলেজ বেসে কপি-পেস্ট না করেই।

## বৈশিষ্ট্য

### ডিজাইন অনুযায়ী রিড-অনলি

ইন্টিগ্রেশন শুধু WooCommerce থেকে **পড়ে** (পণ্য, ইনভেন্টরি, অর্ডার)। এটি কখনো আপনার ক্যাটালগ বা ইনভেন্টরি বদলায় না, কখনো পেমেন্ট নেয় না, এবং কখনো অর্ডার তৈরি করে না। চেকআউট সবসময় আপনার নিজের WooCommerce স্টোরে হয়।

### এক স্টোর, এক কমার্স agent

আপনি **প্রতি সংস্থায় একটি WooCommerce স্টোর** সংযুক্ত করেন এবং সংযোগের সময় **ঠিক একটি agent**-কে কমার্স দেন। আপনি **Commerce → Settings**-এ চালু না করা পর্যন্ত বাকি agents নন-কমার্স থাকে।

### যাচাইকৃত অর্ডার খোঁজা

ক্রেতারা কেবল সঠিক অর্ডার নম্বর **এবং** অর্ডারে থাকা ইমেইল বা ফোন দেওয়ার পরই অর্ডারের বিবরণ দেখে। ভুল যোগাযোগ ও অস্তিত্বহীন অর্ডার একই "খুঁজে পাওয়া যায়নি" উত্তর দেয় কোনো বিবরণ ছাড়াই — এটি অ্যান্টি-এনিউমারেশন সুরক্ষা যা আপনার গ্রাহকদের রক্ষা করে।

### লাইভ ক্যাটালগ ও ইনভেন্টরি

agent উত্তর দেওয়ার মুহূর্তে দাম ও স্টক হালনাগাদ পড়ে, তাই সুপারিশ কেবল আসলে স্টকে থাকা আইটেমে সীমাবদ্ধ। কোনো সিঙ্ক বাদ পড়লে দৈনিক রিকনসাইল তা মেরামত করে।

### অপ্ট-ইন অর্ডার-স্ট্যাটাস আপডেট

ক্রেতা চ্যাটে তার অর্ডার যাচাই করার পর, একটি সমর্থিত চ্যানেলে শিপিং আপডেট পেতে অপ্ট-ইন করতে পারে। আপডেট কেবল তখনই পাঠানো হয় যখন আপনি **Commerce → Settings → Notifications**-এ সেগুলো চালু করেছেন এবং ক্রেতা অপ্ট-ইন করেছে।

## নিরাপত্তা

- **রিড-অনলি অ্যাক্সেস** — ইন্টিগ্রেশন আপনার স্টোরে কিছু তৈরি, সম্পাদনা বা মুছতে, ইনভেন্টরি বদলাতে বা পেমেন্ট নিতে পারে না
- **সংস্থা অনুযায়ী বিচ্ছিন্নতা** — আপনার ক্যাটালগ ও অর্ডার কেবল আপনার সংস্থার এবং অন্য টেন্যান্টদের কাছে কখনো দৃশ্যমান নয়
- **যাচাইকৃত অর্ডার খোঁজা** — অর্ডারের বিবরণের জন্য সঠিক অর্ডার নম্বরসহ মিলে যাওয়া ইমেইল বা ফোন লাগে (অ্যান্টি-এনিউমারেশন)
- **অপ্ট-ইন নোটিফিকেশন** — শিপিং আপডেটের জন্য চ্যাটে প্রতি ক্রেতার স্পষ্ট অপ্ট-ইন লাগে
- **নিরাপদ চেকআউট** — কেনাকাটা আপনার নিজের WooCommerce চেকআউটে সম্পন্ন হয়; কোনো কার্ড বা পেমেন্ট ডেটা agent-এর মধ্য দিয়ে যায় না

## সমস্যা সমাধান

### সংযোগ আটকে যায় বা ব্যর্থ হয়

সংযোগের জন্য সার্ভারকে আপনার স্টোর URL-এ পৌঁছাতে হয় এবং — স্ট্যান্ডার্ড প্রক্রিয়ায় — আপনাকে স্টোরে এককালীন অনুমোদন সম্পন্ন করতে হয়। আটকে গেলে, সাধারণত এটি স্টোরে পৌঁছানোর নেটওয়ার্ক বা ফায়ারওয়াল সমস্যা, আপনার শংসাপত্রের নয়। আপনার স্টোর ফায়ারওয়ালের পেছনে থাকলে, পরিবর্তে একটি **রিড-অনলি** consumer key/secret দিয়ে সংযুক্ত হন (**Enter API keys manually**)।

### agent পণ্যের প্রশ্নের উত্তর দেয় না

কমার্স **ডিফল্টভাবে বন্ধ** এবং সংযোগের সময় একটি agent-কে দেওয়া হয়। কোনো নির্দিষ্ট agent যদি ক্যাটালগ প্রশ্নের উত্তর না দেয়, **Commerce → Settings** খুলুন এবং তার কমার্স টগল চালু করুন।

### সংযোগের পরপরই ক্যাটালগ খালি দেখায়

প্রথম ইমপোর্ট আপনার পুরো ক্যাটালগ পূরণ করে এবং বড় স্টোরের জন্য কয়েক মিনিট লাগতে পারে। শেষ হলে, আপনার পণ্য অনুসন্ধানযোগ্য হয়; এরপর পরিবর্তনগুলো স্বয়ংক্রিয়ভাবে সিঙ্ক হয়।

### দাম বা স্টক লেভেল পুরনো দেখায়

agent প্রতিবার দাম ও স্টক হালনাগাদ পড়ে, তাই সেগুলো পুরনো হওয়ার কথা নয়। কোনো সিঙ্ক বাদ পড়ার বিরল ক্ষেত্রে, দৈনিক রিকনসাইল স্বয়ংক্রিয়ভাবে ক্যাটালগ মেরামত করে।

### অর্ডার খোঁজা কোনো অর্ডার পায় না

অর্ডার-খোঁজার টুল ইচ্ছাকৃতভাবে কঠোর: এটি কেবল তখনই বিবরণ ফেরত দেয় যখন ক্রেতা সঠিক অর্ডার নম্বর **এবং** অর্ডারের সাথে মিলে যাওয়া ইমেইল বা ফোন দেয়।

### কোনো অর্ডার-স্ট্যাটাস আপডেট পাঠানো হয় না

আপডেটের জন্য দুটি শর্তই লাগে: **Commerce → Settings → Notifications**-এ সেগুলো চালু করুন, এবং ক্রেতাকে একটি সমর্থিত চ্যানেলে চ্যাটে অপ্ট-ইন করান।

## সাধারণ প্রশ্ন

### WooCommerce সংযুক্ত করতে কি আমার পেইড প্ল্যান লাগবে?

না। WooCommerce ইন্টিগ্রেশন সব প্ল্যানে, ফ্রি ট্রায়াল সহ কাজ করে। আপনি যেকোনো প্ল্যানে একটি স্টোর সংযুক্ত করে ক্যাটালগ প্রশ্নোত্তর, অর্ডার খোঁজা, সুপারিশ ও অর্ডার-স্ট্যাটাস আপডেট ব্যবহার করতে পারেন।

### আমাকে কি একটি প্লাগইন ইনস্টল করতে হবে?

কোনো প্লাগইন নয়। স্ট্যান্ডার্ড প্রক্রিয়া হলো এককালীন অনুমোদন — আপনার স্টোর URL দিন এবং একটি রিড-অনলি WooCommerce REST API অনুমোদন দিন। শুধুমাত্র আপনার স্টোরের ফায়ারওয়াল স্বয়ংক্রিয় রিডাইরেক্ট ব্লক করলে আপনি একটি **রিড-অনলি** consumer key/secret পেস্ট করেন।

### আমার সব agents কি WooCommerce ব্যবহার করতে পারে, নাকি শুধু একটি?

কমার্স প্রতি agent-এ অপ্ট-ইন এবং ডিফল্টভাবে বন্ধ। সংযোগে আপনি **একটি** agent-কে কমার্স দেন; কেবল সেই agent WooCommerce টুল পায়। পরে আপনি **Commerce → Settings**-এ আরও agents-এর জন্য কমার্স চালু করতে পারেন।

### ইন্টিগ্রেশন আমার স্টোর ডেটা নিয়ে কী করে?

এটি প্রশ্নের উত্তর দিতে এবং অপ্ট-ইন করা আপডেট পাঠাতে আপনার ক্যাটালগ, ইনভেন্টরি ও অর্ডার পড়ে। এটি রিড-অনলি — কখনো আপনার স্টোর বদলায় না, কখনো ইনভেন্টরি বদলায় না, এবং কখনো পেমেন্ট নেয় না। চেকআউট সবসময় আপনার নিজের WooCommerce স্টোরে হয়।

### agent কি কখনো আমার স্টোর বদলায় বা অর্ডার তৈরি করে?

না। ইন্টিগ্রেশন কঠোরভাবে রিড-অনলি। এটি কখনো পণ্য সম্পাদনা করে না, কখনো ইনভেন্টরি সমন্বয় করে না, এবং ক্রেতার পক্ষে কখনো অর্ডার তৈরি বা পরিশোধ করে না — এই ক্রিয়াগুলো সবসময় আপনার নিজের WooCommerce স্টোরে হয়।
