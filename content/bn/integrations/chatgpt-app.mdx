# ChatGPT App

গ্রাহকরা যেখানে ইতিমধ্যেই আছেন সেখানেই পৌঁছান — **ChatGPT**-এর ভেতরে। আমরা **আপনার নিজের verified OpenAI organization**-এর অধীনে **আপনার কোম্পানির জন্য একটি ChatGPT app** প্রকাশ করি, যাতে আপনার গ্রাহকরা সরাসরি ChatGPT-এ আপনার AI agents-এর সাথে কথা বলতে পারেন — উত্তর আসে আপনার knowledge base থেকে এবং, ঐচ্ছিকভাবে, তাদের order দেখে নেওয়া যায়।

## সংক্ষিপ্ত বিবরণ

আপনার ChatGPT app **আপনার নিজের** — এটি আপনার নিজের verified OpenAI organization-এর অধীনে এবং আপনার কোম্পানির ব্র্যান্ডিং সহ প্রকাশিত হয়, অন্য কারও সাথে শেয়ার করা হয় না। live হয়ে গেলে, আপনার গ্রাহকরা পারবেন:

- **ChatGPT-এ আপনার agents-এর সাথে চ্যাট করতে** — উত্তর আসে আপনার agents এবং আপনার knowledge base থেকে, আপনার ব্র্যান্ডের কণ্ঠে
- **তাদের order দেখতে** *(ঐচ্ছিক)* — আপনি চালু করলে, ক্রেতারা একই কথোপকথনের ভেতরেই order-এর status দেখতে পারবেন
- **একটি সত্যিকারের, প্রকাশিত app ব্যবহার করতে** — ChatGPT-এর যেকোনো ব্যবহারকারী এটি ব্যবহার করতে পারবেন, তাদের দিক থেকে কোনো login বা setup ছাড়াই

আপনি ঠিক করেন আপনার কোন agents app-এর মাধ্যমে পাওয়া যাবে, যাতে আপনার গ্রাহকরা সবসময় সঠিক assistant পান।

## এটি কীভাবে কাজ করে

যেহেতু আপনার app আপনার নিজের OpenAI organization-এর অধীনে প্রকাশিত হয় এবং OpenAI দ্বারা পর্যালোচিত হয়, এটি এক-ক্লিকে সংযোগের বদলে একটি guided, managed প্রক্রিয়া:

1. **অনুরোধ করুন** — admin panel থেকে শুরু করুন এবং আপনার কোম্পানি ও ChatGPT-এ আপনি যে assistant চান সে সম্পর্কে আমাদের জানান
2. **আপনার OpenAI organization যাচাই করুন** — আপনি আপনার কোম্পানির domain-এর মালিকানা নিশ্চিত করেন, যাতে app-টি আপনার organization-এর অধীনে প্রকাশ করা যায়
3. **আপনার তথ্য দিন** — আপনার ব্র্যান্ডিং ও পছন্দ (app-এর নাম, assistant-টি কী করবে, order lookup চালু করা হবে কিনা) দিন; আপনি save করে পরে ফিরে আসতে পারেন — প্রক্রিয়াটি যেখানে থামিয়েছিলেন সেখান থেকেই চলতে থাকে
4. **আমরা জমা দিই** — আমাদের টিম আপনার app প্রস্তুত করে এবং পর্যালোচনার জন্য OpenAI-তে জমা দেয়
5. **Live হোন** — OpenAI অনুমোদন করার সাথে সাথেই আমরা আপনার app live করি এবং আপনার গ্রাহকরা ChatGPT-এ এটি ব্যবহার শুরু করতে পারেন

<Callout type="warning">
  **পর্যালোচনায় সময় লাগে।** OpenAI প্রতিটি প্রকাশিত app পর্যালোচনা করে, এবং অনুমোদনের সময়সীমা OpenAI নির্ধারণ করে — কয়েক সপ্তাহ থেকে কয়েক মাস পর্যন্ত ধরে রাখুন। **জমা দেওয়া মানেই অনুমোদিত নয়**: live হওয়ার আগে একটি app মন্তব্যসহ ফেরত পাঠানো হতে পারে। আপনার জমার অবস্থা সম্পর্কে আমরা আপনাকে জানিয়ে রাখি।
</Callout>

## আপনি যা নিয়ন্ত্রণ করেন

- **আপনার ব্র্যান্ডিং** — app-এর নাম এবং assistant কীভাবে নিজেকে পরিচয় করায়
- **কোন agents উত্তর দেবে** — শুধু সেই agents-কে উন্মুক্ত করুন যাদের আপনি ChatGPT-এ পাওয়া যাক চান
- **Order lookup** — order-status-এর ঐচ্ছিক tool-টি চালু বা বন্ধ করুন
- **আপনার OpenAI organization** — app আপনার organization-এর অধীনে থাকে, কখনো কোনো shared organization-এ নয়

## বিলিং

ChatGPT App আপনার প্ল্যানের একটি পেইড add-on:

- app তৈরি ও জমা দেওয়ার জন্য একটি **এককালীন setup fee**
- এটি প্রকাশিত ও সমর্থিত রাখার জন্য একটি **মাসিক upkeep** subscription

আপনি কত দেবেন তা আপনার প্ল্যানের উপর নির্ভর করে — add-on-এর বর্তমান মূল্যের জন্য আপনার প্ল্যানের বিবরণ দেখুন বা admin panel-এ আমাদের জিজ্ঞাসা করুন। আপনার গ্রাহকদের কিছু কেনার নেই; ChatGPT-এ আপনার app ব্যবহার করা তাদের জন্য বিনামূল্যে।

## প্রয়োজনীয়তা

- একটি **সক্রিয় পেইড প্ল্যান** — ChatGPT App একটি পেইড add-on এবং free trial-এ উপলব্ধ নয়
- আপনার কোম্পানির জন্য একটি **verified OpenAI organization** (আমরা আপনাকে এর মধ্য দিয়ে নিয়ে যাই)
- আপনার **কোম্পানির domain**-এর মালিকানা, যাতে app যাচাই করে আপনার organization-এর অধীনে প্রকাশ করা যায়
- অন্তত **একটি agent** যাকে আপনি ChatGPT-এর ভেতরে পাওয়া যাক চান

## সাধারণ জিজ্ঞাসা

### এটি কি অন্যান্য integration-এর মতো self-serve?

না। ChatGPT-এর ভেতরে একটি app প্রকাশ করতে একটি verified OpenAI organization প্রয়োজন এবং এটি OpenAI-এর পর্যালোচনার মধ্য দিয়ে যায়। আমরা এটি একটি managed পরিষেবা হিসেবে আপনার হয়ে সামলাই — আপনি অনুরোধ করেন ও আপনার তথ্য দেন, আর আমাদের টিম জমা দেওয়া ও live করার কাজ করে।

### আমার app live হতে কত সময় লাগবে?

এটি OpenAI-এর পর্যালোচনার উপর নির্ভর করে, যা সাধারণত কয়েক সপ্তাহ থেকে কয়েক মাস সময় নেয়। app জমা দিলেই তাৎক্ষণিক অনুমোদন নিশ্চিত হয় না — OpenAI এটি অনুমোদন করতে পারে, পরিবর্তন চাইতে পারে, বা মন্তব্যসহ ফেরত পাঠাতে পারে। পুরো প্রক্রিয়া জুড়ে আমরা আপনাকে জানিয়ে রাখি।

### app কোন OpenAI organization-এর অধীনে প্রকাশিত হয়?

আপনার। app আপনার নিজের verified OpenAI organization-এর অধীনে এবং আপনার কোম্পানির ব্র্যান্ডিং সহ প্রকাশিত হয় — এটি কোনো shared connector নয়।

### আমার গ্রাহকরা কি আমাদের কাছে account ছাড়াই এটি ব্যবহার করতে পারবেন?

হ্যাঁ। আপনার app live হয়ে গেলে, ChatGPT ব্যবহারকারী যে কেউ এর মাধ্যমে আপনার agents-এর সাথে কথা বলতে পারবেন। আপনার গ্রাহকদের কোনো Cuneiform Chat account বা তাদের দিক থেকে কোনো setup লাগে না।

### আমার কোন agents উত্তর দেবে?

শুধু যাদের আপনি উন্মুক্ত করতে বেছে নেন। আপনার ChatGPT app-এর মাধ্যমে কোন agents পাওয়া যাবে তা আপনিই ঠিক করেন।

### ChatGPT App-এর বিল কীভাবে করা হয়?

এটি আপনার প্ল্যানের একটি পেইড add-on — একটি এককালীন setup fee এবং একটি মাসিক upkeep subscription। সঠিক মূল্য আপনার প্ল্যানের উপর নির্ভর করে, তাই আপনার প্ল্যানের বিবরণ দেখুন বা admin panel-এ জিজ্ঞাসা করুন।
