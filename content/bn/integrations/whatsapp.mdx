# WhatsApp ইন্টিগ্রেশন

গ্রাহক যোগাযোগের জন্য আপনার agent-কে WhatsApp Business-এ সংযুক্ত করুন।

## সংক্ষিপ্ত বিবরণ

WhatsApp integration প্রদান করে:
- Business messaging সক্ষমতা
- Rich media support
- স্বয়ংক্রিয় response
- বৈশ্বিক পরিসর
- ২৪ ঘণ্টার messaging window compliance
- [নথি সংযুক্তি](/integrations/document-attachments) — গ্রাহকরা একটি file পাঠিয়ে সে সম্পর্কে জিজ্ঞাসা করতে পারেন (ডিফল্টে চালু, paid plan)

## পূর্বশর্ত

- একটি active AI agent (Agents section-এ তৈরি)
- একটি WhatsApp Business Account (WABA)
- WhatsApp Business-এ একটি verified ফোন নম্বর
- Meta Developer Portal-এ access

## সেটআপ ধাপসমূহ

### ১. Embedded Signup-এর মাধ্যমে সংযুক্ত করুন (সুপারিশকৃত)

WhatsApp সংযুক্ত করার সবচেয়ে সহজ উপায় হলো embedded Meta signup flow:

1. **Agents** → আপনার agent নির্বাচন করুন
2. **Integrations** tab-এ navigate করুন
3. **WhatsApp**-এ click করুন
4. Meta signup popup খুলতে **Connect with Facebook**-এ click করুন
5. আপনার Facebook/Meta account দিয়ে log in করুন
6. একটি WhatsApp Business Account নির্বাচন বা তৈরি করুন
7. সংযুক্ত করতে ফোন নম্বর বেছে নিন
8. Popup বন্ধ হয় এবং আপনার সংযোগ স্থাপিত হয়

### ২. ফোন Verification (প্রয়োজন হলে)

Meta signup সম্পন্ন হওয়ার পর আপনার ফোন নম্বর verify করতে হতে পারে:

1. Verification code কীভাবে পাবেন তা বেছে নিন: **SMS** বা **Voice Call**
2. **Send Code**-এ click করুন
3. আপনি যে ৬-সংখ্যার code পাবেন তা দিন
4. **Verify**-এ click করুন

Code না পেলে পুনরায় চেষ্টা করতে "Didn't receive the code? Send again"-এ click করুন।

### ৩. Two-Step Verification (Enable থাকলে)

আপনার WhatsApp Business account-এ Two-Step Verification enable থাকলে:

1. Prompt হলে আপনার ৬-সংখ্যার PIN দিন
2. **Complete Registration**-এ click করুন

<Callout type="info">
  এই PIN WhatsApp Business Manager → Security Center-এ সেট আপ করা হয়েছিল। এটি SMS verification code থেকে ভিন্ন।
</Callout>

### ৪. Webhook configure করুন (প্রয়োজন হলে)

সেটআপের পর Meta Business Suite-এ আপনার webhook configure করতে হতে পারে:

1. সংযুক্ত হওয়ার পর প্রদত্ত webhook URL copy করুন
2. Meta Developer Portal-এ **WhatsApp** → **Configuration**-এ যান
3. Webhook URL যোগ করুন
4. `messages` webhook field subscribe করুন

## Bot ব্যবহার করা

### গ্রাহক Message

গ্রাহকরা আপনার WhatsApp নম্বরে message করলে:

1. Message WhatsApp-এর মাধ্যমে আসে
2. Cuneiform Chat request প্রক্রিয়া করে
3. Agent content থেকে response তৈরি করে
4. Response গ্রাহকের কাছে ফেরত যায়

### Conversation Flow

```
গ্রাহক → WhatsApp → Cuneiform Chat → Agent → Response → গ্রাহক
```

## বৈশিষ্ট্যসমূহ

### ২৪ ঘণ্টার Messaging Window

WhatsApp Business API নিয়ম:
- গ্রাহক-initiated message-এ ২৪ ঘণ্টা respond করতে পারবেন
- ২৪ ঘণ্টা পর গ্রাহক আবার message না করা পর্যন্ত window বন্ধ থাকে
- প্রতিটি নতুন গ্রাহক message window পুনরায় খোলে

<Callout type="info">
  আপনার agent স্বয়ংক্রিয়ভাবে ২৪ ঘণ্টার window-এর মধ্যে respond করে। Re-engagement-এর জন্য template message বর্তমানে সমর্থিত নয়।
</Callout>

### Rich Media

Response-এ অন্তর্ভুক্ত থাকতে পারে:
- Text message
- Link
- Formatted text

### নথি সংযুক্তি

গ্রাহকরা একটি PDF, Word, PowerPoint, text বা Markdown file — অথবা একটি ছবি — পাঠিয়ে আপনার agent-কে সে সম্পর্কে জিজ্ঞাসা করতে পারেন। Sticker পড়া হয় না, এবং WhatsApp প্রতি message-এ একটি attachment বহন করে, তাই file একটি একটি করে আসে।

WhatsApp-এ এটি **ডিফল্টে চালু**: একজন admin চাইলে integration card-এ **নথি সংযুক্তির অনুমতি দিন** বন্ধ করতে পারেন। ছবি বা scan-এর জন্য এখনও **জটিল নথির জন্য প্রিমিয়াম পার্সিং** লাগে, যা একজন admin চালু না করা পর্যন্ত বন্ধ থাকে। সমর্থিত type, সীমা ও setup-এর জন্য [নথি সংযুক্তি](/integrations/document-attachments) দেখুন।

### বহু-ভাষা

আপনার agent স্বয়ংক্রিয়ভাবে গ্রাহকের ভাষা শনাক্ত করে এবং সেই ভাষায় respond করে — ১৭৬টি ভাষা সমর্থিত, কোনো configuration প্রয়োজন নেই।

## সংযুক্ত নম্বর পরিচালনা

প্রতিটি সংযুক্ত WhatsApp নম্বর দেখায়:
- **Business name** বা display ফোন নম্বর
- **Status badge** - Active, Inactive, বা Error
- **ফোন নম্বর**
- **শেষ কার্যকলাপ** timestamp

### উপলব্ধ Action

| Action | বিবরণ |
|--------|-------|
| **Test Connection** | Integration কাজ করছে কিনা যাচাই করে |
| **Disconnect** | এই integration সরায় |

Integration card-এ three-dot menu-র মাধ্যমে এগুলো access করুন।

## সমস্যা সমাধান

### সংযোগ ব্যর্থ

1. আপনার একটি valid WhatsApp Business Account আছে কিনা নিশ্চিত করুন
2. আপনার ফোন নম্বর verified কিনা পরীক্ষা করুন
3. Embedded signup flow আবার চেষ্টা করুন

### ফোন Verification কাজ করছে না

1. SMS/Voice-এর জন্য ফোন নম্বরে access আছে কিনা নিশ্চিত করুন
2. নতুন code অনুরোধ করার আগে কয়েক মিনিট অপেক্ষা করুন
3. ফোন নম্বর অন্যত্র সংযুক্ত নেই কিনা পরীক্ষা করুন

### Two-Step Verification Error

1. WhatsApp Business Manager → Security Center-এ সেট আপ করা PIN দিন
2. এটি SMS verification code থেকে ভিন্ন
3. PIN না জানলে আপনার WhatsApp Business admin-এর সাথে যোগাযোগ করুন

### Message আসছে না

1. Meta Business Suite-এ webhook সঠিকভাবে configured কিনা যাচাই করুন
2. Webhook subscription-এ `messages` অন্তর্ভুক্ত কিনা পরীক্ষা করুন
3. Integration status "Active" কিনা নিশ্চিত করুন

### Response ব্যর্থতা

1. Playground-এ আপনার agent কাজ করছে কিনা পরীক্ষা করুন
2. ২৪ ঘণ্টার window active কিনা যাচাই করুন (গ্রাহক সম্প্রতি message করেছে)
3. Admin panel-এ integration status পরীক্ষা করুন

## নিরাপত্তা

- Access token এনক্রিপ্ট করে সুরক্ষিতভাবে সংরক্ষণ করা হয়
- Message secure connection-এর মাধ্যমে প্রক্রিয়া হয়

## Compliance

WhatsApp Business-এর ব্যবহার নীতিমালা:
- শুধুমাত্র গ্রাহক-initiated conversation-এ respond করুন
- Opt-out বিকল্প প্রদান করুন
- Meta-এর Commerce এবং Business নীতিমালা অনুসরণ করুন

## সংযোগ বিচ্ছিন্ন করা

WhatsApp integration সরাতে:

1. **Agents** → agent নির্বাচন করুন → **Integrations**
2. আপনার WhatsApp integration-এ three-dot menu-তে click করুন
3. **Disconnect** নির্বাচন করুন

এটি agent-কে respond করা বন্ধ করে। সম্পূর্ণ সরাতে:
- Meta Developer Portal-এ webhook মুছুন
- ঐচ্ছিকভাবে আপনার Meta app থেকে WhatsApp product সরান

## সাধারণ প্রশ্ন

**প্রশ্ন: কীভাবে WhatsApp সংযুক্ত করব?**
উত্তর: Integrations tab-এ "WhatsApp"-এ click করে, তারপর "Connect with Facebook"-এ click করে embedded signup ব্যবহার করুন। এটি স্বয়ংক্রিয়ভাবে Meta signup প্রক্রিয়ার মাধ্যমে আপনাকে গাইড করে।

**প্রশ্ন: কেন আমাকে verification code দিতে বলা হচ্ছে?**
উত্তর: নতুন সংযোগের জন্য WhatsApp-এর ফোন verification প্রয়োজন। ৬-সংখ্যার code পেতে SMS বা Voice Call বেছে নিন, তারপর setup সম্পন্ন করতে এটি দিন।

**প্রশ্ন: Two-Step Verification PIN কী?**
উত্তর: WhatsApp Business Manager-এ Two-Step Verification enable করে থাকলে, setup-এর সময় সেই ৬-সংখ্যার PIN দিতে হবে। এটি SMS verification code থেকে ভিন্ন।

**প্রশ্ন: একাধিক WhatsApp নম্বর সংযুক্ত করা যায়?**
উত্তর: হ্যাঁ, আপনি একাধিক WhatsApp Business নম্বর সংযুক্ত করতে পারেন। প্রতিটি নম্বর একটি ভিন্ন (বা একই) AI agent-এর সাথে সংযুক্ত করা যায়।
