# ইন্টিগ্রেশন

আপনার agent-গুলো একাধিক channel-এ deploy করুন এবং user-দের কাছে পৌঁছান যেখানেই তারা আছেন।

## উপলব্ধ Channel সমূহ

| Channel | বিবরণ | সবচেয়ে উপযুক্ত |
|---------|-------|-----------------|
| [Telegram](/integrations/telegram) | Telegram bot | Mobile user, community |
| [Discord](/integrations/discord) | Slash command সহ Discord bot | Gaming, developer community |
| [Slack](/integrations/slack) | Slack app | Team workspace |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | গ্রাহক যোগাযোগ |
| [Google Chat](/integrations/google-chat) | Google Workspace app | Enterprise team |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | সাধারণ ব্যবহারকারী |
| [ওয়েবসাইট উইজেট](/integrations/website-widget) | Embeddable chat widget | গ্রাহক সহায়তা, যেকোনো ওয়েবসাইট |

## ইন্টিগ্রেশন কীভাবে কাজ করে

1. **Configure** — আপনার পছন্দের channel-এর জন্য integration সেট আপ করুন
2. **Connect** — আপনার agent-কে channel-এর সাথে সংযুক্ত করুন
3. **Deploy** — আপনার agent user-দের জন্য উপলব্ধ হয়ে যায়
4. **Monitor** — Conversation এবং ব্যবহার ট্র্যাক করুন

## মাল্টি-চ্যানেল Deployment

একটি agent একসাথে একাধিক channel-এ deploy করা যায়:

- সব channel-এ একই content
- সর্বত্র সামঞ্জস্যপূর্ণ response
- কেন্দ্রীভূত conversation history
- একীভূত analytics

## Channel-ভিত্তিক বৈশিষ্ট্য

প্রতিটি channel-এর নিজস্ব সক্ষমতা রয়েছে:

- **Telegram** — Rich message, inline keyboard
- **Discord** — Slash command, server integration
- **Slack** — Workspace app, channel response
- **WhatsApp** — Business messaging, rich media
- **Google Chat** — Google Workspace integration, Spaces support, document Q&A + Space Knowledge Base
- **Meta (Facebook)** — Messenger integration, Page messaging
- **ওয়েবসাইট উইজেট** — Embeddable chat, customizable appearance, domain allowlisting

## প্রয়োজনীয়তা

Integration সেটআপ করার আগে:

1. কমপক্ষে একটি agent তৈরি করুন
2. আপনার content-এ document আপলোড করুন
3. Playground-এ আপনার agent test করুন

প্রতিটি channel-এর অতিরিক্ত প্রয়োজনীয়তা থাকতে পারে (bot token, app credential ইত্যাদি) যা তাদের নিজ নিজ guide-এ বিস্তারিত দেওয়া আছে।
