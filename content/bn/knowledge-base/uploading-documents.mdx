# Document আপলোড

আপনার content-এ document আপলোড করুন যাতে আপনার AI agent-গুলো সেগুলো ব্যবহার করে প্রশ্নের উত্তর দিতে পারে। Document স্বয়ংক্রিয়ভাবে process ও searchable করা হয়।

## কীভাবে যাবেন

1. Admin Panel-এ log in করুন
2. Sidebar menu-তে **Content**-এ navigate করুন
3. Page-এর উপরে upload area দেখা যাবে

## আপলোড পদ্ধতি

### Local File আপলোড

1. Upload area-তে সরাসরি file **drag and drop** করুন, অথবা
2. File browser খুলতে upload area-তে **click** করুন
3. এক বা একাধিক file নির্বাচন করুন
4. Progress tracking সহ file স্বয়ংক্রিয়ভাবে আপলোড শুরু হয়

### Cloud Storage Import

আপনার cloud storage provider থেকে সরাসরি file import করুন:

| Provider | Icon | কীভাবে ব্যবহার করবেন |
|----------|------|----------------------|
| Google Drive | Google Drive icon | Google Drive picker খুলতে click করুন, file নির্বাচন করুন |
| Dropbox | Dropbox icon | Dropbox chooser খুলতে click করুন, file নির্বাচন করুন |
| OneDrive | OneDrive icon | OneDrive picker খুলতে click করুন, file নির্বাচন করুন |
| Box | Box icon | Box picker খুলতে click করুন, file নির্বাচন করুন |

যেকোনো provider থেকে file নির্বাচন করলে সেগুলো স্বয়ংক্রিয়ভাবে আপনার content-এ import হয়।

## আপলোড বিকল্প

### Tag যোগ করা

আপলোডের সময় ঐচ্ছিকভাবে document-এ tag assign করুন:

1. আপলোডের আগে **+ Add Tags**-এ click করুন
2. Dropdown থেকে tag নির্বাচন করুন
3. নির্বাচিত tag সব আপলোড করা document-এ প্রযোজ্য হবে

## সমর্থিত File Type

আপনি যে file type আপলোড করতে পারবেন তা আপনার plan-এর উপর নির্ভর করে। সাধারণ format-গুলো হলো:

- **Document:** PDF, DOCX, DOC, TXT, MD, RTF
- **Presentation:** PPTX, PPT
- **Web/Data:** HTML, HTM, JSON, XML

File size limit-ও plan অনুযায়ী ভিন্ন হয় (upload area-তে দেখানো হয়)।

সম্পূর্ণ তালিকার জন্য [সমর্থিত Format](/knowledge-base/supported-formats) দেখুন।

## আপলোডের সময়

### Progress Tracking

- প্রতিটি file percentage bar সহ আপলোড progress দেখায়
- আপলোড speed ও আনুমানিক অবশিষ্ট সময় প্রদর্শিত হয়
- File একটি একটি করে process হয়

### Cancel বিকল্প

- **Individual file cancel:** একটি file-এর পাশে X-এ click করুন
- **সব cancel:** পুরো batch বন্ধ করতে "Cancel All Pending"-এ click করুন
- আপলোডের সময় page ছেড়ে যেতে চাইলে একটি warning দেখা যায়

## Processing Status

Content-এ document-এর status track করুন:

| Status | অর্থ |
|--------|------|
| Uploaded | Document system-এ আপলোড হয়েছে |
| Validating | Document যাচাই হচ্ছে |
| Stored | Document সংরক্ষিত হয়েছে এবং processing-এর অপেক্ষায় |
| Processing | Document analyze ও index হচ্ছে |
| Ready | Document process সম্পন্ন এবং আপনার agent-দের জন্য উপলব্ধ |
| Failed | Processing-এ সমস্যা হয়েছে (পুনরায় চেষ্টা করা যায়) |

## আপলোডের পরে

### সফল আপলোড

- সফলভাবে আপলোড হওয়া file আপনার document browser-এ দেখা যায়
- Document স্বয়ংক্রিয়ভাবে search-এর জন্য process হয়
- আপনি সেগুলো folder-এ সাজাতে বা tag যোগ করতে পারেন

### Duplicate সনাক্তকরণ

- System স্বয়ংক্রিয়ভাবে duplicate content সনাক্ত করে
- একই content-এর file ইতিমধ্যে থাকলে আপনি একটি warning দেখবেন
- Error message-এ বিদ্যমান file-এর অবস্থান দেখানো হয়

### Error পরিচালনা

- File আপলোড ব্যর্থ হলে একটি error message কারণ ব্যাখ্যা করে
- সাধারণ সমস্যার মধ্যে রয়েছে file বেশি বড় বা অসমর্থিত format
- আপনি individual file retry করতে বা পুনরায় আপলোড করতে পারেন

## পরামর্শ

- সময় বাঁচাতে একসাথে একাধিক file আপলোড করুন
- Document সংগঠিত রাখতে আপলোডের সময় tag প্রয়োগ করুন
- Upload area-তে দেখানো সমর্থিত file type পরীক্ষা করুন

## সাধারণ প্রশ্ন

**প্রশ্ন: একসাথে কতটি file আপলোড করা যায়?**
উত্তর: আপনি batch আপলোডের জন্য একাধিক file নির্বাচন করতে পারেন। সেগুলো progress tracking সহ একটি একটি করে process হয়।

**প্রশ্ন: আমার file কেন প্রত্যাখ্যান হলো?**
উত্তর: File type সমর্থিত কিনা এবং file size সীমার মধ্যে আছে কিনা পরীক্ষা করুন (upload area-তে দেখানো আছে)। কিছু file নিরাপত্তার কারণে block হতে পারে।

**প্রশ্ন: Processing-এ কতক্ষণ লাগে?**
উত্তর: আপলোডের সময় file size ও আপনার connection-এর উপর নির্ভর করে। আপলোডের পর document background-এ process হয় এবং স্বয়ংক্রিয়ভাবে searchable হয়।

**প্রশ্ন: নির্দিষ্ট folder-এ আপলোড করা যায়?**
উত্তর: হ্যাঁ, আপনি folder menu ব্যবহার করে সরাসরি folder-এ আপলোড করতে পারেন অথবা আপলোডের পরে document সাজাতে পারেন।
