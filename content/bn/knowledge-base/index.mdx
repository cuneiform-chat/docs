# Content

Content হলো সেই জায়গা যেখানে আপনার AI agent-গুলো প্রশ্নের উত্তর দিতে যে সব document ব্যবহার করে সেগুলো পরিচালনা করবেন। Document আপলোড করুন, folder-এ সংগঠিত করুন, tag যোগ করুন এবং কোন agent কোন content access করতে পারবে তা নিয়ন্ত্রণ করুন।

## কীভাবে কাজ করে

1. **Content যোগ করুন** — Document আপলোড করুন, cloud storage থেকে import করুন, বা website crawl করুন
2. **Process** — Document স্বয়ংক্রিয়ভাবে process ও index করা হয়
3. **Search** — প্রশ্নের উত্তর দেওয়ার সময় agent প্রাসঙ্গিক content search করে
4. **Respond** — আপনার প্রকৃত content-এর উপর ভিত্তি করে উত্তর তৈরি হয়

## কীভাবে যাবেন

Sidebar menu-তে **Content**-এ navigate করুন। এটি আপনার document management-এর কেন্দ্রীয় hub।

## আপনি যা দেখবেন

### Upload Area

Page-এর উপরে:
- **Cloud Storage Icon** — সরাসরি file import করতে Google Drive, Dropbox, OneDrive, বা Box-এ click করুন
- **Drop Zone** — File drag and drop করুন বা local file browse করতে click করুন
- **Website Tab** — Public website content crawl ও import করতে Website tab-এ যান

### Document Browser

Upload area-র নিচে একটি table আপনার সব document দেখায়:

| কলাম | বিবরণ |
|------|-------|
| Name | Type icon ও source indicator সহ document-এর filename |
| Tags | Document-এ assign করা label |
| Status | Processing-এর অবস্থা (নিচে Document Status দেখুন) |
| Size | MB-তে file size |
| Type | File extension (PDF, DOCX, ইত্যাদি) |
| Uploaded | আপলোডের তারিখ ও সময় |
| Actions | Document operation-এর menu |

### Toolbar

- **Search** — নাম দিয়ে document খুঁজুন
- **Tag Filter** — নির্দিষ্ট tag আছে এমন document দেখুন
- **Refresh** — Document list update করুন
- **New Folder** — সংগঠনের জন্য folder তৈরি করুন
- **Fullscreen** — আরও জায়গার জন্য browser expand করুন

## Document Status

| Status | অর্থ |
|--------|------|
| Uploaded | Document system-এ আপলোড হয়েছে |
| Validating | Document যাচাই হচ্ছে |
| Stored | Document সংরক্ষিত হয়েছে এবং processing-এর অপেক্ষায় |
| Processing | Document analyze ও index হচ্ছে |
| Ready | Document process সম্পন্ন এবং আপনার agent-দের জন্য উপলব্ধ |
| Failed | Processing-এ সমস্যা হয়েছে (পুনরায় চেষ্টা করা যায়) |

## Document নিয়ে কাজ করা

### Document দেখুন

যেকোনো document row-তে click করলে document viewer খুলবে, যেখানে content ও metadata দেখা যায়।

### Document Actions

Document-এর উপর hover করলে quick action button দেখা যায়:
- **Tag** — Tag যোগ বা সরান
- **Premium Processing** — Processing-এর মান উন্নত করুন (যোগ্য হলে)
- **Retry** — ব্যর্থ document পুনরায় process করুন
- **Chat** — এই নির্দিষ্ট document নিয়ে কথোপকথন করুন

Actions menu (...) থেকে:
- **Move to Folder** — Document স্থানান্তর করুন
- **Reprocess** — ব্যর্থ document পুনরায় process করুন
- **Delete** — Document স্থায়ীভাবে মুছুন

## সেরা অনুশীলন

- **Content আপ-টু-ডেট রাখুন** — সঠিকতা বজায় রাখতে নিয়মিত document update করুন
- **Folder দিয়ে সংগঠিত করুন** — সহজ পরিচালনার জন্য সম্পর্কিত document গ্রুপ করুন
- **Cross-cutting theme-এর জন্য tag ব্যবহার করুন** — Tag folder জুড়ে document খুঁজতে সাহায্য করে
- **মান গুরুত্বপূর্ণ** — সুসংগঠিত document ভালো AI response তৈরি করে
- **Duplicate সরান** — একই content একাধিকবার আপলোড করা এড়িয়ে চলুন
