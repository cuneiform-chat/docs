# Folder ও Tag

Folder ও tag ব্যবহার করে আপনার Content-এর document সংগঠিত করুন। Folder শ্রেণিবদ্ধ সংগঠন প্রদান করে, আর tag folder জুড়ে cross-cutting শ্রেণিবিভাগের সুযোগ দেয়।

## কীভাবে যাবেন

Sidebar-এ **Knowledge**-এ navigate করুন। Document browser-এ folder দেখা যায়, এবং toolbar-এ tag control আছে।

## Folder নিয়ে কাজ করা

### Folder তৈরি

1. Toolbar-এ **New Folder** button-এ (folder icon with +) click করুন
2. একটি folder name দিন (আবশ্যক)
3. ঐচ্ছিকভাবে একটি description যোগ করুন
4. Color picker ব্যবহার করে একটি রঙ বেছে নিন
5. **Create**-এ click করুন

### Folder Edit

1. Folder row-তে three-dot menu (...)-এ click করুন
2. **Rename** নির্বাচন করুন
3. Name, description, বা color update করুন
4. **Save Changes**-এ click করুন

### Folder Delete

1. Folder row-তে three-dot menu (...)-এ click করুন
2. **Delete** নির্বাচন করুন
3. Deletion নিশ্চিত করুন

### Folder-এ আপলোড

- সরাসরি folder row-তে file drag করুন
- Folder-এর উপর hover করলে upload icon দেখা যায় (cloud storage + local file)
- Folder expand করতে click করুন এবং এর document দেখুন

## Tag নিয়ে কাজ করা

### Tag পরিচালনা (তৈরি, Edit, Delete)

1. Toolbar-এ **Tag Filter** dropdown-এ click করুন
2. নিচে **Manage Tags**-এ click করুন
3. Modal-এ:
   - নতুন tag যোগ করতে **Create Tag**-এ click করুন
   - দ্রুত তৈরির জন্য suggested tag ব্যবহার করুন
   - বিদ্যমান tag edit করুন (name, color)
   - অব্যবহৃত tag delete করুন

### Document-এ Tag যোগ

1. Document row-এর উপর hover করুন
2. **Tag** button-এ (tag icon) click করুন
3. Manage Tags dialog-এ:
   - উপরে বর্তমান tag দেখুন
   - উপলব্ধ tag search করুন
   - যোগ করতে tag check করুন
   - **Add X tags** button-এ click করুন

### Document থেকে Tag সরানো

1. Document-এর জন্য Manage Tags dialog খুলুন
2. "Current Tags" section-এ সরাতে চাওয়া tag-এ X click করুন
3. **Remove X tags** button-এ click করুন

### Tag দিয়ে Document Filter

1. Toolbar-এ **Tag Filter** dropdown-এ click করুন
2. এক বা একাধিক tag নির্বাচন করুন
3. শুধুমাত্র সেই tag আছে এমন document দেখা যায়
4. নির্বাচিত tag toolbar-এর নিচে filter bar-এ দেখা যায়
5. Filter সরাতে tag chip-এ X click করুন, বা **Clear all**

## Folder বনাম Tag

| বৈশিষ্ট্য | Folder | Tag |
|-----------|--------|-----|
| গঠন | শ্রেণিবদ্ধ (প্রতি document একটি folder) | সমতল (প্রতি document একাধিক tag) |
| উপযুক্ত | বিস্তৃত বিভাগ, project, department | বিষয়, theme, status, cross-cutting বিষয় |
| Filtering | Folder-এ click করে content দেখুন | Folder জুড়ে খুঁজতে tag filter ব্যবহার করুন |
| Document সীমা | প্রতি document একটি folder | প্রতি document সীমাহীন tag |

## পরামর্শ

- প্রধান বিভাগের জন্য folder ব্যবহার করুন (যেমন, "Product Docs", "HR Policies")
- Cross-cutting theme-এর জন্য tag ব্যবহার করুন (যেমন, "Q1-2024", "Compliance", "Draft")
- Visual সংগঠনের জন্য folder ও tag-এ color দিন
- প্রতিটি tag কতটি document ব্যবহার করে তা usage count দেখায়
- সুনির্দিষ্ট document আবিষ্কারের জন্য folder ও tag filtering একসাথে ব্যবহার করুন

## সাধারণ প্রশ্ন

**প্রশ্ন: একটি document কি একাধিক folder-এ থাকতে পারে?**
উত্তর: না, প্রতিটি document একটি folder-এ (বা "Unfiled"-এ) থাকে। Cross-cutting শ্রেণিবিভাগের জন্য tag ব্যবহার করুন।

**প্রশ্ন: Folder delete করলে document-এর কী হয়?**
উত্তর: Document থাকা folder delete করা যায় না। আগে document সরান বা delete করুন।

**প্রশ্ন: নির্দিষ্ট tag-এর সব document কীভাবে দেখব?**
উত্তর: Toolbar-এ Tag Filter dropdown ব্যবহার করুন এবং tag নির্বাচন করুন।
