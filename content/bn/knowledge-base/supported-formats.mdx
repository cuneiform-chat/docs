# সমর্থিত Format

Cuneiform Chat বিভিন্ন ধরনের document format সমর্থন করে।

## Document Type

### Text Document

| Format | Extension | নোট |
|--------|-----------|------|
| PDF | `.pdf` | Text-based ও scanned (OCR সহ) |
| Microsoft Word | `.docx`, `.doc` | সম্পূর্ণ formatting সমর্থন |
| Plain Text | `.txt` | সাধারণ text file |
| Markdown | `.md` | Markdown formatting সংরক্ষিত |
| Rich Text | `.rtf` | মৌলিক formatting সমর্থন |

### Presentation

| Format | Extension | নোট |
|--------|-----------|------|
| PowerPoint | `.pptx`, `.ppt` | Slide content extract করা হয় |

### Web Content

| Format | Extension | নোট |
|--------|-----------|------|
| HTML | `.html`, `.htm` | Web page content |

### Data Format

| Format | Extension | নোট |
|--------|-----------|------|
| JSON | `.json` | Structured data file |
| XML | `.xml` | XML document |

## Format-বিশেষ নোট

### PDF

PDF সবচেয়ে ভালো কাজ করে যখন:
- **Text-based** — Digital document থেকে তৈরি
- **Searchable** — Text select/copy করা যায়

Scanned PDF সমর্থিত তবে OCR সীমাবদ্ধতার কারণে extraction-এর মান কম হতে পারে।

### Word Document

`.docx` (আধুনিক format) সেরা ফলাফলের জন্য `.doc` (legacy format)-এর চেয়ে recommended।

সমর্থিত উপাদান:
- Text ও paragraph
- Heading ও style
- Table
- List

### Markdown

Processing-এর সময় Markdown formatting সংরক্ষিত থাকে:
- Heading section marker হয়
- List-এর গঠন বজায় থাকে
- Code block চিহ্নিত হয়

## অসমর্থিত Format

বর্তমানে নিচের format সমর্থিত নয়:
- Image (`.jpg`, `.png`, `.gif`)
- Audio file (`.mp3`, `.wav`)
- Video file (`.mp4`, `.mov`)
- Compressed archive (`.zip`, `.rar`)
- Executable file (`.exe`, `.app`)

## File Size সীমা

সর্বোচ্চ file size আপনার plan-এর উপর নির্ভর করে। অনেক বড় document process হতে বেশি সময় নিতে পারে।

সেরা পারফরম্যান্সের জন্য:
- অনেক বড় document ছোট file-এ ভাগ করুন
- প্রয়োজন না হলে PDF থেকে অপ্রয়োজনীয় image সরান
- সম্ভব হলে text-based format ব্যবহার করুন
