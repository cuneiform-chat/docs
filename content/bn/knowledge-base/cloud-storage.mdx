# Cloud Storage Integration

import { Callout } from 'nextra/components'

আপনার cloud storage account থেকে সরাসরি document import করুন। Google Drive, Dropbox, OneDrive, বা Box সংযুক্ত করে আগে download না করেই আপনার Content-এ file যোগ করুন।

## কীভাবে যাবেন

Sidebar-এ **Knowledge**-এ navigate করুন। Upload drop zone-এর পাশে page-এর উপরে cloud storage icon দেখা যায়।

## সমর্থিত Provider

| Provider | Icon-এর অবস্থান | যা Import করতে পারবেন |
|----------|-----------------|----------------------|
| Google Drive | Cloud icon row | File, Google Docs, Slides |
| Dropbox | Cloud icon row | আপনার Dropbox-এর file |
| OneDrive | Cloud icon row | আপনার OneDrive-এর file |
| Box | Cloud icon row | আপনার Box account-এর file |

## কীভাবে File Import করবেন

### Step 1: Provider Icon-এ Click করুন

আপনার cloud storage provider-এর icon-এ click করুন। Hover করলে provider name সহ tooltip দেখা যায়।

### Step 2: Sign In করুন

Sign in ও access authorize করতে বলা হবে। এই authorization আপনার browser session-এর জন্য মনে রাখা হয়।

### Step 3: File নির্বাচন করুন

আপনার cloud storage-এর content দেখানো file picker খুলবে:
- File খুঁজতে folder-এ navigate করুন
- একসাথে একাধিক file নির্বাচন করুন
- শুধুমাত্র সমর্থিত file type দেখা যায় (আপনার plan অনুযায়ী)

### Step 4: Import করুন

নির্বাচন নিশ্চিত করতে click করুন। File import-এর জন্য queue হয় এবং স্বয়ংক্রিয়ভাবে processing শুরু হয়।

## Import বিকল্প

Import-এর আগে আপনি configure করতে পারেন:

| বিকল্প | বিবরণ |
|---------|-------|
| Premium Processing | ভালো AI বোঝাপড়ার জন্য enable করুন (upload area-র নিচে checkbox) |
| Target Folder | Folder row-তে provider icon-এ click করে সরাসরি folder-এ আপলোড করুন |

## নির্দিষ্ট Folder-এ Import

আপনি cloud file সরাসরি folder-এ import করতে পারেন:

1. Document browser-এ folder খুঁজুন
2. Folder row-এর উপর hover করুন
3. দেখা যাওয়া cloud storage icon-এ click করুন
4. আপনার cloud storage থেকে file নির্বাচন করুন
5. File সরাসরি সেই folder-এ import হয়

## Import-এর সময়

- Progress indicator import-এর status দেখায়
- Process হওয়ার সাথে সাথে file আপনার document list-এ দেখা যায়
- File import হওয়ার সময় আপনি কাজ চালিয়ে যেতে পারেন
- Duplicate সনাক্ত হলে import সম্পন্ন হওয়ার পর জানানো হবে

## Google Workspace File

Google Drive native Google Workspace document সমর্থন করে:
- **Google Docs** — স্বয়ংক্রিয়ভাবে text-এ রূপান্তরিত
- **Google Slides** — স্বয়ংক্রিয়ভাবে presentation format-এ রূপান্তরিত

<Callout type="info">
  Formatting ও chart সংরক্ষিত হয় না — শুধুমাত্র text content extract করা হয়।
</Callout>

## Permission

Cuneiform Chat ন্যূনতম permission অনুরোধ করে:
- শুধুমাত্র নির্বাচিত file-এ read access
- আপনার cloud storage-এ কোনো write access নেই
- আপনি স্পষ্টভাবে নির্বাচন করেননি এমন file-এ কোনো access নেই

<Callout type="info">
  আপনি যেকোনো সময় আপনার cloud provider-এর setting থেকে access প্রত্যাহার করতে পারেন।
</Callout>

## Sync আচরণ

বর্তমানে cloud import হলো **একবারের import**:
- Import-এর সময় file copy করা হয়
- Cloud storage-এ পরিবর্তন স্বয়ংক্রিয়ভাবে sync হয় না
- Content update করতে পরিবর্তিত file পুনরায় import করুন

## পরামর্শ

- সময় বাঁচাতে একসাথে একাধিক file নির্বাচন করুন
- Picker-এ শুধুমাত্র সমর্থিত file type দেখা যায় (আপনার plan অনুযায়ী)
- ভালো সংগঠনের জন্য folder-level import ব্যবহার করুন
- বড় file import-এর পর process হতে বেশি সময় নিতে পারে

## সাধারণ প্রশ্ন

**প্রশ্ন: প্রতিবার কি পুনরায় authorize করতে হয়?**
উত্তর: সাধারণত না। আপনার session active থাকলে icon-এ click করলে সরাসরি file picker খুলবে। Browser data clear করলে বা নতুন browser ব্যবহার করলে মাঝে মাঝে পুনরায় authorize করতে হতে পারে।

**প্রশ্ন: পুরো folder import করা যায়?**
উত্তর: বর্তমানে আপনি individual file নির্বাচন করেন। Picker-এ folder-এ navigate করে ভেতরের file নির্বাচন করুন।

**প্রশ্ন: আমার মূল file-এর কী হয়?**
উত্তর: আপনার cloud file অপরিবর্তিত থাকে। আমরা আপনার Content-এ একটি copy তৈরি করি।

**প্রশ্ন: Picker-এ কিছু file কেন দেখা যাচ্ছে না?**
উত্তর: শুধুমাত্র সমর্থিত file type দেখানো হয়। উপলব্ধ format দেখতে [সমর্থিত file type](/knowledge-base/supported-formats) পরীক্ষা করুন।

## সমস্যা সমাধান

### Authorization সমস্যা

সংযোগ করতে না পারলে:
- সঠিক account-এ sign in আছেন কিনা পরীক্ষা করুন
- Access প্রত্যাহার করে পুনরায় authorize করার চেষ্টা করুন
- আপনার provider setting-এ third-party app access enabled আছে কিনা নিশ্চিত করুন

### Import ব্যর্থতা

File import ব্যর্থ হলে:
- File সমর্থিত format-এ আছে কিনা যাচাই করুন
- File corrupt নয় কিনা পরীক্ষা করুন
- File access-এর permission আছে কিনা নিশ্চিত করুন
- একবারে কম file import করার চেষ্টা করুন
