# Document পরিচালনা

আপনার content document সংগঠিত, update ও রক্ষণাবেক্ষণ করতে শিখুন। এতে document দেখা, folder দিয়ে সংগঠিত করা, content update করা এবং bulk operation সম্পাদন অন্তর্ভুক্ত।

## কীভাবে যাবেন

1. Sidebar-এ **Content**-এ click করুন
2. List-এ আপনার সব document দেখুন

## Document দেখা

Content section থেকে আপনার document access করুন:

- List-এ সব document দেখুন
- প্রতিটি document-এর processing status দেখুন
- Document কখন যোগ বা update হয়েছে পরীক্ষা করুন

### Document-এর বিবরণ

যেকোনো document-এ click করে দেখুন:

| তথ্য | বিবরণ |
|------|-------|
| **File information** | Name, size, format, আপলোডের তারিখ |
| **Processing status** | Pipeline-এ বর্তমান অবস্থা |
| **Chunk count** | তৈরি হওয়া searchable segment-এর সংখ্যা |

## Document সংগঠিত করা

### Folder ব্যবহার

সম্পর্কিত document সংগঠিত করতে folder তৈরি করুন:

1. **New Folder** button-এ (folder icon with plus) click করুন
2. Folder name দিন
3. **Create**-এ click করুন

প্রস্তাবিত সংগঠন:
- বিষয় অনুযায়ী (Products, Policies, FAQs)
- Department অনুযায়ী (Sales, Support, HR)
- Document type অনুযায়ী (Guides, References, Tutorials)

### Document স্থানান্তর

Folder-এর মধ্যে document সরান:

1. Document menu-তে (⋮) click করুন
2. **Move to Folder** নির্বাচন করুন
3. Destination folder বেছে নিন

### Tag ব্যবহার

নমনীয় শ্রেণিবিভাগের জন্য document-এ tag যোগ করুন:

1. Document menu-তে (⋮) click করুন
2. **Manage Tags** নির্বাচন করুন
3. প্রয়োজনমতো tag যোগ বা সরান

Tag folder-এর পাশাপাশি কাজ করে — প্রাথমিক সংগঠনের জন্য folder এবং cross-cutting বিভাগের জন্য tag ব্যবহার করুন।

## Document Update করা

### ব্যর্থ Document পুনরায় Process

Document process ব্যর্থ হলে পুনরায় চেষ্টা করতে পারেন:

1. Document menu-তে (⋮) click করুন
2. **Reprocess** নির্বাচন করুন

import { Callout } from 'nextra/components'

<Callout type="info">
  Reprocess option শুধুমাত্র "Failed" status-এর document-এ দেখা যায়।
</Callout>

### Content প্রতিস্থাপন

Document-এর content update করতে পুরানো version delete করে নতুন file আপলোড করুন। Document স্বয়ংক্রিয়ভাবে process হবে।

## Document Delete করা

আর প্রয়োজন নেই এমন document সরান:

1. Document menu-তে (⋮) click করুন
2. **Delete** নির্বাচন করুন
3. Deletion নিশ্চিত করুন

<Callout type="warning">
  Delete করা document স্থায়ীভাবে সরানো হয় এবং পুনরুদ্ধার করা যায় না। Content আর আপনার agent-দের দ্বারা searchable থাকবে না।
</Callout>

## Bulk Operation

একসাথে একাধিক document পরিচালনা করুন:

1. Checkbox ব্যবহার করে একাধিক document নির্বাচন করুন
2. Bulk action menu ব্যবহার করুন:
   - **Move to Folder** — নির্বাচিত document folder-এ সরান
   - **Reprocess Failed** — নির্বাচনের মধ্যে ব্যর্থ document পুনরায় process করুন

## Search ও Filter

নির্দিষ্ট document খুঁজুন:

| বৈশিষ্ট্য | বিবরণ |
|-----------|-------|
| **Search** | Document name দিয়ে search করুন |
| **Filter by folder** | Content দেখতে document browser-এ folder-এ click করুন |
| **Filter by tag** | নির্দিষ্ট tag আছে এমন document দেখতে tag filter ব্যবহার করুন |

Document আপলোড তারিখ অনুযায়ী সাজানো থাকে (নতুন আগে)।

## Storage পরিচালনা

আপনার storage ব্যবহার track করুন:

1. **Dashboard**-এ যান
2. বর্তমান ব্যবহার ও সীমা দেখানো "Storage Used" card দেখুন
3. জায়গা খালি করতে অপ্রয়োজনীয় document delete করুন

## পরামর্শ

- Content পরিষ্কার রাখতে নিয়মিত পুরানো document সরান
- সহজ retrieval-এর জন্য folder ও tag দিয়ে document সংগঠিত করুন
- ব্যর্থ document পরীক্ষা করুন এবং প্রয়োজনে reprocess করুন
- Content update করতে পুরানো document delete করে নতুন version আপলোড করুন
- একসাথে একাধিক document folder-এ সরাতে bulk operation ব্যবহার করুন
- Agent-কে বিভ্রান্ত করা এড়াতে duplicate delete করুন

## সাধারণ প্রশ্ন

**প্রশ্ন: Document-এর content কীভাবে update করব?**
উত্তর: পুরানো document delete করে নতুন version আপলোড করুন। নতুন document স্বয়ংক্রিয়ভাবে process হবে।

**প্রশ্ন: Delete করা document কি পুনরুদ্ধার করা যায়?**
উত্তর: না, delete করা document স্থায়ীভাবে সরানো হয় এবং পুনরুদ্ধার করা যায় না। Delete করার আগে backup আছে কিনা নিশ্চিত করুন।

**প্রশ্ন: Document সফলভাবে process হয়েছে কিনা কীভাবে জানব?**
উত্তর: Processing status column পরীক্ষা করুন। সম্পন্ন হলে document **Ready** দেখায়, error হলে **Failed** দেখায়।

**প্রশ্ন: Document process ব্যর্থ হলে কী করব?**
উত্তর: Document menu-তে (⋮) click করে **Reprocess** নির্বাচন করুন। এই option শুধুমাত্র failed document-এ দেখা যায়। বারবার ব্যর্থ হলে file format ও size পরীক্ষা করুন।
