# Agent Knowledge Access

প্রশ্নের উত্তর দেওয়ার সময় প্রতিটি agent কোন document access করতে পারবে তা নিয়ন্ত্রণ করুন। নির্দিষ্ট folder বা tag-এ agent সীমাবদ্ধ করুন, বা নির্দিষ্ট content agent-এর নাগালের বাইরে রাখুন।

## কীভাবে যাবেন

1. Sidebar-এ **Agents**-এ navigate করুন
2. Edit করতে একটি agent-এ click করুন, বা নতুন agent তৈরি করুন
3. **Knowledge Access Control** section-এ scroll করুন

## Access Mode

Access mode নির্ধারণ করে আপনার নির্বাচন agent-এর document access-এ কীভাবে প্রভাব ফেলবে।

| Mode | Icon | বিবরণ | কখন ব্যবহার করবেন |
|------|------|-------|-------------------|
| **Exclude Mode** | Red X | নির্বাচিত ছাড়া agent সব document access করে | Sensitive document লুকিয়ে বাকি সব অনুমতি দিতে চাইলে |
| **Include Mode** | Green Check | Agent শুধুমাত্র নির্বাচিত document access করে | নির্দিষ্ট content-এ agent সীমাবদ্ধ করতে চাইলে |

### সঠিক Mode বেছে নেওয়া

**Exclude Mode** (default):
- সব document-এ সম্পূর্ণ access দিয়ে শুরু
- Agent থেকে block করতে folder/tag নির্বাচন করুন
- উপযুক্ত: HR document, financial data, বা draft লুকাতে

**Include Mode**:
- কোনো access ছাড়া শুরু
- Access দিতে folder/tag নির্বাচন করুন
- উপযুক্ত: নির্দিষ্ট বিষয়ের জন্য specialized agent তৈরি করতে

## Content নির্বাচন

### Folder অনুযায়ী

1. **Folders** tab-এ click করুন
2. Folder খুঁজতে search box ব্যবহার করুন
3. Include/exclude করতে folder check করুন
4. Individual document নির্বাচন করতে folder expand করুন (arrow click করুন)
5. নির্বাচিত item-এ checkmark দেখায়; আংশিক নির্বাচনে dash দেখায়

### Tag অনুযায়ী

1. **Tags** tab-এ click করুন
2. Tag খুঁজতে search box ব্যবহার করুন
3. Include/exclude করতে tag check করুন
4. প্রতিটি tag কতটি document ব্যবহার করে তা দেখায়

## Preview Panel

ডানদিকের preview panel দেখায়:
- বর্তমান নির্বাচনের ভিত্তিতে মোট accessible document
- আপনি পরিবর্তন করার সাথে সাথে real-time-এ update হয়

## পরিবর্তন Save করা

বিদ্যমান agent edit করার সময়:
1. আপনার নির্বাচন করুন
2. **Save Changes** (green button)-এ click করুন
3. অথবা unsaved পরিবর্তন undo করতে **Reset Changes**-এ click করুন

নতুন agent তৈরির সময়:
- Agent form submit করলে knowledge access setting স্বয়ংক্রিয়ভাবে save হয়

## পরামর্শ

- কিছু ব্যতিক্রম সহ বিস্তৃত access চাইলে **Exclude Mode** ব্যবহার করুন
- নির্দিষ্ট বিষয়ের agent-এর জন্য **Include Mode** ব্যবহার করুন
- সুনির্দিষ্ট নিয়ন্ত্রণের জন্য folder এবং tag একসাথে ব্যবহার করুন
- Save করার আগে নির্বাচন যাচাই করতে preview panel পরীক্ষা করুন
- Include Mode-এ অন্তত একটি folder বা tag নির্বাচন করতে হবে

## সাধারণ প্রশ্ন

**প্রশ্ন: Folder ও tag দুটোই নির্বাচন করলে কী হয়?**
উত্তর: Agent আপনার যেকোনো নির্বাচনের সাথে মেলে এমন document access করতে পারে। Folder ও tag inclusively combine হয়।

**প্রশ্ন: Agent-কে সবকিছুতে access দেওয়া যায়?**
উত্তর: হ্যাঁ। Exclude Mode ব্যবহার করুন এবং কিছু exclude নির্বাচন করবেন না। Agent সম্পূর্ণ access পাবে।

**প্রশ্ন: Document নির্বাচিত folder-এ আছে কিন্তু excluded tag আছে — তাহলে কী হয়?**
উত্তর: Exclude Mode-এ excluded content-এর সাথে যেকোনো মিল access block করে। Include Mode-এ included content-এর সাথে যেকোনো মিল access দেয়।

**প্রশ্ন: এটি কি বিদ্যমান conversation-এ প্রভাব ফেলে?**
উত্তর: হ্যাঁ। পরিবর্তন নতুন message-এর জন্য তৎক্ষণাৎ কার্যকর হয়। Agent updated access rule ব্যবহার করবে।
