# ব্যবহার পরিসংখ্যান

আপনার resource ব্যবহার এবং credit ব্যবহার ট্র্যাক করুন।

## Credit ব্যবহারের সংক্ষিপ্ত বিবরণ

Analytics dashboard আপনার বর্তমান billing cycle-এর ব্যবহার দেখায়:

- **Credits Used** — এই সময়ে ব্যবহৃত platform credit
- **Credits Remaining** — সময়সীমা শেষ পর্যন্ত পাওয়া যাবে এমন credit
- **Usage Percentage** — ব্যবহারের visual progress bar

## প্রধান পরিসংখ্যান

### Query Volume

| পরিসংখ্যান | বিবরণ |
|-------------|-------|
| Total Queries | এই সময়ে AI agent execution |
| Conversations | মোট chat session |
| Unique Users | যেসব user interact করেছে |

### বিতরণ বিশ্লেষণ

ব্যবহার কীভাবে বিতরণ হচ্ছে দেখুন:

- **Agent অনুযায়ী** — কোন agent সবচেয়ে বেশি query পরিচালনা করে
- **Channel অনুযায়ী** — Telegram, Discord, Slack, WhatsApp ইত্যাদি জুড়ে ব্যবহার

## ব্যবহারের প্রবণতা

### Query Volume Chart

প্রধান analytics dashboard একটি query volume chart দেখায় যেখানে রয়েছে:
- সময়ের সাথে query
- কনফিগারযোগ্য granularity (ঘণ্টা ভিত্তিক, দৈনিক, সাপ্তাহিক, মাসিক)
- Date range নির্বাচন

### Distribution Chart

Pie chart দেখায়:
- Channel distribution — প্রতি platform-এ query-এর শতকরা হার
- Agent distribution — প্রতি agent-এ query-এর শতকরা হার

## Credit পর্যবেক্ষণ

### বর্তমান সময়কাল

আপনার billing cycle-এর অবস্থা দেখুন:
- সময়কালের শুরু এবং শেষের তারিখ
- ব্যবহৃত credit বনাম বরাদ্দকৃত credit
- ব্যবহারের শতকরা হার

## ব্যবহারের সতর্কতা

**Billing** page-এ স্বয়ংক্রিয় সতর্কতা banner দেখায় যখন:

- **সীমার কাছাকাছি** — আপনি মাসিক quota-র বেশিরভাগ ব্যবহার করেছেন
- **সীমায় পৌঁছেছে** — মাসিক quota শেষ হয়ে গেছে
- **Blocked** — Extra usage balance-ও শেষ হয়ে গেছে

এই সতর্কতা **Billing ও Plans**-এ দেখা যায় যাতে service প্রভাবিত হওয়ার আগে আপনি পদক্ষেপ নিতে পারেন।

## অপটিমাইজেশন পরামর্শ

### Query ব্যবহার কমানো

- প্রথম response-এর সঠিকতা বাড়াতে agent persona উন্নত করুন
- Follow-up প্রশ্ন কমাতে FAQ content যোগ করুন
- দ্রুত retrieval-এর জন্য content অপটিমাইজ করুন

### বেশি ব্যবহারের ক্ষেত্র পর্যবেক্ষণ

- কোন agent সবচেয়ে বেশি credit ব্যবহার করে পরীক্ষা করুন
- সর্বোচ্চ volume-এর channel চিহ্নিত করুন
- বেশি token ব্যবহার করা কথোপকথন পর্যালোচনা করুন
