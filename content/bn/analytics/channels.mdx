# Channel বিশ্লেষণ

Channel অনুযায়ী কার্যকারিতা পরিসংখ্যান দেখুন। আপনার agent-রা যেসব platform-এ query গ্রহণ করে সেগুলো জুড়ে query volume, কথোপকথন, unique user এবং credit ব্যবহার তুলনা করুন।

## Channel বিশ্লেষণে প্রবেশ

1. সাইডবারে **Analytics**-এ navigate করুন
2. "Channel Distribution"-এর পাশে **View All**-এ click করুন, অথবা
3. সরাসরি **Analytics > Channels**-এ যান

## Navigation

Breadcrumb আপনার অবস্থান দেখায়: **Dashboard / Channels**। প্রধান analytics page-এ ফিরে যেতে "Dashboard"-এ click করুন।

## Date Range নিয়ন্ত্রণ

| নিয়ন্ত্রণ | বিবরণ |
|------------|-------|
| **Last 7 days** | গত সপ্তাহের পরিসংখ্যান দেখুন |
| **Last 14 days** | দুই সপ্তাহের পরিসংখ্যান দেখুন |
| **Last 30 days** | গত মাসের পরিসংখ্যান দেখুন |
| **Last 90 days** | গত তিন মাসের পরিসংখ্যান দেখুন |
| **Refresh** | সর্বশেষ মান দিয়ে data reload করুন |

## সারাংশ Card

সব channel জুড়ে সমষ্টিগত পরিসংখ্যান দেখানো চারটি card:

| Card | বিবরণ |
|------|-------|
| Total Channels | সক্রিয় channel-এর সংখ্যা |
| Total Queries | সব channel জুড়ে query-এর যোগফল |
| Total Conversations | সব channel জুড়ে কথোপকথনের যোগফল |
| Total Credits | সব channel জুড়ে ব্যবহৃত credit-এর যোগফল |

## Channel টেবিল

কার্যকারিতা পরিসংখ্যানসহ আপনার সব সক্রিয় channel-এর তালিকা:

| কলাম | বিবরণ |
|------|-------|
| Channel | রঙ-কোডেড badge সহ channel-এর নাম |
| Queries | এই channel-এ মোট উত্তরিত প্রশ্ন |
| Conversations | এই channel-এর chat session |
| Unique Users | এই channel-এর মাধ্যমে interact করা স্বতন্ত্র user |
| Credits | এই channel-এ ব্যবহৃত resource |
| % of Total | মোট query-তে এই channel-এর অংশ দেখানো visual progress bar |
| (Arrow) | বিস্তারিত channel view-এর link |

## Channel-এর ধরন

আপনার agent বিভিন্ন platform থেকে query গ্রহণ করতে পারে:

| Channel | বিবরণ |
|---------|-------|
| Web | Embeddable web chat surface থেকে query |
| Widget | Website chat widget থেকে query |
| Telegram | Telegram bot integration |
| Discord | Discord bot integration |
| Slack | Slack app integration |
| Meta | Meta/Messenger integration |
| WhatsApp | WhatsApp Business integration |
| Google Chat | Google Chat (Workspace) integration |
| OpenAI Apps | OpenAI Apps SDK থেকে কথোপকথন |
| Playground | Agent testing interface থেকে query |
| API | আপনার agent-এ সরাসরি API call |

## Channel-এর বিস্তারিত দেখা

যেকোনো channel row-তে arrow-এ click করে দেখুন:
- সেই নির্দিষ্ট channel-এর বিস্তারিত পরিসংখ্যান
- Granularity option সহ time-series chart (ঘণ্টা ভিত্তিক, দৈনিক, সাপ্তাহিক, মাসিক)
- সেই channel-এর মধ্যে agent breakdown

## পরামর্শ

- কোন channel সবচেয়ে বেশি traffic আনছে বুঝতে **% of Total** তুলনা করুন
- মনোযোগ প্রয়োজন এমন কম কার্যকর channel চিহ্নিত করতে এই view ব্যবহার করুন
- প্রতি platform-এ audience reach বুঝতে **Unique Users** পরীক্ষা করুন
- Channel অনুযায়ী resource ব্যবহার দেখতে **Credits** পর্যালোচনা করুন

## সাধারণ প্রশ্ন

**প্রশ্ন: সব channel কেন তালিকায় দেখা যাচ্ছে না?**

শুধুমাত্র নির্বাচিত সময়সীমায় কমপক্ষে একটি query আছে এমন channel টেবিলে দেখা যায়।

**প্রশ্ন: শতকরা হার কীভাবে গণনা করা হয়?**

শতকরা হার নির্বাচিত সময়সীমায় সব channel জুড়ে মোট query-তে প্রতিটি channel-এর অংশ দেখায়।

**প্রশ্ন: সময়ের সাথে channel তুলনা করা যায়?**

একটি নির্দিষ্ট channel-এ click করে তার time-series data এবং trend দেখুন।
