# Agent বিশ্লেষণ

আপনার সব agent-এর বিস্তারিত কার্যকারিতা পরিসংখ্যান দেখুন। আপনার সম্পূর্ণ agent portfolio জুড়ে query volume, কথোপকথন এবং credit ব্যবহার তুলনা করুন।

## Agent বিশ্লেষণে প্রবেশ

1. সাইডবারে **Analytics**-এ navigate করুন
2. "Top Agents"-এর পাশে **View All**-এ click করুন, অথবা
3. সরাসরি **Analytics > Agents**-এ যান

## Navigation

Breadcrumb আপনার অবস্থান দেখায়: **Dashboard / Agents**। প্রধান analytics page-এ ফিরে যেতে "Dashboard"-এ click করুন।

## Date Range নিয়ন্ত্রণ

| নিয়ন্ত্রণ | বিবরণ |
|------------|-------|
| **Last 7 days** | গত সপ্তাহের পরিসংখ্যান দেখুন |
| **Last 14 days** | দুই সপ্তাহের পরিসংখ্যান দেখুন |
| **Last 30 days** | গত মাসের পরিসংখ্যান দেখুন |
| **Last 90 days** | গত তিন মাসের পরিসংখ্যান দেখুন |
| **Refresh** | সর্বশেষ মান দিয়ে data reload করুন |

## Agent টেবিল

কার্যকারিতা পরিসংখ্যানসহ আপনার সব agent-এর তালিকা:

| কলাম | বিবরণ | সাজানো যায় |
|------|-------|------------|
| Agent | Agent-এর নাম | না |
| Status | active, inactive, testing, বা archived | না |
| Queries | মোট উত্তরিত প্রশ্ন | হ্যাঁ |
| Conversations | Chat session | হ্যাঁ |
| Credits | ব্যবহৃত resource | হ্যাঁ |
| Channels | Agent কোন channel-এ ব্যবহৃত হচ্ছে | না |
| (Arrow) | বিস্তারিত দেখার link | না |

### সাজানো

যেকোনো sortable column header-এ click করে সেই পরিসংখ্যান অনুযায়ী সাজান:
- **প্রথম click**: নিম্নক্রমে সাজান (সর্বোচ্চ প্রথমে)
- **দ্বিতীয় click**: ঊর্ধ্বক্রমে সাজান (সর্বনিম্ন প্রথমে)
- সক্রিয় sort column হাইলাইট করা থাকে

### Pagination

বড় agent তালিকার জন্য:
- "Showing X - Y of Z" দেখায়
- Page navigate করতে **Previous/Next** button ব্যবহার করুন

## Agent Status Badge

| Badge | রঙ | অর্থ |
|-------|-----|------|
| active | সবুজ | Agent deploy করা আছে এবং query গ্রহণ করছে |
| inactive | ধূসর | Agent বিরতিতে আছে |
| testing | হলুদ | Deploy-এর আগে agent test করা হচ্ছে |
| archived | হলুদ | Agent archive করা হয়েছে |

## Channel Badge

Channels column দেখায় প্রতিটি agent কোন platform-এ ব্যবহৃত হচ্ছে:
- সর্বোচ্চ ৩টি channel badge দেখানো হয় (যেমন, "web", "telegram", "discord")
- ৩-এর বেশি হলে অতিরিক্ত channel বোঝাতে "+X" দেখায়

## Agent-এর বিস্তারিত দেখা

যেকোনো agent row-তে arrow-এ click করে দেখুন:
- সেই নির্দিষ্ট agent-এর বিস্তারিত পরিসংখ্যান
- Time-series chart
- Channel breakdown
- আরো বিস্তারিত data

## পরামর্শ

- সবচেয়ে বেশি resource ব্যবহারকারী agent খুঁজতে **Credits** অনুযায়ী সাজান
- সবচেয়ে জনপ্রিয় agent চিহ্নিত করতে **Queries** অনুযায়ী সাজান
- দীর্ঘমেয়াদী trend বিশ্লেষণের জন্য **90 days** ব্যবহার করুন
- Inactive agent পরীক্ষা করুন — পুনরায় সক্রিয় করা উচিত কিনা দেখুন
- গভীর insight-এর জন্য পৃথক agent-এ click করুন

## সাধারণ প্রশ্ন

**প্রশ্ন: সবচেয়ে বেশি ব্যবহৃত agent কীভাবে খুঁজবো?**

Query count অনুযায়ী সাজাতে "Queries" column header-এ click করুন। শীর্ষ row-ই আপনার সবচেয়ে সক্রিয় agent।

**প্রশ্ন: Channel badge-গুলো কী বোঝায়?**

এগুলো দেখায় প্রতিটি agent কোন platform (Web, Telegram, Discord, Slack, ইত্যাদি) থেকে query গ্রহণ করে।

**প্রশ্ন: একটি agent কেন শূন্য query দেখাচ্ছে?**

Agent-টি নতুন হতে পারে, inactive হতে পারে, অথবা এখনো কোনো channel-এ deploy করা হয়নি।
