# কথোপকথন বিশ্লেষণ

আপনার agent এবং channel জুড়ে কথোপকথনের পরিসংখ্যান ট্র্যাক করুন এবং বিস্তারিত transcript দেখুন।

## সংক্ষিপ্ত বিবরণ

কথোপকথন বিশ্লেষণ প্রদান করে:

- মোট কথোপকথনের পরিমাণ
- প্রতি agent-এ কথোপকথন
- প্রতি channel-এ কথোপকথন
- সম্পূর্ণ message transcript
- AI-চালিত কথোপকথন insight

## কথোপকথনে প্রবেশ

### Dashboard থেকে

1. সাইডবারে **Analytics**-এ যান
2. Top Agents বা Top Channels card-এ **View All**-এ click করুন
3. অথবা সরাসরি analytics menu থেকে Conversations-এ navigate করুন

### কথোপকথন তালিকা

সব কথোপকথন দেখুন:

| কলাম | বিবরণ |
|------|-------|
| Title | কথোপকথনের শিরোনাম বা session ID |
| Agent | কোন agent কথোপকথন পরিচালনা করেছে |
| Channel | Platform (Telegram, Discord, Slack, ইত্যাদি) |
| Messages | মোট message সংখ্যা |
| Last Active | কথোপকথন সর্বশেষ কখন আপডেট হয়েছে |
| Status | Active, archived, বা deleted |

## কথোপকথন ফিল্টার করা

কথোপকথন তালিকা ফিল্টার করুন:

- **Agent** — একটি নির্দিষ্ট agent বা সব agent নির্বাচন করুন
- **Channel** — Platform অনুযায়ী ফিল্টার করুন (WhatsApp, Telegram, Meta, Slack, Discord, Google Chat, Playground)
- **Date range** — গত ৭, ১৪, ৩০, বা ৯০ দিন

## কথোপকথনের বিস্তারিত

যেকোনো কথোপকথনে click করে সম্পূর্ণ বিবরণ দেখুন:

### Overview Tab

- **Total Messages** — কথোপকথনে message সংখ্যা
- **Credits Spent** — ব্যবহৃত platform credit
- **Agent** — কোন agent কথোপকথন পরিচালনা করেছে
- **Channel** — যে platform-এ হয়েছে
- **Created** — কথোপকথন কখন শুরু হয়েছে
- **Last Active** — সর্বশেষ কার্যকলাপ

### Message Activity Chart

সময়ের সাথে message pattern দেখুন:
- ঘণ্টা ভিত্তিক এবং দৈনিক granularity-র মধ্যে toggle করুন
- User message এবং assistant message দেখান/লুকান
- কথোপকথনের কার্যকলাপ pattern দেখুন

### Messages Tab

সম্পূর্ণ কথোপকথন transcript দেখুন:

- **সম্পূর্ণ message history** — কথোপকথনের প্রতিটি message দেখুন
- **Role indicator** — User, Assistant, System, এবং Tool message রঙ-কোডেড
- **Timestamp** — প্রতিটি message কখন পাঠানো হয়েছে
- **Token usage** — প্রতি message-এ input/output token (যখন পাওয়া যায়)

#### Message ফিল্টারিং

সময়সীমা অনুযায়ী message ফিল্টার করুন:
- গত ২৪ ঘণ্টা
- গত ৭ দিন
- গত ৩০ দিন
- সব message

#### Export

কথোপকথন JSON file হিসেবে download করতে **Export**-এ click করুন যাতে থাকবে:
- কথোপকথনের metadata
- Timestamp সহ সব message
- Token তথ্য

## AI-চালিত Insight

কথোপকথনের intelligent সারাংশ তৈরি করুন:

1. একটি কথোপকথনের **Messages** tab-এ navigate করুন
2. **Generate Insights**-এ click করুন
3. AI-বিশ্লেষিত insight দেখুন যার মধ্যে রয়েছে:
   - **Key Points** — আলোচিত মূল বিষয়
   - **User Intents** — User কী অর্জন করতে চেয়েছিলেন
   - **Key Info Shared** — বিনিময় করা গুরুত্বপূর্ণ তথ্য
   - **Suggested Actions** — কথোপকথনের ভিত্তিতে সুপারিশ

## গোপনীয়তা বিবেচনা

কথোপকথনের data পরিচালনা করা হয়:

- গোপনীয়তা নীতির প্রয়োজনীয়তা অনুযায়ী
- প্রযোজ্য ক্ষেত্রে user-এর সম্মতি অনুযায়ী

## পরামর্শ

- নির্দিষ্ট agent বা channel থেকে কথোপকথন খুঁজতে filter ব্যবহার করুন
- রেকর্ড রাখা বা বিশ্লেষণের জন্য গুরুত্বপূর্ণ কথোপকথন export করুন
- দীর্ঘ কথোপকথন দ্রুত বুঝতে AI insight তৈরি করুন
- Peak ব্যবহারের সময় চিহ্নিত করতে Message Activity chart পরীক্ষা করুন
- আপনার agent-এর persona উন্নত করতে কথোপকথন transcript পর্যালোচনা করুন
- ব্যবহারের pattern ট্র্যাক করতে ব্যয়িত credit পর্যবেক্ষণ করুন

## সাধারণ প্রশ্ন

**প্রশ্ন: নির্দিষ্ট channel থেকে কথোপকথন কীভাবে খুঁজবো?**

কথোপকথন তালিকার উপরে Channel filter ব্যবহার করে Telegram, Discord, বা Slack-এর মতো নির্দিষ্ট platform নির্বাচন করুন।

**প্রশ্ন: একসাথে একাধিক কথোপকথন export করা যায়?**

বর্তমানে export একবারে একটি কথোপকথনের জন্য কাজ করে। Messages tab থেকে প্রতিটি কথোপকথন আলাদাভাবে export করুন।

**প্রশ্ন: "Generate Insights" কী করে?**

এটি AI ব্যবহার করে কথোপকথন বিশ্লেষণ করে এবং key point, user intent, বিনিময় করা গুরুত্বপূর্ণ তথ্য এবং সুপারিশকৃত পদক্ষেপসহ একটি সারাংশ প্রদান করে।

**প্রশ্ন: AI insight-এ কি credit খরচ হয়?**

হ্যাঁ, insight তৈরি করলে আপনার account থেকে credit খরচ হয়। তবে result cache করা থাকে তাই একই insight আবার দেখা বিনামূল্যে।

**প্রশ্ন: কথোপকথন কতদিন সংরক্ষিত থাকে?**

কথোপকথন নিরাপদভাবে সংরক্ষিত থাকে এবং বিশ্লেষণের জন্য পাওয়া যায়। Data সংরক্ষণ সম্পর্কে প্রশ্ন থাকলে support-এ যোগাযোগ করুন।
