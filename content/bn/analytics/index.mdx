# বিশ্লেষণ

আপনার agent-গুলোর কার্যকারিতা পর্যবেক্ষণ করুন এবং user-রা আপনার chatbot-এর সাথে কীভাবে interact করে তা বুঝুন।

## সংক্ষিপ্ত বিবরণ

বিশ্লেষণ আপনাকে সাহায্য করে:
- কথোপকথনের পরিমাণ এবং query pattern ট্র্যাক করতে
- Agent-এর কার্যকারিতা এবং credit ব্যবহার পর্যবেক্ষণ করতে
- Channel বিতরণ বুঝতে
- উন্নতির ক্ষেত্র চিহ্নিত করতে

## Dashboard

সাইডবারে **Analytics** বিভাগ থেকে বিশ্লেষণে প্রবেশ করুন।

### প্রধান পরিসংখ্যান

| পরিসংখ্যান | বিবরণ |
|-------------|-------|
| Total Queries | Agent execution (AI response) |
| Conversations | Chat session-এর সংখ্যা |
| Unique Users | যেসব user chat করেছে |
| Credits Used | ব্যবহৃত platform credit |

### Credit ব্যবহার

Dashboard আপনার বর্তমান billing cycle-এর credit ব্যবহার দেখায়:
- ব্যবহৃত credit বনাম বরাদ্দকৃত credit
- শতকরা progress bar
- এই সময়ের জন্য অবশিষ্ট credit

### চার্ট

Dashboard-এ visual chart অন্তর্ভুক্ত রয়েছে:
- **Query Volume** — সময়ের সাথে query দেখানো line chart
- **Channel Distribution** — Channel অনুযায়ী query-এর pie chart
- **Agent Distribution** — Agent অনুযায়ী query-এর pie chart

### শীর্ষ Agent সমূহ

আপনার সবচেয়ে সক্রিয় agent-গুলোর ranked তালিকা যেখানে দেখানো হয়:
- Agent-এর নাম এবং rank
- মোট query পরিচালিত
- কথোপকথনের সংখ্যা
- ব্যবহৃত credit
- বর্তমান অবস্থা (active, inactive, testing, archived)

বিস্তারিত বিশ্লেষণ দেখতে যেকোনো agent-এ click করুন, অথবা সব agent দেখতে **View All**-এ click করুন।

### শীর্ষ Channel সমূহ

আপনার সবচেয়ে সক্রিয় communication channel-গুলোর ranked তালিকা যেখানে দেখানো হয়:
- Channel-এর নাম এবং rank
- মোট query পরিচালিত
- কথোপকথনের সংখ্যা
- ব্যবহৃত credit

বিস্তারিত বিশ্লেষণ দেখতে যেকোনো channel-এ click করুন, অথবা সব channel দেখতে **View All**-এ click করুন।

## ফিল্টারিং

বিশ্লেষণ ফিল্টার করুন:
- **Agent** — নির্দিষ্ট agent-এর পরিসংখ্যান দেখুন
- **Channel** — বিভিন্ন platform জুড়ে কার্যকারিতা তুলনা করুন
- **Date range** — নির্দিষ্ট সময়সীমা বিশ্লেষণ করুন

## বিশ্লেষণ ব্যবহার

### প্যাটার্ন চিহ্নিত করুন

কোন channel এবং agent সবচেয়ে বেশি query পরিচালনা করে দেখুন:
- Resource বরাদ্দ অপটিমাইজ করুন
- যেখানে প্রয়োজন সেখানে উন্নতিতে মনোযোগ দিন
- User-দের পছন্দ বুঝুন

### কার্যকারিতা পর্যবেক্ষণ করুন

Trend ট্র্যাক করুন যাতে নিশ্চিত করা যায়:
- Credit ব্যবহার সীমার মধ্যে থাকছে
- User engagement সুস্থ আছে
- অস্বাভাবিক কোনো pattern নেই

### Agent অপটিমাইজ করুন

Insight ব্যবহার করুন:
- Agent persona সমন্বয় করুন
- অনুপস্থিত documentation যোগ করুন
- Response-এর সঠিকতা উন্নত করুন
