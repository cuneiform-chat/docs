# Shopify

**Shopify App Store থেকে একবার install করুন, আপনার workspace-এর সাথে যুক্ত করুন, আর আপনার agent-রা আপনার store-এর catalog, order ও inventory থেকে উত্তর দিতে শুরু করবে।** তৈরি করার মতো কোনো API key নেই, configure করার মতো কোনো redirect URL নেই, install করার মতো কোনো plugin নেই।

## আপনি যা পান [#what-you-get]

আপনার store যুক্ত হয়ে গেলে আপনার store agent পারে:

- **Catalog সংক্রান্ত প্রশ্নের উত্তর দিতে** আপনার আসল product, variant, option ও দাম থেকে
- **আপনার sync করা catalog থেকে stock ও দাম পড়তে**, যা webhook দিয়ে হালনাগাদ রাখা হয়, তাই আপনি সদ্য যা ফুরিয়ে ফেলেছেন সে তা সাধতে বসে না
- **স্টকে থাকা product সুপারিশ করতে**, তার মনে থাকা যা-কিছু নয়
- **Order খুঁজে দিতে** সেই ক্রেতাদের জন্য যারা order-টি নিজের বলে প্রমাণ করতে পারে
- **Order-status আপডেট পাঠাতে** সেই ক্রেতাদের যারা opt-in করে, একই chat-এ
- **কিনতে প্রস্তুত ক্রেতাকে পুরো cart অক্ষত রেখে আপনার Shopify checkout-এ পাঠাতে**

## পূর্বশর্ত [#prerequisites]

- একটি **Shopify store** যা আপনি পরিচালনা করেন
- একটি Cuneiform Chat workspace, এবং তাতে একটি **Owner বা Admin** অ্যাকাউন্ট — একটি store যুক্ত করা একটি admin কাজ
- অন্তত একটি agent, অথবা নতুন একটি তৈরি করার মতো জায়গা (দেখুন [আপনার store agent](/commerce#your-store-agent))

## যুক্ত হওয়া যেভাবে কাজ করে [#how-connecting-works]

Shopify যুক্ত করা দুই ধাপের একটি handshake: Shopify app-টি install করে, তারপর **আপনি** সেই install করা app-কে আপনার Cuneiform Chat workspace-এর সাথে যুক্ত করেন। Shopify জানে আপনি কোন store; কেবল আপনিই জানেন সেটি কোন workspace-এর।

### ১. Shopify App Store থেকে install করুন [#1-install-from-the-shopify-app-store]

Shopify App Store-এ **Cuneiform Chat - AI Commerce** খুঁজে নিয়ে install করুন। Shopify নিজেই installation সামলায় এবং নিচের permission-গুলো অনুমোদন করতে বলে। এই পর্যায়ে আমাদের দিকের কিছুই জড়িত নয়।

### ২. আপনার Shopify admin-এ app-টি খুলুন [#2-open-the-app-in-your-shopify-admin]

App-টি একটি embedded app হিসেবে **`admin.shopify.com`-এর ভেতরে** খোলে। integration-এর জন্য এটিই আপনার Shopify-দিকের ঘর — setup, সংযোগের অবস্থা, configuration, একটি dashboard ও billing সবই এখানে।

### ৩. "Link your workspace" ক্লিক করুন [#3-click-link-your-workspace]

store যুক্ত না হওয়া পর্যন্ত embedded app একটি **"Link your workspace"** banner দেখায়। সেটিতে ক্লিক করলে Cuneiform Chat খোলে একটি **নতুন top-level browser tab**-এ, Shopify frame-এর ভেতরে নয়। এটি ইচ্ছাকৃত: অন্য একটি সাইটের iframe-এর ভেতরে sign in করা যায় না, তাই যুক্ত হওয়ার ধাপটিকে বেরিয়ে আসতে হয়।

### ৪. সংযোগটি অনুমোদন করুন [#4-approve-the-link]

আপনি Cuneiform Chat-এর claim পাতায় পৌঁছান, আপনার store আগে থেকেই শনাক্ত করা অবস্থায়। নিশ্চিত করুন, আর store-টি আপনার workspace-এর সাথে যুক্ত হয়ে যাবে। আপনাকে **Commerce**-এ পাঠানো হয়, আর প্রথম catalog sync শুরু হয়।

সেই পাতায় আপনি যা দেখতে পারেন:

| আপনি যা দেখেন | এর মানে কী |
|---|---|
| **Sign-in prompt** | আপনি sign in করা ছিলেন না। sign in করুন, সংযোগটি যেখানে থেমেছিল সেখান থেকে চলবে। |
| **Confirm the link** | আপনি একজন Owner বা Admin — এটিই স্বাভাবিক পথ। |
| **Ask an admin to finish this** | আপনি একজন Member। Member-রা integration যুক্ত করতে পারে না; লিঙ্কটি একজন Owner বা Admin-কে পাঠান। |
| **Store linked** | হয়ে গেছে। catalog sync ইতিমধ্যেই চলছে। |
| **This connection link expired** | সংযোগের টিকিটটি বাসি হয়ে গেছে, আগেই ব্যবহৃত হয়েছে, বা আর চেনা যাচ্ছে না। আপনার Shopify admin-এ app-এ ফিরে গিয়ে আবার **Link your workspace** ক্লিক করুন। |
| **This store is connected elsewhere** | store-টি অন্য একটি workspace-এর সাথে আগেই যুক্ত। আগে সেখান থেকে disconnect করুন। |
| **This workspace already has a store** | প্রতি workspace-এ একটি Shopify store। নতুন একটি যুক্ত করার আগে বর্তমানটি disconnect করুন। |
| **Couldn't connect your store** | আমাদের দিকে কিছু একটা ভুল হয়েছে। একটি **Try again** বোতাম সেখানেই আবার চেষ্টা করে — Shopify থেকে নতুন করে শুরু করার দরকার নেই। |
| **We couldn't complete the connection** | সংযোগটি আমাদের কাছে পৌঁছানোর আগেই ব্যর্থ হয়েছে। আপনার Shopify admin-এ app-টি আবার খুলে সংযোগটি নতুন করে শুরু করুন। |

## আমরা যেসব permission চাই [#permissions-we-ask-for]

Cuneiform Chat **পাঁচটি read-only permission** চায়। সেটে কোনো write permission নেই — app আপনার store-এ কিছুই বদলাতে পারে না।

| Permission | কেন আমাদের দরকার |
|---|---|
| `read_products` | আপনার catalog পড়া: product, variant, option, দাম, ছবি |
| `read_inventory` | Stock লেভেল পড়া যাতে agent কেবল যা পাওয়া যায় তা-ই সুপারিশ করে |
| `read_orders` | একজন ক্রেতার order খুঁজে দেওয়া ও তাকে status আপডেট পাঠানো |
| `read_fulfillments` | সেই order-গুলোর shipping অগ্রগতি জানানো |
| `read_customers` | ক্রেতা যে order-এর কথা জিজ্ঞাসা করছে তার সাথে তার ফোন নম্বর মেলানো |

<Callout type="info">
  **Read-only মানে read-only।** app product তৈরি, সম্পাদনা বা মুছতে পারে না; inventory বদলাতে পারে না; order তৈরি, সম্পাদনা বা বাতিল করতে পারে না; এবং পেমেন্ট নিতে পারে না। প্রতিটি কেনাকাটা আপনার নিজের Shopify checkout-এ সম্পন্ন হয়।
</Callout>

## প্রতি workspace-এ একটি store [#one-store-per-workspace]

একটি workspace **একটি Shopify store** যুক্ত করে। একই সাথে এটি একটি WooCommerce store-ও যুক্ত করতে পারে — দেখুন [Commerce](/commerce#you-can-connect-both-at-once)।

কেউ যদি এমন একটি store যুক্ত করতে চায় যা আগেই অন্য একটি workspace-এর সাথে যুক্ত, তাহলে চেষ্টাটি প্রত্যাখ্যান করা হয়, নীরবে দখল করে নেওয়া হয় না।

## কোনো "Reconnect" বোতাম নেই [#there-is-no-reconnect-button]

Shopify-তে reconnect ধাপ নেই, আর আপনার সেটি খুঁজতেও যাওয়া উচিত নয়। Permission পরিবর্তন app-এর সাথেই আসে: app-এর permission সেট বদলালে Shopify পরের বার app খোলার সময় আপনাকে সেই পরিবর্তন অনুমোদন করতে বলে। হাতে করে পুনরায় অনুমোদন করার কিছু নেই।

<Callout type="warning">
  Shopify ও WooCommerce-এর পথ দুটির মূল পার্থক্য এখানেই। WooCommerce-এ একটি **Reconnect** বোতাম **আছে**, কারণ একটি সেল্ফ-হোস্টেড store-এর API key তার ভেতর থেকেই বাতিল করা যায়। Shopify-এরটি যায় না।
</Callout>

## যুক্ত হওয়ার পরে [#after-you-connect]

- **আপনার catalog সাথে সাথেই sync হতে শুরু করে।** sync কী কী নেয় ও কীভাবে হালনাগাদ থাকে তার জন্য দেখুন [Catalog ও Knowledge](/commerce/catalog-and-knowledge)।
- **একটি agent আপনার store agent হয়ে যায়**, যুক্ত হওয়ার সময় আপনার হয়ে বেছে নেওয়া। দেখুন [আপনার store agent](/commerce#your-store-agent)।
- **Order-status আপডেট আপনি চালু না করা পর্যন্ত বন্ধ থাকে।** দেখুন [Order](/commerce/orders#order-status-updates)।

## সমস্যা সমাধান [#troubleshooting]

### "Link your workspace" banner যাচ্ছে না [#the-link-your-workspace-banner-wont-go-away]

সংযোগটি সম্পন্ন হয়নি। আবার ক্লিক করুন — এটি একটি নতুন tab-এ একটি নতুন সংযোগ-টিকিট খোলে। খোলার সাথে সাথেই যদি বলে যে লিঙ্কের মেয়াদ শেষ, তার মানে টিকিটটি অব্যবহৃত অবস্থায় বেশিক্ষণ পড়ে ছিল; আবার শুরু করুন।

### লিঙ্ক খুলল কিন্তু কিছুই হলো না [#the-link-opened-but-nothing-happened]

সংযোগের ধাপটিকে একটি **top-level tab**-এ খুলতে হয়, Shopify frame-এর ভেতরে নয়। আপনার browser নতুন tab আটকে দিলে `admin.shopify.com`-এর জন্য pop-up অনুমোদন করে আবার চেষ্টা করুন।

### "This store is connected elsewhere" [#this-store-is-connected-elsewhere]

store-টি অন্য একটি Cuneiform Chat workspace-এর সাথে যুক্ত — প্রায়ই আগে তৈরি করা কোনো trial workspace। সেই workspace-এ sign in করে সেখান থেকে store-টি disconnect করুন, তারপর এখানে যুক্ত করুন।

### একজন Member সংযোগটি শেষ করতে পারছে না [#a-member-cant-finish-the-link]

একটি store যুক্ত করতে **Integration connect** permission লাগে, যা Owner ও Admin-দের আছে এবং Member-দের নেই। লিঙ্কটি একজন Owner বা Admin-কে ফরোয়ার্ড করুন।

### যুক্ত হওয়ার ঠিক পরেই catalog খালি [#the-catalog-is-empty-right-after-linking]

প্রথম import পুরো catalog ভরে দেয় এবং বড় store-এ কয়েক মিনিট লাগে। এরপরও খালি দেখালে **Commerce → Shopify → Catalog & Data** থেকে **Re-sync now** চালান। catalog যতক্ষণ খালি থাকে, Overview ট্যাবের চেকলিস্টও এক ক্লিকে একটি **Sync now** দেয়।

### agent product-এর প্রশ্নের উত্তর দিচ্ছে না [#the-agent-isnt-answering-product-questions]

দেখে নিন আপনি **store agent**-এর সাথেই কথা বলছেন কি না — যেটিকে যুক্ত হওয়ার সময় store-এর সাথে জোড়া হয়েছিল। তার agent পাতায় একটি read-only প্যানেল থাকে যাতে লেখা থাকে এটি আপনার store দ্বারা পরিচালিত। অন্য agent-রা commerce টুল বহন করে না।

## Disconnect করা [#disconnecting]

**Commerce → Shopify → Disconnect** থেকে disconnect করুন। Disconnect করলে:

- সংরক্ষিত সংযোগ ও sync করা catalog মুছে যায়
- সেই catalog থেকে তৈরি product knowledge মুছে যায়, তাই agent-রা সেখান থেকে উত্তর দেওয়া বন্ধ করে
- store agent-এর commerce বরাদ্দ রিসেট হয়, আপনি কখনো সম্পাদনা না করে থাকলে তার commerce persona ফিরিয়ে দেওয়া হয়, আর **agent-টি নিজেই আর্কাইভ হয়ে যায়** — একই store আবার যুক্ত করলে সেটিকে তার tuning ও version ইতিহাস অক্ষত রেখেই ফিরিয়ে নেওয়া হয়
- **সেই store-এর সাথে বাঁধা যেকোনো Storefront স্থায়ীভাবে মুছে যায়**, তার analytics ইতিহাসসহ। আপনার হাতে তৈরি Storefront-গুলো অক্ষত থাকে
- store-এর সাথে আসা commerce Agent Flows আর্কাইভ হয়
- AI quiz suggestion একেবারে মুছে ফেলা হয়, তাই ভবিষ্যতে আবার যুক্ত হলে সেটি একেবারে পরিষ্কার অবস্থা থেকে শুরু করে

<Callout type="warning">
  আপনার যদি এখনো একটি **WooCommerce** store যুক্ত থাকে, তাহলে কেবল workspace-জুড়ে প্রযোজ্য ধাপগুলোই — commerce Agent Flows আর্কাইভ করা ও quiz suggestion মুছে ফেলা — বাদ দেওয়া হয়। Shopify store-এর নিজের catalog, product knowledge, Storefront, analytics ও store agent সবসময়ই ভেঙে ফেলা হয়।
</Callout>

আপনার Shopify admin থেকে app-টি uninstall করলে Shopify-এর দিকের সম্পর্কও শেষ হয়ে যায়।
