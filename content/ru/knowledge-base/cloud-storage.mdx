# Интеграция с облачным хранилищем

import { Callout } from 'nextra/components'

Импортируйте документы напрямую из ваших облачных хранилищ. Подключите Google Drive, Dropbox, OneDrive или Box, чтобы добавлять файлы в ваш Контент без предварительного скачивания.

## Как перейти

Откройте **Content** на боковой панели. Значки облачных хранилищ расположены в верхней части страницы, рядом с зоной загрузки файлов.

## Поддерживаемые провайдеры

| Провайдер | Расположение значка | Что можно импортировать |
|-----------|---------------------|------------------------|
| Google Drive | Ряд облачных значков | Файлы, Google Docs, Slides |
| Dropbox | Ряд облачных значков | Файлы из вашего Dropbox |
| OneDrive | Ряд облачных значков | Файлы из вашего OneDrive |
| Box | Ряд облачных значков | Файлы из вашего аккаунта Box |

## Как импортировать файлы

### Шаг 1: Нажмите на значок провайдера

Нажмите на значок вашего облачного хранилища. При наведении появится всплывающая подсказка с названием провайдера.

### Шаг 2: Войдите в аккаунт

Вам будет предложено войти в аккаунт и предоставить доступ. Авторизация сохраняется на время сессии браузера.

### Шаг 3: Выберите файлы

Откроется файловый менеджер с содержимым вашего облачного хранилища:
- Переходите по папкам для поиска файлов
- Выбирайте несколько файлов одновременно
- Отображаются только поддерживаемые типы файлов (в зависимости от вашего тарифа)

### Шаг 4: Импорт

Нажмите для подтверждения выбора. Файлы будут поставлены в очередь на импорт, и обработка начнётся автоматически.

## Параметры импорта

Перед импортом вы можете настроить:

| Параметр | Описание |
|----------|----------|
| Premium Processing | Включите для улучшенного распознавания ИИ (флажок под зоной загрузки) |
| Target Folder | Загружайте файлы напрямую в папку, нажав на значок провайдера в строке папки |

## Импорт в определённую папку

Вы можете импортировать облачные файлы напрямую в папку:

1. Найдите папку в обозревателе документов
2. Наведите курсор на строку папки
3. Нажмите на появившийся значок облачного хранилища
4. Выберите файлы из вашего облачного хранилища
5. Файлы будут импортированы напрямую в эту папку

## Во время импорта

- Индикатор прогресса показывает статус импорта
- Файлы появляются в списке документов по мере обработки
- Вы можете продолжать работу во время импорта файлов
- При обнаружении дубликатов вы получите уведомление после завершения импорта

## Файлы Google Workspace

Google Drive поддерживает встроенные документы Google Workspace:
- **Google Docs** — автоматически конвертируются в текст
- **Google Slides** — автоматически конвертируются в формат презентации

<Callout type="info">
  Форматирование и диаграммы не сохраняются — извлекается только текстовое содержимое.
</Callout>

## Разрешения

Cuneiform Chat запрашивает минимальные разрешения:
- Доступ на чтение только выбранных файлов
- Без доступа на запись в ваше облачное хранилище
- Без доступа к файлам, которые вы явно не выбрали

<Callout type="info">
  Вы можете отозвать доступ в любое время через настройки вашего облачного провайдера.
</Callout>

## Поведение синхронизации

В настоящее время облачный импорт выполняется **однократно**:
- Файлы копируются на момент импорта
- Изменения в облачном хранилище не синхронизируются автоматически
- Для обновления контента повторно импортируйте изменённые файлы

## Советы

- Выбирайте несколько файлов одновременно для экономии времени
- В файловом менеджере отображаются только поддерживаемые типы файлов (в зависимости от вашего тарифа)
- Используйте импорт на уровне папки для лучшей организации
- Обработка больших файлов после импорта может занять больше времени

## Частые вопросы

**В: Нужно ли повторно авторизоваться каждый раз?**
О: Обычно нет. Если ваша сессия активна, нажатие на значок сразу открывает файловый менеджер. Повторная авторизация может потребоваться после очистки данных браузера или при использовании нового браузера.

**В: Можно ли импортировать целые папки?**
О: В настоящее время вы выбираете отдельные файлы. Переходите в папки в файловом менеджере, чтобы выбрать файлы внутри них.

**В: Что произойдёт с моими оригинальными файлами?**
О: Ваши облачные файлы останутся без изменений. Мы создаём копию в вашем Контенте.

**В: Почему я не вижу некоторые файлы в файловом менеджере?**
О: Отображаются только поддерживаемые типы файлов. Проверьте [поддерживаемые форматы файлов](/ru/knowledge-base/supported-formats) для получения списка доступных форматов.

## Устранение неполадок

### Проблемы с авторизацией

Если не удаётся подключиться:
- Убедитесь, что вы вошли в правильный аккаунт
- Попробуйте отозвать и повторно предоставить доступ
- Убедитесь, что доступ сторонних приложений включён в настройках вашего провайдера

### Ошибки импорта

Если файлы не удаётся импортировать:
- Убедитесь, что файлы в поддерживаемых форматах
- Проверьте, что файлы не повреждены
- Убедитесь, что у вас есть разрешение на доступ к файлам
- Попробуйте импортировать меньше файлов за раз
