# Папки и теги

Организуйте документы в разделе Content с помощью папок и тегов. Папки обеспечивают иерархическую организацию, а теги позволяют выполнять сквозную категоризацию между папками.

## Как перейти

Перейдите в раздел **Content** в боковом меню. Папки отображаются в обозревателе документов, а элементы управления тегами находятся на панели инструментов.

## Работа с папками

### Создание папки

1. Нажмите кнопку **New Folder** (иконка папки с +) на панели инструментов
2. Введите название папки (обязательно)
3. При желании добавьте описание
4. Выберите цвет с помощью палитры цветов
5. Нажмите **Create**

### Редактирование папки

1. Нажмите меню с тремя точками (...) на строке папки
2. Выберите **Rename**
3. Обновите название, описание или цвет
4. Нажмите **Save Changes**

### Удаление папки

1. Нажмите меню с тремя точками (...) на строке папки
2. Выберите **Delete**
3. Подтвердите удаление

### Загрузка в папку

- Перетащите файлы прямо на строку папки
- Наведите курсор на папку, чтобы увидеть иконки загрузки (облачное хранилище + локальные файлы)
- Нажмите, чтобы развернуть папку и увидеть её документы

## Работа с тегами

### Управление тегами (Создание, Редактирование, Удаление)

1. Нажмите выпадающий список **Tag Filter** на панели инструментов
2. Нажмите **Manage Tags** внизу
3. В модальном окне:
   - Нажмите **Create Tag**, чтобы добавить новый тег
   - Используйте предложенные теги для быстрого создания
   - Редактируйте существующие теги (название, цвет)
   - Удаляйте неиспользуемые теги

### Добавление тегов к документу

1. Наведите курсор на строку документа
2. Нажмите кнопку **Tag** (иконка тега)
3. В диалоге Manage Tags:
   - Просмотрите текущие теги вверху
   - Найдите доступные теги через поиск
   - Отметьте теги для добавления
   - Нажмите кнопку **Add X tags**

### Удаление тегов из документа

1. Откройте диалог Manage Tags для документа
2. В разделе "Current Tags" нажмите X на тегах для выбора к удалению
3. Нажмите кнопку **Remove X tags**

### Фильтрация документов по тегам

1. Нажмите выпадающий список **Tag Filter** на панели инструментов
2. Выберите один или несколько тегов
3. Отображаются только документы с этими тегами
4. Выбранные теги появляются в панели фильтров под панелью инструментов
5. Нажмите X на ярлыке тега, чтобы убрать фильтр, или **Clear all**

## Папки и теги: сравнение

| Характеристика | Папки | Теги |
|---------------|-------|------|
| Структура | Иерархическая (одна папка на документ) | Плоская (несколько тегов на документ) |
| Лучше всего для | Широких категорий, проектов, отделов | Тем, статусов, сквозных задач |
| Фильтрация | Нажмите на папку, чтобы увидеть содержимое | Используйте фильтр по тегам для поиска между папками |
| Ограничение | Одна папка на документ | Неограниченное количество тегов на документ |

## Советы

- Используйте папки для основных категорий (напр., "Product Docs", "HR Policies")
- Используйте теги для сквозных тем (напр., "Q1-2024", "Compliance", "Draft")
- Назначайте цвета папкам и тегам для визуальной организации
- Теги показывают количество использований, чтобы вы видели, сколько документов используют каждый тег
- Комбинируйте фильтрацию по папкам и тегам для точного поиска документов

## Частые вопросы

**В: Может ли документ находиться в нескольких папках?**
О: Нет, каждый документ принадлежит одной папке (или "Unfiled"). Используйте теги для сквозной категоризации.

**В: Что происходит с документами при удалении папки?**
О: Папки с документами нельзя удалить. Сначала переместите или удалите документы.

**В: Как увидеть все документы с определённым тегом?**
О: Используйте выпадающий список Tag Filter на панели инструментов и выберите нужный тег.
