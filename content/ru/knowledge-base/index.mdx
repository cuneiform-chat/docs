# Контент

Контент — это раздел, где вы управляете всеми документами, которые ваши ИИ-агенты используют для ответов на вопросы. Загружайте документы, организуйте их в папки, добавляйте теги и контролируйте, какие агенты имеют доступ к какому контенту.

## Как это работает

1. **Добавьте контент** — Загрузите документы, импортируйте из облачного хранилища или просканируйте веб-сайты
2. **Обработка** — Документы автоматически обрабатываются и индексируются
3. **Поиск** — Агенты ищут релевантный контент при ответах на вопросы
4. **Ответ** — Ответы генерируются на основе вашего реального контента

## Как перейти

Перейдите в раздел **Content** в боковом меню. Это ваш центральный узел для управления документами.

## Что вы видите

### Область загрузки

В верхней части страницы:
- **Иконки облачных хранилищ** — Нажмите на Google Drive, Dropbox, OneDrive или Box для прямого импорта файлов
- **Зона перетаскивания** — Перетащите файлы или нажмите для выбора локальных файлов
- **Вкладка Website** — Переключитесь на вкладку Website для сканирования и импорта публичного веб-контента

### Обозреватель документов

Под областью загрузки таблица отображает все ваши документы:

| Столбец | Описание |
|---------|----------|
| Name | Имя файла документа с иконкой типа и индикатором источника |
| Tags | Метки, назначенные документу |
| Status | Состояние обработки (см. Статус документа ниже) |
| Size | Размер файла в МБ |
| Type | Расширение файла (PDF, DOCX и т.д.) |
| Uploaded | Дата и время загрузки |
| Actions | Меню операций с документом |

### Панель инструментов

- **Search** — Поиск документов по имени
- **Tag Filter** — Показать только документы с определёнными тегами
- **Refresh** — Обновить список документов
- **New Folder** — Создать папку для организации
- **Fullscreen** — Развернуть обозреватель для большего пространства

## Статус документа

| Статус | Значение |
|--------|----------|
| Pending | Документ стоит в очереди на обработку |
| Uploaded | Документ загружен в систему |
| Validating | Документ проходит валидацию |
| Stored | Документ сохранён и ожидает обработки |
| Processing | Документ анализируется и индексируется |
| Ready | Документ обработан и доступен для ваших агентов |
| Completed | Обработка документа полностью завершена |
| Failed | При обработке произошла ошибка (можно повторить) |

## Работа с документами

### Просмотр документа

Нажмите на любую строку документа, чтобы открыть просмотрщик документа, который отображает содержимое и метаданные.

### Действия с документами

Наведите курсор на документ, чтобы увидеть кнопки быстрых действий:
- **Tag** — Добавить или удалить теги
- **Premium Processing** — Повысить качество обработки (если доступно)
- **Retry** — Повторно обработать документы с ошибками
- **Chat** — Начать разговор об этом конкретном документе

Из меню Actions (...):
- **Move to Folder** — Переместить документ
- **Reprocess** — Повторить обработку для документов с ошибками
- **Delete** — Удалить документ навсегда

## Лучшие практики

- **Поддерживайте актуальность контента** — Регулярно обновляйте документы для поддержания точности
- **Организуйте с помощью папок** — Группируйте связанные документы для удобного управления
- **Используйте теги для сквозных тем** — Теги помогают находить документы между папками
- **Качество имеет значение** — Хорошо структурированные документы дают лучшие ответы ИИ
- **Удаляйте дубликаты** — Избегайте загрузки одного и того же контента несколько раз
