# Загрузка документов

Загружайте документы в ваш контент, чтобы ваши ИИ-агенты могли использовать их для ответов на вопросы. Документы автоматически обрабатываются и становятся доступными для поиска.

## Как перейти

1. Войдите в Admin Panel
2. Перейдите в раздел **Content** в боковом меню
3. Область загрузки отображается в верхней части страницы

## Способы загрузки

### Загрузка локальных файлов

1. **Перетащите** файлы прямо в область загрузки, ИЛИ
2. **Нажмите** на область загрузки, чтобы открыть проводник файлов
3. Выберите один или несколько файлов для загрузки
4. Файлы начнут загружаться автоматически с отслеживанием прогресса

### Импорт из облачного хранилища

Импортируйте файлы напрямую из ваших облачных хранилищ:

| Провайдер | Иконка | Как использовать |
|-----------|--------|-----------------|
| Google Drive | Иконка Google Drive | Нажмите, чтобы открыть выбор файлов Google Drive |
| Dropbox | Иконка Dropbox | Нажмите, чтобы открыть выбор файлов Dropbox |
| OneDrive | Иконка OneDrive | Нажмите, чтобы открыть выбор файлов OneDrive |
| Box | Иконка Box | Нажмите, чтобы открыть выбор файлов Box |

После выбора файлов из любого провайдера они автоматически импортируются в ваш контент.

## Параметры загрузки

### Добавление тегов

При желании назначайте теги документам во время загрузки:

1. Нажмите **+ Add Tags** перед загрузкой
2. Выберите теги из выпадающего списка
3. Выбранные теги будут применены ко всем загружаемым документам

## Поддерживаемые типы файлов

Типы файлов, которые вы можете загружать, зависят от вашего плана. Распространённые форматы включают:

- **Документы:** PDF, DOCX, DOC, TXT, MD, RTF
- **Презентации:** PPTX, PPT
- **Веб/Данные:** HTML, HTM, JSON, XML

Ограничения размера файлов также зависят от плана (указаны в области загрузки).

См. [Поддерживаемые форматы](/ru/knowledge-base/supported-formats) для полного списка.

## Во время загрузки

### Отслеживание прогресса

- Каждый файл показывает прогресс загрузки с процентной шкалой
- Отображаются скорость загрузки и расчётное оставшееся время
- Файлы обрабатываются по одному

### Варианты отмены

- **Отменить отдельный файл:** Нажмите X рядом с файлом
- **Отменить все:** Нажмите "Cancel All Pending", чтобы остановить всю партию
- При попытке покинуть страницу во время загрузки появится предупреждение

## Статус обработки

Отслеживайте статус документа в разделе Content:

| Статус | Значение |
|--------|----------|
| Pending | Документ стоит в очереди на обработку |
| Uploaded | Документ загружен в систему |
| Validating | Документ проходит валидацию |
| Stored | Документ сохранён и ожидает обработки |
| Processing | Документ анализируется и индексируется |
| Ready | Документ обработан и доступен для ваших агентов |
| Completed | Обработка документа полностью завершена |
| Failed | При обработке произошла ошибка (можно повторить) |

## После загрузки

### Успешная загрузка

- Успешно загруженные файлы появляются в обозревателе документов
- Документы автоматически обрабатываются для поиска
- Вы можете организовать их в папки или добавить теги

### Обработка дубликатов

- Система автоматически обнаруживает дублирующийся контент
- Если файл с идентичным содержимым уже существует, вы увидите предупреждение
- Расположение существующего файла указано в сообщении об ошибке

### Обработка ошибок

- Если файл не удалось загрузить, сообщение об ошибке объясняет причину
- Частые проблемы включают слишком большой размер файла или неподдерживаемый формат
- Вы можете повторить загрузку отдельных файлов или загрузить их заново

## Советы

- Загружайте несколько файлов одновременно для экономии времени
- Применяйте теги во время загрузки, чтобы документы были организованы
- Проверяйте поддерживаемые типы файлов, указанные в области загрузки

## Частые вопросы

**В: Сколько файлов можно загрузить одновременно?**
О: Вы можете выбрать несколько файлов для пакетной загрузки. Они обрабатываются по одному с отслеживанием прогресса.

**В: Почему мой файл был отклонён?**
О: Проверьте, поддерживается ли тип файла и не превышает ли размер файла установленные ограничения (указаны в области загрузки). Некоторые файлы могут быть заблокированы по соображениям безопасности.

**В: Сколько времени занимает обработка?**
О: Время загрузки зависит от размера файла и вашего подключения. После загрузки документы обрабатываются в фоновом режиме и автоматически становятся доступными для поиска.

**В: Можно ли загрузить файл в конкретную папку?**
О: Да, вы можете загружать файлы непосредственно в папки через меню папки или организовать документы после загрузки.
