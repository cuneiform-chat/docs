# Доступ агента к базе знаний

Управляйте тем, какие документы каждый агент может использовать при ответе на вопросы. Ограничьте доступ агентов определёнными папками или тегами, либо исключите определённый контент из их области доступа.

## Как перейти

1. Откройте **Agents** на боковой панели
2. Нажмите на агента для редактирования или создайте нового агента
3. Прокрутите до раздела **Knowledge Access Control**

## Режимы доступа

Режим доступа определяет, как ваш выбор влияет на доступ агента к документам.

| Режим | Значок | Описание | Когда использовать |
|-------|--------|----------|-------------------|
| **Exclude Mode** | Красный X | Агент имеет доступ ко ВСЕМ документам, КРОМЕ выбранных | Вы хотите скрыть конфиденциальные документы, но разрешить доступ ко всему остальному |
| **Include Mode** | Зелёная галочка | Агент имеет доступ ТОЛЬКО к выбранным документам | Вы хотите ограничить агента определённым контентом |

### Выбор подходящего режима

**Exclude Mode** (по умолчанию):
- Начинается с полного доступа ко всем документам
- Выберите папки/теги для блокировки доступа агента
- Подходит для: скрытия HR-документов, финансовых данных или черновиков

**Include Mode**:
- Начинается без доступа
- Выберите папки/теги для предоставления доступа
- Подходит для: создания специализированных агентов по определённым темам

## Выбор контента

### По папкам

1. Нажмите на вкладку **Folders**
2. Используйте поле поиска для нахождения папок
3. Отметьте папки для включения/исключения
4. Разверните папки (нажмите на стрелку) для выбора отдельных документов
5. Галочка показывает выбранные элементы; частичный выбор отображается тире

### По тегам

1. Нажмите на вкладку **Tags**
2. Используйте поле поиска для нахождения тегов
3. Отметьте теги для включения/исключения
4. Каждый тег показывает количество связанных документов

## Панель предварительного просмотра

Панель предварительного просмотра справа показывает:
- Общее количество доступных документов на основе текущего выбора
- Обновляется в реальном времени при внесении изменений

## Сохранение изменений

При редактировании существующего агента:
1. Сделайте свой выбор
2. Нажмите **Save Changes** (зелёная кнопка)
3. Или нажмите **Reset Changes** для отмены несохранённых изменений

При создании нового агента:
- Настройки доступа к знаниям сохраняются автоматически при отправке формы агента

## Советы

- Используйте **Exclude Mode**, когда нужен широкий доступ с несколькими исключениями
- Используйте **Include Mode** для целевых агентов по конкретным темам
- Комбинируйте папки И теги для точного контроля
- Проверяйте панель предварительного просмотра перед сохранением
- Для Include Mode необходимо выбрать хотя бы одну папку или тег

## Частые вопросы

**В: Что произойдёт, если выбрать и папки, и теги?**
О: Агент сможет получить доступ к документам, которые соответствуют ЛЮБОМУ из ваших выборов. Папки и теги объединяются включительно.

**В: Можно ли дать агенту доступ ко всему?**
О: Да. Используйте Exclude Mode и не выбирайте ничего для исключения. Агент будет иметь полный доступ.

**В: Что если документ находится в выбранной папке, но имеет исключённый тег?**
О: В Exclude Mode любое совпадение с исключённым контентом блокирует доступ. В Include Mode любое совпадение с включённым контентом предоставляет доступ.

**В: Повлияет ли это на существующие разговоры?**
О: Да. Изменения вступают в силу немедленно для новых сообщений. Агент будет использовать обновлённые правила доступа.
