# Управление документами

Узнайте, как организовывать, обновлять и поддерживать ваши документы. Это включает просмотр документов, организацию с помощью папок, обновление контента и массовые операции.

## Как перейти

1. Нажмите **Content** на боковой панели
2. Просмотрите все ваши документы в списке

## Просмотр документов

Получите доступ к документам из раздела Content:

- Просматривайте все документы в виде списка
- Отслеживайте статус обработки каждого документа
- Проверяйте, когда документы были добавлены или обновлены

### Сведения о документе

Нажмите на любой документ для просмотра:

| Информация | Описание |
|------------|----------|
| **File information** | Имя, размер, формат, дата загрузки |
| **Processing status** | Текущее состояние в конвейере обработки |
| **Chunk count** | Количество созданных поисковых сегментов |

## Организация документов

### Использование папок

Создавайте папки для организации связанных документов:

1. Нажмите кнопку **New Folder** (значок папки с плюсом)
2. Введите название папки
3. Нажмите **Create**

Рекомендации по организации:
- По теме (Продукты, Политики, FAQ)
- По отделу (Продажи, Поддержка, HR)
- По типу документа (Руководства, Справочники, Учебные материалы)

### Перемещение документов

Перемещайте документы между папками:

1. Нажмите на меню документа (⋮)
2. Выберите **Move to Folder**
3. Выберите целевую папку

### Использование тегов

Добавляйте теги к документам для гибкой категоризации:

1. Нажмите на меню документа (⋮)
2. Выберите **Manage Tags**
3. Добавьте или удалите теги по необходимости

Теги работают совместно с папками — используйте папки для основной организации и теги для перекрёстных категорий.

## Обновление документов

### Повторная обработка документа с ошибкой

Если обработка документа завершилась с ошибкой, вы можете повторить попытку:

1. Нажмите на меню документа (⋮)
2. Выберите **Reprocess**

### Замена контента

Для обновления содержимого документа удалите старую версию и загрузите новый файл. Документ будет обработан автоматически.

## Удаление документов

Удалите документы, которые вам больше не нужны:

1. Нажмите на меню документа (⋮)
2. Выберите **Delete**
3. Подтвердите удаление

<Callout type="warning">
  Удалённые документы удаляются безвозвратно и не могут быть восстановлены. Содержимое больше не будет доступно для поиска вашими агентами.
</Callout>

## Массовые операции

Управляйте несколькими документами одновременно:

1. Выберите несколько документов с помощью флажков
2. Используйте меню массовых действий:
   - **Move to Folder** — переместить выбранные документы в папку
   - **Reprocess Failed** — повторить обработку документов с ошибками в выборке

## Поиск и фильтрация

Находите конкретные документы:

| Функция | Описание |
|---------|----------|
| **Search** | Поиск по названию документа |
| **Filter by folder** | Нажмите на папку в обозревателе документов для просмотра её содержимого |
| **Filter by tag** | Используйте фильтр по тегам для отображения документов с определёнными тегами |

Документы отсортированы по дате загрузки (сначала новые).

## Управление хранилищем

Отслеживайте использование хранилища:

1. Перейдите на **Dashboard**
2. Просмотрите карточку "Storage Used", показывающую текущее использование и лимит
3. Удалите ненужные документы для освобождения места

## Советы

- Регулярно удаляйте устаревшие документы для поддержания порядка
- Используйте папки и теги для организации документов и удобного поиска
- Проверяйте документы с ошибками и повторно обрабатывайте их при необходимости
- Для обновления контента удалите старый документ и загрузите новую версию
- Используйте массовые операции для перемещения нескольких документов в папки за раз
- Удаляйте дубликаты, чтобы не вводить агентов в заблуждение

## Частые вопросы

**В: Как обновить содержимое документа?**
О: Удалите старый документ и загрузите новую версию. Новый документ будет обработан автоматически.

**В: Можно ли восстановить удалённый документ?**
О: Нет, удалённые документы удаляются безвозвратно и не могут быть восстановлены. Убедитесь, что у вас есть резервная копия перед удалением.

**В: Как узнать, был ли документ успешно обработан?**
О: Проверьте столбец статуса обработки. Документы показывают **Ready** при завершении или **Failed** при наличии ошибки.

**В: Что делать, если обработка документа завершилась с ошибкой?**
О: Нажмите на меню документа (⋮) и выберите **Reprocess**. Эта опция отображается только для документов с ошибками. Если ошибка повторяется, проверьте формат и размер файла.
