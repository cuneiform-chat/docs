# Поддерживаемые форматы

Cuneiform Chat поддерживает широкий спектр форматов документов.

## Типы документов

### Текстовые документы

| Формат | Расширения | Примечания |
|--------|-----------|------------|
| PDF | `.pdf` | Текстовые и отсканированные (с OCR) |
| Microsoft Word | `.docx`, `.doc` | Полная поддержка форматирования |
| Plain Text | `.txt` | Простые текстовые файлы |
| Markdown | `.md` | Форматирование Markdown сохраняется |
| Rich Text | `.rtf` | Базовая поддержка форматирования |

### Презентации

| Формат | Расширения | Примечания |
|--------|-----------|------------|
| PowerPoint | `.pptx`, `.ppt` | Содержимое слайдов извлекается |

### Веб-контент

| Формат | Расширения | Примечания |
|--------|-----------|------------|
| HTML | `.html`, `.htm` | Содержимое веб-страниц |

### Форматы данных

| Формат | Расширения | Примечания |
|--------|-----------|------------|
| JSON | `.json` | Файлы структурированных данных |
| XML | `.xml` | XML-документы |

## Примечания по форматам

### PDF

PDF работают лучше всего, когда они:
- **Текстовые** — Созданы из цифровых документов
- **С возможностью поиска** — Текст можно выделить/скопировать

Отсканированные PDF поддерживаются, но качество извлечения может быть ниже из-за ограничений OCR.

### Документы Word

`.docx` (современный формат) рекомендуется вместо `.doc` (устаревший формат) для лучших результатов.

Поддерживаемые элементы:
- Текст и абзацы
- Заголовки и стили
- Таблицы
- Списки

### Markdown

Форматирование Markdown сохраняется при обработке:
- Заголовки становятся маркерами разделов
- Списки сохраняют структуру
- Блоки кода распознаются

## Неподдерживаемые форматы

В настоящее время не поддерживаются:
- Изображения (`.jpg`, `.png`, `.gif`)
- Аудиофайлы (`.mp3`, `.wav`)
- Видеофайлы (`.mp4`, `.mov`)
- Сжатые архивы (`.zip`, `.rar`)
- Исполняемые файлы (`.exe`, `.app`)

import { Callout } from 'nextra/components'

<Callout type="important">
  Если у вас есть контент в неподдерживаемом формате, попробуйте преобразовать его в PDF или текстовый формат перед загрузкой.
</Callout>

## Ограничения размера файлов

Максимальные размеры файлов зависят от вашего плана. Очень большие документы могут обрабатываться дольше.

Для лучшей производительности:
- Разделяйте очень большие документы на файлы поменьше
- Удаляйте ненужные изображения из PDF, если они не требуются
- По возможности используйте текстовые форматы
