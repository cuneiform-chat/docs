# Параметры конфигурации

import { Callout } from 'nextra/components'

Подробное руководство по всем параметрам конфигурации agent.

## Структура страницы

Страница редактирования agent имеет три вкладки:

| Вкладка | Назначение |
|---------|-----------|
| **Configuration** | Основные настройки (статус, имя, persona, LLM, сообщения) |
| **Knowledge Access** | Управление документами, доступными agent |
| **Integrations** | Подключение к внешним каналам (Telegram, Discord и т.д.) |

## Вкладка Configuration

### Статус

Управляйте доступностью вашего agent:

| Статус | Playground | Интеграции | Примечания |
|--------|------------|------------|-----------|
| **Testing** | ✅ Включён | ❌ Отключены | По умолчанию для новых agent. Тестируйте перед запуском. |
| **Active** | ✅ Включён | ✅ Включены | Готов к использованию в продакшене. |
| **Inactive** | ❌ Отключён | ❌ Отключены | Временно отключён. |
| **Archived** | ❌ Отключён | ❌ Отключены | Скрыт из основного списка. |

<Callout type="warning">
  Если у вашего agent есть подключённые интеграции и вы меняете статус с Active на другой, появится диалог подтверждения с предупреждением о том, что agent перестанет отвечать в подключённых каналах.
</Callout>

### Основные настройки

- **Name** — идентифицирует agent в вашей панели управления
- **Description** — внутренние заметки о назначении agent

### Конфигурация LLM

Управляйте AI-моделью, работающей за вашим agent.

**Режим по умолчанию (переключатель Advanced выключен):**
- Используются значения по умолчанию вашего тарифного плана
- Отображается информационное поле с пояснением, что используются настройки тарифа
- Рекомендуется для большинства случаев использования

**Расширенный режим (переключатель Advanced включён):**

| Параметр | Описание |
|----------|----------|
| **Model** | Выберите из доступных AI-моделей в зависимости от вашего плана |
| **Temperature** | Управляет креативностью ответов (0.0-2.0) |

#### Руководство по Temperature

| Значение | Поведение |
|----------|-----------|
| 0.0 - 0.3 | Сфокусированные, детерминированные ответы |
| 0.4 - 0.7 | Баланс между креативностью и последовательностью |
| 0.8 - 2.0 | Более креативные, разнообразные ответы |

**Рекомендация:** начните с 0.3-0.5 для фактических вопросов-ответов на основе документов.

#### Show Document References

Этот переключатель (всегда виден, независимо от режима Advanced) управляет включением ссылок на источники в ответах agent:

- **Off** (по умолчанию) — ответы не упоминают исходные документы
- **On** — ответы включают ссылки на исходные документы

<Callout type="important">
  Включите ссылки на документы для случаев, требующих прозрачности, таких как юридические задачи, комплаенс или внутренний контент, где пользователям нужно проверять источники.
</Callout>

### Поддержка языков

Ваш agent автоматически определяет язык каждого сообщения пользователя и отвечает на том же языке — ручная настройка не требуется. Из коробки поддерживается 176 языков, включая арабский, французский, немецкий, испанский, турецкий, китайский, японский и другие.

### Agent Persona

Инструкции, управляющие поведением agent. Лучшие практики см. в [Agent Personas](/agents/agent-personas).

**Доступные действия:**
- **Generate** — открывает [Agent Persona Builder](/agents/persona-builder)
- **Edit** — открывает выдвижную панель для написания или редактирования persona напрямую

Нажмите на текстовую область persona, чтобы открыть панель редактирования.

**Platform Rules Box:**
Нажмите для просмотра правил надёжности платформы, которые автоматически применяются ко всем agent:
- Без фабрикации — не будет выдумывать факты
- Признание пробелов — говорит «Я не знаю», когда это уместно
- Устойчивость к домыслам — не будет угадывать недостающую информацию
- Без профессиональной имитации — не будет выступать в роли юристов, врачей и т.д.
- Коррекция ложных предпосылок — указывает на неверные предположения
- Блокировка вредоносного контента — отказывает в неуместных запросах

<Callout type="info">
  Platform rules обеспечивают надёжное и безопасное поведение всех agent. Их нельзя отключить или изменить.
</Callout>

## Вкладка Knowledge Access

Управляйте тем, к каким документам ваш agent может обращаться при ответе на запросы.

### Режимы доступа

| Режим | Поведение | Когда использовать |
|-------|-----------|-------------------|
| **Exclude Mode** | Agent имеет доступ ко ВСЕМ документам, КРОМЕ выбранных | Скрыть конфиденциальные документы, сохранив доступ ко всему остальному |
| **Include Mode** | Agent имеет доступ ТОЛЬКО к выбранным элементам | Ограничить agent определённым набором документов |

### Параметры выбора

Точная настройка доступа с помощью нескольких типов выбора:

- **Folders** — выберите целые папки и все документы внутри них
- **Tags** — фильтрация документов по присвоенным тегам
- **Individual Documents** — включение или исключение конкретных документов внутри выбранных папок

### Предпросмотр доступа

Панель предпросмотра показывает эффективный доступ к документам на основе ваших текущих настроек. Используйте её для проверки конфигурации перед сохранением.

<Callout type="info">
  Начните с **Exclude Mode**, если вам нужен широкий доступ с определёнными ограничениями. Используйте **Include Mode**, когда вам нужен строгий контроль над тем, на какие именно документы agent может ссылаться.
</Callout>

## Human Handoff

Включите передачу чата живому оператору, чтобы ваш AI agent мог передавать разговоры реальному человеку по запросу пользователя.

**Как включить:**

1. На вкладке **Configuration** прокрутите до раздела **Human Handoff**
2. Включите переключатель **Enable Human Handoff**
3. Настройте сообщения:
   - **Handoff Message** — показывается пользователю при начале передачи
   - **Accept Message** — автоматически отправляется, когда оператор принимает разговор
   - **Resolve Message** — показывается, когда оператор завершает разговор
   - **Max Wait Time** — автоматическое истечение, если ни один оператор не принял (5, 15, 30, 60 или 120 минут; по умолчанию: 30 минут)
4. Нажмите **Save Changes**

Когда пользователь просит поговорить с человеком, AI создаёт запрос на передачу, видимый на странице **Inbox**. Член команды принимает запрос, общается с пользователем в его канале и завершает разговор, когда всё решено.

<Callout type="info">
  Human Handoff доступен на всех планах. Включите его для каждого agent на вкладке Configuration.
</Callout>

## Тестирование вашего Agent

Перед сохранением изменений вы можете протестировать agent:

1. Нажмите кнопку **Test Agent** внизу формы
2. Откроется панель Playground
3. Проведите тестовый разговор с вашим agent
4. Закройте Playground, когда закончите

<Callout type="info">
  Кнопка Test Agent отключена, когда статус agent — Archived или Inactive. Измените статус на Active или Testing, чтобы включить тестирование.
</Callout>

## Сохранение изменений

| Кнопка | Действие |
|--------|----------|
| **Save Changes** | Сохранить все изменения |
| **Test Agent** | Открыть Playground для тестирования |

Чтобы отменить изменения, перейдите на другую страницу с помощью кнопки «назад» или навигации в боковой панели.

**Что сохраняется:**
- Обновляются только изменённые поля
- Вы увидите «No changes to save», если ничего не было изменено
- После сохранения появляются сообщения об успехе или ошибке

**Обработка частичного сохранения:**
Если некоторые изменения сохранились, а другие нет, вы получите уведомление о том, какие разделы не удалось сохранить, и страница обновится, чтобы показать текущее состояние.

<Callout type="info">
  Изменения настроек agent вступают в силу сразу после сохранения. Протестируйте в Playground после внесения изменений.
</Callout>
