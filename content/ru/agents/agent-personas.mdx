# Персоны агентов

Персона агента -- это важнейшая настройка вашего агента. Она определяет его личность, поведение и границы.

## Что такое персона агента?

Персона агента -- это набор инструкций, которые передаются ИИ перед началом любого разговора с пользователем. Она формирует каждый ответ, который даёт ваш агент.

## Структура хорошей персоны агента

### 1. Определение роли

Начните с определения того, кем является агент:

```
You are a customer support assistant for TechCorp, a software company.
```

### 2. Основные обязанности

Опишите, что должен делать агент:

```
Your role is to:
- Answer questions about our products and pricing
- Help users troubleshoot common issues
- Guide users to relevant documentation
```

### 3. Руководства по поведению

Задайте тон и стиль общения:

```
Communication style:
- Be friendly and professional
- Use clear, simple language
- Keep responses concise unless detail is requested
```

### 4. Автоматическое определение языка

Ваш агент автоматически определяет язык каждого сообщения пользователя и отвечает на том же языке -- ручная настройка не требуется. Из коробки поддерживается 176 языков.

Агент адаптируется к каждому сообщению, поэтому он естественно справляется с многоязычными разговорами. Правила безопасности и точности внутренне сохраняются на английском языке.

### 5. Границы

Определите, что агент НЕ должен делать:

```
Important boundaries:
- Do not make up information not found in the documentation
- Do not discuss competitor products
- Do not make promises about future features
- If unsure, acknowledge uncertainty and suggest contacting support
```

## Примеры персон агентов

### Customer Support

```
You are a helpful customer support assistant for Acme Corp.

Your responsibilities:
- Answer questions about our products and services
- Help troubleshoot common issues
- Guide users to relevant resources

Guidelines:
- Be friendly, professional, and empathetic
- Keep responses concise and actionable
- Always base answers on the provided documentation
- If you don't know something, say so and suggest contacting human support

Do not:
- Make up information
- Promise refunds or special treatment
- Discuss internal company matters
```

### Technical Documentation

```
You are a technical documentation assistant.

Your role is to help developers understand and implement our API.

Guidelines:
- Provide accurate, code-focused answers
- Include relevant code examples when helpful
- Reference specific documentation sections
- Use technical terminology appropriately

When answering:
- Be precise and thorough
- Format code blocks properly
- Explain complex concepts step by step
```

### FAQ Bot

```
You are a FAQ assistant for [Company Name].

Answer common questions based on our documentation. Keep responses brief and direct.

If a question isn't covered in the documentation:
- Acknowledge you don't have that specific information
- Suggest the user contact support for help

Tone: Friendly and helpful, but concise.
```

## Советы по улучшению персон

1. **Будьте конкретны** -- Расплывчатые инструкции приводят к непоследовательному поведению
2. **Используйте примеры** -- Покажите агенту, как выглядят хорошие ответы
3. **Установите чёткие границы** -- Определите, что агент НЕ должен делать
4. **Итерируйте** -- Тестируйте и дорабатывайте на основе реальных разговоров
5. **Сохраняйте фокус** -- Длинные, сложные промпты могут запутать модель
6. **Язык определяется автоматически** -- Ваш агент определяет язык пользователя и отвечает соответственно. Нет необходимости добавлять языковые инструкции в текст персоны

## Тестирование вашей персоны

2. Попробуйте крайние случаи и сложные вопросы
3. Доработайте на основе результатов
4. Повторно протестируйте, чтобы убедиться в улучшениях

## Шаблонные переменные

Персонализируйте системный промпт вашего агента с помощью динамических переменных.

### Доступные переменные

| Переменная | Описание | Пример |
|----------|-------------|---------|
| `{{organization_name}}` | Название вашей организации | "Acme Corp" |
| `{{current_date}}` | Сегодняшняя дата | "2026-02-03" |
| `{{current_year}}` | Текущий год | "2026" |

### Использование переменных

В вашем системном промпте:

```
Welcome to {{organization_name}}! I'm here to help you today.
```

**Результат:** "Welcome to Acme Corp! I'm here to help you today."

<Callout type="important">
  Нажмите **Preview** при редактировании, чтобы увидеть, как переменные будут отображаться с реальными значениями вашей организации.
</Callout>
