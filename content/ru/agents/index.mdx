# Agents

Agents — это AI-чатботы, которые взаимодействуют с вашими пользователями. Каждый agent имеет собственную конфигурацию, доступ к знаниям и характер.

## Что такое Agent?

Agent — это настроенный чатбот, который:

- Отвечает на вопросы, используя ваш контент
- Следует инструкциям, определённым в его agent persona
- Поддерживает контекст разговора в рамках сессий
- Может быть развёрнут в нескольких каналах

## Концепции Agent

### Agent Persona

Agent Persona — это набор инструкций, определяющих поведение agent. Она управляет:

- **Личность** — дружелюбный, профессиональный, неформальный и т.д.
- **Область** — какие темы agent должен и не должен затрагивать
- **Стиль ответов** — длина, формат и тон ответов
- **Ограничения** — границы и лимиты
- **Язык** — автоматическое определение для каждого сообщения (поддерживается 176 языков)

### Доступ к знаниям

Каждый agent обращается к вашему контенту для поиска релевантной информации. Вы можете настроить:

- Какие документы agent может искать
- Сколько источников извлекать
- Показывать ли ссылки на источники

### Каналы

Agent может быть развёрнут в нескольких каналах одновременно:

- Мессенджеры (Telegram, Discord, Slack, WhatsApp, Google Chat)
- Facebook Messenger через интеграцию Meta
- Human Handoff — бесшовная передача разговоров члену команды
