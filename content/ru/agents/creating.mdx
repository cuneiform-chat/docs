# Создание Agent

import { Callout } from 'nextra/components'

Узнайте, как создавать новых agent в Cuneiform Chat.

## Начало работы

1. Перейдите в раздел **Agents** в боковой панели
2. Нажмите кнопку **Create Agent** в правом верхнем углу
3. Заполните разделы формы ниже

## Основная информация

В этом разделе указываются ключевые сведения о вашем agent.

| Поле | Обязательное | Описание |
|------|-------------|----------|
| **Name** | Да | Имя вашего agent (например, «Customer Support Agent»). Максимум 100 символов. |
| **Description** | Нет | Краткое описание назначения agent. Максимум 500 символов. |

**Советы:**
- Выберите описательное имя, отражающее назначение agent
- Описание помогает вам и вашей команде понять роль agent

## Agent Persona

Agent persona определяет, как ваш agent ведёт себя и отвечает, через системный промпт.

**Ключевые элементы:**

- **Platform Rules Box** — показывает встроенные правила безопасности, которые применяются автоматически (нажмите для подробностей)
- **Generate Button** — открывает [Agent Persona Builder](/agents/persona-builder) для помощи в создании persona
- **Edit Button** — открывает панель для ручного написания или редактирования persona

### Platform Rules

Эти защитные механизмы автоматически применяются ко всем agent:

- **Без фабрикации** — не будет выдумывать факты, отсутствующие в вашем контенте
- **Признание пробелов** — говорит «Я не знаю», когда это уместно
- **Устойчивость к домыслам** — не будет угадывать недостающую информацию
- **Без профессиональной имитации** — не будет выступать в роли юристов, врачей и т.д.
- **Коррекция ложных предпосылок** — указывает на неверные предположения
- **Блокировка вредоносного контента** — отказывает в неуместных запросах

<Callout type="info">
  Platform rules обеспечивают надёжное и безопасное поведение всех agent. Их нельзя отключить. Подробнее см. [Agent Persona Builder](/agents/persona-builder#platform-rules).
</Callout>

### Пример быстрой Persona

```
You are a helpful assistant for [Your Company].
Answer questions based on the provided documentation.
Be concise and friendly.
```

Подробные рекомендации по написанию эффективных persona см. в [Agent Personas](/agents/agent-personas).

## Поддержка языков

Ваш agent автоматически определяет язык каждого сообщения пользователя и отвечает на том же языке — настройка не требуется. Из коробки поддерживается 176 языков. Подробнее см. [Agent Personas — Language Detection](/agents/agent-personas#4-automatic-language-detection).

## Конфигурация LLM

Этот раздел управляет настройками AI-модели.

**Режим по умолчанию:**

По умолчанию настройки LLM используют значения по умолчанию вашего тарифного плана. Вы увидите информационное поле «Using tier defaults». Это рекомендуется для большинства случаев использования.

**Расширенный режим:**

Включите переключатель **Advanced** для настройки:

| Параметр | Описание |
|----------|----------|
| **Model** | Выберите из доступных AI-моделей в зависимости от вашего плана |
| **Temperature** | Управляет креативностью ответов (ниже = более последовательные, выше = более креативные) |

**Show Document References:**

Этот переключатель (всегда виден) управляет включением ссылок на источники в ответах agent:
- **Off** (по умолчанию) — ответы не упоминают исходные документы
- **On** — ответы включают ссылки на исходные документы (полезно для юридических/комплаенс-задач)

## Управление доступом к знаниям

Управляйте тем, к каким документам ваш agent может обращаться при ответе на вопросы.

| Режим | Поведение | Когда использовать |
|-------|-----------|-------------------|
| **Exclude Mode** | Agent имеет доступ ко ВСЕМ документам, КРОМЕ выбранных | Скрыть конфиденциальные документы от agent |
| **Include Mode** | Agent имеет доступ ТОЛЬКО к выбранным элементам | Ограничить agent определённым набором знаний |

**При использовании Include Mode:**
- Выберите конкретные папки, к которым agent может обращаться
- Выберите конкретные теги, к которым agent может обращаться
- Выберите отдельные документы, к которым agent может обращаться

Agent будет использовать информацию только из выбранных источников при ответе.

<Callout type="important">
  Начните с Exclude Mode (полный доступ к знаниям), если вам не нужно скрывать конкретные документы. Вы всегда можете ограничить доступ позже.
</Callout>

## Действия формы

Внизу формы:

| Кнопка | Действие |
|--------|----------|
| **Cancel** | Отменить изменения и вернуться назад |
| **Reset** | Очистить все поля и начать заново (показывает диалог подтверждения) |
| **Create Agent** | Сохранить agent и открыть страницу редактирования |

<Callout type="info">
  Ваш черновик автоматически сохраняется по мере работы. Если вы уйдёте и вернётесь, прогресс будет восстановлен.
</Callout>

## После создания

При нажатии **Create Agent**:

1. Agent создаётся со статусом **Testing**
2. Вы переходите на страницу редактирования agent
3. Протестируйте agent с помощью Playground
4. Подключите интеграции, когда будете готовы к запуску
5. Измените статус на **Active**, когда будете готовы

<Callout type="info">
  Новые agent начинают со статусом **Testing**. Вы можете тестировать в Playground, но интеграции с каналами отключены до активации agent.
</Callout>

## Управление Agent

На странице Agents вы можете:

- **Edit** — нажмите на любой agent, чтобы изменить его настройки
- **Test** — нажмите **Test** на карточке agent, чтобы открыть Playground
- **Change Status** — установите статус Testing, Active, Inactive или Archived

Подробности обо всех настройках agent см. в [Параметры конфигурации](/agents/configuring).
