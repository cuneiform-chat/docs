# Аналитика разговоров

Отслеживайте метрики разговоров и просматривайте подробные расшифровки по всем вашим agent и каналам.

## Обзор

Аналитика разговоров предоставляет:

- Общий объём разговоров
- Разговоры по agent
- Разговоры по каналам
- Полные расшифровки сообщений
- Инсайты разговоров на базе ИИ

## Доступ к разговорам

### С панели управления

1. Перейдите в раздел **Analytics** на боковой панели
2. Нажмите **View All** на карточках Top Agents или Top Channels
3. Или перейдите напрямую в раздел Conversations из меню аналитики

### Список разговоров

Просматривайте все разговоры с информацией:

| Столбец | Описание |
|---------|----------|
| Title | Название разговора или ID сеанса |
| Agent | Какой agent обработал разговор |
| Channel | Платформа (Telegram, Discord, Slack и др.) |
| Messages | Общее количество сообщений |
| Last Active | Когда разговор был последний раз обновлён |
| Status | Активный, архивированный или удалённый |

## Фильтрация разговоров

Фильтруйте список разговоров по:

- **Agent** — выберите конкретный agent или все agent
- **Channel** — фильтр по платформе (WhatsApp, Telegram, Meta, Slack, Discord, Google Chat, Playground)
- **Date range** — последние 7, 14, 30 или 90 дней

## Детали разговора

Нажмите на любой разговор, чтобы просмотреть полную информацию:

### Вкладка обзора

- **Total Messages** — количество сообщений в разговоре
- **Credits Spent** — использованные credit платформы
- **Agent** — какой agent обработал разговор
- **Channel** — платформа, на которой он происходил
- **Created** — когда разговор начался
- **Last Active** — последняя активность

### График активности сообщений

Визуализируйте паттерны сообщений во времени:
- Переключайтесь между почасовой и ежедневной детализацией
- Показывайте/скрывайте сообщения пользователей и assistant
- Наблюдайте за паттернами активности разговора

### Вкладка сообщений

Просматривайте полную расшифровку разговора:

- **Полная история сообщений** — просмотр каждого сообщения в разговоре
- **Индикаторы ролей** — сообщения User, Assistant, System и Tool выделены цветом
- **Временные метки** — когда каждое сообщение было отправлено
- **Использование token** — входные/выходные token на сообщение (при наличии)

#### Фильтрация сообщений

Фильтруйте сообщения по периоду времени:
- Последние 24 часа
- Последние 7 дней
- Последние 30 дней
- Все сообщения

#### Экспорт

Нажмите **Export**, чтобы скачать разговор в виде файла JSON, содержащего:
- Метаданные разговора
- Все сообщения с временными метками
- Информацию о token

## Инсайты на базе ИИ

Генерируйте интеллектуальные сводки разговоров:

1. Перейдите на вкладку **Messages** разговора
2. Нажмите **Generate Insights**
3. Просмотрите проанализированные ИИ инсайты, включая:
   - **Key Points** — основные обсуждавшиеся темы
   - **User Intents** — что пользователь пытался достичь
   - **Key Info Shared** — важная обменённая информация
   - **Suggested Actions** — рекомендации на основе разговора

## Конфиденциальность

Данные разговоров обрабатываются в соответствии с:

- Требованиями политики конфиденциальности
- Согласием пользователей, где это применимо

## Советы

- Используйте фильтры для поиска разговоров от конкретных agent или каналов
- Экспортируйте важные разговоры для архивирования или анализа
- Генерируйте ИИ-инсайты для быстрого понимания длинных разговоров
- Проверяйте график активности сообщений для определения пиковых периодов использования
- Просматривайте расшифровки разговоров для улучшения персоны вашего agent
- Отслеживайте потраченные credit для контроля паттернов использования

## Частые вопросы

**В: Как найти разговоры с определённого канала?**

Используйте фильтр Channel в верхней части списка разговоров, чтобы выбрать конкретную платформу, например Telegram, Discord или Slack.

**В: Можно ли экспортировать несколько разговоров одновременно?**

В настоящее время экспорт работает по одному разговору за раз. Экспортируйте каждый разговор отдельно из вкладки Messages.

**В: Что делает "Generate Insights"?**

Функция использует ИИ для анализа разговора и предоставления сводки, включающей ключевые моменты, намерения пользователя, важную обменённую информацию и рекомендуемые действия.

**В: Стоят ли ИИ-инсайты credit?**

Да, генерация инсайтов потребляет credit с вашего аккаунта. Однако результаты кэшируются, поэтому повторный просмотр тех же инсайтов бесплатен.

**В: Как долго хранятся разговоры?**

Разговоры хранятся в безопасности и доступны для аналитики. Свяжитесь с поддержкой, если у вас есть вопросы о хранении данных.
