# Метрики использования

Отслеживайте потребление ресурсов и использование credit.

## Обзор использования credit

Панель аналитики показывает использование за текущий billing цикл:

- **Credits Used** — credit платформы, потреблённые за этот период
- **Credits Remaining** — доступные credit до конца периода
- **Usage Percentage** — визуальный индикатор прогресса потребления

## Ключевые метрики

### Объём запросов

| Метрика | Описание |
|---------|----------|
| Total Queries | Выполнения ИИ agent за период |
| Conversations | Общее количество сеансов чата |
| Unique Users | Уникальные пользователи, которые взаимодействовали |

### Распределение

Просматривайте, как распределяется использование:

- **По Agent** — какие agent обрабатывают больше всего запросов
- **По Channel** — использование по Telegram, Discord, Slack, WhatsApp и др.

## Тенденции использования

### График объёма запросов

Основная панель аналитики отображает график объёма запросов, показывающий:
- Запросы во времени
- Настраиваемую детализацию (по часам, дням, неделям, месяцам)
- Выбор диапазона дат

### Диаграммы распределения

Круговые диаграммы, показывающие:
- Распределение по каналам — процент запросов на каждую платформу
- Распределение по agent — процент запросов на каждый agent

## Предупреждения об использовании

Страница **Billing** отображает автоматические предупреждающие баннеры, когда:

- **Приближение к лимиту** — вы использовали большую часть месячной квоты
- **Лимит достигнут** — месячная квота исчерпана
- **Заблокировано** — баланс дополнительного использования также исчерпан

Эти предупреждения появляются в **Billing & Plans**, чтобы помочь вам принять меры до того, как это повлияет на сервис.

## Советы по оптимизации

### Сокращение использования запросов

- Улучшите персоны agent для повышения точности первого ответа
- Добавьте контент FAQ для уменьшения уточняющих вопросов
- Оптимизируйте контент для ускорения поиска

### Мониторинг областей с высоким использованием

- Проверяйте, какие agent потребляют больше всего credit
- Определяйте каналы с наибольшим объёмом
- Просматривайте разговоры, использующие больше token
