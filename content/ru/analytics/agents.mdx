# Аналитика Agent

Просматривайте подробные метрики производительности всех ваших агентов. Сравнивайте объёмы запросов, разговоры и расход кредитов по всему портфелю агентов.

## Доступ к аналитике Agent

1. Перейдите в раздел **Analytics** на боковой панели
2. Нажмите **View All** рядом с "Top Agents", или
3. Перейдите напрямую в **Analytics > Agents**

## Навигация

Хлебные крошки показывают ваше местоположение: **Dashboard / Agents**. Нажмите "Dashboard", чтобы вернуться на главную страницу аналитики.

## Управление диапазоном дат

| Элемент | Описание |
|---------|----------|
| **Last 7 days** | Метрики за последнюю неделю |
| **Last 14 days** | Метрики за две недели |
| **Last 30 days** | Метрики за последний месяц |
| **Last 90 days** | Метрики за последний квартал |
| **Refresh** | Обновить данные актуальными значениями |

## Таблица агентов

Все ваши агенты с метриками производительности:

| Столбец | Описание | Сортируемый |
|---------|----------|-------------|
| Agent | Имя агента | Нет |
| Status | active, inactive, testing или archived | Нет |
| Queries | Общее количество отвеченных вопросов | Да |
| Conversations | Сессии чата | Да |
| Credits | Израсходованные ресурсы | Да |
| Channels | На каких каналах используется агент | Нет |
| (Стрелка) | Ссылка на подробный просмотр | Нет |

### Сортировка

Нажмите на заголовок любого сортируемого столбца для сортировки по этой метрике:
- **Первый клик**: сортировка по убыванию (наибольшие значения сверху)
- **Второй клик**: сортировка по возрастанию (наименьшие значения сверху)
- Активный столбец сортировки выделен

### Пагинация

Для больших списков агентов:
- Отображается "Showing X - Y of Z"
- Используйте кнопки **Previous/Next** для навигации по страницам

## Значки статуса агента

| Значок | Цвет | Значение |
|--------|------|----------|
| active | Green | Агент развёрнут и получает запросы |
| inactive | Gray | Агент приостановлен |
| testing | Yellow | Агент тестируется перед развёртыванием |
| archived | Yellow | Агент заархивирован |

## Значки каналов

Столбец Channels показывает, на каких платформах используется каждый агент:
- Отображается до 3 значков каналов (например, "web", "telegram", "discord")
- Если каналов больше 3, отображается "+X" для указания дополнительных каналов

## Просмотр деталей агента

Нажмите на стрелку в строке любого агента, чтобы увидеть:
- Подробные метрики для этого конкретного агента
- Графики временных рядов
- Разбивку по каналам
- Более детальные данные

## Советы

- Сортируйте по **Credits**, чтобы найти наиболее ресурсоёмких агентов
- Сортируйте по **Queries**, чтобы определить самых популярных агентов
- Используйте **90 days** для анализа долгосрочных тенденций
- Проверяйте агентов со статусом inactive — возможно, их стоит реактивировать
- Переходите к отдельным агентам для более глубокого анализа

## Частые вопросы

**В: Как найти наиболее используемого агента?**

Нажмите на заголовок столбца "Queries" для сортировки по количеству запросов. Верхняя строка — ваш самый активный агент.

**В: Что означают значки каналов?**

Они показывают, с каких платформ (Web, Telegram, Discord, Slack и др.) каждый агент получает запросы.

**В: Почему у агента отображается ноль запросов?**

Агент может быть новым, неактивным или ещё не подключённым ни к одному каналу.
