# Аналитика

Отслеживайте производительность ваших agent и понимайте, как пользователи взаимодействуют с вашими чат-ботами.

## Обзор

Аналитика помогает вам:
- Отслеживать объём разговоров и паттерны запросов
- Контролировать производительность agent и использование credit
- Понимать распределение по каналам
- Выявлять области для улучшения

## Панель управления

Откройте аналитику в разделе **Analytics** на боковой панели.

### Ключевые метрики

| Метрика | Описание |
|---------|----------|
| Total Queries | Выполнения agent (ответы ИИ) |
| Conversations | Количество сеансов чата |
| Unique Users | Уникальные пользователи, которые общались |
| Credits Used | Потреблённые credit платформы |

### Использование credit

Панель управления показывает потребление credit за текущий billing цикл:
- Использованные credit в сравнении с выделенными
- Индикатор прогресса в процентах
- Оставшиеся credit за период

### Графики

Панель управления включает визуальные графики:
- **Query Volume** — линейный график запросов во времени
- **Channel Distribution** — круговая диаграмма распределения запросов по каналам
- **Agent Distribution** — круговая диаграмма распределения запросов по agent

### Лучшие Agent

Ранжированный список ваших наиболее активных agent, показывающий:
- Имя и ранг agent
- Общее количество обработанных запросов
- Количество разговоров
- Потреблённые credit
- Текущий статус (active, inactive, testing, archived)

Нажмите на любой agent, чтобы просмотреть подробную аналитику, или нажмите **View All**, чтобы увидеть все agent.

### Лучшие каналы

Ранжированный список ваших наиболее активных каналов связи, показывающий:
- Название и ранг канала
- Общее количество обработанных запросов
- Количество разговоров
- Потреблённые credit

Нажмите на любой канал, чтобы просмотреть подробную аналитику, или нажмите **View All**, чтобы увидеть все каналы.

## Временные периоды

Просматривайте аналитику за различные временные диапазоны:
- Текущий billing цикл
- Последние 7 дней
- Последние 14 дней
- Последние 30 дней
- Последние 90 дней

## Детализация

Настройте группировку данных:
- По часам
- По дням
- По неделям
- По месяцам

## Фильтрация

Фильтруйте аналитику по:
- **Agent** — просмотр метрик для конкретных agent
- **Channel** — сравнение производительности на разных платформах
- **Date range** — анализ конкретных временных периодов

## Использование аналитики

### Выявление паттернов

Посмотрите, какие каналы и agent обрабатывают больше всего запросов, чтобы:
- Оптимизировать распределение ресурсов
- Сосредоточить улучшения там, где это необходимо
- Понять предпочтения пользователей

### Мониторинг производительности

Отслеживайте тенденции, чтобы убедиться, что:
- Использование credit остаётся в пределах лимитов
- Вовлечённость пользователей на здоровом уровне
- Нет необычных паттернов

### Оптимизация Agent

Используйте инсайты, чтобы:
- Настроить персоны agent
- Добавить недостающую документацию
- Улучшить точность ответов
