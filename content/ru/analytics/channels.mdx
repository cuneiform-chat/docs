# Аналитика каналов

Просматривайте метрики производительности в разбивке по каналам. Сравнивайте объёмы запросов, разговоры, уникальных пользователей и расход кредитов по всем платформам, на которых ваши агенты получают запросы.

## Доступ к аналитике каналов

1. Перейдите в раздел **Analytics** на боковой панели
2. Нажмите **View All** рядом с "Channel Distribution", или
3. Перейдите напрямую в **Analytics > Channels**

## Навигация

Хлебные крошки показывают ваше местоположение: **Dashboard / Channels**. Нажмите "Dashboard", чтобы вернуться на главную страницу аналитики.

## Управление диапазоном дат

| Элемент | Описание |
|---------|----------|
| **Last 7 days** | Метрики за последнюю неделю |
| **Last 14 days** | Метрики за две недели |
| **Last 30 days** | Метрики за последний месяц |
| **Last 90 days** | Метрики за последний квартал |
| **Refresh** | Обновить данные актуальными значениями |

## Сводные карточки

Четыре карточки с агрегированными метриками по всем каналам:

| Карточка | Описание |
|----------|----------|
| Total Channels | Количество активных каналов |
| Total Queries | Сумма запросов по всем каналам |
| Total Conversations | Сумма разговоров по всем каналам |
| Total Credits | Сумма израсходованных кредитов по всем каналам |

## Таблица каналов

Все ваши активные каналы с метриками производительности:

| Столбец | Описание |
|---------|----------|
| Channel | Название канала с цветным значком |
| Queries | Общее количество отвеченных вопросов на этом канале |
| Conversations | Сессии чата на этом канале |
| Unique Users | Уникальные пользователи, взаимодействовавшие через этот канал |
| Credits | Ресурсы, израсходованные этим каналом |
| % of Total | Визуальная шкала, показывающая долю этого канала в общем количестве запросов |
| (Стрелка) | Ссылка на подробный просмотр канала |

## Типы каналов

Ваши агенты могут получать запросы с различных платформ:

| Канал | Описание |
|-------|----------|
| Playground | Запросы из интерфейса тестирования агентов |
| Telegram | Интеграция с ботом Telegram |
| Discord | Интеграция с ботом Discord |
| Slack | Интеграция с приложением Slack |
| Meta | Интеграция с Meta/Messenger |
| WhatsApp | Интеграция с WhatsApp Business |
| Google Chat | Интеграция с Google Chat (Workspace) |

## Просмотр деталей канала

Нажмите на стрелку в строке любого канала, чтобы увидеть:
- Подробные метрики для этого конкретного канала
- Графики временных рядов с настройками детализации (Hourly, Daily, Weekly, Monthly)
- Разбивку по агентам внутри этого канала

## Советы

- Сравнивайте **% of Total**, чтобы понять, какие каналы генерируют наибольший трафик
- Используйте этот раздел для выявления каналов с низкой эффективностью, требующих внимания
- Проверяйте **Unique Users**, чтобы оценить охват аудитории на каждой платформе
- Просматривайте **Credits**, чтобы видеть расход ресурсов по каналам

## Частые вопросы

**В: Почему я не вижу все каналы в списке?**

В таблице отображаются только каналы, имеющие хотя бы один запрос за выбранный период.

**В: Как рассчитывается процент?**

Процент показывает долю каждого канала в общем количестве запросов по всем каналам за выбранный период.

**В: Можно ли сравнивать каналы во времени?**

Нажмите на конкретный канал, чтобы увидеть его данные и тенденции за различные периоды.
