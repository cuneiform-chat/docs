# Commerce

**Подключите магазин — и ваши agents перестанут гадать.** Вместо ответов по документу, который кто-то обновлял в прошлом квартале, они читают ваш настоящий каталог, ваши настоящие остатки и ваши настоящие заказы — в тот момент, когда покупатель спрашивает.

Cuneiform Chat подключается к двум коммерческим платформам и относится к ним как к равным:

- **[Shopify](/commerce/shopify)** — устанавливается из Shopify App Store и работает как встроенное приложение внутри вашей админки Shopify.
- **[WooCommerce](/commerce/woocommerce)** — подключается к вашему самостоятельно размещённому магазину через WooCommerce REST API.

| **Рекомендации** | «А что к этому подойдёт?» — подсказки только из того, что действительно в наличии | [Каталог и знания](/commerce/catalog-and-knowledge) |

| **Commerce Analytics** | Что покупатели искали, что им показали и на чём они остановились | [Аналитика](/commerce/analytics) |

## Две платформы, один набор возможностей

Shopify и WooCommerce здесь равны — это не основной вариант и запасной. Все возможности из таблицы выше работают на обеих. Там, где поведение действительно различается, различается сама платформа, и каждое отличие описано на той странице, которая его касается:

| Отличие | Shopify | WooCommerce |
|---|---|---|
| **Как подключаться** | Установить из Shopify App Store, затем привязать рабочее пространство изнутри встроенного приложения | Ввести URL магазина и подтвердить одноразовую авторизацию либо вставить ключи API вручную |
| **Повторная авторизация позже** | Шага переподключения нет — изменения прав приходят вместе с самим приложением | **Reconnect** заново запускает подтверждение в вашем магазине |
| **Первичная синхронизация каталога** | Запускается автоматически при подключении | Запускается автоматически при пошаговом подключении; для ручных ключей нужен **Re-sync now** — см. [WooCommerce](/commerce/woocommerce#after-a-manual-connect) |
| **Свежесть остатков** | Отдельные события об остатках, поэтому изменение только остатка приходит само по себе, обычно за считанные секунды | Изменения остатков приходят вместе с обновлениями товара, поэтому изменение только остатка ждёт следующей правки товара или сверки |
| **Передача на checkout** | Одна ссылка на корзину со всеми позициями | Зависит от прав, которые несут ваши ключи — см. [Checkout](/commerce/checkout) |

## Можно подключить обе сразу [#you-can-connect-both-at-once]

Один магазин на платформу и на рабочее пространство — и **магазин Shopify и магазин WooCommerce могут быть подключены одновременно**. Именно так выглядит мультимагазинная конфигурация на практике: не пять магазинов Shopify, а магазин Shopify и магазин Woo рядом друг с другом.

Когда подключены оба, **у каждого магазина появляется свой магазинный agent**, и каждый agent отвечает по своему магазину. Покупатель, который общается с магазинным agent вашего Shopify, получает товары и заказы Shopify; agent WooCommerce отвечает по WooCommerce. В один общий каталог они не сводятся. Аналитика тоже держит их раздельно, с переключателем платформы.

<Callout type="warning">
  Магазин может быть подключён только к одному рабочему пространству одновременно. Если кто-то уже подключил этот же магазин в другом месте, попытка подключения отклоняется с сообщением о том, что сначала нужно отключить его там.
</Callout>

## Ваш магазинный agent [#your-store-agent]

Commerce не включается для всех agents сразу. Когда вы подключаете магазин, **один agent становится вашим магазинным agent** — и именно он несёт коммерческие инструменты и читает ваш каталог.

Этого agent выбираем мы, а не вы. Если вы уже подключали этот же магазин раньше, его прежний магазинный agent возвращается вместе с настройками и историей версий; иначе создаётся новый. Отдельного переключателя для каждого agent здесь нет: магазинный agent показывается на странице самого agent как панель только для чтения «управляется вашим магазином», так что всегда понятно, какой agent связан с каким магазином.

<Callout type="info">
  Если в вашем рабочем пространстве уже израсходован лимит agents, места для магазинного agent не остаётся. Процесс подключения скажет об этом и попросит **перейти на более высокий тариф либо архивировать неиспользуемого agent и подключить магазин заново**, чтобы завершить настройку. Это единственная точка, где ваши лимиты касаются коммерции, и связана она с количеством agents, а не с самой коммерцией.
</Callout>

## С чего начать

1. **Выберите платформу.** Следуйте инструкции [Shopify](/commerce/shopify) или [WooCommerce](/commerce/woocommerce) — процессы подключения довольно разные, результат одинаковый.
2. **Дайте каталогу синхронизироваться.** Первый импорт подтягивает товары, варианты, цены, изображения и остатки. См. [Каталог и знания](/commerce/catalog-and-knowledge).
3. **Задайте магазинному agent вопрос по каталогу.** «Какие размеры есть у льняной рубашки?» — самый быстрый способ убедиться, что всё заработало.
4. **Включите то, что нужно.** [Уведомления о статусе заказа](/commerce/orders#order-status-updates), [чат с покупками](/commerce/shoppable-chat), [опрос Product Finder](/commerce/product-tools#product-finder) — каждое из них независимо.
