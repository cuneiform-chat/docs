# Billing и Plans

Управляйте подпиской и разбирайтесь в billing.

## Обзор

Cuneiform Chat предлагает гибкие планы для ваших потребностей:
- **Trial** — Попробуйте платформу бесплатно
- **Starter** — Для команд на старте
- **Plus** — Для растущего бизнеса
- **Enterprise** — Для масштабных внедрений

## Billing Dashboard

Перейдите в раздел **Billing** в боковой панели:

- Текущий план и статус
- Использование за период
- История транзакций (вкладка Payments)
- Настройки Extra Usage

## Быстрые действия

| Действие | Расположение |
|----------|-------------|
| Посмотреть текущий план | Вкладка Overview |
| Повысить план | Кнопка Change Plan |
| Посмотреть транзакции | Вкладка Payments |
| Пополнить Extra Usage | Раздел Extra Usage |

## Billing Cycle

- Планы оплачиваются ежемесячно
- Использование сбрасывается в начале каждого billing-периода
- Повышение плана вступает в силу немедленно
- Понижение плана вступает в силу в конце billing-периода (изменения плана заблокированы до этого момента)

## Способы оплаты

Принимаемые способы оплаты:
- Кредитные карты (Visa, Mastercard, Amex)
- Дебетовые карты
