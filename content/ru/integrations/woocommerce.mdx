# Интеграция с WooCommerce

Подключите свой самостоятельно размещённый магазин **WooCommerce**, чтобы ваш AI agent мог отвечать на вопросы о товарах, находить заказ покупателя, рекомендовать товары в наличии и отправлять обновления статуса заказа — всё это на основе ваших реальных, актуальных данных о каталоге и заказах.

## Обзор

Интеграция с WooCommerce связывает ваш самостоятельно размещённый магазин с вашими AI agents через WooCommerce REST API. WooCommerce — это ваш бэкенд коммерции; ваш agent Cuneiform — это разговорный слой во всех каналах, куда вы его подключаете. После подключения agent может:

- **Вопросы по каталогу** — отвечает на основе ваших реальных товаров, вариантов, цен и текущего наличия
- **Проверка заказа (WISMO)** — позволяет покупателям узнать «где мой заказ?», указав номер заказа и e-mail или телефон из заказа
- **Рекомендации** — предлагает товары, которые действительно **в наличии**
- **Обновления статуса заказа** — отправляет покупателям, которые подписались, уведомления о доставке в том же чате
- **Актуальный остаток** — всегда считывает цены и остатки в момент ответа
- **Передача к оформлению** — направляет готового к покупке покупателя в ваше собственное оформление заказа WooCommerce

## Предварительные требования

- **Самостоятельно размещённый магазин WooCommerce**, которым вы управляете
- **URL вашего магазина** (например, `https://your-store.com`)
- Как минимум **один agent**, который станет вашим коммерческим agent (можно создать нового в процессе подключения)

Вам **не** нужно устанавливать плагин или писать код. Стандартный процесс подключения — это одноразовое подтверждение; consumer key/secret только для чтения нужны только если ваш магазин за файрволом.

## Шаги Настройки

### 1. Откройте Commerce

В панели администратора перейдите в **Commerce** и выберите **WooCommerce**. Commerce — единый дом интеграции: карточка подключения, ваша **Product Library**, **Settings** и **Analytics** — всё здесь.

### 2. Подключите магазин

Введите URL магазина и нажмите **Connect**. Вы подтвердите одноразовую авторизацию WooCommerce REST API в своём магазине и вернётесь в **Commerce**. Если магазин за файрволом, который блокирует перенаправление, разверните **Enter API keys manually** и вставьте consumer key и secret **только для чтения** (созданные в WooCommerce → Settings → Advanced → REST API).

### 3. Выберите коммерческого agent

Коммерция **включается для каждого agent отдельно** и **выключена по умолчанию**. При подключении выберите **единственного** agent, который станет вашим коммерческим agent — существующего активного или нового. Только этот agent получает инструменты WooCommerce; остальные agents не затрагиваются. Позже это можно изменить в **Commerce → Settings**.

### 4. Дайте каталогу синхронизироваться

Подключение запускает одноразовый импорт ваших товаров, вариантов, цен, изображений и остатков. После этого изменения синхронизируются автоматически, а ежедневная сверка подхватывает всё пропущенное.

### 5. Попробуйте

Откройте своего коммерческого agent и задайте вопрос по каталогу («какие размеры у этого товара?», «синий в наличии?») или проверьте заказ («где мой заказ #1001?»). Agent отвечает на основе ваших актуальных данных WooCommerce.

## Как Это Работает

```
Покупатель задаёт вопрос
  → Коммерческий agent читает ваш актуальный каталог и заказы WooCommerce (только чтение)
  → Отвечает о товарах, остатках и статусе заказа
  → Передаёт в ваше собственное оформление заказа WooCommerce для покупки
```

Agent читает ваши товары, цены, остатки и заказы напрямую через WooCommerce REST API и поддерживает цены и остатки в актуальном состоянии — без копирования каталога в базу знаний.

## Возможности

### Только для чтения по замыслу

Интеграция только **читает** из WooCommerce (товары, остатки, заказы). Она никогда не меняет ваш каталог или остатки, никогда не принимает платежи и никогда не создаёт заказы. Оформление всегда происходит в вашем собственном магазине WooCommerce.

### Один магазин, один коммерческий agent

Вы подключаете **один магазин WooCommerce на организацию** и предоставляете коммерцию **ровно одному agent** при подключении. Остальные agents остаются некоммерческими, пока вы не включите их в **Commerce → Settings**.

### Проверенный поиск заказа

Покупатели видят детали заказа только после указания точного номера заказа **и** e-mail или телефона из заказа. Неверный контакт и несуществующий заказ возвращают один и тот же ответ «не найдено» без деталей — защита от перебора, оберегающая ваших клиентов.

### Актуальный каталог и остатки

Agent читает цены и остатки в момент ответа, поэтому рекомендации ограничены товарами, которые действительно в наличии. Ежедневная сверка исправляет всё, что пропустила синхронизация.

### Уведомления о статусе заказа по подписке

После того как покупатель подтвердил свой заказ в чате, он может подписаться на уведомления о доставке в поддерживаемом канале. Уведомления отправляются только если вы включили их в **Commerce → Settings → Notifications** и покупатель подписался.

## Безопасность

- **Доступ только для чтения** — интеграция не может создавать, изменять или удалять что-либо в вашем магазине, менять остатки или принимать платежи
- **Изоляция по организации** — ваш каталог и заказы принадлежат только вашей организации и никогда не видны другим арендаторам
- **Проверенный поиск заказа** — детали заказа требуют точного номера заказа и соответствующего e-mail или телефона (защита от перебора)
- **Уведомления по подписке** — обновления о доставке требуют явной подписки каждого покупателя в чате
- **Безопасное оформление** — покупки завершаются в вашем собственном оформлении WooCommerce; никакие данные карты или платежа не проходят через agent

## Устранение Неполадок

### Подключение зависает или не удаётся

Для подключения сервер должен достучаться до URL вашего магазина и — для стандартного процесса — вы должны завершить одноразовую авторизацию в магазине. Если процесс зависает, обычно это проблема сети или файрвола при доступе к магазину, а не ваших учётных данных. Если магазин за файрволом, подключитесь с consumer key/secret **только для чтения** (**Enter API keys manually**).

### Agent не отвечает на вопросы о товарах

Коммерция **выключена по умолчанию** и предоставляется одному agent при подключении. Если конкретный agent не отвечает на вопросы каталога, откройте **Commerce → Settings** и включите его переключатель коммерции.

### Каталог пуст сразу после подключения

Первый импорт наполняет весь ваш каталог и может занять несколько минут для большого магазина. После завершения товары становятся доступны для поиска; далее изменения синхронизируются автоматически.

### Цена или остаток выглядят устаревшими

Agent читает цены и остатки заново каждый раз, поэтому они не должны устаревать. В редком случае пропущенной синхронизации ежедневная сверка исправляет каталог автоматически.

### Поиск заказа не находит заказ

Инструмент поиска заказа намеренно строг: он возвращает детали только когда покупатель указывает точный номер заказа **и** e-mail или телефон, соответствующий заказу.

### Уведомления о статусе заказа не отправляются

Уведомления требуют выполнения двух условий: включите их в **Commerce → Settings → Notifications** и попросите покупателя подписаться в чате в поддерживаемом канале.

## Частые Вопросы

### Нужен ли платный план для подключения WooCommerce?

Нет. Интеграция с WooCommerce работает на всех планах, включая бесплатный пробный период. Вы можете подключить магазин и использовать вопросы по каталогу, поиск заказа, рекомендации и уведомления о статусе заказа на любом плане.

### Нужно ли устанавливать плагин?

Никакого плагина. Стандартный процесс — одноразовое подтверждение: введите URL магазина и подтвердите авторизацию WooCommerce REST API только для чтения. Consumer key/secret **только для чтения** вставляются только если файрвол вашего магазина блокирует автоматическое перенаправление.

### Могут ли все мои agents использовать WooCommerce, или только один?

Коммерция включается для каждого agent отдельно и выключена по умолчанию. При подключении вы предоставляете коммерцию **одному** agent; только этот agent получает инструменты WooCommerce. Позже можно включить коммерцию для других agents в **Commerce → Settings**.

### Что интеграция делает с данными моего магазина?

Она читает ваш каталог, остатки и заказы, чтобы отвечать на вопросы и отправлять уведомления по подписке. Она только для чтения — никогда не меняет ваш магазин, не меняет остатки и не принимает платежи. Оформление всегда происходит в вашем собственном магазине WooCommerce.

### Меняет ли agent мой магазин или создаёт заказы?

Нет. Интеграция строго только для чтения. Она никогда не редактирует товары, не корректирует остатки и не создаёт и не оплачивает заказы от имени покупателя — эти действия всегда происходят в вашем собственном магазине WooCommerce.
