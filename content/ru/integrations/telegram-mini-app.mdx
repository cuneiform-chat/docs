# Telegram Mini App (Help Center)

Каждый подключённый Telegram-бот идёт со встроенным **Help Center** — небольшим Mini App, который открывается внутри Telegram, когда конечные пользователи нажимают на кнопку меню рядом с полем ввода сообщения. Используйте его, чтобы публиковать FAQ-записи, отвечающие на распространённые вопросы без затрат LLM, плюс кнопки-шорткаты, которые отправляют заранее написанные вопросы вашему агенту.

## Обзор

Telegram Mini App Help Center предоставляет:

- Сортируемый список FAQ, который конечные пользователи открывают одним нажатием внутри Telegram
- Два режима записей — **curated** (отрендеренный markdown-ответ, нулевая стоимость AI) и **agent** (заранее написанный вопрос, отправляемый в обычный pipeline бота)
- Автоматически настроенную кнопку chat-menu — без настройки BotFather для базового потока
- Доступность на всех планах, включая бесплатный trial
- Locale-aware UI (английский, испанский, португальский, французский — fallback на английский)

## Как это работает для конечных пользователей

Когда кто-то открывает ваш Telegram-бот, он видит небольшую кнопку **меню** рядом с полем ввода (Telegram отображает её либо как иконку из четырёх точек, либо как имя бота). При нажатии Help Center Mini App открывается на полный экран внутри Telegram.

Пользователь видит:

- Сортируемый список FAQ-записей, которые вы создали
- Поле поиска для фильтрации записей
- Два визуальных режима для каждой записи:
  - **Curated entries** — нажмите, чтобы прочитать ответ inline (отрендеренный markdown, без чат-трафика)
  - **Agent entries** — нажмите, чтобы отправить заранее написанный вопрос вашему агенту в чат (Mini App закрывается, и вопрос появляется как обычное пользовательское сообщение)

Конечные пользователи никогда не покидают Telegram. Весь опыт работает внутри встроенного WebView Telegram.

## Предварительные требования

- Подключённая [интеграция с Telegram](/integrations/telegram) (Help Center работает поверх неё — отдельной интеграции «Mini App» добавлять не нужно)
- Хотя бы одна help-запись, чтобы Help Center был полезен

## Шаги настройки

### 1. Подключите Telegram-бота (если ещё не подключили)

Следуйте [руководству по настройке Telegram](/integrations/telegram). Mini App активируется автоматически, как только бот подключён — платформа от вашего имени вызывает Telegram API `setChatMenuButton`, чтобы настроить кнопку меню.

### 2. Создавайте записи Help Center

1. В Cuneiform Chat перейдите в **Integrations** в боковой панели
2. Найдите карточку вашего Telegram-бота и откройте меню из трёх точек
3. Выберите **Help Center**
4. Нажмите **Add entry** и выберите режим:
   - **Curated** — напишите вопрос (метку плитки) и markdown-ответ
   - **Agent** — напишите вопрос (метку плитки) и текст вопроса, который должен быть отправлен боту
5. Сохраните

Можно создать до 50 записей на бота. Перетаскивайте записи для изменения порядка — порядок на карточке совпадает с тем, что видят конечные пользователи в Mini App.

<Callout type="info">
  Изменения попадают в Mini App в течение ~5 минут (server cache). В большинстве сессий редактирования вы не заметите задержку — записи, которые вы сохраняете, видны конечным пользователям к моменту, когда вы заканчиваете следующую.
</Callout>

### 3. Протестируйте

1. Откройте бота в Telegram (DM)
2. Нажмите кнопку **меню** рядом с полем ввода
3. Откроется Help Center — вы должны увидеть свои записи в порядке создания
4. Нажмите curated-запись — ответ отрендерится inline
5. Нажмите agent-запись — Mini App закроется и вопрос появится в чате с ботом

## Возможности

### Режим Curated (нулевая стоимость AI)

Ответ curated-записи — это просто markdown, который вы написали в админ-панели. Нажатие на запись отрендерит этот markdown в Mini App — без вызова LLM, без токенов, без списаний. Используйте curated-записи для evergreen FAQ (политика возврата, часы работы, страницы цен и т. д.), где ответ меняется редко.

### Режим Agent (заранее написанные шорткаты)

У agent-записи нет inline-ответа. При нажатии Mini App закрывается и заранее написанный вопрос отправляется в чат с ботом, как если бы пользователь его набрал. Вопрос проходит через обычный pipeline вашего агента — то же содержимое, те же инструменты, тот же тон.

Используйте agent-записи для вопросов, которые вы хотели бы, чтобы пользователи задали, но не могут легко сформулировать («Помоги выбрать план», «Сравни ваши продукты» и т. д.).

### Поиск

Пользователи могут фильтровать список записей, набирая текст в поле поиска. Совпадение ищется по вопросу записи (метка плитки).

### Locale-aware UI

Chrome Mini App (placeholder поля поиска, навигация) следует языковой настройке Telegram каждого конечного пользователя. Сейчас локализован на:

- Английский
- Испанский (es)
- Португальский (бразильский)
- Французский

Другие языки Telegram возвращаются к английскому.

<Callout type="info">
  *Содержимое* Help Center (ваши вопросы и ответы записей) сегодня одноязычное per entry — что вы пишете, то и видит каждый пользователь. Per-locale варианты содержимого — в roadmap.
</Callout>

### Опционально: ссылка direct-launch

Если вам нужна ссылка `t.me/<your_bot>/<your_app>` для маркетинговых кампаний или QR-кодов, карточка интеграции открывает 5-шаговый плейбук BotFather (откройте меню из трёх точек и выберите **Mini App settings**). Кнопка меню Help Center продолжает работать без этого — плейбук только добавляет marketing-friendly форму ссылки.

## Параметры конфигурации

### Настройки записи

| Настройка | Описание |
|---------|-------------|
| Mode | Curated (inline markdown-ответ) или Agent (отправляет заранее написанный вопрос) |
| Question | Метка плитки, которую видят пользователи |
| Answer (только curated) | Markdown, отрендеренный при нажатии |
| Question text (только agent) | Заранее написанный вопрос, отправляемый боту |
| Order | Позиция в списке (перетаскивайте для изменения порядка) |

### Настройки бота

| Настройка | Описание |
|---------|-------------|
| Лимит записей | 50 на бота |
| Cache TTL | ~5 минут (задано на стороне платформы; не настраивается пользователем) |

## Советы

<Callout type="tip">
  **Начинайте с curated-записей.** Они бесплатны для отдачи, мгновенны для пользователей и снижают объём «лёгких» вопросов, попадающих к вашему агенту, оставляя квоту агента на более сложные.
</Callout>

<Callout type="info">
  **Curated-содержимое — это markdown, не HTML.** Жирный, курсив, списки, ссылки и блоки кода рендерятся. Встроенный `<iframe>` или произвольный HTML — нет.
</Callout>

<Callout type="warning">
  Записи в режиме agent отправляют заранее написанный вопрос через обычный pipeline бота — это значит, они расходуют ту же квоту диалогов, что и реальное сообщение пользователя. Для часто используемых кнопок-шорткатов предпочитайте режим curated.
</Callout>

## Устранение неполадок

### Кнопка меню не открывает Help Center

1. Отключите и переподключите интеграцию с Telegram — кнопка chat-menu устанавливается на этапе подключения, и у устаревшего бота она может отсутствовать
2. Убедитесь, что ваш бот — тот, которому пишут пользователи (`t.me/<bot-username>`)
3. Если вы установили кастомную кнопку меню через BotFather, она перезаписывает авто-настройку платформы — очистите её через `/setmenubutton` BotFather

### Созданные записи не появляются

Mini App использует server cache на 5 минут. Подождите несколько минут, затем попросите пользователя переоткрыть кнопку меню (Telegram также кэширует WebView — потяните Mini App вниз для обновления или перезапустите Telegram, чтобы очистить).

### Curated-ответ отображается странно

Mini App рендерит markdown тем же набором инструментов, что и админ-панель — предварительно просмотрите запись в диалоге **Help Center** перед сохранением. Если список или блок кода выглядит неправильно, в исходном markdown обычно не хватает пустой строки.

### «У этого бота нет Mini App»

Это другая функция — Telegram сообщает об отсутствии ссылки direct-launch `t.me/<bot>/<app>`. Кнопка меню Help Center продолжает работать без этой ссылки. Чтобы добавить ссылку direct-launch, откройте диалог Mini App settings на карточке бота и следуйте плейбуку BotFather.

## Отключение

Help Center — часть интеграции с Telegram, поэтому он удаляется при отключении Telegram-бота:

1. **Из Cuneiform Chat:** Integrations → карточка Telegram → меню из трёх точек → **Delete**

Help-записи, которые вы создали, удаляются вместе с интеграцией. Чтобы убрать только кнопку меню, не удаляя интеграцию, нужно установить кастомную кнопку меню через BotFather (`/setmenubutton`) — но большинству пользователей нужна включённая кнопка меню, поэтому это редкость.
