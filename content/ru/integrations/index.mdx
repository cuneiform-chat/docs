# Интеграции

Разворачивайте своих агентов в нескольких каналах и охватывайте пользователей, где бы они ни были.

## Доступные каналы

| Канал | Описание | Лучше всего подходит для |
|-------|----------|--------------------------|
| [Telegram](/ru/integrations/telegram) | Telegram-бот | Мобильные пользователи, сообщества |
| [Discord](/ru/integrations/discord) | Discord-бот с slash-командами | Игровые и девелоперские сообщества |
| [Slack](/ru/integrations/slack) | Slack-приложение | Командные рабочие пространства |
| [WhatsApp](/ru/integrations/whatsapp) | WhatsApp Business | Общение с клиентами |
| [Google Chat](/ru/integrations/google-chat) | Приложение Google Workspace | Корпоративные команды |
| [Meta (Facebook)](/ru/integrations/facebook) | Facebook Messenger | Массовая аудитория |
| [Website Widget](/ru/integrations/website-widget) | Встраиваемый чат-виджет | Поддержка клиентов, любой сайт |

## Как работают интеграции

1. **Настройка** — настройте интеграцию для выбранного канала
2. **Подключение** — свяжите вашего агента с каналом
3. **Развёртывание** — ваш агент становится доступен пользователям
4. **Мониторинг** — отслеживайте диалоги и использование

## Многоканальное развёртывание

Одного агента можно развернуть в нескольких каналах одновременно:

- Одинаковый контент во всех каналах
- Согласованные ответы повсюду
- Централизованная история диалогов
- Единая аналитика

## Возможности каналов

У каждого канала есть уникальные возможности:

- **Telegram** — расширенные сообщения, инлайн-клавиатуры
- **Discord** — slash-команды, интеграция с сервером
- **Slack** — приложения для рабочих пространств, ответы в каналах
- **WhatsApp** — бизнес-сообщения, мультимедиа
- **Google Chat** — интеграция с Google Workspace, поддержка пространств, вопросы по документам + база знаний Space
- **Meta (Facebook)** — интеграция с Messenger, обмен сообщениями через страницу
- **Website Widget** — встраиваемый чат, настраиваемый внешний вид, белый список доменов

## Требования

Перед настройкой интеграций:

1. ✅ Создайте хотя бы одного агента
2. ✅ Загрузите документы в базу знаний
3. ✅ Протестируйте агента в Playground

Для каждого канала могут потребоваться дополнительные настройки (Bot Token, учётные данные приложения и т. д.), описанные в соответствующих руководствах.
