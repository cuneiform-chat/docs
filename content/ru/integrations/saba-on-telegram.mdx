# Saba в Telegram

Подключите выделенного Telegram-бота, чтобы участники вашей организации могли общаться с **Saba** — платформенным ассистентом Cuneiform Chat — прямо в Telegram. Те же ответы и тот же доступ к данным, что и у Saba внутри админ-панели, только на телефоне.

## Обзор

Saba в Telegram позволяет вашей команде:

- Спрашивать Saba об агентах, диалогах, billing, использовании и интеграциях прямо из Telegram DM
- Отправлять голосовые заметки — Saba транскрибирует их и отвечает как на текстовые вопросы
- Нажимать на подсказки follow-up, которые Saba предлагает под каждым ответом
- Переключаться в середине диалога на **Saba Mini App** (более богатую поверхность чата внутри Telegram) через inline-кнопку под каждым ответом
- Использовать slash-команды (`/agents`, `/analytics`, `/usage`, `/billing`, `/integrations`, `/conversations`, `/health`, `/help`, `/new`, `/clear`, `/reset`)

Это **не** канал для конечных пользователей — он предназначен исключительно для участников организации. Конечные пользователи никогда не взаимодействуют с этим ботом.

## Чем это отличается от обычной интеграции с Telegram

| | Telegram | Saba в Telegram |
|---|----------|------------------|
| Кто общается с ботом? | Ваши конечные пользователи | Участники вашей организации (администраторы, операторы) |
| Что он делает? | Запускает вашего AI-агента | Запускает Saba (платформенного ассистента) |
| Где? | DM и групповые чаты | Только личные сообщения |
| Нужна ли привязка для каждого пользователя? | Нет — общаться может любой | Да — каждый участник один раз привязывает свой аккаунт |

Если вы хотите развернуть своего агента для конечных пользователей, см. [Интеграцию с Telegram](/integrations/telegram). Эта страница — про operator-facing бота.

## Предварительные требования

- Аккаунт в Telegram
- Организация хотя бы с одним участником-администратором
- Свежий BotFather-бот, выделенный под Saba (нельзя переиспользовать бота, уже подключённого к обычной интеграции с Telegram — один webhook на бота)

## Шаги настройки

### 1. Создайте выделенного бота в BotFather

1. Откройте Telegram и найдите **@BotFather**
2. Отправьте `/newbot`
3. Выберите имя и username — что-то вроде `acme-saba-bot` ясно даёт понять назначение
4. Скопируйте **Bot Token**, который выдаст BotFather

<Callout type="warning">
  Используйте новый бот. Telegram-бот может указывать только на один webhook за раз, поэтому делить его с customer-facing интеграцией Telegram или с режимом Telegram Business нельзя.
</Callout>

### 2. Подключите бота

1. В Cuneiform Chat откройте **Integrations** в боковой панели
2. Найдите карточку **Saba on Telegram**
3. Нажмите **Connect Saba Bot**
4. Вставьте Bot Token и подтвердите

Платформа проверит токен, зарегистрирует webhook и активирует карточку.

### 3. Привяжите свой аккаунт

Каждому участнику организации нужно один раз привязать свой личный аккаунт Telegram.

1. На карточке Saba on Telegram нажмите **Link my account**
2. Скопируйте 10-минутный код, который появится (или отсканируйте QR-код)
3. Откройте бота в Telegram
4. Отправьте `/start <ваш-код>` — Saba подтвердит привязку

Коды одноразовые и истекают через 10 минут. Если ваш код истёк, нажмите **Link my account** снова, чтобы сгенерировать новый.

### 4. Подключите остальных администраторов

Отправьте коллегам ссылку `t.me/<bot-username>` бота и попросите их:

1. Открыть ту же карточку Saba on Telegram в собственной сессии админ-панели
2. Сгенерировать собственный код привязки
3. Отправить боту в DM `/start <код>`

Аккаунт Telegram каждого привязанного участника связывается с его членством в организации — Saba применяет те же ролевые разрешения, что и внутри админ-панели.

## Использование бота

### Спросите всё, на что Saba может ответить в панели

```
Сколько у меня агентов?
Сколько мы потратили на Telegram на прошлой неделе?
Покажи интеграции с ошибками.
```

Saba читает данные вашей организации и отвечает inline.

### Голосовые заметки

Отправьте голосовую заметку длиной до 2 минут. Whisper транскрибирует её, и Saba отвечает так, будто вы напечатали вопрос. Удобно, когда вы идёте, за рулём или просто не хотите печатать.

### Slash-команды

Введите `/` в чате, чтобы увидеть меню автодополнения. При подключении бота Saba регистрирует набор команд по умолчанию:

| Команда | Что делает |
|---------|--------------|
| `/help` | Показать возможности и список команд |
| `/new`, `/clear`, `/reset` | Начать новый диалог (очищает память разговора) |
| `/agents` | Сводка по вашим агентам |
| `/analytics` | Обзор недавней аналитики |
| `/usage` | Текущее использование и квоты |
| `/billing` | Подписка и недавние списания |
| `/integrations` | Статус всех подключённых каналов |
| `/conversations` | Недавняя активность в диалогах |
| `/health` | Сводка о состоянии рабочего пространства |

### Подсказки follow-up

Каждый ответ Saba заканчивается до тремя кнопками с уточняющими вопросами. Нажмите одну, чтобы отправить её Saba без повторного ввода. Кнопки активны 24 часа после получения ответа.

### Open in Mini App

У каждого ответа также есть кнопка **Open in Mini App**. Нажмите её, чтобы переключиться в Saba Mini App — более богатую поверхность чата внутри Telegram с историей диалогов, деталями вызовов инструментов и экспортом в markdown. Обе поверхности используют один и тот же диалог, поэтому переключаться между ними можно в любой момент.

## Параметры конфигурации

### Resync slash-команд

Если меню slash-команд Telegram рассинхронизировалось (редко — может случиться, если список команд был обновлён на стороне сервера после подключения бота), откройте меню из трёх точек на карточке Saba on Telegram и выберите **Resync slash commands**. Платформа отправит канонический набор в BotFather повторно.

### Отключение

Чтобы удалить интеграцию:

1. **Из Cuneiform Chat:** Integrations → карточка Saba on Telegram → меню из трёх точек → **Delete**
2. **Из Telegram (опционально):** удалите бота через BotFather (`/mybots` → выберите бота → **Delete bot**)

При отключении удаляются все привязки участников и бот перестаёт отвечать. Сам Telegram-бот остаётся в BotFather, пока вы его там не удалите.

## Read-only по дизайну

Saba в Telegram отвечает на вопросы и предоставляет информацию — она **не** изменяет данные вашей организации. Можно спросить «что не работает?», но нельзя сказать «исправь это» через Telegram. Для действий записи — редактирования агента, изменения billing, удаления диалога — используйте админ-панель.

## Советы

<Callout type="info">
  Привязка каждого участника действует на конкретного бота. Если позже вы подключите нового Saba-бота (например, после смены имени бота), участникам понадобится перепривязаться через `/start <код>` нового бота.
</Callout>

<Callout type="info">
  Saba в Telegram использует только личные сообщения. Добавление бота в групповой чат будет просто проигнорировано — это удерживает каждое входящее сообщение привязанным к одному идентифицируемому участнику.
</Callout>

<Callout type="tip">
  Сочетайте Saba в Telegram с Mini App для лучшего опыта: быстрые вопросы в DM, глубокое погружение в Mini App. Один и тот же диалог, разные поверхности.
</Callout>
