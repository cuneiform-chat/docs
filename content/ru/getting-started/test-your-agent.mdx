# Тестирование Agent

Перед развёртыванием agent используйте Playground для проверки ответов и настройки поведения.

## Доступ к Playground

1. Перейдите в раздел **Agents** в боковой панели
2. Нажмите **Test** на карточке agent
3. Playground откроется как боковая панель — начинайте общение!

Используйте переключатель боковой панели, чтобы скрыть список разговоров для большего пространства. Нажмите **Shift+Enter** для добавления новых строк без отправки.

## Тестирование Agent

### Задайте пробные вопросы

Попробуйте вопросы, которые могут задать ваши пользователи:

- Вопросы, на которые напрямую отвечают ваши документы
- Уточняющие вопросы, требующие контекста
- Пограничные случаи и неоднозначные запросы
- Вопросы за пределами вашего контента (для проверки границ)

### Оценка ответов

Для каждого ответа оцените:

- **Точность** — верна ли информация?
- **Релевантность** — отвечает ли на заданный вопрос?
- **Тон** — соответствует ли ожидаемому стилю?
- **Источники** — полезны ли ссылки на документы?

## Доработка Agent

На основе тестирования вы можете захотеть изменить:

### Agent Persona

Если ответы не совсем подходят, доработайте persona:

- Добавьте конкретные инструкции для типичных сценариев
- Уточните тон и характер
- Установите границы того, что agent должен и не должен делать

### Content

Если agent не находит информацию:

- Проверьте, загружены ли соответствующие документы
- Убедитесь, что документы успешно обработаны
- Рассмотрите добавление более детального контента

## История разговоров

Playground сохраняет историю разговоров в рамках сессии. Используйте это для проверки:

- Многоходовых разговоров
- Сохранения контекста
- Уточняющих вопросов

Пока agent отвечает, вы увидите индикаторы инструментов, показывающие его действия (поиск документов, обработка запроса и т.д.). Нажмите **Stop**, чтобы отменить ответ.

## Активация Agent

Новые agent начинают со статусом **Testing** — вы можете тестировать в Playground, но интеграции с каналами отключены.

Чтобы включить интеграции:

1. Откройте страницу редактирования agent
2. Измените **Status** с "Testing" на "Active"
3. Нажмите **Save**

После активации вы можете развернуть agent в различных каналах:

- [Telegram](/ru/integrations/telegram) — подключение к Telegram
- [Discord](/ru/integrations/discord) — добавление на сервер Discord
- [Slack](/ru/integrations/slack) — интеграция с рабочими пространствами Slack
- [WhatsApp](/ru/integrations/whatsapp) — подключение к WhatsApp Business
- [Messenger](/ru/integrations/facebook) — подключение к Facebook Messenger
- [Google Chat](/ru/integrations/google-chat) — интеграция с Google Workspace
