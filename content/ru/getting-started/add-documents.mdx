# Добавление контента

Знания вашего чатбота основаны на предоставленном вами контенте. Это руководство покажет, как загружать документы и сканировать сайты для наполнения контента.

## Доступ к контенту

1. Войдите в панель управления Cuneiform Chat
2. Перейдите в раздел **Content** в боковой панели
3. Нажмите **Upload Documents** или перетащите файлы

## Поддерживаемые форматы

Cuneiform Chat поддерживает широкий спектр форматов документов:

| Формат | Расширения | Примечания |
|--------|-----------|------------|
| PDF | `.pdf` | Текстовые и отсканированные (OCR) |
| Word | `.docx`, `.doc` | Документы Microsoft Word |
| Текст | `.txt`, `.md`, `.rtf` | Обычный текст, Markdown, Rich Text |
| PowerPoint | `.pptx`, `.ppt` | Слайды презентаций |
| Web/Данные | `.html`, `.htm`, `.json`, `.xml` | Веб-страницы и структурированные данные |

## Способы загрузки

### Прямая загрузка

1. Нажмите **Upload Documents**
2. Выберите файлы с компьютера
3. Дождитесь завершения обработки

### Перетаскивание

Просто перетащите файлы с компьютера в область Content.

### Облачное хранилище

Подключите облачное хранилище для удобного импорта:

- **Google Drive** — импорт напрямую из Drive
- **Dropbox** — подключение аккаунта Dropbox
- **OneDrive** — импорт из Microsoft OneDrive
- **Box** — подключение аккаунта Box

Подробнее в разделе [Облачное хранилище](/ru/knowledge-base/cloud-storage).

### Website Crawling

Сканируйте публичные сайты и импортируйте их содержимое как документы:

1. Перейдите в **Content** и откройте вкладку **Website**
2. Введите URL и нажмите **Crawl**
3. Просмотрите и отредактируйте просканированные страницы
4. Выберите страницы и нажмите **Process Selected**

Сканер переходит по ссылкам на глубину до 2 уровней. Количество страниц зависит от вашего [плана](/ru/billing/plans).

Подробнее в разделе [Website Crawling](/ru/knowledge-base/website-crawling).

## Обработка документов

После загрузки или сканирования ваш контент автоматически обрабатывается и становится доступен для поиска вашими agent.

import { Callout } from 'nextra/components'

<Callout type="info">
  Время обработки зависит от размера и сложности документа. Большинство документов обрабатываются за несколько минут. Система автоматически обнаруживает дублирующийся контент, чтобы избежать повторных загрузок.
</Callout>

## Лучшие практики

- **Качество важнее количества** — хорошо структурированные документы дают лучшие ответы
- **Поддерживайте актуальность** — удаляйте устаревшие документы, чтобы избежать путаницы
- **Организуйте папками** — используйте структуру папок для организации документов
- **Сканируйте выборочно** — просматривайте и редактируйте просканированные страницы перед обработкой, чтобы убрать навигацию и шаблонный текст
