# Platform Assistant

Познакомьтесь с Saba — вашим AI-помощником для навигации по Cuneiform Chat.

## Что такое Saba?

Saba — это встроенный AI-ассистент, который помогает вам максимально эффективно использовать Cuneiform Chat. Названный в честь Nisaba — шумерской богини письма и писцового искусства — Saba олицетворяет наш путь от глиняных табличек к чатботам.

Saba может помочь вам:

- Узнать о возможностях платформы и способах их использования
- Получить информацию о ваших agent, документах и интеграциях
- Разобраться в деталях billing и подписки
- Устранить типичные проблемы

## Доступ к Saba

### Плавающая кнопка

Найдите иконку Saba в **правом нижнем углу** экрана. Нажмите на неё, чтобы открыть ассистента.

### Горячие клавиши

| Действие | Mac | Windows/Linux |
|----------|-----|---------------|
| Открыть/Закрыть Saba | `Cmd + K` | `Ctrl + K` |
| Новый разговор | `Cmd + N` | `Ctrl + N` |
| Закрыть | `Escape` | `Escape` |

### Из Telegram

Вы также можете общаться с Saba из Telegram — те же права, тот же доступ к данным, прямо со смартфона. Две поверхности, обе включены в каждый платный тариф:

- **DM-бот** — администратор вашей организации подключает выделенный Telegram-бот ("Saba on Telegram") в админ-панели. Вы привязываете свой аккаунт один раз с помощью 10-минутного кода, а затем общаетесь с ботом в личных сообщениях, как с коллегой. Голосовые сообщения транскрибируются и передаются в Saba.
- **Saba Mini App** — каждый ответ в DM сопровождается inline-кнопкой "Open in Mini App", которая открывает более богатую поверхность чата внутри Telegram (`saba-mini.cuneiform.chat`) с историей разговоров, деталями вызовов инструментов, голосовым вводом в браузере, экспортом в markdown и встроенным переключателем языка.

Ответы Saba в Telegram включают те же интерактивные кнопки действий, что и в панели — нажмите, и вы будете перенаправлены на нужную страницу админ-панели.

Настройка выполняется со стороны администратора. См. [Интеграция Telegram → Saba on Telegram](/integrations/telegram) для процесса подключения.

## Чем Saba может помочь

### Возможности платформы

Задавайте такие вопросы:

- «Как создать agent?»
- «Какие форматы файлов поддерживаются?»
- «Как подключить Slack?»

### Ваши данные

Saba может обращаться к данным вашей организации для ответа на конкретные вопросы:

- «Сколько у меня agent?»
- «Какие документы есть в моём контенте?»
- «Какие интеграции активны?»

### Информация о Billing

Получайте быстрые ответы о вашем аккаунте:

- «На каком я плане?»
- «Сколько кредитов я использовал?»
- «Когда заканчивается платёжный период?»

## Возможности

### Режим запросов

Переключайтесь между режимами ответов с помощью кнопки рядом с полем ввода:

- **Fast** (иконка молнии) — быстрые ответы на простые вопросы
- **Reasoning** (иконка мозга) — более глубокий анализ для сложных вопросов

Ваши предпочтения сохраняются между сессиями.

### Автоматическое определение языка

Saba автоматически определяет язык вашего сообщения и отвечает на том же языке — настройка не требуется. Поддерживается 176 языков, поэтому вы можете просто писать на предпочитаемом языке, и Saba ответит соответственно.

### Голосовой ввод

Нажмите **иконку микрофона** рядом с кнопкой отправки, чтобы задать вопрос голосом вместо набора текста.

### Slash-команды

Введите `/` в поле ввода, чтобы увидеть быстрые команды:

| Команда | Что делает |
|---------|------------|
| `/health` | Обзор состояния вашей организации |
| `/agents` | Список всех agent со статусами |
| `/analytics` | Метрики производительности agent |
| `/usage` | Статистика ежемесячного использования |
| `/billing` | Детали плана и кредитов |
| `/integrations` | Активные интеграции каналов |
| `/conversations` | Недавняя активность разговоров |
| `/help` | Список доступных команд |

### История разговоров

Разговоры с Saba сохраняются автоматически. Получите доступ к прошлым разговорам через боковую панель, чтобы продолжить с того места, где остановились.

### Предлагаемые вопросы

Saba предлагает релевантные вопросы на основе текущей страницы. Они появляются как варианты для быстрого старта при открытии ассистента.

### Предложения для продолжения

После каждого ответа Saba предлагает связанные вопросы, которые вы можете захотеть задать далее.

### Экспорт разговоров

Сохраняйте разговоры с помощью кнопки экспорта:

- **Download as Markdown** — сохранение в формате .md с форматированием
- **Download as Text** — сохранение в формате .txt
- **Copy to Clipboard** — копирование всего разговора

### Обратная связь

Помогите улучшить Saba с помощью отзывов на каждый ответ:

- **Thumbs up/down** — быстрая оценка качества ответа
- **Submit Feedback** — подробные комментарии для улучшения ассистента
