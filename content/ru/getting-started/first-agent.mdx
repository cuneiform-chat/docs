# Создание первого Agent

Agent — это чатботы, которые взаимодействуют с вашими пользователями. Каждый agent может быть настроен с определёнными знаниями, поведением и характером.

## Создание Agent

1. Перейдите в раздел **Agents** в боковой панели
2. Нажмите **Create Agent**
3. Заполните основную информацию:
   - **Name** — описательное имя для agent (например, "Customer Support Bot")
   - **Description** — чем занимается этот agent (для вашей справки)

## Настройка Agent

### Agent Persona

Agent Persona определяет характер и поведение вашего agent. Это инструкция, которая направляет ответы agent.

Вы можете написать собственную persona или нажать **Generate**, чтобы использовать AI-генератор Persona Builder, который создаст её на основе ваших требований.

**Пример:**
```
You are a helpful customer support assistant for Acme Corp.
You answer questions about our products and services based on the provided documentation.
Be friendly, professional, and concise.
If you don't know the answer, say so rather than making something up.
```

### Platform Rules

Все agent автоматически включают встроенные правила безопасности:

- Не выдумывают факты, числа и даты
- Говорят «я не знаю», когда информация недоступна
- Не угадывают недостающую информацию
- Исправляют некорректные предположения в вопросах
- Не выдают себя за профессионалов (юристов, врачей и т.д.)
- Отклоняют вредоносный или неуместный контент

Эти правила всегда активны и не могут быть отключены.

### Контроль доступа к знаниям

Управляйте тем, к каким документам agent имеет доступ:

- **Exclude Mode** (по умолчанию) — agent получает доступ ко всем документам, кроме выбранных для скрытия
- **Include Mode** — agent получает доступ только к выбранным папкам, тегам или документам

Используйте Include Mode, когда хотите ограничить agent определённым набором знаний.

### Настройка LLM

Для большинства пользователей стандартные настройки AI-модели подходят. Продвинутые пользователи могут настроить:

- **Model** — выбор из доступных AI-моделей
- **Temperature** — ниже = более последовательные ответы, выше = более креативные
- **Show Document References** — включите для отображения ссылок на источники в ответах

## Сохранение Agent

Нажмите **Create Agent** для сохранения. Agent начинает со статусом **Testing**, что означает возможность тестирования в Playground, но интеграции с каналами отключены до активации.
