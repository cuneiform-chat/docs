# Создание аккаунта

Начните работу с Cuneiform Chat, создав свой аккаунт.

## Регистрация

1. Перейдите на [cuneiform.chat](https://cuneiform.chat)
2. Нажмите **Get Started** или **Sign Up**
3. Выберите способ входа:
   - **Google** — нажмите "Sign in with Google" для входа в один клик
   - **Microsoft** — нажмите "Sign in with Microsoft" для использования аккаунта Microsoft 365
   - **Email** — введите email и нажмите "Continue with Email"
4. При использовании email проверьте почту и перейдите по magic-ссылке для входа

## Варианты входа

Вы можете войти с помощью:
- **Google** — вход в один клик через аккаунт Google
- **Microsoft** — вход через аккаунт Microsoft 365 или рабочий аккаунт
- **Email magic link** — вход без пароля по ссылке, отправленной на email

## Создание Organization

После первого входа вам нужно создать Organization. Это ваше рабочее пространство для управления agent, документами и интеграциями.

1. На панели управления нажмите **Create Organization**
2. Введите **Workspace Name** (название компании или проекта)
3. По желанию добавьте **Description** вашей организации
4. Выберите **Industry** и **Team Size**
5. Нажмите **Get Started**

Organization помогает вам:

- Управлять несколькими agent в одном аккаунте
- Приглашать участников команды и контролировать доступ
- Отслеживать использование и billing по всем чатботам

Вы можете обновить данные организации в любое время в разделе **Account Management** в меню профиля.

## Ваш бесплатный план

Новые аккаунты начинаются с бесплатного плана Trial, который включает:
- Полный доступ ко всем функциям
- Ежемесячный объём кредитов на обработку документов и AI-запросы
- Кредитная карта не требуется
- Без даты окончания — кредиты обновляются в начале каждого месячного периода
