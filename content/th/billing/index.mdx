# Billing และ Plans

จัดการ subscription ของคุณและทำความเข้าใจ billing

## ภาพรวม

Cuneiform Chat มี plan ที่ยืดหยุ่นตามความต้องการของคุณ:
- **Trial** — ทดลองใช้ platform ฟรี
- **Starter** — สำหรับทีมที่เพิ่งเริ่มต้น
- **Plus** — สำหรับธุรกิจที่กำลังเติบโต
- **Enterprise** — สำหรับการ deploy ขนาดใหญ่

## Billing Dashboard

เข้าถึง billing จากเมนู **Billing & Plans** ใน sidebar:

- plan และ status ปัจจุบัน
- การใช้งานใน period นี้
- ประวัติ transaction
- การตั้งค่า extra usage

## การดำเนินการด่วน

| การดำเนินการ | ตำแหน่ง |
|-------------|---------|
| ดู plan ปัจจุบัน | Overview tab |
| Upgrade plan | Change Plan button |
| ดู transaction | Payments tab |
| เพิ่ม fund สำหรับ extra usage | Extra Usage section |

## Billing Cycle

- Plan เรียกเก็บเงินรายเดือน
- การใช้งานจะ reset เมื่อเริ่มต้น billing period ใหม่
- Upgrade มีผลทันที
- Downgrade มีผลเมื่อสิ้นสุด billing period (ไม่สามารถเปลี่ยน plan ได้จนกว่าจะถึง period ใหม่)

## วิธีการชำระเงิน

วิธีการชำระเงินที่รองรับ:
- บัตรเครดิต (Visa, Mastercard, Amex)
- บัตรเดบิต

## มีคำถาม?

สำหรับคำถามเกี่ยวกับ billing:
- ดูหน้า [แผนและราคา](/billing/plans)
- อ่าน [การใช้งานและเครดิต](/billing/usage) เพื่อทำความเข้าใจการใช้งาน
- ติดต่อ support สำหรับคำถามเกี่ยวกับ billing โดยเฉพาะ
