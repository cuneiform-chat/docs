# Cloud Storage Integration

import { Callout } from 'nextra/components'

Import เอกสารโดยตรงจากบัญชี Cloud Storage ของคุณ เชื่อมต่อ Google Drive, Dropbox, OneDrive หรือ Box เพื่อเพิ่มไฟล์เข้าสู่เนื้อหาโดยไม่ต้องดาวน์โหลดก่อน

## การเข้าถึง

ไปที่ **Content** ในเมนู sidebar ไอคอน Cloud Storage จะปรากฏที่ด้านบนของหน้า ข้างพื้นที่อัปโหลด

## ผู้ให้บริการที่รองรับ

| ผู้ให้บริการ | ตำแหน่งไอคอน | สิ่งที่ import ได้ |
|-------------|-------------|-------------------|
| Google Drive | แถวไอคอน Cloud | ไฟล์, Google Docs, Slides |
| Dropbox | แถวไอคอน Cloud | ไฟล์จาก Dropbox ของคุณ |
| OneDrive | แถวไอคอน Cloud | ไฟล์จาก OneDrive ของคุณ |
| Box | แถวไอคอน Cloud | ไฟล์จากบัญชี Box ของคุณ |

## วิธี Import ไฟล์

### ขั้นตอนที่ 1: คลิกไอคอนผู้ให้บริการ

คลิกไอคอนของผู้ให้บริการ Cloud Storage ของคุณ คุณจะเห็น tooltip แสดงชื่อผู้ให้บริการเมื่อเลื่อนเมาส์ไป

### ขั้นตอนที่ 2: เข้าสู่ระบบ

คุณจะถูกขอให้เข้าสู่ระบบและอนุญาตการเข้าถึง การอนุญาตนี้จะถูกจดจำสำหรับ session ของเบราว์เซอร์

### ขั้นตอนที่ 3: เลือกไฟล์

File picker จะเปิดขึ้นแสดงเนื้อหา Cloud Storage ของคุณ:
- เรียกดูโฟลเดอร์เพื่อค้นหาไฟล์
- เลือกหลายไฟล์พร้อมกัน
- แสดงเฉพาะประเภทไฟล์ที่รองรับ (ตาม plan ของคุณ)

### ขั้นตอนที่ 4: Import

คลิกเพื่อยืนยันการเลือก ไฟล์จะถูกจัดคิวสำหรับ import และเริ่มประมวลผลโดยอัตโนมัติ

## ตัวเลือก Import

ก่อน import คุณสามารถตั้งค่า:

| ตัวเลือก | คำอธิบาย |
|----------|----------|
| Premium Processing | เปิดใช้งานเพื่อให้ AI เข้าใจได้ดียิ่งขึ้น (checkbox ด้านล่างพื้นที่อัปโหลด) |
| Target Folder | อัปโหลดโดยตรงไปยังโฟลเดอร์โดยคลิกไอคอนผู้ให้บริการบนแถวโฟลเดอร์ |

## Import ไปยังโฟลเดอร์ที่ระบุ

คุณสามารถ import ไฟล์จาก Cloud โดยตรงเข้าไปในโฟลเดอร์:

1. ค้นหาโฟลเดอร์ใน document browser
2. เลื่อนเมาส์ไปบนแถวโฟลเดอร์
3. คลิกไอคอน Cloud Storage ที่ปรากฏ
4. เลือกไฟล์จาก Cloud Storage
5. ไฟล์จะถูก import โดยตรงเข้าไปในโฟลเดอร์นั้น

## ระหว่าง Import

- ตัวแสดงความคืบหน้าแสดงสถานะ import
- ไฟล์จะปรากฏในรายการเอกสารเมื่อถูกประมวลผล
- คุณสามารถทำงานต่อได้ขณะที่ไฟล์กำลัง import
- หากตรวจพบรายการซ้ำ คุณจะได้รับการแจ้งเตือนหลัง import เสร็จสิ้น

## ไฟล์ Google Workspace

Google Drive รองรับเอกสาร Google Workspace:
- **Google Docs** — แปลงเป็นข้อความโดยอัตโนมัติ
- **Google Slides** — แปลงเป็นรูปแบบงานนำเสนอโดยอัตโนมัติ

<Callout type="info">
  การจัดรูปแบบและแผนภูมิจะไม่ถูกคงไว้ — เฉพาะเนื้อหาข้อความเท่านั้นที่ถูกดึงออกมา
</Callout>

## สิทธิ์การเข้าถึง

Cuneiform Chat ขอสิทธิ์ขั้นต่ำ:
- สิทธิ์อ่านอย่างเดียวสำหรับไฟล์ที่คุณเลือก
- ไม่มีสิทธิ์เขียนไปยัง Cloud Storage ของคุณ
- ไม่มีการเข้าถึงไฟล์ที่คุณไม่ได้เลือกโดยชัดแจ้ง

<Callout type="info">
  คุณสามารถเพิกถอนสิทธิ์การเข้าถึงได้ตลอดเวลาผ่านการตั้งค่าผู้ให้บริการ Cloud ของคุณ
</Callout>

## พฤติกรรมการ Sync

ปัจจุบัน การ import จาก Cloud เป็น **import ครั้งเดียว**:
- ไฟล์จะถูกคัดลอกในขณะที่ import
- การเปลี่ยนแปลงใน Cloud Storage จะไม่ถูก sync โดยอัตโนมัติ
- หากต้องการอัปเดตเนื้อหา ให้ import ไฟล์ที่แก้ไขใหม่

## เคล็ดลับ

- เลือกหลายไฟล์พร้อมกันเพื่อประหยัดเวลา
- แสดงเฉพาะประเภทไฟล์ที่รองรับใน picker (ตาม plan ของคุณ)
- ใช้ import ระดับโฟลเดอร์เพื่อการจัดระเบียบที่ดีขึ้น
- ไฟล์ขนาดใหญ่อาจใช้เวลาประมวลผลนานขึ้นหลัง import

## คำถามที่พบบ่อย

**ถาม: ต้อง authorize ใหม่ทุกครั้งหรือไม่?**
ตอบ: โดยปกติไม่ต้อง หาก session ยังทำงานอยู่ การคลิกไอคอนจะเปิด file picker โดยตรง คุณอาจต้อง authorize ใหม่เป็นครั้งคราวหลังจากล้างข้อมูลเบราว์เซอร์หรือใช้เบราว์เซอร์ใหม่

**ถาม: สามารถ import ทั้งโฟลเดอร์ได้หรือไม่?**
ตอบ: ปัจจุบันเลือกไฟล์ทีละไฟล์ เรียกดูโฟลเดอร์ใน picker เพื่อเลือกไฟล์ภายใน

**ถาม: เกิดอะไรขึ้นกับไฟล์ต้นฉบับ?**
ตอบ: ไฟล์ใน Cloud ของคุณไม่มีการเปลี่ยนแปลง เราสร้างสำเนาไว้ในเนื้อหาของคุณ

**ถาม: ทำไมไม่เห็นบางไฟล์ใน picker?**
ตอบ: แสดงเฉพาะประเภทไฟล์ที่รองรับ ดู [รูปแบบที่รองรับ](/knowledge-base/supported-formats) สำหรับรูปแบบที่มี

## การแก้ไขปัญหา

### ปัญหาการ authorize

หากเชื่อมต่อไม่ได้:
- ตรวจสอบว่าเข้าสู่ระบบบัญชีที่ถูกต้อง
- ลอง revoke และ authorize การเข้าถึงใหม่
- ตรวจสอบว่าเปิดใช้งานการเข้าถึงแอปของบุคคลที่สามในการตั้งค่าผู้ให้บริการ

### Import ล้มเหลว

หากไฟล์ import ล้มเหลว:
- ตรวจสอบว่าไฟล์อยู่ในรูปแบบที่รองรับ
- ตรวจสอบว่าไฟล์ไม่เสียหาย
- ตรวจสอบว่าคุณมีสิทธิ์เข้าถึงไฟล์
- ลอง import ไฟล์น้อยลงในแต่ละครั้ง
