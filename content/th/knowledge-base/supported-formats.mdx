# รูปแบบที่รองรับ

Cuneiform Chat รองรับรูปแบบเอกสารหลากหลายประเภท

## ประเภทเอกสาร

### เอกสารข้อความ

| รูปแบบ | นามสกุลไฟล์ | หมายเหตุ |
|--------|-------------|----------|
| PDF | `.pdf` | แบบข้อความและสแกน (พร้อม OCR) |
| Microsoft Word | `.docx`, `.doc` | รองรับการจัดรูปแบบเต็มรูปแบบ |
| Plain Text | `.txt` | ไฟล์ข้อความธรรมดา |
| Markdown | `.md` | คงรูปแบบ Markdown ไว้ |
| Rich Text | `.rtf` | รองรับการจัดรูปแบบพื้นฐาน |

### งานนำเสนอ

| รูปแบบ | นามสกุลไฟล์ | หมายเหตุ |
|--------|-------------|----------|
| PowerPoint | `.pptx`, `.ppt` | ดึงเนื้อหาจากสไลด์ |

### เนื้อหาเว็บ

| รูปแบบ | นามสกุลไฟล์ | หมายเหตุ |
|--------|-------------|----------|
| HTML | `.html`, `.htm` | เนื้อหาหน้าเว็บ |

### รูปแบบข้อมูล

| รูปแบบ | นามสกุลไฟล์ | หมายเหตุ |
|--------|-------------|----------|
| JSON | `.json` | ไฟล์ข้อมูลแบบโครงสร้าง |
| XML | `.xml` | เอกสาร XML |

## หมายเหตุเฉพาะรูปแบบ

### PDF

PDF ทำงานได้ดีที่สุดเมื่อ:
- **เป็นแบบข้อความ** — สร้างจากเอกสารดิจิทัล
- **สามารถค้นหาได้** — ข้อความสามารถเลือก/คัดลอกได้

PDF ที่สแกนรองรับแต่อาจมีคุณภาพการดึงข้อความต่ำกว่าเนื่องจากข้อจำกัดของ OCR

### เอกสาร Word

`.docx` (รูปแบบสมัยใหม่) แนะนำเหนือ `.doc` (รูปแบบเก่า) เพื่อผลลัพธ์ที่ดีที่สุด

องค์ประกอบที่รองรับ:
- ข้อความและย่อหน้า
- หัวข้อและสไตล์
- ตาราง
- รายการ

### Markdown

รูปแบบ Markdown คงไว้ระหว่างการประมวลผล:
- หัวข้อกลายเป็นตัวแบ่งส่วน
- รายการคงโครงสร้าง
- code block ถูกจดจำ

## รูปแบบที่ไม่รองรับ

รูปแบบต่อไปนี้ยังไม่รองรับในขณะนี้:
- ภาพ (`.jpg`, `.png`, `.gif`)
- ไฟล์เสียง (`.mp3`, `.wav`)
- ไฟล์วิดีโอ (`.mp4`, `.mov`)
- ไฟล์บีบอัด (`.zip`, `.rar`)
- ไฟล์ปฏิบัติการ (`.exe`, `.app`)

## ขนาดไฟล์สูงสุด

ขนาดไฟล์สูงสุดขึ้นอยู่กับ plan ของคุณ เอกสารขนาดใหญ่มากอาจใช้เวลาประมวลผลนานขึ้น

เพื่อประสิทธิภาพที่ดีที่สุด:
- แบ่งเอกสารขนาดใหญ่มากออกเป็นไฟล์เล็กๆ
- ลบภาพที่ไม่จำเป็นออกจาก PDF หากไม่ต้องการ
- ใช้รูปแบบข้อความเมื่อเป็นไปได้
