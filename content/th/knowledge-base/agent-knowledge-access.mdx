# การเข้าถึงความรู้ของ Agent

ควบคุมว่า agent แต่ละตัวสามารถเข้าถึงเอกสารใดเมื่อตอบคำถาม จำกัด agent ให้เข้าถึงเฉพาะโฟลเดอร์หรือแท็กที่ระบุ หรือยกเว้นเนื้อหาบางอย่างออก

## การเข้าถึง

1. ไปที่ **Agents** ในเมนู sidebar
2. คลิกที่ agent เพื่อแก้ไข หรือสร้าง agent ใหม่
3. เลื่อนไปที่ส่วน **Knowledge Access Control**

## โหมดการเข้าถึง

โหมดการเข้าถึงกำหนดว่าการเลือกของคุณส่งผลต่อการเข้าถึงเอกสารของ agent อย่างไร

| โหมด | ไอคอน | คำอธิบาย | ใช้เมื่อ |
|------|-------|----------|---------|
| **Exclude Mode** | X สีแดง | Agent เข้าถึงเอกสารทั้งหมด ยกเว้นที่เลือก | ต้องการซ่อนเอกสารที่ละเอียดอ่อนแต่อนุญาตเอกสารอื่นทั้งหมด |
| **Include Mode** | เครื่องหมายถูกสีเขียว | Agent เข้าถึง เฉพาะ เอกสารที่เลือก | ต้องการจำกัด agent ให้เข้าถึงเนื้อหาเฉพาะ |

### การเลือกโหมดที่เหมาะสม

**Exclude Mode** (ค่าเริ่มต้น):
- เริ่มต้นด้วยการเข้าถึงเอกสารทั้งหมด
- เลือกโฟลเดอร์/แท็กเพื่อบล็อกจาก agent
- เหมาะสำหรับ: ซ่อนเอกสาร HR ข้อมูลการเงิน หรือฉบับร่าง

**Include Mode**:
- เริ่มต้นโดยไม่มีสิทธิ์เข้าถึง
- เลือกโฟลเดอร์/แท็กเพื่อให้สิทธิ์เข้าถึง
- เหมาะสำหรับ: สร้าง agent เฉพาะทางสำหรับหัวข้อเฉพาะ

## การเลือกเนื้อหา

### ตามโฟลเดอร์

1. คลิกแท็บ **Folders**
2. ใช้ช่องค้นหาเพื่อหาโฟลเดอร์
3. เลือกโฟลเดอร์เพื่อ include/exclude
4. ขยายโฟลเดอร์ (คลิกลูกศร) เพื่อเลือกเอกสารแต่ละรายการ
5. เครื่องหมายถูกแสดงรายการที่เลือก การเลือกบางส่วนแสดงเป็นขีด

### ตามแท็ก

1. คลิกแท็บ **Tags**
2. ใช้ช่องค้นหาเพื่อหาแท็ก
3. เลือกแท็กเพื่อ include/exclude
4. แต่ละแท็กแสดงจำนวนเอกสารที่ใช้

## แผงตัวอย่าง

แผงตัวอย่างทางขวาแสดง:
- จำนวนเอกสารที่เข้าถึงได้ทั้งหมดตามการเลือกปัจจุบัน
- อัปเดตแบบ real-time เมื่อคุณทำการเปลี่ยนแปลง

## การบันทึกการเปลี่ยนแปลง

เมื่อแก้ไข agent ที่มีอยู่:
1. ทำการเลือก
2. คลิก **Save Changes** (ปุ่มสีเขียว)
3. หรือคลิก **Reset Changes** เพื่อยกเลิกการเปลี่ยนแปลงที่ยังไม่ได้บันทึก

เมื่อสร้าง agent ใหม่:
- การตั้งค่าการเข้าถึงความรู้จะบันทึกโดยอัตโนมัติเมื่อ submit แบบฟอร์ม agent

## เคล็ดลับ

- ใช้ **Exclude Mode** เมื่อต้องการให้เข้าถึงกว้างๆ พร้อมข้อยกเว้นไม่กี่รายการ
- ใช้ **Include Mode** สำหรับ agent ที่เน้นหัวข้อเฉพาะ
- รวมโฟลเดอร์ และ แท็กเพื่อการควบคุมที่แม่นยำ
- ตรวจสอบแผงตัวอย่างเพื่อยืนยันการเลือกก่อนบันทึก
- สำหรับ Include Mode ต้องเลือกอย่างน้อยหนึ่งโฟลเดอร์หรือแท็ก

## คำถามที่พบบ่อย

**ถาม: เกิดอะไรขึ้นถ้าเลือกทั้งโฟลเดอร์และแท็ก?**
ตอบ: Agent สามารถเข้าถึงเอกสารที่ตรงกับการเลือกใดก็ได้ โฟลเดอร์และแท็กรวมกันแบบ inclusive

**ถาม: สามารถให้ agent เข้าถึงทุกอย่างได้หรือไม่?**
ตอบ: ได้ ใช้ Exclude Mode และไม่เลือกสิ่งใดเพื่อยกเว้น Agent จะมีสิทธิ์เข้าถึงทั้งหมด

**ถาม: ถ้าเอกสารอยู่ในโฟลเดอร์ที่เลือกแต่มีแท็กที่ถูกยกเว้น?**
ตอบ: ใน Exclude Mode การตรงกับเนื้อหาที่ถูกยกเว้นจะบล็อกการเข้าถึง ใน Include Mode การตรงกับเนื้อหาที่ include จะให้สิทธิ์เข้าถึง

**ถาม: สิ่งนี้ส่งผลต่อการสนทนาที่มีอยู่หรือไม่?**
ตอบ: ใช่ การเปลี่ยนแปลงมีผลทันทีสำหรับข้อความใหม่ Agent จะใช้กฎการเข้าถึงที่อัปเดตแล้ว
