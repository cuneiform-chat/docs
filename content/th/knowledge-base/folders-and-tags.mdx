# โฟลเดอร์และแท็ก

จัดระเบียบเอกสารในเนื้อหาของคุณโดยใช้โฟลเดอร์และแท็ก โฟลเดอร์ให้การจัดระเบียบแบบลำดับชั้น ในขณะที่แท็กให้จัดหมวดหมู่ข้ามโฟลเดอร์ได้

## การเข้าถึง

ไปที่ **Content** ในเมนู sidebar โฟลเดอร์จะปรากฏใน document browser และตัวควบคุมแท็กอยู่ใน toolbar

## การทำงานกับโฟลเดอร์

### สร้างโฟลเดอร์

1. คลิกปุ่ม **New Folder** (ไอคอนโฟลเดอร์พร้อม +) ใน toolbar
2. ใส่ชื่อโฟลเดอร์ (จำเป็น)
3. เพิ่มคำอธิบายหากต้องการ
4. เลือกสีโดยใช้ color picker
5. คลิก **Create**

### แก้ไขโฟลเดอร์

1. คลิกเมนูสามจุด (...) บนแถวโฟลเดอร์
2. เลือก **Rename**
3. อัปเดตชื่อ คำอธิบาย หรือสี
4. คลิก **Save Changes**

### ลบโฟลเดอร์

1. คลิกเมนูสามจุด (...) บนแถวโฟลเดอร์
2. เลือก **Delete**
3. ยืนยันการลบ

### อัปโหลดไปยังโฟลเดอร์

- ลากไฟล์โดยตรงไปบนแถวโฟลเดอร์
- เลื่อนเมาส์ไปบนโฟลเดอร์เพื่อแสดงไอคอนอัปโหลด (Cloud Storage + ไฟล์จากเครื่อง)
- คลิกเพื่อขยายโฟลเดอร์และดูเอกสารภายใน

## การทำงานกับแท็ก

### จัดการแท็ก (สร้าง, แก้ไข, ลบ)

1. คลิก dropdown **Tag Filter** ใน toolbar
2. คลิก **Manage Tags** ที่ด้านล่าง
3. ใน modal:
   - คลิก **Create Tag** เพื่อเพิ่มแท็กใหม่
   - ใช้แท็กที่แนะนำสำหรับการสร้างอย่างรวดเร็ว
   - แก้ไขแท็กที่มีอยู่ (ชื่อ, สี)
   - ลบแท็กที่ไม่ได้ใช้

### เพิ่มแท็กให้เอกสาร

1. เลื่อนเมาส์ไปบนแถวเอกสาร
2. คลิกปุ่ม **Tag** (ไอคอนแท็ก)
3. ในหน้าต่าง Manage Tags:
   - ดูแท็กปัจจุบันที่ด้านบน
   - ค้นหาแท็กที่มี
   - เลือกแท็กเพื่อเพิ่ม
   - คลิกปุ่ม **Add X tags**

### ลบแท็กจากเอกสาร

1. เปิดหน้าต่าง Manage Tags สำหรับเอกสาร
2. ในส่วน "Current Tags" คลิก X บนแท็กเพื่อเลือกลบ
3. คลิกปุ่ม **Remove X tags**

### กรองเอกสารตามแท็ก

1. คลิก dropdown **Tag Filter** ใน toolbar
2. เลือกแท็กหนึ่งรายการหรือมากกว่า
3. แสดงเฉพาะเอกสารที่มีแท็กเหล่านั้น
4. แท็กที่เลือกจะปรากฏในแถบกรองด้านล่าง toolbar
5. คลิก X บนชิปแท็กเพื่อลบตัวกรอง หรือ **Clear all**

## โฟลเดอร์ vs แท็ก

| คุณสมบัติ | โฟลเดอร์ | แท็ก |
|-----------|----------|------|
| โครงสร้าง | ลำดับชั้น (หนึ่งโฟลเดอร์ต่อเอกสาร) | แบน (หลายแท็กต่อเอกสาร) |
| เหมาะสำหรับ | หมวดหมู่ใหญ่ โปรเจกต์ แผนก | หัวข้อ ธีม สถานะ หมวดหมู่ข้ามกัน |
| การกรอง | คลิกโฟลเดอร์เพื่อดูเนื้อหา | ใช้ตัวกรองแท็กเพื่อค้นหาข้ามโฟลเดอร์ |
| จำกัดเอกสาร | หนึ่งโฟลเดอร์ต่อเอกสาร | ไม่จำกัดแท็กต่อเอกสาร |

## เคล็ดลับ

- ใช้โฟลเดอร์สำหรับหมวดหมู่หลัก (เช่น "Product Docs", "HR Policies")
- ใช้แท็กสำหรับธีมข้ามหมวดหมู่ (เช่น "Q1-2024", "Compliance", "Draft")
- ใช้สีเพื่อจัดระเบียบโฟลเดอร์และแท็กให้เห็นภาพชัดเจน
- แท็กแสดงจำนวนการใช้งานเพื่อให้เห็นว่าเอกสารกี่รายการใช้แท็กแต่ละตัว
- รวมการกรองโฟลเดอร์และแท็กเพื่อค้นหาเอกสารอย่างแม่นยำ

## คำถามที่พบบ่อย

**ถาม: เอกสารสามารถอยู่ในหลายโฟลเดอร์ได้หรือไม่?**
ตอบ: ไม่ได้ แต่ละเอกสารอยู่ในโฟลเดอร์เดียว (หรือ "Unfiled") ใช้แท็กสำหรับการจัดหมวดหมู่ข้ามกัน

**ถาม: เกิดอะไรขึ้นกับเอกสารเมื่อลบโฟลเดอร์?**
ตอบ: โฟลเดอร์ที่มีเอกสารไม่สามารถลบได้ ย้ายหรือลบเอกสารก่อน

**ถาม: จะดูเอกสารทั้งหมดที่มีแท็กเฉพาะได้อย่างไร?**
ตอบ: ใช้ dropdown Tag Filter ใน toolbar และเลือกแท็กที่ต้องการ
