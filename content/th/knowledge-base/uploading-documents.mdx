# การอัปโหลดเอกสาร

อัปโหลดเอกสารไปยังเนื้อหาของคุณเพื่อให้ AI agent ใช้ในการตอบคำถาม เอกสารจะถูกประมวลผลและทำให้ค้นหาได้โดยอัตโนมัติ

## การเข้าถึง

1. เข้าสู่ระบบ Admin Panel
2. ไปที่ **Content** ในเมนู sidebar
3. พื้นที่อัปโหลดจะแสดงที่ด้านบนของหน้า

## วิธีการอัปโหลด

### อัปโหลดไฟล์จากเครื่อง

1. **ลากและวาง** ไฟล์โดยตรงไปยังพื้นที่อัปโหลด หรือ
2. **คลิก** พื้นที่อัปโหลดเพื่อเปิดตัวเลือกไฟล์
3. เลือกไฟล์หนึ่งไฟล์หรือมากกว่า
4. ไฟล์จะเริ่มอัปโหลดโดยอัตโนมัติพร้อมแสดงความคืบหน้า

### Import จาก Cloud Storage

Import ไฟล์โดยตรงจาก Cloud Storage ของคุณ:

| ผู้ให้บริการ | ไอคอน | วิธีใช้ |
|-------------|-------|---------|
| Google Drive | ไอคอน Google Drive | คลิกเพื่อเปิด Google Drive picker เลือกไฟล์ |
| Dropbox | ไอคอน Dropbox | คลิกเพื่อเปิด Dropbox chooser เลือกไฟล์ |
| OneDrive | ไอคอน OneDrive | คลิกเพื่อเปิด OneDrive picker เลือกไฟล์ |
| Box | ไอคอน Box | คลิกเพื่อเปิด Box picker เลือกไฟล์ |

หลังจากเลือกไฟล์จากผู้ให้บริการใดก็ตาม ไฟล์จะถูก import เข้าสู่เนื้อหาของคุณโดยอัตโนมัติ

## ตัวเลือกการอัปโหลด

### การเพิ่มแท็ก

คุณสามารถกำหนดแท็กให้กับเอกสารระหว่างอัปโหลดได้:

1. คลิก **+ Add Tags** ก่อนอัปโหลด
2. เลือกแท็กจาก dropdown
3. แท็กที่เลือกจะถูกนำไปใช้กับเอกสารที่อัปโหลดทั้งหมด

## ประเภทไฟล์ที่รองรับ

ประเภทไฟล์ที่คุณอัปโหลดได้ขึ้นอยู่กับ plan ของคุณ รูปแบบทั่วไปได้แก่:

- **เอกสาร:** PDF, DOCX, DOC, TXT, MD, RTF
- **งานนำเสนอ:** PPTX, PPT
- **เว็บ/ข้อมูล:** HTML, HTM, JSON, XML

ขนาดไฟล์สูงสุดก็แตกต่างกันตาม plan (แสดงในพื้นที่อัปโหลด)

ดู [รูปแบบที่รองรับ](/knowledge-base/supported-formats) สำหรับรายการทั้งหมด

## ระหว่างอัปโหลด

### การติดตามความคืบหน้า

- แต่ละไฟล์แสดงความคืบหน้าด้วยแถบเปอร์เซ็นต์
- แสดงความเร็วการอัปโหลดและเวลาที่เหลือโดยประมาณ
- ไฟล์จะถูกประมวลผลทีละไฟล์

### ตัวเลือกการยกเลิก

- **ยกเลิกไฟล์เดียว:** คลิก X ข้างไฟล์
- **ยกเลิกทั้งหมด:** คลิก "Cancel All Pending" เพื่อหยุดทั้ง batch
- จะมีคำเตือนปรากฏหากคุณพยายามออกจากหน้าระหว่างอัปโหลด

## สถานะการประมวลผล

ติดตามสถานะเอกสารใน Content:

| สถานะ | ความหมาย |
|-------|----------|
| Uploading | กำลังอัปโหลดเอกสารเข้าสู่ระบบ |
| Ready | เอกสารถูกประมวลผลแล้วและพร้อมใช้งานสำหรับ agent |
| Processing | กำลังวิเคราะห์เอกสาร |
| Queued | รอการประมวลผล |
| Retrying | กำลังลองประมวลผลอีกครั้ง |
| Failed | การประมวลผลพบข้อผิดพลาด (สามารถลองใหม่ได้) |

## หลังอัปโหลด

### สำเร็จ

- ไฟล์ที่อัปโหลดสำเร็จจะปรากฏใน document browser ของคุณ
- เอกสารจะถูกประมวลผลสำหรับการค้นหาโดยอัตโนมัติ
- คุณสามารถจัดระเบียบเป็นโฟลเดอร์หรือเพิ่มแท็กได้

### การจัดการรายการซ้ำ

- ระบบตรวจจับเนื้อหาที่ซ้ำกันโดยอัตโนมัติ
- หากมีไฟล์ที่มีเนื้อหาเหมือนกันอยู่แล้ว คุณจะเห็นคำเตือน
- ตำแหน่งของไฟล์ที่มีอยู่จะแสดงในข้อความแจ้งข้อผิดพลาด

### การจัดการข้อผิดพลาด

- หากไฟล์อัปโหลดล้มเหลว ข้อความแจ้งข้อผิดพลาดจะอธิบายสาเหตุ
- ปัญหาที่พบบ่อย ได้แก่ ไฟล์ขนาดใหญ่เกินไป หรือรูปแบบไม่รองรับ
- คุณสามารถลองอัปโหลดไฟล์เดิมอีกครั้งหรืออัปโหลดใหม่

## เคล็ดลับ

- อัปโหลดหลายไฟล์พร้อมกันเพื่อประหยัดเวลา
- ใส่แท็กระหว่างอัปโหลดเพื่อจัดระเบียบเอกสาร
- ตรวจสอบประเภทไฟล์ที่รองรับที่แสดงในพื้นที่อัปโหลด

## คำถามที่พบบ่อย

**ถาม: อัปโหลดไฟล์ได้ครั้งละกี่ไฟล์?**
ตอบ: คุณสามารถเลือกหลายไฟล์สำหรับ batch upload ไฟล์จะถูกประมวลผลทีละไฟล์พร้อมแสดงความคืบหน้า

**ถาม: ทำไมไฟล์ของฉันถูกปฏิเสธ?**
ตอบ: ตรวจสอบว่าประเภทไฟล์รองรับหรือไม่ และขนาดไฟล์อยู่ในขีดจำกัด (แสดงในพื้นที่อัปโหลด) บางไฟล์อาจถูกบล็อกด้วยเหตุผลด้านความปลอดภัย

**ถาม: การประมวลผลใช้เวลานานแค่ไหน?**
ตอบ: เวลาอัปโหลดขึ้นอยู่กับขนาดไฟล์และความเร็วเครือข่าย หลังอัปโหลด เอกสารจะถูกประมวลผลในพื้นหลังและสามารถค้นหาได้โดยอัตโนมัติ

**ถาม: สามารถอัปโหลดไปยังโฟลเดอร์ที่ระบุได้หรือไม่?**
ตอบ: ได้ คุณสามารถอัปโหลดโดยตรงไปยังโฟลเดอร์โดยใช้เมนูโฟลเดอร์ หรือจัดระเบียบเอกสารหลังอัปโหลด
