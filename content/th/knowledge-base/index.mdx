# เนื้อหา

เนื้อหาคือที่ที่คุณจัดการเอกสารทั้งหมดที่ AI agent ใช้ในการตอบคำถาม อัปโหลดเอกสาร จัดระเบียบเป็นโฟลเดอร์ เพิ่มแท็ก และควบคุมว่า agent ใดสามารถเข้าถึงเนื้อหาใดได้

## วิธีการทำงาน

1. **เพิ่มเนื้อหา** — อัปโหลดเอกสาร import จาก Cloud Storage หรือ crawl เว็บไซต์
2. **ประมวลผล** — เอกสารจะถูกประมวลผลและจัดทำ index โดยอัตโนมัติ
3. **ค้นหา** — Agent ค้นหาเนื้อหาที่เกี่ยวข้องเมื่อตอบคำถาม
4. **ตอบ** — คำตอบถูกสร้างจากเนื้อหาจริงของคุณ

## การเข้าถึง

ไปที่ **Content** ในเมนู sidebar นี่คือศูนย์กลางสำหรับจัดการเอกสารของคุณ

## สิ่งที่คุณเห็น

### พื้นที่อัปโหลด

ที่ด้านบนของหน้า:
- **ไอคอน Cloud Storage** — คลิก Google Drive, Dropbox, OneDrive หรือ Box เพื่อ import ไฟล์โดยตรง
- **Drop Zone** — ลากและวางไฟล์ หรือคลิกเพื่อเลือกไฟล์จากเครื่อง
- **แท็บ Website** — สลับไปที่แท็บ Website เพื่อ crawl และ import เนื้อหาเว็บไซต์สาธารณะ

### Document Browser

ใต้พื้นที่อัปโหลด ตารางแสดงเอกสารทั้งหมดของคุณ:

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| Name | ชื่อไฟล์เอกสารพร้อมไอคอนประเภทและตัวบ่งชี้แหล่งที่มา |
| Tags | แท็กที่กำหนดให้กับเอกสาร |
| Status | สถานะการประมวลผล (ดูสถานะเอกสารด้านล่าง) |
| Size | ขนาดไฟล์เป็น MB |
| Type | นามสกุลไฟล์ (PDF, DOCX เป็นต้น) |
| Uploaded | วันที่และเวลาที่อัปโหลด |
| Actions | เมนูสำหรับดำเนินการกับเอกสาร |

### Toolbar

- **Search** — ค้นหาเอกสารตามชื่อ
- **Tag Filter** — แสดงเฉพาะเอกสารที่มีแท็กที่ระบุ
- **Refresh** — อัปเดตรายการเอกสาร
- **New Folder** — สร้างโฟลเดอร์เพื่อจัดระเบียบ
- **Fullscreen** — ขยายหน้าต่างเพื่อพื้นที่เพิ่มเติม

## สถานะเอกสาร

| สถานะ | ความหมาย |
|-------|----------|
| Pending | เอกสารอยู่ในคิวรอการประมวลผล |
| Uploaded | เอกสารถูกอัปโหลดเข้าสู่ระบบแล้ว |
| Validating | เอกสารกำลังถูกตรวจสอบ |
| Stored | เอกสารถูกจัดเก็บแล้วและรอการประมวลผล |
| Processing | เอกสารกำลังถูกวิเคราะห์และจัดทำ index |
| Ready | เอกสารถูกประมวลผลแล้วและพร้อมใช้งานสำหรับ agent |
| Completed | การประมวลผลเอกสารเสร็จสมบูรณ์ |
| Failed | การประมวลผลพบข้อผิดพลาด (สามารถลองใหม่ได้) |

## การทำงานกับเอกสาร

### ดูเอกสาร

คลิกที่แถวเอกสารใดก็ได้เพื่อเปิดตัวแสดงเอกสาร ซึ่งจะแสดงเนื้อหาและ metadata

### การดำเนินการกับเอกสาร

เลื่อนเมาส์ไปบนเอกสารเพื่อดูปุ่มดำเนินการด่วน:
- **Tag** — เพิ่มหรือลบแท็ก
- **Premium Processing** — อัปเกรดคุณภาพการประมวลผล (หากมีสิทธิ์)
- **Retry** — ประมวลผลเอกสารที่ล้มเหลวอีกครั้ง
- **Chat** — สนทนาเกี่ยวกับเอกสารนี้โดยเฉพาะ

จากเมนู Actions (...):
- **Move to Folder** — ย้ายเอกสารไปโฟลเดอร์อื่น
- **Reprocess** — ลองประมวลผลเอกสารที่ล้มเหลวอีกครั้ง
- **Delete** — ลบเอกสารอย่างถาวร

## แนวปฏิบัติที่ดี

- **อัปเดตเนื้อหาให้เป็นปัจจุบัน** — อัปเดตเอกสารเป็นประจำเพื่อรักษาความถูกต้อง
- **จัดระเบียบด้วยโฟลเดอร์** — จัดกลุ่มเอกสารที่เกี่ยวข้องเพื่อการจัดการที่ง่ายขึ้น
- **ใช้แท็กสำหรับธีมข้ามหมวดหมู่** — แท็กช่วยค้นหาเอกสารข้ามโฟลเดอร์
- **คุณภาพสำคัญ** — เอกสารที่มีโครงสร้างดีจะสร้างคำตอบ AI ที่ดีกว่า
- **ลบรายการซ้ำ** — หลีกเลี่ยงการอัปโหลดเนื้อหาเดียวกันหลายครั้ง
