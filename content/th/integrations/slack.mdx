# การเชื่อมต่อ Slack

เพิ่ม agent ของคุณใน Slack workspace เพื่อให้ทั้งทีมเข้าถึงได้

## ภาพรวม

Slack integration มีความสามารถ:
- รองรับ slash command (`/ask`)
- การสนทนาผ่าน direct message
- Channel mention
- ใช้งานได้ทั้ง workspace

## ข้อกำหนดเบื้องต้น

- สิทธิ์ admin หรือสิทธิ์ติดตั้ง app ใน Slack workspace
- บัญชี Cuneiform Chat พร้อม agent ที่ active

## ขั้นตอนการตั้งค่า

### 1. เริ่มตั้งค่า Integration

1. ไปที่ **Agents** → เลือก agent ของคุณ
2. ไปที่แท็บ **Integrations**
3. คลิก **Slack**
4. คลิก **Add to Slack**

### 2. อนุญาต App

1. เลือก workspace ที่ต้องการติดตั้ง
2. ตรวจสอบ permission
3. คลิก **Allow**

### 3. ตรวจสอบการติดตั้ง

1. เปิด Slack
2. ลอง slash command: `/ask Hello`
3. ตรวจสอบว่าได้รับการตอบกลับ

## การใช้งาน Bot

### Slash Command

ใช้ command `/ask` ในทุก channel:

```
/ask What is our refund policy?
```

คำตอบจะแสดงใน channel (หรือเป็น ephemeral message ขึ้นอยู่กับการตั้งค่า)

### Direct Message

ส่งข้อความตรงถึง bot สำหรับการสนทนาส่วนตัว:

1. หา app ใน Slack sidebar
2. เปิด direct message
3. แชทได้ตามปกติ

### Channel Mention

Mention bot ใน channel เพื่อถามคำถาม:

```
@YourBot What are the shipping options?
```

## ฟีเจอร์

### การเข้าถึงทั้ง Workspace

เมื่อติดตั้งแล้ว bot จะใช้งานได้สำหรับสมาชิกทุกคนใน workspace

### Thread Reply

คำตอบสามารถโพสต์ใน thread เพื่อจัดระเบียบ channel

### Rich Formatting

คำตอบรองรับ formatting ของ Slack:
- Bold และ italic text
- Link
- Code block
- List

## ตัวเลือกการตั้งค่า

### การตั้งค่าการตอบกลับ

| การตั้งค่า | คำอธิบาย |
|-----------|----------|
| Response type | In-channel หรือ ephemeral |
| Thread behavior | ตอบใน thread หรือ main channel |

### การจำกัด Channel

สามารถจำกัด bot ให้ทำงานเฉพาะบาง channel เพื่อการใช้งานที่ตรงจุด

## Multi-Workspace Support

คุณสามารถติดตั้ง agent เดียวกันในหลาย Slack workspace:

1. แต่ละ workspace ต้อง authorize แยกกัน
2. ทุก workspace ใช้ agent และ content เดียวกัน
3. การสนทนาถูกติดตามแยกกันตาม workspace

## การแก้ไขปัญหา

### ไม่พบ Command

หาก `/ask` ไม่ทำงาน:
1. ตรวจสอบว่า app ถูกติดตั้งใน workspace แล้ว
2. ตรวจสอบว่า app มี permission ที่ถูกต้อง
3. ลองติดตั้ง integration ใหม่

### ไม่มีการตอบกลับ

หาก bot ไม่ตอบ:
1. ตรวจสอบว่า agent ตั้งค่าถูกต้องและทำงานได้ (ทดสอบใน Playground)
2. ตรวจสอบว่า Slack integration เชื่อมต่อแล้ว
3. ตรวจสอบว่า bot มีสิทธิ์เข้าถึง channel

### ปัญหา Permission

Permission ที่จำเป็น:
- `commands` — สำหรับ slash command
- `chat:write` — สำหรับส่งข้อความ
- `app_mentions:read` — สำหรับ @ mention

## ความปลอดภัย

- OAuth token ถูกเข้ารหัส
- ไม่มีการเข้าถึงข้อความนอกเหนือจาก command/mention โดยตรง
- ข้อมูล workspace ยังคงเป็นส่วนตัว

## การยกเลิกการเชื่อมต่อ

วิธีลบ Slack integration:

1. **จาก Cuneiform Chat:**
   - Agents → เลือก agent → Integrations → Slack → Disconnect

2. **จาก Slack:**
   - ไปที่การตั้งค่า workspace
   - Apps → หา app → Remove

ทั้งสองขั้นตอนช่วยให้การลบสมบูรณ์
