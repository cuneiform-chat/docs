# การเชื่อมต่อ WhatsApp

เชื่อมต่อ agent ของคุณกับ WhatsApp Business สำหรับการสื่อสารกับลูกค้า

## ภาพรวม

WhatsApp integration มีความสามารถ:
- Business messaging
- รองรับ rich media
- ตอบกลับอัตโนมัติ
- เข้าถึงได้ทั่วโลก
- เป็นไปตามกฎ 24-hour messaging window

## ข้อกำหนดเบื้องต้น

- AI agent ที่ active (สร้างในส่วน Agents)
- WhatsApp Business Account (WABA)
- หมายเลขโทรศัพท์ที่ verified ใน WhatsApp Business
- เข้าถึง Meta Developer Portal

## ขั้นตอนการตั้งค่า

### 1. เชื่อมต่อด้วย Embedded Signup (แนะนำ)

วิธีที่ง่ายที่สุดในการเชื่อมต่อ WhatsApp คือผ่าน embedded Meta signup flow:

1. ไปที่ **Agents** → เลือก agent ของคุณ
2. ไปที่แท็บ **Integrations**
3. คลิก **WhatsApp**
4. คลิก **Connect with Facebook** เพื่อเปิด Meta signup popup
5. เข้าสู่ระบบด้วยบัญชี Facebook/Meta ของคุณ
6. เลือกหรือสร้าง WhatsApp Business Account
7. เลือกหมายเลขโทรศัพท์ที่ต้องการเชื่อมต่อ
8. Popup จะปิดและการเชื่อมต่อสำเร็จ

### 2. การยืนยันหมายเลขโทรศัพท์ (หากจำเป็น)

หลังจาก Meta signup เสร็จ คุณอาจต้องยืนยันหมายเลขโทรศัพท์:

1. เลือกวิธีรับรหัสยืนยัน: **SMS** หรือ **Voice Call**
2. คลิก **Send Code**
3. กรอกรหัส 6 หลักที่ได้รับ
4. คลิก **Verify**

หากไม่ได้รับรหัส คลิก "Didn't receive the code? Send again" เพื่อส่งใหม่

### 3. Two-Step Verification (หากเปิดใช้งาน)

หาก WhatsApp Business account ของคุณเปิด Two-Step Verification:

1. กรอก PIN 6 หลักเมื่อได้รับแจ้ง
2. คลิก **Complete Registration**

<Callout type="info">
  PIN นี้ถูกตั้งค่าใน WhatsApp Business Manager → Security Center ซึ่งแตกต่างจากรหัสยืนยัน SMS
</Callout>

### 4. ตั้งค่า Webhook (หากจำเป็น)

หลังตั้งค่าเสร็จ คุณอาจต้องตั้งค่า webhook ใน Meta Business Suite:

1. คัดลอก webhook URL ที่ได้หลังเชื่อมต่อ
2. ใน Meta Developer Portal ไปที่ **WhatsApp** → **Configuration**
3. เพิ่ม webhook URL
4. Subscribe webhook field `messages`

## การใช้งาน Bot

### ข้อความจากลูกค้า

เมื่อลูกค้าส่งข้อความถึงหมายเลข WhatsApp ของคุณ:

1. ข้อความเข้ามาผ่าน WhatsApp
2. Cuneiform Chat ประมวลผลคำขอ
3. Agent สร้างคำตอบจาก content
4. ส่งคำตอบกลับไปยังลูกค้า

### ขั้นตอนการสนทนา

```
Customer → WhatsApp → Cuneiform Chat → Agent → Response → Customer
```

## ฟีเจอร์

### 24-Hour Messaging Window

กฎของ WhatsApp Business API:
- คุณสามารถตอบข้อความที่ลูกค้าเริ่มได้ภายใน 24 ชั่วโมง
- หลัง 24 ชั่วโมง window จะปิดจนกว่าลูกค้าจะส่งข้อความอีกครั้ง
- ข้อความใหม่จากลูกค้าจะเปิด window อีกครั้ง

<Callout type="info">
  Agent ของคุณตอบภายใน 24-hour window โดยอัตโนมัติ Template message สำหรับ re-engagement ยังไม่รองรับในขณะนี้
</Callout>

### Rich Media

คำตอบสามารถรวม:
- ข้อความตัวอักษร
- Link
- Formatted text

### Multi-Language

Agent ของคุณตรวจจับภาษาของลูกค้าโดยอัตโนมัติและตอบในภาษาเดียวกัน — รองรับ 176 ภาษา ไม่ต้องตั้งค่า

## การจัดการหมายเลขที่เชื่อมต่อ

แต่ละหมายเลข WhatsApp ที่เชื่อมต่อจะแสดง:
- **Business name** หรือหมายเลขโทรศัพท์ที่แสดง
- **Status badge** - Active, Inactive หรือ Error
- **Phone number**
- **Last activity** timestamp

### การดำเนินการที่ใช้ได้

| การดำเนินการ | คำอธิบาย |
|-------------|----------|
| **Test Connection** | ตรวจสอบว่า integration ทำงานอยู่ |
| **Disconnect** | ลบ integration นี้ |

เข้าถึงการดำเนินการเหล่านี้ผ่านเมนูสามจุดบน integration card

## การแก้ไขปัญหา

### เชื่อมต่อไม่สำเร็จ

1. ตรวจสอบว่าคุณมี WhatsApp Business Account ที่ valid
2. ตรวจสอบว่าหมายเลขโทรศัพท์ถูก verify แล้ว
3. ลอง embedded signup flow อีกครั้ง

### การยืนยันหมายเลขโทรศัพท์ไม่ทำงาน

1. ตรวจสอบว่าคุณเข้าถึงหมายเลขโทรศัพท์สำหรับ SMS/Voice ได้
2. รอสักครู่ก่อนขอรหัสใหม่
3. ตรวจสอบว่าหมายเลขโทรศัพท์ไม่ได้เชื่อมต่อที่อื่นแล้ว

### Two-Step Verification Error

1. กรอก PIN ที่ตั้งค่าใน WhatsApp Business Manager → Security Center
2. PIN นี้แตกต่างจากรหัสยืนยัน SMS
3. ติดต่อ WhatsApp Business admin หากไม่ทราบ PIN

### ข้อความไม่เข้า

1. ตรวจสอบว่า webhook ตั้งค่าถูกต้องใน Meta Business Suite
2. ตรวจสอบว่า webhook subscription รวม `messages`
3. ยืนยันว่าสถานะ integration เป็น "Active"

### ตอบกลับไม่สำเร็จ

1. ตรวจสอบว่า agent ทำงานได้ใน Playground
2. ตรวจสอบว่า 24-hour window ยัง active อยู่ (ลูกค้าส่งข้อความเมื่อเร็วๆ นี้)
3. ตรวจสอบสถานะ integration ใน admin panel

## ความปลอดภัย

- Access token ถูกเข้ารหัสและจัดเก็บอย่างปลอดภัย
- ข้อความถูกประมวลผลผ่านการเชื่อมต่อที่ปลอดภัย

## ข้อกำหนดการใช้งาน

WhatsApp Business มีนโยบายการใช้งาน:
- ตอบเฉพาะการสนทนาที่ลูกค้าเริ่มต้น
- มีตัวเลือก opt-out
- ปฏิบัติตาม Commerce and Business policies ของ Meta

## การยกเลิกการเชื่อมต่อ

วิธีลบ WhatsApp integration:

1. ไปที่ **Agents** → เลือก agent → **Integrations**
2. คลิกเมนูสามจุดบน WhatsApp integration ของคุณ
3. เลือก **Disconnect**

การดำเนินการนี้จะหยุด agent จากการตอบสนอง วิธีลบอย่างสมบูรณ์:
- ลบ webhook ใน Meta Developer Portal
- ลบ WhatsApp product ออกจาก Meta app (ไม่จำเป็น)

## คำถามที่พบบ่อย

**Q: ฉันเชื่อมต่อ WhatsApp ได้อย่างไร?**
A: ใช้ embedded signup โดยคลิก "WhatsApp" ในแท็บ Integrations จากนั้นคลิก "Connect with Facebook" ระบบจะนำคุณผ่านขั้นตอน Meta signup โดยอัตโนมัติ

**Q: ทำไมถูกขอรหัสยืนยัน?**
A: WhatsApp ต้องการการยืนยันหมายเลขโทรศัพท์สำหรับการเชื่อมต่อใหม่ เลือก SMS หรือ Voice Call เพื่อรับรหัส 6 หลัก จากนั้นกรอกเพื่อตั้งค่าให้เสร็จ

**Q: Two-Step Verification PIN คืออะไร?**
A: หากคุณเปิด Two-Step Verification ใน WhatsApp Business Manager คุณต้องกรอก PIN 6 หลักระหว่างตั้งค่า ซึ่งแตกต่างจากรหัสยืนยัน SMS

**Q: เชื่อมต่อหลายหมายเลข WhatsApp ได้ไหม?**
A: ได้ คุณสามารถเชื่อมต่อหลายหมายเลข WhatsApp Business แต่ละหมายเลขสามารถเชื่อมต่อกับ AI agent ที่แตกต่างกัน (หรือเดียวกัน) ได้
