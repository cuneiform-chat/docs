# Website Chat Widget

ฝัง AI chat widget ลงในเว็บไซต์ของคุณโดยตรง ผู้เข้าชมจะได้คำตอบทันทีจาก AI agent โดยไม่ต้องออกจากเว็บไซต์

## ภาพรวม

Website Widget มีความสามารถ:
- Chat bubble แบบลอยบนเว็บไซต์ของคุณ
- คำตอบ AI แบบ streaming real-time
- ปรับแต่งหน้าตาได้ (สี, ตำแหน่ง, ข้อความ)
- น้อยกว่า 11KB gzipped — แทบไม่กระทบ performance
- Domain allowlisting เพื่อความปลอดภัย

## ข้อกำหนดเบื้องต้น

- AI agent ที่ active ใน admin panel
- เข้าถึง HTML ของเว็บไซต์ (เพื่อวาง script tag)

## ขั้นตอนการตั้งค่า

### 1. สร้าง Widget

1. ไปที่ **Integrations** จาก sidebar
2. เลื่อนไปที่ส่วน **Website Widget**
3. คลิก **Create Widget**
4. กรอกชื่อและเลือก AI agent
5. คลิก **Create**

### 2. ปรับแต่งหน้าตา

คลิก widget card เพื่อเปิด edit sheet:

- **Primary Color** — สีของ chat bubble และ header
- **Text Color** — สีข้อความบน bubble และ header
- **Position** — ขวาล่างหรือซ้ายล่าง
- **Welcome Message** — ข้อความแรกที่ผู้เข้าชมเห็น
- **Suggested Questions** — คำถามแนะนำสูงสุด 4 ข้อที่คลิกได้
- **Avatar URL** — รูปภาพใน chat header
- **Border Radius** — ความโค้งมน

Live preview จะอัปเดตตามที่คุณเปลี่ยนแปลง

### 3. ตั้งค่า Allowed Domain (แนะนำ)

จำกัดเว็บไซต์ที่สามารถฝัง widget:

- เว้นว่างเพื่ออนุญาตทุก domain (ค่าเริ่มต้น)
- เพิ่ม domain เฉพาะ: `example.com`, `*.example.com`
- ใช้ port สำหรับ development: `localhost:3000`

### 4. ฝังบนเว็บไซต์ของคุณ

คลิก embed icon บน widget card และคัดลอก code:

```html
<script src="https://core-api.cuneiform.chat/api/widget/widget.js"
  data-widget-id="your-widget-id" async></script>
```

วางก่อน closing `</body>` tag บนเว็บไซต์ของคุณ

## การทำงาน

```
Visitor opens your website
  → Chat bubble appears in the corner
  → Visitor clicks → Chat panel opens
  → Welcome message + suggested questions shown
  → Visitor types a question
  → AI agent searches your content
  → Response streams in real-time
```

ข้อความถูกประมวลผลแบบ real-time agent ค้นหา content ของคุณและสร้างคำตอบด้วย AI pipeline เดียวกับทุก channel

## ฟีเจอร์

### Streaming Response

คำตอบ stream แบบ real-time ด้วย Server-Sent Events (SSE) ผู้เข้าชมจะเห็นคำตอบปรากฏขึ้นเรื่อยๆ คล้ายกับ ChatGPT

### Session Persistence

ผู้เข้าชมที่กลับมาบน browser เดิมจะกลับเข้าสู่การสนทนาก่อนหน้าภายใน 24 ชั่วโมง Session ถูกเก็บใน localStorage ของ browser

### Suggested Question

ตั้งค่าคำถามแนะนำสูงสุด 4 ข้อที่คลิกได้เมื่อเปิด chat เหมาะสำหรับนำผู้เข้าชมไปยังหัวข้อที่พบบ่อย

import { Callout } from 'nextra/components'

<Callout type="info">
  Widget ทำงานภายใน Shadow DOM จึงไม่กระทบ style หรือ JavaScript ของเว็บไซต์คุณ
</Callout>

### Markdown Rendering

คำตอบของ agent รองรับ markdown formatting รวมถึง bold, italic, list, code block และ link

## การจัดการ Widget

ในหน้า Integrations แต่ละ widget card จะแสดง:

- ชื่อ widget และสถานะ
- Agent ที่เชื่อมต่อ
- การแก้ไข, embed code และการลบ

| การดำเนินการ | วิธีการ |
|-------------|---------|
| แก้ไขการตั้งค่า | คลิก widget card |
| รับ embed code | คลิก embed icon |
| ลบ | เมนูสามจุด → Delete |

## ความปลอดภัย

- **Shadow DOM isolation** — Widget ถูก sandbox จากหน้าเว็บของคุณ
- **HMAC session token** — Signed token พร้อมหมดอายุ 24 ชั่วโมง
- **Domain allowlisting** — จำกัดเว็บไซต์ที่สามารถฝัง widget
- **Rate limiting** — 30 ข้อความ/นาทีต่อ session
- **ไม่มีการเข้าถึงข้อมูล** — Widget ไม่สามารถอ่านหรือแก้ไข content ของหน้าเว็บ

## การแก้ไขปัญหา

### Widget ไม่แสดง

1. ตรวจสอบว่า script tag อยู่ก่อน `</body>` ไม่ใช่ใน `<head>`
2. ตรวจสอบว่า `data-widget-id` ตรงกับ admin panel
3. หากตั้งค่า domain allowlisting ตรวจสอบว่า domain ของคุณอยู่ในรายการ
4. ตรวจสอบ browser console สำหรับ error

### Widget ไม่ตอบ

1. ตรวจสอบว่า agent ที่เชื่อมต่ออยู่ในสถานะ **Active**
2. ตรวจสอบว่า agent มีเอกสารใน content
3. ตรวจสอบ browser Network tab สำหรับ API request ที่ล้มเหลว

### ปัญหาหน้าตา

Widget ใช้ Shadow DOM isolation CSS ของหน้าเว็บจะไม่กระทบ widget ใช้ live preview ของ edit sheet เพื่อปรับแต่งหน้าตา

## FAQ

### ฝัง widget บนหลายหน้าได้ไหม?

ได้ ใช้ embed code เดียวกันในทุกหน้า Widget จะแชร์ session state ข้ามหน้าบน domain เดียวกัน

### ใช้งานบนมือถือได้ไหม?

ได้ Widget responsive เต็มรูปแบบและปรับให้เหมาะกับ mobile browser

### ลบป้าย "Powered by" ได้ไหม?

ป้ายนี้จำเป็นสำหรับ plan Trial และ Starter อัปเกรดเป็น Professional ขึ้นไปเพื่อลบ

### ใช้งานกับ React/Next.js/Vue ได้ไหม?

ได้ Widget โหลดเป็น standalone script และทำงานกับทุก framework รวมถึง single-page application
