# การเชื่อมต่อ

Deploy agent ของคุณไปยังหลาย channel และเข้าถึงผู้ใช้ได้ทุกที่

## Channel ที่พร้อมใช้งาน

| Channel | คำอธิบาย | เหมาะสำหรับ |
|---------|----------|-------------|
| [Telegram](/integrations/telegram) | Telegram bot | ผู้ใช้มือถือ, ชุมชน |
| [Discord](/integrations/discord) | Discord bot พร้อม slash command | Gaming, ชุมชนนักพัฒนา |
| [Slack](/integrations/slack) | Slack app | Team workspace |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | การสื่อสารกับลูกค้า |
| [Google Chat](/integrations/google-chat) | Google Workspace app | ทีมในองค์กร |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | กลุ่มผู้บริโภค |
| [Website Widget](/integrations/website-widget) | Chat widget แบบฝังได้ | Customer support, เว็บไซต์ทั่วไป |

## การเชื่อมต่อทำงานอย่างไร

1. **ตั้งค่า** — กำหนดค่า integration สำหรับ channel ที่เลือก
2. **เชื่อมต่อ** — เชื่อม agent ของคุณกับ channel
3. **Deploy** — Agent ของคุณพร้อมให้ผู้ใช้งาน
4. **ติดตาม** — ตรวจสอบการสนทนาและการใช้งาน

## การ Deploy แบบ Multi-Channel

Agent เดียวสามารถ deploy ไปยังหลาย channel พร้อมกัน:

- เนื้อหาเดียวกันทุก channel
- การตอบสนองที่สอดคล้องกันทุกที่
- ประวัติการสนทนาแบบรวมศูนย์
- Analytics แบบรวม

## ฟีเจอร์เฉพาะของแต่ละ Channel

แต่ละ channel มีความสามารถเฉพาะ:

- **Telegram** — Rich message, inline keyboard
- **Discord** — Slash command, server integration
- **Slack** — Workspace app, channel response
- **WhatsApp** — Business messaging, rich media
- **Google Chat** — Google Workspace integration, Spaces support
- **Meta (Facebook)** — Messenger integration, Page messaging
- **Website Widget** — Chat แบบฝังได้, ปรับแต่งหน้าตา, domain allowlisting

## ข้อกำหนดเบื้องต้น

ก่อนตั้งค่า integration:

1. ✅ สร้าง agent อย่างน้อยหนึ่งตัว
2. ✅ อัปโหลดเอกสารไปยัง content ของคุณ
3. ✅ ทดสอบ agent ใน Playground

แต่ละ channel อาจมีข้อกำหนดเพิ่มเติม (bot token, app credential เป็นต้น) ดูรายละเอียดในคู่มือแต่ละ channel
