# การเชื่อมต่อ Meta (Facebook)

เชื่อมต่อ agent ของคุณกับ Facebook Messenger ผ่าน Facebook Page

## ภาพรวม

Meta integration มีความสามารถ:
- การสนทนา Facebook Messenger ผ่าน Page ของคุณ
- ประมวลผลเบื้องหลังพร้อม typing indicator
- แบ่งข้อความยาวอัตโนมัติ
- เป็นไปตามกฎ 24-hour messaging window
- Conversation memory ภายใน session

## ข้อกำหนดเบื้องต้น

- Facebook Page ที่คุณจัดการ
- สิทธิ์ Admin หรือ Editor บน Page
- บัญชี Cuneiform Chat พร้อม agent ที่ active

## ขั้นตอนการตั้งค่า

### 1. เริ่มตั้งค่า Integration

1. ไปที่ **Agents** → เลือก agent ของคุณ
2. ไปที่แท็บ **Integrations**
3. คลิก **Meta (Facebook)**
4. คลิก **Connect Page**

### 2. Authorize กับ Facebook

1. เลือก **Agent** ที่จะตอบ
2. คลิก **Connect with Facebook**
3. เข้าสู่ระบบ Facebook (หากจำเป็น)
4. เลือก Page ที่ต้องการเชื่อมต่อ
5. ให้สิทธิ์ Messenger
6. คุณจะถูกนำกลับพร้อมข้อความสำเร็จ

### 3. ตรวจสอบการเชื่อมต่อ

เมื่อเชื่อมต่อแล้ว Page ของคุณจะแสดงในรายการ integration พร้อม:
- ชื่อ Page และสถานะ
- Page ID
- Last activity timestamp

## การทำงาน

เมื่อผู้ใช้ส่งข้อความถึง Facebook Page ผ่าน Messenger:

1. ข้อความเข้ามาผ่าน Facebook Messenger
2. Bot แสดง typing indicator ขณะประมวลผล
3. Agent ประมวลผลคำถาม
4. ส่งคำตอบกลับผ่าน Messenger

## ฟีเจอร์

### การตอบกลับอัตโนมัติ

Agent ของคุณตอบข้อความ Messenger ที่เข้ามาโดยอัตโนมัติตาม content ข้อความข้อความทั้งหมดจะถูกตอบ — ไม่ต้องใช้ command หรือ prefix

### Typing Indicator

ขณะที่ agent ประมวลผลข้อความ ผู้ใช้จะเห็น typing indicator ("...") ใน Messenger ให้ความรู้สึกเหมือนการสนทนาธรรมชาติ

### Message Splitting

คำตอบที่ยาวกว่า 2,000 ตัวอักษรจะถูกแบ่งเป็นหลายข้อความโดยอัตโนมัติ โดยรักษา paragraph break และขอบเขตประโยคเพื่อความอ่านง่าย

### Conversation Memory

Bot จดจำ context ภายใน session ผู้ใช้สามารถถามคำถามต่อเนื่องได้โดยไม่ต้องทวนซ้ำ

### Message Queuing

หากผู้ใช้ส่งข้อความเพิ่มเติมขณะที่ bot ยังประมวลผลอยู่ ข้อความจะถูกเข้าคิวและรวมในคำตอบถัดไป

### 24-Hour Messaging Window

นโยบายของ Facebook อนุญาตให้ตอบภายใน 24 ชั่วโมงหลังข้อความล่าสุดจากผู้ใช้ Agent ตอบแบบ real-time ภายใน window นี้ หลังจาก 24 ชั่วโมงที่ไม่มีการใช้งาน ผู้ใช้ต้องส่งข้อความใหม่เพื่อเริ่มการสนทนาอีกครั้ง

<Callout type="warning">
  ผู้ใช้ต้องส่งข้อความถึง Page ของคุณก่อน — คุณไม่สามารถส่งข้อความที่ไม่ได้ร้องขอได้ หาก 24 ชั่วโมงผ่านไปตั้งแต่ข้อความล่าสุด bot จะไม่สามารถตอบได้จนกว่าผู้ใช้จะส่งข้อความอีกครั้ง
</Callout>

## การจัดการ Page

### ดู Page ที่เชื่อมต่อ

แต่ละ Page ที่เชื่อมต่อจะแสดง:
- ชื่อ Page และสถานะการเชื่อมต่อ
- Agent ที่เชื่อมต่อ
- ข้อมูลกิจกรรม

### การดำเนินการที่ใช้ได้

| การดำเนินการ | คำอธิบาย |
|-------------|----------|
| **Test Connection** | ตรวจสอบว่า integration ทำงานอยู่ |
| **Disconnect** | ลบการเชื่อมต่อ Page |

เข้าถึงการดำเนินการเหล่านี้ผ่านเมนูสามจุดบนแต่ละ Page ที่เชื่อมต่อ

## การแก้ไขปัญหา

### Page ไม่แสดง

1. ตรวจสอบว่าคุณมีสิทธิ์ Admin หรือ Editor บน Page
2. ตรวจสอบว่าคุณให้สิทธิ์ทั้งหมดที่ร้องขอ
3. ลอง disconnect แล้วเชื่อมต่อใหม่

### ข้อความไม่ได้รับการตอบกลับ

1. ใช้ "Test Connection" เพื่อตรวจสอบ integration
2. ตรวจสอบว่า agent ตั้งค่าถูกต้องและทำงานได้ (ทดสอบใน Playground)
3. ตรวจสอบว่าได้ให้สิทธิ์ Messenger แล้ว
4. ตรวจสอบว่าผู้ใช้ส่งข้อความภายใน 24 ชั่วโมงล่าสุด (นโยบาย messaging window)

### Authorization Error

1. ล้าง Facebook login session แล้วลองใหม่
2. ตรวจสอบว่าบัญชี Facebook ของคุณมีสิทธิ์เข้าถึง Page
3. ตรวจสอบว่า Page ไม่ถูกจำกัดโดย Facebook

## ความปลอดภัย

- **OAuth token** ถูกเข้ารหัสและจัดเก็บอย่างปลอดภัย
- **Webhook signature** ถูกตรวจสอบด้วย HMAC-SHA256 ทุก request ที่เข้ามา
- ไม่มีการเข้าถึง content ของ Page นอกเหนือจากการสนทนา Messenger
- เป็นไปตาม Facebook Platform policies

## การยกเลิกการเชื่อมต่อ

วิธีลบ Meta integration:

1. ไปที่ **Agents** → เลือก agent → **Integrations**
2. คลิกเมนูสามจุดบน Page ของคุณ
3. เลือก **Disconnect**

วิธีเพิกถอนสิทธิ์ทั้งหมด:
1. ไปที่ Facebook Settings → Business Integrations
2. ลบ Cuneiform Chat app

## หมายเหตุสำคัญ

- **หนึ่ง agent ต่อ Page**: แต่ละ Facebook Page สามารถเชื่อมต่อกับ AI agent ได้ครั้งละหนึ่งตัวเท่านั้น
- **Messenger เท่านั้น**: Integration นี้ทำงานผ่าน Facebook Messenger ไม่ใช่ Page comment หรือ post
- **ข้อจำกัดข้อความ**: ข้อความแต่ละรายการจำกัดที่ 2,000 ตัวอักษร คำตอบที่ยาวกว่าจะถูกแบ่งอัตโนมัติ
- **เปลี่ยน agent**: Disconnect integration ที่มีอยู่ก่อน จากนั้นเชื่อมต่อใหม่กับ agent อื่น
