# การเชื่อมต่อ Telegram

เชื่อมต่อ agent ของคุณกับ Telegram และให้ผู้ใช้แชทกับ bot โดยตรงในแอป Telegram

## ภาพรวม

Telegram integration มีความสามารถ:
- ส่งข้อความตรงกับ bot ของคุณ
- รองรับ group chat
- Rich message formatting
- Inline keyboard สำหรับการโต้ตอบ

## ข้อกำหนดเบื้องต้น

- บัญชี Telegram
- เข้าถึง BotFather (เครื่องมือสร้าง bot ของ Telegram)

## ขั้นตอนการตั้งค่า

### 1. สร้าง Telegram Bot

1. เปิด Telegram และค้นหา **@BotFather**
2. เริ่มแชทและส่ง `/newbot`
3. ทำตามขั้นตอน:
   - ตั้งชื่อ bot ของคุณ (เช่น "My Support Bot")
   - ตั้ง username (ต้องลงท้ายด้วย "bot" เช่น "mysupportbot")
4. BotFather จะให้ **Bot Token** — เก็บรักษาไว้อย่างปลอดภัย

### 2. เชื่อมต่อกับ Cuneiform Chat

1. ไปที่ **Agents** → เลือก agent ของคุณ
2. ไปที่แท็บ **Integrations**
3. คลิก **Telegram**
4. วาง Bot Token ของคุณ
5. คลิก **Connect**

### 3. ตั้งค่า Bot ของคุณ

การตั้งค่า bot เพิ่มเติมผ่าน BotFather (ไม่จำเป็น):

- `/setdescription` — คำอธิบายการทำงานของ bot
- `/setabouttext` — ข้อมูลในโปรไฟล์ bot
- `/setuserpic` — รูปโปรไฟล์สำหรับ bot

### 4. ทดสอบ Bot ของคุณ

1. ค้นหา bot ใน Telegram โดยใช้ username
2. เริ่มการสนทนาด้วย `/start`
3. ส่งข้อความและตรวจสอบว่าได้รับการตอบกลับ

## การทำงาน

```
User sends message → Telegram → Cuneiform Chat → Agent processes → Response sent back
```

ข้อความถูกประมวลผลแบบ real-time agent ค้นหา content ของคุณและสร้างคำตอบตามการตั้งค่า

## ฟีเจอร์

### Direct Message

ผู้ใช้สามารถแชทกับ bot แบบตัวต่อตัวสำหรับการสนทนาส่วนตัว

### Group Chat

เพิ่ม bot ของคุณใน group chat:

1. เพิ่ม bot เข้า group
2. ตั้งให้เป็น admin (เพื่อเข้าถึงข้อความ)
3. ผู้ใช้สามารถ mention bot หรือใช้ command

### Rich Formatting

คำตอบของ agent รองรับ:
- **Bold** และ *italic* text
- Link
- Code block
- List

## Bot Command

คุณสามารถตั้งค่า command ผ่าน BotFather:

| Command | คำอธิบาย |
|---------|----------|
| `/start` | เริ่มการสนทนา |
| `/help` | แสดงข้อความช่วยเหลือ |
| `/ask [question]` | ถามคำถามเฉพาะ |

## การแก้ไขปัญหา

### Bot ไม่ตอบสนอง

1. ตรวจสอบว่า bot token ถูกต้อง
2. ตรวจสอบว่า integration เชื่อมต่อแล้วใน Cuneiform Chat
3. ตรวจสอบว่า agent ตั้งค่าถูกต้อง
4. ทดสอบ agent ใน Playground ก่อน

### ปัญหาเรื่อง Token

หากต้องการ token ใหม่:
1. ไปที่ BotFather
2. ส่ง `/mybots` → เลือก bot ของคุณ → **API Token** → **Revoke**
3. อัปเดต token ใหม่ใน Cuneiform Chat

### ปัญหา Group Chat

- ตรวจสอบว่า bot มีสิทธิ์ admin
- ตรวจสอบการตั้งค่า privacy mode ผ่าน BotFather (`/setprivacy`)

## ความปลอดภัย

- Bot token ถูกเข้ารหัสและจัดเก็บอย่างปลอดภัย
- การสนทนาถูกประมวลผลผ่านการเชื่อมต่อที่ปลอดภัย

## การยกเลิกการเชื่อมต่อ

วิธีลบ Telegram integration:

1. ไปที่ **Agents** → เลือก agent → **Integrations**
2. คลิก **Telegram** → **Disconnect**

การดำเนินการนี้จะหยุด bot จากการตอบสนอง แต่ไม่ได้ลบ Telegram bot ลบผ่าน BotFather หากต้องการ
