# การเชื่อมต่อ Google Chat

เชื่อมต่อ agent ของคุณกับ Google Chat สำหรับการสื่อสารภายใน Google Workspace

## ภาพรวม

Google Chat integration มีความสามารถ:
- ส่งข้อความตรงกับ bot ของคุณ
- รองรับ Google Workspace Spaces พร้อม @mention triggers
- Space-level agent routing — กำหนด agent ต่างกันให้แต่ละ Space
- การตอบกลับแบบข้อความพร้อม conversation memory และการรับรู้บริบทของ thread
- ประมวลผลแบบ async พร้อม acknowledgment ทันที
- ความปลอดภัยระดับองค์กรด้วย domain-based isolation

## ข้อกำหนดเบื้องต้น

- AI agent ที่ active (สร้างในส่วน Agents)
- บัญชี Google Workspace (ไม่รองรับ Gmail ส่วนตัว)
- **Domain ที่ verified** — ยืนยันความเป็นเจ้าของ domain ใน **Settings > Domains** ก่อนเชื่อมต่อ

## ขั้นตอนการตั้งค่า

### 1. ยืนยัน Domain ของคุณ (ตั้งค่าครั้งเดียว)

ก่อนเชื่อมต่อ Google Chat ให้ยืนยันความเป็นเจ้าของ domain:

1. ไปที่ **Settings** จาก sidebar
2. คลิกแท็บ **Domains**
3. Domain ของคุณจะถูกตรวจจับอัตโนมัติจากอีเมลบัญชี
4. เพิ่ม **TXT record** ใน DNS provider ด้วยค่าที่แสดง:
   - **Type:** TXT
   - **Name:** `_cuneiform-verify` (หรือค่าเต็มที่แสดง)
   - **Content:** ข้อความยืนยันที่แสดง (เช่น `cuneiform-verify=abc123...`)
5. คลิก **Verify Now** — การเปลี่ยนแปลง DNS อาจใช้เวลาถึง 48 ชั่วโมงในการ propagate
6. เมื่อสถานะเปลี่ยนเป็น **Verified** ให้ดำเนินการสร้าง integration

ลิงก์ด่วนไปยัง DNS provider ทั่วไป (Cloudflare, GoDaddy, Namecheap, Route 53, DigitalOcean, Hostinger) จะแสดงบน verification card

### 2. สร้าง Google Chat Integration

1. ไปที่ **Integrations** จาก sidebar
2. ใต้ "Google Chat Bots" คลิก **Connect Bot**
3. เลือก **Agent** ที่จะเป็น default สำหรับ DM และ Space ที่ไม่ได้เชื่อมต่อ
4. กรอก **Bot Name** (สำหรับอ้างอิงใน admin panel)
5. คลิก **Connect Bot**
6. คัดลอก **Verification Code** ที่แสดง (รูปแบบ: `VERIFY-XXXXXX`)

### 3. ยืนยัน Bot ให้เสร็จสิ้น

หลังสร้าง integration คุณจะได้รับ verification code:

1. เปิด Google Chat
2. คลิก **Start a chat** → **Find apps**
3. ค้นหา platform bot
4. เริ่ม direct message กับ bot
5. ส่ง verification code (เช่น `VERIFY-ABC123`)
6. Bot จะยืนยัน: "Setup complete! Your workspace (yourdomain.com) is now connected. Send a message to start chatting!"

สถานะ integration จะเปลี่ยนจาก "Pending Verification" เป็น "Active"

<Callout type="warning">
  เฉพาะผู้ใช้จาก Google Workspace domain ของคุณเท่านั้นที่สามารถยืนยันได้ ผู้ใช้จาก domain อื่นหรือ Gmail ส่วนตัวจะเห็นข้อผิดพลาด
</Callout>

## การใช้งาน Bot

### Direct Message

ผู้ใช้สามารถเริ่มการสนทนา:

1. เปิด Google Chat
2. คลิก **Start a chat** → **Find apps**
3. ค้นหาชื่อ bot ของคุณ
4. เริ่มแชทได้ตามปกติ — bot ตอบทุกข้อความใน DM

DM จะถูกจัดการโดย **default agent** เสมอ

### ใน Spaces

เพิ่ม bot ใน Space:

1. เปิด Space
2. คลิกชื่อ Space → **Manage apps**
3. เพิ่ม bot ของคุณ
4. Mention bot ด้วย `@Cuneiform Chat` เพื่อโต้ตอบ — bot จะตอบเฉพาะ @mention ใน Space

<Callout type="info">
  เมื่อ bot ถูกเพิ่มใน Space ครั้งแรก จะส่งข้อความต้อนรับพร้อม bot command ที่ใช้ได้ ใน DM จะส่งข้อความแนะนำตัวสั้นๆ
</Callout>

## Space-Level Agent Routing

แต่ละ Space สามารถใช้ agent ที่แตกต่างจาก default ได้ ใช้ bot command เหล่านี้ใน Space (ต้อง @mention):

| Command | คำอธิบาย |
|---------|----------|
| `@Cuneiform Chat /set-agent <name>` | เชื่อม Space นี้กับ agent เฉพาะ |
| `@Cuneiform Chat /current-agent` | แสดงว่า agent ใดจัดการ Space นี้ |
| `@Cuneiform Chat /reset-agent` | กลับไปใช้ default agent |

**การทำงานของ routing:**
- **DM** → ใช้ default agent เสมอ
- **Space ที่มี custom agent** → ใช้ agent ที่กำหนด
- **Space ที่ไม่มี custom agent** → fallback ไปใช้ default agent

<Callout type="info">
  คุณสามารถดู Space-agent mapping ใน admin panel ใต้ส่วน "Space mappings" ของ integration card
</Callout>

## ฟีเจอร์

### Async Response

เมื่อคุณส่งข้อความ bot จะตอบกลับทันทีด้วย acknowledgment สั้นๆ (เช่น "Working on it...") จากนั้นส่งคำตอบเต็มเมื่อประมวลผลเสร็จ โดยปกติใช้เวลา 3–8 วินาทีขึ้นอยู่กับความซับซ้อนของคำถาม

### Conversation Memory

Bot จดจำ context ภายใน session ดังนั้นคุณสามารถถามคำถามต่อเนื่องได้โดยไม่ต้องทวนซ้ำ

**การรับรู้บริบทของ thread (Spaces):** เมื่อ @mention bot ใน thread ของ Space bot จะอ่านประวัติ thread ทั้งหมดก่อนตอบ — เพื่อเข้าใจว่าทีมกำลังพูดถึงอะไร การ @mention ต่อๆ ไปในช่อง thread เดียวกันจะรักษาความต่อเนื่องของการสนทนาโดยอัตโนมัติ

### Message Queuing

หากคุณส่งข้อความเพิ่มเติมขณะที่ bot ยังประมวลผลอยู่ ข้อความจะถูกเข้าคิวและรวมในคำตอบถัดไป คุณจะเห็นข้อความเช่น "I'm still working on your previous question. I'll include this in my next response."

### `/help` Command

พิมพ์ `/help` หรือ `help` เพื่อดูคำแนะนำการใช้งาน รวมถึง space command ที่ใช้ได้

### Domain-Based Access

เฉพาะผู้ใช้จาก Google Workspace domain ของคุณเท่านั้นที่สามารถโต้ตอบกับ bot เพื่อความปลอดภัยระดับองค์กร

### การตอบกลับแบบข้อความ

Bot ตอบด้วยข้อความเท่านั้น ไม่รองรับรูปภาพ, ไฟล์, interactive button และ card attachment คำตอบจำกัดที่ประมาณ 30,000 ตัวอักษร

## การจัดการ Integration

แต่ละ integration card จะแสดง:
- **Bot name** - ชื่อที่คุณตั้ง
- **Status badge** - Active, Pending Verification หรือ Error
- **Domain name** - Google Workspace domain ของคุณ (หลัง verification)
- **Default agent** - Dropdown เพื่อเปลี่ยน default agent (ใช้สำหรับ DM + Space ที่ไม่ได้เชื่อมต่อ)
- **Space mappings** - ส่วนที่ยุบได้แสดงว่า Space ใดมี custom agent
- **Space commands** - ส่วนที่ยุบได้แสดง bot command ที่ใช้ได้
- **Last activity** timestamp

### การดำเนินการที่ใช้ได้

| การดำเนินการ | คำอธิบาย |
|-------------|----------|
| **Change default agent** | ใช้ dropdown เพื่อเปลี่ยน agent ที่จัดการ DM และ Space ที่ไม่ได้เชื่อมต่อ |
| **Test Connection** | ตรวจสอบว่า integration ทำงานอยู่ (เมนูสามจุด) |
| **Disconnect** | ลบ integration นี้ (เมนูสามจุด) |

## การแก้ไขปัญหา

### Bot ไม่แสดงใน Google Chat

1. ตรวจสอบว่าคุณใช้บัญชี Google Workspace (ไม่ใช่ Gmail ส่วนตัว)
2. ค้นหาชื่อ bot ใน "Find apps"
3. รอสักครู่เพื่อให้ app propagate

### ส่วน Google Chat ไม่แสดง

1. Google Chat แสดงเฉพาะสำหรับองค์กรที่ใช้ Google Workspace
2. หากองค์กรของคุณใช้ email provider อื่น (เช่น Microsoft 365) ส่วนนี้จะถูกซ่อน
3. ระบบตรวจจับ email provider โดยอัตโนมัติผ่าน MX record

### ปัญหา Domain Verification

1. การเปลี่ยนแปลง DNS อาจใช้เวลาถึง 48 ชั่วโมงในการ propagate — รอแล้วลอง **Verify Now** อีกครั้ง
2. ตรวจสอบว่าเพิ่ม TXT record ด้วยค่าที่ถูกต้องตามที่แสดงใน Settings > Domains
3. ตรวจสอบว่า record อยู่บน domain ที่ถูกต้อง (เช่น `_cuneiform-verify.yourdomain.com`)
4. ใช้ลิงก์ด่วน DNS provider บน verification card เพื่อเข้าถึงง่าย

### Verification Code ไม่ทำงาน

1. ตรวจสอบว่าคุณส่ง code จากอีเมล Google Workspace ของคุณ
2. ตรวจสอบว่ากรอก code ตรงตามที่แสดง (รวมถึง prefix `VERIFY-`)
3. ตรวจสอบว่า integration ยังอยู่ในสถานะ "Pending Verification"
4. ลองสร้าง integration ใหม่หาก code หมดอายุ

### Bot บอก "Working on it..." แต่ไม่มีคำตอบตามมา

1. Bot ประมวลผลข้อความแบบ async — รอถึง 25 วินาทีสำหรับคำตอบเต็ม
2. หากไม่มีคำตอบ ลองส่งข้อความอีกครั้ง
3. ตรวจสอบว่า agent ที่เชื่อมต่อตั้งค่าถูกต้อง

### ข้อความไม่ถูกประมวลผล

1. ยืนยันว่า workspace ถูก verify แล้ว (สถานะควรเป็น "Active")
2. สำหรับ Space ตรวจสอบว่าคุณ @mention bot
3. ตรวจสอบว่า agent ที่เชื่อมต่อตั้งค่าถูกต้อง

### ข้อความ "Organization hasn't connected"

หมายความว่า bot ไม่รู้จัก Google Workspace domain ของคุณ:
1. Admin ยังไม่ได้สร้าง integration
2. Domain ยังไม่ได้ verify ด้วย verification code
3. คุณส่งข้อความจาก Gmail ส่วนตัว (ไม่รองรับ)

### `/set-agent` บอกว่าไม่พบ Agent

1. ตรวจสอบชื่อ agent ให้ตรงกับใน admin panel (case-sensitive)
2. ตรวจสอบว่า agent อยู่ในสถานะ "Active"
3. ชื่อ agent ที่มีช่องว่างรองรับได้ — พิมพ์ชื่อเต็มหลัง `/set-agent`

## ความปลอดภัย

- **Domain ownership verification** — DNS TXT record พิสูจน์ว่าองค์กรของคุณเป็นเจ้าของ domain ก่อนเชื่อมต่อ
- **Google Workspace detection** — ตรวจสอบ MX record เพื่อยืนยันว่า domain ใช้ Google Workspace
- **Domain-based isolation** — เฉพาะผู้ใช้ Google Workspace ขององค์กรคุณเท่านั้นที่โต้ตอบกับ bot ได้
- **Webhook verification** — ทุก request ที่เข้ามาจะถูกตรวจสอบกับ Google Cloud project ของ platform
- **Verification code** ใช้ได้ครั้งเดียวและผูกกับ domain ของคุณ
- ข้อความถูกประมวลผลผ่านการเชื่อมต่อที่ปลอดภัยและเข้ารหัส

## การยกเลิกการเชื่อมต่อ

วิธีลบ Google Chat integration:

1. ไปที่ **Integrations** จาก sidebar
2. หา Google Chat integration card
3. คลิกเมนูสามจุด
4. เลือก **Disconnect**

## หมายเหตุสำคัญ

- **ต้องใช้ Google Workspace**: Gmail ส่วนตัวไม่สามารถใช้ integration นี้ได้ หากองค์กรไม่ใช้ Google Workspace ส่วน Google Chat จะไม่แสดง
- **ต้อง verify domain**: ยืนยัน domain ใน Settings > Domains ก่อนเชื่อมต่อ Google Chat
- **หนึ่ง integration ต่อองค์กร**: แต่ละองค์กรมี Google Chat integration ได้หนึ่งตัว
- **ข้อความเท่านั้น**: Bot ไม่รองรับรูปภาพ, ไฟล์ หรือ interactive button
- **จัดการระดับองค์กร**: Google Chat ตั้งค่าในหน้า Integrations ไม่ใช่ต่อ agent
- **Space routing**: ใช้ `/set-agent` ใน Space เพื่อกำหนด agent เฉพาะทางให้ทีมต่างๆ
- **Default agent**: เปลี่ยน default agent ได้ตลอดเวลาด้วย dropdown — ไม่ต้อง disconnect
