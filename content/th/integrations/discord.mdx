# การเชื่อมต่อ Discord

เพิ่ม agent ของคุณใน Discord server ด้วย slash command และ direct message

## ภาพรวม

Discord integration มีความสามารถ:
- รองรับ slash command (`/ask`)
- การสนทนาผ่าน direct message
- ใช้งานได้ทั้ง server
- ตอบเฉพาะ channel
- Rich embed formatting
- Text DM แบบไม่ต้องใช้ command (ตัวเลือกเสริม)

## ข้อกำหนดเบื้องต้น

- บัญชี Discord
- สิทธิ์ Manage Server บน server เป้าหมาย
- เข้าถึง Discord Developer Portal

## ขั้นตอนการตั้งค่า

### 1. สร้าง Discord Application

1. ไปที่ [Discord Developer Portal](https://discord.com/developers/applications)
2. คลิก **New Application**
3. ตั้งชื่อ (เช่น "My Support Bot")
4. คลิก **Create**

### 2. รับ Credential ของคุณ

จาก Discord Developer Portal ให้เก็บค่าเหล่านี้:

| Field | คำอธิบาย | ตำแหน่ง |
|-------|----------|---------|
| **Application ID** | ID ของ Discord app | หน้า General Information |
| **Public Key** | Hex string 64 ตัวอักษรสำหรับ signature verification | หน้า General Information |
| **Bot Token** | Secret token สำหรับ bot | ส่วน Bot → **Reset Token** |
| **Guild ID** (ไม่จำเป็น) | Server ID สำหรับลงทะเบียน command ทันที | คลิกขวาที่ server → Copy Server ID |

### 3. เชื่อมต่อกับ Cuneiform Chat

1. ไปที่ **Agents** → เลือก agent ของคุณ
2. ไปที่แท็บ **Integrations**
3. คลิก **Discord**
4. กรอก **Application ID**, **Public Key** และ **Bot Token**
5. กรอก **Guild ID** (ไม่จำเป็น) สำหรับลงทะเบียน slash command ทันที
6. คลิก **Connect**

### 4. ตั้งค่า Webhook URL (จำเป็น)

หลังเชื่อมต่อ คุณจะเห็น dialog สำเร็จพร้อม **Webhook URL**:

1. คัดลอก **Webhook URL** จาก dialog
2. ใน Discord Developer Portal ไปที่ **General Information**
3. หา **Interactions Endpoint URL**
4. วาง webhook URL และคลิก **Save Changes**

<Callout type="info">
  ขั้นตอนนี้จำเป็น Discord ใช้ URL นี้ในการส่ง slash command interaction ไปยัง bot ของคุณ
</Callout>

### 5. เพิ่ม Bot ใน Server ของคุณ

ใช้ปุ่ม **Add to Server** บน integration card หรือใช้ invite URL ที่ได้หลังเชื่อมต่อ เพื่อเพิ่ม bot พร้อมสิทธิ์ที่จำเป็น

## การใช้งาน Bot

### Slash Command

ผู้ใช้โต้ตอบกับ bot ด้วย slash command `/ask`:

```
/ask What are your business hours?
```

Bot ประมวลผลคำถามและตอบกลับใน channel

### Direct Message

ส่งข้อความตรงถึง bot สำหรับการสนทนาส่วนตัว:

1. หา bot ในรายชื่อสมาชิกของ server
2. คลิกขวาและเลือก **Message**
3. ใช้ command `/ask` หรือเปิด Text DM (ดูด้านล่าง)

### Text DM Toggle

สวิตช์ **Text DMs** บน integration card ควบคุมพฤติกรรม direct message:

- **Off** (ค่าเริ่มต้น): ผู้ใช้ต้องใช้ command `/ask` ใน DM
- **On**: ผู้ใช้สามารถส่งข้อความธรรมดาใน DM ได้ (ไม่ต้องใช้ command prefix)

<Callout type="info">
  เมื่อเปิด Text DM คุณต้องเปิด **Message Content Intent** ใน Discord Developer Portal → ส่วน Bot → Privileged Gateway Intents
</Callout>

### รูปแบบการตอบกลับ

คำตอบจะแสดงเป็น rich embed พร้อม:
- ข้อความคำตอบ
- แหล่งอ้างอิง (ตัวเลือกเสริม)
- Branding ของ bot

## ฟีเจอร์

### การเข้าถึงทั้ง Server

เมื่อเพิ่มแล้ว bot จะใช้งานได้ใน text channel ทั้งหมดที่มีสิทธิ์

### Thread Support

Bot สามารถตอบใน thread เพื่อจัดระเบียบการสนทนา

### Instant vs Global Command

- **มี Guild ID**: Slash command ลงทะเบียนทันทีใน server นั้น
- **ไม่มี Guild ID**: Global command ใช้เวลาถึง 1 ชั่วโมงในการเผยแพร่

<Callout type="important">
  ระบุ Guild ID ระหว่างตั้งค่าเพื่อให้ slash command พร้อมใช้ทันที คุณสามารถเพิ่ม server อื่นได้ภายหลัง
</Callout>

## การจัดการ Bot

แต่ละ bot ที่เชื่อมต่อจะแสดง:
- **Bot username** และสถานะ (Active/Error)
- **Application ID**
- **Agent ที่เชื่อมต่อ**
- **Last activity** timestamp
- **Webhook URL** (สำหรับอ้างอิง)

### การดำเนินการที่ใช้ได้

| การดำเนินการ | คำอธิบาย |
|-------------|----------|
| **Add to Server** | เปิด invite link เพื่อเพิ่ม bot ใน server |
| **Portal** | เปิด Discord Developer Portal สำหรับ app นี้ |
| **Copy URL** | คัดลอก webhook URL |
| **Test Connection** | ตรวจสอบการเชื่อมต่อของ bot |
| **Disconnect** | ลบ integration นี้ |

## การแก้ไขปัญหา

### Bot ไม่ตอบสนอง

1. ตรวจสอบว่า **Interactions Endpoint URL** ตั้งค่าแล้วใน Discord Developer Portal
2. ยืนยันว่า bot มีสิทธิ์ใน channel
3. ตรวจสอบว่า token ถูกต้องใน Cuneiform Chat
4. ทดสอบว่า slash command ลงทะเบียนแล้ว (กด `/` แล้วจะเห็น command ของคุณ)

### Command ไม่แสดง

Slash command อาจใช้เวลาถึงหนึ่งชั่วโมงในการลงทะเบียนแบบ global สำหรับทดสอบทันที:
- ระบุ Guild ID ระหว่างตั้งค่าเพื่อลงทะเบียนทันที
- รอ global propagation หากไม่ได้ระบุ Guild ID

### Permission Error

ตรวจสอบว่า bot มีสิทธิ์เหล่านี้:
- Send Messages
- Use Slash Commands
- Embed Links
- Read Message History (สำหรับ thread support)

### Text DM ไม่ทำงาน

1. ตรวจสอบว่าเปิด **Text DMs** toggle บน integration card แล้ว
2. เปิด **Message Content Intent** ใน Discord Developer Portal → ส่วน Bot
3. Restart การเชื่อมต่อ bot หากจำเป็น

## ความปลอดภัย

- Bot token ถูกเข้ารหัสและจัดเก็บอย่างปลอดภัย
- Command ใช้ signature verification ในตัวของ Discord
- ไม่มีการเข้าถึงข้อมูล server นอกเหนือจากการโต้ตอบโดยตรง

## การยกเลิกการเชื่อมต่อ

วิธีลบ Discord integration:

1. ไปที่ **Agents** → เลือก agent → **Integrations**
2. คลิกเมนูสามจุดบน Discord bot ของคุณ
3. เลือก **Disconnect**

วิธีลบ bot ออกจาก Discord อย่างสมบูรณ์:
1. ไปที่การตั้งค่า Discord server ของคุณ
2. ไปที่ **Integrations** → ลบ bot
