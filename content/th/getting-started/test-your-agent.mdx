# ทดสอบ Agent ของคุณ

ก่อน deploy agent ให้ใช้ Playground เพื่อทดสอบคำตอบและปรับแต่งพฤติกรรม

## การเข้าถึง Playground

1. ไปที่ **Agents** ในแถบด้านข้าง
2. คลิก **Test** บนการ์ด agent ของคุณ
3. Playground จะเปิดเป็น side panel — เริ่มแชทได้เลย!

ใช้ปุ่ม toggle ที่แถบด้านข้างเพื่อซ่อนรายการสนทนาสำหรับพื้นที่เพิ่มเติม กด **Shift+Enter** เพื่อขึ้นบรรทัดใหม่โดยไม่ส่งข้อความ

## การทดสอบ Agent

### ถามคำถามตัวอย่าง

ลองถามคำถามที่ผู้ใช้ของคุณอาจถาม:

- คำถามที่ตอบได้โดยตรงจากเอกสารของคุณ
- คำถามต่อเนื่องที่ต้องใช้ context
- กรณีพิเศษและคำถามที่คลุมเครือ
- คำถามนอกเหนือเนื้อหาของคุณ (เพื่อทดสอบขอบเขต)

### ประเมินคำตอบ

สำหรับแต่ละคำตอบ ให้พิจารณา:

- **Accuracy** — ข้อมูลถูกต้องหรือไม่?
- **Relevance** — ตอบคำถามจริงๆ หรือไม่?
- **Tone** — ตรงกับสไตล์ที่คุณคาดหวังหรือไม่?
- **Sources** — source reference มีประโยชน์หรือไม่?

## การปรับแต่ง Agent

จากการทดสอบ คุณอาจต้องการปรับ:

### Agent Persona

หากคำตอบยังไม่ถูกต้อง ให้ปรับแต่ง agent persona:

- เพิ่มคำสั่งเฉพาะสำหรับสถานการณ์ทั่วไป
- ทำให้ tone และ personality ชัดเจนขึ้น
- กำหนดขอบเขตสิ่งที่ agent ควรและไม่ควรทำ

### เนื้อหา

หาก agent หาข้อมูลไม่เจอ:

- ตรวจสอบว่าอัปโหลดเอกสารที่เกี่ยวข้องแล้ว
- ตรวจสอบว่าเอกสารประมวลผลสำเร็จ
- พิจารณาเพิ่มเนื้อหาที่มีรายละเอียดมากขึ้น

## ประวัติการสนทนา

Playground เก็บประวัติการสนทนาภายใน session ใช้เพื่อทดสอบ:

- การสนทนาหลายรอบ
- การรักษา context
- คำถามต่อเนื่อง

ขณะที่ agent ตอบ คุณจะเห็น tool indicator แสดงว่ากำลังทำอะไรอยู่ (ค้นหาเอกสาร, ประมวลผลคำถามของคุณ เป็นต้น) คลิก **Stop** หากต้องการยกเลิกคำตอบ

## การเปิดใช้งาน Agent

Agent ใหม่จะเริ่มต้นในสถานะ **Testing** — คุณสามารถทดสอบใน Playground ได้ แต่ channel integration จะถูกปิด

เพื่อเปิดใช้งาน integration:

1. เปิดหน้าแก้ไข agent ของคุณ
2. เปลี่ยน dropdown **Status** จาก "Testing" เป็น "Active"
3. คลิก **Save**

เมื่อเปิดใช้งานแล้ว คุณสามารถ deploy ไปยัง channel ต่างๆ:

- [Telegram](/integrations/telegram) — เชื่อมต่อกับ Telegram
- [Discord](/integrations/discord) — เพิ่มไปยัง Discord server ของคุณ
- [Slack](/integrations/slack) — เชื่อมต่อกับ Slack workspace
- [WhatsApp](/integrations/whatsapp) — เชื่อมต่อกับ WhatsApp Business
- [Messenger](/integrations/facebook) — เชื่อมต่อกับ Facebook Messenger
- [Google Chat](/integrations/google-chat) — เชื่อมต่อกับ Google Workspace
