# เพิ่มเนื้อหา

ความรู้ของ chatbot มาจากเนื้อหาที่คุณให้ คู่มือนี้แสดงวิธีอัปโหลดเอกสารและ crawl เว็บไซต์เพื่อสร้างเนื้อหาของคุณ

## การเข้าถึงเนื้อหา

1. เข้าสู่ระบบ Cuneiform Chat dashboard ของคุณ
2. ไปที่ **Content** ในแถบด้านข้าง
3. คลิก **Upload Documents** หรือลากและวางไฟล์

## ประเภทไฟล์ที่รองรับ

Cuneiform Chat รองรับรูปแบบเอกสารหลากหลาย:

| รูปแบบ | นามสกุล | หมายเหตุ |
|--------|---------|----------|
| PDF | `.pdf` | แบบข้อความและสแกน (OCR) |
| Word | `.docx`, `.doc` | เอกสาร Microsoft Word |
| Text | `.txt`, `.md`, `.rtf` | Plain text, Markdown, Rich Text |
| PowerPoint | `.pptx`, `.ppt` | สไลด์นำเสนอ |
| Web/Data | `.html`, `.htm`, `.json`, `.xml` | หน้าเว็บและข้อมูลเชิงโครงสร้าง |

## วิธีการอัปโหลด

### อัปโหลดโดยตรง

1. คลิก **Upload Documents**
2. เลือกไฟล์จากคอมพิวเตอร์ของคุณ
3. รอให้การประมวลผลเสร็จสิ้น

### ลากและวาง

เพียงลากไฟล์จากคอมพิวเตอร์ของคุณและวางลงในพื้นที่ Content

### Cloud Storage

เชื่อมต่อ cloud storage สำหรับการนำเข้าที่สะดวก:

- **Google Drive** — นำเข้าจาก Drive ของคุณโดยตรง
- **Dropbox** — เชื่อมต่อบัญชี Dropbox ของคุณ
- **OneDrive** — นำเข้าจาก Microsoft OneDrive
- **Box** — เชื่อมต่อบัญชี Box ของคุณ

ดู [Cloud Storage Integration](/knowledge-base/cloud-storage) สำหรับคำแนะนำการตั้งค่า

### Website Crawling

Crawl เว็บไซต์สาธารณะและนำเข้าเนื้อหาเป็นเอกสาร:

1. ไปที่ **Content** และคลิกแท็บ **Website**
2. กรอก URL และคลิก **Crawl**
3. ตรวจสอบและแก้ไขหน้าที่ crawl ได้
4. เลือกหน้าและคลิก **Process Selected**

Crawler จะตามลิงก์ได้ลึกสูงสุด 2 ระดับ จำนวนหน้าที่สามารถ crawl ได้ขึ้นอยู่กับ [plan](/billing/plans) ของคุณ

ดู [Website Crawling](/knowledge-base/website-crawling) สำหรับคู่มือฉบับเต็ม

## การประมวลผลเอกสาร

หลังจากอัปโหลดหรือ crawl เนื้อหาของคุณจะถูกประมวลผลและพร้อมให้ agent ค้นหาโดยอัตโนมัติ

import { Callout } from 'nextra/components'

<Callout type="info">
  เวลาในการประมวลผลขึ้นอยู่กับขนาดและความซับซ้อนของเอกสาร เอกสารส่วนใหญ่จะเสร็จภายในไม่กี่นาที ระบบจะตรวจจับเนื้อหาที่ซ้ำซ้อนโดยอัตโนมัติเพื่อหลีกเลี่ยงการอัปโหลดซ้ำ
</Callout>

## แนวทางปฏิบัติที่ดี

- **คุณภาพสำคัญกว่าปริมาณ** — เอกสารที่มีโครงสร้างดีจะให้คำตอบที่ดีกว่า
- **อัปเดตเนื้อหาให้ทันสมัย** — ลบเอกสารที่ล้าสมัยเพื่อหลีกเลี่ยงความสับสน
- **จัดระเบียบด้วยโฟลเดอร์** — ใช้โครงสร้างโฟลเดอร์เพื่อจัดระเบียบเอกสาร
- **Crawl อย่างเลือกสรร** — ตรวจสอบและแก้ไขหน้าที่ crawl ก่อนประมวลผลเพื่อลบ navigation และ boilerplate

## ขั้นตอนถัดไป

เมื่ออัปโหลดเอกสารแล้ว คุณพร้อมที่จะ[สร้าง agent ตัวแรกของคุณ](/getting-started/first-agent)
