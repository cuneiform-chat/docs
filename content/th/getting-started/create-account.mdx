# สร้างบัญชี

เริ่มต้นใช้งาน Cuneiform Chat โดยการสร้างบัญชีของคุณ

## สมัครสมาชิก

1. ไปที่ [cuneiform.chat](https://cuneiform.chat)
2. คลิก **Get Started** หรือ **Sign Up**
3. เลือกวิธีเข้าสู่ระบบ:
   - **Google** — คลิก "Sign in with Google" เพื่อเข้าสู่ระบบด้วยคลิกเดียว
   - **Microsoft** — คลิก "Sign in with Microsoft" เพื่อใช้บัญชี Microsoft 365 ของคุณ
   - **Email** — กรอกอีเมลของคุณและคลิก "Continue with Email"
4. หากใช้ email ให้ตรวจสอบกล่องจดหมายและคลิก magic link เพื่อเข้าสู่ระบบ

## ตัวเลือกการเข้าสู่ระบบ

คุณสามารถเข้าสู่ระบบโดยใช้:
- **Google** — เข้าสู่ระบบด้วยคลิกเดียวผ่านบัญชี Google ของคุณ
- **Microsoft** — เข้าสู่ระบบด้วยบัญชี Microsoft 365 หรือบัญชีที่ทำงาน
- **Email magic link** — เข้าสู่ระบบแบบไม่ต้องใช้รหัสผ่าน ผ่านลิงก์ที่ส่งไปยังอีเมลของคุณ

## สร้าง Organization ของคุณ

หลังจากเข้าสู่ระบบครั้งแรก คุณจะต้องสร้าง organization ซึ่งเป็น workspace สำหรับจัดการ agent, เอกสาร และ integration ต่างๆ

1. ที่ dashboard คลิก **Create Organization**
2. กรอก **Organization Name** (ชื่อบริษัทหรือโปรเจค)
3. เพิ่ม **Description** ของ organization ได้ตามต้องการ
4. เลือก **Industry** และ **Company Size**
5. เพิ่ม **Support Contact** ได้ตามต้องการ (อีเมล, โทรศัพท์, เว็บไซต์, ที่อยู่) — agent ของคุณจะแชร์ข้อมูลเหล่านี้เมื่อผู้ใช้ต้องการความช่วยเหลือจากคน
6. คลิก **Create Organization**

Organization ช่วยให้คุณ:

- จัดการหลาย agent ภายใต้บัญชีเดียว
- เชิญสมาชิกในทีมและควบคุมสิทธิ์การเข้าถึง
- ติดตามการใช้งานและ billing สำหรับ chatbot ทั้งหมดของคุณ

คุณสามารถอัปเดตรายละเอียด organization ได้ตลอดเวลาจาก **Account Management** ในเมนูโปรไฟล์ของคุณ

## ช่วง Trial

บัญชีใหม่จะเริ่มต้นด้วย trial ฟรีที่รวมถึง:
- เข้าถึง feature ทั้งหมด
- credit สำหรับทดสอบการประมวลผลเอกสารและ AI query
- ไม่ต้องใช้บัตรเครดิต
