# สร้าง Agent แรกของคุณ

Agent คือ chatbot ที่โต้ตอบกับผู้ใช้ของคุณ แต่ละ agent สามารถตั้งค่า knowledge, พฤติกรรม และ personality เฉพาะได้

## การสร้าง Agent

1. ไปที่ **Agents** ในแถบด้านข้าง
2. คลิก **Create Agent**
3. กรอกข้อมูลพื้นฐาน:
   - **Name** — ชื่อที่สื่อความหมายสำหรับ agent ของคุณ (เช่น "Customer Support Bot")
   - **Description** — agent ตัวนี้ทำอะไร (สำหรับอ้างอิงของคุณ)

## การตั้งค่า Agent

### Agent Persona

Agent persona กำหนด personality และพฤติกรรมของ agent คือคำสั่งที่แนะนำวิธีการตอบของ agent

คุณสามารถเขียน persona เองหรือคลิก **Generate** เพื่อใช้ Persona Builder ที่ขับเคลื่อนด้วย AI ซึ่งจะสร้าง persona ตามความต้องการของคุณ

**ตัวอย่าง:**
```
You are a helpful customer support assistant for Acme Corp.
You answer questions about our products and services based on the provided documentation.
Be friendly, professional, and concise.
If you don't know the answer, say so rather than making something up.
```

### Platform Rules

Agent ทุกตัวจะมี safety guardrail ในตัวโดยอัตโนมัติ:

- ไม่สร้างข้อเท็จจริง ตัวเลข หรือวันที่ปลอม
- บอกว่า "ไม่ทราบ" เมื่อไม่มีข้อมูล
- ไม่เดาข้อมูลที่ขาดหายไป
- แก้ไขสมมติฐานที่ไม่ถูกต้องในคำถาม
- ไม่แอบอ้างเป็นผู้เชี่ยวชาญ (ทนายความ, แพทย์ เป็นต้น)
- ปฏิเสธเนื้อหาที่เป็นอันตรายหรือไม่เหมาะสม

กฎเหล่านี้ทำงานตลอดเวลาและไม่สามารถปิดได้

### Knowledge Access Control

ควบคุมว่า agent สามารถเข้าถึงเอกสารใดได้บ้าง:

- **Exclude Mode** (ค่าเริ่มต้น) — Agent เข้าถึงเอกสารทั้งหมด ยกเว้นที่คุณเลือกซ่อน
- **Include Mode** — Agent เข้าถึงเฉพาะโฟลเดอร์ แท็ก หรือเอกสารที่คุณเลือกเท่านั้น

ใช้ Include Mode เมื่อคุณต้องการจำกัด agent ให้เข้าถึงเฉพาะชุด knowledge ที่กำหนด

### LLM Configuration

สำหรับผู้ใช้ส่วนใหญ่ การตั้งค่า AI model เริ่มต้นจะเหมาะสมดีอยู่แล้ว ผู้ใช้ขั้นสูงสามารถปรับแต่ง:

- **Model** — เลือกจาก AI model ที่มีให้
- **Temperature** — ต่ำ = สม่ำเสมอมากขึ้น, สูง = สร้างสรรค์มากขึ้น
- **Show Document References** — เปิดใช้เพื่อแสดง source citation ในคำตอบ
