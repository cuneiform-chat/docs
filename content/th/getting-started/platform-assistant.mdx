# Platform Assistant

พบกับ Saba ผู้ช่วย AI สำหรับการใช้งาน Cuneiform Chat

## Saba คืออะไร?

Saba คือ AI assistant ในแอปที่ช่วยให้คุณใช้งาน Cuneiform Chat ได้อย่างเต็มประสิทธิภาพ ตั้งชื่อตาม Nisaba — เทพธิดาแห่งการเขียนและศิลปะการจารึกของชาวสุเมเรียน — Saba เป็นตัวแทนการเดินทางของเราจากแผ่นดินเหนียวสู่ chatbot

Saba สามารถช่วยคุณ:

- เรียนรู้เกี่ยวกับ feature ของ platform และวิธีใช้งาน
- เข้าถึงข้อมูลเกี่ยวกับ agent, เอกสาร และ integration ของคุณ
- เข้าใจรายละเอียด billing และ subscription ของคุณ
- แก้ไขปัญหาทั่วไป

## การเข้าถึง Saba

### ปุ่มลอย

มองหาไอคอน Saba ที่ **มุมขวาล่าง** ของหน้าจอ คลิกเพื่อเปิด assistant

### Keyboard Shortcuts

| การกระทำ | Mac | Windows/Linux |
|----------|-----|---------------|
| เปิด/ปิด Saba | `Cmd + K` | `Ctrl + K` |
| สนทนาใหม่ | `Cmd + N` | `Ctrl + N` |
| ปิด | `Escape` | `Escape` |

## Saba ช่วยอะไรได้บ้าง

### Feature ของ Platform

ถามคำถามเช่น:

- "ฉันจะสร้าง agent ได้อย่างไร?"
- "รองรับรูปแบบไฟล์อะไรบ้าง?"
- "ฉันจะเชื่อมต่อ Slack ได้อย่างไร?"

### ข้อมูลของคุณ

Saba สามารถเข้าถึงข้อมูลของ organization เพื่อตอบคำถามเฉพาะ:

- "ฉันมี agent กี่ตัว?"
- "มีเอกสารอะไรบ้างในเนื้อหาของฉัน?"
- "integration ไหนที่เปิดใช้งานอยู่?"

### ข้อมูล Billing

รับคำตอบเร็วๆ เกี่ยวกับบัญชีของคุณ:

- "ฉันใช้ plan อะไร?"
- "ฉันใช้ credit ไปเท่าไหร่?"
- "billing period สิ้นสุดเมื่อไหร่?"

## Feature ต่างๆ

### Query Mode

สลับระหว่างโหมดการตอบโดยใช้ปุ่มข้างช่องกรอกข้อความ:

- **Fast** (ไอคอน Zap) — คำตอบเร็วสำหรับคำถามง่ายๆ
- **Reasoning** (ไอคอน Brain) — วิเคราะห์ละเอียดขึ้นสำหรับคำถามซับซ้อน

ค่าที่คุณเลือกจะถูกบันทึกข้าม session

### การตรวจจับภาษาอัตโนมัติ

Saba ตรวจจับภาษาของข้อความโดยอัตโนมัติและตอบในภาษาเดียวกัน — ไม่ต้องตั้งค่าใดๆ รองรับ 176 ภาษา เพียงพิมพ์ในภาษาที่คุณต้องการ แล้ว Saba จะตอบตามนั้น

### Voice Input

คลิก **ไอคอนไมโครโฟน** ข้างปุ่มส่งเพื่อพูดคำถามแทนการพิมพ์

### Slash Commands

พิมพ์ `/` ในช่องกรอกข้อความเพื่อดูคำสั่งด่วน:

| คำสั่ง | ทำอะไร |
|--------|--------|
| `/agents` | แสดงรายการ agent ทั้งหมดพร้อมสถานะ |
| `/usage` | แสดงสถิติการใช้งานของคุณ |
| `/docs` | แสดงเอกสารในเนื้อหาของคุณ |
| `/help` | แสดงรายการคำสั่งที่ใช้ได้ |
| `/new` | คำแนะนำแบบ step-by-step เพื่อสร้าง agent |
| `/conversations` | แสดงกิจกรรมสนทนาล่าสุด |

### ประวัติการสนทนา

การสนทนาของคุณกับ Saba จะถูกบันทึกอัตโนมัติ เข้าถึงการสนทนาก่อนหน้าจาก sidebar เพื่อสนทนาต่อจากจุดที่ค้างไว้

### คำถามแนะนำ

Saba แนะนำคำถามที่เกี่ยวข้องตามหน้าปัจจุบันของคุณ คำถามเหล่านี้จะแสดงเป็นตัวเลือกเริ่มต้นเมื่อคุณเปิด assistant

### คำถามต่อเนื่องแนะนำ

หลังจากแต่ละคำตอบ Saba จะเสนอคำถามที่เกี่ยวข้องที่คุณอาจต้องการถามต่อ

### Export การสนทนา

บันทึกการสนทนาโดยใช้ปุ่ม export:

- **Download as Markdown** — บันทึกเป็นไฟล์ .md พร้อม formatting
- **Download as Text** — บันทึกเป็นไฟล์ .txt แบบ plain text
- **Copy to Clipboard** — คัดลอกการสนทนาทั้งหมด

### Feedback

ช่วยปรับปรุง Saba ด้วยตัวเลือก feedback ในแต่ละคำตอบ:

- **Thumbs up/down** — feedback เร็วๆ เกี่ยวกับคุณภาพคำตอบ
- **Submit Feedback** — ให้ความคิดเห็นโดยละเอียดเพื่อช่วยปรับปรุง assistant
