# เริ่มต้นใช้งาน

เริ่มต้นใช้งาน Cuneiform Chat ได้ในเวลาไม่กี่นาที คู่มือนี้จะพาคุณสร้าง AI chatbot ตัวแรกที่เรียนรู้จากเอกสารของคุณ

## สิ่งที่คุณจะได้เรียนรู้

- วิธีสร้างและตั้งค่าบัญชีของคุณ
- วิธีอัปโหลดเอกสารไปยังเนื้อหาของคุณ
- วิธีสร้างและตั้งค่า agent ตัวแรกของคุณ
- วิธีทดสอบ agent ใน Playground

## สิ่งที่ต้องเตรียม

- อีเมลที่ใช้งานได้
- เอกสารที่คุณต้องการให้ chatbot เรียนรู้ (PDF, Word, ไฟล์ข้อความ เป็นต้น)

## เวลาที่ใช้

คุณสามารถมี chatbot ที่ใช้งานได้ภายในไม่ถึง 10 นาที ขึ้นอยู่กับขนาดของเอกสารที่อัปโหลด
