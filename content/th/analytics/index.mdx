# การวิเคราะห์

ติดตามประสิทธิภาพของ agent และทำความเข้าใจว่าผู้ใช้โต้ตอบกับ chatbot ของคุณอย่างไร

## ภาพรวม

การวิเคราะห์ช่วยให้คุณ:
- ติดตามปริมาณการสนทนาและรูปแบบ query
- ตรวจสอบประสิทธิภาพของ agent และการใช้ credit
- เข้าใจการกระจายตามช่องทาง
- ระบุจุดที่ต้องปรับปรุง

## Dashboard

เข้าถึงการวิเคราะห์จากส่วน **Analytics** ในแถบด้านข้าง

### ตัวชี้วัดหลัก

| ตัวชี้วัด | คำอธิบาย |
|-----------|----------|
| Total Queries | การทำงานของ Agent (AI response) |
| Conversations | จำนวน chat session |
| Unique Users | ผู้ใช้ที่ chat เข้ามา |
| Credits Used | Credit ของแพลตฟอร์มที่ใช้ไป |

### การใช้ Credit

Dashboard แสดงการใช้ credit ในรอบบิลปัจจุบันของคุณ:
- Credit ที่ใช้ไป เทียบกับ credit ที่ได้รับ
- แถบแสดงเปอร์เซ็นต์
- Credit ที่เหลือสำหรับช่วงเวลานี้

### แผนภูมิ

Dashboard มีแผนภูมิให้ดู:
- **Query Volume** — กราฟเส้นแสดง query ตามช่วงเวลา
- **Channel Distribution** — กราฟวงกลมแสดง query แยกตาม channel
- **Agent Distribution** — กราฟวงกลมแสดง query แยกตาม agent

### Agent ยอดนิยม

รายการจัดอันดับ agent ที่มีการใช้งานมากที่สุด แสดง:
- ชื่อและอันดับของ agent
- จำนวน query ที่จัดการทั้งหมด
- จำนวนการสนทนา
- Credit ที่ใช้ไป
- สถานะปัจจุบัน (active, inactive, testing, archived)

คลิกที่ agent ใดก็ได้เพื่อดูการวิเคราะห์โดยละเอียด หรือคลิก **View All** เพื่อดู agent ทั้งหมด

### Channel ยอดนิยม

รายการจัดอันดับช่องทางการสื่อสารที่มีการใช้งานมากที่สุด แสดง:
- ชื่อและอันดับของ channel
- จำนวน query ที่จัดการทั้งหมด
- จำนวนการสนทนา
- Credit ที่ใช้ไป

คลิกที่ channel ใดก็ได้เพื่อดูการวิเคราะห์โดยละเอียด หรือคลิก **View All** เพื่อดู channel ทั้งหมด

## ช่วงเวลา

ดูการวิเคราะห์สำหรับช่วงเวลาต่างๆ:
- รอบบิลปัจจุบัน
- 7 วันที่ผ่านมา
- 14 วันที่ผ่านมา
- 30 วันที่ผ่านมา
- 90 วันที่ผ่านมา

## ระดับความละเอียด

ปรับวิธีการจัดกลุ่มข้อมูล:
- รายชั่วโมง
- รายวัน
- รายสัปดาห์
- รายเดือน

## การกรอง

กรองการวิเคราะห์ตาม:
- **Agent** — ดูตัวชี้วัดสำหรับ agent ที่เฉพาะเจาะจง
- **Channel** — เปรียบเทียบประสิทธิภาพข้ามแพลตฟอร์ม
- **Date range** — วิเคราะห์ช่วงเวลาที่ต้องการ

## การใช้งานการวิเคราะห์

### ระบุรูปแบบ

ดูว่า channel และ agent ใดจัดการ query มากที่สุดเพื่อ:
- ปรับการจัดสรรทรัพยากรให้เหมาะสม
- มุ่งเน้นการปรับปรุงในจุดที่จำเป็น
- เข้าใจความต้องการของผู้ใช้

### ตรวจสอบประสิทธิภาพ

ติดตามแนวโน้มเพื่อให้แน่ใจว่า:
- การใช้ credit อยู่ในขอบเขต
- การมีส่วนร่วมของผู้ใช้อยู่ในเกณฑ์ดี
- ไม่มีรูปแบบที่ผิดปกติ

### ปรับปรุง Agent

ใช้ข้อมูลเชิงลึกเพื่อ:
- ปรับ agent persona
- เพิ่มเอกสารที่ขาดหายไป
- ปรับปรุงความแม่นยำของคำตอบ
