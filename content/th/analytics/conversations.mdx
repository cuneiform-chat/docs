# การวิเคราะห์การสนทนา

ติดตามตัวชี้วัดการสนทนาและดูรายละเอียดบทสนทนาจาก agent และ channel ทั้งหมดของคุณ

## ภาพรวม

การวิเคราะห์การสนทนามีให้:

- ปริมาณการสนทนาทั้งหมด
- การสนทนาต่อ agent
- การสนทนาต่อ channel
- บทสนทนาทั้งหมด
- ข้อมูลเชิงลึกจาก AI

## การเข้าถึงการสนทนา

### จาก Dashboard

1. ไปที่ **Analytics** ในแถบด้านข้าง
2. คลิก **View All** ที่การ์ด Top Agents หรือ Top Channels
3. หรือไปที่ Conversations จากเมนูการวิเคราะห์โดยตรง

### รายการการสนทนา

ดูการสนทนาทั้งหมดพร้อม:

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| Title | ชื่อการสนทนาหรือ session ID |
| Agent | Agent ที่จัดการการสนทนา |
| Channel | แพลตฟอร์ม (Telegram, Discord, Slack ฯลฯ) |
| Messages | จำนวนข้อความทั้งหมด |
| Last Active | เวลาที่อัปเดตล่าสุด |
| Status | Active, archived หรือ deleted |

## การกรองการสนทนา

กรองรายการการสนทนาตาม:

- **Agent** — เลือก agent เฉพาะหรือ agent ทั้งหมด
- **Channel** — กรองตามแพลตฟอร์ม (WhatsApp, Telegram, Meta, Slack, Discord, Google Chat, Playground)
- **Date range** — 7, 14, 30 หรือ 90 วันที่ผ่านมา

## รายละเอียดการสนทนา

คลิกการสนทนาใดก็ได้เพื่อดูรายละเอียดทั้งหมด:

### แท็บภาพรวม

- **Total Messages** — จำนวนข้อความในการสนทนา
- **Credits Spent** — Credit ของแพลตฟอร์มที่ใช้ไป
- **Agent** — Agent ที่จัดการการสนทนา
- **Channel** — แพลตฟอร์มที่เกิดการสนทนา
- **Created** — เวลาที่เริ่มการสนทนา
- **Last Active** — กิจกรรมล่าสุด

### กราฟกิจกรรมข้อความ

แสดงรูปแบบข้อความตามเวลา:
- สลับระหว่างระดับรายชั่วโมงและรายวัน
- แสดง/ซ่อนข้อความผู้ใช้และข้อความ assistant
- ดูรูปแบบกิจกรรมของการสนทนา

### แท็บข้อความ

ดูบทสนทนาทั้งหมด:

- **ประวัติข้อความทั้งหมด** — ดูทุกข้อความในการสนทนา
- **ตัวบ่งชี้บทบาท** — ข้อความ User, Assistant, System และ Tool แยกสีตามบทบาท
- **Timestamp** — เวลาที่ส่งแต่ละข้อความ
- **การใช้ token** — Input/output token ต่อข้อความ (เมื่อมีข้อมูล)

#### การกรองข้อความ

กรองข้อความตามช่วงเวลา:
- 24 ชั่วโมงที่ผ่านมา
- 7 วันที่ผ่านมา
- 30 วันที่ผ่านมา
- ข้อความทั้งหมด

#### Export

คลิก **Export** เพื่อดาวน์โหลดการสนทนาเป็นไฟล์ JSON ที่ประกอบด้วย:
- ข้อมูล metadata ของการสนทนา
- ข้อความทั้งหมดพร้อม timestamp
- ข้อมูล token

## ข้อมูลเชิงลึกจาก AI

สร้างบทสรุปอัจฉริยะของการสนทนา:

1. ไปที่แท็บ **Messages** ของการสนทนา
2. คลิก **Generate Insights**
3. ดูข้อมูลเชิงลึกที่วิเคราะห์โดย AI ได้แก่:
   - **Key Points** — หัวข้อหลักที่พูดคุย
   - **User Intents** — สิ่งที่ผู้ใช้ต้องการทำ
   - **Key Info Shared** — ข้อมูลสำคัญที่แลกเปลี่ยน
   - **Suggested Actions** — คำแนะนำจากการสนทนา

## ข้อพิจารณาด้านความเป็นส่วนตัว

ข้อมูลการสนทนาถูกจัดการตาม:

- ข้อกำหนดนโยบายความเป็นส่วนตัว
- ความยินยอมของผู้ใช้ตามที่เกี่ยวข้อง

## เคล็ดลับ

- ใช้ตัวกรองเพื่อค้นหาการสนทนาจาก agent หรือ channel เฉพาะ
- Export การสนทนาสำคัญเพื่อเก็บบันทึกหรือวิเคราะห์
- สร้างข้อมูลเชิงลึกจาก AI เพื่อเข้าใจการสนทนาที่ยาวอย่างรวดเร็ว
- ตรวจสอบกราฟ Message Activity เพื่อระบุช่วงเวลาที่ใช้งานสูงสุด
- ดูบทสนทนาเพื่อปรับปรุง persona ของ agent
- ตรวจสอบ credit ที่ใช้เพื่อติดตามรูปแบบการใช้งาน

## คำถามที่พบบ่อย

**ถาม: ฉันจะหาการสนทนาจาก channel เฉพาะได้อย่างไร?**

ใช้ตัวกรอง Channel ที่ด้านบนของรายการการสนทนาเพื่อเลือกแพลตฟอร์มเฉพาะ เช่น Telegram, Discord หรือ Slack

**ถาม: ฉันสามารถ export หลายการสนทนาพร้อมกันได้ไหม?**

ปัจจุบัน export ทำได้ทีละ 1 การสนทนา Export แต่ละการสนทนาจากแท็บ Messages

**ถาม: "Generate Insights" ทำอะไร?**

ใช้ AI วิเคราะห์การสนทนาและสร้างบทสรุปที่ประกอบด้วย key point, user intent, ข้อมูลสำคัญที่แลกเปลี่ยน และคำแนะนำ

**ถาม: ข้อมูลเชิงลึกจาก AI ใช้ credit ไหม?**

ใช่ การสร้างข้อมูลเชิงลึกใช้ credit จากบัญชีของคุณ อย่างไรก็ตาม ผลลัพธ์จะถูก cache ไว้ ดังนั้นการดูข้อมูลเชิงลึกเดิมอีกครั้งจะไม่เสีย credit

**ถาม: การสนทนาถูกเก็บนานแค่ไหน?**

การสนทนาถูกเก็บอย่างปลอดภัยและพร้อมใช้งานสำหรับการวิเคราะห์ ติดต่อฝ่ายสนับสนุนหากมีคำถามเกี่ยวกับการจัดเก็บข้อมูล
