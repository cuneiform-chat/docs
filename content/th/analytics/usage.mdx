# ตัวชี้วัดการใช้งาน

ติดตามการใช้ทรัพยากรและการใช้ credit ของคุณ

## ภาพรวมการใช้ Credit

Dashboard การวิเคราะห์แสดงการใช้งานรอบบิลปัจจุบันของคุณ:

- **Credits Used** — Credit ของแพลตฟอร์มที่ใช้ในช่วงเวลานี้
- **Credits Remaining** — Credit ที่เหลือจนถึงสิ้นรอบบิล
- **Usage Percentage** — แถบแสดงเปอร์เซ็นต์การใช้งาน

## ตัวชี้วัดหลัก

### ปริมาณ Query

| ตัวชี้วัด | คำอธิบาย |
|-----------|----------|
| Total Queries | จำนวนการทำงานของ AI agent ในช่วงเวลา |
| Conversations | จำนวน chat session ทั้งหมด |
| Unique Users | ผู้ใช้ที่โต้ตอบเข้ามา |

### การกระจายการใช้งาน

ดูว่าการใช้งานกระจายอย่างไร:

- **By Agent** — Agent ใดจัดการ query มากที่สุด
- **By Channel** — การใช้งานใน Telegram, Discord, Slack, WhatsApp ฯลฯ

## แนวโน้มการใช้งาน

### กราฟปริมาณ Query

Dashboard การวิเคราะห์หลักแสดงกราฟปริมาณ query:
- Query ตามช่วงเวลา
- ปรับระดับความละเอียดได้ (รายชั่วโมง, รายวัน, รายสัปดาห์, รายเดือน)
- เลือกช่วงวันที่ได้

### กราฟการกระจาย

กราฟวงกลมแสดง:
- การกระจายตาม channel — เปอร์เซ็นต์ query ต่อแพลตฟอร์ม
- การกระจายตาม agent — เปอร์เซ็นต์ query ต่อ agent

## การตรวจสอบ Credit

### รอบปัจจุบัน

ดูสถานะรอบบิลของคุณ:
- วันเริ่มต้นและสิ้นสุดของรอบ
- Credit ที่ใช้ไป เทียบกับ credit ที่ได้รับ
- เปอร์เซ็นต์ที่ใช้ไป

## คำเตือนการใช้งาน

หน้า **Billing** จะแสดงแบนเนอร์คำเตือนอัตโนมัติเมื่อ:

- **ใกล้ถึงขีดจำกัด** — คุณใช้ quota รายเดือนไปเกือบหมดแล้ว
- **ถึงขีดจำกัด** — Quota รายเดือนหมดแล้ว
- **ถูกบล็อก** — ยอดคงเหลือการใช้งานเพิ่มเติมหมดเช่นกัน

คำเตือนเหล่านี้แสดงใน **Billing & Plans** เพื่อช่วยให้คุณดำเนินการก่อนบริการได้รับผลกระทบ

## เคล็ดลับการปรับปรุง

### ลดการใช้ Query

- ปรับปรุง agent persona เพื่อความแม่นยำในการตอบครั้งแรก
- เพิ่มเนื้อหา FAQ เพื่อลดคำถามติดตาม
- ปรับปรุงเนื้อหาเพื่อการค้นหาที่เร็วขึ้น

### ตรวจสอบพื้นที่ที่ใช้งานสูง

- ตรวจสอบว่า agent ใดใช้ credit มากที่สุด
- ระบุ channel ที่มีปริมาณสูงที่สุด
- ดูการสนทนาที่ใช้ token มาก
