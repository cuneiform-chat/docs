# การวิเคราะห์ช่องทาง

ดูตัวชี้วัดประสิทธิภาพแยกตาม channel เปรียบเทียบปริมาณ query, การสนทนา, ผู้ใช้ที่ไม่ซ้ำ และการใช้ credit ในทุกแพลตฟอร์มที่ agent ของคุณรับ query

## การเข้าถึงการวิเคราะห์ Channel

1. ไปที่ **Analytics** ในแถบด้านข้าง
2. คลิก **View All** ถัดจาก "Channel Distribution" หรือ
3. ไปที่ **Analytics > Channels** โดยตรง

## การนำทาง

Breadcrumb แสดงตำแหน่งของคุณ: **Dashboard / Channels** คลิก "Dashboard" เพื่อกลับไปหน้าการวิเคราะห์หลัก

## ตัวควบคุมช่วงวันที่

| ตัวควบคุม | คำอธิบาย |
|-----------|----------|
| **Last 7 days** | ดูตัวชี้วัดย้อนหลัง 1 สัปดาห์ |
| **Last 14 days** | ดูตัวชี้วัดย้อนหลัง 2 สัปดาห์ |
| **Last 30 days** | ดูตัวชี้วัดย้อนหลัง 1 เดือน |
| **Last 90 days** | ดูตัวชี้วัดย้อนหลัง 1 ไตรมาส |
| **Refresh** | โหลดข้อมูลใหม่ด้วยค่าล่าสุด |

## การ์ดสรุป

การ์ด 4 ใบแสดงตัวชี้วัดรวมจากทุก channel:

| การ์ด | คำอธิบาย |
|-------|----------|
| Total Channels | จำนวน channel ที่ใช้งานอยู่ |
| Total Queries | ผลรวม query จากทุก channel |
| Total Conversations | ผลรวมการสนทนาจากทุก channel |
| Total Credits | ผลรวม credit ที่ใช้จากทุก channel |

## ตาราง Channel

Channel ที่ใช้งานอยู่ทั้งหมดพร้อมตัวชี้วัดประสิทธิภาพ:

| คอลัมน์ | คำอธิบาย |
|---------|----------|
| Channel | ชื่อ channel พร้อมป้ายสี |
| Queries | จำนวนคำถามที่ตอบบน channel นี้ |
| Conversations | จำนวน chat session บน channel นี้ |
| Unique Users | ผู้ใช้ที่ไม่ซ้ำที่โต้ตอบผ่าน channel นี้ |
| Credits | ทรัพยากรที่ใช้โดย channel นี้ |
| % of Total | แถบแสดงสัดส่วน query ของ channel นี้จากทั้งหมด |
| (ลูกศร) | ลิงก์ไปยังมุมมองโดยละเอียดของ channel |

## ประเภท Channel

Agent ของคุณสามารถรับ query จากแพลตฟอร์มต่างๆ:

| Channel | คำอธิบาย |
|---------|----------|
| Playground | Query จากหน้าทดสอบ agent |
| Telegram | Telegram bot integration |
| Discord | Discord bot integration |
| Slack | Slack app integration |
| Meta | Meta/Messenger integration |
| WhatsApp | WhatsApp Business integration |
| Google Chat | Google Chat (Workspace) integration |

## การดูรายละเอียด Channel

คลิกลูกศรที่แถว channel ใดก็ได้เพื่อดู:
- ตัวชี้วัดโดยละเอียดสำหรับ channel นั้น
- กราฟแบบ time-series พร้อมตัวเลือกระดับความละเอียด (รายชั่วโมง, รายวัน, รายสัปดาห์, รายเดือน)
- การแยกย่อยตาม agent ภายใน channel นั้น

## เคล็ดลับ

- เปรียบเทียบ **% of Total** เพื่อเข้าใจว่า channel ใดมี traffic มากที่สุด
- ใช้มุมมองนี้เพื่อระบุ channel ที่ประสิทธิภาพต่ำและต้องการความสนใจ
- ตรวจสอบ **Unique Users** เพื่อเข้าใจการเข้าถึงผู้ใช้ในแต่ละแพลตฟอร์ม
- ดู **Credits** เพื่อตรวจสอบการใช้ทรัพยากรตาม channel

## คำถามที่พบบ่อย

**ถาม: ทำไมฉันไม่เห็น channel ทั้งหมดในรายการ?**

เฉพาะ channel ที่มี query อย่างน้อย 1 รายการในช่วงวันที่เลือกเท่านั้นที่จะแสดงในตาราง

**ถาม: เปอร์เซ็นต์คำนวณอย่างไร?**

เปอร์เซ็นต์แสดงสัดส่วน query ของแต่ละ channel จาก query ทั้งหมดในทุก channel สำหรับช่วงเวลาที่เลือก

**ถาม: ฉันสามารถเปรียบเทียบ channel ตามเวลาได้ไหม?**

คลิกเข้าไปที่ channel เฉพาะเพื่อดูข้อมูล time-series และแนวโน้ม
