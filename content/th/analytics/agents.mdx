# การวิเคราะห์ Agent

ดูตัวชี้วัดประสิทธิภาพโดยละเอียดสำหรับ agent ทั้งหมดของคุณ เปรียบเทียบปริมาณ query, การสนทนา และการใช้ credit ทั่วทั้ง agent portfolio

## การเข้าถึงการวิเคราะห์ Agent

1. ไปที่ **Analytics** ในแถบด้านข้าง
2. คลิก **View All** ถัดจาก "Top Agents" หรือ
3. ไปที่ **Analytics > Agents** โดยตรง

## การนำทาง

Breadcrumb แสดงตำแหน่งของคุณ: **Dashboard / Agents** คลิก "Dashboard" เพื่อกลับไปหน้าการวิเคราะห์หลัก

## ตัวควบคุมช่วงวันที่

| ตัวควบคุม | คำอธิบาย |
|-----------|----------|
| **Last 7 days** | ดูตัวชี้วัดย้อนหลัง 1 สัปดาห์ |
| **Last 14 days** | ดูตัวชี้วัดย้อนหลัง 2 สัปดาห์ |
| **Last 30 days** | ดูตัวชี้วัดย้อนหลัง 1 เดือน |
| **Last 90 days** | ดูตัวชี้วัดย้อนหลัง 1 ไตรมาส |
| **Refresh** | โหลดข้อมูลใหม่ด้วยค่าล่าสุด |

## ตาราง Agent

Agent ทั้งหมดพร้อมตัวชี้วัดประสิทธิภาพ:

| คอลัมน์ | คำอธิบาย | เรียงลำดับได้ |
|---------|----------|--------------|
| Agent | ชื่อ agent | ไม่ |
| Status | active, inactive, testing หรือ archived | ไม่ |
| Queries | จำนวนคำถามที่ตอบทั้งหมด | ได้ |
| Conversations | จำนวน chat session | ได้ |
| Credits | ทรัพยากรที่ใช้ไป | ได้ |
| Channels | channel ที่ agent ถูกใช้งาน | ไม่ |
| (ลูกศร) | ลิงก์ไปยังมุมมองโดยละเอียด | ไม่ |

### การเรียงลำดับ

คลิกหัวคอลัมน์ที่เรียงลำดับได้เพื่อเรียงตามตัวชี้วัดนั้น:
- **คลิกครั้งแรก**: เรียงจากมากไปน้อย (สูงสุดก่อน)
- **คลิกครั้งที่สอง**: เรียงจากน้อยไปมาก (ต่ำสุดก่อน)
- คอลัมน์ที่กำลังเรียงจะถูกไฮไลต์

### การแบ่งหน้า

สำหรับรายการ agent จำนวนมาก:
- แสดง "Showing X - Y of Z"
- ใช้ปุ่ม **Previous/Next** เพื่อเปลี่ยนหน้า

## ป้ายสถานะ Agent

| ป้าย | สี | ความหมาย |
|------|-----|----------|
| active | เขียว | Agent ถูก deploy แล้วและกำลังรับ query |
| inactive | เทา | Agent ถูกหยุดชั่วคราว |
| testing | เหลือง | Agent กำลังถูกทดสอบก่อน deploy |
| archived | เหลือง | Agent ถูกเก็บถาวร |

## ป้าย Channel

คอลัมน์ Channels แสดงแพลตฟอร์มที่ agent แต่ละตัวถูกใช้งาน:
- แสดงป้าย channel สูงสุด 3 รายการ (เช่น "web", "telegram", "discord")
- ถ้ามากกว่า 3 จะแสดง "+X" เพื่อบอกจำนวน channel เพิ่มเติม

## การดูรายละเอียด Agent

คลิกลูกศรที่แถว agent ใดก็ได้เพื่อดู:
- ตัวชี้วัดโดยละเอียดสำหรับ agent นั้น
- กราฟแบบ time-series
- การแยกย่อยตาม channel
- ข้อมูลที่ละเอียดยิ่งขึ้น

## เคล็ดลับ

- เรียงตาม **Credits** เพื่อหา agent ที่ใช้ทรัพยากรมากที่สุด
- เรียงตาม **Queries** เพื่อระบุ agent ที่ได้รับความนิยมมากที่สุด
- ใช้ **90 days** สำหรับการวิเคราะห์แนวโน้มระยะยาว
- ตรวจสอบ agent ที่ inactive ว่าควรเปิดใช้งานอีกครั้งหรือไม่
- คลิกเข้าไปที่ agent แต่ละตัวเพื่อข้อมูลเชิงลึกที่มากขึ้น

## คำถามที่พบบ่อย

**ถาม: ฉันจะหา agent ที่ถูกใช้มากที่สุดได้อย่างไร?**

คลิกหัวคอลัมน์ "Queries" เพื่อเรียงตามจำนวน query แถวบนสุดคือ agent ที่ใช้งานมากที่สุดของคุณ

**ถาม: ป้าย channel หมายความว่าอย่างไร?**

แสดงว่าแพลตฟอร์มใด (Web, Telegram, Discord, Slack ฯลฯ) ที่ agent แต่ละตัวรับ query

**ถาม: ทำไม agent แสดง query เป็นศูนย์?**

Agent อาจเป็นตัวใหม่, inactive หรือยังไม่ได้ deploy ไปยัง channel ใด
