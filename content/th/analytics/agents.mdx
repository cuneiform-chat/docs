# Agent Analytics

View detailed performance metrics for all your agents. Compare query volumes, conversations, and credit usage across your entire agent portfolio.

## Accessing Agent Analytics

1. Navigate to **Analytics** in the sidebar
2. Click **View All** next to "Top Agents", or
3. Go directly to **Analytics > Agents**

## Navigation

The breadcrumb shows your location: **Dashboard / Agents**. Click "Dashboard" to return to the main analytics page.

## Date Range Controls

| Control | Description |
|---------|-------------|
| **Last 7 days** | View metrics for the past week |
| **Last 14 days** | View metrics for two weeks |
| **Last 30 days** | View metrics for the past month |
| **Last 90 days** | View metrics for the past quarter |
| **Refresh** | Reload data with latest values |

## Agents Table

All your agents listed with performance metrics:

| Column | Description | Sortable |
|--------|-------------|----------|
| Agent | Agent name | No |
| Status | active, inactive, testing, or archived | No |
| Queries | Total questions answered | Yes |
| Conversations | Chat sessions | Yes |
| Credits | Resources consumed | Yes |
| Channels | Which channels the agent is used on | No |
| (Arrow) | Link to detailed view | No |

### Sorting

Click any sortable column header to sort by that metric:
- **First click**: Sort descending (highest first)
- **Second click**: Sort ascending (lowest first)
- Active sort column is highlighted

### Pagination

For large agent lists:
- Shows "Showing X - Y of Z"
- Use **Previous/Next** buttons to navigate pages

## Agent Status Badges

| Badge | Color | Meaning |
|-------|-------|---------|
| active | Green | Agent is deployed and receiving queries |
| inactive | Gray | Agent is paused |
| testing | Yellow | Agent is being tested before deployment |
| archived | Yellow | Agent is archived |

## Channel Badges

The Channels column shows which platforms each agent is used on:
- Up to 3 channel badges shown (e.g., "web", "telegram", "discord")
- If more than 3, shows "+X" to indicate additional channels

## Viewing Agent Details

Click the arrow on any agent row to see:
- Detailed metrics for that specific agent
- Time-series charts
- Channel breakdown
- More granular data

## Tips

- Sort by **Credits** to find your most resource-intensive agents
- Sort by **Queries** to identify your most popular agents
- Use **90 days** for long-term trend analysis
- Check inactive agents to see if they should be reactivated
- Click through to individual agents for deeper insights

## Common Questions

**Q: How do I find my most used agent?**

Click the "Queries" column header to sort by query count. The top row is your most active agent.

**Q: What do the channel badges mean?**

They show which platforms (Web, Telegram, Discord, Slack, etc.) each agent receives queries from.

**Q: Why is an agent showing zero queries?**

The agent may be new, inactive, or not yet deployed to any channel.
