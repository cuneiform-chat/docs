# ตัวเลือกการตั้งค่า

import { Callout } from 'nextra/components'

คู่มือฉบับสมบูรณ์สำหรับตัวเลือกการตั้งค่า agent ทั้งหมด

## โครงสร้างหน้า

หน้าแก้ไข agent มีสาม tab:

| Tab | จุดประสงค์ |
|-----|-----------|
| **Configuration** | การตั้งค่าหลัก (status, ชื่อ, persona, LLM, ข้อความ) |
| **Knowledge Access** | ควบคุม document ที่ agent สามารถใช้ได้ |
| **Integrations** | เชื่อมต่อกับ channel ภายนอก (Telegram, Discord ฯลฯ) |

## Configuration Tab

### Status

ควบคุมความพร้อมใช้งานของ agent:

| Status | Playground | Integrations | หมายเหตุ |
|--------|------------|--------------|---------|
| **Testing** | ✅ Enabled | ❌ Disabled | ค่าเริ่มต้นสำหรับ agent ใหม่ ทดสอบก่อนใช้งานจริง |
| **Active** | ✅ Enabled | ✅ Enabled | พร้อมใช้งานจริง |
| **Inactive** | ❌ Disabled | ❌ Disabled | ปิดใช้งานชั่วคราว |
| **Archived** | ❌ Disabled | ❌ Disabled | ซ่อนจากรายการหลัก |

<Callout type="warning">
  หาก agent ของคุณมี integration ที่เชื่อมต่ออยู่ และคุณเปลี่ยนจาก Active เป็นสถานะอื่น คุณจะเห็น confirmation dialog แจ้งเตือนว่า agent จะหยุดตอบบน channel ที่เชื่อมต่อ
</Callout>

### Basic Settings

- **Name** — ระบุ agent ใน dashboard ของคุณ
- **Description** — บันทึกภายในเกี่ยวกับจุดประสงค์ของ agent

### LLM Configuration

ควบคุม AI model ที่ขับเคลื่อน agent ของคุณ

**Default Mode (Advanced toggle ปิด):**
- ใช้ค่า default ของ tier ขององค์กรของคุณ
- แสดง info box อธิบายว่ากำลังใช้ tier default
- แนะนำสำหรับการใช้งานส่วนใหญ่

**Advanced Mode (Advanced toggle เปิด):**

| การตั้งค่า | คำอธิบาย |
|-----------|----------|
| **Model** | เลือก AI model ที่มีให้ตาม plan ของคุณ |
| **Temperature** | ควบคุมความ creative ของการตอบ (0.0-1.0) |

#### Temperature Guide

| ค่า | พฤติกรรม |
|-----|---------|
| 0.0 - 0.3 | การตอบที่มุ่งเน้นและแน่นอน |
| 0.4 - 0.7 | สมดุลระหว่างความ creative และ consistency |
| 0.8 - 1.0 | การตอบที่ creative และหลากหลายมากขึ้น |

**คำแนะนำ:** เริ่มด้วย 0.3-0.5 สำหรับ Q&A ที่อิงข้อเท็จจริงจาก document

#### Show Document References

Toggle นี้ (แสดงเสมอไม่ว่า Advanced mode จะเปิดหรือไม่) ควบคุมว่า agent จะรวม source citation ในคำตอบหรือไม่:

- **Off** (ค่าเริ่มต้น) — คำตอบไม่อ้างอิง source document
- **On** — คำตอบรวม reference ไปยัง source document

<Callout type="important">
  เปิดใช้งาน document reference สำหรับกรณีที่ต้องการความโปร่งใส เช่น legal, compliance หรือเนื้อหาภายในที่ผู้ใช้ต้องการตรวจสอบแหล่งที่มา
</Callout>

### การรองรับภาษา

Agent ของคุณตรวจจับภาษาของแต่ละ user message โดยอัตโนมัติ และตอบกลับในภาษาเดียวกัน — ไม่ต้องตั้งค่าด้วยตนเอง รองรับ 176 ภาษาตั้งแต่เริ่มต้น รวมถึงอาหรับ, ฝรั่งเศส, เยอรมัน, สเปน, ตุรกี, จีน, ญี่ปุ่น และอื่นๆ อีกมาก

### Agent Persona

คำสั่งที่ควบคุมพฤติกรรมของ agent ดู [Agent Personas](/agents/agent-personas) สำหรับแนวทางปฏิบัติที่ดี

**การดำเนินการที่มี:**
- **Generate** — เปิด [Agent Persona Builder](/agents/persona-builder)
- **Edit** — เปิด slide-out panel เพื่อเขียนหรือแก้ไข persona โดยตรง

คลิกที่พื้นที่ข้อความ persona เพื่อเปิด edit panel

**Platform Rules Box:**
คลิกเพื่อดู platform reliability rule ที่ถูกนำไปใช้กับทุก agent โดยอัตโนมัติ:
- No fabrication — ไม่สร้างข้อเท็จจริงขึ้นมา
- Acknowledges gaps — บอก "ไม่ทราบ" เมื่อเหมาะสม
- Resists speculation — ไม่เดาข้อมูลที่ขาดหายไป
- No professional impersonation — ไม่แสดงตัวเป็นทนายความ แพทย์ ฯลฯ
- Corrects false premises — ชี้ให้เห็นสมมติฐานที่ไม่ถูกต้อง
- Blocks harmful content — ปฏิเสธคำขอที่ไม่เหมาะสม

<Callout type="info">
  Platform rule ทำให้ทุก agent ทำงานได้อย่างน่าเชื่อถือและปลอดภัย ไม่สามารถปิดใช้งานหรือแก้ไขได้
</Callout>

## Knowledge Access Tab

ควบคุม document ที่ agent ของคุณสามารถเข้าถึงได้เมื่อตอบคำถาม

### Access Modes

| Mode | พฤติกรรม | เมื่อใดควรใช้ |
|------|---------|--------------|
| **Exclude Mode** | Agent เข้าถึง document ทั้งหมดยกเว้นที่เลือก | ซ่อน document ที่เป็นความลับโดยอนุญาตให้เข้าถึงอย่างอื่นทั้งหมด |
| **Include Mode** | Agent เข้าถึงเฉพาะรายการที่เลือกเท่านั้น | จำกัด agent ให้ใช้เฉพาะ document ที่กำหนด |

### ตัวเลือกการเลือก

ปรับแต่งการเข้าถึงโดยใช้ตัวเลือกการเลือกหลายประเภท:

- **Folders** — เลือกทั้ง folder และ document ทั้งหมดภายใน
- **Tags** — กรอง document ตาม tag ที่กำหนด
- **Individual Documents** — รวมหรือยกเว้น document เฉพาะภายใน folder ที่เลือก

### Access Preview

Preview panel แสดงการเข้าถึง document ที่มีผลตามการเลือกปัจจุบันของคุณ ใช้สิ่งนี้เพื่อตรวจสอบ configuration ก่อนบันทึก

<Callout type="info">
  เริ่มด้วย **Exclude Mode** ถ้าคุณต้องการการเข้าถึงแบบกว้างพร้อมข้อจำกัดเฉพาะ ใช้ **Include Mode** เมื่อคุณต้องการควบคุมอย่างเข้มงวดว่า agent จะอ้างอิง document ใดบ้าง
</Callout>

## Integrations Tab

เชื่อมต่อ agent ของคุณกับ channel สื่อสาร

Tab นี้แสดงตัวเลือก integration ที่มีให้สำหรับ agent ของคุณ คุณสามารถเชื่อมต่อ channel เช่น:
- Telegram
- Discord
- Slack
- WhatsApp
- Meta (Facebook Messenger)
- และอื่นๆ อีก (ตาม plan ของคุณ)

ดู [เอกสาร Integrations](/integrations) สำหรับคู่มือการตั้งค่าแต่ละ channel โดยละเอียด

## Human Handoff

เปิดใช้งาน live chat handoff เพื่อให้ AI agent ของคุณสามารถส่งต่อการสนทนาให้คนจริงเมื่อผู้ใช้ร้องขอ

**วิธีเปิดใช้งาน:**

1. ใน **Configuration** tab เลื่อนไปที่ส่วน **Human Handoff**
2. เปิด toggle **Enable Human Handoff**
3. ตั้งค่าข้อความ:
   - **Handoff Message** — แสดงให้ผู้ใช้เห็นเมื่อเริ่มการส่งต่อ
   - **Resolve Message** — แสดงเมื่อ human agent จบการสนทนา
   - **Max Wait Time** — หมดอายุอัตโนมัติถ้าไม่มี agent รับ (5, 15, 30, 60 หรือ 120 นาที; ค่าเริ่มต้น: 30 นาที)
4. คลิก **Save Changes**

เมื่อผู้ใช้ขอพูดคุยกับคน AI จะสร้างคำขอ handoff ที่มองเห็นได้ในหน้า **Inbox** สมาชิกในทีมจะรับ, แชทกับผู้ใช้บน channel ของพวกเขา และ resolve เมื่อเสร็จ

<Callout type="info">
  Human Handoff มีให้ในทุก plan เปิดใช้งานต่อ agent ใน Configuration tab
</Callout>

## การทดสอบ Agent ของคุณ

ก่อนบันทึกการเปลี่ยนแปลง คุณสามารถทดสอบ agent ของคุณ:

1. คลิกปุ่ม **Test Agent** ที่ด้านล่างของ form
2. Playground panel จะเลื่อนเปิดขึ้น
3. ทดสอบการสนทนากับ agent ของคุณ
4. ปิด Playground เมื่อเสร็จ

<Callout type="info">
  ปุ่ม Test Agent จะถูกปิดใช้งานเมื่อ agent อยู่ในสถานะ Archived หรือ Inactive เปลี่ยนสถานะเป็น Active หรือ Testing เพื่อเปิดใช้งานการทดสอบ
</Callout>

## การบันทึกการเปลี่ยนแปลง

| ปุ่ม | การทำงาน |
|------|---------|
| **Save Changes** | บันทึกการแก้ไขทั้งหมด |
| **Test Agent** | เปิด Playground เพื่อทดสอบ |

หากต้องการยกเลิกการเปลี่ยนแปลง ให้นำทางออกโดยใช้ปุ่มย้อนกลับหรือ sidebar navigation

**สิ่งที่ถูกบันทึก:**
- เฉพาะฟิลด์ที่เปลี่ยนแปลงเท่านั้นที่จะถูกอัปเดต
- คุณจะเห็น "No changes to save" ถ้าไม่มีการแก้ไข
- ข้อความ success หรือ error จะปรากฏหลังบันทึก

**การจัดการ Partial Save:**
ถ้าบางการเปลี่ยนแปลงบันทึกสำเร็จแต่บางส่วนล้มเหลว คุณจะได้รับแจ้งว่าส่วนใดล้มเหลว และหน้าจะ refresh เพื่อแสดงสถานะปัจจุบัน

<Callout type="info">
  การเปลี่ยนแปลงการตั้งค่า agent จะมีผลทันทีหลังบันทึก ทดสอบใน Playground หลังจากทำการเปลี่ยนแปลง
</Callout>
