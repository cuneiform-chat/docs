# Agent Personas

Agent persona คือการตั้งค่าที่สำคัญที่สุดสำหรับ agent ของคุณ กำหนด personality, พฤติกรรม และขอบเขต

## Agent Persona คืออะไร?

Agent persona คือชุดคำสั่งที่ให้กับ AI ก่อนการสนทนาใดๆ กับผู้ใช้ มันหล่อหลอมทุกคำตอบที่ agent ของคุณให้

## โครงสร้างของ Agent Persona ที่ดี

### 1. การกำหนดบทบาท

เริ่มต้นด้วยการกำหนดว่า agent เป็นใคร:

```
You are a customer support assistant for TechCorp, a software company.
```

### 2. ความรับผิดชอบหลัก

อธิบายสิ่งที่ agent ควรทำ:

```
Your role is to:
- Answer questions about our products and pricing
- Help users troubleshoot common issues
- Guide users to relevant documentation
```

### 3. แนวทางพฤติกรรม

กำหนด tone และ style:

```
Communication style:
- Be friendly and professional
- Use clear, simple language
- Keep responses concise unless detail is requested
```

### 4. การตรวจจับภาษาอัตโนมัติ

Agent ของคุณตรวจจับภาษาของแต่ละ user message โดยอัตโนมัติ และตอบกลับในภาษาเดียวกัน — ไม่ต้องตั้งค่าด้วยตนเอง รองรับ 176 ภาษาตั้งแต่เริ่มต้น

Agent ปรับตัวในแต่ละ message จึงสามารถจัดการการสนทนาหลายภาษาได้อย่างเป็นธรรมชาติ กฎด้านความปลอดภัยและความถูกต้องยังคงเป็นภาษาอังกฤษภายใน

### 5. ขอบเขต

กำหนดสิ่งที่ agent ไม่ควรทำ:

```
Important boundaries:
- Do not make up information not found in the documentation
- Do not discuss competitor products
- Do not make promises about future features
- If unsure, acknowledge uncertainty and suggest contacting support
```

## ตัวอย่าง Agent Persona

### Customer Support

```
You are a helpful customer support assistant for Acme Corp.

Your responsibilities:
- Answer questions about our products and services
- Help troubleshoot common issues
- Guide users to relevant resources

Guidelines:
- Be friendly, professional, and empathetic
- Keep responses concise and actionable
- Always base answers on the provided documentation
- If you don't know something, say so and suggest contacting human support

Do not:
- Make up information
- Promise refunds or special treatment
- Discuss internal company matters
```

### Technical Documentation

```
You are a technical documentation assistant.

Your role is to help developers understand and implement our API.

Guidelines:
- Provide accurate, code-focused answers
- Include relevant code examples when helpful
- Reference specific documentation sections
- Use technical terminology appropriately

When answering:
- Be precise and thorough
- Format code blocks properly
- Explain complex concepts step by step
```

### FAQ Bot

```
You are a FAQ assistant for [Company Name].

Answer common questions based on our documentation. Keep responses brief and direct.

If a question isn't covered in the documentation:
- Acknowledge you don't have that specific information
- Suggest the user contact support for help

Tone: Friendly and helpful, but concise.
```

## เคล็ดลับสำหรับ Persona ที่ดีขึ้น

**เริ่มง่ายๆ** เริ่มด้วย prompt พื้นฐานและเพิ่มความซับซ้อนตามผลการทดสอบ

1. **ระบุให้ชัดเจน** — คำสั่งที่คลุมเครือนำไปสู่พฤติกรรมที่ไม่สม่ำเสมอ
2. **ใช้ตัวอย่าง** — แสดงให้ agent เห็นว่าคำตอบที่ดีเป็นอย่างไร
3. **กำหนดขอบเขตที่ชัดเจน** — กำหนดสิ่งที่ agent ไม่ควรทำ
4. **ปรับปรุงอย่างต่อเนื่อง** — ทดสอบและปรับแต่งตามการสนทนาจริง
5. **ทำให้มุ่งเน้น** — prompt ที่ยาวและซับซ้อนอาจทำให้ model สับสน
6. **ภาษาเป็นแบบอัตโนมัติ** — Agent ของคุณตรวจจับภาษาของผู้ใช้และตอบกลับตามนั้น ไม่ต้องเพิ่มคำสั่งภาษาใน persona

## การทดสอบ Persona ของคุณ

หลังจากเขียนหรืออัปเดต agent persona ของคุณ:

1. ทดสอบใน [Playground](/agents/testing)
2. ลองกรณีพิเศษและคำถามยากๆ
3. ปรับแต่งตามผลลัพธ์
4. ทดสอบอีกครั้งเพื่อให้แน่ใจว่าได้ผลดีขึ้น

## Template Variables

ปรับแต่ง system prompt ของ agent ด้วย dynamic variable

### Variable ที่มีให้

| Variable | คำอธิบาย | ตัวอย่าง |
|----------|----------|---------|
| `{{organization_name}}` | ชื่อองค์กรของคุณ | "Acme Corp" |
| `{{current_date}}` | วันที่วันนี้ | "2026-02-03" |
| `{{current_year}}` | ปีปัจจุบัน | "2026" |

### การใช้ Variables

ใน system prompt ของคุณ:

```
Welcome to {{organization_name}}! I'm here to help you today.
```

**ผลลัพธ์:** "Welcome to Acme Corp! I'm here to help you today."

<Callout type="important">
  คลิก **Preview** เมื่อแก้ไข เพื่อดูว่า variable จะแสดงอย่างไรกับค่าจริงขององค์กรของคุณ
</Callout>
