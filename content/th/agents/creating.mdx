# การสร้าง Agent

import { Callout } from 'nextra/components'

เรียนรู้วิธีสร้าง agent ใหม่ใน Cuneiform Chat

## เริ่มต้นใช้งาน

1. ไปที่ **Agents** ใน sidebar
2. คลิกปุ่ม **Create Agent** ที่มุมขวาบน
3. กรอกข้อมูลในแต่ละส่วนของ form ด้านล่าง

## ข้อมูลพื้นฐาน

ส่วนนี้เก็บรายละเอียดสำคัญเกี่ยวกับ agent ของคุณ

| ฟิลด์ | จำเป็น | คำอธิบาย |
|-------|--------|----------|
| **Name** | ใช่ | ชื่อสำหรับ agent ของคุณ (เช่น "Customer Support Agent") สูงสุด 100 ตัวอักษร |
| **Description** | ไม่ | คำอธิบายสั้นๆ เกี่ยวกับสิ่งที่ agent นี้ทำ สูงสุด 500 ตัวอักษร |

**เคล็ดลับ:**
- เลือกชื่อที่สื่อความหมายและบ่งบอกจุดประสงค์ของ agent
- Description ช่วยให้คุณและทีมเข้าใจบทบาทของ agent

## Agent Persona

Agent persona กำหนดพฤติกรรมและการตอบสนองของ agent ผ่าน system prompt

**องค์ประกอบหลัก:**

- **Platform Rules Box** — แสดง safety rule ในตัวที่ถูกนำไปใช้โดยอัตโนมัติ (คลิกเพื่อดูรายละเอียด)
- **Generate Button** — เปิด [Agent Persona Builder](/agents/persona-builder) เพื่อช่วยสร้าง persona ของคุณ
- **Edit Button** — เปิด panel เพื่อเขียนหรือแก้ไข persona ด้วยตนเอง

### Platform Rules

Safety guardrail เหล่านี้ถูกนำไปใช้กับทุก agent โดยอัตโนมัติ:

- **No fabrication** — ไม่สร้างข้อเท็จจริงที่ไม่มีในเนื้อหาของคุณ
- **Acknowledges gaps** — บอก "ไม่ทราบ" เมื่อเหมาะสม
- **Resists speculation** — ไม่เดาข้อมูลที่ขาดหายไป
- **No professional impersonation** — ไม่แสดงตัวเป็นทนายความ แพทย์ ฯลฯ
- **Corrects false premises** — ชี้ให้เห็นสมมติฐานที่ไม่ถูกต้อง
- **Blocks harmful content** — ปฏิเสธคำขอที่ไม่เหมาะสม

<Callout type="info">
  Platform rule ทำให้ทุก agent ทำงานได้อย่างน่าเชื่อถือและปลอดภัย ไม่สามารถปิดใช้งานได้ ดูรายละเอียดที่ [Agent Persona Builder](/agents/persona-builder#platform-rules)
</Callout>

### ตัวอย่าง Persona แบบรวดเร็ว

```
You are a helpful assistant for [Your Company].
Answer questions based on the provided documentation.
Be concise and friendly.
```

ดูคำแนะนำโดยละเอียดเกี่ยวกับการเขียน persona ที่มีประสิทธิภาพได้ที่ [Agent Personas](/agents/agent-personas)

## การรองรับภาษา

Agent ของคุณตรวจจับภาษาของแต่ละ user message โดยอัตโนมัติ และตอบกลับในภาษาเดียวกัน — ไม่ต้องตั้งค่าใดๆ รองรับ 176 ภาษาตั้งแต่เริ่มต้น ดูรายละเอียดที่ [Agent Personas — Language Detection](/agents/agent-personas#4-automatic-language-detection)

## LLM Configuration

ส่วนนี้ควบคุมการตั้งค่า AI model

**Default Mode:**

โดยค่าเริ่มต้น การตั้งค่า LLM ใช้ค่า default ของ tier ขององค์กรของคุณ คุณจะเห็น info box แสดง "Using tier defaults" ซึ่งแนะนำสำหรับการใช้งานส่วนใหญ่

**Advanced Mode:**

เปิด **Advanced** toggle เพื่อปรับแต่ง:

| การตั้งค่า | คำอธิบาย |
|-----------|----------|
| **Model** | เลือก AI model ที่มีให้ตาม plan ของคุณ |
| **Temperature** | ควบคุมความ creative ของการตอบ (ต่ำ = consistent มากขึ้น, สูง = creative มากขึ้น) |

**Show Document References:**

Toggle นี้ (แสดงเสมอ) ควบคุมว่า agent จะรวม source citation ในคำตอบหรือไม่:
- **Off** (ค่าเริ่มต้น) — คำตอบไม่อ้างอิง source document
- **On** — คำตอบรวม reference ไปยัง source document (มีประโยชน์สำหรับ legal/compliance)

## Knowledge Access Control

ควบคุมว่า agent ของคุณสามารถเข้าถึง document ใดบ้างเมื่อตอบคำถาม

| Mode | พฤติกรรม | เมื่อใดควรใช้ |
|------|---------|--------------|
| **Exclude Mode** | Agent เข้าถึง document ทั้งหมดยกเว้นที่เลือก | ซ่อน document ที่เป็นความลับจาก agent |
| **Include Mode** | Agent เข้าถึงเฉพาะรายการที่เลือกเท่านั้น | จำกัด agent ให้ใช้เฉพาะ knowledge ที่กำหนด |

**เมื่อใช้ Include Mode:**
- เลือก folder เฉพาะที่ agent สามารถเข้าถึงได้
- เลือก tag เฉพาะที่ agent สามารถเข้าถึงได้
- เลือก document แต่ละรายการที่ agent สามารถเข้าถึงได้

Agent จะใช้ข้อมูลจาก source ที่เลือกเท่านั้นในการตอบ

<Callout type="important">
  เริ่มด้วย Exclude Mode (เข้าถึง knowledge ทั้งหมด) เว้นแต่คุณต้องการซ่อน document เฉพาะ คุณสามารถจำกัดการเข้าถึงได้ในภายหลัง
</Callout>

## Form Actions

ที่ด้านล่างของ form:

| ปุ่ม | การทำงาน |
|------|---------|
| **Cancel** | ยกเลิกการเปลี่ยนแปลงและย้อนกลับ |
| **Reset** | ล้างทุกฟิลด์และเริ่มใหม่ (แสดง confirmation dialog) |
| **Create Agent** | บันทึก agent และเปิดหน้าแก้ไข |

<Callout type="info">
  Draft ของคุณจะถูกบันทึกอัตโนมัติขณะทำงาน ถ้าคุณออกไปและกลับมา ความคืบหน้าจะถูกกู้คืน
</Callout>

## หลังจากสร้าง

เมื่อคุณคลิก **Create Agent**:

1. Agent จะถูกสร้างด้วยสถานะ **Testing**
2. คุณจะถูกนำไปยังหน้าแก้ไขของ agent
3. ทดสอบ agent โดยใช้ Playground
4. เชื่อมต่อ integration เมื่อพร้อมใช้งานจริง
5. เปลี่ยนสถานะเป็น **Active** เมื่อพร้อม

<Callout type="info">
  Agent ใหม่เริ่มต้นด้วยสถานะ **Testing** คุณสามารถทดสอบใน Playground ได้ แต่ channel integration จะถูกปิดจนกว่าคุณจะ activate agent
</Callout>

## การจัดการ Agent

จากหน้า Agents คุณสามารถ:

- **Edit** — คลิกที่ agent ใดก็ได้เพื่อแก้ไขการตั้งค่า
- **Test** — คลิก **Test** บน agent card เพื่อเปิด Playground
- **Change Status** — ตั้งค่าเป็น Testing, Active, Inactive หรือ Archived

ดูรายละเอียดการตั้งค่า agent ทั้งหมดได้ที่ [Configuration Options](/agents/configuring)
