# การทดสอบใน Playground

import { Callout } from 'nextra/components'

Playground คือสภาพแวดล้อมสำหรับทดสอบและปรับแต่ง agent ก่อน deploy

## การเข้าถึง Playground

1. ไปที่ **Agents** ใน sidebar
2. คลิก **Test** บน agent card (หรือ **Test Agent** เมื่อแก้ไข agent)
3. Playground จะเลื่อนเปิดเป็น side panel — เริ่มการสนทนาได้เลย

<Callout type="info">
  ปุ่ม Test จะถูกปิดใช้งานเมื่อ agent อยู่ในสถานะ **Archived** หรือ **Inactive** เปลี่ยนสถานะเป็น **Active** หรือ **Testing** เพื่อเปิดใช้งานการทดสอบ
</Callout>

## สิ่งที่ควรทดสอบ

### ฟังก์ชันพื้นฐาน

- Agent สามารถตอบคำถามจาก document ของคุณได้หรือไม่?
- คำตอบถูกต้องและเกี่ยวข้องหรือไม่?
- Tone ตรงกับที่คุณคาดหวังหรือไม่?

### กรณีพิเศษ

ทดสอบสถานการณ์ที่อาจทำให้ agent ตอบผิดพลาด:

- คำถามที่ไม่ครอบคลุมโดย document ของคุณ
- คำถามที่คลุมเครือหรือไม่ชัดเจน
- คำถามหลายส่วน
- คำถามติดตามที่ต้องการ context

### การไหลของการสนทนา

ทดสอบการสนทนาหลายรอบ:

- Agent จำ context จาก message ก่อนหน้าได้หรือไม่?
- จัดการการเปลี่ยนหัวข้อได้อย่างราบรื่นหรือไม่?
- ขอคำชี้แจงเมื่อจำเป็นหรือไม่?

## การประเมินคำตอบ

สำหรับแต่ละคำตอบ ให้พิจารณา:

| ด้าน | คำถามที่ควรถาม |
|------|--------------|
| **Accuracy** | ข้อมูลถูกต้องหรือไม่? |
| **Relevance** | ตอบคำถามจริงหรือไม่? |
| **Completeness** | มีข้อมูลสำคัญที่ขาดหายไปหรือไม่? |
| **Tone** | ตรงกับเสียงของแบรนด์ของคุณหรือไม่? |
| **Length** | กระชับหรือละเอียดอย่างเหมาะสมหรือไม่? |

## การปรับปรุงอย่างต่อเนื่อง

### ระบุปัญหา

ปัญหาทั่วไปและวิธีแก้:

| ปัญหา | วิธีแก้ |
|-------|--------|
| ข้อมูลผิด | ตรวจสอบเนื้อหา document, ปรับปรุงการ retrieval |
| ยาวเกินไป | เพิ่ม "be concise" ใน agent persona |
| เป็นทางการ/สบายๆ เกินไป | ปรับ tone ใน agent persona |
| ตอบไม่ได้ | เพิ่ม document ที่เกี่ยวข้อง |
| สร้างข้อมูลขึ้นมาเอง | เสริม boundary ใน prompt |

### ทำการเปลี่ยนแปลง

1. ระบุปัญหาจากการทดสอบใน Playground
2. ปรับการตั้งค่าที่เกี่ยวข้อง (prompt, document, configuration)
3. ทดสอบอีกครั้งด้วยคำถามเดิม
4. ตรวจสอบว่าการแก้ไขไม่ทำให้พฤติกรรมอื่นเสียหาย

## Checklist สถานการณ์ทดสอบ

สร้างชุดคำถามทดสอบมาตรฐาน:

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  บันทึกสถานการณ์ทดสอบของคุณและรันอีกครั้งหลังทำการเปลี่ยนแปลงเพื่อตรวจจับ regression
</Callout>

## พร้อมสำหรับ Deployment

Agent ของคุณพร้อมเมื่อ:

- ✅ ตอบคำถามทั่วไปได้อย่างถูกต้อง
- ✅ จัดการกรณีพิเศษได้อย่างราบรื่น
- ✅ รักษา tone ที่เหมาะสม
- ✅ เคารพขอบเขตที่กำหนด
- ✅ การสนทนาหลายรอบทำงานได้ดี

ขั้นตอนถัดไป deploy agent ของคุณไปยัง [channel](/integrations) ที่ผู้ใช้จะโต้ตอบ
