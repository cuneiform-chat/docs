# Agents

Agent คือ AI chatbot ที่โต้ตอบกับผู้ใช้ของคุณ แต่ละ agent มี configuration, knowledge access และ personality เป็นของตัวเอง

## Agent คืออะไร?

Agent คือ chatbot ที่ถูกตั้งค่าแล้ว ซึ่ง:

- ตอบคำถามโดยใช้เนื้อหาของคุณ
- ปฏิบัติตามคำสั่งที่กำหนดไว้ใน agent persona
- รักษา context ของการสนทนาภายใน session
- สามารถ deploy ไปยังหลาย channel ได้

## แนวคิดของ Agent

### Agent Persona

Agent persona คือชุดคำสั่งที่กำหนดพฤติกรรมของ agent โดยควบคุม:

- **Personality** — เป็นมิตร, มืออาชีพ, สบายๆ เป็นต้น
- **Scope** — หัวข้อที่ agent ควรและไม่ควรพูดถึง
- **Response style** — ความยาว, รูปแบบ และ tone ของคำตอบ
- **Guardrails** — ขอบเขตและข้อจำกัด
- **Language** — ตรวจจับภาษาอัตโนมัติในแต่ละ message (รองรับ 176 ภาษา)

### Knowledge Access

แต่ละ agent เข้าถึงเนื้อหาของคุณเพื่อค้นหาข้อมูลที่เกี่ยวข้อง คุณสามารถตั้งค่า:

- document ใดที่ agent สามารถค้นหาได้
- จำนวน source ที่จะดึงมา
- จะแสดง source citation หรือไม่

### Channels

Agent สามารถ deploy ไปยังหลาย channel พร้อมกันได้:

- Messaging platform (Telegram, Discord, Slack, WhatsApp, Google Chat)
- Facebook Messenger ผ่าน Meta integration
- Human Handoff — ส่งต่อการสนทนาให้สมาชิกในทีมได้อย่างราบรื่น
