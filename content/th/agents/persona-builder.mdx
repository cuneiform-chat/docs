# Agent Persona Builder

import { Callout } from 'nextra/components'

สร้าง agent persona ระดับมืออาชีพในไม่กี่วินาทีด้วยการเลือกคุณลักษณะ

<Callout type="info">
  Agent Persona Builder ช่วยให้คุณสร้าง agent persona ที่มีประสิทธิภาพโดยไม่ต้องเขียน prompt ตั้งแต่ต้น
</Callout>

## เริ่มต้นใช้งาน

1. ไปที่ **Agents** แล้วสร้างหรือแก้ไข agent
2. คลิก **Generate** ข้างฟิลด์ Agent Persona
3. Agent Persona Builder panel จะเลื่อนเปิดขึ้นพร้อมสาม tab

## Builder Tabs

### Custom Build

สร้าง persona ที่ไม่เหมือนใครด้วยการเลือกคุณลักษณะจาก 5 หมวดหมู่:

| หมวดหมู่ | ควบคุมอะไร |
|---------|-----------|
| **Role & Identity** | ฟังก์ชันหลักของ agent (customer support, sales, tech support, HR ฯลฯ) |
| **Communication Style** | ความเป็นทางการ, tone, ความละเอียด และระดับเทคนิค |
| **Response Behavior** | รูปแบบ (conversational vs bullet points), proactivity, การจัดการคำถาม |
| **Operational Boundaries** | ความเข้มงวดในการอยู่ในหัวข้อ, แนวโน้มการ escalation |
| **Knowledge Integration** | รูปแบบการอ้างอิง, วิธีจัดการความไม่แน่นอน |

**การนำทางหมวดหมู่:**
- คลิกที่ header ของหมวดหมู่ใดก็ได้เพื่อขยายหรือย่อ
- แต่ละหมวดหมู่มีหลายฟิลด์พร้อมตัวเลือก dropdown
- ตัวเลือกที่เลือกจะถูก highlight

**Reset Button:**
คลิก **Reset** ในส่วน Custom Build เพื่อคืนค่าเริ่มต้นทั้งหมด

#### ตัวเลือก Role & Identity

เลือกฟังก์ชันหลักของ agent:
- Customer Support Representative
- Sales Consultant
- Technical Support Specialist
- HR/People Operations
- Education
- Healthcare Information
- Legal Information
- Finance/Accounting
- General Assistant
- Custom role

#### Communication Style

ปรับแต่งวิธีที่ agent สื่อสาร:

| การตั้งค่า | ตัวเลือก |
|-----------|---------|
| **Formality** | Formal, Professional, Casual |
| **Tone** | Warm & Friendly, Neutral, Direct |
| **Verbosity** | Concise, Balanced, Detailed |
| **Technical Level** | Non-technical, Mixed, Technical |

#### ตัวเลือก Tone

Tone preset ที่มีให้:
- Empathetic & Supportive
- Confident & Authoritative
- Calm & Reassuring
- Enthusiastic & Engaging
- Neutral & Objective

#### ระดับรายละเอียด

- **Concise** — คำตอบสั้นกระชับตรงประเด็น
- **Balanced** — รายละเอียดปานกลางพร้อมคำอธิบายที่ชัดเจน
- **Comprehensive** — คำตอบที่ละเอียดครบถ้วน

#### Response Behavior

ควบคุมโครงสร้างของคำตอบ:
- **Format** — ย่อหน้าแบบสนทนาหรือ bullet point แบบมีโครงสร้าง
- **Proactivity** — agent จะแนะนำหัวข้อที่เกี่ยวข้องหรือไม่
- **Question Handling** — วิธีที่ agent ขอคำชี้แจง

#### Operational Boundaries

กำหนด guardrail สำหรับ agent ของคุณ:
- **Scope Strictness** — ความเข้มงวดในการอยู่ในหัวข้อที่มีเอกสาร
- **Escalation** — เมื่อใดควรแนะนำให้ติดต่อ human support
- **Out-of-scope Handling** — วิธีตอบคำถามที่นอกหัวข้อ

#### Knowledge Integration

ตั้งค่าวิธีที่ agent ใช้ document ของคุณ:
- **Citation Style** — จะอ้างอิง document เฉพาะหรือไม่
- **Uncertainty Handling** — วิธีตอบเมื่อไม่แน่ใจ

### Use Preset

โหลด persona ที่ตั้งค่าล่วงหน้าสำหรับ use case ทั่วไป:

- **System Templates** — Preset ที่ platform จัดเตรียมให้สำหรับบทบาทเฉพาะ
- **My Templates** — Preset ที่บันทึกโดย admin ขององค์กรของคุณ

**การใช้ Preset:**
1. คลิก tab **Use Preset**
2. เรียกดู preset ที่มีให้
3. คลิกที่ preset เพื่อเลือก
4. Preset จะโหลดเข้า Custom Build tab
5. ปรับคุณลักษณะตามต้องการ
6. คลิก **Generate Persona**

### Platform Rules

ดู guardrail แบบ read-only ที่ถูกนำไปใช้กับทุก agent โดยอัตโนมัติ:

- **No fabrication** — ไม่สร้างข้อเท็จจริง, ตัวเลข หรือวันที่ที่ไม่มีในเนื้อหาของคุณ
- **Acknowledges gaps** — บอก "ไม่มีข้อมูลนั้น" แทนที่จะเดา
- **Resists speculation** — ไม่ประมาณค่าที่ขาดหายไปแม้ถูกถาม
- **No professional impersonation** — ไม่สวมบทบาทเป็นทนายความ, แพทย์, CPA หรือที่ปรึกษาทางการเงิน
- **Corrects false premises** — ชี้ให้เห็นสมมติฐานที่ไม่ถูกต้องก่อนตอบ
- **Blocks harmful content** — ปฏิเสธเนื้อหาทำร้ายตนเอง, ไม่เหมาะสม หรือฉ้อโกง

<Callout type="info">
  Platform rule ทำให้ทุก agent ทำงานได้อย่างน่าเชื่อถือและปลอดภัย ไม่ว่า persona จะตั้งค่าอย่างไร ไม่สามารถปิดใช้งานได้
</Callout>

## การสร้าง Persona

**ก่อนสร้าง:**
Panel จะแสดงตัวเลือก configuration ของคุณแบบเต็มความกว้าง

**Generate Button:**
เมื่ออยู่ที่ Custom Build tab:
1. คลิก **Generate Persona** ที่ด้านล่าง
2. สถานะ loading จะแสดงขณะสร้าง
3. ใช้เวลาไม่กี่วินาที

**หลังสร้าง:**
Layout ของ panel จะเปลี่ยนเป็นแบบแบ่งสองส่วน:
- **ด้านซ้าย:** ตัวเลือก configuration ของคุณ
- **ด้านขวา:** Preview prompt ที่สร้างขึ้น

**คุณสมบัติของ Preview Panel:**
- ข้อความเต็มของ system prompt ที่สร้างขึ้น
- แก้ไขได้ — คุณสามารถปรับข้อความได้โดยตรง
- แสดงจำนวนตัวอักษรที่ด้านล่าง

## หลังจากสร้าง

เมื่อคุณมี persona ที่สร้างแล้ว คุณมีหลายตัวเลือก:

### สร้างใหม่

คลิก **Regenerate** เพื่อสร้างเวอร์ชันใหม่ด้วยการตั้งค่าเดิม แต่ละครั้งจะให้ผลลัพธ์ที่แตกต่างกันเล็กน้อย

### แก้ไข Prompt

คลิกใน preview panel เพื่อแก้ไขข้อความที่สร้างขึ้นโดยตรง ปรับแต่งตามที่ต้องการสำหรับ use case เฉพาะของคุณ

### Save as Preset

คลิก **Save as Preset** เพื่อบันทึก configuration สำหรับใช้ซ้ำ:
1. Dialog เปิดขึ้นถามชื่อ preset
2. ใส่ชื่อที่สื่อความหมาย
3. Preset จะบันทึกในองค์กรของคุณภายใต้ **My Templates**

<Callout type="important">
  Preset ที่บันทึกไว้จะมีให้ admin ทุกคนในองค์กรของคุณ ใช้เพื่อรักษา personality ของ agent ให้สม่ำเสมอในหลาย agent
</Callout>

### Apply to Agent

คลิก **Apply to Agent** เพื่อใช้ persona นี้:
1. Prompt จะถูกแทรกลงในฟิลด์ system prompt ของ agent
2. Builder จะปิด
3. ตั้งค่า agent อื่นๆ ต่อได้

## แนวทางปฏิบัติที่ดี

- **เริ่มด้วย preset** — ใช้ system template เป็นจุดเริ่มต้น แล้วปรับแต่ง
- **จับคู่บทบาทกับจุดประสงค์** — เลือก role ที่ตรงกับฟังก์ชันจริงของ agent
- **สมดุลความละเอียด** — Concise เหมาะสำหรับ Q&A สั้นๆ, Detailed สำหรับหัวข้อซับซ้อน
- **ทดสอบหลังสร้าง** — ทดสอบ agent ใน Playground เสมอหลังใช้ persona ใหม่
- **ปรับปรุงอย่างต่อเนื่อง** — สร้างใหม่ด้วยการตั้งค่าต่างๆ ถ้าผลลัพธ์ยังไม่ดีพอ
- **ทำให้มุ่งเน้น** — prompt ที่ซับซ้อนเกินไปอาจทำให้ agent สับสน
