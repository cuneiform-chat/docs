# Meta (Facebook) Integration

Connect your agent to Facebook Messenger through your Facebook Page.

## Overview

Meta integration provides:
- Facebook Messenger conversations via your Page
- A built-in [Messenger Storefront](/integrations/messenger-mini-app) launchable from the Page's Persistent Menu
- Background processing with typing indicators
- Automatic message splitting for long responses
- 24-hour messaging window compliance
- Conversation memory within sessions
- [Document attachments](/integrations/document-attachments) — customers can send a file and ask about it (on by default, paid plans)

## Prerequisites

- A Facebook Page you manage
- Admin or Editor role on the Page
- Cuneiform Chat account with an active agent

## Setup Steps

### 1. Start Integration Setup

1. Go to **Integrations** in the sidebar
2. Open the **Facebook Pages** card
3. Click **Connect Page**

### 2. Authorize with Facebook

1. Select which **Agent** should respond
2. Click **Connect with Facebook**
3. Log in to Facebook (if needed)
4. Select the Page you want to connect
5. Grant Messenger permissions
6. You'll be redirected back with a success message

### 3. Verify Connection

Once connected, your Page will appear in the integrations list showing:
- Page name and status
- Page ID
- Last activity timestamp

## How It Works

When users message your Facebook Page through Messenger:

1. Message arrives via Facebook Messenger
2. The bot shows a typing indicator while processing
3. Your agent processes the question
4. Response is sent back through Messenger

<Callout type="info">
  Messages are processed in the background. The bot shows a typing indicator while your agent generates a response.
</Callout>

## Features

### Automatic Responses

Your agent automatically responds to incoming Messenger conversations based on your content. All text messages trigger a response — no commands or prefixes needed.

### Typing Indicators

While your agent processes a message, users see a typing indicator ("...") in Messenger, providing a natural conversation feel.

### Message Splitting

Responses longer than 2,000 characters are automatically split into multiple messages, preserving paragraph breaks and sentence boundaries for readability.

### Conversation Memory

The bot remembers context within a session, so users can ask follow-up questions without repeating themselves.

### Message Queuing

If a user sends additional messages while the bot is still processing, they are queued and included in the next response.

### 24-Hour Messaging Window

Facebook's policy allows responses within 24 hours of the last user message. Your agent responds in real-time, well within this window. After 24 hours of inactivity, the user must send a new message to restart the conversation.

<Callout type="warning">
  Users must message your Page first — you cannot send unsolicited messages. If more than 24 hours pass since their last message, the bot cannot reply until the user messages again.
</Callout>

### Document Attachments

Customers can send a file or a photo in Messenger and ask your agent about it. Files are recognised **by their file extension**, so one with an unusual or missing extension isn't read and the bot replies as it does today.

This is **on by default** on Messenger — an admin can switch **Allow document attachments** off on the Page's integration card. Photos or scans still need **Premium parsing for complex documents**, which stays off until an admin turns it on. See [Document Attachments](/integrations/document-attachments) for supported types, limits and setup.

## Troubleshooting

### Page Not Appearing

1. Verify you have Admin or Editor role on the Page
2. Check you granted all requested permissions
3. Try disconnecting and reconnecting

### Messages Not Receiving Responses

1. Use "Test Connection" to verify the integration
2. Check your agent is configured and working (test in Playground)
3. Ensure Messenger permissions are granted
4. Verify the user messaged within the last 24 hours (messaging window policy)

### Authorization Errors

1. Clear Facebook login session and try again
2. Verify your Facebook account has Page access
3. Check Page isn't restricted by Facebook

## Security

- **OAuth tokens** are encrypted and stored securely
- **Webhook signatures** are verified using HMAC-SHA256 on every incoming request
- No access to Page content beyond Messenger conversations
- Compliant with Facebook Platform policies

## Disconnecting

To remove the Meta integration:

1. Go to **Integrations** in the sidebar
2. Click the three-dot menu on your Page
3. Select **Disconnect**

To fully revoke access:
1. Go to Facebook Settings → Business Integrations
2. Remove the Cuneiform Chat app

## Important Notes

- **One agent per Page**: Each Facebook Page can only connect to one AI agent at a time
- **Messenger only**: This integration works through Facebook Messenger, not Page comments or posts
- **Message limit**: Individual messages are limited to 2,000 characters; longer responses are automatically split
- **To change agents**: Disconnect the existing integration first, then reconnect with a different agent
