# Pastas e Tags

Organize os documentos do seu Content usando pastas e tags. Pastas fornecem organização hierárquica, enquanto tags permitem categorização transversal entre pastas.

## Como Chegar

Navegue até **Content** na barra lateral. Pastas aparecem no navegador de documentos, e controles de tags estão na barra de ferramentas.

## Trabalhando com Pastas

### Criar uma Pasta

1. Clique no botão **New Folder** (ícone de pasta com +) na barra de ferramentas
2. Digite um nome para a pasta (obrigatório)
3. Opcionalmente adicione uma descrição
4. Escolha uma cor usando o seletor de cores
5. Clique em **Create**

### Editar uma Pasta

1. Clique no menu de três pontos (...) na linha da pasta
2. Selecione **Rename**
3. Atualize o nome, descrição ou cor
4. Clique em **Save Changes**

### Excluir uma Pasta

1. Clique no menu de três pontos (...) na linha da pasta
2. Selecione **Delete**
3. Confirme a exclusão

### Enviar para uma Pasta

- Arraste arquivos diretamente sobre a linha da pasta
- Passe o mouse sobre uma pasta para revelar ícones de upload (cloud storage + arquivos locais)
- Clique para expandir uma pasta e ver seus documentos

## Trabalhando com Tags

### Gerenciar Tags (Criar, Editar, Excluir)

1. Clique no dropdown **Tag Filter** na barra de ferramentas
2. Clique em **Manage Tags** na parte inferior
3. No modal:
   - Clique em **Create Tag** para adicionar uma nova tag
   - Use tags sugeridas para criação rápida
   - Edite tags existentes (nome, cor)
   - Exclua tags não utilizadas

### Adicionar Tags a um Documento

1. Passe o mouse sobre a linha do documento
2. Clique no botão **Tag** (ícone de tag)
3. No diálogo Manage Tags:
   - Veja as tags atuais no topo
   - Pesquise tags disponíveis
   - Marque tags para adicionar
   - Clique no botão **Add X tags**

### Remover Tags de um Documento

1. Abra o diálogo Manage Tags do documento
2. Na seção "Current Tags", clique no X das tags para selecionar para remoção
3. Clique no botão **Remove X tags**

### Filtrar Documentos por Tags

1. Clique no dropdown **Tag Filter** na barra de ferramentas
2. Selecione uma ou mais tags
3. Apenas documentos com essas tags são exibidos
4. Tags selecionadas aparecem em uma barra de filtro abaixo da barra de ferramentas
5. Clique no X de uma tag para remover esse filtro, ou **Clear all**

## Pastas vs Tags

| Recurso | Pastas | Tags |
|---------|--------|------|
| Estrutura | Hierárquica (uma pasta por documento) | Plana (múltiplas tags por documento) |
| Melhor para | Categorias amplas, projetos, departamentos | Tópicos, temas, status, assuntos transversais |
| Filtragem | Clique na pasta para ver o conteúdo | Use o filtro de tags para encontrar entre pastas |
| Limite por documento | Uma pasta por documento | Tags ilimitadas por documento |

## Dicas

- Use pastas para categorias principais (ex.: "Product Docs", "HR Policies")
- Use tags para temas transversais (ex.: "Q1-2024", "Compliance", "Draft")
- Use cores em pastas e tags para organização visual
- Tags mostram contagem de uso para que você veja quantos documentos usam cada tag
- Combine filtros de pasta e tag para descoberta precisa de documentos

## Perguntas Comuns

**P: Um documento pode estar em múltiplas pastas?**
R: Não, cada documento pertence a uma pasta (ou "Unfiled"). Use tags para categorização transversal.

**P: O que acontece com os documentos quando excluo uma pasta?**
R: Pastas com documentos não podem ser excluídas. Mova ou exclua os documentos primeiro.

**P: Como vejo todos os documentos com uma tag específica?**
R: Use o dropdown Tag Filter na barra de ferramentas e selecione a tag.
