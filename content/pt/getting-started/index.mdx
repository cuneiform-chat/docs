# Primeiros Passos

Comece a usar o Cuneiform Chat em apenas alguns minutos. Este guia mostra como criar seu primeiro chatbot de AI treinado nos seus documentos.

## O Que Você Vai Aprender

- Como criar e configurar sua conta
- Como fazer upload de documentos para seu conteúdo
- Como criar e configurar seu primeiro agent
- Como testar seu agent no Playground

## Pré-requisitos

- Um endereço de email válido
- Documentos que você quer que seu chatbot aprenda (PDFs, documentos Word, arquivos de texto, etc.)
