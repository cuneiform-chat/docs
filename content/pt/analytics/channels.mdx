# Analíticas de Canais

Veja métricas de desempenho divididas por canal. Compare volumes de consultas, conversas, usuários únicos e uso de credits em todas as plataformas onde seus agents recebem consultas.

## Acessando Analíticas de Canais

1. Navegue até **Analytics** na barra lateral
2. Clique em **View All** ao lado de "Channel Distribution", ou
3. Vá diretamente até **Analytics > Channels**

## Navegação

O breadcrumb mostra sua localização: **Dashboard / Channels**. Clique em "Dashboard" para retornar à página principal de analíticas.

## Controles de Período

| Controle | Descrição |
|----------|-----------|
| **Last 7 days** | Ver métricas da última semana |
| **Last 14 days** | Ver métricas das duas últimas semanas |
| **Last 30 days** | Ver métricas do último mês |
| **Last 90 days** | Ver métricas do último trimestre |
| **Refresh** | Recarregar dados com valores mais recentes |

## Cards de Resumo

Quatro cards mostrando métricas agregadas de todos os canais:

| Card | Descrição |
|------|-----------|
| Total Channels | Número de canais ativos |
| Total Queries | Soma de consultas de todos os canais |
| Total Conversations | Soma de conversas de todos os canais |
| Total Credits | Soma de credits usados de todos os canais |

## Tabela de Canais

Todos os seus canais ativos listados com métricas de desempenho:

| Coluna | Descrição |
|--------|-----------|
| Channel | Nome do canal com badge codificado por cor |
| Queries | Total de perguntas respondidas neste canal |
| Conversations | Sessões de chat neste canal |
| Unique Users | Usuários distintos que interagiram via este canal |
| Credits | Recursos consumidos por este canal |
| % of Total | Barra de progresso visual mostrando a participação deste canal no total de consultas |
| (Seta) | Link para visualização detalhada do canal |

## Tipos de Canal

Seus agents podem receber consultas de diversas plataformas:

| Canal | Descrição |
|-------|-----------|
| Playground | Consultas da interface de teste do agent |
| Telegram | Integração com bot do Telegram |
| Discord | Integração com bot do Discord |
| Slack | Integração com app do Slack |
| Meta | Integração com Meta/Messenger |
| WhatsApp | Integração com WhatsApp Business |
| Google Chat | Integração com Google Chat (Workspace) |

## Visualizando Detalhes do Canal

Clique na seta de qualquer linha de canal para ver:
- Métricas detalhadas para aquele canal específico
- Gráficos de séries temporais com opções de granularidade (Por hora, Diário, Semanal, Mensal)
- Distribuição por agent dentro daquele canal

## Dicas

- Compare **% of Total** para entender quais canais geram mais tráfego
- Use esta visualização para identificar canais com baixo desempenho que precisam de atenção
- Verifique **Unique Users** para entender o alcance de audiência por plataforma
- Revise **Credits** para ver o consumo de recursos por canal

## Perguntas Comuns

**P: Por que não vejo todos os canais listados?**

Apenas canais com pelo menos uma consulta durante o período selecionado aparecem na tabela.

**P: Como o percentual é calculado?**

O percentual mostra a participação de cada canal no total de consultas de todos os canais para o período selecionado.

**P: Posso comparar canais ao longo do tempo?**

Clique em um canal específico para ver seus dados de séries temporais e tendências.
