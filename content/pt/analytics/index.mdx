# Analíticas

Monitore o desempenho dos seus agents e entenda como os usuários interagem com seus chatbots.

## Visão Geral

As analíticas ajudam você a:
- Acompanhar volume de conversas e padrões de consultas
- Monitorar desempenho dos agents e uso de credits
- Entender a distribuição por canais
- Identificar áreas para melhoria

## Dashboard

Acesse as analíticas na seção **Analytics** na barra lateral.

### Métricas Principais

| Métrica | Descrição |
|---------|-----------|
| Total Queries | Execuções do agent (respostas de AI) |
| Conversations | Número de sessões de chat |
| Unique Users | Usuários individuais que conversaram |
| Credits Used | Credits da plataforma consumidos |

### Uso de Credits

O dashboard mostra o consumo de credits do ciclo de billing atual:
- Credits usados vs. alocados
- Barra de progresso percentual
- Credits restantes para o período

### Gráficos

O dashboard inclui gráficos visuais:
- **Query Volume** — Gráfico de linha mostrando consultas ao longo do tempo
- **Channel Distribution** — Gráfico de pizza dividindo consultas por canal
- **Agent Distribution** — Gráfico de pizza dividindo consultas por agent

### Top Agents

Uma lista classificada dos seus agents mais ativos mostrando:
- Nome do agent e posição
- Total de consultas atendidas
- Número de conversas
- Credits consumidos
- Status atual (active, inactive, testing, archived)

Clique em qualquer agent para ver analíticas detalhadas, ou clique em **View All** para ver todos os agents.

### Top Channels

Uma lista classificada dos seus canais de comunicação mais ativos mostrando:
- Nome do canal e posição
- Total de consultas atendidas
- Número de conversas
- Credits consumidos

Clique em qualquer canal para ver analíticas detalhadas, ou clique em **View All** para ver todos os canais.

## Períodos de Tempo

Veja analíticas para diferentes intervalos:
- Ciclo de Billing Atual
- Últimos 7 dias
- Últimos 14 dias
- Últimos 30 dias
- Últimos 90 dias

## Granularidade

Ajuste como os dados são agrupados:
- Por hora
- Diário
- Semanal
- Mensal

## Filtros

Filtre analíticas por:
- **Agent** — Veja métricas para agents específicos
- **Channel** — Compare desempenho entre plataformas
- **Período** — Analise períodos de tempo específicos

## Usando as Analíticas

### Identificar Padrões

Veja quais canais e agents atendem mais consultas para:
- Otimizar alocação de recursos
- Focar melhorias onde necessário
- Entender preferências dos usuários

### Monitorar Desempenho

Acompanhe tendências para garantir que:
- O uso de credits permanece dentro dos limites
- O engajamento dos usuários é saudável
- Não há padrões incomuns

### Otimizar Agents

Use insights para:
- Ajustar personas dos agents
- Adicionar documentação faltante
- Melhorar a precisão das respostas
