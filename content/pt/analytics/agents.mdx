# Analíticas de Agents

Veja métricas detalhadas de desempenho para todos os seus agents. Compare volumes de consultas, conversas e uso de credits em todo o seu portfólio de agents.

## Acessando Analíticas de Agents

1. Navegue até **Analytics** na barra lateral
2. Clique em **View All** ao lado de "Top Agents", ou
3. Vá diretamente até **Analytics > Agents**

## Navegação

O breadcrumb mostra sua localização: **Dashboard / Agents**. Clique em "Dashboard" para retornar à página principal de analíticas.

## Controles de Período

| Controle | Descrição |
|----------|-----------|
| **Last 7 days** | Ver métricas da última semana |
| **Last 14 days** | Ver métricas das duas últimas semanas |
| **Last 30 days** | Ver métricas do último mês |
| **Last 90 days** | Ver métricas do último trimestre |
| **Refresh** | Recarregar dados com valores mais recentes |

## Tabela de Agents

Todos os seus agents listados com métricas de desempenho:

| Coluna | Descrição | Ordenável |
|--------|-----------|-----------|
| Agent | Nome do agent | Não |
| Status | active, inactive, testing ou archived | Não |
| Queries | Total de perguntas respondidas | Sim |
| Conversations | Sessões de chat | Sim |
| Credits | Recursos consumidos | Sim |
| Channels | Em quais canais o agent é usado | Não |
| (Seta) | Link para visualização detalhada | Não |

### Ordenação

Clique em qualquer cabeçalho de coluna ordenável para classificar por essa métrica:
- **Primeiro clique**: Ordenar decrescente (maior primeiro)
- **Segundo clique**: Ordenar crescente (menor primeiro)
- A coluna de ordenação ativa fica destacada

### Paginação

Para listas grandes de agents:
- Mostra "Showing X - Y of Z"
- Use os botões **Previous/Next** para navegar entre páginas

## Badges de Status do Agent

| Badge | Cor | Significado |
|-------|-----|-------------|
| active | Verde | Agent está implantado e recebendo consultas |
| inactive | Cinza | Agent está pausado |
| testing | Amarelo | Agent está sendo testado antes da implantação |
| archived | Amarelo | Agent está arquivado |

## Badges de Canal

A coluna Channels mostra em quais plataformas cada agent é usado:
- Até 3 badges de canal exibidos (ex.: "web", "telegram", "discord")
- Se mais de 3, mostra "+X" para indicar canais adicionais

## Visualizando Detalhes do Agent

Clique na seta de qualquer linha de agent para ver:
- Métricas detalhadas para aquele agent específico
- Gráficos de séries temporais
- Distribuição por canal
- Dados mais granulares

## Dicas

- Ordene por **Credits** para encontrar seus agents mais intensivos em recursos
- Ordene por **Queries** para identificar seus agents mais populares
- Use **90 days** para análise de tendências de longo prazo
- Verifique agents inativos para ver se devem ser reativados
- Clique nos agents individuais para insights mais profundos

## Perguntas Comuns

**P: Como encontro meu agent mais usado?**

Clique no cabeçalho da coluna "Queries" para ordenar por contagem de consultas. A primeira linha é seu agent mais ativo.

**P: O que significam os badges de canal?**

Eles mostram de quais plataformas (Web, Telegram, Discord, Slack, etc.) cada agent recebe consultas.

**P: Por que um agent mostra zero consultas?**

O agent pode ser novo, inativo ou ainda não implantado em nenhum canal.
