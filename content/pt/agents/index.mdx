# Agents

Os agents são os chatbots de AI que interagem com seus usuários. Cada agent tem sua própria configuração, acesso ao conhecimento e personalidade.

## O que é um Agent?

Um agent é um chatbot configurado que:

- Responde perguntas usando seu conteúdo
- Segue as instruções definidas em seu agent persona
- Mantém o contexto da conversa dentro das sessões
- Pode ser implantado em múltiplos canais

## Conceitos de Agent

### Agent Persona

O agent persona é o conjunto de instruções que define como seu agent se comporta. Ele controla:

- **Personalidade** — Amigável, profissional, casual, etc.
- **Escopo** — Quais tópicos o agent deve e não deve abordar
- **Estilo de resposta** — Tamanho, formato e tom das respostas
- **Guardrails** — Limites e restrições
- **Idioma** — Detecção automática por mensagem (176 idiomas suportados)

### Acesso ao Conhecimento

Cada agent acessa seu conteúdo para encontrar informações relevantes. Você pode configurar:

- Quais documentos o agent pode pesquisar
- Quantas fontes recuperar
- Se deve mostrar citações de fontes

### Canais

Os agents podem ser implantados em múltiplos canais simultaneamente:

- Plataformas de mensagens (Telegram, Discord, Slack, WhatsApp, Google Chat)
- Facebook Messenger via integração com Meta
- Human Handoff — transfira conversas sem interrupções para um membro humano da equipe
