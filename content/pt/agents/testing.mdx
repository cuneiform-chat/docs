# Testar no Playground

import { Callout } from 'nextra/components'

O Playground é seu ambiente para testar e refinar agents antes da implantação.

## Acessando o Playground

1. Acesse **Agents** na barra lateral
2. Clique em **Test** no card do seu agent (ou em **Test Agent** ao editar um agent)
3. O Playground se abre como um painel lateral — inicie uma conversa

<Callout type="info">
  O botão Test fica desativado quando o status do agent é **Archived** ou **Inactive**. Mude o status para **Active** ou **Testing** para ativar os testes.
</Callout>

## O Que Testar

### Funcionalidade Básica

- O agent consegue responder perguntas a partir dos seus documentos?
- As respostas são precisas e relevantes?
- O tom corresponde às suas expectativas?

### Casos de Borda

Teste cenários que possam confundir seu agent:

- Perguntas não cobertas pelos seus documentos
- Perguntas ambíguas ou pouco claras
- Perguntas com várias partes
- Perguntas de acompanhamento que exigem contexto

### Fluxo de Conversa

Teste conversas com vários turnos:

- O agent lembra o contexto de mensagens anteriores?
- Lida bem com mudanças de tópico?
- Pede esclarecimentos quando necessário?

## Avaliando Respostas

Para cada resposta, considere:

| Aspecto | Perguntas a Fazer |
|--------|-----------------|
| **Accuracy** | A informação está correta? |
| **Relevance** | Responde realmente à pergunta? |
| **Completeness** | Está faltando algo importante? |
| **Tone** | Combina com a voz da sua marca? |
| **Length** | Está adequadamente conciso ou detalhado? |

## Melhoria Iterativa

### Identificar Problemas

Problemas comuns e soluções:

| Problema | Solução |
|-------|----------|
| Informação errada | Verifique o conteúdo do documento, melhore a recuperação |
| Muito verboso | Adicione "be concise" ao agent persona |
| Muito formal/casual | Ajuste o tom no agent persona |
| Não sabe a resposta | Adicione documentos relevantes |
| Inventa fatos | Reforce os limites no prompt |

### Fazer Alterações

1. Identifique o problema durante os testes no Playground
2. Ajuste as configurações relevantes (prompt, documentos, configuração)
3. Teste novamente com as mesmas perguntas
4. Verifique se a correção não quebra outros comportamentos

## Lista de Cenários de Teste

Crie um conjunto padrão de perguntas de teste:

```markdown
## Test Scenarios for [Agent Name]

### Basic Questions
- [ ] Q: "What is [product]?" — Expected: Clear description
- [ ] Q: "How much does it cost?" — Expected: Pricing info

### Edge Cases
- [ ] Q: Random unrelated question — Expected: Polite redirect
- [ ] Q: Competitor comparison — Expected: Stays on topic

### Follow-ups
- [ ] Q: Initial question, then "Tell me more" — Expected: Expands on previous answer
```

<Callout type="important">
  Salve seus cenários de teste e execute-os novamente após fazer alterações para detectar regressões.
</Callout>

## Pronto para Implantação

Seu agent está pronto quando:

- ✅ Responde perguntas comuns com precisão
- ✅ Lida bem com casos de borda
- ✅ Mantém o tom adequado
- ✅ Respeita os limites definidos
- ✅ As conversas com vários turnos funcionam bem

Em seguida, implante seu agent nos [canais](/integrations) onde os usuários interagirão com ele.
