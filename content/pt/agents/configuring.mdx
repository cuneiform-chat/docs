# Opções de Configuração

import { Callout } from 'nextra/components'

Guia detalhado de todas as opções de configuração do agent.

## Estrutura da Página

A página de edição do agent tem três abas:

| Aba | Propósito |
|-----|---------|
| **Configuration** | Configurações principais (status, nome, persona, LLM, mensagens) |
| **Knowledge Access** | Controla quais documentos o agent pode usar |
| **Integrations** | Conecta a canais externos (Telegram, Discord, etc.) |

## Aba Configuration

### Status

Controle a disponibilidade do seu agent:

| Status | Playground | Integrações | Notas |
|--------|------------|--------------|-------|
| **Testing** | ✅ Ativado | ❌ Desativado | Padrão para novos agents. Teste antes de colocar em produção. |
| **Active** | ✅ Ativado | ✅ Ativado | Pronto para uso em produção. |
| **Inactive** | ❌ Desativado | ❌ Desativado | Desativado temporariamente. |
| **Archived** | ❌ Desativado | ❌ Desativado | Oculto da lista principal. |

<Callout type="warning">
  Se o seu agent tem integrações conectadas e você muda de Active para outro status, verá um diálogo de confirmação avisando que o agent vai parar de responder nos canais conectados.
</Callout>

### Configurações Básicas

- **Name** — Identifica o agent no seu dashboard
- **Description** — Notas internas sobre o propósito do agent

### Configuração do LLM

Controle o modelo de AI que alimenta o seu agent.

**Modo Padrão (toggle Advanced desativado):**
- Usa os valores padrão do tier da sua organização
- Exibe uma caixa de informação explicando que os valores padrão do tier estão em uso
- Recomendado para a maioria dos casos

**Modo Avançado (toggle Advanced ativado):**

| Configuração | Descrição |
|---------|-------------|
| **Model** | Selecione entre os modelos de AI disponíveis conforme seu plano |
| **Temperature** | Controla a criatividade das respostas (0.0-1.0) |

#### Guia de Temperature

| Valor | Comportamento |
|-------|----------|
| 0.0 - 0.3 | Respostas focadas e determinísticas |
| 0.4 - 0.7 | Equilíbrio entre criatividade e consistência |
| 0.8 - 1.0 | Respostas mais criativas e variadas |

**Recomendação:** Comece com 0.3-0.5 para Q&A factual baseado em documentos.

#### Show Document References

Este toggle (sempre visível, independentemente do modo Advanced) controla se o agent inclui citações de fontes nas respostas:

- **Off** (padrão) — As respostas não mencionam os documentos de origem
- **On** — As respostas incluem referências aos documentos de origem

<Callout type="important">
  Ative as referências a documentos para casos de uso que exijam transparência, como conteúdos jurídicos, de compliance ou internos onde os usuários precisem verificar as fontes.
</Callout>

### Suporte a Idiomas

Seu agent detecta automaticamente o idioma de cada mensagem do usuário e responde de acordo — sem precisar de configuração manual. 176 idiomas são suportados nativamente, incluindo árabe, francês, alemão, espanhol, turco, chinês, japonês e muitos outros.

### Agent Persona

As instruções que controlam o comportamento do agent. Veja [Agent Personas](/agents/agent-personas) para boas práticas.

**Ações disponíveis:**
- **Generate** — Abre o [Agent Persona Builder](/agents/persona-builder)
- **Edit** — Abre um painel deslizante para escrever ou modificar a persona diretamente

Clique na área de texto da persona para abrir o painel de edição.

**Caixa Platform Rules:**
Clique para ver as regras de confiabilidade da plataforma que são aplicadas automaticamente a todos os agents:
- No fabrication — não inventa fatos
- Acknowledges gaps — diz "não sei" quando apropriado
- Resists speculation — não chuta informações faltantes
- No professional impersonation — não atua como advogado, médico, etc.
- Corrects false premises — aponta suposições incorretas
- Blocks harmful content — recusa solicitações inadequadas

<Callout type="info">
  As Platform Rules garantem que todos os agents se comportem de forma confiável e segura. Elas não podem ser desativadas nem modificadas.
</Callout>

## Aba Knowledge Access

Controle quais documentos seu agent pode acessar ao responder consultas.

### Modos de Acesso

| Modo | Comportamento | Quando Usar |
|------|----------|-------------|
| **Exclude Mode** | O agent acessa TODOS os documentos EXCETO os selecionados | Ocultar documentos sensíveis permitindo o acesso a todo o resto |
| **Include Mode** | O agent acessa APENAS os itens selecionados | Restringir o agent a um conjunto específico de documentos |

### Opções de Seleção

Refine o acesso usando vários tipos de seleção:

- **Folders** — Selecione pastas inteiras e todos os documentos contidos nelas
- **Tags** — Filtre documentos pelas tags atribuídas
- **Documentos Individuais** — Inclua ou exclua documentos específicos dentro das pastas selecionadas

### Pré-visualização de Acesso

O painel de pré-visualização mostra o acesso efetivo aos documentos com base nas suas seleções atuais. Use-o para verificar sua configuração antes de salvar.

<Callout type="info">
  Comece com **Exclude Mode** se quiser acesso amplo com restrições específicas. Use **Include Mode** quando precisar de controle estrito sobre quais documentos o agent pode consultar.
</Callout>

## Human Handoff

Ative a transferência para chat ao vivo para que seu agent de AI possa transferir conversas para uma pessoa real quando os usuários solicitarem.

**Como ativar:**

1. Na aba **Configuration**, role até a seção **Human Handoff**
2. Ative **Enable Human Handoff**
3. Configure as mensagens:
   - **Handoff Message** — Mostrada ao usuário quando a transferência começa
   - **Resolve Message** — Mostrada quando o agente humano encerra a conversa
   - **Max Wait Time** — Expiração automática se nenhum agente aceitar (5, 15, 30, 60 ou 120 minutos; padrão: 30 minutos)
4. Clique em **Save Changes**

Quando um usuário pede para falar com uma pessoa, a AI cria uma solicitação de handoff visível na página **Inbox**. Um membro da equipe aceita, conversa com o usuário no canal dele e resolve quando termina.

<Callout type="info">
  Human Handoff está disponível em todos os planos. Ative-o por agent na aba Configuration.
</Callout>

## Testar Seu Agent

Antes de salvar as alterações, você pode testar seu agent:

1. Clique no botão **Test Agent** na parte inferior do formulário
2. O painel do Playground se abre
3. Tenha uma conversa de teste com seu agent
4. Feche o Playground quando terminar

<Callout type="info">
  O botão Test Agent fica desativado quando o status do agent é Archived ou Inactive. Mude o status para Active ou Testing para ativar os testes.
</Callout>

## Salvar Alterações

| Botão | Ação |
|--------|--------|
| **Save Changes** | Salva todas as modificações |
| **Test Agent** | Abre o Playground para testar |

Para descartar alterações, saia da página usando o botão de voltar ou a navegação da barra lateral.

**O que é salvo:**
- Apenas os campos alterados são atualizados
- Você verá "No changes to save" se nada foi modificado
- Mensagens de sucesso ou erro aparecem após salvar

**Tratamento de Salvamento Parcial:**
Se algumas alterações forem salvas mas outras falharem, você será notificado sobre quais seções falharam e a página será recarregada para mostrar o estado atual.

<Callout type="info">
  As alterações nas configurações do agent têm efeito imediato após salvar. Teste no Playground depois de fazer alterações.
</Callout>
