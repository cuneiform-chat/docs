# Integração com Slack

Adicione seu agent a workspaces do Slack para acesso de toda a equipe.

## Visão Geral

A integração com Slack oferece:
- Suporte a slash commands (`/ask`)
- Conversas por mensagem direta
- Menções em canais
- Disponibilidade em todo o workspace
- [Anexos de documentos](/integrations/document-attachments) — envie um arquivo e pergunte sobre ele (ativado por padrão, planos pagos)

## Pré-requisitos

- Permissões de admin do workspace do Slack ou de instalação de apps
- Conta do Cuneiform Chat com um agent ativo

## Passos de Configuração

### 1. Iniciar a Configuração da Integração

1. Vá para **Agents** → Selecione seu agent
2. Navegue até a aba **Integrations**
3. Clique em **Slack**
4. Clique em **Add to Slack**

### 2. Autorizar o App

1. Selecione o workspace para instalar
2. Revise as permissões
3. Clique em **Allow**

### 3. Verificar a Instalação

1. Abra o Slack
2. Teste o slash command: `/ask Hello`
3. Confirme que você recebeu uma resposta

## Usando o Bot

### Slash Commands

Use o comando `/ask` em qualquer canal:

```
/ask Qual é a nossa política de reembolso?
```

A resposta aparece no canal (ou como mensagem efêmera, dependendo das configurações).

### Mensagens Diretas

Envie uma mensagem ao bot diretamente para conversas privadas:

1. Encontre o app na barra lateral do Slack
2. Abra uma mensagem direta
3. Converse naturalmente

### Menções em Canais

Mencione o bot em canais para fazer perguntas:

```
@YourBot Quais são as opções de envio?
```

## Recursos

### Acesso em Todo o Workspace

Uma vez instalado, o bot fica disponível para todos os membros do workspace.

### Respostas em Threads

As respostas podem ser publicadas em threads para manter os canais organizados.

### Formatação Rica

As respostas suportam a formatação do Slack:
- Texto em negrito e itálico
- Links
- Blocos de código
- Listas

### Anexos de Documentos

Alguém pode enviar um arquivo em uma DM ou em um canal e perguntar ao seu agent sobre ele. Só são lidos os arquivos **enviados ao Slack** — um arquivo apenas vinculado a partir do Google Drive, do Dropbox ou de outro serviço não é baixado. Vários arquivos em uma mesma mensagem são todos lidos.

No Slack isso vem **ativado por padrão**: um admin pode desativar **Permitir anexos de documentos** no card da integração. Veja [Anexos de Documentos](/integrations/document-attachments) para os tipos suportados, os limites e a configuração.

## Opções de Configuração

### Configurações de Resposta

| Configuração | Descrição |
|---------|-------------|
| Tipo de resposta | In-channel ou ephemeral |
| Comportamento de thread | Responder no thread ou no canal principal |

### Restrições por Canal

Opcionalmente, restrinja o bot a canais específicos para um uso mais focado.

## Suporte Multi-Workspace

Você pode instalar o mesmo agent em vários workspaces do Slack:

1. Cada workspace exige autorização separada
2. Todos os workspaces compartilham o mesmo agent e conteúdo
3. As conversas são rastreadas separadamente por workspace

## Solução de Problemas

### Comando Não Encontrado

Se `/ask` não funcionar:
1. Verifique se o app está instalado no seu workspace
2. Confira se o app tem as permissões corretas
3. Tente reinstalar a integração

### Sem Resposta

Se o bot não responder:
1. Confira se seu agent está configurado e funcionando (teste-o no Playground)
2. Verifique se a integração com Slack está conectada
3. Garanta que o bot tenha acesso ao canal

### Problemas de Permissão

Permissões necessárias:
- `commands` — Para slash commands
- `chat:write` — Para enviar mensagens
- `app_mentions:read` — Para @ menções

## Segurança

- Os OAuth tokens são criptografados
- Sem acesso às mensagens, exceto por comandos/menções explícitos
- Os dados do workspace permanecem privados

## Desconectando

Para remover a integração com Slack:

1. **No Cuneiform Chat:**
   - Agents → Selecione o agent → Integrations → Slack → Disconnect

2. **No Slack:**
   - Vá para as configurações do workspace
   - Apps → Encontre o app → Remove

Os dois passos garantem a remoção completa.
