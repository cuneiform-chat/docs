# Integrações

Implante seus agents em vários canais e alcance os usuários onde quer que eles estejam.

## Canais Disponíveis

| Canal | Descrição | Ideal Para |
|---------|-------------|----------|
| [Telegram](/integrations/telegram) | Bot do Telegram | Usuários mobile, comunidades |
| [Discord](/integrations/discord) | Bot do Discord com slash commands | Gaming, comunidades de desenvolvedores |
| [Slack](/integrations/slack) | App do Slack | Espaços de trabalho em equipe |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | Comunicação com clientes |
| [Google Chat](/integrations/google-chat) | App do Google Workspace | Equipes corporativas |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | Público de consumidores |
| [Website Widget](/integrations/website-widget) | Widget de chat incorporável | Atendimento ao cliente, qualquer site |

## Como as Integrações Funcionam

1. **Configurar** — Configure a integração para o canal escolhido
2. **Conectar** — Vincule seu agent ao canal
3. **Implantar** — Seu agent fica disponível para os usuários
4. **Monitorar** — Acompanhe conversas e uso

## Implantação Multicanal

Um único agent pode ser implantado em vários canais simultaneamente:

- Mesmo conteúdo em todos os canais
- Respostas consistentes em todos os lugares
- Histórico de conversas centralizado
- Analítica unificada

## Recursos Específicos por Canal

Cada canal tem capacidades únicas:

- **Telegram** — Mensagens enriquecidas, teclados inline
- **Discord** — Slash commands, integração com servidores
- **Slack** — Apps de workspace, respostas em canais
- **WhatsApp** — Mensageria empresarial, mídia rica
- **Google Chat** — Integração com Google Workspace, suporte a Spaces, perguntas e respostas sobre documentos + Base de Conhecimento do Space
- **Meta (Facebook)** — Integração com Messenger, mensagens de Page
- **Website Widget** — Chat incorporável, aparência personalizável, lista de domínios permitidos

## Requisitos

Antes de configurar as integrações:

1. ✅ Crie pelo menos um agent
2. ✅ Faça upload de documentos para o seu conteúdo
3. ✅ Teste seu agent no Playground

Cada canal pode ter requisitos adicionais (bot tokens, credenciais de app, etc.) detalhados em seus respectivos guias.
