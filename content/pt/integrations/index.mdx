# Integrações

Implante seus agents em múltiplos canais e alcance os usuários onde quer que estejam.

## Canais Disponíveis

| Canal | Descrição | Melhor Para |
|-------|-----------|-------------|
| [Telegram](/integrations/telegram) | Bot do Telegram | Usuários mobile, comunidades |
| [Discord](/integrations/discord) | Bot do Discord com slash commands | Gaming, comunidades de desenvolvedores |
| [Slack](/integrations/slack) | App do Slack | Workspaces de equipe |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | Comunicação com clientes |
| [Google Chat](/integrations/google-chat) | App do Google Workspace | Equipes enterprise |
| [Meta (Facebook)](/integrations/facebook) | Facebook Messenger | Público consumidor |
| [Website Widget](/integrations/website-widget) | Widget de chat incorporável | Suporte ao cliente, qualquer website |

## Como as Integrações Funcionam

1. **Configure** — Configure a integração para o canal escolhido
2. **Conecte** — Vincule seu agent ao canal
3. **Implante** — Seu agent fica disponível para os usuários
4. **Monitore** — Acompanhe conversas e uso

## Implantação Multi-Canal

Um único agent pode ser implantado em múltiplos canais simultaneamente:

- Mesmo conteúdo em todos os canais
- Respostas consistentes em todos os lugares
- Histórico de conversas centralizado
- Analytics unificado

## Recursos Específicos por Canal

Cada canal tem capacidades únicas:

- **Telegram** — Mensagens ricas, teclados inline
- **Discord** — Slash commands, integração com servidor
- **Slack** — Apps de workspace, respostas em canais
- **WhatsApp** — Mensagens empresariais, mídia rica
- **Google Chat** — Integração com Google Workspace, suporte a Spaces
- **Meta (Facebook)** — Integração com Messenger, mensagens de página
- **Website Widget** — Chat incorporável, aparência personalizável, allowlisting de domínios

## Requisitos

Antes de configurar integrações:

1. ✅ Crie pelo menos um agent
2. ✅ Envie documentos para seu conteúdo
3. ✅ Teste seu agent no Playground

Cada canal pode ter requisitos adicionais (tokens de bot, credenciais de app, etc.) detalhados nos seus respectivos guias.
