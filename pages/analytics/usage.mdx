# Usage Metrics

Track your resource consumption and plan utilization.

## Usage Overview

The usage dashboard shows:
- Current period consumption
- Plan limits and remaining capacity
- Historical usage trends

## Key Metrics

### Message Volume

| Metric | Description |
|--------|-------------|
| AI queries | Questions processed by agents |
| Total messages | All messages (including user messages) |
| Daily average | Average queries per day |

### Document Processing

| Metric | Description |
|--------|-------------|
| Documents processed | Files uploaded and indexed |
| Storage used | Total storage consumption |
| Processing capacity | Monthly processing limit |

## Usage by Agent

Compare usage across your agents:
- Which agents handle the most queries
- Storage per agent's knowledge base
- Channel distribution per agent

## Usage Trends

### Charts

Visualize usage over time:
- Daily query volume
- Weekly patterns
- Month-over-month comparison

### Patterns

Identify trends:
- Growing or declining usage
- Peak usage periods
- Seasonal patterns

## Plan Limits

### Current Plan

View your plan details:
- Included queries/credits
- Storage allocation
- Feature access

### Usage vs. Limits

Monitor your consumption:
- Percentage of limits used
- Projected usage for the period
- Days remaining in billing cycle

## Usage Warnings

The dashboard displays automatic warnings when:

- Approaching your monthly credit limit
- Usage limit is reached or exceeded

These warnings appear as banners in your dashboard to help you take action before service is affected.

## Optimization Tips

### Reduce Query Usage

- Improve system prompts for better first-response accuracy
- Add FAQ content to reduce follow-up questions
- Optimize knowledge base for faster retrieval

### Manage Storage

- Remove outdated documents
- Avoid duplicate uploads
- Use efficient file formats

## Historical Data

Access historical usage data:
- Previous billing periods
- Long-term trends
- Year-over-year comparison

## Usage Reports

View usage summaries directly in the dashboard:

- Monthly summaries
- Detailed breakdowns by agent and channel
- Historical comparisons
