# Conversation Analytics

Deep dive into your conversation data to understand user interactions.

## Conversation Overview

### Volume Metrics

| Metric | Description |
|--------|-------------|
| Total conversations | Chat sessions started |
| Completed conversations | Sessions with responses |
| Avg. duration | Average conversation length |
| Peak hours | Busiest times |

### Conversation List

View individual conversations:
- Date and time
- Channel (web, Telegram, etc.)
- Message count
- Agent used

Click any conversation to see the full transcript.

## Conversation Details

### Transcript View

See the complete conversation flow:
- User messages
- Agent responses
- Timestamps
- Sources cited

### Metadata

Additional information for each conversation:
- User identifier (anonymized)
- Channel source
- Duration
- Agent configuration at time of chat

## Analyzing Conversations

### Find Issues

Look for patterns in problematic conversations:
- Questions the agent couldn't answer
- Repeated clarification requests
- User frustration signals

### Identify Successes

Learn from good interactions:
- Questions answered well
- Positive feedback signals
- Efficient resolution

## Filtering Options

Filter conversations by:

| Filter | Options |
|--------|---------|
| Date range | Custom start and end dates |
| Agent | Specific agent or all agents |
| Channel | Web, Telegram, Discord, etc. |
| Status | Completed, abandoned |

## Search

Search conversation transcripts for:
- Specific questions
- Topics or keywords
- User feedback

Export conversation data for external analysis:
- CSV format for spreadsheets
- Date range selection
- Filtered exports

## Privacy Considerations

Conversation data is handled according to:
- Your data retention settings
- Privacy policy requirements
- User consent where applicable

You can configure retention periods in account settings.
