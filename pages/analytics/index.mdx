# Analytics

Monitor your agents' performance and understand how users interact with your chatbots.

## Overview

Analytics help you:
- Track conversation volume and patterns
- Monitor agent performance
- Understand user behavior
- Identify areas for improvement

## Dashboard

Access analytics from the **Analytics** section in your dashboard.

### Key Metrics

| Metric | Description |
|--------|-------------|
| Total conversations | Number of chat sessions |
| Messages | Total messages exchanged |
| Unique users | Individual users who chatted |
| Avg. messages per conversation | Engagement depth |

## Time Periods

View analytics for different time ranges:
- Last 24 hours
- Last 7 days
- Last 30 days
- Custom date range

## Filtering

Filter analytics by:
- **Agent** — See metrics for specific agents
- **Channel** — Compare performance across channels
- **Date range** — Analyze specific time periods

## Using Analytics

### Identify Popular Topics

See what users ask about most frequently to:
- Improve your knowledge base
- Create targeted content
- Refine agent responses

### Monitor Performance

Track trends to ensure:
- Response quality remains high
- User engagement is healthy
- No unusual patterns

### Optimize Agents

Use insights to:
- Adjust system prompts
- Add missing documentation
- Improve response accuracy
