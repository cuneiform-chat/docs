## Billing Dashboard

Access billing from **Settings** → **Billing**:

- Current plan and status
- Usage this period
- Payment history
- Manage subscription

## Quick Actions

| Action | Location |
|--------|----------|
| View current plan | Billing dashboard |
| Upgrade plan | Billing → Upgrade |
| View invoices | Billing → History |
| Update payment | Billing → Payment Method |

## Billing Cycle

- Plans are billed monthly
- Usage resets at the start of each billing period
- Upgrades take effect immediately
- Downgrades take effect at the next billing period

## Payment Methods

Accepted payment methods:
- Credit cards (Visa, Mastercard, Amex)
- Debit cards
