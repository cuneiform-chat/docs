# Integrations

Deploy your agents to multiple channels and reach users wherever they are.

## Available Channels

| Channel | Description | Best For |
|---------|-------------|----------|
| [Telegram](/integrations/telegram) | Telegram bot | Mobile users, communities |
| [Discord](/integrations/discord) | Discord bot with slash commands | Gaming, developer communities |
| [Slack](/integrations/slack) | Slack app | Team workspaces |
| [WhatsApp](/integrations/whatsapp) | WhatsApp Business | Customer communication |
| [Google Chat](/integrations/google-chat) | Google Workspace app | Enterprise teams |
| [Meta (Facebook)](/integrations/meta) | Facebook Messenger | Consumer audience |
| [Website Widget](/integrations/website-widget) | Embeddable chat widget | Customer support, any website |

## How Integrations Work

1. **Configure** — Set up the integration for your chosen channel
2. **Connect** — Link your agent to the channel
3. **Deploy** — Your agent becomes available to users
4. **Monitor** — Track conversations and usage

## Multi-Channel Deployment

A single agent can be deployed to multiple channels simultaneously:

- Same content across all channels
- Consistent responses everywhere
- Centralized conversation history
- Unified analytics

## Channel-Specific Features

Each channel has unique capabilities:

- **Telegram** — Rich messages, inline keyboards
- **Discord** — Slash commands, server integration
- **Slack** — Workspace apps, channel responses
- **WhatsApp** — Business messaging, rich media
- **Google Chat** — Google Workspace integration, spaces support
- **Meta (Facebook)** — Messenger integration, page messaging
- **Website Widget** — Embeddable chat, customizable appearance, domain allowlisting

Before setting up integrations:

1. ✅ Create at least one agent
2. ✅ Upload documents to your content
3. ✅ Test your agent in the Playground

Each channel may have additional requirements (bot tokens, app credentials, etc.) detailed in their respective guides.
