# Configuration Options

Detailed guide to all agent configuration options.

## Basic Settings

### Name and Description

- **Name** — Identifies the agent in your dashboard
- **Description** — Internal notes about the agent's purpose

### System Prompt

The instructions that control agent behavior. See [System Prompts](/agents/system-prompts) for best practices.

### AI Prompt Builder

Use the AI Prompt Builder to generate a custom system prompt based on personality characteristics. Click **Generate** next to the System Prompt field to open the builder.

#### Builder Tabs

| Tab | Purpose |
|-----|---------|
| **Custom Build** | Select characteristics to generate a unique persona |
| **Use Preset** | Load system presets or your saved organization presets |
| **Platform Rules** | View the read-only guardrails applied to all agents |

#### Custom Build Characteristics

Configure your agent's personality across 5 categories:

| Category | Options | What It Controls |
|----------|---------|------------------|
| **Role & Identity** | Customer support, Sales consultant, Tech support, HR specialist, etc. | Agent's primary function |
| **Communication Style** | Formality (formal/casual), Tone (warm/neutral), Verbosity (concise/detailed), Technical level | How the agent communicates |
| **Response Behavior** | Format (conversational/bullet points), Proactivity, Question handling | How responses are structured |
| **Operational Boundaries** | Scope strictness, Escalation tendency, Out-of-scope handling | How strictly agent stays on topic |
| **Knowledge Integration** | Citation style, Uncertainty handling | How agent references your documents |

#### Using Presets

- **System Templates** — Platform-provided presets for common use cases
- **My Templates** — Presets saved by your organization admins

Click any preset to load its characteristics, then customize further or generate directly.

#### Platform Rules

These guardrails are automatically applied to ensure reliable, safe responses:

- **No fabrication** — Won't invent facts not in your knowledge base
- **Acknowledges gaps** — Says "I don't have that information" rather than guessing
- **Resists speculation** — Won't estimate missing values even when prompted
- **No professional impersonation** — Won't role-play as attorneys, doctors, or financial advisors
- **Corrects false premises** — Points out incorrect assumptions before answering
- **Blocks harmful content** — Refuses self-harm, explicit, or fraudulent content

#### Workflow

1. Click **Generate** to open the AI Prompt Builder
2. Configure characteristics in Custom Build, or select a preset
3. Click **Generate Persona** to create the prompt
4. Review and edit the generated text in the preview panel
5. Optionally click **Save as Preset** to reuse later
6. Click **Apply to Agent** to use the generated prompt

## Response Configuration

### Temperature

Controls how creative or focused the agent's responses are:

| Value | Behavior |
|-------|----------|
| 0.0 - 0.3 | Focused, deterministic responses |
| 0.4 - 0.7 | Balanced creativity and consistency |
| 0.8 - 1.0 | More creative, varied responses |

**Recommendation:** Start with 0.3-0.5 for factual Q&A based on documents.

### Max Response Length

Limits how long responses can be. Consider:

- **Short (256 tokens)** — Quick answers, mobile-friendly
- **Medium (512 tokens)** — Standard responses
- **Long (1024+ tokens)** — Detailed explanations

## Knowledge Settings

### Knowledge Access Control

Control which documents your agent can access when responding to queries.

#### Access Modes

Choose how the agent interacts with your knowledge base:

| Mode | Behavior | When to Use |
|------|----------|-------------|
| **Exclude Mode** | Agent accesses ALL documents EXCEPT those selected | Hide sensitive documents while allowing access to everything else |
| **Include Mode** | Agent accesses ONLY selected items | Restrict agent to a specific set of documents |

#### Selection Options

Fine-tune access using multiple selection types:

- **Folders** — Select entire folders and all documents within them
- **Tags** — Filter documents by their assigned tags
- **Individual Documents** — Include or exclude specific documents within selected folders

#### Access Preview

The preview panel shows the effective document access based on your current selections. Use this to verify your configuration before saving.

### Retrieval Settings

Fine-tune how the agent finds information:

- **Number of sources** — How many document chunks to retrieve
- **Similarity threshold** — Minimum relevance score

## Conversation Settings

### Greeting Message

The message displayed when a conversation starts. Leave empty for no greeting.

### Conversation Memory

How the agent handles conversation context:

- **Full context** — Remembers entire conversation
- **Limited context** — Only recent messages

Choose the underlying AI model (if available on your plan).
