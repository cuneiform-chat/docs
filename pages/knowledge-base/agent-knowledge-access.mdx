# Agent Knowledge Access

Control which documents each agent can access when answering questions. Restrict agents to specific folders or tags, or exclude certain content from their reach.

## Getting There

1. Navigate to **Agents** in the sidebar
2. Click on an agent to edit it, or create a new agent
3. Scroll to the **Knowledge Access Control** section

## Access Modes

The access mode determines how your selections affect the agent's document access.

| Mode | Icon | Description | Use When |
|------|------|-------------|----------|
| **Exclude Mode** | Red X | Agent accesses ALL documents EXCEPT selected | You want to hide sensitive documents but allow everything else |
| **Include Mode** | Green Check | Agent accesses ONLY selected documents | You want to restrict the agent to specific content |

### Choosing the Right Mode

**Exclude Mode** (default):
- Starts with full access to all documents
- Select folders/tags to block from the agent
- Good for: Hiding HR documents, financial data, or drafts

**Include Mode**:
- Starts with no access
- Select folders/tags to grant access
- Good for: Creating specialized agents for specific topics

## Selecting Content

### By Folders

1. Click the **Folders** tab
2. Use the search box to find folders
3. Check folders to include/exclude
4. Expand folders (click arrow) to select individual documents
5. A checkmark shows selected items; partial selection shows a dash

### By Tags

1. Click the **Tags** tab
2. Use the search box to find tags
3. Check tags to include/exclude
4. Each tag shows how many documents use it

## Preview Panel

The preview panel on the right shows:
- Total accessible documents based on current selection
- Updates in real-time as you make changes

## Saving Changes

When editing an existing agent:
1. Make your selections
2. Click **Save Changes** (green button)
3. Or click **Reset Changes** to undo unsaved changes

When creating a new agent:
- Knowledge access settings save automatically when you submit the agent form

## Tips

- Use **Exclude Mode** when you want broad access with a few exceptions
- Use **Include Mode** for focused, topic-specific agents
- Combine folders AND tags for precise control
- Check the preview panel to verify your selection before saving
- For Include Mode, you must select at least one folder or tag

## Common Questions

**Q: What happens if I select both folders and tags?**
A: The agent can access documents that match ANY of your selections. Folders and tags combine inclusively.

**Q: Can I give an agent access to everything?**
A: Yes. Use Exclude Mode and don't select anything to exclude. The agent will have full access.

**Q: What if a document is in a selected folder but has an excluded tag?**
A: In Exclude Mode, any match to excluded content blocks access. In Include Mode, any match to included content grants access.

**Q: Does this affect existing conversations?**
A: Yes. Changes take effect immediately for new messages. The agent will use the updated access rules.
